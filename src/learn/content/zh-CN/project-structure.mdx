你刚刚在 Mastra Studio 中运行了 Weather Agent。本课将带你查看构建过程中会持续编辑的核心文件，先弄清楚眼前的各个部分，再开始扩展项目。

你将打开 Agent 文件，了解如何通过 instructions、模型选择、Tool 访问和 Memory 定义行为；再查看 Tool 文件，理解如何为 Tool 定义清晰的输入和输出，并在运行时完成验证；最后浏览 Workflow 文件，了解多步骤逻辑如何连接，以及如何在 Studio 中预览。

Mastra 应用由少量可组合的基础单元构成，其中的约束是有意设计的：Agent 只能使用挂载给它的 Tool，也只能基于这些 Tool 返回的数据结构进行推理。熟悉这三类文件后，你就能更快调试，并基于同样的模式构建自己的主题公园 Agent。

> “Agent 只能调用你挂载的 Tool，也只能处理 Tool 返回的数据。因此，正确设计边界和数据结构，会让后续所有工作更容易。”
>
> — Guil Hernandez
