课程刚刚开始，本课将搭建并运行 Mastra 环境，以便在构建主题公园 Agent 时快速迭代。你会创建一个新的独立项目脚手架，配置模型 Provider，并验证整个流程能够端到端运行。

你将运行开发 Server，使用 Mastra Studio 与默认 Agent 交互、单独测试 Tool，并逐步执行示例 Workflow。在此过程中，你会看到即使还没有构建前端，Studio 也能帮助检查输出并了解系统正在做什么。

随着课程推进，CLI 生成的项目结构将承载所有 Agent、Tool、Workflow 和配置。现在熟悉 Studio 和可观测性功能，能让你在 Agent 逐渐复杂后，仍有可靠的方法调试意外输出并跟踪质量。

> “Studio 是开发和测试 Mastra 应用的地方。甚至在开始编写前端之前，你就能运行所有内容、检查发生了什么并快速迭代。”
>
> — Guil Hernandez
