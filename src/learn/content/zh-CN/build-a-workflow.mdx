Agent 已经能够查询公园、获取实时排队时间、抓取更多公园详情并考虑天气因素，但有些任务无法通过一次 Tool 调用完成。本课将构建一个多步骤购票 Workflow，并加入 Human-in-the-Loop 审批门禁。

你将创建一个模拟购票 Workflow，其中包含三个明确步骤：生成报价、暂停等待用户批准，以及处理扣款。每个步骤都有自己的输入和输出 schema，数据可以清晰地从一个步骤流向下一个步骤。随后将 Workflow 接入 Mastra 入口并在 Studio 中运行，观察每个步骤按顺序执行，包括 suspend 和 resume。

有些逻辑具有确定性，不应交给语言模型处理，例如计算费用、验证输入和确认金额。Workflow 让你完全掌控执行顺序，并提供清晰的暂停点，以便在任何资金操作发生之前获得批准。

> “如果某件事是确定性的，就不要让模型推理，直接把它放进 Workflow 步骤。”
>
> — Guil Hernandez
