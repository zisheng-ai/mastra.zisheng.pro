本课将在 Mastra 项目中添加一个全新的主题公园 Agent，并让它显示在 Mastra Studio 中。这一步保持简单，暂时不加入 Tool 或 Workflow，以便先建立一个可以运行、调整和调试的清晰基线。

你将创建 Agent 文件，编写简洁的 instructions 来控制语气和行为，然后把 Agent 接入应用，使它可以在 Studio 中使用。最后运行一个简单的测试 prompt，确认 Agent 按预期响应。

instructions 是后续所有能力的基础。只有 Agent 的默认行为足够可靠，Tool、Workflow 和外部数据才能真正发挥作用。你还会使用 Studio 的可观测性界面，确认模型实际看到和生成了什么，并观察启用 Memory 后，后续对话如何从“无状态”转变为连贯的持续对话。

> “从简单开始，先确定 Agent 的行为和输出格式。确认基线正常工作后，再添加 Tool 等能力。”
>
> — Guil Hernandez
