项目已经进入编辑器中的 coding Agent 真正与你协作的阶段。本课重点介绍如何确保 AI 提供准确的帮助。Guil 将演示一套实用配置，避免 Agent 猜测或使用过时的 Mastra 模式。

你将了解 Mastra Skill 如何存放在项目中、Agent 实际会读取哪些文件，以及这些参考资料如何指导代码生成和修改。随后还会了解何时应该配合 MCP 文档 Server 使用，以便直接查询最新文档和迁移指南。

“过时或凭空编造的 Mastra 细节”是 AI 辅助编程最常见的失误之一。为 Agent 提供可靠的本地知识源，并在需要时用在线文档作为 fallback，可以减少返工，让主题公园 Agent 项目中的实现始终与 Mastra 的真实 API 和模式保持一致。

> “最大的失败模式，是 coding Agent 自信地编造 Mastra 细节。因此我们把 Skill 直接放进仓库，让它工作时可以读取真正的模式。”
>
> — Guil Hernandez
