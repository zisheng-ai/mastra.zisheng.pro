随着课程推进，主题公园 Agent 正从“按照 instructions 对话”逐步转变为能够可靠处理真实数据。本课将补上第一个缺失的构建模块：让 Agent 把用户输入的公园名称转换为规范公园 ID 的 Tool。

你将创建专用的公园查询 Tool：调用远程 endpoint，使用 schema 验证输入和输出，并在名称存在歧义时返回少量匹配项。随后直接在 Mastra Studio 中测试，再将它接入主题公园 Agent，使 Agent 能够在对话中自动调用。

所有后续 Q Times 请求都依赖正确的公园 ID，而不能只靠猜测公园名称。通过验证 Tool 的返回结构，并在可观测性界面中检查 Tool 调用，可以为下一步获取实时排队时间建立可靠基础。

> “当 Agent 需要真实上下文时就应该使用 Tool，例如把公园名称转换为其他所有 API 调用都依赖的唯一 ID。”
>
> — Guil Hernandez
