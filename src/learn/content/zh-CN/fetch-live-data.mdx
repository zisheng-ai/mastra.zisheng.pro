公园查询已经正常工作，接下来要让主题公园 Agent 真正发挥作用。本课将添加一项新能力：获取公园当前状况的实时快照。

你将创建一个接收公园 ID 的 Tool，返回经过筛选的游乐设施列表，其中包含园区位置、开放状态和当前公布的排队时间等关键字段。结果还会按排队时间排序，让等待时间最短的项目显示在顶部，便于 Agent 直接给出建议。

公园的实时状况变化很快，Agent 需要最新的结构化数据，才能规划切实可行的一日路线。你还会把 Tool 接入 Agent，并在 Mastra Studio 中测试完整的“查询 → 实时快照”调用链，确保 Agent 总能在正确的时机调用正确的 Tool。

> “排队时间变化很快，因此一定要返回数据的获取时间。时间戳让这份快照更可信。”
>
> — Guil Hernandez
