主題樂園 Agent 已經部署，並可透過 HTTP 存取。在本課中，你會使用 Mastra 的 Channels 功能將它連接至 Slack，這樣無論在哪裏使用 Slack，都可以向它傳送訊息。

你會安裝 `@chat-adapter/slack` 依賴套件、在主題樂園 Agent 加入 `channels` 設定，並建立一個具備正確 scope 的 Slack app。Mastra 會自動公開 webhook 路由。只要將 Slack 的 Event Subscriptions 指向該路由，訊息便會直接傳送至 Agent。

同一套 Tool、Memory，以及設有批准關卡的購票 Workflow，都可以從私人訊息中運行。Channels 亦以相同模式支援 Discord 和 Telegram：安裝 adapter、將它加入 `channels.adapters`、設定環境變數、部署，然後把平台 webhook 指向 Mastra 產生的路由。

> 「你毋須自行建立 webhook handler，也毋須自行驗證 Slack signature。這一切都由 adapter 處理。」
>
> — Guil Hernandez
