主題樂園 Agent 已經啟用 Memory。在本課中，你會深入了解這實際代表甚麼：為何模型在不同調用之間仍然是無狀態，以及 Mastra 如何讓後續問題正常運作。

你會在 Studio 中追蹤一個真實的後續 prompt，清楚查看 Agent 收到的情境，並了解 `lastMessages`：這項設定控制每次調用會包含多少近期對話記錄。Mastra 會將訊息保存至儲存空間，再於之後的輪次重新加入，讓模型取得所需內容。

這一點很重要，因為 Memory 並非魔法。你真正進行的是 context engineering：決定模型在每次調用時可以看到甚麼。理解這一點後，你便能更容易分析 Agent 行為，並在結果看似不對勁時進行除錯。

> 「模型仍然是無狀態。Mastra 會儲存情境，再於之後的調用中重新加入。」
>
> — Guil Hernandez
