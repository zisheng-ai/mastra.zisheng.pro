主題樂園 Agent 現在已經可以取得樂園 ID 和即時輪候時間，但仍缺少 QTimes JSON API 無法提供的重要規劃資訊。在本課中，你會透過外部 Tool 來源擴展 Agent，讓它能回答樂園開放時間和人流預測等問題。

你會將 Agent 連接至 MCP 伺服器，引入網絡內容提取 Tool，並讓這些 Tool 與現有本地 Tool 一起使用。然後，你會更新 Agent 的指引，讓它知道何時應先查找樂園 ID，以及何時從樂園網頁取得結構化詳情。

這一點很重要，因為現實世界的助手很少能從單一 API 取得所有資料。結合即時 API 數據和網頁的結構化提取結果，並在相關時加入天氣資料，便能讓 Agent 可靠地補足資訊缺口，而毋須為每種情況建立一次性的 scraper。

> 「單是提供 Tool 存取權限，並不保證 Agent 會採取正確行為；你必須教它何時使用 Tool，以及為甚麼要使用。」
>
> — Guil Hernandez
