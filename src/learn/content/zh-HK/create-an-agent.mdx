在本課中，你會在 Mastra 項目中加入一個全新的主題樂園 Agent，並讓它顯示於 Mastra Studio。這個步驟講求「保持簡單」——暫時不加入 Tool 或 Workflow——讓你專注建立一個可以執行、調整和除錯的乾淨基準。

你會建立 Agent 檔案、編寫精簡的 instructions 區塊來控制語氣和行為，然後把 Agent 接入應用程式，讓它可以在 Studio 中使用。之後，你會執行一個快速測試 prompt，確認 Agent 按照你的預期回應。

這一點很重要，因為 instructions 是日後加入所有功能的基礎——只有 Agent 的預設行為本身穩健，Tool、Workflow 和外部數據才能真正發揮作用。你亦會使用 Studio 的 observability 檢視，確認模型實際接收和產生了甚麼內容，並了解啟用 Memory 後，後續問題如何由「無狀態」變成一致而持續的對話。

> 「由簡單開始——先確定 Agent 的行為和輸出格式。確認基準正常運作後，才加入 Tool 等功能。」
>
> — Guil Hernandez
