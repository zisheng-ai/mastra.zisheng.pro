你已經完成樂園查找功能，現在會再進一步，讓主題樂園 Agent 真正變得實用。在本課中，你會加入一項新功能，取得樂園當下情況的即時快照。

你會建立一個 Tool，接收樂園 ID，並傳回精選遊樂設施清單，包含位置／園區、開放狀態和目前公佈輪候時間等重要欄位。你亦會確保結果已經排序，讓輪候時間最短的設施排在最前，輸出可以立即用於提供建議。

這一點很重要，因為樂園的即時情況變化迅速，而 Agent 需要最新的結構化數據，才能規劃一條切合實際的全日路線。你亦會把 Tool 接入 Agent，並在 Mastra Studio 測試完整的「查找 → 即時快照」流程，確保 Agent 每次都在正確時間調用正確的 Tool。

> 「輪候時間變化很快，所以必須傳回取得數據的時間。這個時間戳記能令快照更可靠。」
>
> — Guil Hernandez
