你正處於課程初段，本課的重點是設定並運行 Mastra 環境，讓你在建立主題樂園 Agent 的過程中可以快速反覆開發。你會 scaffold 一個新的獨立項目、設定模型 Provider，並驗證整個流程都能正常運作。

你會啟動開發伺服器，使用 Mastra Studio 與預設 Agent 互動、獨立測試 Tool，並逐步執行範例 Workflow。在這個過程中，你會了解 Studio 如何協助你檢視輸出和理解系統運作，而毋須先建立任何 frontend。

這一點很重要，因為隨着課程推進，由 CLI 產生的項目結構會成為所有 Agent、Tool、Workflow 和設定的所在。現在熟習 Studio 和 observability，能讓你可靠地對意外輸出進行除錯，並隨着 Agent 變得更複雜持續追蹤質素。

> 「Studio 是你開發和測試 Mastra 應用程式的地方——你可以執行所有內容、檢視發生過的事，並在接觸 frontend 之前快速反覆改進。」
>
> — Guil Hernandez
