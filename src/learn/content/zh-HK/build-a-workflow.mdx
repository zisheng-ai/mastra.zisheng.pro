Agent 已經能夠查找樂園、取得即時輪候時間、抓取更多樂園詳情，並將天氣納入考慮。不過，有些工作無法透過一次 Tool 調用完成。在本課中，你會建立一個多步驟購票 Workflow，並加入 human-in-the-loop 批准關卡。

你會建立一個模擬購票 Workflow，當中包含三個明確步驟：建立報價、暫停以等待用戶批准，以及處理收費。每個步驟都有自己的輸入和輸出 schema，讓數據可以清晰地由一個步驟流向下一個。你會把 Workflow 接入 Mastra 進入點，並在 Studio 中執行，觀察每個步驟依次運行，包括暫停與繼續。

這一點很重要，因為某些邏輯具有確定性，不應交由語言模型處理，例如計算費用、驗證輸入和確認金額。Workflow 讓你掌控執行次序，也提供一個清晰的位置，讓你在轉移任何款項之前暫停並等待批准。

> 「如果一件事具有確定性，就不要讓模型推理。直接把它放進 Workflow 步驟即可。」
>
> — Guil Hernandez
