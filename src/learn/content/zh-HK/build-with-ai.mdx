項目開發到這個階段，你的編輯器內的編程助手開始真正與你並肩工作，而本課會集中講解如何確保它提供準確的協助。Guil 會介紹實際設定，避免編程助手胡亂猜測或使用過時的 Mastra 模式。

你會了解 Mastra Skill 如何存在於項目中、編程助手實際會讀取哪些檔案，以及這些參考資料如何指導程式碼產生和編輯。然後，你會看看何時應該以 MCP 形式的文件伺服器補充 Skill，直接查詢最新文件和遷移協助。

這一點很重要，因為「過時或虛構的 Mastra 細節」是 AI 輔助編程失控的最常見原因之一。為編程助手提供可靠的本地知識來源，並在有需要時以即時文件作後備，便能減少重做工作，並在你繼續為主題樂園 Agent 項目建立 Tool 時，確保實作符合 Mastra 真正的 API 和模式。

> 「最常見的失敗情況，是編程助手自信地虛構 Mastra 細節；所以我們把 Skill 直接放進儲存庫，讓它在工作時讀取真正的模式。」
>
> — Guil Hernandez
