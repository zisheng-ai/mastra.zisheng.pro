你已經建立購票 Workflow，現在正好可以清楚區分 Agent 和 Workflow 各自的作用。人們有時會寬鬆地使用這些術語，但這裏真正重要的，是它們在實際運作時有甚麼不同，以及如何在這個項目中互相配合。

Agent 是系統中「會說話的大腦」：一個配備 Tool 和 Memory 的語言模型。它的路徑並非預先定義；模型會自行決定要做甚麼、調用哪些 Tool，以及何時完成。Workflow 則相反：步驟、次序和「完成」的定義都由你設定。購票流程就是最清楚的例子。你不是要求模型自行摸索結帳流程，而是親自定義它。在 Mastra 中，你可以將兩者結合：在 Workflow 內使用 Agent，或將 Workflow 作為 Agent 的 Tool。

這一點很重要，因為懂得選擇合適方式，能避免你把簡單工作過度設計成 Workflow，或要求模型處理本應具確定性並受控的工作。

> 「我們不是要求模型自行摸索結帳流程，而是由我們定義結帳流程。」
>
> — Guil Hernandez
