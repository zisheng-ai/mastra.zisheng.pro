你一直在 Studio 中建立主題樂園 Agent。要與其他人分享，就必須讓它在公開位置運行。在本課中，你會把它部署至 Mastra Server，也就是 Mastra 為 Agent 提供的雲端部署產品。只需一個指令，便能將本地項目部署成正式 endpoint，而路由、擴展和基礎設施都由平台管理。

部署前，你會瀏覽位於 `http://localhost:4111/swagger-ui` 的 Swagger UI。主題樂園 Agent 和本課程中的其他 Agent，都已經在該處公開為 HTTP endpoint，包括產生回應、串流及執行 Workflow 的路由。然後，`mastra server deploy` 會進行身分驗證、建立 Docker image、部署，並輸出一個穩定 URL。

Mastra 本身已經是 HTTP 伺服器，Studio 只是你在本地與它互動的其中一種方式。Mastra Server 會把同一個伺服器放到公開 URL，讓任何服務都可以透過 endpoint 調用主題樂園 Agent。

> 「Mastra 本身已經是 HTTP 伺服器。Studio 只是你在本地與它互動的其中一種方式，而 Mastra Server 會把同一個伺服器放到公開位置。」
>
> — Guil Hernandez
