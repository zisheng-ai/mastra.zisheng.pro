Studio에서 Theme Park Agent를 구축해 왔습니다. 다른 사람과 공유하려면 공개된 위치에서 실행되어야 합니다. 이 레슨에서는 Agent를 위한 Mastra의 클라우드 배포 제품인 Mastra Server에 배포합니다. 하나의 명령으로 라우팅, 확장 및 인프라가 관리되는 라이브 엔드포인트로 로컬 프로젝트를 이동할 수 있습니다.

배포하기 전에 `http://localhost:4111/swagger-ui`에서 Swagger UI를 살펴보겠습니다. 이 과정의 테마파크 Agent와 다른 모든 Agent는 이미 응답 생성, 스트리밍 및 Workflow 실행을 위한 경로인 HTTP 엔드포인트로 노출되어 있습니다. 그런 다음 `mastra server deploy`는 인증하고 Docker 이미지를 구축하고 배포한 후 안정적인 URL을 인쇄합니다.

Mastra는 이미 HTTP 서버입니다. Studio는 로컬에서 대화하는 한 가지 방법일 뿐입니다. Mastra Server는 동일한 서버를 공용 URL에 배치하고 Theme Park Agent는 모든 서비스가 호출할 수 있는 엔드포인트가 됩니다.

> "Mastra는 이미 HTTP 서버입니다. Studio는 로컬로 통신하는 한 가지 방법일 뿐입니다. Mastra Server는 동일한 서버를 공개된 곳에 배치합니다."
>
> — 길 에르난데스
