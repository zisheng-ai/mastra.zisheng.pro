在本課程中，你會在 Mastra 專案中加入全新的 Theme Park Agent，並讓它顯示在 Mastra Studio 中。這是一個「保持簡單」的步驟，暫時不加入 Tool 或 Workflow，讓你能專注建立一個可以執行、調整及偵錯的簡潔基準。

你會建立 Agent 檔案、撰寫精簡的指示區塊來控制語氣與行為，再將 Agent 連接至應用程式，使其能在 Studio 中使用。之後，你會執行一個簡短的測試提示詞，確認 Agent 的回應符合預期。

這點很重要，因為指示是你之後加入所有項目的基礎；只有 Agent 的預設行為已經穩固，Tool、Workflow 和外部資料才能真正發揮作用。你也會使用 Studio 的 Observability 檢視畫面，確認模型實際接收和產生的內容，並了解啟用 Memory 後，如何讓後續互動從「無狀態」轉變為一致且持續的對話。

> 「先從簡單的做起：優先確立 Agent 的行為與輸出格式。確認基準運作正常後，再加入 Tool 等功能。」
>
> — Guil Hernandez
