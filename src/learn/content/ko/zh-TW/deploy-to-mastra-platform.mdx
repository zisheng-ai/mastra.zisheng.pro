你一直在 Studio 中建置 Theme Park Agent。若要與其他人分享，它就必須在公開環境中執行。在本課程中，你會將它部署至 Mastra Server，也就是 Mastra 專為 Agent 提供的雲端部署產品。只需一道指令，就能將本機專案部署為即時 endpoint，並由平台代為管理 routing、scaling 與基礎架構。

部署之前，你會先探索位於 `http://localhost:4111/swagger-ui` 的 Swagger UI。Theme Park Agent 以及本課程中的其他所有 Agent，都已經在該處公開為 HTTP endpoint，其中包含用於產生回應、streaming 與執行 Workflow 的 route。接著，`mastra server deploy` 會進行驗證、建置 Docker image、完成部署，並顯示一個固定 URL。

Mastra 本身就是 HTTP server。Studio 只是你在本機與它互動的其中一種方式。Mastra Server 會將同一個 server 放到公開 URL 上，讓 Theme Park Agent 成為任何 service 都能呼叫的 endpoint。

> 「Mastra 本身就是 HTTP server。Studio 只是你在本機與它互動的其中一種方式。Mastra Server 會將同一個 server 放到公開環境。」
>
> — Guil Hernandez
