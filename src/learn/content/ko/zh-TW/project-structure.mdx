你剛剛已在 Mastra Studio 中執行 Weather Agent。本課程將帶你導覽建置過程中會持續編輯的核心檔案。這趟導覽會說明「你眼前看到的是什麼」，讓你在著手擴充專案之前，先清楚掌握專案結構。

你會開啟 Agent 檔案，瞭解如何透過 instructions、model 選擇、Tool 存取權限及 memory 定義行為。接著，你會查看 Tool 檔案，瞭解 Tool 如何透過明確的輸入與輸出來塑造，並在 runtime 進行驗證。最後，你會逐步查看 Workflow 檔案，瞭解如何串接多步驟邏輯，以及如何在 Studio 中預覽。

這點很重要，因為 Mastra 應用程式由一小組可組合的基礎元件建構而成，而這些限制是刻意設計的：Agent 只能使用你附加的 Tool，也只能根據這些 Tool 回傳的資料結構進行推理。當你能快速讀懂這三種檔案類型，就能更快進行偵錯，並有信心依循相同模式開始建置自己的主題樂園 Agent。

> 「你的 Agent 只能呼叫你附加的 Tool，也只能運用 Tool 回傳的內容。因此，只要正確設定這些邊界與資料結構，後續的一切都會更容易。」
>
> — Guil Hernandez
