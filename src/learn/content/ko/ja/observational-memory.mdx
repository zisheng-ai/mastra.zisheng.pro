基本的なメッセージ履歴には限界があります。会話が長くなると、Tool の呼び出し、待ち時間の検索、天気の確認、Web から抽出したパークデータなど、生の履歴が急速に積み上がります。このレッスンでは Observational Memory を有効にし、増え続ける履歴を、Agent が実際に活用できる密度の高いコンテキストへ圧縮します。

Agent を `observationalMemory` に切り替え、スコープを `resource` に設定して、スレッドをまたいでユーザーの Memory が引き継がれるようにします。Studio で、あるスレッドから会話を始め、新しいスレッドで続きを再開してテストします。新しいスレッドでも、以前の設定や好みは引き継がれます。

Observational Memory は `lastMessages` の手動調整を自動圧縮に置き換えるため重要です。呼び出しのたびに生の履歴をすべて持ち越さなくても、長いセッションや複数のスレッドにわたって会話の一貫性を保てます。

> 「これまでの会話の一語一句をすべて覚えているわけではありません。何が起きたかを観察し、それが時間とともに、より役立つ情報へ凝縮されます。OM も同じ考え方に基づいています。」
>
> — Guil Hernandez
