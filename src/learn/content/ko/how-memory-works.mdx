테마파크 Agent에서 Memory가 이미 활성화되어 있습니다. 이 강의에서는 이것이 실제로 무엇을 의미하는지, 즉 호출 사이에 Model이 여전히 상태 비저장인 이유와 후속 작업을 수행하기 위해 Mastra가 수행하는 작업을 자세히 살펴보겠습니다.

Studio에서 실제 후속 Prompt를 추적하여 Agent가 정확히 어떤 컨텍스트를 수신했는지 확인하고 `lastMessages`를 살펴보세요. 통화당 최근 대화 기록이 얼마나 포함되는지 제어하는 ​​설정입니다. Mastra는 메시지를 스토리지에 보관한 다음 나중에 해당 메시지를 다시 포함하여 Model에 필요한 정보를 제공합니다.

기억은 마법이 아니기 때문에 이것이 중요합니다. 실제로 수행하는 작업은 컨텍스트 엔지니어링입니다. 즉, 각 호출에 대해 Model이 볼 내용을 결정하는 것입니다. 이를 이해하면 Agent 동작을 추론하고 문제가 있을 때 디버깅하기가 훨씬 쉬워집니다.

> "Model은 여전히 ​​상태 비저장입니다. Mastra는 컨텍스트를 저장한 다음 이후 호출에 다시 포함합니다."
>
> — 길 에르난데스
