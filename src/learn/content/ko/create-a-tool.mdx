수업을 거듭할수록 테마파크 Agent는 "지침에 따른 채팅"에서 실제 데이터를 사용하여 안정적으로 작업하는 방식으로 전환하고 있습니다. 이 강의에서는 누락된 첫 번째 빌딩 블록, 즉 Agent가 인간 공원 이름을 표준 공원 ID로 변환하는 데 사용할 수 있는 Tool을 추가합니다.

원격 엔드포인트를 쿼리하고, 스키마를 사용하여 입력/출력의 유효성을 검사하고, 이름이 모호할 경우 일치하는 작은 집합을 반환하는 전용 파크 조회 Tool을 만듭니다. 그런 다음 Mastra Studio에서 직접 Tool을 테스트하고 마지막으로 대화 중에 자동으로 Tool을 호출할 수 있도록 테마파크 Agent에 연결합니다.

이는 모든 다운스트림 Q Times 요청이 단지 추측된 공원 이름이 아니라 올바른 공원 ID를 갖는지에 달려 있기 때문에 중요합니다. Tool의 반환 형태를 검증하고 Observability에서 Tool 호출을 검사함으로써 다음에 실시간 대기 시간을 가져오기 위한 신뢰할 수 있는 기반을 설정합니다.

> "Tool은 공원 이름을 다른 모든 API 호출이 의존하는 하나의 ID로 바꾸는 것과 같이 Agent에 실제 컨텍스트가 필요한 순간을 위한 것입니다."
>
> — 길 에르난데스
