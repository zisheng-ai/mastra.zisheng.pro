你一直在 Studio 中构建主题公园 Agent。要与其他人分享，就需要让它在公网环境中运行。本课将把它部署到 Mastra Server——Mastra 面向 Agent 的云部署产品。只需一条命令，即可将本地项目发布为线上 endpoint，路由、扩缩容和基础设施均由平台管理。

部署前，你将查看 `http://localhost:4111/swagger-ui` 上的 Swagger UI。主题公园 Agent 和课程中的其他 Agent 已经作为 HTTP endpoint 暴露，其中包括生成响应、流式输出和运行 Workflow 的路由。随后运行 `mastra server deploy` 完成认证、构建 Docker image 和部署，并获得稳定的 URL。

Mastra 本身已经是 HTTP Server，Studio 只是本地与它交互的一种方式。Mastra Server 将同一个 Server 发布到公开 URL，使主题公园 Agent 成为任何服务都能调用的 endpoint。

> “Mastra 本身已经是 HTTP Server，Studio 只是本地与它交互的一种方式。Mastra Server 会把同一个 Server 发布到公网。”
>
> — Guil Hernandez
