이미 공원 조회가 작동 중입니다. 이제 다음 단계로 나아가 테마파크 Agent가 진정으로 도움이 되도록 만들겠습니다. 이 단원에서는 현재 공원에서 일어나고 있는 상황에 대한 실시간 스냅샷을 가져오는 새로운 기능을 추가합니다.

공원 ID를 승인하고 위치/토지, 개방 상태, 현재 게시된 대기 시간과 같은 주요 필드가 포함된 선별된 명소 목록을 반환하는 Tool를 만듭니다. 또한 가장 짧은 대기 시간이 맨 위로 올라가도록 결과가 정렬되어 권장 사항에 즉시 출력을 사용할 수 있게 됩니다.

실시간 공원 조건은 빠르게 변하고 Agent는 하루 동안 현실적인 경로를 계획하기 위해 신선하고 구조화된 데이터가 필요하기 때문에 이는 중요합니다. 또한 Tool를 Agent에 연결하고 Mastra Studio 내부의 전체 "조회 → 라이브 스냅샷" 체인을 테스트하므로 Agent가 적시에 올바른 Tool를 일관되게 호출합니다.

> "대기 시간은 빠르게 변하므로 데이터를 가져올 때 항상 돌아오십시오. 해당 타임스탬프가 스냅샷을 신뢰할 수 있게 만듭니다."
>
> — 길 에르난데스
