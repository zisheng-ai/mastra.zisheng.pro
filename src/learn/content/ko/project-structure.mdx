방금 Mastra Studio에서 Weather Agent를 실행했습니다. 이번 강의에서는 빌드하면서 계속 편집하게 될 핵심 파일을 둘러보게 됩니다. 이것은 확장을 시작하기 전에 프로젝트 구조가 명확하게 느껴지도록 하기 위한 "현재 보고 있는 내용" 연습입니다.

Agent 파일을 열어 지침, Model 선택, Tool 액세스 및 Memory를 통해 동작이 어떻게 정의되는지 확인합니다. 그런 다음 Tool 파일을 검사하여 Tool이 명확한 입력/출력으로 구성되고 런타임에 유효성이 검사되는 방식을 이해합니다. 마지막으로 Workflow 파일을 살펴보며 Studio 내에서 다단계 논리가 어떻게 연결되고 미리 볼 수 있는지 살펴보겠습니다.

Mastra 앱은 구성 가능한 작은 기본 요소 집합으로 구축되었으며 제약 조건은 의도적이기 때문에 이는 중요합니다. Agent는 연결한 Tool만 사용할 수 있으며 해당 Tool이 반환하는 데이터 형태에 대해서만 추론할 수 있습니다. 이 세 가지 파일 형식을 빠르게 읽을 수 있으면 더 빠르게 디버그할 수 있으며 동일한 패턴 위에 자신만의 테마파크 Agent 구축을 자신 있게 시작할 수 있습니다.

> "Agent는 귀하가 연결한 Tool만 호출할 수 있으며 Tool이 반환하는 것만 작동할 수 있습니다. 따라서 이러한 경계와 데이터 형태를 올바르게 설정하면 모든 다운스트림이 더 쉬워집니다."
>
> — 길 에르난데스
