테마파크 Agent가 이미 파크 ID와 실시간 대기 시간을 가져올 수 있지만 QTimes JSON API에서 사용할 수 없는 주요 계획 정보가 누락된 시점입니다. 이 레슨에서는 외부 Tool 소스를 사용하여 Agent를 확장하여 공원 시간 및 군중 예측과 같은 질문에 답할 수 있도록 합니다.

Agent를 MCP 서버에 연결하고, 웹 추출 Tool를 가져오고, 해당 Tool를 기존 로컬 Tool와 함께 사용할 수 있게 만듭니다. 그런 다음 Agent 지침을 업데이트하여 공원 ID를 먼저 조회할 시기와 공원 웹 페이지에서 구조화된 세부 정보를 가져올 시기를 알 수 있습니다.

실제 어시스턴트는 단일 API에서 모든 것을 얻는 경우가 거의 없기 때문에 이는 중요합니다. 라이브 API 데이터를 웹 페이지의 구조화된 추출과 결합하고 관련성이 있는 경우 날씨 입력을 추가함으로써 일회성 스크레이퍼를 구축하지 않고도 정보 격차를 안정적으로 메울 수 있는 Agent로 전환할 수 있습니다.

> "Tool 액세스만으로는 올바른 행동이 보장되지 않습니다. Agent에게 Tool를 사용해야 하는 시기와 이유를 가르쳐야 합니다."
>
> — 길 에르난데스
