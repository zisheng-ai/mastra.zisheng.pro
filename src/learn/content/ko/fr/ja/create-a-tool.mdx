レッスンを重ねるにつれて、テーマパーク Agent は「指示に基づいて会話する」段階から、実際のデータを確実に扱う段階へ進んでいます。このレッスンでは、最初に不足している構成要素を追加します。それは、人が入力したパーク名を正式なパーク ID に変換するための Tool です。

リモートエンドポイントに問い合わせ、スキーマで入力と出力を検証し、名前が曖昧な場合は少数の候補を返す、専用のパーク検索 Tool を作成します。次に Mastra Studio で Tool を単独テストし、最後にテーマパーク Agent に接続して、会話中に Agent が自動で呼び出せるようにします。

これは、後続の Q Times リクエストがすべて、推測したパーク名ではなく正しいパーク ID に依存するため重要です。Tool の戻り値の形式を検証し、Observability で Tool の呼び出しを確認することで、次にリアルタイムの待ち時間を取得するための信頼できる基盤を整えます。

> 「Tool が必要になるのは、Agent が実際のコンテキストを必要とする場面です。たとえば、パーク名を、ほかのすべての API 呼び出しが依存する 1 つの ID に変換するときです。」
>
> — Guil Hernandez
