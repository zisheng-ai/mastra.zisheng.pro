テーマパーク Agent はデプロイされ、HTTP 経由でアクセスできるようになりました。このレッスンでは、Mastra の Channels 機能を使って Slack に接続し、Slack を使える場所ならどこからでもメッセージを送れるようにします。

`@chat-adapter/slack` パッケージをインストールし、テーマパーク Agent に `channels` 設定を追加して、適切なスコープを持つ Slack アプリを作成します。Mastra は Webhook ルートを自動的に公開します。Slack の Event Subscriptions にそのルートを指定すれば、メッセージが Agent に直接届きます。

同じ Tool、Memory、そして承認ゲートを備えたチケット購入 Workflow を DM から実行できます。Channels は同じパターンで Discord と Telegram にも対応しています。アダプターをインストールし、`channels.adapters` の下に追加して、環境変数を設定し、デプロイしてから、プラットフォームの Webhook に Mastra が生成したルートを指定します。

> 「Webhook ハンドラーを自分で作る必要はありません。Slack の署名を自分で検証する必要もありません。すべてアダプターが処理します。」
>
> — Guil Hernandez
