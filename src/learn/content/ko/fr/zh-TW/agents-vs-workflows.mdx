你已經建好購票 Workflow，現在正適合清楚區分 Agent 與 Workflow 各自負責的工作。這些術語常被寬鬆使用，但這裡真正重要的是它們在實務上如何運作，以及在這個專案中如何相互配合。

Agent 是系統中「會對話的大腦」：一個具備 Tool 與記憶功能的語言模型。它的執行路徑並未預先定義；模型會決定該做什麼、呼叫哪些 Tool，以及何時完成工作。Workflow 則正好相反：步驟、順序及「完成」的定義都由你決定。購票流程就是最清楚的例子。你不是要求模型自行摸索結帳方式，而是親自定義結帳流程。在 Mastra 中，你可以結合兩者：在 Workflow 中使用 Agent，或將 Workflow 當成 Agent 的 Tool。

這點很重要，因為知道何時該使用哪一種方式，可以避免你把簡單工作過度設計成 Workflow，也不會要求模型處理原本應該具備確定性且受到控制的工作。

> 「我們不是要求模型自行摸索結帳方式，而是在定義結帳流程。」
>
> — Guil Hernandez
