專案建置進展到這個階段時，編輯器中的程式開發 Agent 會開始與你並肩處理實際工作，而本課程著重於如何讓這些協助維持正確。Guil 會逐步說明一套實用的設定方式，避免 Agent 猜測或使用過時的 Mastra 模式。

你會查看 Mastra Skill 如何存放在專案中、Agent 實際讀取哪些檔案，以及這些參考資料如何引導程式碼產生與編輯。接著，你會瞭解何時該使用 MCP 風格的文件伺服器來補充 Skill，以便直接查詢最新文件並取得遷移協助。

這點很重要，因為「過時或捏造的 Mastra 詳細資訊」是 AI 輔助程式開發偏離正軌最常見的原因之一。為 Agent 提供可靠的本機知識來源（並在需要時以即時文件作為備援），就能減少重工；當你繼續為主題樂園 Agent 專案建置 Tool 時，也能讓實作持續符合 Mastra 真正的 API 與模式。

> 「最嚴重的失敗情況，就是程式開發 Agent 信心十足地捏造 Mastra 的詳細資訊——因此我們把 Skill 直接放進儲存庫，讓它在工作時能讀取真正的模式。」
>
> — Guil Hernandez
