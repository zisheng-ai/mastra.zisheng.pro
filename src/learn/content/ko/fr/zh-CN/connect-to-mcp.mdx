主题公园 Agent 已经能够获取公园 ID 和实时排队时间，但 QTimes JSON API 并不提供营业时间和客流预测等关键规划信息。本课将通过外部 Tool 来源扩展 Agent，让它能够回答这类问题。

你将把 Agent 连接到 MCP Server，引入网页提取 Tool，并让它们与现有本地 Tool 一起使用。随后更新 Agent 的指引，让它知道何时应该先查询公园 ID，何时应该从公园网页获取结构化详情。

真实世界中的助手很少能从单个 API 获得全部信息。结合实时 API 数据、网页结构化提取，并在相关时加入天气信息，可以让 Agent 可靠地补全信息缺口，而不必为每种情况单独构建 scraper。

> “仅仅让 Agent 能够访问 Tool，并不能保证它做出正确行为；你还需要教会它何时使用 Tool，以及为什么使用。”
>
> — Guil Hernandez
