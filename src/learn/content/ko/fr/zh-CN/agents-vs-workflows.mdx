你已经构建了购票 Workflow，现在正适合厘清 Agent 和 Workflow 各自负责什么。这两个术语有时会被宽泛使用，但这里真正重要的是它们在实践中的行为，以及如何在项目中协同工作。

Agent 是系统中“会说话的大脑”：一个拥有 Tool 和 Memory 的语言模型。它的执行路径并未预先定义，而是由模型决定要做什么、调用哪些 Tool，以及何时结束。Workflow 正好相反：由你定义步骤、顺序和完成条件。购票流程就是最清楚的例子——并非让模型自行决定如何结账，而是由你明确规定。在 Mastra 中，两者可以组合使用：在 Workflow 内调用 Agent，或将 Workflow 作为 Agent 的 Tool。

理解如何选择二者，可以避免把简单任务过度设计成 Workflow，也能避免让模型处理本应确定且受控的逻辑。

> “我们不是让模型自己琢磨如何结账，而是在明确地定义结账流程。”
>
> — Guil Hernandez
