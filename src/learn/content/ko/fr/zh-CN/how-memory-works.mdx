主题公园 Agent 已经启用了 Memory。本课将深入了解其实际含义：为什么模型在多次调用之间仍然没有状态，以及 Mastra 如何让后续追问正常工作。

你将在 Studio 中追踪一次真实的后续 prompt，准确查看 Agent 收到的上下文，并了解 `lastMessages`——控制每次调用包含多少近期对话历史的设置。Mastra 会将消息持久化到 Storage，再在后续轮次中重新加入，让模型获得所需信息。

Memory 并不是魔法。你真正做的是上下文工程：决定模型在每次调用中能看到什么。理解这一点，就能更容易地分析 Agent 行为，并在结果异常时进行调试。

> “模型仍然是无状态的。Mastra 会存储上下文，再将它加入后续调用。”
>
> — Guil Hernandez
