你剛在 Mastra Studio 執行了 Weather Agent。在本課中，你會在導覽下認識接下來建立項目時會持續編輯的核心檔案。這是一個「了解眼前內容」的導賞，讓你在開始擴展項目之前，先清楚掌握項目結構。

你會開啟 Agent 檔案，了解如何透過 instructions、模型選擇、Tool 存取權限和 Memory 定義行為。然後，你會檢視 Tool 檔案，了解如何為 Tool 設定清晰的輸入和輸出，並在運行期間進行驗證。最後，你會逐步查看 Workflow 檔案，了解如何連接多步驟邏輯，以及如何在 Studio 中預覽。

這一點很重要，因為 Mastra 應用程式由一組精簡而可組合的 primitive 建立，而這些限制都是刻意設計的：Agent 只能使用你附加的 Tool，也只能根據這些 Tool 回傳的數據結構進行推理。當你能快速讀懂這三類檔案，便可更快除錯，並有信心按照相同模式開始建立自己的主題樂園 Agent。

> 「Agent 只能調用你附加的 Tool，也只能處理 Tool 回傳的內容。因此，正確設定這些界線和數據結構，會令後續所有工作更順利。」
>
> — Guil Hernandez
