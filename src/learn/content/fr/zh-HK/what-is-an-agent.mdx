你正站在課程的起點。Guil 會在這裏為接下來的內容打好基礎，並展示「agentic」行為在實際運作時是怎樣的。本課是一個導覽：甚麼是 Agent、為何單靠 prompt 會遇到限制，以及 Mastra 如何組織各個基本元件。

你會觀看 Agent 由頭到尾運行，包括它如何調用 Tool、如何使用先前情境回答後續問題，以及如何透過更改模型和 instructions 來調整行為。你亦會清楚預覽本課程將建立的項目：一個主題樂園同行助手，它可以取得即時數據、提供建議，並引導用戶完成多步驟工作。

這一點很重要，因為課程其餘部分都假設你能分辨單輪聊天回應，與可以可靠採取行動的系統。理解 Tool、Workflow、Memory 和 observability 如何配合後，你便能建立在開發期間可測試、在生產環境可推出的功能，而毋須猜測模型「實際做了甚麼」。

> 「我是 Guil Hernandez，會擔任這個課程的導師。我有超過十年建立和教授軟件的經驗，課程透過 Treehouse、Scrimba 和 YouTube 等平台接觸了超過 50 萬名學員。現在，我全心投入 AI Agent，而這個課程就是你的路線圖。Agent 是下一次平台轉變；現在學會建立 Agent 的工程師，將塑造未來。」
>
> — Guil Hernandez
