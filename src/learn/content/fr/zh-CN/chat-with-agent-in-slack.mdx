主题公园 Agent 已经部署并可通过 HTTP 访问。本课将使用 Mastra 的 Channels 功能把它连接到 Slack，让你可以在任何能够使用 Slack 的地方向它发送消息。

你将安装 `@chat-adapter/slack` 包，为主题公园 Agent 添加 `channels` 配置，并创建具有正确 scope 的 Slack 应用。Mastra 会自动暴露 webhook 路由，只需让 Slack 的 Event Subscriptions 指向该路由，消息就会直接发送给 Agent。

通过私信也能使用相同的 Tool、Memory 和带审批门禁的购票 Workflow。Channels 以同样的模式支持 Discord 和 Telegram：安装 adapter，将其添加到 `channels.adapters`，设置环境变量并部署，然后把平台 webhook 指向 Mastra 生成的路由。

> “你无需自己构建 webhook handler，也无需自己验证 Slack 签名，这些都由 adapter 处理。”
>
> — Guil Hernandez
