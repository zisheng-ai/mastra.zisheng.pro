课程从这里开始。Guil 将为后续内容打下基础，并展示“Agentic”行为在实践中的真实形态。本课会引导你了解什么是 Agent、为什么只靠 prompt 会遇到限制，以及 Mastra 如何组织各个构建模块。

你将观察一个 Agent 端到端运行，包括它如何调用 Tool、如何利用先前上下文回答后续问题，以及如何通过更换模型和修改 instructions 调整行为。你还会预览本课程将构建的项目：一个可以获取实时数据、给出建议并引导用户完成多步骤任务的主题公园伴侣。

后续课程要求你能区分单轮聊天响应和能够可靠采取行动的系统。理解 Tool、Workflow、Memory 和可观测性如何协作后，你就能构建在开发环境中可测试、在生产环境中可交付的功能，而无需猜测模型“实际上做了什么”。
