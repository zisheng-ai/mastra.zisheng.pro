Vous avez créé le Workflow d'achat de billets : c'est donc le bon moment pour distinguer clairement ce que font les Agents et ce que font les Workflows. Ces termes sont souvent employés de façon imprécise, mais l'essentiel ici est leur comportement concret et leur collaboration dans ce projet.

Un Agent est le « cerveau conversationnel » du système : un modèle de langage doté de Tools et de mémoire. Son parcours n'est pas prédéfini ; le modèle décide quoi faire, quels Tools appeler et quand il a terminé. Un Workflow fonctionne à l'inverse : vous définissez les étapes, leur ordre et ce que signifie « terminé ». Le flux d'achat de billets en est l'exemple le plus clair. Vous ne demandez pas au modèle de déterminer le paiement, vous le définissez. Dans Mastra, vous pouvez les combiner : des Agents dans des Workflows, ou des Workflows comme Tools pour des Agents.

Le comprendre évite de surconcevoir une tâche simple en Workflow ou de demander à un modèle de gérer une opération qui devrait être déterministe et contrôlée.

> "Nous ne demandons pas au modèle de déterminer le paiement. Nous définissons le paiement."
>
> — Guil Hernandez
