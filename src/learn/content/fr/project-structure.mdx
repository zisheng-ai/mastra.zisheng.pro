Vous venez d'exécuter le Weather Agent dans Mastra Studio et, dans cette leçon, vous ferez une visite guidée des fichiers principaux que vous continuerez à modifier pendant le développement. Cette présentation de « ce que vous avez sous les yeux » rend la structure du projet évidente avant de commencer à l'étendre.

Vous ouvrirez le fichier de l'Agent pour voir comment son comportement est défini par les instructions, le choix du modèle, l'accès aux Tools et la mémoire. Vous inspecterez ensuite le fichier des Tools pour comprendre comment ils sont façonnés par des entrées et sorties claires, puis validés à l'exécution. Enfin, vous parcourrez un fichier de Workflow pour voir comment une logique en plusieurs étapes est reliée et prévisualisée dans Studio.

C'est important, car les applications Mastra sont constituées d'un petit ensemble de primitives composables, et leurs contraintes sont intentionnelles : les Agents ne peuvent utiliser que les Tools que vous leur attachez et ne peuvent raisonner qu'à partir de la forme des données que ces Tools renvoient. Une fois ces trois types de fichiers rapidement lisibles, vous pourrez déboguer plus vite et créer avec assurance votre propre Agent de parc à thème à partir des mêmes modèles.

> "Votre Agent ne peut appeler que les Tools que vous lui attachez, et ne peut travailler qu'avec ce que ces Tools renvoient. Bien définir ces limites et ces formes de données simplifie donc tout ce qui suit."
>
> — Guil Hernandez
