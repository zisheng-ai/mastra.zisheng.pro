Vous avez créé l'Agent de parc à thème dans Studio. Pour le partager avec d'autres personnes, il doit s'exécuter dans un environnement public. Dans cette leçon, vous le déploierez sur Mastra Server, le produit de déploiement cloud de Mastra pour les Agents. Une seule commande transforme votre projet local en point de terminaison actif, avec routage, mise à l'échelle et infrastructure gérés pour vous.

Avant le déploiement, vous explorerez l'interface Swagger à `http://localhost:4111/swagger-ui`. L'Agent de parc à thème et tous les autres Agents de ce cours y sont déjà exposés sous forme de points de terminaison HTTP : routes de génération de réponses, de streaming et d'exécution de Workflows. Ensuite, `mastra server deploy` s'authentifie, construit une image Docker, la déploie et affiche une URL stable.

Mastra est déjà un serveur HTTP. Studio n'est qu'une manière de lui parler localement. Mastra Server place ce même serveur sur une URL publique, et l'Agent de parc à thème devient un point de terminaison que tout service peut appeler.

> "Mastra est déjà un serveur HTTP. Studio n'est qu'une manière de lui parler localement. Mastra Server place ce même serveur dans un environnement public."
