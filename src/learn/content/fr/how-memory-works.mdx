La mémoire est déjà activée sur l'Agent de parc à thème. Dans cette leçon, vous examinerez ce que cela implique réellement : pourquoi le modèle reste sans état entre les appels et ce que fait Mastra pour permettre les échanges de suivi.

Vous tracerez un véritable prompt de suivi dans Studio pour voir exactement quel contexte l'Agent a reçu, puis étudierez `lastMessages`, le réglage qui contrôle la quantité d'historique de conversation récent incluse à chaque appel. Mastra persiste les messages dans le stockage, puis les réinclut lors des tours suivants afin que le modèle dispose des informations nécessaires.

C'est important, car la mémoire n'est pas magique. Vous effectuez en réalité de l'ingénierie du contexte : vous décidez ce que le modèle peut voir à chaque appel. Le comprendre facilite grandement le raisonnement sur le comportement de l'Agent et son débogage lorsqu'un résultat semble anormal.

> "Le modèle reste sans état. Mastra stocke le contexte, puis l'inclut de nouveau lors des appels suivants."
>
> — Guil Hernandez
