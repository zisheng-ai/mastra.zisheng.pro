Dans cette leçon, vous ajouterez un nouvel Agent de parc à thème à votre projet Mastra et le ferez apparaître dans Mastra Studio. C'est une étape volontairement simple, sans Tools ni Workflows pour le moment, qui vous permet de vous concentrer sur une base nette à exécuter, ajuster et déboguer.

Vous créerez le fichier de l'Agent, rédigerez un bloc d'instructions concis qui contrôle son ton et son comportement, puis relierez l'Agent à l'application afin de le rendre disponible dans Studio. Vous exécuterez ensuite un rapide prompt de test pour confirmer qu'il répond comme prévu.

C'est important, car les instructions sont la base de tout ce que vous ajouterez ensuite : Tools, Workflows et données externes ne sont utiles que si le comportement par défaut de l'Agent est déjà solide. Vous utiliserez aussi la vue d'observabilité de Studio pour vérifier ce que le modèle a réellement reçu et produit, et constaterez comment l'activation de la mémoire transforme des échanges « sans état » en conversations cohérentes et continues.

> "Commencez simplement : fixez d'abord le comportement et le format de sortie de l'Agent. Ajoutez ensuite des capacités comme les Tools une fois la base validée."
>
> — Guil Hernandez
