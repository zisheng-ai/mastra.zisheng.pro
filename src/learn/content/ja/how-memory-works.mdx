テーマパーク Agent では、すでに Memory が有効になっています。このレッスンでは、その内部動作を確認します。呼び出しの間でモデルが依然としてステートレスである理由と、フォローアップを機能させるために Mastra が何をしているのかを学びます。

Studio で実際のフォローアッププロンプトをトレースし、Agent が受け取ったコンテキストを正確に確認します。さらに、呼び出しごとに含める最近の会話履歴の量を制御する設定、`lastMessages` も確認します。Mastra はメッセージをストレージに永続化し、後続のターンで再び含めることで、モデルに必要な情報を提供します。

Memory は魔法ではないため、この仕組みを理解することが重要です。実際に行っているのは、呼び出しごとにモデルへ何を見せるかを決めるコンテキストエンジニアリングです。これを理解すれば、Agent の動作を考察しやすくなり、違和感があるときのデバッグも大幅に簡単になります。

> 「モデルは依然としてステートレスです。Mastra がコンテキストを保存し、後続の呼び出しに再び含めています。」
>
> — Guil Hernandez
