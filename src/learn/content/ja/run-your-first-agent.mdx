コースの序盤にあたるこのレッスンでは、テーマパーク Agent を構築しながらすばやく反復できるよう、Mastra 環境を立ち上げることに集中します。新しいスタンドアロンプロジェクトをスキャフォールドし、モデル Provider を設定して、すべてがエンドツーエンドで動作することを確認します。

開発サーバーを起動し、Mastra Studio を使って標準の Agent と対話し、Tool を単独でテストして、サンプル Workflow をステップごとに実行します。その過程で、フロントエンドをまだ構築しなくても、Studio を使って出力を調べ、システムの動作を理解できることを確認します。

CLI が生成するプロジェクト構造は、コースが進むにつれてすべての Agent、Tool、Workflow、設定を置く場所になるため重要です。また、この段階で Studio と Observability に慣れておけば、Agent が複雑になっても、予想外の出力をデバッグし、品質を追跡するための信頼できる手段になります。

> 「Studio は Mastra アプリを開発、テストする場所です。フロントエンドに着手する前から、すべてを実行し、何が起きたかを調べ、すばやく改善できます。」
>
> — Guil Hernandez
