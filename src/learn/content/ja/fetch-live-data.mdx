パーク検索はすでに動作しています。次のステップでは、テーマパーク Agent を本当に役立つものにします。このレッスンでは、パークの現在の状況をリアルタイムのスナップショットとして取得する新しい機能を追加します。

パーク ID を受け取り、エリア、営業状況、現在の案内待ち時間といった主要フィールドを含む、厳選したアトラクション一覧を返す Tool を作成します。また、待ち時間が短い順に結果を並べ替え、すぐにおすすめ情報として使える出力にします。

これは、パークの状況が短時間で変化し、現実的な一日のルートを計画するには、Agent に最新の構造化データが必要なため重要です。Tool を Agent に接続し、Mastra Studio で「検索 → リアルタイムのスナップショット」という処理全体もテストします。これにより、Agent が適切なタイミングで一貫して正しい Tool を呼び出すことを確認できます。

> 「待ち時間はすぐ変わるため、データを取得した時刻を必ず返してください。そのタイムスタンプが、スナップショットの信頼性を支えます。」
>
> — Guil Hernandez
