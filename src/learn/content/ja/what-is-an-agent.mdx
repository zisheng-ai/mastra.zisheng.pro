コースの出発点となるこのレッスンでは、Guil が以降の内容すべての基礎を築き、「Agent らしい」動作が実際にどのようなものかを示します。Agent とは何か、プロンプトだけではなぜ限界があるのか、Mastra が構成要素をどのように整理するのかを理解するためのガイドです。

Tool の呼び出し、フォローアップの質問での過去のコンテキスト利用、モデルや instructions の変更による動作の調整など、Agent がエンドツーエンドで動く様子を確認します。また、このコースで構築するプロジェクトの全体像も把握します。リアルタイムデータを取得し、おすすめを提案し、複数ステップのタスクを通じてユーザーを案内できるテーマパーク案内 Agent です。

これは、コースの残りの内容で、1 回限りのチャット応答と、確実にアクションを実行するシステムを区別できることが前提になるため重要です。Tool、Workflow、Memory、Observability の関係を理解すれば、モデルが「実際に何をしたか」を推測せずに、開発環境でテストでき、本番環境へリリースできる機能を構築できます。

> 「Guil Hernandez です。このコースの講師を務めます。ソフトウェアの開発と教育に 10 年以上携わり、Treehouse、Scrimba、YouTube などのプラットフォームで、私のコースは 50 万人以上の受講者に届きました。今は AI Agent に全力で取り組んでおり、このコースは皆さんのロードマップになります。Agent は次のプラットフォーム転換です。今 Agent の構築を学ぶエンジニアが、これから先を形作ります。」
>
> — Guil Hernandez
