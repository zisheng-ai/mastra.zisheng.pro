このレッスンでは、新しいテーマパーク Agent を Mastra プロジェクトに追加し、Mastra Studio に表示させます。ここでは Tool や Workflow をまだ追加せず、シンプルさを保ちます。実行、調整、デバッグができる明確な基準を作ることに集中してください。

Agent ファイルを作成し、口調と動作を制御する簡潔な instructions ブロックを記述してから、Studio で利用できるようアプリに接続します。その後、簡単なテストプロンプトを実行し、意図したとおりに Agent が応答することを確認します。

instructions は、後から追加するすべての機能の基盤になるため重要です。Tool、Workflow、外部データも、Agent の標準動作が安定していなければ役に立ちません。また、Studio の Observability ビューを使って、モデルが実際に何を受け取り、何を生成したかを確認します。さらに、Memory を有効にすると、フォローアップが「ステートレス」な応答から、一貫した継続的な会話へ変わることも確認します。

> 「まずはシンプルに始め、Agent の動作と出力形式を先に固めます。基準となる動作を確認できたら、Tool などの機能を追加してください。」
>
> — Guil Hernandez
