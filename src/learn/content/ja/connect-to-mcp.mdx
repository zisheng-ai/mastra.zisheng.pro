テーマパーク Agent はすでにパーク ID とリアルタイムの待ち時間を取得できますが、QTimes JSON API では得られない重要な計画情報が不足しています。このレッスンでは、営業時間や混雑予測などの質問にも答えられるよう、外部の Tool ソースを追加して Agent を拡張します。

Agent を MCP サーバーに接続し、Web から情報を抽出する Tool を導入して、既存のローカル Tool と併用できるようにします。次に、パーク ID を先に検索する場面と、パークの Web ページから構造化された詳細情報を取得する場面を Agent が判断できるよう、指示を更新します。

これは、実際のアシスタントが 1 つの API だけですべての情報を得られることはほとんどないため重要です。リアルタイムの API データと Web ページからの構造化抽出を組み合わせ、必要に応じて天気情報も追加すれば、用途ごとのスクレイパーを構築しなくても、情報の不足を確実に補える Agent になります。

> 「Tool にアクセスできるだけでは、適切に動作するとは限りません。いつ、なぜその Tool を使うのかを Agent に教える必要があります。」
>
> — Guil Hernandez
