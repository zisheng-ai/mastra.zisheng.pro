エディターのコーディング Agent が実際の作業を支援し始める段階まで来ました。このレッスンでは、その支援を正確に保つ方法に焦点を当てます。Agent が推測したり、古い Mastra のパターンを使ったりするのを防ぐための実践的な設定を Guil が解説します。

Mastra Skills がプロジェクト内のどこにあり、Agent が実際にどのファイルを読み、それらの参照情報がコードの生成や編集をどう導くのかを確認します。さらに、最新ドキュメントや移行情報を直接検索できるようにするため、Skills を MCP 形式のドキュメントサーバーで補うべき場面も学びます。

これは、AI 支援コーディングが失敗する最も一般的な原因の一つが、「古い、または架空の Mastra 情報」だからです。信頼できるローカルの知識ソースを Agent に提供し、必要に応じて最新ドキュメントも参照できるようにすれば、手戻りを減らし、テーマパーク Agent プロジェクト用の Tool を構築し続ける間も、実装を Mastra の実際の API やパターンに合わせられます。

> 「最大の失敗要因は、コーディング Agent が Mastra の情報を自信満々に作り上げてしまうことです。そこで Skills をリポジトリ内に置き、作業中に実際のパターンを読めるようにします。」
>
> — Guil Hernandez
