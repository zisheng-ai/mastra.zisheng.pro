Mastra Studio で Weather Agent を実行したばかりです。このレッスンでは、開発を進めるなかで繰り返し編集する主要ファイルを順に確認します。拡張を始める前に、表示されているものを理解し、プロジェクト構造を分かりやすくするためのガイドツアーです。

まず Agent ファイルを開き、instructions、モデルの選択、Tool へのアクセス、Memory によって動作がどう定義されるかを確認します。次に Tool ファイルを調べ、明確な入出力を備え、実行時に検証される Tool の構造を理解します。最後に Workflow ファイルを確認し、複数ステップのロジックがどのように接続され、Studio 内でプレビューされるかを見ていきます。

これは、Mastra アプリが少数の組み合わせ可能なプリミティブから作られ、制約が意図的に設けられているため重要です。Agent が使えるのは接続した Tool だけであり、推論できるのも Tool が返すデータ形式の範囲内に限られます。これら 3 種類のファイルをすばやく読めるようになれば、デバッグが速くなり、同じパターンを基に独自のテーマパーク Agent を自信を持って構築し始められます。

> 「Agent が呼び出せるのは接続した Tool だけであり、扱えるのは Tool が返す内容だけです。その境界とデータ形式を正しく定めれば、後続のすべての処理が容易になります。」
>
> — Guil Hernandez
