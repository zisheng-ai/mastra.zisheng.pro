これまで Studio でテーマパーク Agent を構築してきました。ほかの人と共有するには、公開された環境で実行する必要があります。このレッスンでは、Agent 向けの Mastra クラウドデプロイ製品である Mastra Server にデプロイします。1 つのコマンドでローカルプロジェクトをライブエンドポイントに変換でき、ルーティング、スケーリング、インフラストラクチャは自動で管理されます。

デプロイの前に、`http://localhost:4111/swagger-ui` の Swagger UI を確認します。テーマパーク Agent を含め、このコースのすべての Agent は、応答の生成、ストリーミング、Workflow の実行に対応する HTTP エンドポイントとしてすでに公開されています。その後、`mastra server deploy` が認証、Docker イメージのビルド、デプロイを行い、安定した URL を出力します。

Mastra はすでに HTTP サーバーです。Studio は、ローカルで接続する方法の一つにすぎません。Mastra Server は同じサーバーを公開 URL 上で稼働させ、テーマパーク Agent をあらゆるサービスから呼び出せるエンドポイントにします。

> 「Mastra はすでに HTTP サーバーです。Studio は、ローカルで接続する方法の一つにすぎません。Mastra Server は同じサーバーを公開された場所で稼働させます。」
>
> — Guil Hernandez
