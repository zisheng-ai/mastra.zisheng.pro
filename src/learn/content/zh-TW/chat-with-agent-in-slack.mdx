Theme Park Agent 已完成部署，可透過 HTTP 存取。在本課程中，你會使用 Mastra 的 Channels 功能將它連接至 Slack，這樣無論在哪裡使用 Slack，都能傳訊息給它。

你會安裝 `@chat-adapter/slack` 套件、在 Theme Park Agent 中加入 `channels` 設定，並建立具備正確權限範圍的 Slack 應用程式。Mastra 會自動公開 webhook 路由。將 Slack 的 Event Subscriptions 指向該路由後，訊息就會直接傳送給 Agent。

你也能從私訊中使用相同的 Tool、Memory，以及設有核准關卡的購票 Workflow。Channels 也以相同模式支援 Discord 和 Telegram：安裝轉接器、將其加入 `channels.adapters`、設定環境變數、部署，再將平台 webhook 指向 Mastra 產生的路由。

> 「你不需要自行建置 webhook 處理程式，也不需要自行驗證 Slack 簽章。這些全都由轉接器處理。」
>
> — Guil Hernandez
