目前 Theme Park Agent 已能取得樂園 ID 和即時等候時間，但仍缺少 QTimes JSON API 未提供的重要規劃資訊。在本課程中，你會透過外部 Tool 來源擴充 Agent，使其能回答樂園營業時間和人潮預測等問題。

你會將 Agent 連接至 MCP 伺服器、引入網頁擷取 Tools，並讓這些 Tools 能與既有的本機 Tools 一起使用。接著，你會更新 Agent 的指引，讓它知道何時應先查詢樂園 ID，以及何時應從樂園網頁擷取結構化詳細資料。

這點很重要，因為現實世界中的助理很少能從單一 API 取得所有資訊。結合即時 API 資料與從網頁擷取的結構化資料，並在適合的情況下加入天氣資訊，就能讓 Agent 可靠地補足資訊缺口，而不必建置一次性的網頁爬蟲。

> 「僅讓 Agent 存取 Tool 並不能保證它會採取正確行動；你必須教它何時使用 Tool，以及為何要使用。」
>
> — Guil Hernandez
