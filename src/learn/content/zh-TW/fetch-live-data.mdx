你已經完成樂園查詢功能，現在將進一步讓 Theme Park Agent 真正派上用場。在本課程中，你會新增一項功能，擷取樂園當下情況的即時快照。

你會建立一個 Tool，讓它接收樂園 ID，並傳回精選的遊樂設施清單，其中包含位置／園區、開放狀態，以及目前公告的等候時間等重要欄位。你也會確保結果已排序，讓等候時間最短的設施排在最前面，使輸出能立即用於提供建議。

這點很重要，因為樂園的即時狀況變化快速，Agent 需要最新且結構化的資料，才能規劃符合實際情況的一日動線。你也會將這個 Tool 接入 Agent，並在 Mastra Studio 中測試完整的「查詢 → 即時快照」流程，確保 Agent 能在正確時機穩定呼叫正確的 Tool。

> 「等候時間變化很快，因此務必一併傳回資料的擷取時間。這個時間戳記能讓快照值得信賴。」
>
> — Guil Hernandez
