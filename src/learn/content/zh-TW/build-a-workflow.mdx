Agent 已經可以查詢樂園、取得即時等候時間、抓取更多樂園詳細資料，並將天氣因素納入考量。但有些工作無法透過單次 Tool 呼叫完成。在本課程中，你將建立一個多步驟的購票 Workflow，並加入人工介入核准關卡。

你會建立一個模擬購票 Workflow，其中包含三個明確步驟：建立報價、暫停以等待使用者核准，以及處理扣款。每個步驟都有自己的輸入與輸出 schema，讓資料能順暢地從一個步驟傳遞到下一個步驟。你會將 Workflow 接入 Mastra 進入點，並在 Studio 中執行，以便觀察每個步驟依序執行，包括暫停與繼續執行的過程。

這點很重要，因為有些邏輯具備確定性，不應交由語言模型處理，例如計算費用、驗證輸入及確認金額。Workflow 能讓你掌控執行順序，也提供明確的位置，讓你能在任何款項移轉前暫停並等待核准。

> 「如果某件事具備確定性，就不要讓模型推理它。直接把它放進 Workflow 步驟即可。」
>
> — Guil Hernandez
