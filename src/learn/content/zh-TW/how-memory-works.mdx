Theme Park Agent 已經啟用 Memory。在本課程中，你會深入了解這實際上代表什麼：為什麼 model 在各次呼叫之間仍然是 stateless，以及 Mastra 如何讓後續提問正常運作。

你會在 Studio 中追蹤一次真實的後續提問，確認 Agent 實際收到哪些 context，並查看 `lastMessages`：這項設定控制每次呼叫會納入多少近期對話紀錄。Mastra 會將訊息保存至 storage，再於之後的對話輪次中重新納入這些訊息，讓 model 取得所需資訊。

這點很重要，因為 Memory 並不是魔法。你真正進行的是 context engineering：決定每次呼叫時 model 能看到哪些內容。了解這一點後，你就能更輕鬆地分析 Agent 的行為，並在感覺有異常時進行 debug。

> 「model 仍然是 stateless。Mastra 會儲存 context，再於之後的呼叫中重新納入這些內容。」
>
> — Guil Hernandez
