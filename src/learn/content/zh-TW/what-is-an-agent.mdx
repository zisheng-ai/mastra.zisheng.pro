你正站在課程的起跑線上，Guil 會在這裡為後續內容奠定基礎，並展示「agentic」行為在實務中究竟是什麼樣貌。本課程是一趟引導式入門：介紹 Agent 是什麼、為什麼只靠 prompt 會遇到限制，以及 Mastra 如何組織各項建構要素。

你會觀看 Agent 端到端執行的過程，包括它如何呼叫 Tool、如何運用先前的 context 回答後續問題，以及如何透過變更 model 和 instructions 來調整行為。你也會清楚預覽本課程將建置的專案：一個能擷取即時資料、提供建議，並引導使用者完成多步驟任務的主題樂園夥伴。

這點很重要，因為後續課程會假設你能分辨單輪對話回應與可可靠執行動作的系統。瞭解 Tool、Workflow、memory 與 observability 如何相互配合後，你就能建置可在開發階段測試、也能部署至 production 的功能，不必猜測 model「實際上做了什麼」。
