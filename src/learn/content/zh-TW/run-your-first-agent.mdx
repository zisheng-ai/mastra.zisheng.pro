課程才剛開始，本課程的重點是設定並啟動 Mastra 環境，讓你在建置主題樂園 Agent 的過程中能快速反覆調整。你將 scaffold 一個新的獨立專案、設定 model Provider，並驗證所有環節皆能端到端正常運作。

你會啟動開發伺服器，並使用 Mastra Studio 與預設 Agent 互動、單獨測試 Tool，以及逐步執行範例 Workflow。在這個過程中，你會看到 Studio 如何協助你檢查輸出並瞭解系統的運作方式，而不必先建置任何 frontend。

這點很重要，因為隨著課程進行，由 CLI 產生的專案結構會成為所有 Agent、Tool、Workflow 與設定的所在之處。現在先熟悉 Studio 與 observability，就能擁有一套可靠的方法，在 Agent 變得更複雜時針對非預期輸出進行偵錯並追蹤品質。

> 「Studio 是你開發及測試 Mastra 應用程式的地方。在接觸 frontend 之前，你就能執行所有內容、檢查發生過的情況，並快速反覆調整。」
>
> — Guil Hernandez
