# <NetlifyLogo className="inline w-8 h-8 mr-2 align-middle" />Netlify {/* #netlify */}

Netlify AI Gateway は、キャッシュと可観測性を内蔵し、複数の Provider への統一されたアクセス手段を提供します。Mastra のモデルルーター経由で 66 個のモデルを利用できます。

詳しくは、[Netlify のドキュメント](https://docs.netlify.com/build/ai-gateway/overview/)を参照してください。

## 使用方法 {/* #usage */}

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'netlify/anthropic/claude-fable-5',
})
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Netlify のドキュメント](https://docs.netlify.com/build/ai-gateway/overview/)を確認してください。

:::

## 設定 {/* #configuration */}

```bash
# Use gateway API key
NETLIFY_TOKEN=your-netlify-token
NETLIFY_SITE_ID=your-netlify-site-id

# Or use provider API keys directly
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=ant-...
```
