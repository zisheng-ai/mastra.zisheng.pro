Mastra のモデルルーターを通じて 9 個の Berget.AI モデルを利用できます。認証には `BERGET_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Berget.AI のドキュメント](https://api.berget.ai)を参照してください。

```bash title=".env"
BERGET_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "berget/google/gemma-4-31B-it"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Berget.AI のドキュメント](https://api.berget.ai)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.berget.ai/v1",
    id: "berget/google/gemma-4-31B-it",
    apiKey: process.env.BERGET_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "berget/zai-org/GLM-5.2"
      : "berget/google/gemma-4-31B-it";
  }
});
```
