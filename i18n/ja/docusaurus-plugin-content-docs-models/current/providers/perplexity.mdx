Mastra のモデルルーターを通じて 4 個の Perplexity モデルを利用できます。認証には `PERPLEXITY_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Perplexity のドキュメント](https://docs.perplexity.ai)を参照してください。

```bash title=".env"
PERPLEXITY_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "perplexity/sonar"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    id: "perplexity/sonar",
    apiKey: process.env.PERPLEXITY_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "perplexity/sonar-reasoning-pro"
      : "perplexity/sonar";
  }
});
```

## Provider を直接インストールする

この Provider はスタンドアロン package として直接インストールし、Mastra のモデルルーター文字列の代わりに使用することもできます。詳しくは、[package のドキュメント](https://www.npmjs.com/package/@ai-sdk/perplexity)を参照してください。

```bash npm2yarn
npm install @ai-sdk/perplexity
```

Provider 固有の詳細については、[AI SDK Perplexity Provider のドキュメント](https://ai-sdk.dev/providers/ai-sdk-providers/perplexity)を参照してください。
