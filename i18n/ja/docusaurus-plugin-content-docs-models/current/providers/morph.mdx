# <img src="https://models.dev/logos/morph.svg" alt="Morph ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Morph {/* #morph */}

Mastra のモデルルーターを通じて 3 個の Morph モデルを利用できます。認証には `MORPH_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Morph のドキュメント](https://docs.morphllm.com)を参照してください。

```bash title=".env"
MORPH_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'morph/auto',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Morph のドキュメント](https://docs.morphllm.com)を確認してください。

:::
