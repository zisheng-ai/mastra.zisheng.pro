Mastra のモデルルーターを通じて 8 個の StepFun (Global) モデルを利用できます。認証には `STEPFUN_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[StepFun (Global) のドキュメント](https://platform.stepfun.ai/docs/en/overview/concept)を参照してください。

```bash title=".env"
STEPFUN_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "stepfun-ai/step-1-32k"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[StepFun (Global) のドキュメント](https://platform.stepfun.ai/docs/en/overview/concept)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.stepfun.ai/v1",
    id: "stepfun-ai/step-1-32k",
    apiKey: process.env.STEPFUN_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "stepfun-ai/stepaudio-2.5-tts"
      : "stepfun-ai/step-1-32k";
  }
});
```
