# <img src="https://models.dev/logos/model-oracle-ai.svg" alt="Model Oracle AI ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Model Oracle AI

Mastra のモデルルーターを通じて 15 個の Model Oracle AI モデルを利用できます。認証には `MODEL_ORACLE_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Model Oracle AI のドキュメント](https://modeloracle.com/setup/)を参照してください。

```bash title=".env"
MODEL_ORACLE_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "model-oracle-ai/auto"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Model Oracle AI のドキュメント](https://modeloracle.com/setup/)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.modeloracle.com/api/v1",
    id: "model-oracle-ai/auto",
    apiKey: process.env.MODEL_ORACLE_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "model-oracle-ai/o4-mini"
      : "model-oracle-ai/auto";
  }
});
```
