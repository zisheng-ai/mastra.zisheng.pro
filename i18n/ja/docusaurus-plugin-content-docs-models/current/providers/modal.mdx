# <img src="https://models.dev/logos/modal.svg" alt="Modal ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Modal

Mastra のモデルルーターを通じて 2 個の Modal モデルを利用できます。認証には `MODAL_PROXY_TOKEN` 環境変数が自動的に使用されます。

詳しくは、[Modal のドキュメント](https://modal.com/docs/guide/endpoints)を参照してください。

```bash title=".env"
MODAL_PROXY_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "modal/moonshotai/Kimi-K3"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Modal のドキュメント](https://modal.com/docs/guide/endpoints)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://inference.us-west.modal.direct/v1",
    id: "modal/moonshotai/Kimi-K3",
    apiKey: process.env.MODAL_PROXY_TOKEN,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "modal/thinkingmachines/Inkling-NVFP4"
      : "modal/moonshotai/Kimi-K3";
  }
});
```
