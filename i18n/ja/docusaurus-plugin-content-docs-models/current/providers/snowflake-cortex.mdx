# <img src="https://models.dev/logos/snowflake-cortex.svg" alt="Snowflake Cortex ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Snowflake Cortex

Mastra のモデルルーターを通じて 21 個の Snowflake Cortex モデルを利用できます。認証には `SNOWFLAKE_CORTEX_PAT` 環境変数が自動的に使用されます。 Configure `SNOWFLAKE_ACCOUNT` as well.

詳しくは、[Snowflake Cortex のドキュメント](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api)を参照してください。

```bash title=".env"
SNOWFLAKE_ACCOUNT=your-value
SNOWFLAKE_CORTEX_PAT=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "snowflake-cortex/claude-fable-5"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Snowflake Cortex のドキュメント](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api)を確認してください。

:::

const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "snowflake-cortex/snowflake-llama3.3-70b"
      : "snowflake-cortex/claude-fable-5";
  }
});
