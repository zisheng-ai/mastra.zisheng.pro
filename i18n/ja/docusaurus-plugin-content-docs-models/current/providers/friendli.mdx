# <img src="https://models.dev/logos/friendli.svg" alt="Friendli ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Friendli

Mastra のモデルルーターを通じて 5 個の Friendli モデルを利用できます。認証には `FRIENDLI_TOKEN` 環境変数が自動的に使用されます。

詳しくは、[Friendli のドキュメント](https://friendli.ai/docs/guides/serverless_endpoints/introduction)を参照してください。

```bash title=".env"
FRIENDLI_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "friendli/MiniMaxAI/MiniMax-M2.5"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Friendli のドキュメント](https://friendli.ai/docs/guides/serverless_endpoints/introduction)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.friendli.ai/serverless/v1",
    id: "friendli/MiniMaxAI/MiniMax-M2.5",
    apiKey: process.env.FRIENDLI_TOKEN,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "friendli/zai-org/GLM-5.2"
      : "friendli/MiniMaxAI/MiniMax-M2.5";
  }
});
```
