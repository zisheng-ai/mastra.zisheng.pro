Mastra のモデルルーターを通じて 7 個の MiniMax (minimaxi.com) モデルを利用できます。認証には `MINIMAX_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[MiniMax (minimaxi.com) のドキュメント](https://platform.minimaxi.com/docs/guides/quickstart)を参照してください。

```bash title=".env"
MINIMAX_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'minimax-cn/MiniMax-M2',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[MiniMax (minimaxi.com) のドキュメント](https://platform.minimaxi.com/docs/guides/quickstart)を確認してください。

:::

### カスタムヘッダー {/* #custom-headers */}

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: 'custom-agent',
  name: 'custom-agent',
  model: {
    url: 'https://api.minimaxi.com/anthropic/v1',
    id: 'minimax-cn/MiniMax-M2',
    apiKey: process.env.MINIMAX_API_KEY,
    headers: {
      'X-Custom-Header': 'value',
    },
  },
})
```

### 動的なモデル選択 {/* #dynamic-model-selection */}

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: 'dynamic-agent',
  name: 'Dynamic Agent',
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === 'complex'
    return useAdvanced ? 'minimax-cn/MiniMax-M3' : 'minimax-cn/MiniMax-M2'
  },
})
```

## Provider を直接インストールする {/* #direct-provider-installation */}

この Provider はスタンドアロン package として直接インストールし、Mastra のモデルルーター文字列の代わりに使用することもできます。詳しくは、[package のドキュメント](https://www.npmjs.com/package/@ai-sdk/anthropic)を参照してください。

```bash npm2yarn
npm install @ai-sdk/anthropic
```
