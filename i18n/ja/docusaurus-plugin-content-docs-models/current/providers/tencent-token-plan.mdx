Mastra のモデルルーターを通じて 1 個の Tencent Token Plan モデルを利用できます。認証には `TENCENT_TOKEN_PLAN_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Tencent Token Plan のドキュメント](https://cloud.tencent.com/document/product/1823/130060)を参照してください。

```bash title=".env"
TENCENT_TOKEN_PLAN_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "tencent-token-plan/hy3"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Tencent Token Plan のドキュメント](https://cloud.tencent.com/document/product/1823/130060)を確認してください。

:::
