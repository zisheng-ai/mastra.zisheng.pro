# <img src="https://models.dev/logos/the-grid-ai.svg" alt="The Grid AI ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />The Grid AI

Mastra のモデルルーターを通じて 9 個の The Grid AI モデルを利用できます。認証には `THEGRID_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[The Grid AI のドキュメント](https://thegrid.ai/docs)を参照してください。

```bash title=".env"
THEGRID_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "the-grid-ai/agent-max"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[The Grid AI のドキュメント](https://thegrid.ai/docs)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.thegrid.ai/v1",
    id: "the-grid-ai/agent-max",
    apiKey: process.env.THEGRID_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "the-grid-ai/text-standard"
      : "the-grid-ai/agent-max";
  }
});
```
