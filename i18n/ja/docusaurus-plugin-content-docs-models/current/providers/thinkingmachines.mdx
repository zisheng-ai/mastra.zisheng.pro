# <img src="https://models.dev/logos/thinkingmachines.svg" alt="Thinking Machines ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Thinking Machines {/* #thinking-machines */}

Mastra のモデルルーターを通じて 2 個の Thinking Machines モデルを利用できます。認証には `TINKER_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Thinking Machines のドキュメント](https://tinker-docs.thinkingmachines.ai/tinker/compatible-apis/anthropic/)を参照してください。

```bash title=".env"
TINKER_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'thinkingmachines/thinkingmachines/Inkling',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Thinking Machines のドキュメント](https://tinker-docs.thinkingmachines.ai/tinker/compatible-apis/anthropic/)を確認してください。

:::

## Provider を直接インストールする {/* #direct-provider-installation */}

この Provider はスタンドアロン package として直接インストールし、Mastra のモデルルーター文字列の代わりに使用することもできます。詳しくは、[package のドキュメント](https://www.npmjs.com/package/@ai-sdk/anthropic)を参照してください。

