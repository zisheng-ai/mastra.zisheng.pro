詳しくは、[CrofAI のドキュメント](https://crof.ai/docs)を参照してください。

```bash title=".env"
CROF_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "crof/deepseek-v3.2"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://crof.ai/v1",
    id: "crof/deepseek-v3.2",
    apiKey: process.env.CROF_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "crof/qwen3.6-27b"
      : "crof/deepseek-v3.2";
  }
});
```
