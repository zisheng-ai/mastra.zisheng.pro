# <img src="https://models.dev/logos/alibaba-coding-plan.svg" alt="Alibaba Coding Plan ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Alibaba Coding Plan {/* #alibaba-coding-plan */}

Mastra のモデルルーターを通じて 12 個の Alibaba Coding Plan モデルを利用できます。認証には `ALIBABA_CODING_PLAN_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Alibaba Coding Plan のドキュメント](https://www.alibabacloud.com/help/en/model-studio/coding-plan)を参照してください。

```bash title=".env"
ALIBABA_CODING_PLAN_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'alibaba-coding-plan/MiniMax-M2.5',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Alibaba Coding Plan のドキュメント](https://www.alibabacloud.com/help/en/model-studio/coding-plan)を確認してください。

:::
