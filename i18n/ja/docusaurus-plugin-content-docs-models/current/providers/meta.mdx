# <img src="https://models.dev/logos/meta.svg" alt="Meta ロゴ" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Meta

Mastra のモデルルーターを通じて 3 個の Meta モデルを利用できます。認証には `META_MODEL_API_KEY` 環境変数が自動的に使用されます。

詳しくは、[Meta のドキュメント](https://dev.meta.ai/docs)を参照してください。

```bash title=".env"
META_MODEL_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "meta/muse-spark-1.1"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra は OpenAI 互換の `/chat/completions` endpoint を使用します。一部の Provider 固有機能は利用できない場合があります。詳しくは、[Meta のドキュメント](https://dev.meta.ai/docs)を確認してください。

:::

## 高度な設定

### カスタムヘッダー

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.meta.ai/v1",
    id: "meta/muse-spark-1.1",
    apiKey: process.env.META_MODEL_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動的なモデル選択

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "meta/muse-spark-1.2-contributor"
      : "meta/muse-spark-1.1";
  }
});
```

## Provider を直接インストールする

この Provider はスタンドアロン package として直接インストールし、Mastra のモデルルーター文字列の代わりに使用することもできます。詳しくは、[package のドキュメント](https://www.npmjs.com/package/@ai-sdk/openai)を参照してください。

```bash npm2yarn
npm install @ai-sdk/openai
```
