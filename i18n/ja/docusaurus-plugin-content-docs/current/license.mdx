## Apache License 2.0 とは {/* #whats-apache-license-20 */}

Apache License 2.0 は、ソフトウェアの使用、変更、配布に関する広範な権利をユーザーに認める寛容なオープンソースライセンスです。次のことが許可されます。

- 商用利用を含む、あらゆる目的での無償利用
- ソースコードの閲覧、変更、再配布
- 派生著作物の作成と配布
- 制限のない商用利用
- コントリビューターによる特許保護

Apache License 2.0 は、特に寛容でビジネスにも適したオープンソースライセンスの 1 つです。

## Apache License 2.0 を採用した理由 {/* #why-we-chose-apache-license-20 */}

Apache License 2.0 を採用した主な理由は次のとおりです。

1. **真正なオープンソース**：オープンソースの原則とコミュニティの期待に沿った、広く認められているオープンソースライセンスです。

1. **ビジネスに適している**：商用利用と配布に制限がないため、あらゆる規模の企業に適しています。

1. **特許保護**：ユーザーに対する明示的な特許保護が含まれ、法的な安全性がさらに高まります。

1. **コミュニティ重視**：制約なくコミュニティへの貢献と協力を促進します。

1. **幅広い採用実績**：業界で広く採用され、よく理解されているオープンソースライセンスの 1 つです。

## Mastra を活用したビジネスの構築 {/* #building-your-business-with-mastra */}

Apache License 2.0 は、Mastra を活用してビジネスを構築する際に最大限の柔軟性を提供します。

### 許可されるビジネスモデル {/* #allowed-business-models */}

- **アプリケーションの構築**：Mastra で構築したアプリケーションを作成し、販売する
- **コンサルティングサービスの提供**：専門知識、導入、カスタマイズのサービスを提供する
- **カスタムソリューションの開発**：Mastra を使用してクライアント向けの専用 AI ソリューションを構築する
- **アドオンと拡張機能の作成**：Mastra の機能を拡張する補完的な Tool を開発し、販売する
- **研修と教育**：Mastra を効果的に使用するための講座や教材を提供する
- **ホステッドサービス**：Mastra をホステッドサービスまたはマネージドサービスとして提供する
- **SaaS プラットフォーム**：Mastra を利用した SaaS プラットフォームを構築する

### ライセンスに準拠した利用例 {/* #examples-of-compliant-usage */}

- 企業が Mastra を使用して AI 対応のカスタマーサービスアプリケーションを構築し、顧客に販売する
- コンサルティング会社が Mastra の導入およびカスタマイズサービスを提供する
- 開発者が Mastra で特化型の Agent と Tool を作成し、他社にライセンス供与する
- スタートアップが Mastra を利用して、特定業界向けのソリューション（医療 AI アシスタントなど）を構築する
- 企業が Mastra をホステッドサービスとして顧客に提供する
- SaaS プラットフォームが AI バックエンドとして Mastra を統合する
