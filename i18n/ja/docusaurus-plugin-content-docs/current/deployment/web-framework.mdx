# Web フレームワークを使用したデプロイ {/* #deploy-with-a-web-framework */}

Mastra を Web フレームワークと統合すると、フレームワークの標準的なデプロイ手順を使用して、アプリケーションと一緒にデプロイされます。Mastra の統合を正しくデプロイするため、以下の手順に従ってください。

:::warning
クラウドプロバイダーにデプロイする場合は、Mastra の設定から [LibSQLStore](/reference/storage/libsql) の使用箇所をすべて削除してください。LibSQLStore にはファイルシステムへのアクセスが必要なため、サーバーレスプラットフォームとは互換性がありません。
:::

統合ガイド：

- [Next.js との統合](/guides/getting-started/next-js)
- [Astro との統合](/guides/getting-started/astro)

## Vercel 上の Next.js との統合 {/* #with-nextjs-on-vercel */}

[ガイドの手順](/guides/getting-started/next-js)に従って Mastra を Next.js と統合し、Vercel へのデプロイを予定している場合は、`next.config.ts` に `serverExternalPackages: ["@mastra/*"]` を追加します。

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## Vercel 上の Astro との統合 {/* #with-astro-on-vercel */}

[ガイドの手順](/guides/getting-started/astro)に従って Mastra を Astro と統合し、Vercel へのデプロイを予定している場合は、Vercel アダプターとサーバー出力を `astro.config.mjs` に追加します。

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## Netlify 上の Astro との統合 {/* #with-astro-on-netlify */}

[ガイドの手順](/guides/getting-started/astro)に従って Mastra を Astro と統合し、Netlify へのデプロイを予定している場合は、Netlify アダプターとサーバー出力を `astro.config.mjs` に追加します。

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
