# クラウド Provider へのデプロイ

Mastra アプリケーションは、クラウド Provider やサーバーレスプラットフォームにデプロイできます。Mastra には、デプロイプロセスを自動化するための Vercel、Netlify、Cloudflare 向け組み込み Deployer がオプションで用意されています。

## Mastra platform {/* #mastra-platform */}

Mastra は、サーバーをクラウドにデプロイするためのプラットフォームを提供しています。詳しくは、[Mastra platform デプロイガイド](/docs/mastra-platform/overview)を参照してください。
