# Workflow runner

Mastra の [Workflow](/docs/workflows/overview) は、組み込みの Workflow runner で実行することも、オーケストレーション、監視、信頼性を担う専用の Workflow 実行プラットフォームにデプロイすることもできます。

## Inngest

Inngest は、インフラストラクチャを管理せずにバックグラウンド Workflow を実行できる開発者向けプラットフォームです。Mastra Workflow を Inngest にデプロイすると、ステップのメモ化、自動再試行、リアルタイム監視、一時停止と再開の機能を利用できます。

設定手順については [Inngest デプロイガイド](/guides/deployment/inngest)を、完全な実装については [Inngest Workflow のサンプル](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)を参照してください。

## Temporal

Temporal は、長時間実行される Workflow をオーケストレーションするための耐久性のある実行プラットフォームです。Mastra Workflow は Temporal worker 上で実行でき、各 `createStep` は Temporal activity にマッピングされ、自動再試行と永続的な状態管理が行われます。

`@mastra/temporal` パッケージは実験段階であり、本番環境での使用には適していません。設定手順については [Temporal デプロイガイド](/guides/deployment/temporal)を参照してください。
