# Arize exporter

[Arize](https://arize.com/) は、[Phoenix](https://phoenix.arize.com/)（オープンソース）と [Arize AX](https://arize.com/generative-ai/)（エンタープライズ）を通じて、AI アプリケーション向けのオブザーバビリティプラットフォームを提供します。Arize exporter は、OpenTelemetry と [OpenInference](https://github.com/Arize-ai/openinference/tree/main/spec) のセマンティック規約を使用して Trace を送信します。OpenInference に対応するあらゆる OpenTelemetry プラットフォームと互換性があります。

## インストール {/* #installation */}

```bash npm2yarn
npm install @mastra/arize@latest
```

## 設定 {/* #configuration */}

### Phoenix のセットアップ {/* #phoenix-setup */}

Phoenix は、セルフホストまたは Phoenix Cloud で利用できるオープンソースのオブザーバビリティプラットフォームです。

#### 前提条件 {/* #prerequisites */}

1. **Phoenix インスタンス**：Docker を使用してデプロイするか、[Phoenix Cloud](https://app.phoenix.arize.com/login) に登録する
1. **エンドポイント**：Phoenix エンドポイントの URL（`/v1/traces` で終わるもの）
1. **API キー**：認証なしのインスタンスではオプション、Phoenix Cloud では必須
1. **環境変数**：設定を指定する

```bash title=".env"
# Required
PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces  # Or your Phoenix Cloud URL

# Optional
PHOENIX_API_KEY=your-api-key  # For authenticated Phoenix instances
PHOENIX_PROJECT_NAME=mastra-service  # Defaults to 'mastra-service'
```

#### 設定不要のセットアップ {/* #zero-config-setup */}

環境変数を設定したら、設定を渡さずに exporter を使用できます。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 明示的な設定 {/* #explicit-configuration */}

認証情報を直接渡すこともできます。この値は環境変数より優先されます。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.PHOENIX_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
            apiKey: process.env.PHOENIX_API_KEY,
            projectName: process.env.PHOENIX_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

:::info[Docker を使用したクイックスタート]

インメモリの Phoenix インスタンスを使用してローカルでテストします。

```bash
docker run --pull=always -d --name arize-phoenix -p 6006:6006 \
  -e PHOENIX_SQL_DATABASE_URL="sqlite:///:memory:" \
  arizephoenix/phoenix:latest
```

`PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces` を設定して Mastra Agent を実行すると、[localhost:6006](http://localhost:6006) で Trace を確認できます。

:::

### Arize AX のセットアップ {/* #arize-ax-setup */}

Arize AX は、本番環境の AI システム向けに高度な機能を備えたエンタープライズオブザーバビリティプラットフォームです。

#### 前提条件 {/* #prerequisites-1 */}

1. **Arize AX アカウント**：[app.arize.com](https://app.arize.com/) で登録する
1. **Space ID**：組織の space 識別子
1. **API キー**：Arize AX の設定で生成する
1. **環境変数**：認証情報を設定する

```bash title=".env"
# Required
ARIZE_SPACE_ID=your-space-id
ARIZE_API_KEY=your-api-key

# Optional
ARIZE_PROJECT_NAME=mastra-service
```

#### 設定不要のセットアップ {/* #zero-config-setup-1 */}

環境変数を設定したら、設定を渡さずに exporter を使用できます。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({

        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 明示的な設定 {/* #explicit-configuration-1 */}


## 設定オプション {/* #configuration-options */}

Arize exporter は、OpenTelemetry の動作を細かく調整するための高度な設定に対応しています。

### 完全な設定 {/* #complete-configuration */}

```typescript
new ArizeExporter({
  // Phoenix Configuration
  endpoint: 'https://your-collector.example.com/v1/traces', // Required for Phoenix

  // Arize AX Configuration
  spaceId: 'your-space-id', // Required for Arize AX

  // Shared Configuration
  apiKey: 'your-api-key', // Required for authenticated endpoints
  projectName: 'mastra-service', // Optional project name

  // Optional OTLP settings
  headers: {
    'x-custom-header': 'value', // Additional headers for OTLP requests
  },

  // Debug and performance tuning
  logLevel: 'debug', // Logging: debug | info | warn | error
  batchSize: 512, // Batch size before exporting spans
  timeout: 30000, // Timeout in ms before exporting spans

  // Custom resource attributes
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.version': process.env.APP_VERSION,
  },
})
```

### バッチ処理のオプション {/* #batch-processing-options */}

Trace をバッチ化してエクスポートする方法を制御します。

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  apiKey: process.env.PHOENIX_API_KEY,

  // Batch processing configuration
  batchSize: 512, // Number of spans to batch (default: 512)
  timeout: 30000, // Max time in ms to wait before export (default: 30000)
})
```

### リソース属性 {/* #resource-attributes */}

エクスポートするすべての span にカスタム属性を追加します。

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.namespace': 'production',
    'service.instance.id': process.env.HOSTNAME,
    'custom.attribute': 'value',
  },
})
```

### カスタムメタデータ {/* #custom-metadata */}

予約されていない span 属性は OpenInference の `metadata` ペイロードへシリアライズされ、Arize/Phoenix に表示されます。`tracingOptions.metadata` を使用して追加できます。

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      companyId: 'acme-co',
      tier: 'enterprise',
    },
  },
})
```

`input`、`output`、`sessionId`、thread/user ID、OpenInference ID などの予約済みフィールドは自動的に除外されます。

## OpenInference のセマンティック規約 {/* #openinference-semantic-conventions */}

この exporter は生成 AI アプリケーション向けの [OpenInference Semantic Conventions](https://github.com/Arize-ai/openinference/tree/main/spec) を実装し、さまざまなオブザーバビリティプラットフォームで標準化された Trace 構造を提供します。
