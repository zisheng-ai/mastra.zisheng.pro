# Laminar exporter

[Laminar](https://laminar.sh/) は、AI Agent 向けのオープンソースかつ OpenTelemetry ネイティブな可観測性プラットフォームです。`Observability` 設定に 1 つの `MastraExporter` を組み込むだけで、Mastra Agent のすべての実行、モデルのステップ、Tool の呼び出し、サブ Agent をトレース、デバッグ、監視できます。

## インストール {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 設定 {/* #configuration */}

### 前提条件 {/* #prerequisites */}

1. **Laminar プロジェクト**: Laminar でプロジェクトを作成または選択します
1. **プロジェクト API キー**: Laminar のプロジェクト設定からコピーします
1. **環境変数**: 認証情報を設定します

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 設定不要でのセットアップ {/* #zero-config-setup */}

環境変数を設定したら、設定を渡さずに exporter を使用できます。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 明示的な設定 {/* #explicit-configuration */}

認証情報を直接渡すこともできます。この値は環境変数より優先されます。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::note
`MastraExporter` の全オプションやマルチ Agent のトレース例など、高度な使用方法については、[Laminar の Mastra 統合ガイド](https://laminar.sh/docs/tracing/integrations/mastra)を参照してください。
:::

Mastra には、OTLP/HTTP 経由で span を送信するスタンドアロンの [`LaminarExporter`](/reference/observability/tracing/exporters/laminar) も `@mastra/laminar` に含まれています。この exporter はアクティブな OTel context を継承できず、Mastra の span を Laminar ネイティブ形式へ完全にはマッピングしません。そのため、`observe()` wrapper、マルチ Agent の root span、Laminar での正確な表示には、上記の `@lmnr-ai/lmnr` 統合を使用してください。
