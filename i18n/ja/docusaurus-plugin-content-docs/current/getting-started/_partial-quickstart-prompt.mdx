<CopyPrompt identifier="quickstart">
  新しい Mastra プロジェクトを作成してください。Mastra は、モダンな TypeScript スタック上で AI アプリケーションと Agent を構築するためのフレームワークです。回答がすでに示されている場合を除き、コマンドを実行する前に次の質問を 1 つずつ行い、それぞれの回答を待ってください。

  1. プロジェクト名は何ですか？（デフォルト："my-mastra-app"）
  1. Provider は何ですか？（必須。選択肢："openai"、"anthropic"、"google"、"xai"）

  Provider がサポートされていない場合は、サポートされている値を列挙して、もう一度質問してください。

  次を実行します：`npm create mastra@latest <project-name> -- --llm <provider>`

  このコマンドはデフォルトの Mastra プロジェクトを作成し、検出したコーディングアシスタント向けの Mastra Skill をインストールします。また、必要に応じて Git を初期化します。

  作成後、プロジェクトディレクトリに移動し、開発サーバーを起動します：`npx bgproc start -n <project-name> -w -- npm run dev`

  `http://localhost:4111` で Mastra Studio を開きます。Studio は、Agent、Workflow、Tool を構築、テスト、管理するためのインターフェースです。

  Mastra のモデルルーターから数千種類のモデルを利用できることも伝えてください：[https://mastra.ai/models](https://mastra.ai/models)
</CopyPrompt>
