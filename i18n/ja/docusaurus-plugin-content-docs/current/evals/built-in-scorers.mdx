# 組み込み Scorer {/* #built-in-scorers */}

Mastra は、AI の出力を評価するための組み込み Scorer を一通り提供しています。一般的な評価シナリオに最適化されており、Agent や Workflow ですぐに利用できます。

独自の Scorer を作成する方法については、[カスタム Scorer](/docs/evals/custom-scorers) ガイドを参照してください。

## 利用可能な Scorer {/* #available-scorers */}

### 正確性と信頼性 {/* #accuracy-and-reliability */}

以下の Scorer は、Agent の回答がどの程度正確で、事実に忠実かつ完全であるかを評価します。

- [`answer-relevancy`](/reference/evals/answer-relevancy): 応答が入力クエリにどの程度適切に答えているかを評価します（`0-1`、高いほど良い）
- [`answer-similarity`](/reference/evals/answer-similarity): セマンティック分析を使用して Agent の出力を正解と比較し、CI/CD テストに利用します（`0-1`、高いほど良い）
- [`faithfulness`](/reference/evals/faithfulness): 応答が与えられたコンテキストをどの程度正確に反映しているかを測定します（`0-1`、高いほど良い）
- [`hallucination`](/reference/evals/hallucination): 事実との矛盾や裏付けのない主張を検出します（`0-1`、低いほど良い）
- [`completeness`](/reference/evals/completeness): 応答に必要な情報がすべて含まれているかを確認します（`0-1`、高いほど良い）
- [`content-similarity`](/reference/evals/content-similarity): 文字単位のマッチングを使用してテキストの類似度を測定します（`0-1`、高いほど良い）
- [`textual-difference`](/reference/evals/textual-difference): 文字列間のテキスト差分を測定します（`0-1`、高いほど類似）
- [`tool-call-accuracy`](/reference/evals/tool-call-accuracy): LLM が利用可能な選択肢から正しい Tool を選択したかを評価します（`0-1`、高いほど良い）
- [`trajectory-accuracy`](/reference/evals/trajectory-accuracy): すべての Span タイプについて、期待されるアクションの順序を評価します。対象には Tool と Model のアクティビティ、および Workflow のステップが含まれます（`0-1`、高いほど良い）
- [`prompt-alignment`](/reference/evals/prompt-alignment): Agent の応答が、ユーザープロンプトの意図、要件、完全性、形式にどの程度沿っているかを測定します（`0-1`、高いほど良い）

### コンテキストの品質 {/* #context-quality */}

以下の Scorer は、応答の生成に使用されたコンテキストの品質と関連性を評価します。

- [`context-precision`](/reference/evals/context-precision): Mean Average Precision を使用してコンテキストの順位を評価します。関連するコンテキストが上位にあるほど高いスコアになります（`0-1`、高いほど良い）
- [`context-relevance`](/reference/evals/context-relevance): 関連性レベルと使用状況の追跡を通じて、コンテキストの有用性を測定します。不足しているコンテキストも検出します（`0-1`、高いほど良い）

:::tip[コンテキスト Scorer の選び方]

- コンテキストの順序が重要で、標準的な情報検索指標が必要な場合は **Context Precision** を使用します（RAG のランキング評価に最適です）
- 関連性を詳細に評価し、コンテキストの使用状況を追跡して不足を特定したい場合は **Context Relevance** を使用します

どちらのコンテキスト Scorer も以下をサポートします。

- **静的コンテキスト**: 事前定義されたコンテキスト配列
- **動的なコンテキスト抽出**: カスタム関数を使用して実行結果からコンテキストを抽出（RAG システムやベクトルデータベースなどに最適です）

:::

### 出力品質 {/* #output-quality */}

以下の Scorer は、形式、スタイル、安全性の要件に準拠しているかを評価します。

- [`tone-consistency`](/reference/evals/tone-consistency): 文体のフォーマルさ、複雑さ、スタイルの一貫性を測定します（`0-1`、高いほど良い）
- [`toxicity`](/reference/evals/toxicity): 有害または不適切なコンテンツを検出します（`0-1`、低いほど良い）
- [`bias`](/reference/evals/bias): 出力に含まれる潜在的なバイアスを検出します（`0-1`、低いほど良い）
- [`keyword-coverage`](/reference/evals/keyword-coverage): 技術用語の使用状況を評価します（`0-1`、高いほど良い）

### Quick Checks {/* #quick-checks */}

高速で決定論的なアサーションに使用できる、LLM を使わない小規模な Scorer です。使用方法の詳細については、[Quick Checks](/docs/evals/quick-checks) ガイドを参照してください。

- [`checks.includes`](/reference/evals/checks#checksincludesexpected-options): 出力に部分文字列が含まれている場合は 1（`0` または `1`）
- [`checks.excludes`](/reference/evals/checks#checksexcludesunwanted-options): 出力に部分文字列が含まれていない場合は 1（`0` または `1`）
- [`checks.equals`](/reference/evals/checks#checksequalsexpected-options): 出力が文字列と完全に一致する場合は 1（`0` または `1`）
- [`checks.matches`](/reference/evals/checks#checksmatchespattern-options): 出力が正規表現に一致する場合は 1（`0` または `1`）
- [`checks.similarity`](/reference/evals/checks#checkssimilarityexpected-options): Dice 係数による文字列類似度（`0-1`、しきい値を指定した場合は二値）
- [`checks.calledTool`](/reference/evals/checks#checkscalledtooltoolname-options): Tool が N 回以上呼び出された場合は 1（`0` または `1`）
- [`checks.didNotCall`](/reference/evals/checks#checksdidnotcalltoolname): Tool が呼び出されなかった場合は 1（`0` または `1`）
- [`checks.toolOrder`](/reference/evals/checks#checkstoolorderexpectedorder): Tool が指定された順序で呼び出された場合は 1（`0` または `1`）
- [`checks.maxToolCalls`](/reference/evals/checks#checksmaxtoolcallsmax): Tool の呼び出し回数が上限以内の場合は 1（`0` または `1`）
- [`checks.usedNoTools`](/reference/evals/checks#checksusednotools): Tool が一度も呼び出されなかった場合は 1（`0` または `1`）
- [`checks.noToolErrors`](/reference/evals/checks#checksnotoolerrors): Tool 呼び出しでエラーが発生しなかった場合は 1（`0` または `1`）
