# WhatsApp {/* #whatsapp */}

WhatsApp channel を使用すると、Mastra Agent は WhatsApp Business Cloud を通じて顧客のメッセージを受信できます。Mastra は Agent の接続と Webhook ルートを処理します。Meta アプリの設定、認証情報、Webhook の設定については、Chat SDK の WhatsApp アダプターのドキュメントを参照してください。

## アダプターのインストール {/* #install-the-adapter */}

Chat SDK から WhatsApp アダプターをインストールします。

```bash npm2yarn
npm install @chat-adapter/whatsapp
```

## Agent の設定 {/* #agent-configuration */}

Agent の `channels.adapters` オブジェクトに `createWhatsAppAdapter()` を追加します。

```typescript title="src/mastra/agents/whatsapp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createWhatsAppAdapter } from '@chat-adapter/whatsapp'

export const whatsappAgent = new Agent({
  id: 'whatsapp-agent',
  name: 'WhatsApp Agent',
  instructions: 'Answer customer questions and help with tasks in WhatsApp.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      whatsapp: createWhatsAppAdapter(),
    },
  },
})
```

Mastra インスタンスに Agent を登録します。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { whatsappAgent } from './agents/whatsapp-agent'

export const mastra = new Mastra({
  agents: { whatsappAgent },
})
```

## アダプターの設定 {/* #adapter-setup */}

Meta アプリの設定、アクセストークン、電話番号 ID、Webhook の検証、メッセージ制限など、WhatsApp 固有の設定については、[Chat SDK WhatsApp アダプターのドキュメント](https://chat-sdk.dev/adapters/official/whatsapp)に従ってください。

アダプターは、次のような環境変数から WhatsApp の認証情報を読み取ります。

```bash title=".env"
WHATSAPP_ACCESS_TOKEN=your-meta-access-token
WHATSAPP_APP_SECRET=your-meta-app-secret
WHATSAPP_PHONE_NUMBER_ID=your-whatsapp-phone-number-id
WHATSAPP_VERIFY_TOKEN=your-webhook-verify-token
```

## Webhook URL {/* #webhook-url */}

Mastra は、Agent ID とアダプターキーから WhatsApp の Webhook ルートを生成します。

```text
/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

公開されている Mastra サーバーの URL をベース URL として使用します。

```text
https://your-app.example.com/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

WhatsApp の受信イベントの配信には、この URL を使用します。生成された Mastra ルートは WhatsApp からの POST イベントを処理します。Meta のコールバックと Webhook 検証フローについては、Chat SDK WhatsApp アダプターのドキュメントに従ってください。
