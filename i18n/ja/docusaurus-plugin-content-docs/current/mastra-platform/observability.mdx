# Mastra platform の Observability

Mastra platform の Observability は、Mastra のプロジェクトとデプロイ全体から検索可能なトレース、ログ、メトリクスを収集する、独立したホスト型プロダクトです。Studio を先にデプロイしたり、ローカルストレージを設定したりせずに可観測性を導入したい場合に使用します。

既存のアプリケーションに Mastra を追加する際は、`mastra init` を使用して platform の Observability を設定します。新しく作成した Mastra プロジェクトでは、手動で設定することもできます。

## クイックスタート

プロジェクトに合ったセットアップ方法を選択してください。

### 新規プロジェクト

マネージド Mastra プロジェクトを作成します。確認メッセージが表示されたら、Mastra Platform Observability を有効にすると、自動的に設定されます。

```bash npm2yarn
npm create mastra@latest
```

Observability を選択すると、作成コマンドが Mastra Platform で認証を行い、platform プロジェクトをプロビジョニングして、認証情報をプロジェクトに書き込みます。platform のセットアップをスキップした場合や、プロンプトなしの作成フローを使用した場合は、代わりに[手動セットアップ](#manual-setup)の手順に従ってください。

### Mastra をまだ導入していない既存プロジェクト

Next.js アプリなどの既存アプリケーションがあり、Mastra をまだ追加していない場合は、`mastra init` を実行し、確認メッセージが表示されたら Mastra Observability を有効にします。

```bash npm2yarn
npx mastra init
```

CLI では、既存の platform プロジェクトを選択するか、新しいプロジェクトを作成できます。

### 手動セットアップ

[Mastra Platform](https://projects.mastra.ai) でプロジェクトを作成し、`MASTRA_PLATFORM_ACCESS_TOKEN` と `MASTRA_PROJECT_ID` を `.env` に追加してから、Mastra 設定に `MastraPlatformExporter` を登録します。設定済みの Mastra Storage に Observability イベントも永続化する場合は、`MastraStorageExporter` を追加します。

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Observability, MastraPlatformExporter } from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraPlatformExporter()],
      },
    },
  }),
})
```

platform の Observability で使用する環境変数については、[Mastra platform の設定](/docs/mastra-platform/configuration#observability)を参照してください。

## Observability データを照会する

プロジェクトから Mastra Platform Observability へのトレース、ログ、スコアの送信が始まると、Mastra CLI または `curl` を使ってターミナルからデータを照会できます。

```bash npm2yarn
npx mastra api trace list
```

Observability コマンドを使用すると、CLI はホスト型 Observability API を対象とし、プロジェクト環境から認証情報を推測できます。利用可能な Observability コマンド、フィルタリング、ページネーション、認証情報の解決については、[`mastra api` CLI リファレンス](/reference/cli/mastra#mastra-api)を参照してください。このリファレンスには、`curl` を直接使用する例も掲載されています。
