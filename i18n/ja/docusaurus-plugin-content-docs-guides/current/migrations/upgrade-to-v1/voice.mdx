# Voice

Voice パッケージは speech から voice へ改名され、クラス名と API メソッドも更新されました。

## 変更

### Voice 設定のプロパティ名

一貫性を保つため、Voice 設定のプロパティ名が変更されました。`speakProvider` は `output`、`listenProvider` は `input`、`realtimeProvider` は `realtime` になりました。新しい名前は、Voice の入力と出力における各プロパティの役割に対応しています。

移行するには、Agent に Voice 機能を設定する際の設定プロパティ名を更新します。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip[Codemod]

Mastra の codemod CLI を使用すると、コードを自動更新できます。

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
