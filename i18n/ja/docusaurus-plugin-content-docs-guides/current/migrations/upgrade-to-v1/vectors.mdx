# Vector

Vector Store のコンストラクターで `id` プロパティが必須になり、Vector Store のメソッド名も一貫した命名規則に合わせて変更されました。

## 変更 {/* #changed */}

### Vector Store インスタンスで `id` プロパティが必須に {/* #required-id-property-for-vector-store-instances */}

Vector Store のインスタンスでは `id` プロパティが必須になりました。この一意な識別子は、Mastra 内で Vector Store インスタンスを追跡、管理するために使用されます。`id` には、アプリケーション内の Vector Store ごとに、内容を表す一意な文字列を指定してください。

移行するには、Vector Store のコンストラクターに `id` フィールドを追加します。

```diff
  const vectorStore = new PgVector({
+   id: 'main-vector-store',
    connectionString: process.env.POSTGRES_CONNECTION_STRING,
  });

  const chromaStore = new ChromaVector({
+   id: 'chroma-embeddings',
    url: process.env.CHROMA_URL,
  });

  const pineconeStore = new PineconeVector({
+   id: 'pinecone-production',
    apiKey: process.env.PINECONE_API_KEY,
  });
```

### `getVectors` から `listVectors` へ {/* #getvectors-to-listvectors */}

`getVectors()` メソッドは `listVectors()` に改名されました。この変更は、複数の値を取得する getter メソッドに `list` プレフィックスを使用する API 全体の命名規則に合わせたものです。

移行するには、`getVectors()` の呼び出しをすべて `listVectors()` に置き換えます。

```diff
  const vectorStore = new VectorStore({ ... });

- const vectors = await vectorStore.getVectors({ ... });
+ const vectors = await vectorStore.listVectors({ ... });
```

### `LibSQLVector`：`connectionUrl` から `url` へ {/* #libsqlvector-connectionurl-to-url */}

`connectionUrl` パラメーターは `@libsql/client` API に合わせ、LibSQLStorage と名前を統一するため、`url` に改名されました。

```diff
  const vectorStore = new LibSQLVector({
    id: 'my-vector',
-   connectionUrl: 'file:./db.sqlite',
+   url: 'file:./db.sqlite',
  });
```

### `OpenSearchVector`：`url` から `node` へ {/* #opensearchvector-url-to-node */}

`url` パラメーターは OpenSearch の `ClientOptions` API に合わせて `node` に改名されました。コンストラクターは、認証、SSL、圧縮を含む OpenSearch のすべてのクライアントオプションを受け取れるようになりました。

```diff
  const vectorStore = new OpenSearchVector({
    id: 'my-vector',
-   url: 'http://localhost:9200',
+   node: 'http://localhost:9200',
  });
```

### `PineconeVector`：`environment` を削除 {/* #pineconevector-environment-removed */}

`environment` パラメーターが削除されました。カスタム Controller Host を指定する必要がある場合は、代わりに `controllerHostUrl` を使用してください。コンストラクターは Pinecone のすべての設定オプションを受け取れるようになりました。

```diff
  const vectorStore = new PineconeVector({
    id: 'my-vector',
    apiKey: process.env.PINECONE_API_KEY,
-   environment: process.env.PINECONE_ENVIRONMENT,
  });
```

カスタム Controller Host が必要な場合：

```ts
const vectorStore = new PineconeVector({
  id: 'my-vector',
  apiKey: process.env.PINECONE_API_KEY,
  controllerHostUrl: 'https://api.pinecone.io',
})
```
