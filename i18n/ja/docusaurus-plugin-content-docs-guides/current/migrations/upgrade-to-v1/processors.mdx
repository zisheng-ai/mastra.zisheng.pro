# Processor

Processor インターフェースでは、一貫した命名パターンとデータベースメッセージ型を使用するようになりました。

## 変更

### Processor 設定の `name` から `id` へ

Processor では、`name` の代わりに `id` フィールドが必須になりました。`name` フィールドは任意になりました。この変更により、Scorer や Agent などの他の Mastra エンティティと一貫性が保たれます。

移行するには、Processor の定義を更新し、`id` を必須フィールドとして使用します。

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### Processor のメッセージ型を `MastraMessageV2` から `MastraDBMessage` へ変更

Processor のメッセージ型が `MastraMessageV2` から `MastraDBMessage` に変更されました。Processor と Scorer は、データベースメッセージ形式とその型を使用するようになりました。

移行するには、Processor のメッセージ型の import と使用箇所を更新します。

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 削除

### 非推奨の Input Processor export

組み込み Processor を含む非推奨の Input Processor export が、`@mastra/core/agent/input-processors/processors` から削除されました。代わりに `@mastra/core/processors` を使用してください。この変更により、Processor の型が統一された `Processor` インターフェースに集約されます。

`InputProcessor` を使用している場合は、`processInput` 関数を実装する `Processor` に置き換えます。

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory Processor の export を core に移動

`@mastra/memory/processors` の export は削除されました。すべての Processor は `@mastra/core/processors` から export されるようになりました。この変更により、すべての Processor の export が 1 か所に集約されます。

移行するには、import パスを `@mastra/memory/processors` から `@mastra/core/processors` に更新します。

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
