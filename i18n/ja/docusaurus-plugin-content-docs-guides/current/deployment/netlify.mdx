# Mastra を Netlify にデプロイする {/* #deploy-mastra-to-netlify */}

`@mastra/deployer-netlify` を使用して、Mastra サーバーを Netlify にデプロイします。Deployer はコードをバンドルし、Netlify の [Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/) に準拠した `.netlify` ディレクトリを生成します。デフォルトでは Serverless Function としてデプロイしますが、レイテンシを下げ、実行時間を延ばすために [Edge Function](https://docs.netlify.com/build/edge-functions/overview/) としてデプロイすることもできます。

:::info
このガイドでは、[Mastra サーバー](/docs/server/mastra-server)のデプロイについて説明します。[Server Adapter](/docs/server/server-adapters) または [Web フレームワーク](/docs/deployment/web-framework)を使用している場合は、そのフレームワークの通常の方法でデプロイしてください。
:::

## 始める前に {/* #before-you-begin */}

[Mastra アプリケーション](/guides/getting-started/quickstart)と [Netlify](https://www.netlify.com/) アカウントが必要です。

:::warning
Netlify Functions のファイルシステムは一時的なため、設定するすべてのストレージ（Observability ストレージを含む）は外部でホストする必要があります。[LibSQLStore](/reference/storage/libsql) でファイル URL を使用している場合は、リモートでホストされるデータベースに切り替えてください。
:::

## インストール {/* #installation */}

`@mastra/deployer-netlify` パッケージをプロジェクトに追加します。

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

[`NetlifyDeployer`](/reference/deployer/netlify) をインポートし、Mastra 設定の Deployer として指定します。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

代わりに Edge Function としてデプロイするには、`{ target: 'edge' }` を渡します。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

Edge Function はユーザーに最も近いエッジ上の Deno で動作します。厳密な実行タイムアウトはなく、CPU 時間の上限のみであるため、実行時間の長い AI Workflow に適しています。詳しくは[コンストラクターのオプション](/reference/deployer/netlify#constructor-options)を参照してください。

プロジェクトルートに、次の内容で `netlify.toml` ファイルを作成します。

```toml
[build]
command = "mastra build"
```

## デプロイする {/* #deploy */}

プロジェクトを設定したら、使用するリモート Git Provider（GitHub など）にプッシュします。

<Steps>
  <StepItem>
    リポジトリを Netlify に接続します。設定中に Netlify が `netlify.toml` ファイルを検出し、ビルドコマンドを `mastra build` に設定します。

    :::note

    アプリケーションの実行に必要な環境変数（[モデル Provider](/models/providers) の API キーなど）を設定してください。

    :::
  </StepItem>

  <StepItem>
    準備ができたら **Deploy** ボタンをクリックし、最初のデプロイが完了するまで待ちます。1 つの Function がデプロイされたことが表示されます。
  </StepItem>

  <StepItem>
    `https://<random-slug>.netlify.app/api/agents` でデプロイを確認します。Agent の一覧が JSON で返されます。

    [Mastra サーバー](/docs/server/mastra-server)はすべての API エンドポイントに `/api` を付けるため、リクエスト時の URL に追加する必要があります。

    :::info

    Netlify Functions は通常、`https://<random-slug>.netlify.app/.netlify/functions/api` にデプロイされます。`NetlifyDeployer` は `/*` へのすべてのリクエストを `/.netlify/functions/api/:splat` にリダイレクトするため、URL に `.netlify/functions` プレフィックスを含める必要はありません。

    :::
  </StepItem>

  <StepItem>
    これで、Mastra エンドポイントを HTTP 経由で呼び出せます。

    :::warning
    エンドポイントを公開する前に、[認証](/docs/server/auth)を設定してください。
    :::
  </StepItem>
</Steps>
