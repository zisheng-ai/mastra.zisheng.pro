# Mastra を Cloudflare にデプロイする

`@mastra/deployer-cloudflare` を使用して、Mastra サーバーを Cloudflare Workers にデプロイします。Deployer はコードをバンドルし、Cloudflare の [wrangler 設定](https://developers.cloudflare.com/workers/wrangler/configuration/)に準拠した `wrangler.jsonc` ファイルを生成するため、追加設定なしでデプロイできます。

:::info

[Server Adapter](/docs/server/server-adapters) または [Web フレームワーク](/docs/deployment/web-framework)を使用している場合は、そのフレームワークの通常の方法でデプロイしてください。

:::

## 始める前に {/* #before-you-begin */}

[Mastra アプリケーション](/guides/getting-started/quickstart)と [Cloudflare](https://cloudflare.com/) アカウントが必要です。

:::warning
Cloudflare Workers のファイルシステムは一時的なため、設定するすべてのストレージ（Observability ストレージを含む）は外部でホストする必要があります。[LibSQLStore](/reference/storage/libsql) でファイル URL を使用している場合は、リモートでホストされるデータベースに切り替えてください。
:::

## インストール {/* #installation */}

`@mastra/deployer-cloudflare` パッケージをプロジェクトに追加します。

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

[`CloudflareDeployer`](/reference/deployer/cloudflare) をインポートし、Mastra 設定の Deployer として指定します。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

Cloudflare Worker をローカルでテストするには、[`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/) もインストールします。

```bash npm2yarn
npm install -D wrangler
```

## 使用方法 {/* #usage */}

プロジェクトを設定したら、使用するリモート Git Provider（GitHub など）にプッシュします。

<Steps>
  <StepItem>
    リポジトリを Cloudflare に接続します。"Workers & Pages" ダッシュボードで **Create application** を選択し、次の Step で Git Provider を選択します。設定を続け、デプロイするリポジトリを選択します。

    :::note

    アプリケーションの実行に必要な環境変数（[モデル Provider](/models/providers) の API キーなど）を設定してください。`npx wrangler secret bulk .env` を使用すると、`.env` ファイルからシークレットをアップロードできます。詳しくは [Secrets](/reference/deployer/cloudflare#secrets) を参照してください。

    :::
  </StepItem>

  <StepItem>
    準備ができたら **Deploy** ボタンをクリックし、最初のデプロイが完了するまで待ちます。
  </StepItem>

  <StepItem>
    `https://<your-project-name>.<slug>.workers.dev/api/agents` にアクセスして、新しくデプロイした Function を試します。利用可能なすべての Agent を一覧にした JSON レスポンスが返されます。

    [Mastra サーバー](/docs/server/mastra-server)はすべての API エンドポイントに `/api` を付けるため、リクエスト時の URL に追加する必要があります。
  </StepItem>

  <StepItem>
    これで、Mastra エンドポイントを HTTP 経由で呼び出せます。

    :::note

    エンドポイントを公開する前に、[認証](/docs/server/auth)を設定してください。

    :::
  </StepItem>
</Steps>
