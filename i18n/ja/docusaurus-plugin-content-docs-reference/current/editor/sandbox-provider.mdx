# SandboxProvider

`SandboxProvider` は、Sandbox を [`MastraEditor`](/reference/editor/mastra-editor) に登録するためにパッケージが実装するインターフェースです。Editor は Workspace のハイドレーション時に `createSandbox(config)` を呼び出し、保存された [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) の Sandbox 設定にある `provider` ID を検索キーとして使用します。

組み込みの `local` Sandbox Provider は自動的に登録されます。外部 Provider（E2B など）は `MastraEditorConfig.sandboxes` を介して指定します。

## 使用例

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { e2bSandboxProvider } from '@mastra/e2b'

new MastraEditor({
  sandboxes: {
    [e2bSandboxProvider.id]: e2bSandboxProvider,
  },
})
```

## Provider を実装する

```typescript title="src/providers/my-sandbox.ts"
import type { SandboxProvider, WorkspaceSandbox } from '@mastra/core/editor'

export const mySandboxProvider: SandboxProvider<{ apiKey: string }> = {
  id: 'my-sandbox',
  name: 'My Sandbox',
  description: 'Cloud sandbox for command execution.',
  configSchema: {
    type: 'object',
    required: ['apiKey'],
    properties: {
      apiKey: { type: 'string' },
    },
  },
  async createSandbox(config): Promise<WorkspaceSandbox> {
    return createMySandbox({ apiKey: config.apiKey })
  },
}
```

登録後、管理者はインラインの Workspace 設定または保存された [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) から Provider を参照できます。
