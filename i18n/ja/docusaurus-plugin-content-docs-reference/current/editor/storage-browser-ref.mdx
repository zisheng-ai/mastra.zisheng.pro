# StorageBrowserRef

`StorageBrowserRef` は、保存された Agent に付加するインラインのブラウザー設定です。`provider` ID はハイドレーション時に、[`BrowserProvider`](/reference/editor/browser-provider) に対して解決されます。この Provider は [`MastraEditor.browsers`](/reference/editor/mastra-editor) に登録されています。

これは、[`BuilderAgentDefaults.browser`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) と保存済みの Agent レコードで使用される型です。

## 使用例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { stagehandBrowserProvider } from '@mastra/stagehand'

new MastraEditor({
  browsers: { [stagehandBrowserProvider.id]: stagehandBrowserProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        browser: {
          type: 'inline',
          config: {
            provider: 'stagehand',
            headless: true,
            viewport: { width: 1280, height: 720 },
          },
        },
      },
    },
  },
})
```

## 型 {/* #type */}

```typescript
type StorageBrowserRef = { type: 'inline'; config: StorageBrowserConfig }
```

ブラウザーでは `{ type: 'id' }` バリアントを使用できません。ブラウザーは常にインライン化されます。

## ハイドレーション {/* #hydration */}

`StorageBrowserRef` は、`mastra.editor.agent.getById()` の呼び出し時に遅延解決されます。Editor は `MastraEditor.browsers` で `config.provider` を検索し、`provider.createBrowser(config)` を呼び出します。Provider が登録されていない場合、Editor は警告をログに記録して `undefined` を返します。Agent は引き続き読み込まれますが、ブラウザーは使用できません。
