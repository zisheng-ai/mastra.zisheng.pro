# dataset.getDetails()

**追加バージョン：** `@mastra/core@1.4.0`

メタデータ、スキーマ、バージョン情報を含む完全なデータセットレコードをストレージから取得します。

## 使用例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## パラメータ {/* #parameters */}

このメソッドにパラメータはありません。

## 戻り値 {/* #returns */}

`Promise<DatasetRecord>` を返します。データセットが見つからない場合は `MastraError` をスローします。
