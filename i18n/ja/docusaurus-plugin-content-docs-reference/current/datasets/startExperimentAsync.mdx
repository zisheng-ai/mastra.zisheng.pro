# dataset.startExperimentAsync() {/* #datasetstartexperimentasync */}

**追加バージョン：** `@mastra/core@1.4.0`

Experiment を非同期（fire-and-forget）で開始します。Experiment ID と `'pending'` ステータスをすぐに返し、Experiment はバックグラウンドで実行されます。

## 使用例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
console.log(`Current status: ${experiment.status}`)
```

## パラメータ {/* #parameters */}

[`dataset.startExperiment()`](/reference/datasets/startExperiment) と同じ `StartExperimentConfig` を受け取ります。

`persistence.experiments` を `'none'` に設定すると、`startExperimentAsync()` は Experiment レコード、進行状況の更新、項目結果を永続化しません。スコアの永続化は引き続き `persistence.scores` で個別に制御します。Experiment Event Observer がない場合、実行は fire-and-forget となり、Experiment API では完了または失敗を確認できません。

呼び出し側で返される概要が必要な場合は、同期版の [`startExperiment()`](/reference/datasets/startExperiment) を使用します。Experiment Event Observer はライフサイクルイベントと最終概要を受信できます。
