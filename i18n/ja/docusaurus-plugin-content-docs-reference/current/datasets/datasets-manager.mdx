# DatasetsManager {/* #datasetsmanager */}

**追加バージョン：** `@mastra/core@1.4.0`

`DatasetsManager` クラスは、CRUD 操作やデータセット間の Experiment 比較など、データセットを管理する公開 API を提供します。`mastra.datasets` からアクセスします。

## 使用例 {/* #usage-examples */}

### データセットを作成して一覧表示する {/* #create-and-list-datasets */}

```typescript title="src/mastra/datasets/manage.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Create a dataset
const dataset = await mastra.datasets.create({
  name: 'QA pairs',
  description: 'Question-answer evaluation set',
})

// List all datasets
const { datasets } = await mastra.datasets.list()
```

### データセットを取得・削除する {/* #get-and-delete-a-dataset */}

```typescript title="src/mastra/datasets/get-delete.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Get by ID
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Delete by ID
await mastra.datasets.delete({ id: 'dataset-id' })
```

### Experiment を取得する {/* #get-experiment */}

ID を指定して特定の Experiment（実行）を取得します。`dataset.getExperiment()` とは異なり、先にデータセット参照を取得しなくても、すべてのデータセットを対象に機能します。

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Get experiment directly without knowing the dataset
const experiment = await mastra.datasets.getExperiment({
  experimentId: 'exp-id',
})

console.log(`Dataset: ${experiment.datasetId}`)
console.log(`Status: ${experiment.status}`)
```

### Experiment を比較する {/* #compare-experiments */}

```typescript title="src/mastra/datasets/compare.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const comparison = await mastra.datasets.compareExperiments({
  experimentIds: ['exp-1', 'exp-2'],
  baselineId: 'exp-1',
})
```

## アクセス {/* #access */}

`DatasetsManager` は直接インスタンス化しません。`Mastra` インスタンスからアクセスします：

```typescript
const mastra = new Mastra({/* storage config */})
const datasetsManager = mastra.datasets
```
