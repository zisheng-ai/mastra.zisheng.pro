# DeepEvalExporter

評価と Observability のために、Tracing データを [Confident AI](https://www.confident-ai.com/) へ送信します。DeepEval SDK を基盤とする `@mastra/deepeval` からエクスポートされます。

セットアップと使用方法については、[Confident AI exporter](/docs/observability/integrations/exporters/confident-ai) を参照してください。

## コンストラクター

```typescript prettier:false
new DeepEvalExporter(config?: DeepEvalExporterConfig)
```

## `DeepEvalExporterConfig`

```typescript
interface DeepEvalExporterConfig extends BaseExporterConfig {
  apiKey?: string
  environment?: string
  name?: string
  tags?: string[]
  metadata?: Record<string, any>
  threadId?: string
  userId?: string
  testCaseId?: string
  turnId?: string
  metricCollection?: string
  traceMetricCollection?: string
  llmMetricCollection?: string
  agentMetricCollection?: string
  toolMetricCollectionMap?: Record<string, string>
  prompt?: Prompt
  debug?: boolean
  traceCaptureSink?: (trace: Trace) => void
}
```

`BaseExporterConfig` を拡張し、次の項目を含みます。

- `logger?: IMastraLogger` - Logger インスタンス
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - ログレベル（デフォルト：INFO）

## メソッド

### `exportTracingEvent`

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

Tracing イベントを Confident AI へエクスポートします。Mastra の Span ストリームから Trace ツリーを構築し、ルート Span の終了時に Trace を送信します。

### `flush`

```typescript prettier:false
async flush(): Promise<void>
```

exporter をシャットダウンせず、処理中の Trace 送信が完了するまで待機します。

### `shutdown`

```typescript prettier:false
async shutdown(): Promise<void>
```

開いている Trace を完了させ、保留中の送信をフラッシュします。

## 使用方法

### ゼロコンフィグ（環境変数を使用）

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

// Reads from CONFIDENT_API_KEY, CONFIDENT_TRACE_ENVIRONMENT
const exporter = new DeepEvalExporter()
```

### 明示的な設定

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

const exporter = new DeepEvalExporter({
  apiKey: process.env.CONFIDENT_API_KEY,
  environment: 'production',
})
```

## Span タイプのマッピング

| Mastra Span タイプ | Confident AI Span タイプ |
| - | - |
| `AGENT_RUN`, `WORKFLOW_RUN` | `AGENT` |
| `MODEL_GENERATION` | `LLM` |
| `TOOL_CALL`, `MCP_TOOL_CALL`, `PROVIDER_TOOL_CALL`, `CLIENT_TOOL_CALL` | `TOOL` |
| `RAG_EMBEDDING`, `RAG_VECTOR_OPERATION` | `RETRIEVER` |
| その他のエクスポート対象 Span タイプ | `CUSTOM` |

イベント Span（`MODEL_CHUNK` など）は破棄されます。
