# PosthogExporter

AI の Observability と分析のために Tracing データを PostHog へ送信します。

## コンストラクター {/* #constructor */}

```typescript prettier:false
new PosthogExporter(config: PosthogExporterConfig)
```

## `PosthogExporterConfig` {/* #posthogexporterconfig */}

```typescript
interface PosthogExporterConfig extends BaseExporterConfig {
  apiKey?: string
  host?: string
  flushAt?: number
  flushInterval?: number
  serverless?: boolean
  defaultDistinctId?: string
  enablePrivacyMode?: boolean
}
```

`BaseExporterConfig` を拡張し、次の項目を含みます。

- `logger?: IMastraLogger` - Logger インスタンス
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - ログレベル（デフォルト：INFO）

## メソッド {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

Tracing イベントを PostHog へエクスポートします。

### `onFeedbackEvent` {/* #onfeedbackevent */}

```typescript prettier:false
async onFeedbackEvent(event: FeedbackEvent): Promise<void>
```

フィードバックイベントを PostHog へエクスポートします。[フィードバックのエクスポート](#feedback-export)を参照してください。

### flush {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

exporter をシャットダウンせず、バッファー内のすべてのイベントを PostHog へ強制的にフラッシュします。ランタイム終了前に Span が確実にエクスポートされるようにする必要があるサーバーレス環境で役立ちます。

### shutdown {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

保留中のバッチイベントをフラッシュし、PostHog クライアントをシャットダウンします。

## 使用方法 {/* #usage */}

### ゼロコンフィグ（環境変数を使用） {/* #zero-config-using-environment-variables */}

```typescript
import { PosthogExporter } from '@mastra/posthog'

// Reads from POSTHOG_API_KEY, POSTHOG_HOST
const exporter = new PosthogExporter()
```

### 明示的な設定 {/* #explicit-configuration */}

```typescript
import { PosthogExporter } from '@mastra/posthog'

const exporter = new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  host: 'https://us.i.posthog.com',
  serverless: true,
})
```

## フィードバックのエクスポート {/* #feedback-export */}

[`addFeedback()`](/docs/observability/feedback) で記録されたフィードバックは、ネイティブの `$ai_feedback` イベントとして PostHog へエクスポートされます。PostHog では、リンクされた Trace 上に **ユーザーフィードバック** として表示されます。追加設定は不要です。

```typescript
const trace = await mastra.observability.getRecordedTrace({ traceId })
await trace.addFeedback({
  feedbackType: 'thumbs',
  value: 'down',
  comment: 'Wrong answer',
})
```

フィードバックイベントは、次の PostHog プロパティにマッピングされます。

| Mastra フィードバックフィールド | PostHog プロパティ |
| - | - |
| `traceId` | `$ai_trace_id` |
| `comment`（ない場合は `value`） | `$ai_feedback_text` |
| `feedbackId` | `feedback_id` |
| `feedbackType` | `feedback_type` |
| `value` | `feedback_value` |
| `feedbackSource` | `feedback_source` |
| `spanId` | `span_id` |
| `sourceId` | `source_id` |
| `metadata.sessionId` | `$ai_session_id` |
| `metadata`（その他のキー） | カスタムプロパティ |

PostHog は `$ai_trace_id` を介してフィードバックを Trace に紐付けるため、`traceId` のないフィードバックは破棄されます。イベントの distinct ID は、`feedbackUserId`、`metadata.userId`、`defaultDistinctId`、`anonymous` の順で決定されます。
