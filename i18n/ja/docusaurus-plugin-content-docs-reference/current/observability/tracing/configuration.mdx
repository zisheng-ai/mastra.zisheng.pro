## `SamplingStrategy`

```typescript
type SamplingStrategy =
  | { type: 'always' }
  | { type: 'never' }
  | { type: 'ratio'; probability: number }
  | { type: 'custom'; sampler: (options?: TracingOptions) => boolean }
```

## レジストリメソッド

Observability クラスは、Observability インスタンスを管理するためのメソッドを提供します。

### `registerInstance`

```typescript prettier:false
registerInstance(
  name: string,
  instance: ObservabilityInstance,
  isDefault?: boolean
): void;
```

Observability インスタンスをレジストリに登録します。

### `getInstance`

```typescript prettier:false
getInstance(name: string): ObservabilityInstance | undefined;
```

名前で Observability インスタンスを取得します。

### `getDefaultInstance`

```typescript prettier:false
getDefaultInstance(): ObservabilityInstance | undefined;
```

デフォルトの Observability インスタンスを返します。

### `getSelectedInstance`

```typescript prettier:false
getSelectedInstance(
  options: ConfigSelectorOptions
): ObservabilityInstance | undefined;
```

設定セレクターで選択された Observability インスタンス、またはデフォルトのインスタンスを返します。

### `listInstances`

```typescript prettier:false
listInstances(): ReadonlyMap<string, ObservabilityInstance>;
```

登録済みのすべての Observability インスタンスを返します。

### `hasInstance`

```typescript prettier:false
hasInstance(name: string): boolean;
```

Observability インスタンスが存在するか確認します。

### `setConfigSelector`

```typescript prettier:false
setConfigSelector(selector: ConfigSelector): void;
```

設定セレクター関数を設定します。

### `unregisterInstance`

```typescript prettier:false
unregisterInstance(name: string): boolean;
```

Observability インスタンスをレジストリから削除します。

### clear

```typescript prettier:false
clear(): void;
```

シャットダウンせずにすべてのインスタンスを消去します。

### shutdown

```typescript prettier:false
async shutdown(): Promise<void>;
```

すべての Observability インスタンスをシャットダウンし、レジストリを消去します。
