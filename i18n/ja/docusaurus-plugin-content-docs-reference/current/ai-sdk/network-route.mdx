# networkRoute()

:::warning[非推奨]

Agent network は非推奨であり、今後のリリースで削除される予定です。代わりに、`agent.stream()` または `agent.generate()` とともに [supervisor agents](/docs/capabilities/subagents) を使用してください。アップグレード方法については、[移行ガイド](/guides/migrations/network-to-supervisor)を参照してください。

:::

AI SDK 形式を使用してネットワーク実行をストリーミングするためのネットワークルートハンドラーを作成します。この関数は、メッセージを受け取り、Agent network を実行し、AI SDK 互換形式でレスポンスをクライアントにストリーミングする HTTP `POST` エンドポイントを登録します。Agent network では、ルーティング Agent が他の Agent にタスクを委譲できます。[カスタム API ルート](/docs/server/custom-api-routes)内で使用する必要があります。

フレームワークに依存しないハンドラーが必要な場合は、[`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream) を使用してください。

`networkRoute()` では、既存の AI SDK v5 のデフォルト動作が維持されます。アプリが AI SDK v6 に対して型付けされている場合は、`version: 'v6'` を渡してください。

## 使用例

次の例では、ID が `weatherAgent` の Agent を使用するネットワークルートを `/network` エンドポイントに設定します。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

`agentId` に基づいて実行時に定義される Agent ルーティングも使用できます。URL `/network/weatherAgent` は、ID が `weatherAgent` の Agent に解決されます。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 追加設定

[`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) を使用すると、ネットワークルートに送信するリクエストをカスタマイズできます。たとえば、Agent に追加設定を渡せます。

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
