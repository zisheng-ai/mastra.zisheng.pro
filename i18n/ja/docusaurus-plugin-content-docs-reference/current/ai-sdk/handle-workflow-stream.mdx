# handleWorkflowStream()

AI SDK 互換形式で Workflow の実行をストリーミングする、フレームワークに依存しないハンドラーです。Hono または Mastra 独自の [apiRoutes](/docs/server/custom-api-routes) 機能の外部で Workflow のストリーミングを処理する必要がある場合は、この関数を直接使用します。

`handleWorkflowStream()` は、[`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) でラップできる `ReadableStream` を返します。

`handleWorkflowStream()` は、既存の AI SDK v5／デフォルトの動作を維持します。アプリが AI SDK v6 の型を使用している場合は、`version: 'v6'` を渡します。

Mastra サーバー内に Workflow ルートを作成する場合は、[`workflowRoute()`](/reference/ai-sdk/workflow-route) を使用してください。

:::tip Workflow 内での Agent ストリーミング

Workflow のステップが Agent のストリームを Workflow の writer にパイプすると（例: `await response.fullStream.pipeTo(writer)`）、Agent が Workflow のステップ内で実行されている場合でも、そのテキストチャンクと Tool 呼び出しがリアルタイムで UI ストリームに転送されます。

詳細は、[Workflow のストリーミング](/docs/workflows/overview#inspecting-workflow-stream-payloads)を参照してください。

:::

## 使用例 {/* #usage-example */}

Next.js App Router の例:

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
