# handleNetworkStream() {/* #handlenetworkstream */}

:::warning[非推奨]

Agent ネットワークは非推奨であり、今後のリリースで削除されます。代わりに、`agent.stream()` または `agent.generate()` とともに [Supervisor Agent](/docs/capabilities/subagents) を使用してください。移行するには[移行ガイド](/guides/migrations/network-to-supervisor)を参照してください。

:::

AI SDK 互換形式でネットワーク実行をストリーミングする、フレームワークに依存しないハンドラーです。Hono または Mastra 独自の [apiRoutes](/docs/server/custom-api-routes) 機能の外部でネットワークストリーミングを処理する必要がある場合は、この関数を直接使用します。

`handleNetworkStream()` は、[`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) でラップできる `ReadableStream` を返します。

`handleNetworkStream()` は、既存の AI SDK v5／デフォルトの動作を維持します。アプリが AI SDK v6 の型を使用している場合は、`version: 'v6'` を渡します。

Mastra サーバー内にネットワークルートを作成する場合は、[`networkRoute()`](/reference/ai-sdk/network-route) を使用してください。

## 使用例 {/* #usage-example */}

Next.js App Router の例:

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
