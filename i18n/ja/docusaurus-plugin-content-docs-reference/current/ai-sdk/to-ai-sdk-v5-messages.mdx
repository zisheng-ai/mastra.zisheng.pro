# toAISdkV5Messages() {/* #toaisdkv5messages */}

さまざまな入力形式のメッセージを、AI SDK V5 以降の UI メッセージ形式に変換します。この関数は、文字列、AI SDK V4/V5 メッセージ、Mastra DB メッセージなど、複数の形式のメッセージを受け取り、AI SDK V5 以降の `UIMessage` 形式に正規化します。この形式は、`useChat()` などの AI SDK UI コンポーネントでの使用に適しています。

## 使用例 {/* #usage-example */}

```typescript title="app/chat/page.tsx"
import { toAISdkV5Messages } from '@mastra/ai-sdk/ui'
import { useChat } from 'ai/react'

// Stored messages from your database, memory or API
const storedMessages = [
  { id: '1', role: 'user', content: 'Hello', parts: [{ type: 'text', text: 'Hello' }] },
  {
    id: '2',
    role: 'assistant',
    content: 'Hi there!',
    parts: [{ type: 'text', text: 'Hi there!' }],
  },
]

export default function Chat() {
  const { messages } = useChat({
    initialMessages: toAISdkV5Messages(storedMessages),
  })

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.role}: {message.parts.map(part => (part.type === 'text' ? part.text : null))}
        </div>
      ))}
    </div>
  )
}
```

## 例 {/* #examples */}

### テキストメッセージの変換 {/* #converting-text-messages */}

```typescript
import { toAISdkV5Messages } from '@mastra/ai-sdk/ui'

const messages = toAISdkV5Messages(['Hello', 'How can I help you today?'])
// Returns array of UIMessage objects with user role
```

### Mastra クライアントを使用したメッセージの読み込み {/* #loading-messages-with-mastra-client */}

```typescript
import { MastraClient } from '@mastra/client-js'
import { toAISdkV5Messages } from '@mastra/ai-sdk/ui'

const client = new MastraClient()

const { messages } = await client.listThreadMessages('thread-id', { agentId: 'myAgent' })
const uiMessages = toAISdkV5Messages(messages)
```
