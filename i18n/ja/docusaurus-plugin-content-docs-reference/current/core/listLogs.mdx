# Mastra.listLogs()

`.listLogs()` メソッドは、特定の Transport ID に対応するすべてのログを取得します。このメソッドを使用するには、`listLogs` 操作をサポートする Logger が設定されている必要があります。

## 使用例

```typescript
mastra.listLogs('456')
```
