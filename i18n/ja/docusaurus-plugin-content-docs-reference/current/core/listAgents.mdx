# Mastra.listAgents()

`.listAgents()` メソッドは、Mastra インスタンスに設定されているすべての Agent を取得します。

## 使用例

```typescript
mastra.listAgents()
```

## パラメーター

このメソッドはパラメーターを受け取りません。
