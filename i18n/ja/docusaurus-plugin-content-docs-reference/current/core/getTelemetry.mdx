# Mastra.getTelemetry() {/* #mastragettelemetry */}

`.getTelemetry()` メソッドは、Mastra インスタンスに設定されている Telemetry インスタンスを取得します。

## 使用例 {/* #usage-example */}

```typescript
mastra.getTelemetry()
```

## パラメーター {/* #parameters */}

このメソッドはパラメーターを受け取りません。
