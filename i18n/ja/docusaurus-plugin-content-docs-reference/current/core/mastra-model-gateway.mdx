# MastraModelGateway

カスタムモデル Gateway を実装するための抽象基底クラスです。Gateway は、Provider の設定、認証、URL の構築、モデルのインスタンス化など、言語モデルにアクセスするための Provider 固有のロジックを処理します。

基底クラスを拡張せず、プレーンオブジェクトの Gateway を提供する場合は `MastraModelGatewayInterface` を使用します。

## クラスの概要 {/* #class-overview */}

```typescript
import { MastraModelGateway, type ProviderConfig } from '@mastra/core/llm'
import { createOpenAICompatible } from '@ai-sdk/openai-compatible-v5'
import type { LanguageModelV2 } from '@ai-sdk/provider-v5'

class MyCustomGateway extends MastraModelGateway {
  readonly id = 'custom'
  readonly name = 'My Custom Gateway'

  async fetchProviders(): Promise<Record<string, ProviderConfig>> {
    return {
      'my-provider': {
        name: 'My Provider',
        models: ['__GATEWAY_OPENAI_MODEL__', '__GATEWAY_ANTHROPIC_MODEL_SONNET__'],
        apiKeyEnvVar: 'MY_API_KEY',
        gateway: this.id,
      },
    }
  }

  buildUrl(modelId: string, envVars?: Record<string, string>): string {
    return 'https://api.my-provider.com/v1'
  }

  async getApiKey(modelId: string): Promise<string> {
    const apiKey = process.env.MY_API_KEY
    if (!apiKey) throw new Error('MY_API_KEY not set')
    return apiKey
  }

  async resolveLanguageModel({
    modelId,
    providerId,
    apiKey,
  }: {
    modelId: string
    providerId: string
    apiKey: string
  }): Promise<LanguageModelV2> {
    const baseURL = this.buildUrl(`${providerId}/${modelId}`)
    return createOpenAICompatible({
      name: providerId,
      apiKey,
      baseURL,
    }).chatModel(modelId)
  }
}
```

### `buildUrl()` {/* #buildurl */}

Provider の URL に `${ACCOUNT_ID}` などのプレースホルダーが含まれる場合は、最終的な URL を返す前に、`buildUrl()` 内で `envVars` または `process.env` から解決します。

### `resolveAuth()` {/* #resolveauth */}

Mastra が言語モデルを作成する前に認証情報を解決します。Gateway が認証を担う場合は、この任意のフックを実装します。省略すると、Mastra は `getApiKey()` にフォールバックします。

**パラメーター:**

<PropertiesTable
  content={[

**戻り値:** `GatewayAuthResult | undefined | Promise<GatewayAuthResult | undefined>`

`GatewayAuthResult` には `apiKey`、`bearerToken`、`headers` と、認証情報の取得元を追跡するための任意の `source` フィールドを含めることができます。

Gateway の一意の識別子を返します。

**戻り値:** `string` - Gateway の `id` プロパティ

## モデル ID の形式 {/* #model-id-format */}

実際の Gateway では、Gateway ID がプレフィックスとして使用され、次の形式でモデルにアクセスします。

```
[gateway-id]/[provider]/[model]
```

例:

- `id = 'custom'` の Gateway: `'custom/my-provider/model-1'`
