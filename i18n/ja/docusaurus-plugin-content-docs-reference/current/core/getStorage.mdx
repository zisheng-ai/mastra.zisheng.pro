# Mastra.getStorage() {/* #mastragetstorage */}

`.getStorage()` メソッドは、Mastra インスタンスに設定されている Storage インスタンスを取得します。

## 使用例 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## パラメーター {/* #parameters */}

このメソッドはパラメーターを受け取りません。
