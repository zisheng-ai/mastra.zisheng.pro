# Mastra.getDeployer()

`.getDeployer()` メソッドは、Mastra インスタンスに設定されている Deployer インスタンスを取得します。

## 使用例 {/* #usage-example */}

```typescript
mastra.getDeployer()
```

## パラメーター {/* #parameters */}

このメソッドはパラメーターを受け取りません。
