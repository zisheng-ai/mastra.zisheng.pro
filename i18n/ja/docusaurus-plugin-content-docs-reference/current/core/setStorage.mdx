# Mastra.setStorage()

`.setStorage()` メソッドは、Mastra インスタンスに Storage インスタンスを設定します。単一の `MastraCompositeStore` パラメーターを受け取ります。

## 使用例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
