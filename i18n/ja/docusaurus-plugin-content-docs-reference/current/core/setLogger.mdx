# Mastra.setLogger() {/* #mastrasetlogger */}

`.setLogger()` メソッドは、Mastra インスタンスのすべてのコンポーネント（Agent、Workflow など）に Logger を設定します。logger プロパティを持つ単一のオブジェクトパラメーターを受け取ります。

## 使用例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
