# Mastra.getLogger()

`.getLogger()` メソッドは、Mastra インスタンスに設定されている Logger インスタンスを取得します。

## 使用例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## パラメータ {/* #parameters */}

このメソッドはパラメータを受け取りません。
