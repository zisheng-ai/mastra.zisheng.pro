# Mastra.getWorkflow() {/* #mastragetworkflow */}

`.getWorkflow()` メソッドは、登録キーで Workflow を取得します。このメソッドでは、Workflow の入出力スキーマに対して TypeScript の完全な型推論が適用されます。

## 使用例 {/* #usage-example */}

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 型推論 {/* #type-inference */}

TypeScript のサポートを最大限に活用するには、Workflow の**登録キー**（Workflow を Mastra に追加したときに使用したキー）を `getWorkflow()` に渡します。次の項目で完全な型推論が適用されます。

- 入力データスキーマ
- 出力データスキーマ
- ステップの結果

登録キーではなく Workflow の `id` プロパティで取得する必要がある場合は、`getWorkflowById()` を使用できます。ただし、型推論の精度は低くなります。
