# Mastra.listVectors() {/* #mastralistvectors */}

`.listVectors()` メソッドは、Mastra インスタンスに設定されているすべての Vector Store を取得します。

## 使用例 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## パラメーター {/* #parameters */}

このメソッドはパラメーターを受け取りません。
