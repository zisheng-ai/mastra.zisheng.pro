# Mastra.removeWorkspace() {/* #mastraremoveworkspace */}

`.removeWorkspace()` メソッドは、Mastra のランタイムレジストリから Workspace を削除します。削除前に Workspace を破棄するには、`{ destroy: true }` を渡します。

## 使用例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

<PropertiesTable
  content={[
  {
    name: 'id',

  },
]}
/>

## 戻り値 {/* #returns */}

<PropertiesTable
  content={[
  {
    name: 'removed',
    type: 'Promise<boolean>',
    description: 'Workspace が削除された場合は `true`。指定した ID の Workspace が存在しない場合は `false`。',
  },
]}
/>

`destroy` が `true` で `workspace.destroy()` が例外をスローした場合、呼び出しはそのエラーで拒否されます。呼び出し元がクリーンアップを再試行できるよう、Workspace は登録されたままになります。
