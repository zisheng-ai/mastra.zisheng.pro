# Mastra.listMCPServers()

`.listMCPServers()` メソッドは、Mastra インスタンスに登録されているすべての MCP Server インスタンスを取得します。返されるレコードでは、レジストリキー（`mcpServers` 設定のキー）がキーとして使用されます。

## 使用例

```typescript
// Register MCP servers
const server1 = new MCPServer({
  id: 'server-one',
  name: 'Server One',
  version: '1.0.0',
  tools: {/* ... */},
})

const server2 = new MCPServer({
  id: 'server-two',
  name: 'Server Two',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    firstServer: server1, // Registry key: 'firstServer'
    secondServer: server2, // Registry key: 'secondServer'
  },
})

// List all registered servers
const servers = mastra.listMCPServers()
// Returns: { firstServer: MCPServerBase, secondServer: MCPServerBase }
```

## パラメーター

このメソッドはパラメーターを受け取りません。
