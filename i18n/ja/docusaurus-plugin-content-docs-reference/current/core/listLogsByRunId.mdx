# Mastra.listLogsByRunId()

`.listLogsByRunId()` メソッドは、特定の Run ID と Transport ID に対応するログを取得します。このメソッドを使用するには、`listLogsByRunId` 操作をサポートする Logger が設定されている必要があります。

## 使用例 {/* #usage-example */}

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
