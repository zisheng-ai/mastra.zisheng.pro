# Mastra.getVector()

`.getVector()` メソッドは、名前で Vector Store を取得します。Vector Store 名を表す単一の `string` パラメーターを受け取ります。

## 使用例 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```

## パラメーター {/* #parameters */}

  {
    name: 'name',

    description: '取得する Vector Store の名前。Mastra の設定に存在する有効な Vector Store 名である必要があります。',
  },
]}
/>

]}
