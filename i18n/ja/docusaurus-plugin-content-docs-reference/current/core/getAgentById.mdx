# Mastra.getAgentById() {/* #mastragetagentbyid */}

`.getAgentById()` メソッドは、登録済みの Agent を `id` で取得します。最初に `agent.id` で登録済み Agent を検索します。一致する Agent がなければ [`Mastra.getAgent()`](/reference/core/getAgent) にフォールバックし、指定された値を Agent の登録キーとして扱います。

コードで定義した Agent を取得するには `mastra.getAgentById(id)` を使用します。バージョン管理された Agent を取得するには `await mastra.getAgentById(id, version)` を使用します。

## 使用例 {/* #usage-example */}

次の例では Agent を登録し、ID で取得して、返された Agent を使用します。

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
