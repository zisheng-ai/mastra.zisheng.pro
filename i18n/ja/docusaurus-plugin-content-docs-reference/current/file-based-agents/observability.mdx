# Observability {/* #observability */}

Mastra は、`src/mastra/` 直下の `observability.ts` ファイルから [Observability](/docs/observability/overview) を設定します。このファイルは、プロジェクトのトレース、ログ、メトリクス、フィードバックをセットアップする `Observability` インスタンスをデフォルト export します。

ファイルベースの規約については、このページを参照してください。シグナルモデル、Exporter、ストレージ、複数設定のセットアップについては、[Observability の概要](/docs/observability/overview)と [Observability の設定](/docs/observability/overview#configuration)を参照してください。

## クイックスタート {/* #quickstart */}

`src/mastra/observability.ts` を作成し、`Observability` インスタンスをデフォルト export します。

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability とストレージ {/* #observability-and-storage */}

`observability.ts` は、収集するシグナルとそのエクスポート先を設定します。[`storage.ts`](/reference/file-based-agents/storage) は、Observability のレコードを永続化できるプロジェクトストアを設定します。シグナルごとのストレージ対応状況については、[Observability のシグナル対応状況](/docs/observability/overview#signal-support)を参照してください。

## コードとの優先順位 {/* #precedence-with-code */}

コードで登録した Observability は、`observability.ts` より優先されます。プロジェクト全体で 1 つの設定で十分な場合は、`observability.ts` を使用してください。セットアップが `src/mastra/index.ts` のランタイム構成に依存する場合は、コードで登録してください。
