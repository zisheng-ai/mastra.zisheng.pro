# FirecrawlBrowser クラス

`FirecrawlBrowser` クラスは、[Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) を利用したブラウザー自動化を提供します。Firecrawl API を通じてリモートブラウザーセッションをプロビジョニングし、Chrome DevTools Protocol（CDP）経由で接続します。

`FirecrawlBrowser` は [`AgentBrowser`](/reference/browser/agent-browser) を拡張し、同じ決定論的な Tool セットを公開します。ローカルに Chromium をインストールせず、ホストされたブラウザーセッションを使用する場合に利用してください。ローカルでの自動化については [`AgentBrowser`](/reference/browser/agent-browser) を参照してください。自然言語を使用した AI による操作については [`StagehandBrowser`](/reference/browser/stagehand-browser) を参照してください。

## 使用例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## セッションのライフサイクル {/* #session-lifecycle */}

セッションのプロビジョニング方法は、`AgentBrowser` から継承した `scope` オプションによって異なります。

- `'thread'`（デフォルト）: 会話スレッドごとに専用の Firecrawl Sandbox セッションが割り当てられます。セッションは初回使用時に作成され、スレッドのブラウザーセッションが破棄されると削除されます。
- `'shared'`: ブラウザーの起動時に Firecrawl Sandbox セッションを1つ作成し、すべてのスレッドで共有します。ブラウザーを閉じるとセッションは削除されます。

どちらの場合も、`FirecrawlBrowser` はブラウザーを閉じる際にリモートの Firecrawl セッションを削除します。セッションの作成や接続が途中で失敗した場合も同様です。

## Tool {/* #tools */}

`FirecrawlBrowser` は、`browser_goto`、`browser_snapshot`、`browser_click`、`browser_type`、`browser_screenshot` など、`AgentBrowser` と同じ Tool セットを提供します。完全な一覧と Tool のパラメーターについては、[`AgentBrowser` Tool リファレンス](/reference/browser/agent-browser)を参照してください。
