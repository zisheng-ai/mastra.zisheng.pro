# LanceDBストレージ

LanceDBストレージ実装は、従来のデータストレージとベクトル操作の両方に優れたLanceDBデータベースシステムを使用し、高性能なストレージソリューションを提供します。

:::warning[Observabilityはサポートされていません]

LanceDBストレージは**Observabilityドメインをサポートしていません**。`MastraStorageExporter`のトレースをLanceDBに永続化できず、LanceDBだけをストレージProviderとして使用すると[Studio](/docs/studio/overview)のObservability機能も動作しません。Observabilityを有効にするには、[複合ストレージ](/reference/storage/composite#specialized-storage-for-observability)を使用して、ObservabilityデータをClickHouseなどの対応Providerに振り分けてください。

:::

## インストール

```bash npm2yarn
npm install @mastra/lance@latest
```

## 使用方法

### 基本的なストレージの使用方法

```typescript
import { LanceStorage } from '@mastra/lance'

// Connect to a local database
const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Connect to a LanceDB cloud database
const storage = await LanceStorage.create('my-storage', 'db://host:port')

// Connect to a cloud database with custom options
const storage = await LanceStorage.create('my-storage', 's3://bucket/db', {
  storageOptions: { timeout: '60s' },
})
```

## 補足事項

### スキーマ管理

LanceStorage実装は、スキーマの作成と更新を自動で処理します。Mastraのスキーマ型を、LanceDBが内部で使用するApache Arrowデータ型に次のように対応付けます。

- `text`, `uuid` → Utf8
- `int`, `integer` → Int32
- `float` → Float32
- `jsonb`, `json` → Utf8（シリアライズ済み）
- `binary` → Binary

### 初期化

ストレージをMastraクラスに渡すと、ストレージ操作の前に`init()`が自動で呼び出されます。

```typescript
import { Mastra } from '@mastra/core'
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

const mastra = new Mastra({
  storage, // init() is called automatically
})
```

Mastraを介さずにストレージを直接使用する場合は、テーブルを作成するために`init()`を明示的に呼び出す必要があります。

```typescript
import { LanceStorage } from '@mastra/lance'

const storage = await LanceStorage.create('my-storage', '/path/to/db')

// Required when using storage directly
await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

:::warning
`init()`を呼び出さないとテーブルが作成されず、ストレージ操作が何も通知せずに失敗するか、エラーがスローされます。
:::

### デプロイ方法

LanceDBストレージは、さまざまなデプロイ環境に合わせて設定できます。

- **ローカル開発**: 開発とテストにはローカルファイルパスを使用します
  ```
  /path/to/db
  ```
- **クラウドへのデプロイ**: ホストされたLanceDBインスタンスに接続します
  ```
  db://host:port
  ```
- **S3ストレージ**: 大容量のクラウドストレージとしてAmazon S3を使用します
  ```
  s3://bucket/db
  ```

### テーブル管理

LanceStorageは、テーブルを管理するための次のメソッドを提供します。

- カスタムスキーマでテーブルを作成
- テーブルを削除
- テーブルをクリア（すべてのレコードを削除）
- キーでレコードを読み込み
- 単一または複数のレコードを挿入
