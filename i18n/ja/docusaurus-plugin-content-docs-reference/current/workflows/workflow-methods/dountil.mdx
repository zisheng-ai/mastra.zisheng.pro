# Workflow\.dountil() {/* #workflowdountil */}

`.dountil()` メソッドは、条件を満たすまでステップを実行します。条件を評価する前に、必ずステップを 1 回以上実行します。条件が初めて評価されるとき、`iterationCount` は `1` です。

## 使用例 {/* #usage-example */}

```typescript
workflow.dountil(step1, async ({ inputData }) => true)
```
