# Workflow\.branch()

`.branch()` メソッドは Workflow のステップ間に条件分岐を作成し、前のステップの結果に基づいて異なるパスを選択できるようにします。

## 使用例 {/* #usage-example */}

```typescript
workflow.branch([
  [async ({ context }) => true, step1],
  [async ({ context }) => false, step2],
])
```
