# Workflow\.then() {/* #workflowthen */}

`.then()` メソッドは Workflow のステップ間に順次依存関係を作成し、ステップが指定した順序で実行されるようにします。

## 使用例 {/* #usage-example */}

```typescript
workflow.then(step1).then(step2)
```
