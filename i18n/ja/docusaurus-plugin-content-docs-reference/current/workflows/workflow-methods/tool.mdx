# Workflow\.tool()

`.tool()` メソッドは、Tool を宣言的なステップとして追加します。Tool 自身の入出力スキーマが適用されるため、前のステップの出力は Tool の入力スキーマを満たす必要があります。一致しない場合は、`.map()` を使用してデータを変換します。

Tool を `createStep()` でラップする場合とは異なり、`.tool()` は Workflow グラフに宣言的なエントリを記録します。これにより Workflow は移植可能になり、同じグラフをシリアライズして[動的 Workflow](/docs/workflows/dynamic-workflows) として永続化できます。

## 使用例 {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts" prettier:false
workflow.tool(testTool).commit();
```

## ID で Tool を参照する {/* #referencing-a-tool-by-id */}

登録済みの Tool をインポートせずに参照するには、文字列を渡します。Workflow の実行時に、その Tool が Mastra インスタンスへ登録されている必要があります。

```typescript filename="src/mastra/workflows/test-workflow.ts" prettier:false
workflow.tool("lookup-customer", { retries: 2 }).commit();
```

## Tool ステップを永続化する {/* #persisting-tool-steps */}

`.tool()` で構築した Workflow は、[動的 Workflow](/docs/workflows/dynamic-workflows) が使用するものと同じ宣言的なエントリにシリアライズされます。保存と復元の間で維持されるのは `retries` と `metadata` のみです。関数値の `scorers` オプションがある場合、Workflow の保存時にエラーがスローされます。
