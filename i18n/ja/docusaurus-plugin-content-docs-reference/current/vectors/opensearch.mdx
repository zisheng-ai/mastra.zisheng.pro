# OpenSearch vector store

OpenSearchVector クラスは、オープンソースの検索・分析エンジン [OpenSearch](https://opensearch.org/) を使用したベクトル検索を提供します。OpenSearch の k-NN 機能を使用してベクトル類似度検索を行います。

## コンストラクターオプション {/* #constructor-options */}

コンストラクターは、必須の `id` フィールドに加えて、すべての [OpenSearch ClientOptions](https://opensearch.org/docs/latest/clients/javascript/index/) を受け取ります。
