# Cloudflare vector store {/* #cloudflare-vector-store */}

CloudflareVector クラスは、Cloudflare のエッジネットワークと統合されたベクトルデータベースサービス [Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/) を使用したベクトル検索を提供します。

## レスポンス型 {/* #response-types */}

クエリ結果は次の形式で返されます。

```typescript
interface QueryResult {
  id: string
  score: number
  metadata: Record<string, any>
  vector?: number[]
}
```

## エラー処理 {/* #error-handling */}

store は捕捉可能な型付きエラーをスローします。

```typescript
try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof VectorStoreError) {
    console.log(error.code) // 'connection_failed' | 'invalid_dimension' | etc
    console.log(error.details) // Additional error context
  }
}
```

## 環境変数 {/* #environment-variables */}

必要な環境変数:

- `CLOUDFLARE_ACCOUNT_ID`: Cloudflare アカウント ID
- `CLOUDFLARE_API_TOKEN`: Vectorize 権限を持つ Cloudflare API トークン
