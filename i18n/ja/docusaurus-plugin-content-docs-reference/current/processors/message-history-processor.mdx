# MessageHistory

`MessageHistory` は、メッセージ履歴の取得と永続化の両方を処理する **ハイブリッド Processor** です。入力時にはストレージから過去のメッセージを取得して会話の先頭に追加し、出力時には新しいメッセージをストレージに永続化します。

## 使用例 {/* #usage-example */}

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
})
```

## 詳細な使用例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStorage } from '@mastra/pg'

const storage = new PostgresStorage({
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
    }),
  ],
})
```

## 動作 {/* #behavior */}

### 入力処理 {/* #input-processing */}

1. Request コンテキストから `threadId` を取得します
1. ストレージから過去のメッセージを取得します（作成日時の降順）
1. System メッセージを除外します（データベースに保存しないため）
1. ID の重複を避けながら、過去のメッセージと受信メッセージを統合します
1. 過去のメッセージに `source: 'memory'` タグを追加します

### 出力処理 {/* #output-processing */}

1. Request コンテキストから `threadId` を取得します
1. Memory 設定で `readOnly` が指定されている場合は永続化をスキップします
1. メッセージから未完了の Tool 呼び出しを除外します
1. 新しいユーザー入力と Assistant の応答メッセージをストレージに永続化します
1. Thread の `updatedAt` タイムスタンプを更新します
