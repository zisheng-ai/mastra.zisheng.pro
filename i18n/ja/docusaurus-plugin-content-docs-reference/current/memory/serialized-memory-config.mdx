# SerializedMemoryConfig

`SerializedMemoryConfig` は、保存された Agent レコードに格納される、JSON でシリアライズ可能な [`Memory`](/reference/memory/memory-class) 設定のサブセットです。ランタイムは、設定済みの `Mastra` インスタンスに対して vector ID と embedder ID を解決し、この設定を `Memory` インスタンスへ復元します。

これは [`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) と `EditorAgentNamespace.create({ memory })` で使われる型です。

## 使用例

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
