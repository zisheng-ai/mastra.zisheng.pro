# Agent.listWorkflows() {/* #agentlistworkflows */}

`.listWorkflows()` メソッドは、Agent に設定された Workflow を取得します。設定が関数の場合は、その関数を解決します。これらの Workflow により、Agent は実行経路が定義された複雑な複数 Step のプロセスを実行できます。

## 使用例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
