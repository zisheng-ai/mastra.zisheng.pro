# Agent.getTools()

`.getTools()` メソッドは、Agent に設定された Tool を取得し、関数の場合は解決します。これらの Tool は Agent の機能を拡張し、特定の操作の実行や外部システムへのアクセスを可能にします。

## 使用例

```typescript
await agent.getTools()
```
