# Agent.getLLM()

`.getLLM()` メソッドは、Agent に設定された言語モデルのインスタンスを取得し、関数の場合は解決します。Agent に設定されたモデルを変更せずに、リクエスト単位で上書きする `model` を渡すこともできます。

## 使用例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
