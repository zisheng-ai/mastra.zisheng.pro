# Agent.listTools()

`.listTools()` メソッドは、Agent に設定された Tool を取得します。設定が関数の場合は、その関数を解決します。これらの Tool によって Agent の機能が拡張され、特定の処理の実行や外部システムへのアクセスが可能になります。

## 使用例

```typescript
await agent.listTools()
```
