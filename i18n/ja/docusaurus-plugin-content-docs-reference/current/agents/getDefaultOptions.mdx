# Agent.getDefaultOptions()

Agent では、Memory の使用方法と出力形式のデフォルトオプションを設定できます。反復 Step も設定できます。`.getDefaultOptions()` メソッドは、関数の場合は解決したうえで、これらのデフォルト値を返します。上書きしない限り、すべての `stream()` と `generate()` 呼び出しに適用され、内容が不明な Agent のデフォルト値を確認する際に役立ちます。

## 使用例 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
