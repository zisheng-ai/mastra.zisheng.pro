# `.listSkills()`

Agent レベルの Skill と Workspace の Skill を含め、Agent が利用できるすべての Skill のメタデータを返します。

## 使用例

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## 戻り値

`Promise<SkillMetadata[]>` を返します。

各要素には、検出された Skill のメタデータが含まれます。

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  source: { type: string; projectPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: string[]
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## マージ動作

Agent レベルの Skill と Workspace の Skill の両方が設定されている場合、`.listSkills()` はそれらをマージした集合を返します。同じ名前が競合した場合は、Agent レベルの Skill が優先されます。両方に `code-review` という Skill が定義されている場合、Agent レベルのものだけが返されます。
