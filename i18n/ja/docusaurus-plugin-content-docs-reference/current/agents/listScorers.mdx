# Agent.listScorers() {/* #agentlistscorers */}

`.listScorers()` メソッドは、Agent に設定された Scorer 設定を取得します。設定が関数の場合は、その関数を解決します。このメソッドにより、Agent のレスポンスとパフォーマンスの評価に使用する Scorer システムへアクセスできます。

## 使用例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
