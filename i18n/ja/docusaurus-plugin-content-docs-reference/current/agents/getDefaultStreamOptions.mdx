# Agent.getDefaultStreamOptionsLegacy()

:::warning

**非推奨**：このメソッドは非推奨で、V1 モデルでのみ動作します。V2 モデルでは、新しい [`.getDefaultOptions()`](./getDefaultOptions) メソッドを使用してください。

:::

Agent では、Memory の使用方法と出力形式のデフォルトストリーミングオプションを設定できます。反復 Step も設定できます。`.getDefaultStreamOptionsLegacy()` メソッドは、関数の場合は解決したうえで、これらのデフォルト値を返します。上書きしない限り、すべての `streamLegacy()` 呼び出しに適用され、内容が不明な Agent のデフォルト値を確認する際に役立ちます。

## 使用例

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
