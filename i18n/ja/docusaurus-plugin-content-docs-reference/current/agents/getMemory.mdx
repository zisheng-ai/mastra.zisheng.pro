# Agent.getMemory()

`.getMemory()` メソッドは、Agent に関連付けられた Memory システムを取得します。このメソッドは、会話をまたいで情報を保存、取得する Agent の Memory 機能へアクセスするために使います。

## 使用例 {/* #usage-example */}

```typescript
await agent.getMemory()
```
