# Agent.listAgents()

`.listAgents()` メソッドは、Agent に設定された Subagent を取得します。設定が関数の場合は、その関数を解決します。これらの Subagent により、Agent はほかの Agent にアクセスし、複雑な処理を実行できます。

## 使用例

```typescript
await agent.listAgents()
```
