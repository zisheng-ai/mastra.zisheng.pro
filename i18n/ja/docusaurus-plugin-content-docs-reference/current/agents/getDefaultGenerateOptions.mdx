# Agent.getDefaultGenerateOptionsLegacy() {/* #agentgetdefaultgenerateoptionslegacy */}

:::warning

**非推奨**：このメソッドは非推奨で、V1 モデルでのみ動作します。V2 モデルでは、新しい [`.getDefaultOptions()`](./getDefaultOptions) メソッドを使用してください。

:::

Agent では、モデルの動作、出力形式、Tool や Workflow の呼び出しを制御するデフォルトの生成オプションを設定できます。`.getDefaultGenerateOptionsLegacy()` メソッドは、関数の場合は解決したうえで、これらのデフォルト値を取得します。上書きしない限り、すべての `generateLegacy()` 呼び出しに適用され、内容が不明な Agent のデフォルト値を確認する際に役立ちます。

## 使用例 {/* #usage-example */}

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
