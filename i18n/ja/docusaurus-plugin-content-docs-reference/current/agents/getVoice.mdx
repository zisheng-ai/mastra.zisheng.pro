# Agent.getVoice()

`.getVoice()` メソッドは、Agent に設定された Voice Provider を取得し、関数の場合は解決します。このメソッドは、テキスト読み上げと音声テキスト変換に使う Agent の音声機能へアクセスするために使います。

## 使用例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
