# Agent.getDescription()

`.getDescription()` メソッドは、Agent に設定された説明を取得します。Agent の目的と機能を表す文字列を返します。

## 使用例

```typescript
agent.getDescription()
```

## パラメータ

このメソッドにパラメータはありません。

]}
