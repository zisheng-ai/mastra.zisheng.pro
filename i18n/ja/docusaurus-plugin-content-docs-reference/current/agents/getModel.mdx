# Agent.getModel() {/* #agentgetmodel */}

`.getModel()` メソッドは、Agent に設定された言語モデルを取得し、関数の場合は解決します。このメソッドは、Agent の機能を動かす基盤モデルへアクセスするために使います。

## 使用例 {/* #usage-example */}

```typescript
await agent.getModel()
```
