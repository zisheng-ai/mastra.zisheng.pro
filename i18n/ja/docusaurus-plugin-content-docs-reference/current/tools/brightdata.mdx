# Bright Data Tools

`@mastra/brightdata` パッケージは、[Bright Data SDK](https://github.com/brightdata/bright-data-sdk-node) を Mastra 互換の Tool としてラップします。Web 検索と Web ページ取得のファクトリ関数を公開しています。各関数は、完全な Zod 入出力スキーマを含む [`createTool()`](./create-tool) で作成された Tool を返します。

検索 Tool は Bright Data の [SERP API](https://brightdata.com/products/serp-api) を、取得 Tool は [Web Unlocker](https://brightdata.com/products/web-unlocker) を利用します。どちらも Bot 検出と CAPTCHA を回避します。

## インストール

```sh npm2yarn
npm install @mastra/brightdata zod
```

## クイックスタート

共有設定で両方の Tool を取得するには、`createBrightDataTools()` を使用します。

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()
// Or pass an explicit API key:
// const { webSearch, webFetch } = createBrightDataTools({ apiKey: 'brd-...' })
```

各 Tool を個別に作成することもできます。

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataSearchTool, createBrightDataFetchTool } from '@mastra/brightdata'

const searchTool = createBrightDataSearchTool()
const fetchTool = createBrightDataFetchTool({ apiKey: 'brd-...' })
```

デフォルトでは、すべての Tool が環境から `BRIGHTDATA_API_TOKEN` を読み取ります。明示的に `{ apiKey }` を渡して上書きできます。

## 設定

すべてのファクトリ関数は、`@brightdata/sdk` の `BrightDataClientOptions` を受け取ります。

## `createBrightDataTools()`

共有設定を使用する両方の Tool を含むオブジェクトを返します。

```typescript
import { createBrightDataTools } from '@mastra/brightdata'

const tools = createBrightDataTools({ apiKey: 'brd-...' })
// tools.webSearch, tools.webFetch
```

**戻り値：** `{ webSearch, webFetch }`

## Agent の例

次の例は、検索と取得を組み合わせた調査 Agent を示しています。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the search tool to find relevant pages, then use the fetch tool to read full Markdown content from the best results.',
  tools: {
    webSearch,
    webFetch,
  },
})
```
