# createBedrockKBTool()

`createBedrockKBTool()` 関数は、Amazon Bedrock Knowledge Base から関連ドキュメントを取得する Tool を作成します。マネージド検索設定と Agentic Retrieval（クエリ分解およびマネージド再ランキング）の両方をサポートし、標準検索へ自動的にフォールバックします。

## 使用例 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### Agent と使用する {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

### BedrockKBResult {/* #bedrockkbresult */}

| フィールド | 型 | 説明 |
| - | - | - |
| `content` | `string` | 取得した一節のテキストコンテンツ。 |

## 検索モード {/* #retrieval-modes */}

### Agentic Retrieval（デフォルト） {/* #agentic-retrieval-default */}

`useAgenticRetrieval` が `true`（デフォルト）の場合、この Tool は `AgenticRetrieveStreamCommand` を使用して次の処理を行います。

- 複雑なクエリをサブクエリに分解する
- 複数のパスにわたって検索する
- マネージド再ランキングを適用して結果を改善する

Agentic Retrieval が失敗した場合（古い SDK や権限不足など）、標準のマネージド検索へ自動的にフォールバックします。

### 標準のマネージド検索 {/* #standard-managed-retrieval */}

`useAgenticRetrieval` が `false` の場合、この Tool は `managedSearchConfiguration` を指定した `RetrieveCommand` を使用し、1 回のパスで直接検索します。

## ユーザー単位のアクセス制御 {/* #user-based-access-control */}

Mastra のリクエストコンテキストに `userId` を設定すると、Bedrock の `userContext.userId` として転送されます。これにより、ドキュメントレベルのアクセス制御を適用する Knowledge Base を利用できます。リクエストコンテキストの値は、Tool に設定されたデフォルトの `userId` より優先されます。

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```

## 必要な IAM 権限 {/* #required-iam-permissions */}

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["bedrock:Retrieve", "bedrock:AgenticRetrieveStream"],
      "Resource": "arn:aws:bedrock:*:*:knowledge-base/*"
    }
  ]
}
```

## SDK の要件 {/* #sdk-requirements */}

- `@aws-sdk/client-bedrock-agent-runtime` >= 3.1000（AgenticRetrieveStreamCommand には \~3.1000 以降が必要です）
