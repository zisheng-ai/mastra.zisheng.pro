# MastraServer {/* #mastraserver */}

`MastraServer` 抽象クラスは、すべてのサーバーアダプターの基底クラスです。Hono または Express 以外のフレームワーク用アダプターを作成するには、このクラスを拡張します。

## インポート {/* #import */}

```typescript
import { MastraServer } from '@mastra/server/server-adapter'
```

## 型パラメーター {/* #type-parameters */}

```typescript
MastraServer<TApp, TRequest, TResponse>
```

| パラメーター | 説明 |
| - | - |
| `TApp` | フレームワークのアプリ型（例：`Hono`、`Application`） |
| `TRequest` | フレームワークのリクエスト型 |
| `TResponse` | フレームワークのレスポンス／コンテキスト型 |

## コンストラクター {/* #constructor */}

```typescript prettier:false
constructor(options: MastraServerOptions<TApp>)
```

## 抽象メソッド {/* #abstract-methods */}

アダプターでは、次のメソッドを実装する必要があります。

### `registerContextMiddleware()` {/* #registercontextmiddleware */}

すべてのリクエストに Mastra コンテキストを付加します。

```typescript prettier:false
abstract registerContextMiddleware(): void
```

**付加するコンテキスト：**

- `mastra` - Mastra のインスタンス
- `requestContext` - リクエストスコープのコンテキスト
- `tools` - 利用可能な Tool
- `abortSignal` - リクエストのキャンセルシグナル

### `registerAuthMiddleware()` {/* #registerauthmiddleware */}

初期化時にアダプターの認証フックを実行します。公式アダプターでは、ルートごとに認証を適用する場合、このメソッドを何もしない実装にできます。

```typescript prettier:false
abstract registerAuthMiddleware(): void
```

### `registerRoute()` {/* #registerroute */}

フレームワークに単一のルートを登録します。

```typescript prettier:false
abstract registerRoute(
  app: TApp,
  route: ServerRoute,
  options: { prefix?: string }
): Promise<void>
```

### `getParams()` {/* #getparams */}

リクエストからパラメーターを抽出します。

```typescript prettier:false
abstract getParams(
  route: ServerRoute,
  request: TRequest
): Promise<{
  urlParams: Record<string, string>;
  queryParams: Record<string, string>;
  body: unknown;
}>
```

### `sendResponse()` {/* #sendresponse */}

ルートの種類に応じてレスポンスを送信します。

```typescript prettier:false
abstract sendResponse(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

### `stream()` {/* #stream */}

ストリーミングレスポンスを処理します。

```typescript prettier:false
abstract stream(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

## インスタンスメソッド {/* #instance-methods */}

### `init()` {/* #init */}

すべてのミドルウェアとルートを登録してサーバーを初期化します。

```typescript prettier:false
async init(): Promise<void>
```

次の順序で呼び出します。

1. `registerContextMiddleware()`
1. `registerAuthMiddleware()`
1. `registerRoutes()`

### `registerRoutes()` {/* #registerroutes */}

すべての Mastra ルートを登録します。

```typescript prettier:false
async registerRoutes(): Promise<void>
```

### `getApp()` {/* #getapp */}

フレームワークのアプリインスタンスを取得します。

```typescript prettier:false
getApp<T = TApp>(): T
```

### `parsePathParams()` {/* #parsepathparams */}

ルートの Zod スキーマを使用してパスパラメーターを検証します。

```typescript prettier:false
async parsePathParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseQueryParams()` {/* #parsequeryparams */}

ルートの Zod スキーマを使用してクエリパラメーターを検証します。

```typescript prettier:false
async parseQueryParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseBody()` {/* #parsebody */}

ルートの Zod スキーマを使用してリクエストボディを検証します。

```typescript prettier:false
async parseBody(
  route: ServerRoute,
  body: unknown
): Promise<unknown>
```

### `registerOpenAPIRoute()` {/* #registeropenapiroute */}

OpenAPI 仕様を配信するエンドポイントを登録します。

```typescript prettier:false
async registerOpenAPIRoute(
  app: TApp,
  config: OpenAPIConfig,
  options: { prefix?: string }
): Promise<void>
```

### MCPOptions {/* #mcpoptions */}

```typescript
interface MCPOptions {
  serverless?: boolean
  sessionIdGenerator?: () => string
}
```

| プロパティ | 説明 |
| - | - |
| `serverless` | `true` の場合、MCP はセッション管理を行わないステートレスモードで実行されます。Cloudflare Workers や Vercel Edge などのサーバーレス環境で使用します。 |
| `sessionIdGenerator` | セッション ID を生成するカスタム関数。 |

  registerContextMiddleware(): void {
    this.app.use('*', (req, res, next) => {
      res.locals.mastra = this.mastra
      next()
    })
  }

  registerAuthMiddleware(): void {
    const auth = this.mastra.getServer()?.auth
    if (!auth) return

  }

    return response.json(result)
  }

}
