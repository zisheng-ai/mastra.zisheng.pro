# AgentFSFilesystem

[AgentFS](https://github.com/nichochar/agentfs) SDK を介して、ファイルを Turso/SQLite データベースに保存します。ファイルはセッションをまたいでローカル SQLite データベースに保持されるため、外部クラウドサービスなしで Agent に永続ストレージを提供できます。インターフェースの詳細は、[WorkspaceFilesystem インターフェース](/reference/workspace/filesystem)を参照してください。

## インストール {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## 使用方法 {/* #usage */}

Workspace に `AgentFSFilesystem` を追加して Agent に割り当てます。`AgentFSFilesystem` クラスのインスタンス化時には、`agentId`、`path`、`agent` のいずれか1つ以上を指定する必要があります。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### データベースパスを明示的に指定する {/* #using-an-explicit-database-path */}

デフォルトでは、データベースは `.agentfs` ディレクトリ内に `agentId` をファイル名として保存されます。カスタムのデータベースパスも指定できます。

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### 事前に開いた AgentFS インスタンスを使用する {/* #using-a-pre-opened-agentfs-instance */}

AgentFS のライフサイクルを自分で管理する場合は、次のように設定します。

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
