# VercelSandbox

[Vercel Sandbox](https://vercel.com/docs/vercel-sandbox) 内でコマンドを実行します。これは Amazon Linux 2023 を実行する一時的な [Firecracker](https://firecracker-microvm.github.io/) MicroVM です。セッション内で永続化される Filesystem、`sudo` アクセス、公開ポート、バックグラウンドプロセスを提供します。インターフェースの詳細は、[WorkspaceSandbox インターフェース](/reference/workspace/sandbox)を参照してください。

:::note

これは、ステートレスな Vercel サーバーレス **Function** としてコマンドを実行する [`VercelServerlessSandbox`](/reference/workspace/vercel-serverless) とは異なります。`VercelSandbox` は、永続的な Filesystem と長時間稼働するプロセスを備えた完全な Linux MicroVM を実行します。

:::

## インストール

```bash npm2yarn
npm install @mastra/vercel
```

## 認証

明示的な認証情報を指定しない場合、`@vercel/sandbox` SDK は Vercel OIDC トークンを自動的に使用します。`token`、`teamId`、`projectId` のいずれかを指定する場合は、3つすべてを指定してください。

## 使用方法

Workspace に `VercelSandbox` を追加して Agent に割り当てます。

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { VercelSandbox } from '@mastra/vercel'

const workspace = new Workspace({
  sandbox: new VercelSandbox({
    runtime: 'node24',
    timeout: 600_000,
  }),
})

const agent = new Agent({
  id: 'code-agent',
  name: 'Code Agent',
  instructions: 'You are a coding assistant working in this workspace.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  workspace,
})

const response = await agent.generate('Print "Hello, world!" and show the Node.js version.')

console.log(response.text)
```

### リソースと公開ポート

vCPU（1 vCPU あたり 2048 MB のメモリ）を割り当て、Sandbox 内で動作するネットワークサービスへアクセスするためのポートを公開します。

```typescript
const sandbox = new VercelSandbox({
  runtime: 'node24',
  resources: { vcpus: 4 },
  ports: [3000],
})

const workspace = new Workspace({ sandbox })
await sandbox.start()

// The public HTTPS domain for an exposed port is available via getInfo()
const { metadata } = sandbox.getInfo()
console.log(metadata?.domains) // { 3000: 'https://....vercel.run' }
```

### 出力のストリーミング

`onStdout` と `onStderr` コールバックを介して、コマンド出力をリアルタイムでストリーミングします。

```typescript
await sandbox.executeCommand('sh', ['-c', 'for i in 1 2 3; do echo "line $i"; sleep 1; done'], {
  onStdout: chunk => process.stdout.write(chunk),
  onStderr: chunk => process.stderr.write(chunk),
})
```

どちらのコールバックも任意で、個別に使用できます。

## バックグラウンドプロセス

`VercelSandbox` には、バックグラウンドプロセスを起動・管理するプロセスマネージャーが含まれます。起動した各プロセスは MicroVM 内でデタッチ済みコマンドとして動作し、出力はコマンドログを介してストリーミングされます。

```typescript
const sandbox = new VercelSandbox({ runtime: 'node24', ports: [3000] })
await sandbox.start()

const handle = await sandbox.processes.spawn('node server.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

console.log(handle.stdout)
await handle.kill()
```

完全な API は、[`SandboxProcessManager` リファレンス](/reference/workspace/process-manager)を参照してください。

:::note

Vercel Sandbox SDK は実行中のコマンドに stdin チャネルを公開しないため、`handle.sendStdin()` はエラーをスローします。この Provider は Filesystem のマウント（FUSE）にも対応していません。

:::

## 制限

- 最大32 vCPU。1 vCPU あたり 2048 MB のメモリ。
- 公開ポートは最大15個。
- Filesystem は一時的です。セッション内でのみ維持され、Sandbox の停止時に失われます。
- 最大実行時間はプランによって異なり（Hobby は45分、Pro と Enterprise は最大24時間）、デフォルトは5分です。

現在の制限と料金は、[Vercel Sandbox ドキュメント](https://vercel.com/docs/vercel-sandbox)を参照してください。
