# mountAgentControllerOnMastra()

:::experimental

`@mastra/code-sdk` パッケージは実験的機能であり、マイナーバージョンで破壊的変更が行われる可能性があります。

:::

`mountAgentControllerOnMastra()` 関数は、Mastra Code Agent Controller（[`mastracode`](https://www.npmjs.com/package/mastracode) CLI の基盤となる Coding Agent で、モード、Tool、Memory、スレッド管理を備えています）を構築し、サーバーが所有する [Mastra](/reference/core/mastra-class) インスタンスに登録します。Mastra Code Agent を独自の UI（Web アプリ、エディター、Bot）から利用できるようにするために使用します。各クライアントは、返された [`AgentController`](/reference/agent-controller/agent-controller-class) を通じて、独立したセッションを作成または再開します。

（デプロイ可能なエントリーファイル内などで）`Mastra` インスタンスを自分で構築するには、同じパッケージの `prepareAgentControllerMount()` を使用します。この関数はコンストラクター引数と `finalize()` コールバックを返します。

## 使用例

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

すでに他のプリミティブをホストしている Mastra インスタンスに Controller をマウントするには、既存の `mastra` を渡します。

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
