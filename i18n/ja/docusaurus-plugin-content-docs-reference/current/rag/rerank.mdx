# rerank()

`rerank()` 関数は、意味的関連性、ベクトル類似度、位置ベースのスコアリングを組み合わせ、ベクトル検索結果に高度な再ランキング機能を提供します。

```typescript
function rerank(
  results: QueryResult[],
  query: string,
  modelConfig: ModelConfig,
  options?: RerankerFunctionOptions,
): Promise<RerankResult[]>
```

## 使用例 {/* #usage-example */}

```typescript
import { rerank } from '@mastra/rag'

const model = '__GATEWAY_OPENAI_MODEL__'

const rerankedResults = await rerank(vectorSearchResults, 'How do I deploy to production?', model, {
  weights: {
    semantic: 0.5,
    vector: 0.3,
    position: 0.2,
  },
  topK: 3,
})
```

rerank 関数は、Vercel AI SDK の任意の LanguageModel を受け取ります。Cohere モデル `rerank-v3.5` を使用する場合は、Cohere の再ランキング機能が自動的に使用されます。

:::note

再ランキング時に意味スコアリングを正しく機能させるには、各結果の `metadata.text` フィールドにテキストコンテンツを含める必要があります。

:::
