# Cloudflare

Mastra の CloudflareVoice クラスは、Cloudflare Workers AI を使用した Text-to-Speech 機能を提供します。この Provider は、エッジコンピューティング環境に適した、効率的で低レイテンシーの音声合成に特化しています。

## 使用例

```typescript
import { CloudflareVoice } from '@mastra/voice-cloudflare'

// Initialize with configuration
const voice = new CloudflareVoice({
  speechModel: {
    name: '@cf/meta/m2m100-1.2b',
    apiKey: 'your-cloudflare-api-token',
    accountId: 'your-cloudflare-account-id',
  },
  speaker: 'en-US-1', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  speaker: 'en-US-2', // Override default voice
})

// Get available voices
const speakers = await voice.getSpeakers()
console.log(speakers)
```

## 注意事項

- API トークンは、コンストラクターオプションまたは環境変数（CLOUDFLARE\_API\_TOKEN と CLOUDFLARE\_ACCOUNT\_ID）で指定できます
- Cloudflare Workers AI は、低レイテンシーのエッジコンピューティング向けに最適化されています
- この Provider は Text-to-Speech（TTS）機能だけをサポートし、Speech-to-Text（STT）はサポートしません
- このサービスは、ほかの Cloudflare Workers 製品と適切に統合できます
- 本番環境で使用する場合は、Cloudflare アカウントに適切な Workers AI サブスクリプションがあることを確認してください
- 一部の Provider と比べると Voice オプションは限定的ですが、エッジで優れたパフォーマンスを発揮します
