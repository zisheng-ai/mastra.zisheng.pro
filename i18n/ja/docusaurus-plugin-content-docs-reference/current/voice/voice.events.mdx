# Voice イベント

Voice Provider は、リアルタイム Voice 対話中にイベントを送出します。これらのイベントは [voice.on()](./voice.on) メソッドでリッスンでき、対話型 Voice アプリケーションの構築で特に重要です。

## 注意事項 {/* #notes */}

- すべての Voice Provider がすべてのイベントをサポートするわけではありません
- 正確なペイロード構造は Provider によって異なる場合があります
- 非リアルタイム Provider では、これらのイベントのほとんどは送出されません
- イベントは、会話状態に応答する対話型 UI の構築に役立ちます
- 不要になったイベントリスナーを削除するには、[voice.off()](./voice.off) メソッドの使用を検討してください
