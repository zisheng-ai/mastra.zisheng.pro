# CompositeVoice {/* #compositevoice */}

CompositeVoice クラスを使用すると、Text-to-Speech と Speech-to-Text の操作に異なる Voice Provider を組み合わせられます。たとえば Speech-to-Text には OpenAI、Text-to-Speech には PlayAI を使用するなど、操作ごとに最適な Provider を使用したい場合に特に役立ちます。

CompositeVoice は、Mastra Voice Provider と AI SDK Model Provider の両方をサポートします。

## メソッド {/* #methods */}

### `speak()` {/* #speak */}

設定された発話 Provider を使用してテキストを音声に変換します。

注意事項：

- 発話 Provider が設定されていない場合、このメソッドはエラーをスローします
- オプションは設定された発話 Provider にそのまま渡されます
- 音声データのストリームを返します

### `getSpeakers()` {/* #getspeakers */}

発話 Provider から使用可能な Voice の一覧を返します。各要素には次の値が含まれます。

<PropertiesTable
  content={[
  {
    name: 'voiceId',
    type: 'string',
    description: 'Voice の一意な識別子',
    isOptional: false,
  },
  {
    name: 'key',
    type: 'value',
    description: 'Provider によって異なる追加の Voice プロパティ（例：名前、言語）',
    isOptional: true,
  },
]}
/>

注意事項：

- 発話 Provider の Voice だけを返します
- 発話 Provider が設定されていない場合は空の配列を返します
- 各 Voice オブジェクトには少なくとも voiceId プロパティがあります
- 追加の Voice プロパティは発話 Provider によって異なります

## 使用例 {/* #usage-examples */}

### Mastra Voice Provider の使用 {/* #using-mastra-voice-providers */}

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIVoice } from '@mastra/voice-openai'
import { PlayAIVoice } from '@mastra/voice-playai'

// Create voice providers
const openai = new OpenAIVoice()
const playai = new PlayAIVoice()

// Use OpenAI for listening (speech-to-text) and PlayAI for speaking (text-to-speech)
const voice = new CompositeVoice({
  input: openai,
  output: playai,
})

// Convert speech to text using OpenAI
const text = await voice.listen(audioStream)

// Convert text to speech using PlayAI
const audio = await voice.speak('Hello, world!')
```

### AI SDK Model Provider の使用 {/* #using-ai-sdk-model-providers */}

AI SDK の文字起こしモデルと音声モデルを CompositeVoice に直接渡せます。

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { openai } from '@ai-sdk/openai'
import { elevenlabs } from '@ai-sdk/elevenlabs'

// Use AI SDK models directly - they will be auto-wrapped
const voice = new CompositeVoice({
  input: openai.transcription('whisper-1'), // AI SDK transcription
  output: elevenlabs.speech('eleven_turbo_v2'), // AI SDK speech
})

// Works the same way as with Mastra providers
const text = await voice.listen(audioStream)
const audio = await voice.speak('Hello from AI SDK!')
```

### 組み合わせて使用 {/* #mix-and-match */}

Mastra Provider と AI SDK モデルを組み合わせられます。

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { PlayAIVoice } from '@mastra/voice-playai'
import { groq } from '@ai-sdk/groq'

const voice = new CompositeVoice({
  input: groq.transcription('whisper-large-v3'), // AI SDK for STT
  output: new PlayAIVoice(), // Mastra for TTS
})
```
