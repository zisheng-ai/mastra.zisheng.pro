# voice.updateConfig()

`updateConfig()` メソッドを使用すると、実行時に Voice Provider の設定を更新できます。新しいインスタンスを作成せずに、Voice 設定、API キー、その他の Provider 固有のオプションを変更する際に役立ちます。

## 使用例 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

// Initialize a real-time voice provider
const voice = new OpenAIRealtimeVoice({
  realtimeConfig: {
    model: 'gpt-5.1-realtime',
    apiKey: process.env.OPENAI_API_KEY,
  },
  speaker: 'alloy',
})

// Connect to the real-time service
await voice.connect()

// Later, update the configuration
voice.updateConfig({
  voice: 'nova', // Change the default voice
  turn_detection: {
    type: 'server_vad',
    threshold: 0.5,
    silence_duration_ms: 1000,
  },
})

// The next speak() call will use the new configuration
await voice.speak('Hello with my new voice!')
```

## 注意事項 {/* #notes */}

- Provider がこのメソッドをサポートしない場合、デフォルト実装は警告を記録します
- 通常、設定の更新は進行中の操作ではなく、後続の操作に適用されます
- コンストラクターで設定できるすべてのプロパティを実行時に更新できるわけではありません
- 具体的な動作は Voice Provider の実装によって異なります
- リアルタイム Voice Provider では、設定変更によってサービスへの再接続が必要になる場合があります
