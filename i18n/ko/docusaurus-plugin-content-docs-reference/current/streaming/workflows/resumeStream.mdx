# 실행.이력스트림()

그만큼`.resumeStream()`메서드는 새 데이터로 일시 중단된 Workflow 실행을 재개하므로 특정 단계부터 실행을 계속하고 이벤트 스트림을 관찰할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

const result = await stream.result

if (result!.status === 'suspended') {
  const resumedStream = await run.resumeStream({
    resumeData: {
      value: 'resume data',
    },
  })
}
```

## 이벤트 스트리밍 {/* #stream-events */}

스트림은 Workflow 실행 중에 이벤트 유형을 내보냅니다. 각 이벤트에는`type` field and a `payload` containing relevant data:

* **`workflow-start`**: Workflow 실행이 시작됩니다.
* **`workflow-step-start`**: 단계가 실행을 시작합니다.
* **`workflow-step-output`**: 단계의 사용자 정의 출력
* **`workflow-step-result`**: 단계가 결과로 완료됩니다.
* **`workflow-finish`**: 사용 통계와 함께 Workflow 실행이 완료됩니다. 성공적인 실행을 위해서는`payload.finalWorkflowResult` carries the workflow's final result
