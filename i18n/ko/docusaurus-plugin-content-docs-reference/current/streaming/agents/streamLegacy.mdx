# Agent.streamLegacy() (레거시)

:::warning

**사용 중단됨**: 이 메서드는 사용 중단되었으며 V1 Model에서만 작동합니다. V2 Model의 경우 새로운 [`.stream()`](./stream) 메서드를 대신 사용하세요. 업그레이드에 대한 자세한 내용은 [마이그레이션 가이드](/guides/migrations/vnext-to-standard-apis)를 참조하세요.
:::

`.streamLegacy()` 메서드는 Agent 스트리밍 API의 레거시 버전으로, V1 Model Agent의 응답을 실시간으로 스트리밍하는 데 사용됩니다. 이 메서드는 메시지와 선택적 스트리밍 옵션을 받습니다.
## 사용예 {/* #usage-example */}

```typescript
await agent.streamLegacy('message for agent')
```

## 새로운 API로 마이그레이션 {/* #migration-to-new-api */}

:::info

새로운 `.stream()` 메서드는 AI SDK v5+ 호환성, 향상된 구조화 출력 처리, 개선된 콜백 시스템을 비롯한 확장된 기능을 제공합니다. 자세한 마이그레이션 지침은 [마이그레이션 가이드](/guides/migrations/vnext-to-standard-apis)를 참조하세요.
:::

### 빠른 마이그레이션 예 {/* #quick-migration-example */}

#### 이전(레거시) {/* #before-legacy */}

```typescript
const result = await agent.streamLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```

#### 이후(새 API) {/* #after-new-api */}

```typescript
const result = await agent.stream('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```
