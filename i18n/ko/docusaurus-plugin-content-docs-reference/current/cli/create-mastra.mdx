# 창조 마스트라

독립형 Mastra 프로젝트를 만듭니다. 기본적으로`create-mastra`기본 스타터를 설치하고 선택한 Model 공급자에 맞게 구성합니다.

```bash npm2yarn
npx create-mastra@latest
```

## 생성 모드 {/* #creation-modes */}

### 기본 스타터 {/* #default-starter */}

기본 스타터는 작업 공간 Tool, Memory, 작업 추적, 웹 액세스, 반복 일정, 저장 및 Observability을 갖춘 Agent 하네스를 생성합니다. OpenAI, Anthropic, Gemini 또는 xAI를 Model 공급자로 선택하세요.

메시지 없이 프로젝트를 생성하려면 프로젝트 이름과 공급자를 모두 제공하세요. 이 예에서는 Anthropic을 사용합니다. 너도 합격할 수 있어`openai`, `google`, or `xai`:

```bash npm2yarn
npx create-mastra@latest my-mastra-project --llm anthropic
```

생략`--llm` to select the provider and optionally enter its API key interactively. The interactive setup also offers to connect your project to the Mastra platform. If enabled, the command opens the browser authentication flow and creates a platform project with the same name as the local project. It then writes `MASTRA_PLATFORM_ACCESS_TOKEN` and `MASTRA_PROJECT_ID` to `.env`.

### 주형 {/* #template */}

템플릿 슬러그 또는 공개 GitHub URL을 사용하세요.

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template agent-harness
```

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template https://github.com/mastra-ai/template-agent-harness
```

대화형으로 템플릿을 선택하려면 템플릿 값을 비워 두세요.

```bash npm2yarn
npx create-mastra@latest my-mastra-project --template
```

템플릿 작성자는 자신의 종속성, Model, 환경 변수 및 소스 코드를 소유합니다.`create-mastra` doesn't apply `--llm` or `--llm-api-key`.

### 빈 비계 {/* #empty-scaffold */}

사용`--empty` to create a provider-free project without agents, examples, model SDKs, or environment files:

```bash npm2yarn
npx create-mastra@latest my-empty-project --empty
```

## 자동 설정 {/* #automatic-setup */}

종속성을 설치한 후 명령은 다음과 같습니다.

1. 지원되는 코딩 도우미를 감지합니다.`PATH` and installs Mastra skills. If none are detected, it installs universal skills.
2. 현재 디렉터리와 생성된 프로젝트가 Git 리포지토리 내에 아직 없는 경우 초기 Git 커밋을 만듭니다.

사용`--no-skills` or `--no-git` to skip these steps. Skills and Git setup failures produce warnings but don't remove a successfully created project.

## 충돌 및 검증 {/* #conflicts-and-validation */}

* `--empty`그리고`--template` can't be used together.
* `--llm`그리고`--llm-api-key` are only valid for the default starter project.
* 프로젝트 이름은 안전한 소문자 단일 디렉터리 이름이어야 하며 대상이 이미 존재하지 않아야 합니다.

템플릿을 가져오거나 파일을 생성하기 전에 잘못된 입력이 거부됩니다.

## 원격 측정 {/* #telemetry */}

Mastra는 운영 체제, Mastra 버전, Node.js 버전 등 익명의 CLI 사용 정보를 수집합니다. 다음을 검토할 수 있습니다.[analytics source](https://github.com/mastra-ai/mastra/blob/main/packages/cli/src/analytics/index.ts).

세트`MASTRA_TELEMETRY_DISABLED=1` to opt out:

```bash
MASTRA_TELEMETRY_DISABLED=1 npx create-mastra@latest my-project --empty
```
