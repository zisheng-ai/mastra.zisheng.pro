# 개요

이 참조 자료에서는 기존 Mastra 템플릿을 사용하고 자신만의 템플릿을 만드는 방법을 설명합니다. 또한 커뮤니티 생태계에 템플릿을 제공하는 방법도 다룹니다.

Mastra 템플릿은 특정 사용 사례와 패턴을 보여주는 사전 구축된 프로젝트 구조입니다. 그들은 다음을 제공합니다:

* **실제 사례**: 완벽하고 기능적인 Mastra 애플리케이션
* **모범 사례**: 적절한 프로젝트 구조 및 코딩 규칙
* **교육 자료**: 실제 구현을 통해 마스트라 패턴을 학습합니다.
* **빠른 시작**: 처음부터 구축하는 것보다 부트스트랩 프로젝트가 더 빠릅니다.

## 사용 가능한 템플릿 {/* #available-templates */}

다음 템플릿은 게이트웨이 우선 Mastra 애플리케이션을 보여줍니다.

* `template-docs-expert`: 게이트웨이 웹 검색, 인용, 기억 및 구조화된 응답을 통해 문서 관련 질문에 답변합니다.
* `template-browser-agent`: AgentBrowser를 사용하여 웹 페이지를 찾아보고 검사하고 상호 작용합니다.
* `template-meeting-notes`: Zoom 성적표 또는 업로드된 성적표를 결정 및 작업 항목이 포함된 구조화된 노트로 전환합니다.
* `template-company-knowledge`: 선형 및 개념 콘텐츠를 pgVector로 인덱싱하고 내부 지식 질문에 답변합니다.
* `template-claw-assistant`: 파일시스템, 샌드박스, 브라우저, 웹 검색 Tool를 갖춘 작업공간을 운영합니다.

## 템플릿 사용 {/* #using-templates */}

### 설치 {/* #installation */}

다음을 사용하여 템플릿을 설치합니다.`create-mastra` command:

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```

그러면 완전한 프로젝트가 생성되고 해당 종속성이 설치됩니다. 템플릿 작성자는 Model, 공급자 종속성, 환경 변수 및 소스 코드를 제어합니다.

### 설정 프로세스 {/* #setup-process */}

설치 후:

1. **프로젝트 디렉토리로 이동**:

   ```bash
   cd your-project-name
   ```

2. **환경 변수 구성**:

   ```bash
   cp .env.example .env
   ```

   템플릿의 README에 설명된 필수 API 키로 `.env`를 편집하세요.
3. **개발 서버 시작**:

   ```sh npm2yarn
   npm run dev
   ```

### 템플릿 구조 {/* #template-structure */}

모든 템플릿은 다음과 같은 표준화된 구조를 따릅니다.

```
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
