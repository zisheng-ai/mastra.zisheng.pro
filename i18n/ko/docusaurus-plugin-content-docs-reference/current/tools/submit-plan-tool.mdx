# submitPlanTool

사용자 검토를 위해 구현 계획을 제출하는 기본 제공 Agent 독립적 Tool입니다. Agent는 마크다운 파일에 계획을 작성하고 파일 경로를 이 Tool에 전달합니다. Tool는 사용자가 계획을 승인하거나 거부할 때까지 실행을 일시 중단합니다.

Tool는 기본을 통해 일시 중지됩니다.[tool suspension](/docs/agents/agent-approval#runtime-suspension-with-suspend) primitive: it calls `suspend({ path })`, 이는 Agent가`tool-call-suspended`이벤트. 호스트는 계획 파일을 읽고 이를 사용자에게 제시합니다. 그런 다음 승인 또는 거부를 통해 재개됩니다.

Agent 실행 외부에서 실행되는 경우(아니요`suspend` available), the tool returns a readable fallback string containing the file path.

## 사용예 {/* #usage-example */}

추가하다`submitPlanTool` to an agent's toolset:

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

정지 처리 및 재개:

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

피드백을 통해 거부하려면 다음 안내를 따르세요.

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## 승인 행동 {/* #approval-behavior */}

* **승인됨:**&#xB3C4;구가 반환됩니다.`"Plan approved. Proceed with implementation following the approved plan."` to the model.
* **피드백으로 거부됨:**&#xB3C4;구는 피드백을 반환하고 Model에 계획을 수정하고 다시 제출하도록 요청합니다.
* **피드백 없이 거부됨:**&#xC774; Tool는 수정하기 전에 사용자의 다음 메시지를 기다리도록 Model에 지시합니다.

내부에서 사용하는 경우[AgentController](/docs/harness/agent-controller), plan approval switches from the current mode to the mode configured by `transitionsTo`. When no `transitionsTo` is configured, the controller switches to its resolved default mode. See [Modes](/docs/harness/agent-controller#switch-modes-and-models) for details.
