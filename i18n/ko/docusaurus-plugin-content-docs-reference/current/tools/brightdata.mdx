# 브라이트 데이터 Tool

그만큼`@mastra/brightdata`패키지는[브라이트 데이터 SDK](https://github.com/brightdata/bright-data-sdk-node)Mastra 호환 Tool로. 웹 검색 및 웹 가져오기를 위한 팩토리 기능을 노출합니다. 각 함수는 다음으로 생성된 Tool을 반환합니다.[`createTool()`](./create-tool)여기에는 전체 Zod 입력/출력 스키마가 포함됩니다.

검색 Tool은 Bright Data의 [SERP API](https://brightdata.com/products/serp-api)를 기반으로 하며, 가져오기 Tool은 [Web Unlocker](https://brightdata.com/products/web-unlocker)를 기반으로 합니다. 둘 다 봇 탐지와 CAPTCHA를 우회합니다.
## 설치 {/* #installation */}

```sh npm2yarn
npm install @mastra/brightdata zod
```

## 빠른 시작 {/* #quick-start */}

공유 구성으로 두 Tool을 모두 가져오려면 `createBrightDataTools()`를 사용하세요.
```typescript title="src/mastra/tools/index.ts"
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()
// Or pass an explicit API key:
// const { webSearch, webFetch } = createBrightDataTools({ apiKey: 'brd-...' })
```

각 Tool을 개별적으로 만들 수도 있습니다.

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataSearchTool, createBrightDataFetchTool } from '@mastra/brightdata'

const searchTool = createBrightDataSearchTool()
const fetchTool = createBrightDataFetchTool({ apiKey: 'brd-...' })
```

기본적으로 모든 Tool은 환경에서 `BRIGHTDATA_API_TOKEN`을 읽습니다. 명시적으로 `{ apiKey }`를 전달하여 재정의할 수 있습니다.
## 구성 {/* #configuration */}

모든 팩토리 함수는 `@brightdata/sdk`의 `BrightDataClientOptions`를 허용합니다.

## `createBrightDataTools()` {/* #createbrightdatatools */}

공유 구성이 있는 두 Tool을 모두 포함하는 개체를 반환합니다.

```typescript
import { createBrightDataTools } from '@mastra/brightdata'

const tools = createBrightDataTools({ apiKey: 'brd-...' })
// tools.webSearch, tools.webFetch
```

**보고:** `{ webSearch, webFetch }`

## Agent 예시 {/* #agent-example */}

다음 예는 검색과 가져오기를 결합하는 연구 Agent를 보여줍니다.

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the search tool to find relevant pages, then use the fetch tool to read full Markdown content from the best results.',
  tools: {
    webSearch,
    webFetch,
  },
})
```
