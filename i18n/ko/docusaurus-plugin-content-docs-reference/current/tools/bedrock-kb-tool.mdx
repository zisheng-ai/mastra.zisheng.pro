# createBedrockKBTool()

그만큼`createBedrockKBTool()`함수는 Amazon Bedrock Knowledge Base에서 관련 문서를 검색하는 Tool를 생성합니다. 표준 검색으로 자동 대체하여 관리형 검색 구성과 Agent 검색(쿼리 분해 및 관리형 재순위 지정)을 모두 지원합니다.

## 사용예 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### Agent와 함께 {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

| 필드 | 유형 | 설명 |

## 검색 모드 {/* #retrieval-modes */}

### Agent 검색(기본값) {/* #agentic-retrieval-default */}

언제`useAgenticRetrieval` is `true` (default), the tool uses `AgenticRetrieveStreamCommand` which:

* 복잡한 쿼리를 하위 쿼리로 분해합니다.
* 여러 패스에 걸쳐 검색
* 더 나은 결과를 위해 관리형 재순위 적용

Agent 검색이 실패하면(예: 이전 SDK, 권한) 자동으로 표준 관리형 검색으로 대체됩니다.

### 표준 관리 검색 {/* #standard-managed-retrieval */}

언제`useAgenticRetrieval` is `false`, the tool uses `RetrieveCommand` with `managedSearchConfiguration` for direct single-pass retrieval.

## 사용자 기반 접근 제어 {/* #user-based-access-control */}

세트`userId` in the Mastra request context to forward it as the Bedrock `userContext.userId`. This supports knowledge bases that enforce document-level access control. The request context value overrides the default `userId` configured on the tool.

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```
