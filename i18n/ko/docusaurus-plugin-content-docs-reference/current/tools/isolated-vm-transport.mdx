# 격리된Vm코드모드전송

:::실험적

이 기능은 베타 버전입니다. API가 안정될 때까지 주요 버전 변경 없이 주요 변경 사항이 발생할 수 있습니다.

:::

그만큼`IsolatedVmCodeModeTransport` class runs [Code mode](/docs/agents/code-mode) programs in an in-process V8 isolate, backed by [격리된 VM](https://github.com/laverdet/isolated-vm). 격리는 실행 경계이므로 작업 공간 샌드박스가 필요하지 않습니다. 프로그램에는 파일 시스템, 네트워크, 프로세스 또는 모듈 액세스가 없습니다. 그 유일한 능력은`external_*`호스트의 실제 Tool를 다시 호출하는 함수입니다.

기본값과 비교하면`StdioCodeModeTransport`, this transport spawns no processes and writes no temp files, which makes it a good fit for serverless and multi-tenant hosts where OS-level sandboxing isn't available.

## 설치 {/* #installation */}

```bash npm2yarn
npm install @mastra/isolated-vm
```

`isolated-vm`기본 애드온입니다. 일반적인 플랫폼에 대해 사전 구축된 바이너리를 제공하므로 설치에는 일반적으로 추가 설정이 필요하지 않습니다. C++ 툴체인은 일치하는 사전 빌드가 없는 플랫폼에서만 필요하며, 소스에서 컴파일하도록 대체됩니다.

Node.js 20 이상에서는 호스트 프로세스를 다음으로 시작해야 합니다.`--no-node-snapshot` flag, otherwise creating an isolate crashes the process. The constructor throws an error when the flag is missing. Pass the flag when starting your server, or set it through `NODE_OPTIONS`:

```bash
NODE_OPTIONS=--no-node-snapshot npm run dev
```

## 용법 {/* #usage */}

전송을 두 번째 인수로 전달합니다.`createCodeMode()`. No `sandbox` is needed:

```typescript
import { createCodeMode } from '@mastra/core/tools'
import { IsolatedVmCodeModeTransport } from '@mastra/isolated-vm'

const { tool, instructions } = createCodeMode(
  { tools: { getTopProducts, getProductRatings } },
  new IsolatedVmCodeModeTransport({ memoryLimitMb: 128 }),
)
```

## 작동 원리 {/* #how-it-works */}

각 실행은 자체 힙으로 새로운 격리를 생성합니다. TypeScript는 esbuild를 사용하여 호스트에서 제거된 다음 프로그램이 격리 내에서 평가됩니다. 모든`external_*` call crosses the isolate boundary as JSON strings in both directions, so no host object references leak into model-authored code. The allow-list, tool validation, request context, and tracing all run on the host, the same as with other transports.

그만큼`timeout` configured on `createCodeMode()` applies to both asynchronous hangs and synchronous infinite loops, and the isolate is disposed after every run.
