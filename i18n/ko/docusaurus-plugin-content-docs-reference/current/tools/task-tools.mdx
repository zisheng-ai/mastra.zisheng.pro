# 작업 Tool

Agent 실행을 위해 구조화된 작업 목록을 관리하는 4개의 기본 제공 Agent 독립적 Tool입니다. 작업 목록은 스레드 범위에 유지됩니다.`threadState`스토리지 도메인을 Agent에 투영하여[상태 신호](/docs/long-running-agents/signals)레인 그래서 살아남는다[관찰 기억](/docs/memory/observational-memory)잘림.

작업 추적에는 Memory를 지원하는 스레드(`threadId` + `resourceId`)가 필요합니다. Memory가 없으면 Tool이 작업 추적에 Agent Memory가 필요하다는 오류를 반환합니다.
권장 설정은 네 가지 Tool과 `TaskStateProcessor`를 하나의 등록으로 묶는 [`TaskSignalProvider`](/reference/signals/task-signal-provider)입니다. 개념 가이드는 [기본 제공 Tool](/docs/agents/using-tools#task-tracking)을 참조하세요.
## 사용예 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { Memory } from '@mastra/memory'
import { TaskSignalProvider } from '@mastra/core/signals'

const agent = new Agent({
  id: 'coder',
  name: 'Coder',
  instructions: 'Track your progress with the task tools.',
  model,
  memory: new Memory(),
  signals: [new TaskSignalProvider()],
})
```

또는 Tool을 직접 가져옵니다.

```typescript title="src/mastra/agents/index.ts"
import { taskWriteTool, taskUpdateTool, taskCompleteTool, taskCheckTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'coder',
  name: 'Coder',
  instructions: 'Track your progress with the task tools.',
  model,
  memory: new Memory(),
  tools: { taskWriteTool, taskUpdateTool, taskCompleteTool, taskCheckTool },
})
```

## `task_write` {/* #task_write */}

전체 작업 목록을 생성하거나 교체합니다. 각 호출은 이전 목록을 대체합니다.

### 산출 {/* #output */}

사람이 읽을 수 있는 `content` 요약, 할당된 ID가 포함된 전체 `tasks` 배열, `isError` 플래그가 있는 `TaskToolResult`를 반환합니다.
### 행동 {/* #behavior */}

* ID는 호출 내에서 고유해야 합니다. 명시적 ID가 중복되면 대체 ID를 생성합니다.
* 기존 목록을 다시 작성할 때 ID를 생략하면, 명확하게 하나만 일치하는 작업은 안정성을 위해 이전 ID를 재사용합니다.
* 한 번에 하나의 작업만 `in_progress` 상태일 수 있습니다. 여러 `in_progress` 작업을 제출하면 오류가 반환됩니다.
## `task_update` {/* #task_update */}

안정적인 ID로 하나의 작업을 업데이트합니다. 변경된 필드만 포함합니다.

### 입력 스키마 {/* #input-schema-1 */}

<PropertiesTable
  content={[
{
  name: 'id',
  type: 'string',
  description: '업데이트할 작업의 안정적인 식별자입니다.',
  isOptional: false,
},{
  name: 'content',
  type: 'string',
  description: '명령형으로 작성한 새로운 작업 설명입니다.',
  isOptional: true,
},{
  name: 'status',
  type: "'pending' | 'in_progress' | 'completed'",
  description: '새로운 작업 상태입니다.',
  isOptional: true,
},{
  name: 'activeForm',
  type: 'string',
  description: '새로운 현재진행형 표현입니다.',
  isOptional: true,
},
]}
/>
`content`, `status`, `activeForm` 중 하나 이상이 필요합니다.
### 행동 {/* #behavior-1 */}

* 업데이트로 작업을 `in_progress`로 설정하면, 다른 모든 `in_progress` 작업은 자동으로 `pending`으로 변경됩니다.
* ID를 찾을 수 없으면 사용 가능한 작업 ID가 포함된 오류를 반환합니다.

안정적인 ID로 하나의 작업을 완료된 것으로 표시합니다.
