# 난해함 Tool

그만큼`@mastra/perplexity`패키지는[혼란 검색 API](https://docs.perplexity.ai/docs/search/quickstart)Mastra 호환 Tool로 사용됩니다. 다음으로 생성된 Tool를 반환하는 팩토리 함수를 노출합니다.[`createTool()`](./create-tool)그리고 전체 Zod 입력/출력 스키마.

Perplexity 기반 채팅 완성 또는 Agent Workflow에는 Mastra에 내장된 [Perplexity Model Provider](/models/providers/perplexity) 또는 [Perplexity Agent Provider](/models/providers/perplexity-agent)를 사용하세요. 이들은 이 검색 Tool과 별개입니다.
## 설치 {/* #installation */}

Zod와 함께 패키지를 설치합니다.

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 사용예 {/* #usage-example */}

다음 예에서는 기본 구성으로 검색 Tool을 생성합니다. 기본적으로 Tool은 환경에서 `PERPLEXITY_API_KEY`를 읽고, 이 값이 없으면 `PPLX_API_KEY`를 사용합니다. 재정의하려면 `{ apiKey }`를 명시적으로 전달하세요.
```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

API 키를 명시적으로 전달하려면 다음 안내를 따르세요.

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 행동 양식 {/* #methods */}

### 공장 기능 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

제공된 구성을 공유하는 모든 Perplexity Tool가 포함된 개체를 반환합니다.

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

보고:`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

Perplexity Search API를 사용하여 웹을 검색하는 Tool를 만듭니다. 제목, URL, 스니펫 및 선택적 게시 날짜와 함께 순위가 매겨진 결과를 반환합니다.

Tool는 ID로 등록됩니다`perplexity-search`.

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent 예시 {/* #agent-example */}

다음 예에서는 응답하기 전에 새로운 웹 결과를 가져올 수 있도록 Agent에 검색 Tool를 등록합니다.

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 환경변수 {/* #environment-variables */}

| 변수 | 설명 |
| - | - |
|`PERPLEXITY_API_KEY` | Perplexity API 키입니다. 팩터리 함수에 `apiKey`를 전달하지 않았을 때 기본값으로 사용됩니다. |
| `PPLX_API_KEY` | `PERPLEXITY_API_KEY`가 설정되지 않았을 때 사용하는 대체 값입니다. |
