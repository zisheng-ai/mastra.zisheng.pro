# 생성코딩Agent()

`createCodingAgent()`코딩을 빌드합니다[`Agent`](/reference/agents/agent)코딩 Agent가 항상 필요로 하는 부분(로컬 작업 공간, 작업 목록 신호 제공자, 네트워크 재시도 오류 프로세서 및 목표 판단 Prompt)에 대한 이식 가능한 기본값이 있습니다. 공급만 가능`model`, `instructions`, 그리고`tools`작동하는 Agent를 얻거나 기본값을 무시합니다.

반환된 값은 표준입니다.`Agent`, so it works anywhere an `Agent` does: including as the agent passed to an [`AgentController`](/reference/agent-controller/agent-controller-class).

## 사용예 {/* #usage-example */}

Model, 지침 및 Tool를 전달합니다. 공장에서는 작업 공간, 작업 신호, 오류 프로세서 및 목표 Prompt를 채웁니다.

```typescript title="src/mastra/coding-agent.ts"
import { createCodingAgent } from '@mastra/core/coding-agent'

const agent = createCodingAgent({
  id: 'my-coding-agent',
  name: 'My Coding Agent',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  instructions: 'You are a helpful coding assistant.',
  tools: {},
})
```

## 기본값 {/* #defaults */}

공장에서는 해당 필드를 제공하지 않은 경우에만 기본값을 채웁니다. 호출자가 제공한 값은 항상 승리합니다.

| 필드 | 생략 시 기본값 |
| - | - |
|`workspace` | A [`Workspace`](/reference/workspace/workspace-class) backed by `LocalFilesystem` and `LocalSandbox` rooted at the base path. |
| `signals` | A single [`TaskSignalProvider`](/reference/signals/task-signal-provider). |
| `errorProcessors` | Unknown stream-error retries with specialized ECONNRESET and bad-request policies, plus `PrefillErrorHandler` and `ProviderHistoryCompat`. |
| `goal.prompt` | `DEFAULT_GOAL_JUDGE_PROMPT`(한 경우에만`goal`구성됨). |

### 작업공간 {/* #workspace */}

때`workspace` key is omitted, the factory builds a local workspace rooted at `basePath` (default `process.cwd()`):

```typescript
import { Workspace, LocalFilesystem, LocalSandbox } from '@mastra/core/workspace'

new Workspace({
  filesystem: new LocalFilesystem({ basePath }),
  sandbox: new LocalSandbox({ workingDirectory: basePath }),
})
```

옵트아웃하려면(예를 들어 작업공간이[`AgentController`](/reference/agent-controller/agent-controller-class) level), pass `workspace: undefined` explicitly:

```typescript
const agent = createCodingAgent({
  id: 'my-coding-agent',
  name: 'My Coding Agent',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  instructions: 'You are a helpful coding assistant.',
  tools: {},
  workspace: undefined, // opt out of the default workspace
})
```

### 오류 프로세서 {/* #error-processors */}

기본값[`StreamErrorRetryProcessor`](/reference/processors/stream-error-retry-processor) applies these retry policies:

* 공급자 메타데이터와 일치하지 않는 알 수 없는 오류 또는 특정 일치자가 다음을 사용하여 최대 두 번 재시도합니다.`3000ms` delay. Known authorization failures surface immediately.
* 네트워크 재설정(`ECONNRESET` / `socket hang up`) retry up to twice with exponential backoff (`1000ms * 2^retryCount`, capped at `30000ms`).
* 잘못된 요청 오류가 발생한 후 한 번 다시 시도`2000ms`.

특정 네트워크 재설정 및 잘못된 요청 정책은 알 수 없는 오류 정책보다 우선합니다. 통과`errorProcessors` replaces the default processor stack. `PrefillErrorHandler` and `ProviderHistoryCompat` are also included for provider compatibility.
