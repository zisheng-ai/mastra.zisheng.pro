# GoogleCloudPubSub

`GoogleCloudPubSub`는[`PubSub`](/reference/pubsub/base)구현 지원[Google Cloud 게시/구독](https://cloud.google.com/pubsub/docs). 순차적 전달 및 메시지 확인과 함께 Google Cloud 주제 및 구독을 사용하여 프로세스와 호스트 전반에 이벤트를 전달합니다.

Google Cloud의 분산 배포에 사용하세요. 단일 프로세스 전달의 경우 다음을 사용하세요.[`EventEmitterPubSub`](/reference/pubsub/event-emitter). For Redis, use [`RedisStreamsPubSub`](/reference/pubsub/redis-streams).

각 주제는 Google Cloud 주제에 매핑됩니다. 그룹 구독은 구독을 공유하므로 회원은 이벤트를 위해 경쟁합니다. 그룹이 없는 구독은 인스턴스별 구독을 생성하므로 모든 인스턴스가 모든 이벤트를 수신합니다.

## 설치 {/* #installation */}

```bash npm2yarn
npm install @mastra/google-cloud-pubsub
```

## 사용예 {/* #usage-example */}

프로젝트 ID와 같은 Google Cloud 클라이언트 구성을 전달합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { GoogleCloudPubSub } from '@mastra/google-cloud-pubsub'

export const mastra = new Mastra({
  pubsub: new GoogleCloudPubSub({
    projectId: 'my-project',
  }),
})
```

## 행동 양식 {/* #methods */}

`GoogleCloudPubSub`구현[`PubSub`](/reference/pubsub/base) contract. The methods below are specific to this implementation.

### `init(topicName, group?)` {/* #inittopicname-group */}

주제와 구독이 아직 없는 경우 생성하고 구독을 반환합니다.`subscribe` calls this internally, so you rarely call it directly.

```typescript
await pubsub.init('workflow.events')
```

### `subscribe(topic, cb, options?)` {/* #subscribetopic-cb-options */}

주제를 구독합니다. 와 함께`options.group`, members of the group share a subscription and compete for events. Without a group, the instance receives every event through its own subscription.

```typescript
await pubsub.subscribe('workflow.events', (event, ack, nack) => {
  console.log(event)
})
```

### `flush()` {/* #flush */}

보류 중인 승인이 완료될 때까지 기다립니다.

```typescript
await pubsub.flush()
```

### `destroy(topicName)` {/* #destroytopicname */}

주제 이름에 대한 구독 및 주제를 제거합니다. 이를 사용하여 Google Cloud 리소스를 정리합니다.

```typescript
await pubsub.destroy('workflow.events')
```

## 승인 {/* #acknowledgment */}

전달된 각 이벤트에는 다음이 포함됩니다.`ack` and `nack` functions. Call `ack` after successful processing to remove the event from the subscription. When neither is called, Google Cloud redelivers the event after its acknowledgment deadline expires.
