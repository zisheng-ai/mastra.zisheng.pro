# 피노로거

Logger 인스턴스는 다음을 사용하여 생성됩니다.`new PinoLogger()`심각도 수준에서 이벤트를 기록하는 방법을 제공합니다.

## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

export const mastra = new Mastra({
  logger: new PinoLogger({
    name: 'Mastra',
    level: 'info',
  }),
})
```

## 로그 강화`mixin` {/* #log-enrichment-with-mixin */}

사용`mixin` when you want the same structured fields on every line (for correlation with the rest of your services):

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

function getTraceContext() {
  return { traceId: 'abc-123' }
}

export const mastra = new Mastra({
  logger: new PinoLogger({
    name: 'Mastra',
    level: 'info',
    mixin() {
      return getTraceContext()
    },
  }),
})
```

## 맞춤 수준 {/* #custom-levels */}

`customLevels`피노에게 전달됩니다.`PinoLogger` only exposes `debug`, `info`, `warn`, 그리고`error`; 추가 레벨 이름(예:`audit`), 서브클래싱하여 기본 Pino 인스턴스로 전달합니다.

```typescript title="src/mastra/logger.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

type AuditLevel = 'audit'

class MastraPinoWithAudit extends PinoLogger<AuditLevel> {
  audit(message: string, meta: Record<string, unknown> = {}) {
    this.logger.audit(meta, message)
  }
}

const logger = new MastraPinoWithAudit({
  name: 'Mastra',
  level: 'info',
  customLevels: { audit: 35 },
})

export const mastra = new Mastra({ logger })
```

숫자 값은 Pino의 순서를 따릅니다(내장 레벨은 10~60을 사용함). 수준`35` sits between `info` (30) and `warn` (40), so with `level: 'info'` both `info` and `audit` lines are emitted.

## 파일 전송(구조화된 로그) {/* #file-transport-structured-logs */}

다음을 사용하여 구조화된 로그를 파일에 기록합니다.`FileTransport`. The logger accepts a plain message as the first argument and structured metadata as the second argument. These are internally converted to a `BaseLogMessage` and persisted to the configured file path.

```typescript title="src/mastra/loggers/file-transport.ts"
import { FileTransport } from '@mastra/loggers/file'
import { PinoLogger } from '@mastra/loggers/pino'

export const fileLogger = new PinoLogger({
  name: 'Mastra',
  transports: { file: new FileTransport({ path: 'test-dir/test.log' }) },
  level: 'warn',
})
```

### 파일 전송 사용량 {/* #file-transport-usage */}

```typescript
fileLogger.warn('Low disk space', {
  destinationPath: 'system',
  type: 'WORKFLOW',
})
```

## Upstash 전송(원격 로그 유출) {/* #upstash-transport-remote-log-drain */}

다음을 사용하여 구조화된 로그를 원격 Redis 목록으로 스트리밍합니다.`UpstashTransport`. The logger accepts a string message and a structured metadata object. It supports centralized logging for distributed environments, supporting filtering by `destinationPath`, `type`, and `runId`.

```typescript title="src/mastra/loggers/upstash-transport.ts"
import { UpstashTransport } from '@mastra/loggers/upstash'
import { PinoLogger } from '@mastra/loggers/pino'

export const upstashLogger = new PinoLogger({
  name: 'Mastra',
  transports: {
    upstash: new UpstashTransport({
      listName: 'production-logs',
      upstashUrl: process.env.UPSTASH_URL!,
      upstashToken: process.env.UPSTASH_TOKEN!,
    }),
  },
  level: 'info',
})
```

### 업스태시 전송 사용량 {/* #upstash-transport-usage */}

```typescript
upstashLogger.info('User signed in', {
  destinationPath: 'auth',
  type: 'AGENT',
  runId: 'run_123',
})
```

## 맞춤형 운송 {/* #custom-transport */}

다음을 사용하여 사용자 정의 전송을 생성할 수 있습니다.`createCustomTransport` utility to integrate with any logging service or stream.

### 센트리 수송 예시 {/* #sentry-transport-example */}

다음을 사용하여 사용자 정의 전송을 생성합니다.`createCustomTransport` and integrates it with a third-party logging stream such as `pino-sentry-transport`. This allows forwarding logs to an external system like Sentry for advanced monitoring and observability.

```typescript title="src/mastra/loggers/sentry-transport.ts"
import { createCustomTransport } from '@mastra/core/loggers'
import { PinoLogger } from '@mastra/loggers/pino'
import pinoSentry from 'pino-sentry-transport'

const sentryStream = await pinoSentry({
  sentry: {
    dsn: 'YOUR_SENTRY_DSN',
    _experiments: {
      enableLogs: true,
    },
  },
})

const customTransport = createCustomTransport(sentryStream)

export const sentryLogger = new PinoLogger({
  name: 'Mastra',
  level: 'info',
  transports: { sentry: customTransport },
})
```
