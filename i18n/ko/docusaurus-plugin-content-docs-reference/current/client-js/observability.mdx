# Observability API

Observability API는 추적을 검색하고, 애플리케이션 성능을 모니터링하고, 평가를 위해 추적에 점수를 매기고, 추적 및 범위에 연결된 피드백을 기록하는 메서드를 제공합니다.

## 특정 추적 얻기 {/* #getting-a-specific-trace */}

모든 범위 및 세부정보를 포함하여 해당 ID로 특정 추적을 검색합니다.

```typescript
const trace = await mastraClient.getTrace('trace-id-123')
```

## 필터링으로 추적 얻기 {/* #getting-traces-with-filtering */}

선택적 필터링을 사용하여 페이지가 매겨진 추적 루트 범위 목록을 검색합니다.

```typescript
const traces = await mastraClient.getTraces({
  pagination: {
    page: 1,
    perPage: 20,
    dateRange: {
      start: new Date('2024-01-01'),
      end: new Date('2024-01-31'),
    },
  },
  filters: {
    name: 'weather-agent', // Filter by trace name
    spanType: 'agent', // Filter by span type
    entityId: 'weather-agent-id', // Filter by entity ID
    entityType: 'agent', // Filter by entity type
  },
})

console.log(`Found ${traces.spans.length} root spans`)
console.log(`Total pages: ${traces.pagination.totalPages}`)

// To get the complete trace with all spans, use getTrace
const completeTrace = await mastraClient.getTrace(traces.spans[0].traceId)
```

## 목록 보기의 추적 나열 {/* #listing-traces-for-a-list-view */}

`listTracesLight()`추적 목록과 동일한 행을 반환합니다.`input`, `output` and `attributes` payloads. Each row carries a short `inputPreview`대신 문자열을 사용하므로 목록은 전체 Prompt를 전송하지 않고도 미리보기 열을 렌더링할 수 있습니다.

한 번에 많은 트레이스를 렌더링할 때마다 선호하고 행이 열릴 때만 전체 레코드를 가져옵니다.

```typescript
const list = await mastraClient.listTracesLight({
  pagination: { page: 0, perPage: 25 },
  filters: { entityType: 'agent' },
})

for (const span of list.spans) {
  console.log(span.name, span.inputPreview)
}

// Fetch the full payload only for the trace the user selects
const selected = await mastraClient.getTrace(list.spans[0].traceId)
```

이는 다음과 동일한 필터링, 순서 지정 및 델타 폴링 인수를 허용합니다.`listTraces()`. Use `listTraces()` when you actually need the full span payloads.

## 득점 흔적 {/* #scoring-traces */}

평가를 위해 등록된 채점자를 사용하여 특정 추적에 점수를 매깁니다.

```typescript
const result = await mastraClient.score({
  scorerName: 'answer-relevancy',
  targets: [
    { traceId: 'trace-1', spanId: 'span-1' }, // Score specific span
    { traceId: 'trace-2' }, // Score specific span which defaults to the parent span
  ],
})
```

## 범위별 점수 얻기 {/* #getting-scores-by-span */}

추적 내의 특정 범위에 대한 점수를 검색합니다.

```typescript
const scores = await mastraClient.listScoresBySpan({
  traceId: 'trace-123',
  spanId: 'span-456',
  page: 1,
  perPage: 20,
})
```

## 피드백 {/* #feedback */}

피드백 방법은 평점, 추천, 의견, 수정 사항과 같은 인간 참여형 신호를 생성, 나열 및 쿼리합니다. 참조[feedback guide](/docs/observability/feedback) for examples and the [feedback reference](/reference/observability/feedback) for full schemas.

### 피드백 만들기 {/* #creating-feedback */}

추적 또는 범위에 연결된 피드백 레코드를 만듭니다.

```typescript
const response = await mastraClient.createFeedback({
  feedback: {
    traceId: 'trace-123',
    spanId: 'span-456',
    feedbackSource: 'user',
    feedbackType: 'rating',
    value: 1,
    comment: 'Helpful answer.',
  },
})
```

### 피드백 나열 {/* #listing-feedback */}

선택적 필터를 사용하여 페이지가 매겨진 피드백 레코드를 검색합니다.

```typescript
const feedback = await mastraClient.listFeedback({
  filters: {
    feedbackType: 'rating',
    feedbackSource: 'studio',
  },
  pagination: { page: 0, perPage: 20 },
  orderBy: { field: 'timestamp', direction: 'DESC' },
})
```

### 피드백 집계 {/* #aggregating-feedback */}

평점이나 엄지손가락과 같은 숫자 피드백 값을 집계합니다.`1` and `-1`:

```typescript
const averageRating = await mastraClient.getFeedbackAggregate({
  feedbackType: 'rating',
  aggregation: 'avg',
  comparePeriod: 'previous_day',
})
```

### 피드백 그룹화 {/* #grouping-feedback */}

Observability 차원별로 숫자 피드백을 그룹화합니다.

```typescript
const ratingsByAgent = await mastraClient.getFeedbackBreakdown({
  feedbackType: 'rating',
  groupBy: ['entityName'],
  aggregation: 'avg',
})
```

### 시간 경과에 따른 피드백 쿼리 {/* #querying-feedback-over-time */}

간격별 버킷 수치 피드백:

```typescript
const ratingsOverTime = await mastraClient.getFeedbackTimeSeries({
  feedbackType: 'rating',
  interval: '1h',
  aggregation: 'avg',
  groupBy: ['feedbackSource'],
})
```

### 피드백 백분위수 쿼리 {/* #querying-feedback-percentiles */}

숫자 피드백 값에 대한 백분위수 계열을 반환합니다.

```typescript
const ratingPercentiles = await mastraClient.getFeedbackPercentiles({
  feedbackType: 'rating',
  percentiles: [0.5, 0.95],
  interval: '1d',
})
```
