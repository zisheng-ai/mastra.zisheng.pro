# OpenAI 응답 API 대화

OpenAI Responses API Conversations 표면은 Mastra Agents의 대화 관리 측면을 Responses API로 제공합니다. Mastra에서 스레드 기반 대화를 생성, 검색, 삭제 및 검사하는 방법을 제공합니다.

이 API는[OpenAI Responses API](/reference/client-js/responses). Stored Responses calls return `conversation_id`, 그리고 Mastra에서 해당 값은 원시 Memory입니다.`threadId`. 사용`client.conversations`해당 스레드로 직접 작업하고 싶을 때.

이 API는 현재 실험적입니다.

## OpenAI 응답과의 관계 {/* #relationship-to-openai-responses */}

생성 및 지속을 위해 OpenAI Responses API를 사용하십시오.

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

console.log(response.conversation_id)
```

저장된 스레드를 검사하거나 관리하려면 Conversations API를 사용하세요.

```typescript
const conversation = await client.conversations.retrieve(response.conversation_id!)
const items = await client.conversations.items.list(response.conversation_id!)
```

## 사용예 {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const conversation = await client.conversations.create({
  agent_id: 'support-agent',
})

console.log(conversation.id)
```

## 행동 양식 {/* #methods */}

### 수명주기 {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

선택한 Agent에 대한 새 대화 스레드를 만듭니다.

```typescript
const conversation = await client.conversations.create({
  agent_id: 'support-agent',
  title: 'Billing support',
})
```

**보고:** `Promise<Conversation>`.

#### `retrieve(conversationId, requestContext?)` {/* #retrieveconversationid-requestcontext */}

스레드 ID로 대화를 검색합니다.

```typescript
const conversation = await client.conversations.retrieve('thread_123')

console.log(conversation.thread)
```

**보고:** `Promise<Conversation>`.

#### `delete(conversationId, requestContext?)` {/* #deleteconversationid-requestcontext */}

스레드 ID로 대화를 삭제합니다.

```typescript
const deleted = await client.conversations.delete('thread_123')

console.log(deleted.deleted)
```

**보고:** `Promise<ConversationDeleted>`.

### 품목 {/* #items */}

#### `items.list(conversationId, requestContext?)` {/* #itemslistconversationid-requestcontext */}

대화에 대해 저장된 항목을 나열합니다.

```typescript
const items = await client.conversations.items.list('thread_123')

console.log(items.data)
```

**보고:** `Promise<ConversationItemsPage>`.

## 응답 형태 {/* #response-shape */}

`create()`그리고`retrieve()` return a conversation object with:

* `id`: 원시 스레드 ID
* `object`: 언제나`'conversation'`
* `thread`: 저장된 스레드 기록

`delete()`보고:

* `id`: 원시 스레드 ID
* `object`: 언제나`'conversation.deleted'`
* `deleted`: 언제나`true`

`items.list()`보고:

* `object`: 언제나`'list'`
* `data`: 다음과 같은 대화 항목`message`, `function_call`, and `function_call_output`
* `first_id`: 페이지의 첫 번째 항목 ID
* `last_id`: 페이지의 마지막 항목 ID
* `has_more`: 현재 페이지 외에 더 많은 항목이 존재하는지 여부
