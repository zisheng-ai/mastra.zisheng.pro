# 오류 처리

Mastra Client SDK에는 재시도 메커니즘과 오류 처리 기능이 내장되어 있습니다.

## 오류 처리 {/* #error-handling-1 */}

모든 API 메서드는 사용자가 포착하고 처리할 수 있는 오류를 발생시킬 수 있습니다.

```typescript
try {
  const agent = mastraClient.getAgent('agent-id')
  const response = await agent.generate('Hello')
} catch (error) {
  console.error('An error occurred:', error.message)
}
```
