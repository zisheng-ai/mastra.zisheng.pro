# Tool API

Tool API는 Mastra 플랫폼에서 사용 가능한 Tool와 상호 작용하고 실행하는 방법을 제공합니다.

## 모든 Tool 얻기 {/* #getting-all-tools */}

사용 가능한 모든 Tool 목록을 검색합니다.

```typescript
const tools = await mastraClient.listTools()
```

## 특정 Tool로 작업하기 {/* #working-with-a-specific-tool */}

특정 Tool의 인스턴스를 가져옵니다.

```typescript
const tool = mastraClient.getTool('tool-id')
```

## Tool 방법 {/* #tool-methods */}

### Tool 세부정보 가져오기 {/* #get-tool-details */}

Tool에 대한 자세한 정보를 검색합니다.

```typescript
const details = await tool.details()
```

### Tool 실행 {/* #execute-tool */}

특정 인수를 사용하여 Tool를 실행합니다.

```typescript
const result = await tool.execute({
  args: {
    param1: 'value1',
    param2: 'value2',
  },
  threadId: 'thread-1', // Optional: Thread context
  resourceId: 'resource-1', // Optional: Resource identifier
})
```
