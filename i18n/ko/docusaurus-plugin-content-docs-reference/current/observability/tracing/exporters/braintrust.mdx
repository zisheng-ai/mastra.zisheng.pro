# Braintrust수출업체

평가 및 Observability을 위해 추적 데이터를 Braintrust로 보냅니다.

## 건설자 {/* #constructor */}

```typescript prettier:false
new BraintrustExporter(config: BraintrustExporterConfig)
```

## `BraintrustExporterConfig` {/* #braintrustexporterconfig */}

```typescript
interface BraintrustExporterConfig extends BaseExporterConfig {
  apiKey?: string
  endpoint?: string
  projectName?: string
  braintrustLogger?: Logger<true>
  currentSpan?: () => Span | undefined
  tuningParameters?: Record<string, any>
}
```

확장`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 로거 인스턴스
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 로그 수준(기본값: INFO)

## 행동 양식 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

추적 이벤트를 Braintrust로 내보냅니다.

### 내보내다 {/* #export */}

```typescript prettier:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

일괄 내보내기는 Braintrust로 범위를 내보냅니다.

### 플러시 {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Force는 내보내기를 종료하지 않고 모든 버퍼링된 범위를 Braintrust로 플러시합니다. 런타임이 종료되기 전에 범위를 내보내야 하는 서버리스 환경에 유용합니다.

### 일시 휴업 {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

보류 중인 데이터를 플러시하고 클라이언트를 종료합니다.

## 용법 {/* #usage */}

### Zero-Config(환경 변수 사용) {/* #zero-config-using-environment-variables */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

// Reads from BRAINTRUST_API_KEY, BRAINTRUST_ENDPOINT
const exporter = new BraintrustExporter()
```

### 명시적 구성 {/* #explicit-configuration */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

const exporter = new BraintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-ai-project',
})
```
