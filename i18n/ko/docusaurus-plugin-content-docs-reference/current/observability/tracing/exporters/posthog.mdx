# Posthog수출업자

AI Observability 및 분석을 위해 추적 데이터를 PostHog에 보냅니다.

## 건설자 {/* #constructor */}

```typescript prettier:false
new PosthogExporter(config: PosthogExporterConfig)
```

## `PosthogExporterConfig` {/* #posthogexporterconfig */}

```typescript
interface PosthogExporterConfig extends BaseExporterConfig {
  apiKey?: string
  host?: string
  flushAt?: number
  flushInterval?: number
  serverless?: boolean
  defaultDistinctId?: string
  enablePrivacyMode?: boolean
}
```

확장`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 로거 인스턴스
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 로그 수준(기본값: INFO)

## 행동 양식 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

추적 이벤트를 PostHog로 내보냅니다.

### `onFeedbackEvent` {/* #onfeedbackevent */}

```typescript prettier:false
async onFeedbackEvent(event: FeedbackEvent): Promise<void>
```

피드백 이벤트를 PostHog로 내보냅니다. 보다[Feedback export](#feedback-export).

### 플러시 {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Force는 내보내기를 종료하지 않고 버퍼링된 이벤트를 PostHog로 플러시합니다. 런타임이 종료되기 전에 범위를 내보내야 하는 서버리스 환경에 유용합니다.

### 일시 휴업 {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

보류 중인 일괄 처리 이벤트를 플러시하고 PostHog 클라이언트를 종료합니다.

## 용법 {/* #usage */}

### Zero-Config(환경 변수 사용) {/* #zero-config-using-environment-variables */}

```typescript
import { PosthogExporter } from '@mastra/posthog'

// Reads from POSTHOG_API_KEY, POSTHOG_HOST
const exporter = new PosthogExporter()
```

### 명시적 구성 {/* #explicit-configuration */}

```typescript
import { PosthogExporter } from '@mastra/posthog'

const exporter = new PosthogExporter({
  apiKey: process.env.POSTHOG_API_KEY!,
  host: 'https://us.i.posthog.com',
  serverless: true,
})
```

## 피드백 내보내기 {/* #feedback-export */}

다음으로 피드백이 기록되었습니다.[`addFeedback()`](/docs/observability/feedback) is exported to PostHog as a native `$ai_feedback` event. PostHog shows it as **User feedback** on the linked trace. No extra configuration is needed.

```typescript
const trace = await mastra.observability.getRecordedTrace({ traceId })
await trace.addFeedback({
  feedbackType: 'thumbs',
  value: 'down',
  comment: 'Wrong answer',
})
```

피드백 이벤트는 다음 PostHog 속성에 매핑됩니다.

| 마스트라 피드백 필드 | PostHog 속성 |
| - | - |
|`traceId` | `$ai_trace_id` |
| `comment` (or `value` when no comment) | `$ai_feedback_text` |
| `feedbackId` | `feedback_id` |
| `feedbackType` | `feedback_type` |
| `value` | `feedback_value` |
| `feedbackSource` | `feedback_source` |
| `spanId` | `span_id` |
| `sourceId` | `source_id` |
| `metadata.sessionId` | `$ai_session_id` |
| `metadata` (other keys) | custom properties |

없는 피드백`traceId` is dropped because PostHog anchors feedback to a trace through `$ai_trace_id`. The event's distinct ID resolves from `feedbackUserId`, then `metadata.userId`, then `defaultDistinctId`, then `anonymous`.
