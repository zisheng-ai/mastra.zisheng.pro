# DeepEvalExporter

추적 데이터를 다음으로 보냅니다.[Confident AI](https://www.confident-ai.com/)평가 및 Observability을 위해. 수출자`@mastra/deepeval`, DeepEval SDK를 기반으로 구축되었습니다.

보다[Confident AI exporter](/docs/observability/integrations/exporters/confident-ai) for setup and usage.

## 건설자 {/* #constructor */}

```typescript prettier:false
new DeepEvalExporter(config?: DeepEvalExporterConfig)
```

## `DeepEvalExporterConfig` {/* #deepevalexporterconfig */}

```typescript
interface DeepEvalExporterConfig extends BaseExporterConfig {
  apiKey?: string
  environment?: string
  name?: string
  tags?: string[]
  metadata?: Record<string, any>
  threadId?: string
  userId?: string
  testCaseId?: string
  turnId?: string
  metricCollection?: string
  traceMetricCollection?: string
  llmMetricCollection?: string
  agentMetricCollection?: string
  toolMetricCollectionMap?: Record<string, string>
  prompt?: Prompt
  debug?: boolean
  traceCaptureSink?: (trace: Trace) => void
}
```

확장`BaseExporterConfig`, which includes:

* `logger?: IMastraLogger`- 로거 인스턴스
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 로그 수준(기본값: INFO)

## 행동 양식 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

추적 이벤트를 Confident AI로 내보냅니다. Mastra 범위 스트림에서 추적 트리를 구축하고 루트 범위가 끝나면 추적을 게시합니다.

### `flush` {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

내보내기를 종료하지 않고 진행 중인 추적 게시물이 정착될 때까지 기다립니다.

### `shutdown` {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

열려 있는 모든 추적을 마무리하고 보류 중인 게시물을 플러시합니다.

## 용법 {/* #usage */}

### Zero-Config(환경 변수 사용) {/* #zero-config-using-environment-variables */}

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

// Reads from CONFIDENT_API_KEY, CONFIDENT_TRACE_ENVIRONMENT
const exporter = new DeepEvalExporter()
```

### 명시적 구성 {/* #explicit-configuration */}

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

const exporter = new DeepEvalExporter({
  apiKey: process.env.CONFIDENT_API_KEY,
  environment: 'production',
})
```

## 스팬 유형 매핑 {/* #span-type-mapping */}

| 마스트라 스팬 유형 | 자신 있는 AI 스팬 유형 |
| - | - |
|`AGENT_RUN`, `WORKFLOW_RUN` | `AGENT` |
| `MODEL_GENERATION` | `LLM` |
| `TOOL_CALL`, `MCP_TOOL_CALL`, `PROVIDER_TOOL_CALL`, `CLIENT_TOOL_CALL` | `TOOL` |
| `RAG_EMBEDDING`, `RAG_VECTOR_OPERATION` | `RETRIEVER`|
| 내보낸 기타 모든 범위 유형 |`CUSTOM` |

이벤트 범위(예:`MODEL_CHUNK`) are dropped.
