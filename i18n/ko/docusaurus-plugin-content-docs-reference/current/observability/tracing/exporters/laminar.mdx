# Laminar수출업체

OTLP/HTTP(protobuf)를 통해 Laminar에 추적 데이터를 보냅니다.

## 건설자 {/* #constructor */}

```typescript prettier:false
new LaminarExporter(config?: LaminarExporterConfig)
```

## `LaminarExporterConfig` {/* #laminarexporterconfig */}

```typescript
interface LaminarExporterConfig extends BaseExporterConfig {
  apiKey?: string
  baseUrl?: string
  endpoint?: string
  headers?: Record<string, string>
  realtime?: boolean
  disableBatch?: boolean
  batchSize?: number
  timeoutMillis?: number
}
```

`BaseExporterConfig`를 확장하며, 포함되는 항목은 다음과 같습니다.
* `logger?: IMastraLogger`- 로거 인스턴스
* `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'`- 로그 수준(기본값: INFO)

## 행동 양식 {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

추적 이벤트를 Laminar로 내보냅니다.

### 플러시 {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Force는 내보내기를 종료하지 않고 모든 버퍼링된 범위를 Laminar로 플러시합니다. 런타임이 종료되기 전에 범위를 내보내야 하는 서버리스 환경에 유용합니다.

### 일시 휴업 {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

보류 중인 데이터를 플러시하고 내보내기를 종료합니다.

## 용법 {/* #usage */}

### Zero-Config(환경 변수 사용) {/* #zero-config-using-environment-variables */}

```typescript
import { LaminarExporter } from '@mastra/laminar'

// Reads from LMNR_PROJECT_API_KEY, LMNR_BASE_URL, LAMINAR_ENDPOINT
const exporter = new LaminarExporter()
```

### 명시적 구성 {/* #explicit-configuration */}

```typescript
import { LaminarExporter } from '@mastra/laminar'

const exporter = new LaminarExporter({
  apiKey: process.env.LMNR_PROJECT_API_KEY,
  baseUrl: 'https://api.lmnr.ai',
  realtime: true,
})
```
