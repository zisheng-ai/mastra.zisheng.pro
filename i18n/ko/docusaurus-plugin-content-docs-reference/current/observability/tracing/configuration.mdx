## `SamplingStrategy` {/* #samplingstrategy */}

```typescript
type SamplingStrategy =
  | { type: 'always' }
  | { type: 'never' }
  | { type: 'ratio'; probability: number }
  | { type: 'custom'; sampler: (options?: TracingOptions) => boolean }
```

## 레지스트리 방법 {/* #registry-methods */}

Observability 클래스는 Observability 인스턴스를 관리하기 위한 메서드를 제공합니다.

### `registerInstance` {/* #registerinstance */}

```typescript prettier:false
registerInstance(
  name: string,
  instance: ObservabilityInstance,
  isDefault?: boolean
): void;
```

관측 가능성 인스턴스를 레지스트리에 등록합니다.

### `getInstance` {/* #getinstance */}

```typescript prettier:false
getInstance(name: string): ObservabilityInstance | undefined;
```

이름으로 Observability 인스턴스를 검색합니다.

### `getDefaultInstance` {/* #getdefaultinstance */}

```typescript prettier:false
getDefaultInstance(): ObservabilityInstance | undefined;
```

기본 관측 가능성 인스턴스를 반환합니다.

### `getSelectedInstance` {/* #getselectedinstance */}

```typescript prettier:false
getSelectedInstance(
  options: ConfigSelectorOptions
): ObservabilityInstance | undefined;
```

구성 선택기 또는 기본값으로 선택한 관측 가능성 인스턴스를 반환합니다.

### `listInstances` {/* #listinstances */}

```typescript prettier:false
listInstances(): ReadonlyMap<string, ObservabilityInstance>;
```

등록된 모든 관측 가능성 인스턴스를 반환합니다.

### `hasInstance` {/* #hasinstance */}

```typescript prettier:false
hasInstance(name: string): boolean;
```

관측 가능성 인스턴스가 존재하는지 확인합니다.

### `setConfigSelector` {/* #setconfigselector */}

```typescript prettier:false
setConfigSelector(selector: ConfigSelector): void;
```

구성 선택기 기능을 설정합니다.

### `unregisterInstance` {/* #unregisterinstance */}

```typescript prettier:false
unregisterInstance(name: string): boolean;
```

레지스트리에서 Observability 인스턴스를 제거합니다.

### 분명한 {/* #clear */}

```typescript prettier:false
clear(): void;
```

종료하지 않고 모든 인스턴스를 지웁니다.

### 일시 휴업 {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>;
```

모든 Observability 인스턴스를 종료하고 레지스트리를 지웁니다.
