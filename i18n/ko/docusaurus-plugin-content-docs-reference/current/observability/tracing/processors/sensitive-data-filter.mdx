# 민감한 데이터 필터

범위 필드에서 민감한 정보를 수정하는 SpanOutputProcessor입니다.

## 기본적으로 자동 적용됨 {/* #auto-applied-by-default */}

`Observability`자동으로 추가`SensitiveDataFilter` to every configured instance's `spanOutputProcessors`따라서 비밀은 Mastra 클라우드 수출업체와 같은 수출업체에 도달하기 전에 수정됩니다. 필터는 마지막으로(사용자가 제공한 프로세서 이후) 실행되므로 업스트림 프로세서에 의해 도입되거나 표면화된 민감한 데이터는 여전히 수정됩니다. 옵션을 사용자 정의하려는 경우가 아니면 수동으로 추가할 필요가 없습니다.

자동 적용 필터를 선택 해제하거나 맞춤설정하려면`sensitiveDataFilter` option on the [`Observability` registry config](/reference/observability/tracing/configuration#observabilityregistryconfig):

```typescript
import { Observability } from '@mastra/observability'

new Observability({
  configs: {/* ... */},
  // disable the auto-applied filter
  sensitiveDataFilter: false,
  // or customize it
  // sensitiveDataFilter: { sensitiveFields: ['mySecret'], redactionStyle: 'partial' },
})
```

구성에 이미`SensitiveDataFilter` in `spanOutputProcessors`, the auto-applied filter is skipped to avoid double redaction. Pre-instantiated `ObservabilityInstance` values aren't modified. Add a `SensitiveDataFilter`필요한 경우 프로세서에 직접 문의하십시오.

## `SensitiveDataFilterOptions` {/* #sensitivedatafilteroptions */}

```typescript
interface SensitiveDataFilterOptions {
  /**
   * List of sensitive field names to redact.
   * Matching is case-insensitive and normalizes separators
   * (api-key, api_key, Api Key → apikey).
   * Defaults include: password, token, secret, key, apikey, auth,
   * authorization, bearer, bearertoken, jwt, credential,
   * clientsecret, privatekey, refresh, ssn.
   */
  sensitiveFields?: string[]

  /**
   * The token used for full redaction.
   * Default: "[REDACTED]"
   */
  redactionToken?: string

  /**
   * Style of redaction to use:
   * - "full": always replace with redactionToken
   * - "partial": show 3 characters from the start and end, redact the middle
   * Default: "full"
   */
  redactionStyle?: RedactionStyle
}
```

## 처리 동작 {/* #processing-behavior */}

### 필드 매칭 {/* #field-matching */}

* **대소문자를 구분하지 않음**: `APIKey`, `apikey`, `ApiKey` all match
* **구분 기호에 구애받지 않음**: `api-key`, `api_key`, `apiKey` are treated identically
* **정확한 일치**: 정규화 후 필드는 정확히 일치해야 합니다.
  * `token`성냥`token`, `Token`, `TOKEN`
  * `token`일치하지 않습니다`promptTokens` or `tokenCount`

### 교정 스타일 {/* #redaction-styles */}

#### 전체 교정(기본값) {/* #full-redaction-default */}

일치하는 모든 값은 redactionToken으로 대체됩니다.

#### 부분 편집 {/* #partial-redaction */}

* 처음 3자와 마지막 3자를 표시합니다.
* 6자 이하의 값은 완전히 수정되었습니다.
* 문자열이 아닌 값은 부분 수정 전에 문자열로 변환됩니다.

### 오류 처리 {/* #error-handling */}

필드 필터링이 실패하면 해당 필드는 다음으로 대체됩니다.

```typescript
{
  error: {
    processor: 'sensitive-data-filter'
  }
}
```

### 처리된 필드 {/* #processed-fields */}

필터는 다음을 재귀적으로 처리합니다.

* `span.attributes`- 스팬 메타데이터 및 속성
* `span.metadata`- 맞춤형 메타데이터
* `span.input`- 입력 데이터
* `span.output`- 출력 데이터
* `span.errorInfo`- 오류 정보

중첩된 개체, 배열 및 순환 참조를 안전하게 처리합니다.
