# voice.updateConfig()

그만큼`updateConfig()`메서드를 사용하면 런타임에 음성 제공자의 구성을 업데이트할 수 있습니다. 이는 새 인스턴스를 생성하지 않고도 음성 설정, API 키 또는 기타 공급자별 옵션을 변경하는 데 유용합니다.

## 사용예 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

// Initialize a real-time voice provider
const voice = new OpenAIRealtimeVoice({
  realtimeConfig: {
    model: 'gpt-5.1-realtime',
    apiKey: process.env.OPENAI_API_KEY,
  },
  speaker: 'alloy',
})

// Connect to the real-time service
await voice.connect()

// Later, update the configuration
voice.updateConfig({
  voice: 'nova', // Change the default voice
  turn_detection: {
    type: 'server_vad',
    threshold: 0.5,
    silence_duration_ms: 1000,
  },
})

// The next speak() call will use the new configuration
await voice.speak('Hello with my new voice!')
```

## 메모 {/* #notes */}

* 공급자가 이 메서드를 지원하지 않는 경우 기본 구현에서는 경고를 기록합니다.
* 구성 업데이트는 일반적으로 진행 중인 작업이 아닌 후속 작업에 적용됩니다.
* 생성자에서 설정할 수 있는 모든 속성이 런타임에 업데이트될 수 있는 것은 아닙니다.
* 구체적인 동작은 음성 공급자 구현에 따라 다릅니다.
* 실시간 음성 Provider의 경우 일부 구성을 변경하려면 서비스에 다시 연결해야 할 수도 있습니다.
