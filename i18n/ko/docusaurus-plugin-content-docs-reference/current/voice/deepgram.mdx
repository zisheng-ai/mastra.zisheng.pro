# 딥그램

Mastra의 Deepgram 음성 구현은 Deepgram의 API를 사용하여 텍스트 음성 변환(TTS) 및 음성 텍스트 변환(STT) 기능을 제공합니다. 음성 합성 및 전사에 대한 구성 가능한 옵션을 통해 여러 음성 Model 및 언어를 지원합니다.

## 사용예 {/* #usage-example */}

```typescript
import { DeepgramVoice } from '@mastra/voice-deepgram'

// Initialize with default configuration (uses DEEPGRAM_API_KEY environment variable)
const voice = new DeepgramVoice()

// Initialize with custom configuration
const voice = new DeepgramVoice({
  speechModel: {
    name: 'aura',
    apiKey: 'your-api-key',
  },
  listeningModel: {
    name: 'nova-2',
    apiKey: 'your-api-key',
  },
  speaker: 'asteria-en',
})

// Text-to-Speech
const audioStream = await voice.speak('Hello, world!')

// Speech-to-Text
const transcript = await voice.listen(audioStream)
```
