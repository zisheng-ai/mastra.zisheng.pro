# 사르밤

Mastra의 SarvamVoice 클래스는 Sarvam AI Model을 사용하여 텍스트 음성 변환 및 음성 텍스트 변환 기능을 제공합니다.

## 사용예 {/* #usage-example */}

```typescript
import { SarvamVoice } from '@mastra/voice-sarvam'

// Initialize with default configuration using environment variables
const voice = new SarvamVoice()

// Or initialize with specific configuration
const voiceWithConfig = new SarvamVoice({
  speechModel: {
    model: 'bulbul:v3',
    apiKey: process.env.SARVAM_API_KEY!,
    language: 'en-IN',
    properties: {
      pace: 1.0,
      temperature: 0.6,
      speech_sample_rate: 24000,
      output_audio_codec: 'wav',
    },
  },
  listeningModel: {
    model: 'saarika:v2.5',
    apiKey: process.env.SARVAM_API_KEY!,
    languageCode: 'en-IN',
    filetype: 'wav',
  },
  speaker: 'shubh', // Default voice for bulbul:v3
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?')

// Convert speech to text
const text = await voice.listen(audioStream, {
  filetype: 'wav',
})
```

## 메모 {/* #notes */}

* API 키는 생성자 옵션 또는`SARVAM_API_KEY` environment variable
* API 키가 제공되지 않으면 생성자에서 오류가 발생합니다.
* 이 서비스는 Sarvam AI API와 통신합니다.`https://api.sarvam.ai`
* 오디오는 바이너리 오디오 데이터가 포함된 스트림으로 반환됩니다.
* 음성 인식은 mp3 및 wav 오디오 형식을 지원합니다.
* `bulbul:v1`, `saarika:v1`, `saarika:v2`, and `saarika:flash` have been deprecated by Sarvam and are no longer supported. Use `bulbul:v3` (or `bulbul:v2`) for TTS and `saarika:v2.5` (or `saaras:v3`) for STT.
* 화자 이름은 서로 바꿔서 사용할 수 없습니다.`bulbul:v2` and `bulbul:v3`. Each model version has its own speaker catalog.
