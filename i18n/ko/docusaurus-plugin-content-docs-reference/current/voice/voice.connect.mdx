# 음성.연결()

그만큼`connect()`메서드는 실시간 음성 간 통신을 위해 WebSocket 또는 WebRTC 연결을 설정합니다. 이 메소드는 다음과 같은 다른 실시간 기능을 사용하기 전에 호출되어야 합니다.`send()`또는`answer()`.

## 사용예 {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import Speaker from '@mastra/node-speaker'

const speaker = new Speaker({
  sampleRate: 24100, // Audio sample rate in Hz - standard for high-quality audio on MacBook Pro
  channels: 1, // Mono audio output (as opposed to stereo which would be 2)
  bitDepth: 16, // Bit depth for audio quality - CD quality standard (16-bit resolution)
})

// Initialize a real-time voice provider
const voice = new OpenAIRealtimeVoice({
  realtimeConfig: {
    model: 'gpt-5.1-realtime',
    apiKey: process.env.OPENAI_API_KEY,
    options: {
      sessionConfig: {
        turn_detection: {
          type: 'server_vad',
          threshold: 0.6,
          silence_duration_ms: 1200,
        },
      },
    },
  },
  speaker: 'alloy', // Default voice
})
// Connect to the real-time service
await voice.connect()
// Now you can use real-time features
voice.on('speaker', stream => {
  stream.pipe(speaker)
})
// With connection options
await voice.connect({
  timeout: 10000, // 10 seconds timeout
  reconnect: true,
})
```

## 함께 사용`CompositeVoice` {/* #using-with-compositevoice */}

사용시`CompositeVoice`, the `connect()` method delegates to the configured real-time provider:

```typescript
import { CompositeVoice } from '@mastra/core/voice'
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
const realtimeVoice = new OpenAIRealtimeVoice()
const voice = new CompositeVoice({
  realtime: realtimeVoice,
})
// This will use the OpenAIRealtimeVoice provider
await voice.connect()
```

## 메모 {/* #notes */}

* 이 방법은 음성-음성 기능을 지원하는 실시간 음성 공급자에 의해서만 구현됩니다.
* 이 기능을 지원하지 않는 음성 Provider에서 호출하면 경고를 기록하고 즉시 해결됩니다.
* 다음과 같은 다른 실시간 방법을 사용하기 전에 연결을 설정해야 합니다.`send()` or `answer()`
* 음성 인스턴스가 완료되면 다음으로 전화하세요.`close()` to properly clean up resources
* 일부 공급자는 구현에 따라 연결이 끊어지면 자동으로 다시 연결할 수 있습니다.
* 연결 오류는 일반적으로 잡아서 처리해야 하는 예외로 발생합니다.
