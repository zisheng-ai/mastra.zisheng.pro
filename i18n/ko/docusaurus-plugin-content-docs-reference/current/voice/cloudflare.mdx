# 클라우드플레어

Mastra의 CloudflareVoice 클래스는 Cloudflare Workers AI를 사용하여 텍스트 음성 변환 기능을 제공합니다. 이 공급자는 엣지 컴퓨팅 환경에 적합한 효율적이고 지연 시간이 짧은 음성 합성을 전문으로 합니다.

## 사용예 {/* #usage-example */}

```typescript
import { CloudflareVoice } from '@mastra/voice-cloudflare'

// Initialize with configuration
const voice = new CloudflareVoice({
  speechModel: {
    name: '@cf/meta/m2m100-1.2b',
    apiKey: 'your-cloudflare-api-token',
    accountId: 'your-cloudflare-account-id',
  },
  speaker: 'en-US-1', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  speaker: 'en-US-2', // Override default voice
})

// Get available voices
const speakers = await voice.getSpeakers()
console.log(speakers)
```

## 메모 {/* #notes */}

* API 토큰은 생성자 옵션 또는 환경 변수(CLOUDFLARE\_API\_TOKEN 및 CLOUDFLARE\_ACCOUNT\_ID)를 통해 제공될 수 있습니다.
* Cloudflare Workers AI는 대기 시간이 짧은 엣지 컴퓨팅에 최적화되어 있습니다.
* 이 공급자는 STT(음성-텍스트)가 아닌 TTS(텍스트 음성 변환) 기능만 지원합니다.
* 이 서비스는 다른 Cloudflare Workers 제품과 잘 통합됩니다.
* 프로덕션 용도로 사용하려면 Cloudflare 계정에 적절한 Workers AI 구독이 있는지 확인하세요.
* 다른 Provider에 비해 음성 옵션이 더 제한적이지만 엣지에서의 성능은 뛰어납니다.
