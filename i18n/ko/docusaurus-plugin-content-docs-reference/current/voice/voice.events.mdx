# 음성 이벤트

음성 공급자는 실시간 음성 상호 작용 중에 이벤트를 내보냅니다. 이러한 이벤트는 다음을 사용하여 들을 수 있습니다.[voice.on()](./voice.on)방법이며 대화형 음성 애플리케이션을 구축하는 데 특히 중요합니다.

## 메모 {/* #notes */}

* 모든 음성 Provider가 모든 이벤트를 지원하는 것은 아닙니다.
* 정확한 페이로드 구조는 Provider마다 다를 수 있습니다.
* 실시간이 아닌 공급자의 경우 이러한 이벤트의 대부분은 발생하지 않습니다.
* 이벤트는 대화 상태에 응답하는 대화형 UI를 구축하는 데 유용합니다.
* 다음을 사용하는 것을 고려해보세요.[voice.off()](./voice.off) method to remove event listeners when they're no longer needed
