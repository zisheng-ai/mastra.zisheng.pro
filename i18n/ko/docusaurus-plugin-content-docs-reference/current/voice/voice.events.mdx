# 음성 이벤트

음성 Provider는 실시간 음성 상호작용 중에 이벤트를 방출합니다. 이러한 이벤트는 [voice.on()](./voice.on) 메서드로 수신할 수 있으며, 대화형 음성 애플리케이션을 구축할 때 특히 중요합니다.

## 메모 {/* #notes */}

* 모든 음성 Provider가 모든 이벤트를 지원하는 것은 아닙니다.
* 정확한 페이로드 구조는 Provider마다 다를 수 있습니다.
* 실시간이 아닌 Provider에서는 이러한 이벤트 대부분이 발생하지 않습니다.
* 이벤트는 대화 상태에 반응하는 대화형 UI를 구축하는 데 유용합니다.
* 이벤트 리스너가 더 이상 필요하지 않으면 [voice.off()](./voice.off) 메서드로 제거하는 것이 좋습니다.
