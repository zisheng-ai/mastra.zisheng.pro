# FirecrawlBrowser 클래스

그만큼`FirecrawlBrowser`클래스는[Firecrawl 브라우저 샌드박스](https://docs.firecrawl.dev/features/browser). Firecrawl API를 통해 원격 브라우저 세션을 프로비저닝하고 CDP(Chrome DevTools Protocol)를 통해 연결합니다.

`FirecrawlBrowser`는 [`AgentBrowser`](/reference/browser/agent-browser)를 확장하며 동일한 결정적 Tool 세트를 제공합니다. 로컬 Chromium 설치 대신 호스팅된 브라우저 세션을 사용하려면 이 클래스를 사용하세요. 로컬 자동화는 [`AgentBrowser`](/reference/browser/agent-browser)를 참조하세요. 자연어를 사용하는 AI 기반 상호작용은 [`StagehandBrowser`](/reference/browser/stagehand-browser)를 참조하세요.
## 사용예 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 세션 수명주기 {/* #session-lifecycle */}

세션 프로비저닝은 `AgentBrowser`에서 상속된 `scope` 옵션에 따라 달라집니다.
* `'thread'`(기본값): 각 대화 스레드는 처음 사용할 때 생성되고 스레드의 브라우저 세션이 삭제되면 삭제되는 자체 Firecrawl 샌드박스 세션을 갖습니다.
* `'shared'`: 브라우저가 시작되고 모든 스레드에서 공유될 때 하나의 Firecrawl 샌드박스 세션이 생성됩니다. 브라우저가 닫히면 세션이 삭제됩니다.

두 경우 모두 브라우저가 닫히면 `FirecrawlBrowser`가 원격 Firecrawl 세션을 삭제합니다. 세션 생성 또는 연결이 도중에 실패한 경우도 포함됩니다.
## Tool {/* #tools */}

`FirecrawlBrowser`는 `browser_goto`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_screenshot`을 포함하여 `AgentBrowser`와 동일한 Tool 세트를 제공합니다. 전체 목록과 Tool 매개변수는 [`AgentBrowser` Tool 참조](/reference/browser/agent-browser)를 확인하세요.
