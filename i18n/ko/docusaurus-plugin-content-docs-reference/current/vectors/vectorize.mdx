# Cloudflare 벡터 스토어

CloudflareVector 클래스는 다음을 사용하여 벡터 검색을 제공합니다.[Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/), Cloudflare의 에지 네트워크와 통합된 벡터 데이터베이스 서비스입니다.

## 오류 처리 {/* #error-handling */}

상점에서는 포착할 수 있는 입력된 오류를 발생시킵니다.

```typescript
try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof VectorStoreError) {
    console.log(error.code) // 'connection_failed' | 'invalid_dimension' | etc
    console.log(error.details) // Additional error context
  }
}
```

## 환경변수 {/* #environment-variables */}

필수 환경 변수:

* `CLOUDFLARE_ACCOUNT_ID`: Cloudflare 계정 ID
* `CLOUDFLARE_API_TOKEN`: 벡터화 권한이 있는 Cloudflare API 토큰
