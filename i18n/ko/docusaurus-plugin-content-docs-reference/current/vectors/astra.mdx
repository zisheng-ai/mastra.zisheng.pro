# 아스트라 벡터 스토어

AstraVector 클래스는 다음을 사용하여 벡터 검색을 제공합니다.[DataStax Astra DB](https://www.datastax.com/products/datastax-astra), Apache Cassandra를 기반으로 구축된 클라우드 네이티브, 서버리스 데이터베이스입니다.
엔터프라이즈급 용량과 고가용성을 갖춘 벡터 검색 기능을 제공합니다.


## 오류 처리 {/* #error-handling */}

상점에서는 포착할 수 있는 입력된 오류를 발생시킵니다.

```typescript
try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof VectorStoreError) {
    console.log(error.code) // 'connection_failed' | 'invalid_dimension' | etc
    console.log(error.details) // Additional error context
  }
}
```
