# OpenSearch 벡터 저장소

OpenSearchVector 클래스는 다음을 사용하여 벡터 검색을 제공합니다.[OpenSearch](https://opensearch.org/), 오픈 소스 검색 및 분석 엔진입니다. OpenSearch의 k-NN 기능을 사용하여 벡터 유사성 검색을 수행합니다.

## 생성자 옵션 {/* #constructor-options */}

생성자는 필수 `id` 필드와 함께 모든 [OpenSearch ClientOptions](https://opensearch.org/docs/latest/clients/javascript/index/)를 허용합니다.
