# 프로젝트 구조

새로운 Mastra 프로젝트는`create mastra`명령에는 시작하는 데 도움이 되는 미리 정의된 파일 및 폴더 세트가 함께 제공됩니다.

Mastra는 프레임워크이지만 대부분**unopinionated** about how you organize or colocate your files. The CLI provides a sensible default structure that works well for most projects, but you're free to adapt it to your workflow or team conventions. You could even build your entire project in a single file if you wanted! Whatever structure you choose, keep it consistent to ensure your code stays maintainable and straightforward to browse.

## 기본 프로젝트 구조 {/* #default-project-structure */}

으로 만든 프로젝트`create mastra` command looks like this:

```bash
src/
├── mastra/
│   ├── agents/
│   │   └── weather-agent.ts
│   ├── tools/
│   │   └── weather-tool.ts
│   ├── workflows/
│   │   └── weather-workflow.ts
│   ├── scorers/
│   │   └── weather-scorer.ts
│   └── index.ts
├── .env.example
├── package.json
└── tsconfig.json
```

미리 정의된 파일을 템플릿으로 사용합니다. 이를 복제하고 조정하여 고유한 Agent, Tool, Workflow 등을 빠르게 생성하세요.

### 폴더 {/* #folders */}

Mastra는 코드를 다음 폴더에 구성할 것을 권장합니다.

| 폴더 | 설명 |
| - | - |
|`src/mastra` | Entry point for all Mastra-related code and configuration. |
| `src/mastra/agents` | Define and configure your agents - their behavior, goals, and tools. |
| `src/mastra/workflows` | Define multi-step workflows that orchestrate agents and tools together. |
| `src/mastra/tools` | Create reusable tools that your agents can call |
| `src/mastra/mcp`| 외부 Agent와 Tool를 공유하기 위한 사용자 정의 MCP 서버 구현 |
|`src/mastra/scorers`| 시간 경과에 따른 Agent 성과 평가를 위한 채점자 정의 |

Mastra에는 두 가지 특별한 폴더 규칙이 있습니다.

* `src/mastra/agents/<name>`: 코드로 구성하는 대신 파일 규칙으로 Agent를 정의할 수 있습니다. 자세한 내용은 다음에서 확인하세요.[File-based Agents](/docs/getting-started/develop#file-based-agents) docs.
* `src/mastra/public`: 내용이`.build/output` directory during the build process, making them available for serving at runtime.

### 최상위 파일 {/* #top-level-files */}

최상위 파일은 Mastra 프로젝트가 구성, 구축 및 환경에 연결되는 방법을 정의합니다.

| 파일 | 설명 |
| - | - |
|`src/mastra/index.ts` | Central entry point where you configure and initialize Mastra. |
| `.env.example` | Template for environment variables - copy and rename to `.env` to add your secret [model provider](/models) keys. |
| `package.json` | Defines project metadata, dependencies, and available npm scripts. |
| `tsconfig.json` | Configures TypeScript options such as path aliases, compiler settings, and build output. |
