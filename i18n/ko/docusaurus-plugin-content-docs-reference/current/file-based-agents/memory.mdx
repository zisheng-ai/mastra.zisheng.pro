# Memory

파일 기반 Agent는[memory](/docs/memory/overview)에서`memory.ts`기본적으로 내보내는 파일[`Memory`](/reference/memory/memory-class)사례. 파일 기반 규칙을 보려면 이 페이지를 사용하십시오. 메시지 기록, 의미적 회상, 저장 및 프로세서에 대한 Memory 문서를 사용하십시오.

없이`memory.ts` or `config.memory`, the agent has no memory by default. Each `generate()` or `stream()`이전 컨텍스트를 직접 전달하지 않는 한 기억된 대화 상태 없이 통화가 시작됩니다.

## 빠른 시작 {/* #quickstart */}

만들다`memory.ts` next to the agent's `config.ts`:

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

내보낸 인스턴스는 Agent의 인스턴스가 됩니다.`memory`. If your app configures a storage provider on the main Mastra instance, memory data is stored there. See [storage](/docs/storage/overview) for more information.

같은 것을 사용하세요`resource` and `thread` values when calling the agent to continue a conversation:

```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## Memory 구성 {/* #configure-memory */}

옵션을 다음으로 전달`new Memory()` when the default behavior isn't enough.

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

방문[`Memory` reference](/reference/memory/memory-class) for constructor options. Use these pages for related memory features:

* [저장](/docs/storage/overview): Memory 데이터의 지속성을 구성합니다.
* [의미적 회상](/docs/memory/semantic-recall): 의미론적 의미를 통해 관련 과거 메시지를 검색합니다.
* [Memory 프로세서](/docs/memory/memory-processors): Memory가 메시지를 Model 컨텍스트에 추가하기 전에 메시지를 필터링, 정리 또는 변환합니다.

## 구성 우선순위 {/* #precedence-with-config */}

`config.memory`승리하다`memory.ts`. If neither is present, the assembled file-based agent has no memory. See [`config.ts` precedence](/reference/file-based-agents/config#precedence) for the full merge table.
