# Memory

파일 기반 Agent는[memory](/docs/memory/overview)에서`memory.ts`기본적으로 내보내는 파일[`Memory`](/reference/memory/memory-class)사례. 파일 기반 규칙을 보려면 이 페이지를 사용하십시오. 메시지 기록, 의미적 회상, 저장 및 프로세서에 대한 Memory 문서를 사용하십시오.

`memory.ts` 또는 `config.memory`가 없으면 Agent에는 기본적으로 Memory가 없습니다. 이전 컨텍스트를 직접 전달하지 않는 한 각 `generate()` 또는 `stream()` 호출은 기억된 대화 상태 없이 시작됩니다.
## 빠른 시작 {/* #quickstart */}

Agent의 `config.ts` 옆에 `memory.ts`를 만드세요.
```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

내보낸 인스턴스는 Agent의 `memory`가 됩니다. 앱이 기본 Mastra 인스턴스에 스토리지 Provider를 구성하면 Memory 데이터가 해당 위치에 저장됩니다. 자세한 내용은 [스토리지](/docs/storage/overview)를 참조하세요.
대화를 계속하려면 Agent를 호출할 때 동일한 `resource` 및 `thread` 값을 사용하세요.
```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## Memory 구성 {/* #configure-memory */}

기본 동작으로 충분하지 않으면 `new Memory()`에 옵션을 전달하세요.
```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

생성자 옵션은 [`Memory` 참조](/reference/memory/memory-class)를 확인하세요. 관련 Memory 기능은 다음 페이지를 참조하세요.
* [저장](/docs/storage/overview): Memory 데이터의 지속성을 구성합니다.
* [의미적 회상](/docs/memory/semantic-recall): 의미론적 의미를 통해 관련 과거 메시지를 검색합니다.
* [Memory 프로세서](/docs/memory/memory-processors): Memory가 메시지를 Model 컨텍스트에 추가하기 전에 메시지를 필터링, 정리 또는 변환합니다.

## 구성 우선순위 {/* #precedence-with-config */}

`config.memory`가 `memory.ts`보다 우선합니다. 둘 다 없으면 조립된 파일 기반 Agent에 Memory가 없습니다. 전체 병합 표는 [`config.ts` 우선순위](/reference/file-based-agents/config#precedence)를 참조하세요.
