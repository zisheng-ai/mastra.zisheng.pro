# 나무꾼

Mastra는 프로젝트의[logger](/docs/observability/logging)에서`logger.ts`바로 아래 파일`src/mastra/`. 파일은 기본적으로 내장된 로거를 대체하는 로거를 내보냅니다.`ConsoleLogger`Agent, Workflow 및 기타 구성 요소 전반에 걸쳐 사용됩니다.

파일 기반 규칙에 대해서는 이 페이지를 사용하십시오. 로그 수준, 전송 및 공급자 세부정보는 다음을 참조하세요.[logging](/docs/observability/logging).

## 빠른 시작 {/* #quickstart */}

`src/mastra/logger.ts`를 만들고 [`PinoLogger`](/reference/logging/pino-logger)와 같은 로거를 기본 내보내기하세요.
```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra는 저장, Observability 및 파일 기반 Agent 전에 로거를 등록하므로 해당 기본 요소는 연결된 대로 이 로거를 통해 기록합니다.

## 코드 우선순위 {/* #precedence-with-code */}

코드로 등록한 로깅 구성이 `logger.ts`보다 우선합니다. `src/mastra/index.ts`의 `new Mastra({ logger })`에 `logger`를 전달하거나 `logger: false`로 로깅을 비활성화하면 경고와 함께 `logger.ts`가 무시됩니다. 프로젝트 전체에서 하나의 로거로 충분하면 `logger.ts`를 사용하세요. 설정이 런타임 연결에 따라 달라지면 코드 등록을 사용하세요.
