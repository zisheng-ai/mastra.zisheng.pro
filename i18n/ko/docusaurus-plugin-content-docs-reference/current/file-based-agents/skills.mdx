# 기술

파일 기반 Agent는 해당 Agent에서 기술을 발견합니다.`skills/`디렉토리에 저장하고 빌드 시 번들로 묶습니다. 스킬은 상시 Prompt에 모든 세부 정보를 입력하는 대신 관련성이 있을 때 Agent이 로드할 수 있는 재사용 가능한 절차 또는 참조 자료입니다.

파일 기반 규칙에 대해서는 이 페이지를 사용하십시오. 코드 정의 기술은 다음을 참조하세요.[Agent skills](/docs/agents/skills). For the `SKILL.md`패키지 형식, 참조[작업 공간 기술](/docs/workspace/skills).

## 빠른 시작 {/* #quickstart */}

가장 간단한 기술은 아래에 하나의 마크다운 파일입니다.`skills/`. The filename becomes the skill name, and `description` tells the agent when to load it.

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## 기술 vs Tool vs 지침 {/* #skills-vs-tools-vs-instructions */}

| 필요 | 사용 | 왜 |
| - | - | - |
| 상시 ID, 어조 또는 규칙 |[`instructions.md`](/reference/file-based-agents/instructions) | The model should see the guidance every turn. |
| Callable action with inputs and outputs | [`tools/`](/reference/file-based-agents/tools) | The model needs to execute code, call APIs, or perform side effects. |
| Detailed reference or procedure loaded when relevant | `skills/` | The model only needs the full guidance for specific tasks. |

## 스킬 형식 {/* #skill-formats */}

Mastra는 세 가지 파일 기반 기술 형식을 지원합니다.

| 형식 | 다음과 같은 경우에 사용하세요 |
| - | - |
| TypeScript/JavaScript 모듈 | 기본 내보내기를 원합니다.[`createSkill()`](/reference/agents/createSkill) result from code. |
| Packaged `SKILL.md` directory | The skill has instructions plus supporting files under `references/`. |
| Flat markdown file | The skill is one markdown file with frontmatter and instructions. |

패키지 스킬의 경우,`description` is required in `SKILL.md` frontmatter. Flat markdown skills also require `description` in frontmatter. Write when to use the skill, not only what the skill contains.

## 로드되는 내용 {/* #what-gets-loaded */}

파일 기반 Agent 기술은 빌드 시 생성된 번들에 추가되므로 배포된 Agent는 디스크에서 해당 기술을 읽지 않습니다.

패키지 기술에 대해 Mastra는 다음과 같이 말합니다.

* `SKILL.md`메타데이터 및 지침을 확인하세요.
* 바로 아래의 파일`references/` as supporting reference content.

참조 파일은 파일 이름으로 입력됩니다. 아래의 심볼릭 링크된 파일 및 디렉터리`references/` are skipped during discovery.

## 구성 우선순위 {/* #precedence-with-config */}

발견한 기술은 어떤 기술과도 병합됩니다.`skills` in [`config.ts`](/reference/file-based-agents/config). On a name collision, `config.skills` wins and a warning is logged.

만약에`config.skills` is a function, discovered skills are ignored with a warning because function-valued skills can't be statically merged.
