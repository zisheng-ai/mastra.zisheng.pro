# 프로세서

파일 기반 Agent가 검색합니다.[processors](/docs/agents/processors)그로부터`processors/`예배 규칙서. 파일 기반 규칙을 보려면 이 페이지를 사용하십시오. 내장 프로세서, 맞춤형 프로세서, 스트리밍 동작 및 고급 패턴에 대한 프로세서 가이드를 사용하세요.

아래의 파일`processors/input/` run before messages reach the model. Files under `processors/output/` run after the model responds. Each file default-exports one [`Processor`](/reference/processors/processor-interface), 파일 이름이 검색 키가 됩니다.

## 빠른 시작 {/* #quickstart */}

아래에 프로세서 파일을 배치하여 입력 프로세서를 추가합니다.`processors/input/`:

```typescript title="src/mastra/agents/weather/processors/input/pii.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'block',
})
```

이 프로세서는 사용자 메시지가 Model에 도달하기 전에 실행됩니다.

## 출력 프로세서 추가 {/* #add-an-output-processor */}

출력 프로세서는 Model 응답이 반환되기 전에 필터링하거나 변환하는 데 적합합니다. 이 예에서는 최종 응답에서 PII를 수정합니다.

```typescript title="src/mastra/agents/weather/processors/output/redact.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'redact',
})
```

## 주문 {/* #ordering */}

검색된 프로세서는 다음에 정의된 프로세서 뒤에 추가됩니다.[`config.ts`](/reference/file-based-agents/config). That means config processors run first.

```text title="Ordering"
config.inputProcessors → processors/input/* → model
model → config.outputProcessors → processors/output/* → response
```

만약에`config.inputProcessors` or `config.outputProcessors` is a function, discovered processors of that type are ignored with a warning because function-valued processors can't be statically merged.

## 구성 우선순위 {/* #precedence-with-config */}

사용`config.ts` for processors that need to be created at runtime or shared across agents. Use file-based processors for static, per-agent processors that should be reviewed alongside the agent.

우선순위는 다음과 같습니다.

1. 함수 가치`config.inputProcessors` or `config.outputProcessors`
2. 배열 값`config.inputProcessors` or `config.outputProcessors`
3. 다음 위치에서 발견된 파일`processors/input/` or `processors/output/`

방문[`Processor` reference](/reference/processors/processor-interface) for the full interface.
