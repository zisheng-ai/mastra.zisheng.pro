# 작업공간

에이[workspace](/docs/workspace/overview)Agent 파일 시스템 액세스 및 명령 실행을 제공합니다. 파일 기반 Agent는 다음을 통해 검색되면 자동으로 기본 작업 공간을 얻습니다.`mastra dev`또는`mastra build`, 추가 구성 없이 파일을 읽고 쓸 수 있으며 셸 명령을 실행할 수 있습니다.

파일 기반 규칙에 대해서는 이 페이지를 사용하십시오. 작업 영역 공급자, Tool, 검색, 수명 주기 및 샌드박스 세부 정보는 다음을 참조하세요.[Workspaces](/docs/workspace/overview).

## 기본 작업공간 {/* #default-workspace */}

없이`workspace.ts`, a file-based agent gets a default [`Workspace`](/reference/workspace/workspace-class) when the build provides a per-agent workspace path. The default workspace uses:

* [`LocalFilesystem`](/reference/workspace/local-filesystem)Agent의 번들 작업 공간 디렉터리에 루트가 있습니다.
* [`LocalSandbox`](/reference/workspace/local-sandbox)동일한 작업 디렉토리를 사용합니다.

그러면 Agent 파일 Tool와 셸 Tool가 자동으로 제공됩니다. 기본 작업 영역은 Agent별로 이루어집니다. 하위 Agent는 상위 Agent의 작업 영역 경로 아래에 중첩된 작업 영역 디렉터리를 가져옵니다.

## 빠른 시작 {/* #quickstart */}

기본 작업공간의 경우 파일을 추가하지 마세요. 다음과 같은 Agent 디렉터리로 시작하세요.

```text title="Default workspace"
src/mastra/agents/weather/
├── config.ts
└── instructions.md
```

추가하다`workspace.ts` only when you need to customize the workspace:

```typescript title="src/mastra/agents/weather/workspace.ts"
import { Workspace, LocalFilesystem, LocalSandbox } from '@mastra/core/workspace'

export default new Workspace({
  name: 'weather-workspace',
  filesystem: new LocalFilesystem({ basePath: './data/weather' }),
  sandbox: new LocalSandbox({ workingDirectory: './data/weather' }),
})
```

방문[`Workspace` reference](/reference/workspace/workspace-class) for the full config.

## 작업공간을 사용자 정의해야 하는 경우 {/* #when-to-customize-the-workspace */}

기본 로컬 디렉토리가 충분하지 않은 경우 작업공간을 사용자 정의하십시오. 일반적인 이유는 다음과 같습니다.

* 다른 파일 시스템 루트에 있는 포인트 파일 Tool.
* 다른 샌드박스 공급자에서 셸 명령을 실행합니다.
* BM25 또는 벡터 검색으로 작업공간 검색을 추가하세요.
* 여러 Agent가 하나의 작업 공간을 공유합니다.

공급자 패턴 및 런타임 동작은 다음을 참조하세요.[workspace overview](/docs/workspace/overview), [sandbox guide](/docs/workspace/sandbox), and [workspace search](/docs/workspace/search).

## 런타임 경계 {/* #runtime-boundary */}

작업 공간 파일 시스템은 Tool가 읽고 쓸 수 있는 파일을 제어합니다. 샌드박스는 셸 명령이 실행되는 위치를 제어합니다. 코드를 포함한 애플리케이션 런타임 코드[`tools/`](/reference/file-based-agents/tools), still runs in your app/server process unless it explicitly calls workspace or sandbox APIs.

## 시드 파일 {/* #seed-files */}

추가`workspace/` directory to include starting files with the agent. Mastra mirrors files under `workspace/` into the agent's default runtime workspace at build time, so the agent starts with those files on disk.

```text title="Seed files"
src/mastra/agents/weather/
├── config.ts
└── workspace/
    ├── README.md
    └── data/
        └── cities.json
```

파일은 작업 공간 파일 Tool와 샌드박스 명령이 읽을 수 있는 번들 작업 공간 경로에 복사됩니다. 미러링 중에는 Symlinked 시드 파일을 건너뜁니다.

## 구성 우선순위 {/* #precedence-with-config */}

`config.workspace`승리하다`workspace.ts`; otherwise the default file-based workspace is used. See [`config.ts` precedence](/reference/file-based-agents/config#precedence) for the full merge table.
