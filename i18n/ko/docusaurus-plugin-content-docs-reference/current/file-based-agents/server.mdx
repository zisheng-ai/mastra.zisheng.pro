# 섬기는 사람

Mastra는 HTTP를 구성합니다.[server](/docs/server/mastra-server)에서`server.ts`바로 아래 파일`src/mastra/`. 서버는 Agent, Workflow 및 기타 등록된 기본 요소를 REST 엔드포인트로 노출하고 파일은 기본적으로 동일한 항목을 내보냅니다.`ServerConfig`당신이 전달할 모양[`new Mastra()`](/reference/core/mastra-class).

파일 기반 규칙에 대해서는 이 페이지를 사용하십시오. 서버 기능, 미들웨어, 사용자 정의 경로, 생성된 API 문서 및 배포 동작에 대해서는 다음을 참조하세요.[Server overview](/docs/server/mastra-server).

## 빠른 시작 {/* #quickstart */}

만들다`src/mastra/server.ts` and default-export a `ServerConfig` object:

```typescript title="src/mastra/server.ts"
import type { ServerConfig } from '@mastra/core/server'

export default {
  port: 4111,
  host: '0.0.0.0',
} satisfies ServerConfig
```

## 일반적인 구성 {/* #common-configurations */}

`server.ts`코드 등록과 동일한 서버 옵션을 구성할 수 있습니다.

| 필요 | 사용 |
| - | - |
| 배포 플랫폼 주소에 바인딩 |`host` and `port` |
| Restrict browser access | `cors` |
| Add webhooks or health checks | `apiRoutes` |
| Enable generated API docs | `build.openAPIDocs` and `build.swaggerUI` |

보다[Mastra server](/docs/server/mastra-server), [middleware](/docs/server/middleware), and [custom API routes](/docs/server/custom-api-routes) for examples.

## 코드 우선순위 {/* #precedence-with-code */}

코드 등록된 서버 구성이 승리합니다.`server.ts`. Routes added during startup, such as channel webhooks, are preserved when file-based server config is applied.
