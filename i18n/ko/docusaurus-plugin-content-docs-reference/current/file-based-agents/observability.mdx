# Observability

마스트라 구성[observability](/docs/observability/overview)에서`observability.ts`바로 아래 파일`src/mastra/`. 파일은 기본적으로`Observability`프로젝트에 대한 추적, 로깅, 측정항목 및 피드백을 설정하는 인스턴스입니다.

파일 기반 규칙에 대해서는 이 페이지를 사용하십시오. 신호 Model, 내보내기, 저장소 및 다중 구성 설정에 대해서는 다음을 참조하세요.[observability overview](/docs/observability/overview) and [observability configuration](/docs/observability/overview#configuration).

## 빠른 시작 {/* #quickstart */}

만들다`src/mastra/observability.ts` and default-export an `Observability` instance:

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability 및 저장 {/* #observability-and-storage */}

`observability.ts`어떤 신호를 수집하고 어디로 내보낼지 구성합니다.[`storage.ts`](/reference/file-based-agents/storage) configures the project store that can persist observability records. For storage support by signal, see [observability signal support](/docs/observability/overview#signal-support).

## 코드 우선순위 {/* #precedence-with-code */}

코드 등록된 관측 가능성이 승리합니다`observability.ts`. Use `observability.ts` when one project-wide configuration is enough. Use code registration when setup depends on runtime wiring in `src/mastra/index.ts`.
