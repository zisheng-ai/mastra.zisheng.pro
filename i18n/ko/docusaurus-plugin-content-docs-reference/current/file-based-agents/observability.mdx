# Observability

마스트라 구성[observability](/docs/observability/overview)에서`observability.ts`바로 아래 파일`src/mastra/`. 파일은 기본적으로`Observability`프로젝트에 대한 추적, 로깅, 측정항목 및 피드백을 설정하는 인스턴스입니다.

파일 기반 규칙은 이 페이지를 참조하세요. 신호 Model, 내보내기, 스토리지 및 다중 구성 설정은 [Observability 개요](/docs/observability/overview)와 [Observability 구성](/docs/observability/overview#configuration)을 참조하세요.
## 빠른 시작 {/* #quickstart */}

`src/mastra/observability.ts`를 만들고 `Observability` 인스턴스를 기본 내보내기하세요.
```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability 및 저장 {/* #observability-and-storage */}

`observability.ts`는 수집할 신호와 내보낼 위치를 구성합니다. [`storage.ts`](/reference/file-based-agents/storage)는 Observability 레코드를 영구 저장할 수 있는 프로젝트 스토어를 구성합니다. 신호별 스토리지 지원 여부는 [Observability 신호 지원](/docs/observability/overview#signal-support)을 참조하세요.
## 코드 우선순위 {/* #precedence-with-code */}

코드로 등록한 Observability 구성이 `observability.ts`보다 우선합니다. 프로젝트 전체에서 하나의 구성으로 충분하면 `observability.ts`를 사용하세요. 설정이 `src/mastra/index.ts`의 런타임 연결에 따라 달라지면 코드 등록을 사용하세요.
