# 지침

Agent의 지시 사항에는 항상 켜져 있는 시스템 Prompt가 포함되어 있습니다. Model은 매 턴마다 이를 읽습니다. 이를 사용하여 Agent의 신원, 어조, 역할 및 입장 규칙을 정의합니다.

Agent 루트에 있는 두 파일 중 하나에 기록합니다. 사용`instructions.md` when the prompt is fixed text. Use `instructions.ts`Prompt에 코드가 필요한 경우(예: 공유 상수로 빌드되거나 요청에 따라 해결되는 경우)

지침은 항상 상황에 맞게 작성되므로 모든 요청에 ​​적용되는 안정적인 동작을 위해 지침을 유지하세요. 조건부, 대규모 또는 작업 지향적인 항목을[`tools/`](/reference/file-based-agents/tools) or [`skills/`](/reference/file-based-agents/skills), which the model uses only when relevant.

## 빠른 시작 {/* #quickstart */}

추가`instructions.md` at the agent root. Whatever you write becomes the prompt, so the shortest version is a single sentence.

```markdown title="src/mastra/agents/weather/instructions.md"
You are a helpful weather assistant. Answer questions about current conditions and forecasts.
```

## 지침에 들어가는 내용 {/* #what-goes-in-instructions */}

효과적인 지침은 요청 간에 변경되지 않는 Agent 동작의 일부를 다룹니다.

* 역할과 정체성
* 톤과 스타일
* 상임 규칙
* 출력 형식

조건부, 대규모 또는 작업 중심 지침을[`tools/`](/reference/file-based-agents/tools) or [`skills/`](/reference/file-based-agents/skills), which the model uses only when relevant.

## TypeScript의 지침 {/* #instructions-in-typescript */}

사용`instructions.ts` when markdown can't express the prompt. The file default-exports a string, a system message, or a function returning one, and `agentInstructions()` types the export without changing it.

예를 들어 앱의 나머지 부분과 공유되는 상수에서 Prompt가 코드로 조합되면 문자열을 내보냅니다.

```typescript title="src/mastra/agents/weather/instructions.ts"
import { agentInstructions } from '@mastra/core/agent'
import { SUPPORTED_UNITS } from '../../constants'

export default agentInstructions(`
You are a helpful weather assistant.
Report conditions using one of these units: ${SUPPORTED_UNITS.join(', ')}.
`)
```

Prompt가 요청에 따라 달라지면 함수를 내보냅니다. Mastra는 매 턴마다 이를 호출하고 요청 컨텍스트를 전달합니다.

```typescript title="src/mastra/agents/support/instructions.ts"
import { agentInstructions } from '@mastra/core/agent'

export default agentInstructions(({ requestContext }) => {
  const tier = requestContext.get('tier') ?? 'standard'
  return `You are a support agent. Treat this as a ${tier}-tier customer.`
})
```

기능은 다음과 같습니다.`async` and receives `mastra` alongside `requestContext`, so it can read from storage or another registered primitive before returning the prompt.

두 파일 모두[subagent](/reference/file-based-agents/subagents) directory, which follows the same rules.

## 빌드 타임 동작 {/* #build-time-behavior */}

`instructions.md`그리고`instructions.ts` reach the deployed agent differently:

* `instructions.md`: Mastra는 파일을 읽고 빌드 시 생성된 코드에 해당 내용을 인라인합니다.
* `instructions.ts`: 생성된 코드는 모듈을 가져오므로 다른 TypeScript 파일처럼 번들로 제공되며 프로젝트의 나머지 부분에서 가져올 수 있습니다.

아래에`mastra dev`, editing either file triggers a rebuild. In a deployed app neither file is read from disk at runtime, so changes take effect after the next build.

## 구성 우선순위 {/* #precedence-with-config */}

지침은 다음에서 올 수 있습니다.`instructions.ts`, `instructions.md`, or the `instructions` field in [`config.ts`](/reference/file-based-agents/config):

* 런타임 정의(함수)`instructions` in `config.ts` wins over both files.
* 그렇지 않으면`instructions.ts` wins over `instructions.md`.
* `instructions.md`정적을 이긴다`instructions` string in `config.ts`.
* 아무것도 없으면 빌드가 실패하고 Agent 디렉터리의 이름이 지정됩니다.

여러 곳에서 지침을 정의하면 두 소스의 이름과 어느 소스가 승리하는지에 대한 경고가 기록됩니다. Agent당 하나의 소스를 유지하세요.
