# 득점자

파일 기반 Agent가 검색합니다.[scorers](/docs/evals/overview)그로부터`scorers/`예배 규칙서. 파일 기반 규칙을 보려면 이 페이지를 사용하십시오. 내장 채점기, 맞춤 채점기, 샘플링에 대해서는 채점기 가이드를 사용하세요.

아래의 각 파일`scorers/` default-exports one scorer, and the filename becomes its key. The default export is either a [`MastraScorer`](/reference/evals/create-scorer) or a `{ scorer, sampling }`기입.

## 빠른 시작 {/* #quickstart */}

Agent 아래에 파일을 배치하여 득점자를 추가하세요.`scorers/` directory. This example uses a [custom scorer](/docs/evals/custom-scorers):

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

export default createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)
```

득점자는 다음 사이트에 등록됩니다.`weather` agent under the key `relevance`, the same as adding it to `config.scorers`.

## 견본 추출 {/* #sampling */}

채점자가 실행되는 빈도를 제어하려면 기본 내보내기`{ scorer, sampling }` entry instead of a bare scorer:

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

const relevance = createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)

export default {
  scorer: relevance,
  sampling: { type: 'ratio', rate: 0.5 },
}
```

## 구성 우선순위 {/* #precedence-with-config */}

발견된 득점자는 다음에 정의된 득점자와 병합됩니다.[`config.ts`](/reference/file-based-agents/config). On a key collision, `config.scorers` wins with a warning. If `config.scorers` is a function, discovered scorers are ignored with a warning because function-valued scorers can't be statically merged.

키가 충돌할 때 우선순위는 다음과 같습니다.

1. 함수 가치`config.scorers`
2. 기록적인 가치`config.scorers`
3. 다음 위치에서 발견된 파일`scorers/`

충돌하지 않는 발견된 득점자는 보존됩니다.

방문하다[`createScorer()`](/reference/evals/create-scorer) for the full scorer interface.
