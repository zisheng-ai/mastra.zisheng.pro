# Netlify배포자

그만큼`NetlifyDeployer`클래스는 서버의 최적화된 버전을 만들기 위해 Mastra의 출력을 조정하여 패키징, 구성 및 배포를 처리합니다. 베이스를 확장해줍니다[`Deployer`](/reference/deployer/)Netlify 관련 기능을 갖춘 클래스입니다. 이를 통해 Netlify 서버리스 기능 또는 에지 기능 내에서 Mastra를 실행할 수 있습니다.

## 설치 {/* #installation */}

사용하려면`NetlifyDeployer`, you need to install the `@mastra/deployer-netlify` package:

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## 사용예 {/* #usage-example */}

수입`NetlifyDeployer` and set it as the deployer in your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## 생성자 옵션 {/* #constructor-options */}

* `target?: 'serverless' | 'edge'`: Netlify용 대상을 배포합니다. 기본값은`'serverless'`.
  * `'serverless'`: 기준[Netlify Functions](https://docs.netlify.com/functions/overview/) (Node.js runtime, 60s default timeout).
  * `'edge'`: [Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) (Deno-based runtime, runs at the edge closest to users, without a fixed timeout).

### 엣지 기능 예시 {/* #edge-functions-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## 산출 {/* #output */}

달리고 난 후`mastra build`, the deployer generates a `.netlify` folder. The build output includes all agents, tools, and workflows of your project, alongside a `config.json` file that configures the [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/).

### 서버리스 출력(기본값) {/* #serverless-output-default */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

그만큼`config.json` file contains:

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### 엣지 출력 {/* #edge-output */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

그만큼`config.json` file contains:

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
