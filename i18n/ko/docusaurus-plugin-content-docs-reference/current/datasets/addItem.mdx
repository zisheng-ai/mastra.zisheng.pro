# 데이터세트.추가항목()

**추가된 항목:** `@mastra/core@1.4.0`

데이터 세트에 단일 항목을 추가합니다. 각 항목에는 입력과 선택적인 Ground Truth가 있습니다. 메타데이터도 선택 사항입니다.

## 사용예 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

const item = await dataset.addItem({
  input: { question: 'What is TypeScript?' },
  groundTruth: { answer: 'A typed superset of JavaScript' },
  metadata: { source: 'manual' },
})

console.log(item.id)
```
