# 데이터 세트.startExperimentAsync()

**추가된 항목:** `@mastra/core@1.4.0`

실험을 비동기적으로 시작합니다(Fire-and-forget). 실험 ID와 `'pending'` 상태를 즉시 반환합니다. 실험은 백그라운드에서 실행됩니다.
## 사용 예시 {/* #usage-example */}
```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
console.log(`Current status: ${experiment.status}`)
```

## 매개변수 {/* #parameters */}

[`dataset.startExperiment()`](/reference/datasets/startExperiment)과 동일한 `StartExperimentConfig`를 받습니다.
`persistence.experiments`가 `'none'`으로 설정되면 `startExperimentAsync()`는 실험 레코드, 진행 상황 업데이트 또는 항목 결과를 영속화하지 않습니다. 점수 영속화는 `persistence.scores`로 별도로 제어됩니다. 실험 이벤트 관찰자가 없으면 실행은 Fire-and-forget 방식으로 진행되며, 실험 API는 완료 또는 실패 여부를 보고할 수 없습니다.
호출자에게 반환되는 요약이 필요한 경우 동기식 [`startExperiment()`](/reference/datasets/startExperiment)을 사용하세요. 실험 이벤트 관찰자는 수명 주기 이벤트와 최종 요약을 받을 수 있습니다.
