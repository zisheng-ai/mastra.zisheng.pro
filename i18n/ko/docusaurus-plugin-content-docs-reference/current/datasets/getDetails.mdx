# 데이터세트.getDetails()

**추가된 항목:** `@mastra/core@1.4.0`

메타데이터, 스키마, 버전 정보를 포함하여 스토리지에서 전체 데이터 세트 레코드를 검색합니다.

## 사용예 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 사용하지 않습니다.

## 보고 {/* #returns */}

`Promise<DatasetRecord>`를 반환합니다. 데이터 세트를 찾을 수 없으면 `MastraError`를 던집니다.
