# 직렬화된 Memory 구성

`SerializedMemoryConfig`JSON 직렬화 가능한 하위 집합입니다.[`Memory`](/reference/memory/memory-class)저장된 Agent 기록에 있는 구성입니다. 런타임은 이를 다시 수화합니다.`Memory`구성된 인스턴스에 대해 벡터 및 임베더 ID를 확인하여 인스턴스`Mastra`사례.

[`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 및 `EditorAgentNamespace.create({ memory })`에서 사용하는 타입입니다.
## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
