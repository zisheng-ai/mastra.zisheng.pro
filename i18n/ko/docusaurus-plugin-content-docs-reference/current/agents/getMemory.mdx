# Agent.getMemory()

그만큼`.getMemory()`메소드는 Agent와 연관된 Memory 시스템을 검색합니다. 이 방법은 대화 전반에 걸쳐 정보를 저장하고 검색하기 위해 Agent의 Memory 기능에 액세스하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getMemory()
```
