# Agent.getDefaultGenerateOptionsLegacy()

:::경고

**더 이상 사용되지 않음**: 이 방법은 더 이상 사용되지 않으며 V1 Model에서만 작동합니다. V2 Model의 경우 새로운[`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

Model 동작, 출력 형식, Tool 및 Workflow 호출을 제어하기 위한 기본 생성 옵션을 사용하여 Agent를 구성할 수 있습니다. 그만큼`.getDefaultGenerateOptionsLegacy()` method retrieves these defaults, resolving them if they're functions. These options apply to all `generateLegacy()` calls unless overridden and are useful for inspecting an agent’s unknown defaults.

## 사용예 {/* #usage-example */}

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
