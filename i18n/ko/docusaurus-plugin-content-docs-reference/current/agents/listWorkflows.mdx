# Agent.listWorkflows()

그만큼`.listWorkflows()`메서드는 Agent에 대해 구성된 Workflow를 검색하여 해당 Workflow가 기능인지 확인합니다. 이러한 Workflow를 통해 Agent는 정의된 실행 경로를 사용하여 복잡한 다단계 프로세스를 실행할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
