# Agent.listAgent()

그만큼`.listAgents()`메서드는 Agent에 대해 구성된 하위 Agent를 검색하여 함수인 경우 이를 확인합니다. 이러한 하위 Agent를 사용하면 Agent가 다른 Agent에 액세스하고 복잡한 작업을 수행할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.listAgents()
```
