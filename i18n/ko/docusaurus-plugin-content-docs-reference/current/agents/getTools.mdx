# Agent.getTools()

그만큼`.getTools()`메서드는 Agent에 대해 구성된 Tool를 검색하여 해당 Tool가 기능인지 확인합니다. 이러한 Tool는 Agent의 기능을 확장하여 특정 작업을 수행하거나 외부 시스템에 액세스할 수 있도록 합니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getTools()
```
