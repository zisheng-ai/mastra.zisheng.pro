# Agent.getLLM()

그만큼`.getLLM()`메서드는 Agent에 대해 구성된 언어 Model 인스턴스를 검색하여 함수인 경우 이를 확인합니다. 요청 범위를 전달할 수도 있습니다.`model`Agent의 구성된 Model을 변경하지 않고 재정의합니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
