# Agent.getInstructions()

그만큼`.getInstructions()`메서드는 Agent에 대해 구성된 지침을 검색하여 해당 지침이 기능인 경우 해결합니다. 이러한 지침은 Agent의 동작을 안내하고 해당 기능과 제약 조건을 정의합니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
