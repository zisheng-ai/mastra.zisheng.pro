# Agent.네트워크()

그만큼`.network()`방법을 사용하면 다중 Agent 협업 및 라우팅이 가능합니다. 이 메서드는 메시지와 선택적 실행 옵션을 허용합니다.

:::warning\[사용되지 않음]

`.network()` primitive은 더 이상 사용되지 않으며 향후 메이저 릴리스에서 제거될 예정입니다. 대신 `agent.stream()` 또는 `agent.generate()`와 함께 [supervisor Agent](/docs/capabilities/subagents)를 사용하세요. 업그레이드하려면 [마이그레이션 가이드](/guides/migrations/network-to-supervisor)를 참고하세요.
:::

## 사용예 {/* #usage-example */}

```typescript
import { Agent } from '@mastra/core/agent'
import { agent1, agent2 } from './agents'
import { workflow1 } from './workflows'
import { tool1, tool2 } from './tools'

const agent = new Agent({
  id: 'network-agent',
  name: 'Network Agent',
  instructions: 'You are a network agent that can help users with a variety of tasks.',
  model: '__GATEWAY_OPENAI_MODEL__',
  agents: {
    agent1,
    agent2,
  },
  workflows: {
    workflow1,
  },
  tools: {
    tool1,
    tool2,
  },
})

await agent.network(`
  Find me the weather in Tokyo.
  Based on the weather, plan an activity for me.
`)
```

## 구조화된 출력 {/* #structured-output */}

네트워크에서 타입이 지정되고 검증된 결과가 필요하면 `structuredOutput` 옵션을 사용하세요. 네트워크는 작업 완료 후 스키마와 일치하는 응답을 생성합니다.
```typescript
import { z } from 'zod'

const resultSchema = z.object({
  summary: z.string().describe('A brief summary of the findings'),
  recommendations: z.array(z.string()).describe('List of recommendations'),
  confidence: z.number().min(0).max(1).describe('Confidence score'),
})

const stream = await agent.network('Research AI trends and summarize', {
  structuredOutput: {
    schema: resultSchema,
  },
})

// Consume the stream
for await (const chunk of stream) {
  // Handle streaming events
}

// Get the typed result
const result = await stream.object
// result is typed as { summary: string; recommendations: string[]; confidence: number }
console.log(result?.summary)
console.log(result?.recommendations)
```

### 부분 개체 스트리밍 {/* #streaming-partial-objects */}

생성되는 부분 객체를 스트리밍할 수도 있습니다.

```typescript
const stream = await agent.network('Analyze data', {
  structuredOutput: { schema: resultSchema },
})

// Stream partial objects
for await (const partial of stream.objectStream) {
  console.log('Partial result:', partial)
}

// Get final result
const final = await stream.object
```

### 청크 유형 {/* #chunk-types */}

구조화된 출력을 사용하는 경우 추가 청크 유형이 방출됩니다.

* `network-object`: 스트리밍 중에 부분 개체와 함께 방출됩니다.
* `network-object-result`: 최종 구조화된 객체와 함께 방출됨

## 네트워크 중단 {/* #aborting-a-network */}

실행 중인 네트워크를 취소하려면 `abortSignal`을 사용하세요. 중단되면 네트워크가 라우팅을 멈추고 진행 중인 모든 subagent, Tool 또는 Workflow 실행을 취소하며 부분 결과를 Memory에 저장하지 않습니다.
```typescript
const controller = new AbortController()

// Abort after 30 seconds
setTimeout(() => controller.abort(), 30_000)

const stream = await agent.network('Research this topic thoroughly', {
  abortSignal: controller.signal,
  onAbort: ({ primitiveType, primitiveId, iteration }) => {
    console.log(`Aborted ${primitiveType} "${primitiveId}" at iteration ${iteration}`)
  },
})

for await (const chunk of stream) {
  if (
    chunk.type === 'routing-agent-abort' ||
    chunk.type === 'agent-execution-abort' ||
    chunk.type === 'tool-execution-abort' ||
    chunk.type === 'workflow-execution-abort'
  ) {
    console.log('Network was aborted')
  }
}
```
