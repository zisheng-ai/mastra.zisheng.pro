# Agent.getDefaultStreamOptionsLegacy()

:::warning

**더 이상 사용되지 않음**: 이 방법은 더 이상 사용되지 않으며 V1 Model에서만 작동합니다. V2 Model의 경우 새로운[`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

Memory 사용 및 출력 형식에 대한 기본 스트리밍 옵션으로 Agent를 구성할 수 있습니다. 반복 단계도 구성할 수 있습니다. `.getDefaultStreamOptionsLegacy()` 메서드는 이러한 기본값을 반환하며, 함수인 경우 이를 해석합니다. 별도로 재정의하지 않는 한 이 옵션은 모든 `streamLegacy()` 호출에 적용되며, Agent의 알 수 없는 기본값을 검사할 때 유용합니다.
## 사용예 {/* #usage-example */}

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
