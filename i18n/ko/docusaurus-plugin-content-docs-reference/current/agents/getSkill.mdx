# `.getSkill()`

Agent의 구성된 기술(Agent 수준 및 작업 영역 기술 모두)에서 이름으로 특정 기술을 검색합니다.

## 사용예 {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skill = await agent.getSkill('code-review')

if (skill) {
  console.log(skill.name) // "code-review"
  console.log(skill.description) // "Use when reviewing code changes."
  console.log(skill.instructions) // Full markdown instructions
}
```

## 반환 값 {/* #return-value */}

보고`Promise<Skill | null>`.

다음을 반환합니다.`Skill` object if found, or `null` if no skill with that name exists.

```typescript
interface Skill {
  name: string
  description: string
  instructions: string
  path: string
  source: { type: string; projectPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: string[]
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## 병합 동작 {/* #merging-behavior */}

Agent 수준 기술과 작업 영역 기술이 모두 구성된 경우`.getSkill()` searches the merged set. Agent-level skills take precedence on name conflicts.
