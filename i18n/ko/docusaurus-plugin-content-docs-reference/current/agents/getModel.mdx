# Agent.getModel()

그만큼`.getModel()`메서드는 Agent에 대해 구성된 언어 Model을 검색하여 함수인 경우 이를 확인합니다. 이 방법은 Agent의 기능을 강화하는 기본 Model에 액세스하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getModel()
```
