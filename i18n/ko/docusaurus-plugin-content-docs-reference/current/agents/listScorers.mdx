# Agent.listScorers()

그만큼`.listScorers()`메서드는 Agent에 구성된 점수 구성을 검색하여 함수인 경우 이를 해결합니다. 이 방법은 Agent 응답 및 성과를 평가하는 데 사용되는 채점 시스템에 대한 액세스를 제공합니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.listScorers()
```
