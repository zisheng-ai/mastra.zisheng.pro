# Agent.getDefaultOptions()

Memory 사용량 및 출력 형식에 대한 기본 옵션을 사용하여 Agent를 구성할 수 있습니다. 반복 단계도 구성할 수 있습니다. 그만큼`.getDefaultOptions()`메소드는 이러한 기본값을 반환하고, 함수인 경우 이를 확인합니다. 이 옵션은 모두에 적용됩니다.`stream()`그리고`generate()`재정의되지 않는 한 호출하며 Agent의 알 수 없는 기본값을 검사하는 데 유용합니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
