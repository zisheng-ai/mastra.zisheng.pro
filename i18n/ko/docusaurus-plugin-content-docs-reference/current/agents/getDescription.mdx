# Agent.getDescription()

그만큼`.getDescription()`메소드는 Agent에 대해 구성된 설명을 검색합니다. 이 메서드는 Agent의 목적과 기능을 설명하는 문자열 설명을 반환합니다.

## 사용예 {/* #usage-example */}

```typescript
agent.getDescription()
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 사용하지 않습니다.
