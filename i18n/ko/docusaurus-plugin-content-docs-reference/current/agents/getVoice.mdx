# Agent.getVoice()

그만큼`.getVoice()`메소드는 Agent에 대해 구성된 음성 제공자를 검색하여 기능인 경우 이를 확인합니다. 이 방법은 텍스트 음성 변환 및 음성 텍스트 변환 기능을 위한 Agent의 음성 기능에 액세스하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
await agent.getVoice()
```
