# MastraAuthOkta 및 MastraRBACokta 클래스

## MastraAuthOkta 클래스 {/* #mastraauthokta-class */}

그만큼`MastraAuthOkta` class provides authentication for Mastra using Okta. It implements an OAuth 2.0 / OIDC login flow with encrypted session cookies and integrates with the Mastra server using the `auth`옵션.

### 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta({
      domain: process.env.OKTA_DOMAIN,
      clientId: process.env.OKTA_CLIENT_ID,
      clientSecret: process.env.OKTA_CLIENT_SECRET,
      redirectUri: process.env.OKTA_REDIRECT_URI,
    }),
  },
})
```

:::메모

필수 환경 변수가 설정된 경우 생성자 매개변수를 생략할 수 있습니다. 그런 경우에는`new MastraAuthOkta()` without any arguments.

:::

### 인증 흐름 {/* #authentication-flow */}

`MastraAuthOkta`다음 순서로 요청을 인증합니다.

1. **세션 쿠키**: 암호화된 세션 쿠키를 읽고 해독합니다. 세션이 유효하고 만료되지 않은 경우 사용자가 인증됩니다.
2. **JWT 대체**: 세션 쿠키가 없으면`Authorization` header token against Okta's JWKS endpoint.

인증 후,`authorizeUser` checks that the user has a valid `oktaId`. Provide a custom `authorizeUser` function to implement additional logic.

## MastraRBACOkta 클래스 {/* #mastrarbacokta-class */}

그만큼`MastraRBACOkta` class maps Okta groups to Mastra permissions. It fetches user groups from the Okta API and resolves them against a configurable role mapping. Use it with `MastraAuthOkta` or any other auth provider.

:::메모

RBAC에는 유효한 Enterprise Edition 라이선스가 필요합니다. 개발 중에는 라이선스 없이 작동하므로 로컬에서 사용해 볼 수 있지만 프로덕션에는 라이선스가 필요합니다.[Contact sales](https://mastra.ai/contact) for more information.

:::

### 사용예 {/* #usage-example-1 */}

사용`MastraRBACOkta` alongside an auth provider by passing it to the `rbac` option:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta, MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta(),
    rbac: new MastraRBACOkta({
      roleMapping: {
        Admin: ['*'],
        Engineering: ['agents:*', 'workflows:*', 'tools:*'],
        Viewer: ['agents:read', 'workflows:read'],
        _default: [],
      },
    }),
  },
})
```

다른 인증 공급자와 함께 Okta RBAC를 사용하려면`getUserId` function to resolve the Okta user ID from the other provider's user object:

```typescript title="src/mastra/index.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'
import { MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
    rbac: new MastraRBACOkta({
      getUserId: user => user.metadata?.oktaUserId || user.email,
      roleMapping: {
        Engineering: ['agents:*', 'workflows:*'],
        Admin: ['*'],
        _default: [],
      },
    }),
  },
})
```
