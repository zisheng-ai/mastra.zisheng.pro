# 마스트라서버

그만큼`MastraServer`추상 클래스는 모든 서버 어댑터의 기본입니다. Hono 또는 Express 이외의 프레임워크용 어댑터를 만들려면 이 클래스를 확장하세요.

## 수입 {/* #import */}

```typescript
import { MastraServer } from '@mastra/server/server-adapter'
```

## 유형 매개변수 {/* #type-parameters */}

```typescript
MastraServer<TApp, TRequest, TResponse>
```

| 매개변수 | 설명 |
| - | - |
|`TApp` | Framework app type (e.g., `Hono`, `Application`) |
| `TRequest`| 프레임워크 요청 유형 |
|`TResponse`| 프레임워크 응답/컨텍스트 유형 |

## 건설자 {/* #constructor */}

```typescript prettier:false
constructor(options: MastraServerOptions<TApp>)
```

## 추상 메소드 {/* #abstract-methods */}

이러한 메서드는 어댑터로 구현되어야 합니다.

### `registerContextMiddleware()` {/* #registercontextmiddleware */}

모든 요청에 ​​Mastra 컨텍스트를 연결합니다.

```typescript prettier:false
abstract registerContextMiddleware(): void
```

**첨부할 컨텍스트:**

* `mastra`- 마스트라 인스턴스
* `requestContext`- 요청 범위 컨텍스트
* `tools`- 사용 가능한 Tool
* `abortSignal`- 취소 신호 요청

### `registerAuthMiddleware()` {/* #registerauthmiddleware */}

초기화 중에 어댑터 인증 후크를 실행합니다. 공식 어댑터는 인증이 경로별로 시행될 때 이를 무작동(no-op)으로 구현할 수 있습니다.

```typescript prettier:false
abstract registerAuthMiddleware(): void
```

### `registerRoute()` {/* #registerroute */}

프레임워크에 단일 경로를 등록합니다.

```typescript prettier:false
abstract registerRoute(
  app: TApp,
  route: ServerRoute,
  options: { prefix?: string }
): Promise<void>
```

### `getParams()` {/* #getparams */}

요청에서 매개변수를 추출합니다.

```typescript prettier:false
abstract getParams(
  route: ServerRoute,
  request: TRequest
): Promise<{
  urlParams: Record<string, string>;
  queryParams: Record<string, string>;
  body: unknown;
}>
```

### `sendResponse()` {/* #sendresponse */}

경로 유형에 따라 응답을 보냅니다.

```typescript prettier:false
abstract sendResponse(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

### `stream()` {/* #stream */}

스트리밍 응답을 처리합니다.

```typescript prettier:false
abstract stream(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

## 인스턴스 메소드 {/* #instance-methods */}

### `init()` {/* #init */}

모든 미들웨어와 경로를 등록하여 서버를 초기화합니다.

```typescript prettier:false
async init(): Promise<void>
```

순서대로 호출:

1. `registerContextMiddleware()`
2. `registerAuthMiddleware()`
3. `registerRoutes()`

### `registerRoutes()` {/* #registerroutes */}

모든 Mastra 경로를 등록하세요.

```typescript prettier:false
async registerRoutes(): Promise<void>
```

### `getApp()` {/* #getapp */}

프레임워크 앱 인스턴스를 가져옵니다.

```typescript prettier:false
getApp<T = TApp>(): T
```

### `parsePathParams()` {/* #parsepathparams */}

경로의 Zod 스키마를 사용하여 경로 매개변수의 유효성을 검사합니다.

```typescript prettier:false
async parsePathParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseQueryParams()` {/* #parsequeryparams */}

경로의 Zod 스키마를 사용하여 쿼리 매개변수의 유효성을 검사합니다.

```typescript prettier:false
async parseQueryParams(
  route: ServerRoute,
  params: Record<string, string>
): Promise<Record<string, unknown>>
```

### `parseBody()` {/* #parsebody */}

경로의 Zod 스키마를 사용하여 요청 본문의 유효성을 검사합니다.

```typescript prettier:false
async parseBody(
  route: ServerRoute,
  body: unknown
): Promise<unknown>
```

### `registerOpenAPIRoute()` {/* #registeropenapiroute */}

OpenAPI 사양을 제공하는 엔드포인트를 등록합니다.

```typescript prettier:false
async registerOpenAPIRoute(
  app: TApp,
  config: OpenAPIConfig,
  options: { prefix?: string }
): Promise<void>
```

### MCP옵션 {/* #mcpoptions */}

```typescript
interface MCPOptions {
  serverless?: boolean
  sessionIdGenerator?: () => string
}
```

| 부동산 | 설명 |
| - | - |
|`serverless` | When `true`, runs MCP in stateless mode without session management. Use for serverless environments like Cloudflare Workers or Vercel Edge. |
| `sessionIdGenerator` | Custom function to generate session IDs. |

  registerContextMiddleware(): void {
    this.app.use('*', (req, res, next) => {
      res.locals.mastra = this.mastra
      next()
    })
  }

  registerAuthMiddleware(): void {
    const auth = this.mastra.getServer()?.auth
    if (!auth) return
    // Register global auth middleware, or leave this empty and
