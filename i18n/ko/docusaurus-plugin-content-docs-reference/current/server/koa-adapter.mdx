# 코아 어댑터

그만큼`@mastra/koa`패키지는 Mastra를 실행하기 위한 서버 어댑터를 제공합니다.[코아](https://koajs.com). 일반적인 어댑터 개념(생성자 옵션, 초기화 흐름 등)은 다음을 참조하세요.[서버 어댑터](/docs/server/server-adapters).

## 설치 {/* #installation */}

Koa 어댑터와 Koa 프레임워크를 설치합니다.

```bash npm2yarn
npm install @mastra/koa@latest koa koa-bodyparser
```

## 사용예 {/* #usage-example */}

```typescript title="server.ts"
import Koa from 'koa'
import bodyParser from 'koa-bodyparser'
import { MastraServer } from '@mastra/koa'
import { mastra } from './mastra'

const app = new Koa()
app.use(bodyParser())

const server = new MastraServer({ app, mastra })

await server.init()

app.listen(3000, () => {
  console.log('Server running on http://localhost:3000')
})
```

## 오류 처리 {/* #error-handling */}

Koa 어댑터는 Koa의 표준 오류 처리 패턴에 따라 경로 핸들러의 오류를 Koa의 미들웨어 체인을 통해 전파합니다. 이는 일반 Koa 오류 처리 미들웨어를 사용할 수 있음을 의미합니다.

```typescript title="server.ts"
const app = new Koa()
app.use(bodyParser())

// Your error middleware catches errors from Mastra route handlers
app.use(async (ctx, next) => {
  try {
    await next()
  } catch (err) {
    ctx.status = err.status || 500
    ctx.body = { error: err.message }
    // Log, report to Sentry, etc.
  }
})

const server = new MastraServer({ app, mastra })
await server.init()
```

[`server.onError`](/reference/configuration#serveronerror) 훅도 지원됩니다. 구성하면 오류가 미들웨어로 전파되기 전에 호출되며, 훅의 응답이 직접 사용됩니다.
```typescript title="src/mastra/index.ts"
const mastra = new Mastra({
  server: {
    onError: (err, c) => {
      console.error('Unhandled error:', err)
      return c.json({ error: err.message }, 500)
    },
  },
})
```

`init()`을 사용하면 전역 오류 처리 미들웨어도 안전망으로 등록됩니다. 이 미들웨어에 도달한 오류는 표준 Koa 규칙에 따라 `ctx.app.emit('error', err, ctx)`를 통해 방출됩니다.
## 원시 경로 보호 {/* #protecting-raw-routes */}

`requiresAuth` 같은 Mastra 관리 인증 및 경로 메타데이터가 필요하다면 [`registerApiRoute()`](/reference/server/register-api-route)를 사용하는 것이 좋습니다. 앱에 직접 마운트된 원시 Koa 경로에는 `createAuthMiddleware()`를 사용하세요.
```typescript title="server.ts"
import Koa from 'koa'
import { createAuthMiddleware, MastraServer } from '@mastra/koa'
import { mastra } from './mastra'

const app = new Koa()
const server = new MastraServer({ app, mastra })

await server.init()

app.use(createAuthMiddleware({ mastra }))
app.use(async ctx => {
  if (ctx.path !== '/custom/protected') return

  const user = ctx.state.requestContext.get('user')
  ctx.body = { user }
})
```
