# MastraEditor 클래스

그만큼`MastraEditor`클래스는 편집기 시스템을 설정합니다. 그것을 전달`Mastra`Prompt 블록, Agent 코드 재정의, 버전 관리, Tool 제공자와 같은 편집기 기능을 켜는 생성자입니다.

편집기의 기능에 대한 소개는 [Editor](/docs/editor/overview)를 참조하세요.
## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'

export const mastra = new Mastra({
  agents: {/* your agents */},
  editor: new MastraEditor(),
})
```

## Agent 빌더 {/* #agent-builder */}

`builder` 필드는 저장된 Agent를 만들고 편집할 수 있는 브라우저 기반 UI인 [Agent Builder](https://agent-builder.mastra.ai/)를 활성화합니다. 다음을 참조하세요.
* [Agent 빌더 개요](https://agent-builder.mastra.ai/): 개념 및 시작하기
* [AgentBuilder옵션](https://agent-builder.mastra.ai/reference/agent-builder-options): 전체 옵션 스키마.
* [BuilderAgentDefaults](https://agent-builder.mastra.ai/reference/builder-agent-defaults): 새 Agent에 대해 관리자가 고정한 기본값입니다.
* [빌더.구성.Agent.Model](https://agent-builder.mastra.ai/reference/builder-models): Model 허용 목록 및 기본 Model입니다.

### Builder Agent 등록 {/* #registering-the-builder-agent */}

Builder UI는 `@mastra/editor/ee`의 `createBuilderAgent()` 팩터리로 생성된 Agent에 대해 실행됩니다. 팩터리를 가져와 호출한 후 반환된 Agent를 Mastra 인스턴스의 `agents` 아래에 등록하세요.
```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'
import { createBuilderAgent } from '@mastra/editor/ee'

export const mastra = new Mastra({
  agents: { builderAgent: createBuilderAgent() },
  editor: new MastraEditor({
    builder: { enabled: true },
  }),
})
```

키 이름(`builderAgent`)은 관례일 뿐이며 어떤 키든 사용할 수 있습니다. `@mastra/editor/ee` 하위 경로는 런타임에 Mastra Enterprise Edition 라이선스의 적용을 받습니다.
전체 설정 체크리스트는 [Agent Builder 개요](https://agent-builder.mastra.ai/#prerequisites)를 참조하세요.
## 네임스페이스 {/* #namespaces */}

### 원천 {/* #source */}

#### `getSource()` {/* #getsource */}

구성된 소스(`'code'` 또는 `'db'`)를 반환하며, 명시적인 `source` 없이 편집기를 생성한 경우에는 `undefined`를 반환합니다.
```typescript
const source = mastra.getEditor()?.getSource()
```

보고:`'code' | 'db' | undefined`

`source`를 생략하면 `getSource()`가 `undefined`를 반환하더라도 Editor는 구성된 데이터베이스 스토리지를 사용합니다. 스토리지 Workflow는 [Editor 스토리지 옵션](/docs/editor/overview#choose-where-changes-are-stored)을, 활성화 및 Git 기록 동작은 [코드 소스 버전 관리](/reference/editor/versioning#code-source)를 참조하세요.
