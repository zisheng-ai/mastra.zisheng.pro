# MastraEditor 클래스

그만큼`MastraEditor`클래스는 편집기 시스템을 설정합니다. 그것을 전달`Mastra`Prompt 블록, Agent 코드 재정의, 버전 관리, Tool 제공자와 같은 편집기 기능을 켜는 생성자입니다.

보다[Editor](/docs/editor/overview) for an introduction to what the editor does.

## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'

export const mastra = new Mastra({
  agents: {/* your agents */},
  editor: new MastraEditor(),
})
```

### Builder Agent 등록 {/* #registering-the-builder-agent */}

Builder UI는 다음에 의해 생성된 Agent에 대해 실행됩니다.`createBuilderAgent()` factory from `@mastra/editor/ee`. Import the factory, invoke it, and register the returned agent under `agents` on your Mastra instance:

```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'
import { createBuilderAgent } from '@mastra/editor/ee'

export const mastra = new Mastra({
  agents: { builderAgent: createBuilderAgent() },
  editor: new MastraEditor({
    builder: { enabled: true },
  }),
})
```

키 이름(`builderAgent`) is conventional. Any key works. The `@mastra/editor/ee` subpath is gated by the Mastra Enterprise Edition license at runtime.

참조[Agent Builder overview](https://agent-builder.mastra.ai/#prerequisites) for the full setup checklist.

### Agent 네임스페이스 예시 {/* #agent-namespace-examples */}

기존 코드 정의 Agent에 대한 저장된 재정의를 만듭니다.

```typescript title="src/scripts/seed-agent.ts"
import { mastra } from '../mastra'

const editor = mastra.getEditor()!

await editor.agent.create({
  id: 'support-agent',
  instructions: 'You are a friendly support agent for Acme.',
  tools: {
    search_kb: { description: 'Search the Acme knowledge base' },
  },
})
```

### 공급자 액세스 {/* #provider-access */}

const composio = mastra.getEditor()?.getToolProvider('composio')

등록된 모든 Blob 저장소 공급자를 반환합니다.

### 원천 {/* #source */}

#### `getSource()` {/* #getsource */}

구성된 소스를 반환합니다(`'code'` or `'db'`), or `undefined` when the editor was constructed without an explicit `source`.

```typescript
const source = mastra.getEditor()?.getSource()
```

보고:`'code' | 'db' | undefined`

언제`source` is omitted, Editor uses the configured database storage even though `getSource()` returns `undefined`. See [Editor storage options](/docs/editor/overview#choose-where-changes-are-stored) for the storage workflows and [code-source versioning](/reference/editor/versioning#code-source) for activation and Git history behavior.
