# Tool 제공자

그만큼`ToolProvider`인터페이스는 편집기가 외부 플랫폼에서 통합 Tool를 검색하고 해결하는 방법을 정의합니다. Mastra에는 두 가지 내장 구현이 포함되어 있습니다.`ComposioToolProvider`그리고`ArcadeToolProvider`.

보다[Editor tools](/docs/editor/overview#tools) for provider setup and the Studio workflow. See [tool configuration](/reference/editor/tools) for stored selections and resolution behavior.

## ComposioToolProvider {/* #composiotoolprovider */}

연결 대상[Composio](https://composio.dev) for access to hundreds of integration tools.

### 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { ComposioToolProvider } from '@mastra/editor/composio'

const editor = new MastraEditor({
  toolProviders: {
    composio: new ComposioToolProvider({
      apiKey: process.env.COMPOSIO_API_KEY!,
    }),
  },
})
```

### Tool 슬러그 {/* #tool-slugs */}

Composio Tool는 대문자 슬러그 형식을 사용합니다.`GITHUB_CREATE_ISSUE`, `SLACK_SEND_MESSAGE`.

### 입증 {/* #authentication */}

연결은 기본적으로 작성자별 범위를 사용합니다. 세트`defaultScope: 'caller-supplied'` to bucket authorization by the caller identity resolved from `MASTRA_RESOURCE_ID_KEY` in request context. Ensure each authenticated request provides a stable, unique resource ID. When using `MastraAuthWorkos`, configure `mapUserToResourceId` to set this value from the authenticated user.

### 연결 관리 Tool {/* #connection-management-tools */}

Composio는 Agent 채팅에서 승인을 시작하고 모니터링하기 위한 Tool를 제공합니다. 언제`allowedToolkits` is set, include `composio` to make these tools available:

```typescript title="src/mastra/index.ts"
const editor = new MastraEditor({
  toolProviders: {
    composio: new ComposioToolProvider({
      apiKey: process.env.COMPOSIO_API_KEY!,
      allowedToolkits: ['composio', 'gmail'],
      defaultScope: 'caller-supplied',
    }),
  },
})
```

Agent에 필요한 연결 관리 Tool만 추가하세요.

| Tool | 행동 |
| - | - |
|`COMPOSIO_MANAGE_CONNECTIONS` | Creates an authorization link in chat through a session owned by the caller. |
| `COMPOSIO_WAIT_FOR_CONNECTIONS` | Waits for the caller to finish authorization before the agent continues. |

`COMPOSIO_WAIT_FOR_CONNECTIONS`선택 사항입니다. 해당 정보가 없으면 승인을 완료하고 채팅으로 돌아갑니다. 그런 다음 Agent에게 계속하도록 요청하세요. 연결된 계정은 이후 요청을 위해 발신자 리소스 ID와 연결된 상태로 유지됩니다.

## 아케이드Tool공급자 {/* #arcadetoolprovider */}

연결 대상[Arcade](https://arcade.dev) for a curated tool catalog with built-in authentication.

### 사용예 {/* #usage-example-1 */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { ArcadeToolProvider } from '@mastra/editor/arcade'

const editor = new MastraEditor({
  toolProviders: {
    arcade: new ArcadeToolProvider({
      apiKey: process.env.ARCADE_API_KEY!,
    }),
  },
})
```

### Tool 슬러그 {/* #tool-slugs-1 */}

아케이드 Tool 사용`Toolkit.ToolName` format: `Github.GetRepository`, `Slack.SendMessage`.

### 입증 {/* #authentication-1 */}

레거시 아케이드 리졸버는 다음을 사용합니다.`resourceId` from request context when available. It otherwise falls back to the supplied `userId`, then to a shared `default` identity. Use `default` only for intentionally shared integrations. In tenant-isolated deployments, provide a trusted, stable `resourceId` or explicit `userId`. Omitting both doesn't isolate callers.
