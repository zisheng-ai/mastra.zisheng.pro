# 스토리지브라우저참조

`StorageBrowserRef`저장된 Agent에 연결된 인라인 브라우저 구성입니다. 그만큼`provider`ID는 수화 시간에 해결됩니다.[`BrowserProvider`](/reference/editor/browser-provider)등록된[`MastraEditor.browsers`](/reference/editor/mastra-editor).

사용하는 타입이에요[`BuilderAgentDefaults.browser`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) and by stored agent records.

## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { stagehandBrowserProvider } from '@mastra/stagehand'

new MastraEditor({
  browsers: { [stagehandBrowserProvider.id]: stagehandBrowserProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        browser: {
          type: 'inline',
          config: {
            provider: 'stagehand',
            headless: true,
            viewport: { width: 1280, height: 720 },
          },
        },
      },
    },
  },
})
```

## 유형 {/* #type */}

```typescript
type StorageBrowserRef = { type: 'inline'; config: StorageBrowserConfig }
```

에이`{ type: 'id' }` variant for browsers isn't available: they're always inlined.

## 수분 공급 {/* #hydration */}

`StorageBrowserRef`느리게 해결되었습니다`mastra.editor.agent.getById()`. The editor looks up `config.provider` on `MastraEditor.browsers` and calls `provider.createBrowser(config)`. If the provider isn't registered, the editor logs a warning and returns `undefined`: the agent still loads, but without a browser.
