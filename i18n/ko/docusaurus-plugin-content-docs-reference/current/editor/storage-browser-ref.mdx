# 스토리지브라우저참조

`StorageBrowserRef`저장된 Agent에 연결된 인라인 브라우저 구성입니다. 그만큼`provider`ID는 수화 시간에 해결됩니다.[`BrowserProvider`](/reference/editor/browser-provider)등록된[`MastraEditor.browsers`](/reference/editor/mastra-editor).

[`BuilderAgentDefaults.browser`](https://agent-builder.mastra.ai/reference/builder-agent-defaults)와 저장된 Agent 레코드에서 사용하는 유형입니다.
## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { stagehandBrowserProvider } from '@mastra/stagehand'

new MastraEditor({
  browsers: { [stagehandBrowserProvider.id]: stagehandBrowserProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        browser: {
          type: 'inline',
          config: {
            provider: 'stagehand',
            headless: true,
            viewport: { width: 1280, height: 720 },
          },
        },
      },
    },
  },
})
```

## 유형 {/* #type */}

```typescript
type StorageBrowserRef = { type: 'inline'; config: StorageBrowserConfig }
```

브라우저에는 `{ type: 'id' }` 변형을 사용할 수 없습니다. 브라우저는 항상 인라인됩니다.

## 수분 공급 {/* #hydration */}

`StorageBrowserRef`는 `mastra.editor.agent.getById()`에서 지연 해석됩니다. 편집기는 `MastraEditor.browsers`에서 `config.provider`를 조회하고 `provider.createBrowser(config)`를 호출합니다. Provider가 등록되지 않은 경우 편집기는 경고를 기록하고 `undefined`를 반환합니다. Agent는 계속 로드되지만 브라우저는 포함되지 않습니다.
