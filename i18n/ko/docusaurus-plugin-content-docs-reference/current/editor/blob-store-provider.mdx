# BlobStoreProvider

`BlobStoreProvider`Blob 저장소를 등록하기 위해 패키지가 구현하는 인터페이스입니다.[`MastraEditor`](/reference/editor/mastra-editor). Blob 저장소에는 콘텐츠 주소 지정이 가능한 기술 Blob과 편집자가 생성한 기타 대규모 아티팩트가 보관됩니다.

내장`storage` provider uses the configured storage backend's `blobs` domain. External providers (for example, S3) are supplied via `MastraEditorConfig.blobStores`.

## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { s3BlobStoreProvider } from '@mastra/s3'

new MastraEditor({
  blobStores: {
    [s3BlobStoreProvider.id]: s3BlobStoreProvider,
  },
})
```

## 공급자 구현 {/* #implementing-a-provider */}

```typescript title="src/providers/my-blob-store.ts"
import type { BlobStore, BlobStoreProvider } from '@mastra/core/editor'

export const myBlobStoreProvider: BlobStoreProvider<{ bucket: string; region: string }> = {
  id: 'my-blob-store',
  name: 'My Blob Store',
  description: 'Object-store-backed blob storage.',
  configSchema: {
    type: 'object',
    required: ['bucket', 'region'],
    properties: {
      bucket: { type: 'string' },
      region: { type: 'string' },
    },
  },
  async createBlobStore(config): Promise<BlobStore> {
    return createMyBlobStore({ bucket: config.bucket, region: config.region })
  },
}
```

아니오`providerId` is passed to `MastraEditor.resolveBlobStore()`, the editor falls back to the storage backend's `blobs` domain.
