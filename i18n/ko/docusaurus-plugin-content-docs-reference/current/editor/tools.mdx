# Tool 구성

편집기는 Tool 선택 사항을 Agent 버전의 일부로 저장합니다. 저장된 구성은 등록된 Tool, 통합 공급자의 Tool 및 MCP(Model Context Protocol) 클라이언트의 Tool를 추가할 수 있습니다.

보다[Editor tools](/docs/editor/overview#tools) for the Studio workflow and common uses.

## Tool 소스 {/* #tool-sources */}

| 소스 | 설명 |
| - | - |
| 등록된 Tool | Mastra 런타임 Tool 레지스트리에 등록된 Tool |
| MCP 클라이언트 | 저장된 로컬 또는 원격 MCP 서버 구성에 의해 노출되는 Tool |
| 통합 Tool | 레거시 통합 공급자 구성으로 해결된 Tool |
|[Tool providers](/reference/editor/tool-provider) | Tools resolved by providers registered on `MastraEditor`, such as Composio or Arcade |

코드 정의 Agent는 기존 Tool를 유지합니다. 그만큼[`editor` override setting](/reference/agents/agent#editor-overrides) controls whether Editor can add and remove tools or only change descriptions.

## 설명 재정의 {/* #description-overrides */}

선택한 각 Tool는 Agent별 설명을 저장할 수 있습니다. 설명은 원래 Tool 정의를 수정하지 않고 Model에 표시되는 내용을 변경합니다.

설명 전용 모드에서 편집기는 코드 정의 Agent에 이미 존재하는 Tool에만 재정의를 적용합니다. MCP Tool의 경우 Agent 수준 설명이 MCP 클라이언트에 저장된 설명보다 우선합니다.

두 소스가 동일한 Tool ID를 확인하는 경우 최신 소스가 해당 설명을 포함하여 이전 Tool 전체를 대체합니다. 보다[Resolution order](#resolution-order).

## 조건부 Tool 세트 {/* #conditional-tool-sets */}

편집기는 다음에 대한 조건부 변형을 저장할 수 있습니다.`tools`, `mcpClients`, `integrationTools`, and `toolProviders` fields. At runtime, matching variants are shallow-merged based on request-context values.

규칙 언어는 다음과 동일한 연산자 및 중첩 동작을 사용합니다.[prompt block display conditions](/reference/editor/prompt-blocks#display-conditions).

조건은 Tool 필드 변형 또는 MCP 클라이언트 참조에 적용됩니다. Tool별`rules` values in stored tool entries aren't evaluated by the current Editor resolver.

## 저장된 MCP 클라이언트 {/* #stored-mcp-clients */}

그만큼`editor.mcp` namespace manages reusable MCP client configurations. See the [`mcp` namespace](/reference/editor/mastra-editor#namespaces) for CRUD method signatures.

`@mastra/mcp`선택적 피어 종속성입니다.`@mastra/editor`. Install it before configuring stored MCP clients so Editor can load their tools at runtime:

```bash npm2yarn
npm install @mastra/mcp
```

### 교통수단 {/* #transports */}

| 교통 | 저장된 구성 |
| - | - |
|`stdio` | `command` with optional `args`, `env`, and `timeout` |
| HTTP | `url` with optional `timeout` |

저장된 HTTP 정의는 임의의 헤더를 허용하지 않습니다. 예약했을 때`mastra__authToken` value is present in request context, Editor forwards it as an `Authorization: Bearer` header.

### 필터링 {/* #filtering */}

MCP Tool는 두 가지 수준으로 허용 목록에 추가될 수 있습니다.

1. **서버 수준**: 저장된 서버의`tools` map limits tools for every agent that uses the client.
2. **Agent 수준**: Agent의 MCP 클라이언트 참조는 해당 Agent에 대한 나머지 Tool를 제한합니다.

Agent 수준 Tool 이름은 네임스페이스 이름 또는 기본 이름을 사용할 수 있습니다. 명시적인 비어 있음`tools` map selects all tools. With the current resolver, omitting `tools` from an agent-level MCP reference selects none.

### 네임스페이스 {/* #namespacing */}

MCP Tool 사용`serverName_toolName` IDs to avoid conflicts. A `search` tool from the `docs` server becomes `docs_search`.

## 해결 순서 {/* #resolution-order */}

편집기는 다음 순서로 Tool 기록을 병합합니다. 이후 레코드는 이전 레코드를 동일한 ID로 대체합니다.

1. 코드 정의 Tool
2. 등록된 저장 Tool
3. MCP Tool
4. 레거시 통합 Tool
5. V1 Tool 제공자 Tool

독립형 저장 Agent는 코드 정의 Tool 없이 동일한 순서를 사용합니다. 레거시 통합 Tool 이후 정적 코드 Agent 재정의가 중지됩니다.

가능하면 소스 전반에 걸쳐 고유한 Tool ID를 사용하십시오. 충돌은 해당 필드를 병합하는 대신 전체 이전 Tool를 대체합니다.
