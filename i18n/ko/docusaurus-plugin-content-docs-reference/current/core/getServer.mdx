# 마스트라.getServer()

그만큼`.getServer()`메소드는 Mastra 인스턴스에 구성된 서버 구성을 검색하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 허용하지 않습니다.
