# Mastra.getTelemetry()

그만큼`.getTelemetry()`메서드는 Mastra 인스턴스에 구성된 원격 측정 인스턴스를 검색하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.getTelemetry()
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 허용하지 않습니다.
