# Mastra.listLogs()

그만큼`.listLogs()`메서드는 특정 전송 ID에 대한 모든 로그를 검색하는 데 사용됩니다. 이 방법을 사용하려면 다음을 지원하는 구성된 로거가 필요합니다.`listLogs`작업.

## 사용예 {/* #usage-example */}

```typescript
mastra.listLogs('456')
```
