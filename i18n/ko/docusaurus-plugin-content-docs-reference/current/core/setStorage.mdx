# 마스트라.세트스토리지()

그만큼`.setStorage()`메소드는 Mastra 인스턴스에 대한 스토리지 인스턴스를 설정하는 데 사용됩니다. 이 방법은 단일을 허용합니다`MastraCompositeStore`매개변수.

## 사용예 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
