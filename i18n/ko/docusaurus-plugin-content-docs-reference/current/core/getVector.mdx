# 마스트라.getVector()

그만큼`.getVector()`메서드는 이름으로 벡터 저장소를 검색하는 데 사용됩니다. 이 방법은 단일을 허용합니다`string`벡터 저장소 이름에 대한 매개변수입니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```
