# 목록득점자()

그만큼`listScorers()`메소드는 Mastra 인스턴스에 등록된 모든 득점자를 반환합니다. 채점자는 AI 출력을 평가하는 데 사용되며 Agent 생성 또는 Workflow 실행 중에 기본 채점자를 재정의할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

// Get all registered scorers
const allScorers = mastra.listScorers()

// Access a specific scorer
const myScorer = allScorers.relevancyScorer
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 사용하지 않습니다.
