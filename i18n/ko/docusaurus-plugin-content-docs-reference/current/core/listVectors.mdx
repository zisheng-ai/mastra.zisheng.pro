# Mastra.listVectors()

그만큼`.listVectors()`메서드는 Mastra 인스턴스에 구성된 모든 벡터 저장소를 검색하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 허용하지 않습니다.
