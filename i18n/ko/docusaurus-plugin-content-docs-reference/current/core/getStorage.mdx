# 마스트라.getStorage()

그만큼`.getStorage()`메소드는 Mastra 인스턴스에 구성된 스토리지 인스턴스를 검색하는 데 사용됩니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## 매개변수 {/* #parameters */}

이 메서드는 매개변수를 허용하지 않습니다.
