# 마스트라.setLogger()

그만큼`.setLogger()`메서드는 Mastra 인스턴스의 모든 구성 요소(Agent, Workflow 등)에 대한 로거를 설정하는 데 사용됩니다. 이 메소드는 로거 속성이 있는 단일 객체 매개변수를 허용합니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
