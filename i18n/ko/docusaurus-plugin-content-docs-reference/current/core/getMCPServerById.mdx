# Mastra.getMCPServerById()

그만큼`.getMCPServerById()`메소드는 고유한 방식으로 MCP 서버 인스턴스를 검색합니다.`id`재산. 레지스트리 키(구성에 사용된 키)로 검색하려면 다음을 사용하세요.`.getMCPServer()`대신에.

## 사용예 {/* #usage-example */}

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by intrinsic ID
const server = mastra.getMCPServerById('my-mcp-server')

// Alternatively, retrieve by registry key
const serverByKey = mastra.getMCPServer('customKey')
```

## 메모 {/* #notes */}

* 서버의`id` is slugified during construction, so `'myMcpServer'` becomes `'my-mcp-server'`
* 여러 서버가 동일한 경우`id` but different versions, you must provide the `version` parameter to disambiguate
* 그렇지 않은 경우`version` is provided and multiple versions exist, the method returns the first match
