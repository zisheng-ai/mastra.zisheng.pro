# 마스트라.getAgent()

그만큼`.getAgent()`메서드를 사용하여 Agent를 검색합니다. 이 방법은 단일을 허용합니다`string`Agent 이름에 대한 매개변수입니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
