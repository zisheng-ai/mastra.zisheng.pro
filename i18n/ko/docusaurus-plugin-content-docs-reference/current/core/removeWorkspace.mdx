# Mastra.removeWorkspace()

그만큼`.removeWorkspace()`메소드는 Mastra 런타임 레지스트리에서 작업공간을 제거합니다. 통과하다`{ destroy: true }`작업 공간이 제거되기 전에 파괴합니다.

## 사용예 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 보고 {/* #returns */}

<PropertiesTable
  content={[
{
  name: 'removed',
  type: 'Promise<boolean>',
  description: '`true` when a workspace was removed. `false` when no workspace exists for the ID.',
},
]}

언제`destroy` is `true` and `workspace.destroy()` throws, the call rejects with that error and the workspace remains registered so the caller can retry cleanup.
