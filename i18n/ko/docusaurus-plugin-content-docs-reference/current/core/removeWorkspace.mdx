# Mastra.removeWorkspace()

그만큼`.removeWorkspace()`메소드는 Mastra 런타임 레지스트리에서 작업공간을 제거합니다. 통과하다`{ destroy: true }`작업 공간이 제거되기 전에 파괴합니다.

## 사용예 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 보고 {/* #returns */}

<PropertiesTable
  content={[
{
  name: 'removed',
  type: 'Promise<boolean>',

`destroy`가 `true`이고 `workspace.destroy()`에서 오류가 발생하면 호출은 해당 오류와 함께 거부되며, 호출자가 정리를 다시 시도할 수 있도록 Workspace는 등록된 상태로 유지됩니다.
