# Mastra.getWorkflow()

그만큼`.getWorkflow()`메서드는 등록 키로 Workflow를 검색하는 데 사용됩니다. 이 방법은 Workflow 입력 및 출력 스키마에 대한 전체 TypeScript 유형 추론을 제공합니다.

## 사용예 {/* #usage-example */}

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 유형 추론 {/* #type-inference */}

최상의 TypeScript 지원을 받으려면 Workflow의 **등록 키**(Mastra에 Workflow를 추가할 때 사용한 키)와 함께 `getWorkflow()`를 사용하세요. 그러면 다음 항목에 대해 완전한 타입 추론이 제공됩니다.
* 입력 데이터 스키마
* 출력 데이터 스키마
* 단계 결과

등록 키 대신 Workflow의 `id` 속성으로 검색해야 하는 경우 `getWorkflowById()`를 사용할 수 있지만, 타입 추론의 정확도가 떨어진다는 점에 유의하세요.
