# 마스트라.getAgentById()

그만큼`.getAgentById()`메소드는 등록된 Agent를 검색합니다.`id`. 먼저 등록된 Agent를 검색합니다.`agent.id`. 일치하는 Agent가 없으면 다음으로 대체됩니다.[`Mastra.getAgent()`](/reference/core/getAgent)제공된 값을 Agent 레지스트리 키로 처리합니다.

코드에 정의된 Agent를 가져오려면 `mastra.getAgentById(id)`를 사용합니다. 버전이 지정된 Agent를 가져오려면 `await mastra.getAgentById(id, version)`을 사용합니다.
## 사용예 {/* #usage-example */}

다음 예에서는 Agent를 등록하고 ID로 검색한 후 반환된 Agent를 사용합니다.

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
