# Mastra.listWorkflows()

그만큼`.listWorkflows()`메서드는 Mastra 인스턴스에 구성된 모든 Workflow를 검색하는 데 사용됩니다. 이 메서드는 선택적 옵션 개체를 허용합니다.

## 사용예 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```
