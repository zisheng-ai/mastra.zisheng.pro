# Slack공급자

`SlackProvider`Agent를 Slack에 연결하기 위한 관리 경로입니다. 등록하세요`Mastra.channels`매니페스트 API를 통해 Slack 앱을 프로비저닝하고, OAuth 설치 흐름을 실행하고, 구성 토큰을 순환하고, Slack 이벤트를 Agent에 라우팅합니다. Mastra가 앱 생성 및 설치를 소유하게 하려는 경우에 사용하세요. Slack 앱을 생성하고 범위 및 웹후크를 직접 구성하는 하위 수준 경로의 경우 다음을 사용합니다.[`createSlackAdapter`](/docs/capabilities/channels/slack)대리인의`channels.adapters`대신에.

## 사용예 {/* #usage-example */}

`Mastra` 생성자에 Provider를 등록하세요. 새로 고침 토큰은 일회용이며 시작 시 교체됩니다. 생성된 액세스 토큰은 `Mastra.storage`에 영구 저장됩니다.
```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  storage,
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

생성 시 자격 증명을 사용할 수 없는 경우(예: 편집기 UI를 통해 입력하거나 볼트에서 로드한 경우) 해당 자격 증명 없이 공급자를 구성하고 호출합니다.[`configure()`](#configurecredentials) later:

```typescript title="src/mastra/index.ts"
const slack = new SlackProvider()

await slack.configure({
  refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
})
```

## 행동 양식 {/* #methods */}

### Agent 연결 {/* #agent-connections */}

#### `connect(agentId, options?)` {/* #connectagentid-options */}

Manifest API를 통해 Agent용 새 Slack 앱을 생성하고, 사용자를 리디렉션할 인증 URL과 함께 OAuth 결과를 반환합니다. `baseUrl`이 설정되어 있어야 합니다. Agent에 대기 중인 설치가 이미 있으면 중복 앱을 생성하지 않고 기존 인증 URL을 반환합니다.
```typescript
const result = await slack.connect('support-agent', {
  name: 'Support Bot',
})

// Redirect the user to result.authorizationUrl to install the app
```

보고:`Promise<ChannelConnectResult>`

```typescript
interface ChannelConnectResult {
  type: 'oauth'
  installationId: string
  authorizationUrl: string
}
```

`SlackConnectOptions`직렬화 가능하며 저장된 Agent에 대해 저장할 수 있습니다.

#### `disconnect(agentId)` {/* #disconnectagentid */}

해당 앱을 삭제하고 스토리지에서 설치를 제거하여 Slack에서 Agent의 연결을 끊습니다.

```typescript
await slack.disconnect('support-agent')
```

보고:`Promise<void>`

#### `getInstallation(agentId)` {/* #getinstallationagentid */}

Agent의 Slack 설치를 반환하며, 설치가 없으면 `null`을 반환합니다.
```typescript
const installation = await slack.getInstallation('support-agent')
```

보고:`Promise<SlackInstallation | null>`

#### `listInstallations()` {/* #listinstallations */}

활성 및 보류 중을 포함하여 모든 Slack 설치(공개 정보만)를 나열합니다.

```typescript
const installations = await slack.listInstallations()
```

보고:`Promise<ChannelInstallationInfo[]>`

### 구성 {/* #configuration */}

#### `configure(credentials)` {/* #configurecredentials */}

런타임에 Slack 앱 구성 자격 증명을 제공하거나 지웁니다. 생성 시 자격 증명을 사용할 수 없는 경우 사용하세요. 자격 증명을 지우고 저장된 토큰을 삭제하려면 `null`을 전달하세요.
```typescript
// Provide credentials (persists to storage immediately)
await slack.configure({ refreshToken: 'xoxe-1-...' })

// Clear credentials and stored tokens
await slack.configure(null)
```

보고:`Promise<void>`

#### `setBaseUrl(baseUrl)` {/* #setbaseurlbaseurl */}

웹훅 및 OAuth 콜백에 사용되는 공개 기본 URL을 설정합니다. 생성 시 URL을 알 수 없고 서버 구성에서 자동 감지할 수 없는 경우 이 방법을 사용하세요.

```typescript
slack.setBaseUrl('https://abc123.trycloudflare.com')
```

#### `initialize()` {/* #initialize */}

저장소의 각 활성 설치에 대해 `SlackAdapter`를 다시 생성하고 해당 Agent에 `AgentChannels`를 주입하여 시작 시 Slack 이벤트를 수신하도록 합니다. 새 앱을 자동으로 프로비저닝하지는 않습니다. 앱을 생성하려면 `connect()`를 사용하세요. Mastra가 이를 자동으로 호출하므로 직접 호출할 일은 거의 없습니다.
```typescript
await slack.initialize()
```

보고:`Promise<void>`

## 공급자에 액세스 {/* #accessing-the-provider */}

등록할 때 사용한 ID를 키로 하는 `channels` getter를 통해 등록된 Provider에 접근합니다.
```typescript
const result = await mastra.channels.slack.connect('support-agent')
```

키가 런타임에만 알려진 경우 문자열 ID로 키를 찾고 구체적인 유형을 전달합니다.

```typescript
const slack = mastra.getChannelProvider<SlackProvider>('slack')
const result = await slack.connect('support-agent')
```

## 저장 요구 사항 {/* #storage-requirement */}

`SlackProvider`가 설치 및 교체되는 구성 토큰을 암호화하고 영구 저장하려면 `Mastra`에 영구 저장소가 필요합니다. 영구 저장소를 사용할 수 없고 사용자 정의 `storage`도 전달하지 않으면 생성자에서 오류가 발생합니다.
