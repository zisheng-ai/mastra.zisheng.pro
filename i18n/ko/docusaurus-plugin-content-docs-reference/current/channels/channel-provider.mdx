# 채널 제공자

`ChannelProvider`Agent를 메시징 플랫폼에 연결하기 위해 플랫폼 통합이 구현하는 인터페이스입니다. 공급자는 앱 프로비저닝 및 OAuth, 웹훅 라우팅 및 이벤트 처리, 어댑터 생성 및 Agent 연결, 자격 증명 관리 등 통합의 전체 수명주기를 소유합니다.

공급자를 등록하세요.`Mastra` constructor under `channels`, 선택한 ID로 입력됩니다. 각 공급자의 경로는 서버의 API 경로에 자동으로 병합됩니다.`initialize()`Mastra 시작 중에 실행됩니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_REFRESH_TOKEN!,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

공급자의`baseUrl` is the public URL the platform sends webhooks and events to. In production this is your deployed Mastra server URL. For local development, the platform can't reach `http://localhost:4111`, so run a tunnel (such as [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) or [ngrok](https://ngrok.com/)) 그리고 포인트`baseUrl`터널 URL에서(예:`https://abc123.trycloudflare.com`) 이벤트가 로컬 개발 프로세스에 도달하도록 합니다.

[`SlackProvider`](/reference/channels/slack-provider)최초의 내장 구현입니다. 이 인터페이스를 구현하여 사용자 정의 공급자를 구축합니다.

## 공급자에 액세스 {/* #accessing-a-provider */}

다음을 통해 등록된 Provider에 액세스하세요.`channels` getter, keyed by the id you registered it under. The getter is typed from the constructor config, so `mastra.channels.slack` is the concrete provider with its full method surface.

```typescript
await mastra.channels.slack.configure({ refreshToken })
```

키가 런타임에만 알려지면 대신 문자열 ID로 공급자를 찾으세요.`getChannelProvider` takes the concrete type as a generic, and `getChannelProviders` returns every registered provider keyed by id.

```typescript
import type { SlackProvider } from '@mastra/slack'

const slack = mastra.getChannelProvider<SlackProvider>('slack')
const all = mastra.getChannelProviders()
```
