# BatchParts프로세서

그만큼`BatchPartsProcessor`은**출력 프로세서**스트리밍 중 방출 빈도를 줄이기 위해 여러 스트림 부분을 함께 일괄 처리합니다. 이 프로세서는 네트워크 오버헤드를 줄이고, 작은 텍스트 청크를 통합하여 사용자 경험을 개선하고, 부분이 클라이언트에 내보내지는 시기를 제어하여 스트리밍 성능을 최적화하는 데 유용합니다.

## 사용예 {/* #usage-example */}

```typescript
import { BatchPartsProcessor } from '@mastra/core/processors'

const processor = new BatchPartsProcessor({
  batchSize: 5,
  maxWaitTime: 100,
  emitOnNonText: true,
})
```

## 확장된 사용 예 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/batched-agent.ts"
import { Agent } from '@mastra/core/agent'
import { BatchPartsProcessor } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'batched-agent',
  name: 'batched-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new BatchPartsProcessor({
      batchSize: 5,
      maxWaitTime: 100,
      emitOnNonText: true,
    }),
  ],
})
```
