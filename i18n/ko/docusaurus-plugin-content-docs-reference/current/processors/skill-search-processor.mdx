# SkillSearch 프로세서

그만큼`SkillSearchProcessor`은**입력 프로세서**이는 주문형 기술 검색 및 로딩을 가능하게 합니다. 모든 스킬 메타데이터를 시스템 Prompt에 미리 삽입하는 대신(예:`SkillsProcessor`), Agent에게 두 개의 메타 Tool(`search_skills`그리고`load_skill`) 필요에 따라 기술을 찾아 로드할 수 있습니다. 이렇게 하면 작업 영역에 많은 기술이 있는 경우 컨텍스트 토큰 사용량이 줄어듭니다.

기본적으로 첨부하는 경우에만`SkillSearchProcessor` to an agent with a skill-enabled `Workspace`, the agent treats skills as on-demand:

* 기본 열망`SkillsProcessor` isn't auto-added.
* `search_skills`그리고`load_skill` are exposed for discovery and instruction loading.
* 겹치는`skill` and `skill_search` tools are hidden.
* `skill_read`Agent이 참조, 스크립트, 자산과 같은 지원 기술 파일을 읽을 수 있도록 계속 사용 가능합니다.

명시적으로 구성하는 경우`SkillsProcessor` alongside `SkillSearchProcessor`, the agent preserves the eager `skill` and `skill_search` tools as an opt-in path.

## 사용예 {/* #usage-example */}

```typescript
import { SkillSearchProcessor } from '@mastra/core/processors'

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})
```

## 확장된 사용 예 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/skill-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SkillSearchProcessor } from '@mastra/core/processors'
import { Workspace, LocalFilesystem } from '@mastra/core/workspace'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: './project' }),
  skills: ['skills'],
  bm25: true,
})

const skillSearch = new SkillSearchProcessor({
  workspace,
  search: {
    topK: 5,
    minScore: 0.1,
  },
})

const agent = new Agent({
  id: 'skill-agent',
  name: 'skill-agent',
  instructions:
    'You are a helpful assistant. Use search_skills to find relevant skills, then load_skill to load their instructions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  inputProcessors: [skillSearch],
})
```

Agent Workflow는 다음과 같습니다.

1. Agent가 사용자 메시지를 받습니다.
2. Agent 통화`search_skills` with keywords (e.g., "api design")
3. Agent이 결과를 검토하고 통화합니다.`load_skill` with the skill name
4. 해당 스킬의 지시 사항은 다음 턴에 시스템 메시지로 나타납니다.
5. Agent는 로드된 스킬의 지시를 따릅니다.

## 작업공간 파일 Tool {/* #workspace-file-tools */}

`SkillSearchProcessor`기술 지침을 대화에 로드합니다. 작업 공간 파일 Tool가 파일을 읽는 것을 차단하지 않습니다.

사용`skill_read` for supporting files that belong to a loaded skill, such as files under `references/`, `scripts/`, or `assets/`.

다음과 같은 작업 공간 파일 Tool 예약`mastra_workspace_read_file` for explicit file inspection or editing workflows. During normal task execution, the agent doesn't need to read the same `SKILL.md` file after `load_skill` succeeds.

## SkillsProcessor와 비교 {/* #compared-to-skillsprocessor */}

| | 기술프로세서 | SkillSearch프로세서 |
| - | - | - |
| 스케일링 | 모든 기술을 미리 주입 | 주문형 검색 |
| 컨텍스트 사용법 | 스킬 수에 따라 성장 | 상수(로드된 스킬만) |
| 상담사 Workflow | 항상 보이는 기술 | Agent는 필요에 따라 검색 및 로드 |
| | 기술이 거의 없음(\< 10) | 다양한 기술(10+) |
