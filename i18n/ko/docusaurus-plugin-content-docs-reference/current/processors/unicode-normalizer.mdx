# 유니코드노멀라이저

그만큼`UnicodeNormalizer`은**입력 프로세서**메시지가 언어 Model로 전송되기 전에 일관된 형식을 보장하고 잠재적으로 문제가 있는 문자를 제거하기 위해 유니코드 텍스트를 정규화합니다. 이 프로세서는 유니코드 표현을 처리하고 제어 문자를 제거합니다. 또한 공백 형식도 표준화합니다.

## 사용예 {/* #usage-example */}

```typescript
import { UnicodeNormalizer } from '@mastra/core/processors'

const processor = new UnicodeNormalizer({
  stripControlChars: true,
  collapseWhitespace: true,
})
```

## 확장된 사용 예 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/normalized-agent.ts"
import { Agent } from '@mastra/core/agent'
import { UnicodeNormalizer } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'normalized-agent',
  name: 'normalized-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new UnicodeNormalizer({
      stripControlChars: true,
      preserveEmojis: true,
      collapseWhitespace: true,
      trim: true,
    }),
  ],
})
```
