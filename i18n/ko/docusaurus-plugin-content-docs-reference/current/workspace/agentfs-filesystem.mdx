# AgentFS파일 시스템

다음을 통해 Turso/SQLite 데이터베이스에 파일을 저장합니다.[AgentFS](https://github.com/nichochar/agentfs)SDK. 파일은 로컬 SQLite 데이터베이스의 세션 전반에 걸쳐 유지되므로 외부 클라우드 서비스 없이 Agent에 내구성 있는 스토리지를 제공합니다. 인터페이스에 대한 자세한 내용은 다음을 참조하세요.[Workspace파일 시스템 인터페이스](/reference/workspace/filesystem).

## 설치 {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## 용법 {/* #usage */}

추가`AgentFSFilesystem` to a workspace and assign it to an agent. You must provide at least one of `agentId`, `path`, or `agent`인스턴스화할 때`AgentFSFilesystem`수업.

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### 명시적 데이터베이스 경로 사용 {/* #using-an-explicit-database-path */}

기본적으로 데이터베이스는 다음 내부에 저장됩니다.`.agentfs` directory with the `agentId` as filename. You can specify a custom database path:

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### 미리 열린 AgentFS 인스턴스 사용 {/* #using-a-pre-opened-agentfs-instance */}

AgentFS 수명주기를 직접 관리해야 하는 경우:

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
