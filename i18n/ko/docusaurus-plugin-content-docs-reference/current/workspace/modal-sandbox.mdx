# 모달샌드박스

격리된 상태에서 명령을 실행합니다.[Modal](https://modal.com)클라우드 샌드박스. Modal의 인프라가 지원되는 안전하고 임시적인 환경을 제공합니다. 인터페이스에 대한 자세한 내용은 다음을 참조하세요.[WorkspaceSandbox 인터페이스](/reference/workspace/sandbox).

## 설치 {/* #installation */}

```bash npm2yarn
npm install @mastra/modal
```

## 용법 {/* #usage */}

추가`ModalSandbox` to a workspace and assign it to an agent:

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ModalSandbox } from '@mastra/modal'

const workspace = new Workspace({
  sandbox: new ModalSandbox({
    id: 'dev-sandbox',
    baseImage: 'ubuntu:22.04',
    timeoutMs: 60_000,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

## 입증 {/* #authentication */}

환경 변수 또는 생성자 옵션을 통해 모달 자격 증명을 설정합니다.

```bash
MODAL_TOKEN_ID=ak-...
MODAL_TOKEN_SECRET=as-...
```

또는 직접 전달하세요.

```typescript
const sandbox = new ModalSandbox({
  tokenId: process.env.MODAL_TOKEN_ID,
  tokenSecret: process.env.MODAL_TOKEN_SECRET,
})
```

다음에서 자격 증명을 받으세요.[Modal dashboard](https://modal.com/settings/tokens).

## 샌드박스 수명주기 {/* #sandbox-lifecycle */}

* **`_start()`**: 기존 실행 중인 샌드박스에 다시 연결을 시도합니다. 아무 것도 발견되지 않으면 최신 스냅샷에서 샌드박스를 생성합니다(이전 스냅샷에서 사용 가능한 경우).`_stop()`), or from the baseImage.
* **`_stop()`**: 파일 시스템의 스냅샷을 찍은 다음 샌드박스를 종료합니다. 스냅샷은 향후 시작을 위해 동일한 인스턴스의 Memory에 보관됩니다.
* **`_destroy()`**: 샌드박스를 종료하고 모든 스냅샷을 삭제합니다.

```typescript
const sandbox = new ModalSandbox({
  id: 'dev-sandbox',
  baseImage: 'ubuntu:22.04',
  timeoutMs: 300_000,
})

await sandbox._start()
await sandbox.processes.spawn('npm install')
await sandbox._stop()
await sandbox._start()
```

## 백그라운드 프로세스 {/* #background-processes */}

`ModalSandbox`백그라운드 프로세스 생성 및 관리를 위한 내장 프로세스 관리자가 포함되어 있습니다. 각`spawn()` call creates a new `ContainerProcess` via the Modal SDK's `Sandbox.exec()` API.

```typescript
const sandbox = new ModalSandbox({ id: 'dev-sandbox' })
await sandbox._start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node script.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Wait for the process to complete
const result = await handle.wait()
console.log(result.exitCode)

// Kill the process
await handle.kill()
```

:::메모

`sendStdin()`지원되지 않습니다. Modal JS SDK는 stdin을 노출하지 않습니다.`Sandbox.exec()`.

:::

보다[`SandboxProcessManager` reference](/reference/workspace/process-manager) for the full API.
