# 작업공간샌드박스

**추가된 항목:** `@mastra/core@1.1.0`

그만큼`WorkspaceSandbox` interface defines how workspaces execute commands and manage background processes.

## 행동 양식 {/* #methods */}

### `start()` {/* #start */}

샌드박스를 시작하고 다음에 의해 자동으로 호출됩니다.`workspace.init()` or the first `executeCommand()` call.

```typescript
await sandbox.start()
```

이 메서드는 명령 실행을 위해 샌드박스를 준비합니다.

### `stop()` {/* #stop */}

샌드박스를 중지합니다.

```typescript
await sandbox.stop?.()
```

### `destroy()` {/* #destroy */}

샌드박스 리소스를 정리합니다. 호출자`workspace.destroy()`.

```typescript
await sandbox.destroy()
```

### `executeCommand(command, args?, options?)` {/* #executecommandcommand-args-options */}

쉘 명령을 실행합니다.

```typescript
const result = await sandbox.executeCommand('ls', ['-la', '/docs'])
const result = await sandbox.executeCommand('npm', ['install', 'lodash'])
```

### `getInfo()` {/* #getinfo */}

샌드박스 상태 및 리소스 정보를 가져옵니다.

```typescript
const info = await sandbox.getInfo()
// { status: 'running', resources: { memoryMB: 512, cpuPercent: 5 } }
```

### `getInstructions(opts?)` {/* #getinstructionsopts */}

이 샌드박스의 작동 방식에 대한 설명을 반환합니다. 작업 영역이 Agent에 할당될 때 Agent의 시스템 메시지에 삽입됩니다.

```typescript
const instructions = sandbox.getInstructions?.()
// 'Local command execution. Working directory: "/workspace".'
```
