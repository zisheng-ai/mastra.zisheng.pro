# AI로 구축

Mastra 기술과 CLI를 사용한 일상적인 AI 지원 개발에 대해서는 다음을 참조하세요.[Develop](/docs/getting-started/develop#build-with-ai). 이 페이지에서는 코딩 Agent에게 Mastra 문서에 대한 액세스 권한을 부여하는 다른 방법을 다룹니다.

## 임베디드 패키지 문서 {/* #embedded-package-docs */}

Mastra 패키지에는 다음 문서가 내장되어 있습니다.`dist/docs`. When you install a Mastra package, your AI agent can read these files directly from `node_modules` to understand the package's APIs and patterns.

각`dist/docs` includes:

* `SKILL.md`: 스킬 기준에 따른 스킬 파일
* `references/`: 패키지와 관련된 문서 파일이 있는 폴더
* `assets/SOURCE_MAP.json`: 공개 내보내기를 해당 위치에 연결하는 소스 맵 파일`node_modules`

## 컨텍스트 파일 {/* #context-files */}

Mastra는 루트를 제공합니다[`llms.txt`](https://mastra.ai/llms.txt) file that contains an overview of all available documentation pages. It doesn't provide an `llms-full.txt` file as it's not useful to have all documentation in one file.

대신 각 문서 페이지에는 고유한`llms.txt` file. These files are streamlined markdown files. At the end of each docs page you'll find a link to the corresponding `llms.txt` file.

추가하다`/llms.txt` to any Mastra docs URL to access it. You can also request it by adding a `.md` extension to the end of the URL.

다음에 대한 예[introduction page](/docs):

* [`/docs/llms.txt`](https://mastra.ai/docs/llms.txt)
* [`/docs.md`](https://mastra.ai/docs.md)

## MCP 문서 서버 {/* #mcp-docs-server */}

:::경고

MCP 문서 서버는 일상적인 개발에는 권장되지 않습니다. 사용[Mastra skill](/docs/getting-started/develop#mastra-skill) instead because it's more up to date and performs better.

:::

그만큼`@mastra/mcp-docs-server` package provides direct local access to Mastra’s full documentation via the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro). It works with Cursor, Windsurf, Cline, Claude Code, VS Code, Codex or any tool that supports MCP.

이러한 Tool는 Agent에 기능을 추가하거나 새 프로젝트를 스캐폴딩하거나 작업 방식을 탐색하는 등 Agent가 정확한 작업별 정보를 검색하는 데 도움이 되도록 설계되었습니다.

로컬 MCP 서버를 사용할 수 없고 원격 서버에 연결해야 하는 경우 다음 URL을 사용하세요.`https://mastra.mcp.kapa.ai`. You need to authenticate with your Google Account (only an anonymous ID is transmitted) for rate-limiting purposes. If possible, Mastra recommends using a local MCP server for better performance and reliability.

### 설치 {/* #installation */}

그만큼[`create-mastra`](/reference/cli/create-mastra) command doesn't configure the MCP docs server. Add the server manually when you need MCP-specific tools such as the migration tool.

아래 Tool에 대한 특정 지침이 없는 경우 이 공통 JSON 구성을 사용하여 MCP 서버를 추가할 수 있습니다.

```json title="mcp.json"
{
  "mcpServers": {
    "mastra": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }
}
```

#### 클로드 코드 CLI {/* #claude-code-cli */}

터미널 명령을 사용하여 설치합니다.

```bash
claude mcp add --scope project mastra -- npx -y @mastra/mcp-docs-server@latest
```

이렇게 하면 프로젝트 범위의`.mcp.json` file if one doesn't already exist. You can use the same command when using Claude Code as a [Visual Studio Code extension](https://code.claude.com/docs/en/vs-code#connect-to-external-tools-with-mcp).

[Claude Code와 함께 MCP 서버 사용에 대한 추가 정보](https://docs.claude.com/en/docs/claude-code/mcp)

#### 반중력 {/* #antigravity */}

Google Antigravity는 외부 문서, API 및 프로젝트 컨텍스트에 액세스하기 위해 MCP 서버를 지원하는 Agent 우선 개발 플랫폼입니다.

1. Antigravity MCP 구성 파일을 엽니다.

   * 클릭하세요**Agent session** and select the **“…” dropdown** at the top of the editor’s side panel, then select **MCP Servers** to access the **MCP Store**.
   * Antigravity의 MCP Store 인터페이스를 통해 액세스할 수 있습니다.

   ![The Antigravity MCP store. At the top is a search bar and below a list of available MCP servers. On the very top right is a dropdown menu.](/img/antigravity_mcp_server.png)

2. 사용자 정의 MCP 서버를 추가하려면 다음을 선택하십시오.**Manage MCP Servers** at the top of the MCP Store and select **View raw config** in the main tab.

   ![The Antigravity MCP store showing the Manage MCP Servers option and the View raw config button.](/img/antigravity_managed_mcp.png)

3. Mastra MCP 서버 구성을 추가합니다.

   ```json
   {
     "mcpServers": {
       "mastra-docs": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server"]
       }
     }
   }
   ```

4. 구성을 저장하고 Antigravity를 다시 시작하세요.

   ![The UI shows that the MCP server is enabled. You can also toggle individual tools.](/img/antigravity_final_interface_mcp.png)

일단 구성되면 Mastra MCP 서버는 Antigravity Agent에 다음을 노출합니다.

* 코드 생성 중 관련 컨텍스트를 프로그래밍 방식으로 검색할 수 있는 Mastra용 색인화된 문서 및 API 스키마
* Mastra Docs에 저장된 예제 코드 조각 및 사용 패턴에 액세스
* 편집기에서 오류 처리 및 디버깅 참조를 위한 구조화된 데이터
* 코드 제안 및 완성을 위한 현재 Mastra 프로젝트 패턴에 대한 메타데이터

MCP 서버는 Antigravity의 MCP Store에 나타나며, 필요한 경우 연결 상태와 인증을 관리할 수 있습니다.

[Antigravity와 함께 MCP 서버 사용에 대한 추가 정보](https://antigravity.google)

#### 비주얼 스튜디오 코드 {/* #visual-studio-code */}

1. 만들기`.vscode/mcp.json` file in your workspace
2. 다음 구성을 삽입합니다.

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "mastra": {
         "type": "stdio",
         "command": "npx",
   ```

MCP 서버를 설치하면 다음과 같이 사용할 수 있습니다.

1. VSCode 설정을 엽니다.
2. MCP 설정으로 이동합니다.
3. 채팅 > MCP 옵션에서 "활성화"를 클릭하세요.

   ![Entry in VSCode's settings page. The option is called "Chat > MCP: Enabled (Preview)". The description says: "Enables integration with Model Context Protocol servers to provide additional tools and functionality."](/img/vscode-mcp-setting.png)

MCP는 VSCode의 Agent 모드에서만 작동합니다. Agent 모드에 있으면 다음을 엽니다.`mcp.json` file and select the "start" button. Note that the "start" button will only appear if the `.vscode` folder containing `mcp.json` is in your workspace root, or the highest level of the in-editor file explorer.

![A screenshot of the mcp.json file showing the start button in the editor](/img/vscode-start-mcp.png)

MCP 서버를 시작한 후 Copilot 창에서 Tool 버튼을 선택하여 사용 가능한 Tool를 확인합니다.

![Tools page of VSCode to see available tools](/img/vscode-mcp-running.png)

#### 오픈코드 {/* #opencode */}

MCP 서버를 정의할 수 있습니다.[OpenCode configuration](https://opencode.ai/docs/config/) under `mcp`. Create an `opencode.jsonc` file in your project root with the following content:

```json title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mastra": {
      "type": "local",
      "command": ["npx", "-y", "@mastra/mcp-docs-server@latest"],
      "enabled": true
    }
  }
}
```

[OpenCode와 함께 MCP 서버 사용에 대한 추가 정보](https://opencode.ai/docs/mcp-servers)

### 용법 {/* #usage */}

구성이 완료되면 AI Tool에 Mastra에 대해 질문하거나 조치를 취하도록 지시할 수 있습니다. 이 단계에서는 Mastra의 MCP 서버에서 최신 정보를 가져옵니다.

**기능 추가:**

* "Agent에 평가를 추가하고 테스트를 작성하세요"
* "다음을 수행하는 Workflow를 작성해 주세요.`[task]`"
* "내 Agent가 액세스할 수 있는 새 Tool를 만들어 보세요.`[3rd party API]`"

**통합에 대해 문의하세요.**

* "Mastra는 AI SDK와 작동하나요?
  내에서는 어떻게 사용할 수 있나요?`[React/Svelte/etc]` project?"
* "Mastra는 지원합니까?`[provider]` speech and voice APIs? Show me an example in my code of how I can use it."

**기존 코드를 디버그하거나 업데이트합니다.**

* "Agent Memory에 버그가 발생했습니다. 최근에 관련 변경 사항이나 버그 수정이 있었나요?"
* "Mastra에서 작업 Memory는 어떻게 작동하며 이를 어떻게 사용할 수 있습니까?`[task]`? It doesn't seem to work the way I expect."
* "새로운 Workflow 기능이 있는 것을 보고 나에게 설명하고 업데이트했습니다.`[workflow]` to use them."

### 문제 해결 {/* #troubleshooting */}

1. **서버가 시작되지 않음**
   * 보장하다[npx](https://docs.npmjs.com/cli/v11/commands/npx) is installed and working.
   * MCP 서버 충돌을 확인하십시오.
   * 구성 파일 구문을 확인하십시오.

2. **Tool 호출 실패**
   * MCP 서버 및/또는 IDE를 다시 시작합니다.
   * 최신 버전의 IDE로 업데이트하세요.
