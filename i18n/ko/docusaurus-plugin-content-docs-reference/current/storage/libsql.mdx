# libSQL 스토리지

[libSQL](https://docs.turso.tech/libsql)로컬 및 원격 배포를 모두 지원하는 오픈 소스 SQLite 호환 데이터베이스입니다. 메시지 기록, Workflow 스냅샷, 추적 및 평가 점수를 저장하는 데 사용할 수 있습니다.

의미적 회상이나 전통적인 RAG와 같은 벡터의 경우 다음을 사용하세요.[libSQL Vector](/reference/vectors/libsql) which covers embeddings and vector search.

## 설치 {/* #installation */}

스토리지 공급자는 별도의 패키지로 설치해야 합니다.

```bash npm2yarn
npm install @mastra/libsql@latest
```

## 용법 {/* #usage */}

```typescript
import { LibSQLStore } from '@mastra/libsql'
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  storage: new LibSQLStore({
    id: 'libsql-storage',
    url: 'file:./storage.db',
  }),
})
```

Agent 수준 파일 저장소:

```typescript
import { Memory } from '@mastra/memory'
import { Agent } from '@mastra/core/agent'
import { LibSQLStore } from '@mastra/libsql'

export const agent = new Agent({
  id: 'example-agent',
  memory: new Memory({
    storage: new LibSQLStore({
      id: 'libsql-storage',
      url: 'file:./agent.db',
    }),
  }),
})
```

:::경고
파일 스토리지는 임시 파일 시스템이 있는 서버리스 플랫폼에서는 작동하지 않습니다. 서버리스 배포의 경우 다음을 사용합니다.[Turso](https://turso.tech) or a different database engine.
:::

원격 데이터베이스를 사용한 프로덕션:

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: 'libsql://your-db-name.aws-ap-northeast-1.turso.io',
  authToken: process.env.TURSO_AUTH_TOKEN,
})
```

로컬 개발 및 테스트를 위해 데이터를 Memory에 저장할 수 있습니다.

```typescript
storage: new LibSQLStore({
  id: 'libsql-storage',
  url: ':memory:',
})
```

:::경고
프로세스가 변경되면 Memory 내 저장소가 재설정됩니다. 개발에만 적합합니다.
:::

## 관리되는 테이블 {/* #managed-tables */}

스토리지 구현은 다음을 포함하여 핵심 스토리지 테이블을 자동으로 생성합니다.`mastra_notifications` for notification inbox records and delivery metadata.

`LibSQLStore`다음을 통해 알림 저장소를 노출합니다.`getStore('notifications')`.

## 초기화 {/* #initialization */}

Mastra 클래스에 스토리지를 전달하면,`init()` is called automatically to create the [core schema](/reference/storage/overview#core-schema):

```typescript
import { Mastra } from '@mastra/core'
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

const mastra = new Mastra({
  storage, // init() called automatically
})
```

Mastra 없이 직접 저장소를 사용하는 경우`init()` explicitly:

```typescript
import { LibSQLStore } from '@mastra/libsql'

const storage = new LibSQLStore({
  id: 'libsql-storage',
  url: 'file:./storage.db',
})

await storage.init()

// Access domain-specific stores via getStore()
const memoryStore = await storage.getStore('memory')
const thread = await memoryStore?.getThreadById({ threadId: '...' })
```

## Observability {/* #observability */}

libSQL은 Observability을 지원하며 로컬 개발에 이상적입니다. 사용`realtime` [tracing strategy](/docs/observability/integrations/exporters/mastra-storage#tracing-strategies) for immediate visibility while debugging.

추적 볼륨이 더 높은 프로덕션 환경의 경우 다음을 사용하는 것이 좋습니다.[PostgreSQL](/reference/storage/postgresql) or [ClickHouse via composite storage](/reference/storage/composite#specialized-storage-for-observability).
