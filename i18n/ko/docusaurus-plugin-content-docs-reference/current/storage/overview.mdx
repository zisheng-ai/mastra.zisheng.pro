# 스토리지 개요

Mastra 스토리지는 도메인으로 구성됩니다. 각 도메인은 테이블 또는 컬렉션 집합을 소유합니다. 어댑터 및 구성에 따라 모든 도메인을 사용할 수도 있고 하위 집합만 사용할 수도 있습니다.

## 스토리지 도메인 {/* #storage-domains */}

`MastraCompositeStore`다음 도메인 키를 라우팅할 수 있습니다.

모든 스토리지 어댑터가 모든 도메인을 구현하는 것은 아닙니다. 복합 스토리지를 사용하면 어댑터 패키지가 해당 도메인 클래스를 내보낼 때 도메인당 어댑터를 혼합할 수 있습니다.

| 도메인 | 설명 |
| - | - |
|`memory` | 대화 영속성: 메시지, 스레드 및 리소스(작업 Memory 포함). |
| `workflows` | 일시 중지 및 재개에 사용되는 Workflow 실행 스냅샷. |
| `workflowDefinitions`| 영속화된 [동적 Workflow](/docs/workflows/dynamic-workflows) 정의(베타). 부팅 시 로드되고 런타임에 등록됩니다. |
|`scores`| Evals 실행의 평가 점수 레코드. |
|`observability`| Observability 내보내기 및 Studio에서 사용하는 Trace와 스팬. |
|`datasets`| 실험에 사용되는 데이터세트 레코드, 버전이 지정된 항목 및 데이터세트 버전. |
|`experiments`| 실험 실행 및 항목별 실험 결과. |
아래 스키마 정의에서는 `memory`, `workflows`, `scores`, `observability`에 대해 문서화된 기본 제공 데이터베이스 지원 테이블을 다룹니다. 다른 도메인과 데이터베이스 이외의 어댑터는 구현별 저장소 구조를 사용합니다.
