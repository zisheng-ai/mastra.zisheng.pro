# 스토리지 개요

Mastra 스토리지는 도메인으로 구성됩니다. 각 도메인은 테이블 또는 컬렉션 집합을 소유합니다. 어댑터 및 구성에 따라 모든 도메인을 사용할 수도 있고 하위 집합만 사용할 수도 있습니다.

## 스토리지 도메인 {/* #storage-domains */}

`MastraCompositeStore`다음 도메인 키를 라우팅할 수 있습니다.

모든 스토리지 어댑터가 모든 도메인을 구현하는 것은 아닙니다. 복합 스토리지를 사용하면 어댑터 패키지가 해당 도메인 클래스를 내보낼 때 도메인당 어댑터를 혼합할 수 있습니다.

| 도메인 | 설명 |
| - | - |
|`memory` | Conversation persistence: messages, threads, and resources (including working memory). |
| `workflows` | Workflow run snapshots used for suspend and resume. |
| `workflowDefinitions`| 지속됨[동적 작업흐름](/docs/workflows/dynamic-workflows)정의(베타). 부팅 시 로드되고 실시간 등록됩니다. |
|`scores`| 평가 실행의 평가 점수 기록입니다. |
|`observability`| 관측 가능성 내보내기 및 Studio에서 사용되는 추적 및 범위입니다. |
|`datasets`| 실험에 사용되는 데이터세트 레코드, 버전이 지정된 항목, 데이터세트 버전입니다. |
|`experiments`| 실험 실행 및 항목별 실험 결과입니다. |

아래 스키마 정의는 다음에 대해 문서화된 내장 데이터베이스 지원 테이블을 다룹니다.`memory`, `workflows`, `scores`, and `observability`. Other domains, and non-database adapters, use implementation-specific storage structures.
