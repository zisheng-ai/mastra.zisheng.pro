# 마운트AgentControllerOnMastra()

:::실험적

`@mastra/code-sdk` 패키지는 실험 단계이며 마이너 버전에서 호환성을 깨는 변경이 발생할 수 있습니다.
:::

`mountAgentControllerOnMastra()` 함수는 Mastra Code Agent 컨트롤러([`mastracode`](https://www.npmjs.com/package/mastracode) CLI의 기반이 되는 코딩 Agent로, 모드, Tool, Memory 및 스레드 관리 기능 포함)를 빌드하고 서버가 소유한 [Mastra](/reference/core/mastra-class) 인스턴스에 등록합니다. 이 함수를 사용하면 자체 UI(웹 앱, 편집기, 봇)에서 Mastra Code Agent를 제공할 수 있습니다. 각 클라이언트는 반환된 [`AgentController`](/reference/agent-controller/agent-controller-class)를 통해 격리된 자체 세션을 생성하거나 재개합니다.
`Mastra` 인스턴스를 직접 구성하려면(예: 배포 가능한 엔트리 파일에서) 동일한 패키지의 `prepareAgentControllerMount()`를 사용하세요. 이 함수는 생성자 인수와 `finalize()` 콜백을 반환합니다.
## 사용예 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

이미 다른 프리미티브를 호스팅하는 Mastra 인스턴스에 컨트롤러를 마운트하려면 기존 `mastra`를 전달하세요.
```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
