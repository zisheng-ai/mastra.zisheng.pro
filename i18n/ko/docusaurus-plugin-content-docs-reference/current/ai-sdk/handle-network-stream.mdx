# 핸들네트워크스트림()

:::경고\[사용되지 않음]

Agent 네트워크는 더 이상 사용되지 않으며 향후 릴리스에서 제거될 예정입니다. 사용[supervisor agents](/docs/capabilities/subagents) with `agent.stream()`또는`agent.generate()`대신에. 참조[마이그레이션 가이드](/guides/migrations/network-to-supervisor)업그레이드합니다.

:::

AI SDK 호환 형식의 스트리밍 네트워크 실행을 위한 프레임워크에 구애받지 않는 핸들러입니다. Hono 또는 Mastra 자체 외부의 네트워크 스트리밍을 처리해야 하는 경우 이 기능을 직접 사용하십시오.[apiRoutes](/docs/server/custom-api-routes) feature.

`handleNetworkStream()`반환합니다`ReadableStream` that you can wrap with [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleNetworkStream()`기존 AI SDK v5/기본 동작을 유지합니다. 앱이 AI SDK v6에 대해 입력된 경우 다음을 통과하세요.`version: 'v6'`.

사용[`networkRoute()`](/reference/ai-sdk/network-route) if you want to create a network route inside a Mastra server.

## 사용예 {/* #usage-example */}

Next.js 앱 라우터 예:

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
