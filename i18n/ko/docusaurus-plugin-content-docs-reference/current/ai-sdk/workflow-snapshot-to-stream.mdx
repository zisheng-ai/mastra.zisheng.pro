# Workflow우SnapshotToStream()

변환합니다`WorkflowState`객체(에 의해 반환됨)`workflow.getWorkflowRunById()`)로`ReadableStream`AI SDK UIMessage 데이터 부분. 스트림에는 동일한 내용이 포함되어 있습니다.`WorkflowDataPart`그리고`WorkflowStepDataPart`살아있는 덩어리[`workflowRoute()`](/reference/ai-sdk/workflow-route)생산합니다.

라이브 Workflow 스트림을 렌더링하는 동일한 UI 구성 요소를 사용하여 완료되거나 일시 중단된 Workflow 실행을 표시하려는 경우 이를 사용합니다.

## 사용예 {/* #usage-example */}

과거 Workflow 실행을 스트림으로 재생하는 Next.js 앱 라우터 엔드포인트:

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## 보고 {/* #returns */}

`ReadableStream`: 다음을 포함하는 AI SDK UIMessage 데이터 부분의 스트림입니다.

* 에이`start` marker
* 에이`WorkflowDataPart` with the workflow status and all step summaries
* 에이`WorkflowStepDataPart` for each step with its full output
* 에이`finish` marker

이 스트림을 다음으로 전달하세요.[`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) or `createUIMessageStream()` from the AI SDK.
