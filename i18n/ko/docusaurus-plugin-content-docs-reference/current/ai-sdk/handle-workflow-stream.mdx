# 핸들Workflow우스트림()

AI SDK 호환 형식의 스트리밍 Workflow 실행을 위한 프레임워크에 구애받지 않는 핸들러입니다. Hono 또는 Mastra 자체 외부의 Workflow우 스트리밍을 처리해야 하는 경우 이 기능을 직접 사용하십시오.[apiRoutes](/docs/server/custom-api-routes)특징.

`handleWorkflowStream()`반환합니다`ReadableStream` that you can wrap with [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleWorkflowStream()`기존 AI SDK v5/기본 동작을 유지합니다. 앱이 AI SDK v6에 대해 입력된 경우 다음을 통과하세요.`version: 'v6'`.

사용[`workflowRoute()`](/reference/ai-sdk/workflow-route) if you want to create a workflow route inside a Mastra server.

:::tip Workflow에서 Agent 스트리밍

Workflow 단계에서 Agent의 스트림을 Workflow 작성자에게 파이프하는 경우(예:`await response.fullStream.pipeTo(writer)`), the agent's text chunks and tool calls are forwarded to the UI stream in real time, even when the agent runs inside workflow steps.

보다[Workflow Streaming](/docs/workflows/overview#inspecting-workflow-stream-payloads) for more details.

:::

## 사용예 {/* #usage-example */}

Next.js 앱 라우터 예:

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
