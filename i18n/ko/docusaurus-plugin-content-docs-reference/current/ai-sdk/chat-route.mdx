# 채팅경로()

AI SDK 형식을 사용하여 스트리밍 Agent 대화를 위한 채팅 경로 핸들러를 만듭니다. 이 함수는 HTTP를 등록합니다.`POST`메시지를 수락하고, Agent를 실행하고, AI SDK 호환 형식으로 클라이언트에 응답을 다시 스트리밍하는 엔드포인트입니다. 내부에서 사용해야합니다.[커스텀 API 경로](/docs/server/custom-api-routes).

사용[`handleChatStream()`](/reference/ai-sdk/handle-chat-stream) if you need a framework-agnostic handler.

`chatRoute()`기존 AI SDK v5/기본 동작을 유지합니다. 앱이 AI SDK v6에 대해 입력된 경우 다음을 통과하세요.`version: 'v6'`.

:::note 연결 끊기 동작

`chatRoute()`들어오는 요청을 전달합니다.`AbortSignal` to `agent.stream()`. If the client disconnects, Mastra aborts the in-flight generation.

서버가 생성을 계속하고 연결이 끊어진 후에도 최종 응답을 유지하도록 하려면[custom API route](/docs/server/custom-api-routes#continue-generation-after-client-disconnect) around `agent.stream()` and call `consumeStream()` on the returned `MastraModelOutput`.

:::

## 사용예 {/* #usage-example */}

이 예에서는 채팅 경로를 설정하는 방법을 보여줍니다.`/chat` endpoint that uses an agent with the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

또한 다음을 기반으로 런타임 정의 Agent 라우팅을 사용할 수도 있습니다.`agentId`. The URL `/chat/weatherAgent` will resolve to the agent with the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 추가 구성 {/* #additional-configuration */}

당신은 사용할 수 있습니다[`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) to customize the request sent to the chat route, for example to pass additional configuration to the agent:

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/chat',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
