# withMastra()

Mastra 프로세서 및/또는 Memory로 AI SDK Model을 래핑합니다.

## 사용예 {/* #usage-example */}

```typescript title="src/example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import type { Processor } from '@mastra/core/processors'

const loggingProcessor: Processor<'logger'> = {
  id: 'logger',
  async processInput({ messages }) {
    console.log('Input:', messages.length, 'messages')
    return messages
  },
}

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [loggingProcessor],
})

const { text } = await generateText({
  model,
  prompt: 'What is 2 + 2?',
})
```

## 스트리밍 동작 {/* #streaming-behavior */}

`processOutputResult`를 구현하는 출력 프로세서는 스트림이 완료된 후 실행됩니다. 메시지 기록과 의미 기반 회상을 영속화하려면 스트림을 끝까지 소비하세요.
