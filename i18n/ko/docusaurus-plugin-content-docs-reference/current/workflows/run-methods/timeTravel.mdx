# 실행.시간여행()

그만큼`.timeTravel()`메서드는 저장된 스냅샷 데이터 또는 사용자가 제공하는 사용자 지정 컨텍스트를 사용하여 특정 단계부터 시작하는 Workflow를 다시 실행합니다. 이를 사용하여 실패한 Workflow를 디버깅하고 다양한 입력으로 개별 단계를 테스트하세요. 또한 전체 Workflow를 다시 실행하지 않고도 오류를 복구할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const result = await run.timeTravel({
  step: 'step2',
  inputData: { value: 10 },
})
```

## 확장된 사용 예 {/* #extended-usage-examples */}

### 맞춤형 컨텍스트를 통한 시간 여행 {/* #time-travel-with-custom-context */}

```typescript
const result = await run.timeTravel({
  step: 'step2',
  context: {
    step1: {
      status: 'success',
      payload: { value: 0 },
      output: { step1Result: 2 },
      startedAt: Date.now(),
      endedAt: Date.now(),
    },
  },
})
```

### 중첩된 Workflow 단계로의 시간 이동 {/* #time-travel-to-nested-workflow-step */}

```typescript
// Using dot notation
const result = await run.timeTravel({
  step: 'nestedWorkflow.step3',
  inputData: { value: 10 },
})

// Using array of step IDs
const result = await run.timeTravel({
  step: ['nestedWorkflow', 'step3'],
  inputData: { value: 10 },
})
```

### 초기 상태의 시간 여행 {/* #time-travel-with-initial-state */}

```typescript
const result = await run.timeTravel({
  step: 'step2',
  inputData: { value: 10 },
  initialState: {
    counter: 5,
    metadata: { source: 'time-travel' },
  },
})
```

### 중첩된 Workflow 컨텍스트를 사용한 시간 여행 {/* #time-travel-with-nested-workflows-context */}

```typescript
const result = await run.timeTravel({
  step: 'nestedWorkflow.step3',
  context: {
    step1: {
      status: 'success',
      payload: { value: 0 },
      output: { step1Result: 2 },
      startedAt: Date.now(),
      endedAt: Date.now(),
    },
    nestedWorkflow: {
      status: 'running',
      payload: { step1Result: 2 },
      startedAt: Date.now(),
    },
  },
  nestedStepsContext: {
    nestedWorkflow: {
      step2: {
        status: 'success',
        payload: { step1Result: 2 },
        output: { step2Result: 3 },
        startedAt: Date.now(),
        endedAt: Date.now(),
      },
    },
  },
})
```

## 메모 {/* #notes */}

* 시간 여행은 지속적인 Workflow 스냅샷에 의존하므로 스토리지를 구성해야 합니다.
* Workflow를 다시 실행할 때 Workflow는 스토리지에서 기존 스냅샷을 로드합니다(사용 가능한 경우).
* 대상 단계 이전의 단계 결과는 스냅샷 또는 제공된 컨텍스트에서 재구성됩니다.
* 제공된 또는 재구성된 입력 데이터를 사용하여 지정된 단계부터 실행이 시작됩니다.
* Workflow는 해당 시점부터 계속 완료됩니다.
* 시작하는 단계에 대한 사용자 정의 컨텍스트 또는 입력 데이터를 제공하여 아직 실행되지 않은 Workflow에서 시간 여행을 사용할 수 있습니다.
