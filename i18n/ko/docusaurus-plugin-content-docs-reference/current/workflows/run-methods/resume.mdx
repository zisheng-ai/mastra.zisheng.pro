# 실행.이력서()

그만큼`.resume()`메서드는 새 데이터로 일시 중단된 Workflow 실행을 재개하므로 특정 단계부터 계속 실행할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const result = await run.start({ inputData: { value: 'initial data' } })

if (result.status === 'suspended') {
  const resumedResults = await run.resume({
    resumeData: { value: 'resume data' },
  })
}
```

## 확장된 사용 예 {/* #extended-usage-example */}

```typescript
if (result.status === 'suspended') {
  const resumedResults = await run.resume({
    step: result.suspended[0],
    resumeData: { value: 'resume data' },
  })
}
```

:::note

정확히 한 단계만 일시 중지된 경우 `step` 매개변수를 생략할 수 있으며, Workflow가 해당 단계를 자동으로 재개합니다. 일시 중지된 단계가 여러 개인 Workflow에서는 재개할 단계를 명시적으로 지정해야 합니다.
:::

### 싱글 재개[`.foreach()`](../workflow-methods/foreach) iteration {/* #resuming-a-single-foreach-iteration */}

[`.foreach()`](../workflow-methods/foreach) 단계가 여러 반복에서 일시 중지되면 `forEachIndex`(0부터 시작)를 사용하여 서로 다른 `resumeData`로 한 번에 하나의 반복을 재개하세요. `forEachIndex`로 지정하지 않은 반복은 재개될 때까지 일시 중지된 상태로 유지됩니다.
```typescript
// Resume only the second iteration (index 1) with its own data
await run.resume({
  step: 'approve',
  resumeData: { ok: true },
  forEachIndex: 1,
})

// Later, resume the first iteration with different data
await run.resume({
  step: 'approve',
  resumeData: { ok: false },
  forEachIndex: 0,
})
```

`forEachIndex`를 생략하면 해당 단계에서 일시 중지된 모든 반복이 동일한 `resumeData`로 재개됩니다.
