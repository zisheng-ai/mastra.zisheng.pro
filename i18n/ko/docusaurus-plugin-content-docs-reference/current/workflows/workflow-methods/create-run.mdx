# Workflow.createRun()

그만큼`.createRun()`메서드는 새로운 Workflow 실행 인스턴스를 생성하여 특정 입력 데이터로 Workflow를 실행할 수 있도록 합니다. 이는 다음을 반환하는 현재 API입니다.`Run`사례.

## 사용예 {/* #usage-example */}

```typescript
await workflow.createRun()
```

## 확장된 사용 예 {/* #extended-usage-example */}

```typescript
const workflow = mastra.getWorkflow('workflow')

const run = await workflow.createRun()

const result = await run.start({
  inputData: {
    value: 10,
  },
})
```

## 사용`resourceId` {/* #using-resourceid */}

`resourceId` 매개변수는 Workflow 실행을 사용자나 테넌트 같은 특정 리소스와 연결합니다. 이는 멀티테넌트 애플리케이션이나 Workflow를 시작한 사용자를 추적해야 할 때 유용합니다.
```typescript
const workflow = mastra.getWorkflow('workflow')

// Create a run associated with a specific user
const run = await workflow.createRun({
  resourceId: 'user-123',
})

const result = await run.start({
  inputData: {
    value: 10,
  },
})

// Later, retrieve the run and access the resourceId
const storedRun = await workflow.getWorkflowRunById(run.runId)
console.log(storedRun.resourceId) // "user-123"
```
