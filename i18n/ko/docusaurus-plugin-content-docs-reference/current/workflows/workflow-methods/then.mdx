# Workflow.then()
그만큼`.then()`메서드는 Workflow 단계 간에 순차적 종속성을 생성하여 단계가 특정 순서로 실행되도록 합니다.

## 사용예 {/* #usage-example */}

```typescript
workflow.then(step1).then(step2)
```
