# Workflow우.맵()

그만큼`.map()`메서드는 이전 단계의 출력 데이터를 후속 단계의 입력으로 매핑하므로 단계 간에 데이터를 변환할 수 있습니다.

## 사용예 {/* #usage-example */}

```typescript
workflow.map(async ({ inputData }) => `${inputData.value} - map`)
```

## 사용`inputData` {/* #using-inputdata */}

사용`inputData` to access the full output of the previous step.

```typescript {3} filename="src/mastra/workflows/test-workflow.ts" prettier:false
  .then(step1)
  .map(({ inputData }) => {
    console.log(inputData);
  })
```

## 사용`getStepResult()` {/* #using-getstepresult */}

사용`getStepResult()` to access the full output of a specific step by referencing the step's instance.

```typescript {3} filename="src/mastra/workflows/test-workflow.ts" prettier:false
  .then(step1)
  .map(async ({ getStepResult }) => {
    console.log(getStepResult(step1));
  })
```

## 사용`getInitData()` {/* #using-getinitdata */}

사용`getInitData<typeof workflow>()` to access the initial input data provided to the workflow.

```typescript prettier:false {3} filename="src/mastra/workflows/test-workflow.ts"
  .then(step1)
  .map(async ({ getInitData }) => {
    console.log(getInitData<any>());
  })
```

## 사용`mapVariable()` {/* #using-mapvariable */}

객체 형태의`.map()` provides an alternative declarative syntax for mapping fields. Instead of writing a function, you define an object where each key is a new field name and each value uses `mapVariable()` to extract data from previous steps or workflow input.
Import `mapVariable()` from the workflows module:

```typescript filename="src/mastra/workflows/test-workflow.ts"
import { mapVariable } from '@mastra/core/workflows'
```

### 단계 출력에서 ​​필드 추출 {/* #extracting-fields-from-step-outputs */}

사용`mapVariable()` with `step` to extract a specific field from a step's output and map it to a new field name. The `path` parameter specifies which field to extract.
In this example, the `value` field from `step1`'s output is extracted and mapped to a new field called `details`:

```typescript prettier:false {3-6} filename="src/mastra/workflows/test-workflow.ts"
  .then(step1)
  .map({
    details: mapVariable({
      step: step1,
      path: "value"
    })
  })
```

### Workflow 입력에서 필드 추출 {/* #extracting-fields-from-workflow-input */}

사용`mapVariable()` with `initData` to extract a specific field from the workflow's initial input data. This is useful when you need to pass the original workflow input to a later step.
In this example, the `value` field from the workflow's input is extracted and mapped to a field called `details`:

```typescript prettier:false {6-9} filename="src/mastra/workflows/test-workflow.ts"
export const testWorkflow = createWorkflow({...});

testWorkflow
  .then(step1)
  .map({
    details: mapVariable({
      initData: testWorkflow,
      path: "value"
    })
  })
```
