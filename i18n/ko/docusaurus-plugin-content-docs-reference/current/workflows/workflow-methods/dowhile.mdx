# Workflow.dowhile()

그만큼`.dowhile()`메소드는 조건이 충족되는 동안 단계를 실행합니다. 조건을 평가하기 전에 항상 단계를 한 번 이상 실행합니다. 조건이 처음 평가될 때,`iterationCount`~이다`1`.

## 사용예 {/* #usage-example */}

```typescript
workflow.dowhile(step1, async ({ inputData }) => true)
```
