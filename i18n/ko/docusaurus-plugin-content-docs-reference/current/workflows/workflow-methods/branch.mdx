# Workflow.branch()

그만큼`.branch()`메서드는 Workflow 단계 사이에 조건부 분기를 생성하여 이전 단계의 결과에 따라 다양한 경로를 선택할 수 있도록 합니다.

## 사용예 {/* #usage-example */}

```typescript
workflow.branch([
  [async ({ context }) => true, step1],
  [async ({ context }) => false, step2],
])
```
