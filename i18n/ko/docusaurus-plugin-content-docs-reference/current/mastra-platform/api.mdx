# API 참조

## 회원 API {/* #members-api */}

아래 엔드포인트의 루트 URL은 다음과 같습니다.`/v1/org/members`

| 방법 | 엔드포인트 | 설명 |
| - | - | - |
| 받기 |`/` | List members |
| POST | `/invitations`| 초대장 보내기 |
| 받기 |`/invitations`| 초대장 나열 |
| 삭제 |`/invitations/:id`| 초대 취소 |
| 패치 |`/:id`| 회원 역할 업데이트 |
| 삭제 |`/:id`| 회원 삭제 |

## API 토큰 {/* #api-tokens */}

아래 엔드포인트의 루트 URL은 다음과 같습니다.`/v1/auth/tokens`

| 메서드 | 엔드포인트 | 설명 |
| - | - | - |
| POST |`/` | API 토큰 생성 |
| GET | `/` | API 토큰 목록 조회 |
| DELETE | `/:id` | API 토큰 삭제 |
## 스튜디오 API {/* #studio-api */}

아래 엔드포인트의 루트 URL은 다음과 같습니다.`/v1/studio`

| 메서드 | 엔드포인트 | 설명 |
| - | - | - |
| GET |`/projects` | Studio 프로젝트 목록 조회 |
| POST | `/projects` | 프로젝트 생성 |
| GET | `/projects/:id` | 프로젝트 세부 정보 및 배포 조회 |
| DELETE | `/projects/:id` | 프로젝트 삭제 |
| POST | `/deploys` | 배포 생성 |
| POST | `/deploys/:id/upload-complete` | 아티팩트 업로드 확인 |
| GET | `/deploys/:id` | 배포 상태 조회 |
| GET | `/deploys/:id/logs` | 배포 로그 조회 |
| GET | `/deploys/:id/logs/stream` | 배포 로그 스트리밍(SSE) |
## 서버 API {/* #server-api */}

아래 엔드포인트의 루트 URL은 다음과 같습니다.`/v1/server`

| 메서드 | 엔드포인트 | 설명 |
| - | - | - |
| GET |`/projects` | 서버 프로젝트 목록 조회 |

| DELETE | `/projects/:id` | 프로젝트 삭제 |
| PUT | `/projects/:id/env` | 환경 변수 설정 |
| GET | `/projects/:id/env` | 환경 변수 조회 |
| POST | `/projects/:id/env/restart` | 환경 변수 변경 후 재시작 |
| GET | `/projects/:id/domains` | 도메인 목록 조회 |
| POST | `/projects/:id/domains` | 사용자 정의 도메인 추가 |
| GET | `/projects/:id/runtime-logs` | 런타임 로그 조회 |
| POST | `/projects/:id/redeploy`| 재배포 트리거 |
| POST |`/projects/:id/always-on`| 상시 실행 활성화 |
| DELETE |`/projects/:id/always-on`| 상시 실행 비활성화 |
| POST |`/deploys`| 배포 생성 |
| POST |`/deploys/:id/upload-complete`| 아티팩트 업로드 확인 |
| GET |`/deploys/:id`| 배포 상태 조회 |
| GET |`/deploys/:id/logs`| 배포 로그 조회 |
| POST |`/deploys/:id/cancel`| 대기 중이거나 진행 중인 배포 취소 |
| DELETE |`/deploys/:id`| 실행 중인 배포 중지 |
## 게이트웨이 API {/* #gateway-api */}

아래 엔드포인트의 루트 URL은 다음과 같습니다.`/v1/gateway`

| 메서드 | 엔드포인트 | 설명 |
| - | - | - |
| GET |`/projects` | 게이트웨이 프로젝트 목록 조회 |
| GET | `/projects/:id` | 프로젝트 세부 정보 조회 |
| PATCH | `/projects/:id` | 프로젝트 설정 업데이트 |
| DELETE | `/projects/:id` | 프로젝트 삭제 |
| POST | `/projects/provision` | 새 게이트웨이 프로젝트 프로비저닝 |
| GET | `/projects/:id/keys` | API 키 목록 조회 |
| POST | `/projects/:id/keys` | API 키 생성 |
| DELETE | `/projects/:id/keys/:keyId` | API 키 폐기 |
| GET | `/projects/:id/keys/:keyId/bindings` | 키 수준 Provider 바인딩 목록 조회 |
| POST | `/projects/:id/keys/:keyId/bindings` | 키 수준 Provider 바인딩 추가(BYOK) |
| DELETE | `/projects/:id/keys/:keyId/bindings/:provider` | 키 수준 바인딩 제거 |
| GET | `/projects/:id/bindings` | 프로젝트 수준 Provider 바인딩 목록 조회 |
| POST | `/projects/:id/bindings` | 프로젝트 수준 Provider 바인딩 추가(BYOK) |
| DELETE | `/projects/:id/bindings/:provider` | 프로젝트 수준 바인딩 제거 |
| GET | `/projects/:id/usage/has-activity` | 프로젝트에 요청이 있는지 확인 |
| GET | `/projects/:id/usage/activity` | 집계된 사용 활동 조회 |
| GET | `/projects/:id/usage/memory-activity` | 지정 기간의 Memory 토큰 합계 조회 |
| GET | `/projects/:id/usage/logs` | 요청 로그 조회 |
| GET | `/projects/:id/usage/logs/facets` | 로그 필터 패싯 조회 |
| GET | `/projects/:id/usage/logs/:requestId` | 특정 요청 세부 정보 조회 |
| GET | `/projects/:id/memory/threads`| 스레드 목록 조회(대시보드) |
| POST |`/projects/:id/memory/threads`| 스레드 생성(대시보드) |
| GET |`/projects/:id/memory/threads/:threadId`| 스레드 조회(대시보드) |
| PATCH |`/projects/:id/memory/threads/:threadId`| 스레드 업데이트(대시보드) |
| DELETE |`/projects/:id/memory/threads/:threadId`| 스레드 삭제(대시보드) |
| POST |`/projects/:id/memory/threads/:threadId/clone`| 스레드 복제(대시보드) |
| GET |`/projects/:id/memory/threads/:threadId/messages`| 메시지 목록 조회(대시보드) |
| POST |`/projects/:id/memory/threads/:threadId/messages`| 메시지 저장(대시보드) |
| DELETE |`/projects/:id/memory/threads/:threadId/messages`| 메시지 삭제(대시보드) |
| GET |`/projects/:id/memory/threads/:threadId/observations/history`| 관찰 기록 조회(대시보드) |
| GET |`/models`| 사용 가능한 Model 목록 조회 |
