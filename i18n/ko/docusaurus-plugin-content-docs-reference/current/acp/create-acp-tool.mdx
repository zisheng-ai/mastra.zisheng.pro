# 생성ACPTool()

그만큼`createACPTool()`함수는 다음을 보내는 Mastra Tool를 생성합니다.`task`문자열을 ACP(Agent 클라이언트 프로토콜) 호환 코딩 Agent에 전송하고 최종 ACP 응답을 다음과 같이 반환합니다.`output`. 상위 Agent가 ACP Agent를 Tool로 호출할 시기를 결정해야 할 때 사용하십시오.

대신 ACP Agent를 Mastra 하위 Agent로 등록하려면[`AcpAgent` class](/reference/acp/acp-agent).

## 사용예 {/* #usage-example */}

코드 편집 Tool를 만들고 상위 Agent에 등록합니다.

```typescript title="src/mastra/agents/code-supervisor.ts"
import { createACPTool } from '@mastra/acp'
import { Agent } from '@mastra/core/agent'

const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent to inspect and edit code',
  command: 'acp-agent',
  args: ['--stdio'],
  cwd: process.cwd(),
})

export const codeSupervisor = new Agent({
  id: 'code-supervisor',
  name: 'Code Supervisor',
  instructions: 'Use the code-agent tool when a task requires repository inspection or code edits.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    codeAgentTool,
  },
})
```

## 세션 수명주기 {/* #session-lifecycle */}

각 Tool 실행은 ACP 연결을 생성하고 구성된`command`. It initializes the ACP client and creates an ACP session before sending the `task` with ACP `session/prompt`.

기본적으로`persistSession` is `true` for the ACP connection created during tool execution. Set `persistSession: false` when the ACP process should stop as soon as that prompt completes.

사용[`AcpAgent`](/reference/acp/acp-agent#session-lifecycle) when you need a reusable ACP subagent instance with explicit session lifecycle control across calls.

## 권한 처리 {/* #permission-handling */}

ACP Agent는 계속하기 전에 클라이언트에게 권한 옵션을 선택하도록 요청할 수 있습니다. 기본적으로`@mastra/acp` selects the first option returned by the ACP agent, or cancels when no option is available.

통과하다`onPermissionRequest` to inspect the request and return your own permission response:

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  async onPermissionRequest(request) {
    const allowOption = request.options.find(option => option.name === 'Allow')

    if (!allowOption) {
      return { outcome: { outcome: 'cancelled' } }
    }

    return {
      outcome: {
        outcome: 'selected',
        optionId: allowOption.optionId,
      },
    }
  },
})
```

이 콜백을 사용하여 로컬 정책을 시행하거나 권한 제목을 검사하세요. 또한 결정을 자체 승인 흐름으로 라우팅할 수도 있습니다.

## 확장 방법 {/* #extension-methods */}

일부 ACP Agent는 표준 ACP 요청 세트 외부에서 클라이언트의 사용자 정의 확장 메소드를 호출합니다. 기본 클라이언트는 "메소드를 찾을 수 없음" 오류와 함께 알 수 없는 메서드를 거부하며, 이로 인해 Agent의 차례가 중단될 수 있습니다.

통과하다`createClient` to extend or replace the default client. The callback receives the default client and returns the client used for the connection:

```typescript title="src/mastra/agents/code-agent.ts"
import { createACPTool } from '@mastra/acp'

export const codeAgentTool = createACPTool({
  id: 'code-agent',
  description: 'Use an ACP-compatible coding agent',
  command: 'acp-agent',
  args: ['--stdio'],
  createClient: defaultClient =>
    Object.assign(defaultClient, {
      async extMethod(method: string, params: Record<string, unknown>) {
        return {}
      },
      async extNotification(method: string, params: Record<string, unknown>) {},
    }),
})
```

완전히 사용자 정의를 반환`Client` implementation when you need to change the standard handlers as well. The `Client` type is re-exported from `@mastra/acp`.
