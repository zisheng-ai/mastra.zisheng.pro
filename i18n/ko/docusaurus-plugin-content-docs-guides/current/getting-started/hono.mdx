# Hono 프로젝트에 Mastra 통합

이 가이드에서는 Mastra와 Hono를 사용하여 Tool 호출 AI Agent를 구축합니다. 사용하여[Hono server adapter](/reference/server/hono-adapter), 라우팅을 직접 작성하거나 별도의 Mastra 서버를 실행하지 않고도 Agent를 HTTP 엔드포인트로 노출할 수 있습니다.

## 시작하기 전에 {/* #before-you-begin */}

* 지원되는 API 키가 필요합니다.[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* Node.js 설치`v22.13.0` or later

## 새 Hono 앱 만들기(선택 사항) {/* #create-a-new-hono-app-optional */}

이미 Hono 앱이 있다면 다음 단계로 건너뛰세요.

다음 명령을 실행하여[create a new Hono app](https://hono.dev/docs/getting-started/basic):

```bash npm2yarn
npm create hono@latest mastra-hono -- --template nodejs --install --pm npm
```

그러면 다음과 같은 프로젝트가 생성됩니다.`mastra-hono`, but you can replace it with any name you want.

## 마스트라 초기화 {/* #initialize-mastra */}

Hono 프로젝트 디렉터리로 이동합니다.

```bash
cd mastra-hono
```

달리다[`mastra init`](/reference/cli/mastra#mastra-init). When prompted, choose a provider (e.g. OpenAI) and enter your key:

```bash npm2yarn
npx mastra@latest init
```

이것은`src/mastra` folder with an example weather agent and the following files:

* `index.ts`- Memory를 포함한 마스트라 구성
* `tools/weather-tool.ts`- 특정 위치의 날씨를 가져오는 Tool
* `agents/weather-agent.ts`- Tool를 사용하는 Prompt가 있는 기상 요원

당신은 통과할 것이다`src/mastra/index.ts` file to the Hono server adapter later.

## 서버 어댑터 추가 {/* #add-server-adapter */}

Hono 서버 어댑터 패키지를 설치합니다.

```bash npm2yarn
npm install @mastra/hono@latest
```

다음 위치에서 Hono 항목 파일을 엽니다.`src/index.ts` and add the required import and initialization code:

```typescript title="src/index.ts" {3-8,10-11,13}
import { serve } from '@hono/node-server'
import { Hono } from 'hono'
import { type HonoBindings, type HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra/index.js'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/', c => {
  return c.text('Hello Hono!')
})

serve(
  {
    fetch: app.fetch,
    port: 3000,
  },
  info => {
    console.log(`Server is running on http://localhost:${info.port}`)
  },
)
```

⁠`MastraServer` is initialized with the existing Hono `app` and the root ⁠`mastra` instance. Calling `⁠init()` registers the Mastra middleware and exposes all available Mastra endpoints.

## Agent 테스트 {/* #test-your-agent */}

기본적으로 Mastra의 엔드포인트는`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

Hono 서버를 시작합니다:

```bash npm2yarn
npm run dev
```

별도의 터미널 창에서 다음을 사용하십시오.`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
