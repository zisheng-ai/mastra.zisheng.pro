# Express 프로젝트에 Mastra 통합

이 가이드에서는 Mastra 및 Express를 사용하여 Tool 호출 AI Agent를 구축합니다. 사용하여[Express server adapter](/reference/server/express-adapter), 라우팅을 직접 작성하거나 별도의 Mastra 서버를 실행하지 않고도 Agent를 HTTP 엔드포인트로 노출할 수 있습니다.

## 시작하기 전에 {/* #before-you-begin */}

* 지원되는 API 키가 필요합니다.[model provider](/models). If you don't have a preference, use [OpenAI](/models/providers/openai).
* Node.js 설치`v22.13.0` or later

## 마스트라 초기화 {/* #initialize-mastra */}

Express 프로젝트 디렉터리 내에서 다음을 실행하세요.[`mastra init`](/reference/cli/mastra#mastra-init).

메시지가 표시되면 공급자(예: OpenAI)를 선택하고 키를 입력합니다.

```bash
npx mastra@latest init
```

이것은`src/mastra` folder with an example weather agent and the following files:

* `index.ts`- Memory를 포함한 마스트라 구성
* `tools/weather-tool.ts`- 특정 위치의 날씨를 가져오는 Tool
* `agents/weather-agent.ts`- Tool를 사용하는 Prompt가 있는 기상 요원

당신은 통과할 것이다`src/mastra/index.ts` file to the Express server adapter later.

## 서버 어댑터 추가 {/* #add-server-adapter */}

Express 서버 어댑터 패키지를 설치합니다.

```bash npm2yarn
npm install @mastra/express@latest
```

Express 항목 파일을 다음에서 엽니다.`src/index.ts` and add the required import and initialization code:

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

⁠`MastraServer` is initialized with the existing Express `app` and the root ⁠`mastra` instance. Calling `⁠init()` registers the Mastra middleware and exposes all available Mastra endpoints.

## Agent 테스트 {/* #test-your-agent */}

기본적으로 Mastra의 엔드포인트는`/api` subpath and use your agent/workflow IDs. The default `weather-agent` created by `mastra init` is available at `/api/agents/weather-agent`.

Express 서버를 시작하십시오.

```bash
npm run start
```

별도의 터미널 창에서 다음을 사용하십시오.`curl` to ask the weather agent:

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
