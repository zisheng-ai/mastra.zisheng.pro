# 마스트라 빠른 시작

<Inject>
  **AI Agent의 경우:**&#xBE44;대화식으로 새로운 Mastra 프로젝트를 생성합니다.`npm create mastra@latest <project-name> -- --llm <provider>`, 교체`<provider>`~와 함께`openai`, `anthropic`, `google`, 또는`xai`. Agent나 Model 제공자가 없는 최소 프로젝트의 경우 다음을 사용하세요.`npm create mastra@latest <project-name> -- --empty`. Mastra 프로젝트를 처음부터 빌드하려면 다음을 참조하세요.[수동 설치 가이드](/guides/getting-started/manual-install).
</Inject>

그만큼`create-mastra` CLI is the quickest way to start a Mastra project. It creates an agent harness with workspace tools, memory, task tracking, web access, schedules, storage, and observability.

더 자세한 제어 방법은 다음을 참조하세요.[manual installation guide](/guides/getting-started/manual-install). To add Mastra to an existing project, use [`mastra init`](/reference/cli/mastra#mastra-init).

## 시작하기 전에 {/* #before-you-begin */}

OpenAI, Anthropic, Google Gemini 또는 xAI의 API 키가 필요합니다. 설정하는 동안 입력을 건너뛰고 추가할 수 있습니다.`.env` later.

## 프로젝트 만들기 {/* #create-the-project */}

대화형 설정을 실행합니다.

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

이 명령은 프로젝트 이름, Model 공급자 및 선택적 API 키를 요청합니다. 그런 다음 종속성을 설치하고, 코딩 도우미를 위한 Mastra 기술을 설치하고, 아직 리포지토리 내부에 있지 않을 때 초기 Git 커밋을 생성합니다.

생성된`src/mastra` directory contains the Mastra entry point, agent, workspace tools, and supporting code. See the [project structure reference](/reference/project-structure) for the standard Mastra layout.

:::팁

사용`--template <template>` to start from a template, or `--empty` to create a minimal provider-free project. Use `--no-skills` or `--no-git` to skip automatic setup. See the [`create-mastra` reference](/reference/cli/create-mastra) for all flags.

:::

## Agent 테스트 {/* #test-your-agent */}

터미널 지침에 따라 프로젝트 디렉터리를 입력하고 개발 서버를 시작합니다.

```bash npm2yarn
npm run dev
```

열려 있는[Studio at localhost:4111](http://localhost:4111), select the agent, and send a message. Add the provider API key named in `.env.example` to an `.env` file if you skipped it during setup.

[사진관](/docs/studio/overview)별도의 UI를 만들지 않고도 Agent를 구축하고 테스트할 수 있습니다.
