# 마스트라 빠른 시작

<Inject>
  **AI Agent의 경우:**&#xBE44;대화식으로 새로운 Mastra 프로젝트를 생성합니다.`npm create mastra@latest <project-name> -- --llm <provider>`, 교체`<provider>`~와 함께`openai`, `anthropic`, `google`, 또는`xai`. Agent나 Model 제공자가 없는 최소 프로젝트의 경우 다음을 사용하세요.`npm create mastra@latest <project-name> -- --empty`. Mastra 프로젝트를 처음부터 빌드하려면 다음을 참조하세요.[수동 설치 가이드](/guides/getting-started/manual-install).
</Inject>

`create-mastra` CLI는 Mastra 프로젝트를 시작하는 가장 빠른 방법입니다. Workspace Tool, Memory, 작업 추적, 웹 접근, 일정, 스토리지, Observability를 갖춘 Agent 실행 환경을 생성합니다.
더 세부적으로 제어하려면 [수동 설치 가이드](/guides/getting-started/manual-install)를 참조하세요. 기존 프로젝트에 Mastra를 추가하려면 [`mastra init`](/reference/cli/mastra#mastra-init)을 사용하세요.
<QuickstartPrompt />

:::tip\[📹 보기]

Mastra로 Agent를 구축하는 방법을 단계별로 소개하는 [Mastra AI Agent 강좌](https://www.youtube.com/watch?v=lCmf_qrGfGA)를 시청하세요.
:::

## 시작하기 전에 {/* #before-you-begin */}

OpenAI, Anthropic, Google Gemini 또는 xAI의 API 키가 필요합니다. 설정하는 동안 입력을 건너뛰고 추가할 수 있습니다.`.env` later.

## 프로젝트 만들기 {/* #create-the-project */}

대화형 설정을 실행합니다.

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

이 명령은 프로젝트 이름, Model 공급자 및 선택적 API 키를 요청합니다. 그런 다음 종속성을 설치하고, 코딩 도우미를 위한 Mastra 기술을 설치하고, 아직 리포지토리 내부에 있지 않을 때 초기 Git 커밋을 생성합니다.

생성된 `src/mastra` 디렉터리에는 Mastra 진입점, Agent, Workspace Tool 및 지원 코드가 포함됩니다. 표준 Mastra 레이아웃은 [프로젝트 구조 레퍼런스](/reference/project-structure)를 참조하세요.
:::tip

`--template <template>`으로 템플릿에서 시작하거나 `--empty`로 Provider가 없는 최소 프로젝트를 생성하세요. 자동 설정을 건너뛰려면 `--no-skills` 또는 `--no-git`을 사용합니다. 모든 플래그는 [`create-mastra` 레퍼런스](/reference/cli/create-mastra)를 참조하세요.
:::

## Agent 테스트 {/* #test-your-agent */}

터미널 지침에 따라 프로젝트 디렉터리를 입력하고 개발 서버를 시작합니다.

```bash npm2yarn
npm run dev
```

[localhost:4111의 Studio](http://localhost:4111)를 열고 Agent를 선택한 후 메시지를 보냅니다. 설정 과정에서 건너뛰었다면 `.env.example`에 명시된 Provider API 키를 `.env` 파일에 추가하세요.
[사진관](/docs/studio/overview)별도의 UI를 만들지 않고도 Agent를 구축하고 테스트할 수 있습니다.
