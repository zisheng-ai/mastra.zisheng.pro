# Cloudflare에 Mastra 배포

사용`@mastra/deployer-cloudflare`Cloudflare Workers에 Mastra 서버를 배포합니다. 배포자는 코드를 번들로 묶고`wrangler.jsonc`Cloudflare를 준수하는 파일[랭글러 구성](https://developers.cloudflare.com/workers/wrangler/configuration/), 추가 구성 없이 배포 준비가 완료되었습니다.

:::info

당신이 사용하는 경우[server adapter](/docs/server/server-adapters) or [web framework](/docs/deployment/web-framework), 해당 프레임워크에서 평소 사용하는 방식으로 배포하세요.

:::

## 시작하기 전에 {/* #before-you-begin */}

당신은[Mastra application](/guides/getting-started/quickstart) and a [Cloudflare](https://cloudflare.com/) account.

:::warning
Cloudflare 작업자는 임시 파일 시스템을 사용하므로 구성한 모든 저장소(관측성 저장소 포함)는 외부에서 호스팅되어야 합니다. 당신이 사용하는 경우[LibSQLStore](/reference/storage/libsql) 를 파일 URL과 함께 사용하고 있다면 원격으로 호스팅되는 데이터베이스로 전환하세요.
:::

## 설치 {/* #installation */}

추가`@mastra/deployer-cloudflare` package to your project:

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

수입[`CloudflareDeployer`](/reference/deployer/cloudflare) 를 설치하고 Mastra 구성에서 deployer로 설정하세요:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

Cloudflare Worker를 로컬에서 테스트하려면 다음도 설치하세요.[`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/):

```bash npm2yarn
npm install -D wrangler
```

## 용법 {/* #usage */}

프로젝트를 설정한 후 선택한 원격 Git 공급자(예: GitHub)에 푸시하세요.

<Steps>
  <StepItem>
    저장소를 Cloudflare에 연결하세요. "작업자 및 페이지" 대시보드에서**Create application** 를 선택하고 다음 단계에서 Git Provider를 선택하세요. 설정 절차를 계속 진행한 후 배포할 리포지토리를 선택하세요.

    :::메모

    애플리케이션을 실행하는 데 필요한 환경 변수(예:[model provider](/models/providers) API key). You can upload secrets from your `.env` file using `npx wrangler secret bulk .env`. See [Secrets](/reference/deployer/cloudflare#secrets) for details.

    :::
  </StepItem>

  <StepItem>
    준비가 되었으면**Deploy** 버튼을 선택하고 첫 번째 배포가 완료될 때까지 기다리세요.
  </StepItem>

  <StepItem>
    다음으로 이동하여 새로 배포된 기능을 사용해 보세요.`https://<your-project-name>.<slug>.workers.dev/api/agents`. 사용 가능한 모든 Agent를 나열하는 JSON 응답이 반환되어야 합니다.

    이후[Mastra server](/docs/server/mastra-server) prefixes every API endpoint with `/api`, 요청할 때 URL에 이를 추가해야 합니다.
  </StepItem>

  <StepItem>
    이제 HTTP를 통해 Mastra 엔드포인트를 호출할 수 있습니다.

    :::메모

    설정[authentication](/docs/server/auth) before exposing your endpoints publicly.

    :::
  </StepItem>
</Steps>
