# Amazon EC2에 Mastra 배포

Mastra 서버를 Amazon EC2에 배포합니다. 서버는 귀하가 관리하는 인프라에서 실행되며 장기 실행 Agent 및 Workflow를 지원할 수 있습니다.

:::info
이 가이드에서는[Mastra server](/docs/server/mastra-server). If you're using a [서버 어댑터](/docs/server/server-adapters)또는[웹 프레임워크](/docs/deployment/web-framework), 해당 프레임워크에 대해 일반적인 방식으로 배포합니다.
:::

## 시작하기 전에 {/* #before-you-begin */}

다음이 필요합니다.

* 에이[Mastra application](/guides/getting-started/quickstart)
* 안[EC2](https://aws.amazon.com/ec2/) Git과 Node.js 22.13.0 이상이 설치된 인스턴스(Ubuntu 또는 Amazon Linux)

프로덕션을 위해서는 다음도 필요합니다.

* 인스턴스를 가리키는 도메인 이름(SSL 인증서에 필요)
* 도메인에 대한 SSL 인증서(예:[Certbot](https://certbot.eff.org/) with Let's Encrypt)
* 역방향 프록시(예:[nginx](https://nginx.org/)) to forward traffic to your application

## 배포 {/* #deploy */}

<Steps>
  <StepItem>
    EC2 인스턴스에 연결하고 리포지토리를 복제합니다.

    <Tabs>
      <TabItem value="public" label="Public Repository">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Private Repository">
        ```bash
        git clone git@github.com:<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    저장소 디렉터리로 이동합니다.

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    종속성을 설치합니다.

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    만들기`.env` file and add your environment variables:

    ```bash
    touch .env
    ```

    애플리케이션을 실행하는 데 필요한 환경 변수(예: Model 공급자 API 키)를 설정해야 합니다.

    ```bash
    OPENAI_API_KEY=<your-openai-api-key>
    # Add other required environment variables
    ```
  </StepItem>

  <StepItem>
    애플리케이션을 빌드합니다.

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    애플리케이션을 실행합니다.

    ```bash
    node --env-file=".env" .mastra/output/index.mjs
    ```

    이것은 기본적인 예입니다. 프로덕션에서는 다음과 같은 프로세스 관리자를 사용하십시오.[PM2](https://pm2.keymetrics.io/) or [systemd](https://systemd.io/) 애플리케이션을 계속 실행하고 재시작을 처리하도록 합니다.

    :::warning
    설정[authentication](/docs/server/auth) before exposing your endpoints publicly.
    :::
  </StepItem>

  <StepItem>
    이제 Mastra 서버가 포트 4111에서 실행되고 있지만 로컬에서만 액세스할 수 있습니다.

    직접 액세스를 위해 EC2 보안 그룹에서 포트 4111을 열거나, 포트 80 및 443을 수신하고 요청을 다음으로 전달하도록 역방향 프록시(예: nginx)를 구성할 수 있습니다.`http://localhost:4111`.

    프로덕션에서는 HTTPS를 구성할 수 있도록 역방향 프록시를 사용해야 합니다. HTTPS는 트래픽을 암호화하며 Agent가 상호 작용하는 대부분의 웹후크 통합 및 외부 서비스에 필요합니다.
  </StepItem>

  <StepItem>
    배포를 확인하세요.`https://<your-ec2-address>/api/agents`, 그러면 Agent의 JSON 목록이 반환되어야 합니다.
  </StepItem>

  <StepItem>
    이제 HTTP를 통해 Mastra 엔드포인트를 호출할 수 있습니다.
  </StepItem>
</Steps>
