# Azure App Services에 Mastra 배포

Mastra 애플리케이션을 Azure App Services에 배포합니다.

:::정보
이 가이드에서는[Mastra server](/docs/server/mastra-server). If you're using a [서버 어댑터](/docs/server/server-adapters)또는[웹 프레임워크](/docs/deployment/web-framework), 해당 프레임워크에 대해 일반적인 방식으로 배포합니다.
:::

## 시작하기 전에 {/* #before-you-begin */}

다음이 필요합니다.

* 에이[Mastra application](/guides/getting-started/quickstart)
* 안[Azure account](https://azure.microsoft.com/) with an active subscription
* 에이[GitHub repository](https://github.com/) containing your Mastra application

:::경고
Azure App Services에서 파일 시스템은 일부 가격 책정 계층에 대해 일시적이므로 배포 간에 로컬 데이터베이스 파일이 손실됩니다. 당신이 사용하는 경우[LibSQLStore](/reference/storage/libsql) with a local file, configure it to use a remote LibSQL-compatible database (for example, [Turso](https://turso.tech/)) instead.
:::

## 새 앱 서비스 만들기 {/* #create-a-new-app-service */}

이 단계에서는 Mastra 애플리케이션을 호스팅하기 위한 새로운 Azure App Service를 만드는 방법을 알아봅니다. 그러면 애플리케이션을 실행하는 데 필요한 인프라와 환경이 설정됩니다.

<Steps>
  <StepItem>
    로그인[Azure Portal](https://portal.azure.com) and navigate to **[App Services](https://docs.microsoft.com/en-us/azure/app-service/)** or search for it in the top search bar. Select **Create** to create a new App Service, and in the drop-down, select **Web App**.
  </StepItem>

  <StepItem>
    앱 서비스 설정을 구성합니다.

    * **신청**: Azure 구독을 선택하세요.
    * **리소스 그룹**: 새 리소스 그룹을 생성하거나 기존 리소스 그룹을 선택합니다.
    * **인스턴스 이름**: 앱의 고유한 이름을 입력하세요(URL의 일부임).
    * **게시**: 선택하다**Code**
    * **런타임 스택**: 선택하다**Node 22 LTS**
    * **운영 체제**: 선택하다**Linux**
    * **지역**: 사용자와 가까운 지역을 선택하세요
    * **리눅스 계획**: 선택한 지역에 따라 요금제를 선택할 수 있으며, 귀하의 필요에 맞는 요금제를 선택하세요.
    * 선택하다**Review + Create** and wait for validation to complete, then select **Create**.
  </StepItem>

  <StepItem>
    새로운 배포가 트리거되었습니다. 배포가 완료될 때까지 기다린 후 다음을 선택합니다.**Go to resource** under the next steps section.
  </StepItem>

  <StepItem>
    GitHub 배포를 설정하기 전에 환경 변수를 구성하세요. 다음으로 이동**Settings** > **Environment variables** in the left sidebar. Add your required environment variables, such as:

    * Model 제공자 API 키(예:`OPENAI_API_KEY`)
    * 데이터베이스 연결 문자열
    * Mastra 애플리케이션에 필요한 기타 구성 값

    선택하다**Apply** to save the changes.
  </StepItem>
</Steps>

## GitHub 배포 {/* #github-deployment */}

이 단계에서는 Azure App Service를 GitHub 리포지토리에 연결하여 지속적인 배포를 활성화합니다. 즉, 변경 사항을 리포지토리에 푸시할 때마다 Azure가 자동으로 애플리케이션을 빌드하고 배포합니다.

<Steps>
  <StepItem>
    다음으로 이동**Deployment Center** in the left sidebar and select **GitHub** as your source. Sign in to GitHub if you're not already authenticated with Azure.

    이 예에서는[GitHub Actions](https://docs.github.com/en/actions) as your provider. Select your organization, repository, and branch.

    Azure는 GitHub Workflow 파일을 생성하며 진행하기 전에 미리 볼 수 있습니다. 선택하다**Save** (the save button is located at the top of the page).
  </StepItem>

  <StepItem>
    Azure가 Workflow를 생성하면 GitHub Actions 실행이 트리거되고 Workflow 파일이 분기에 병합됩니다.**Cancel this initial run** as it will fail without the necessary modifications.

    :::경고
    Azure에서 생성된 기본 Workflow는 Mastra 애플리케이션에 대해 실패하므로 수정해야 합니다.
    :::

    최신 변경 사항을 로컬 저장소로 가져오고 생성된 Workflow 파일(`.github/workflows/main_<your-app-name>.yml`):
  </StepItem>

  <StepItem>
    "npm install, build, and test"라는 단계를 찾아 다음을 수행합니다.

    * 단계 이름을 "npm install and build"로 변경합니다.
    * Mastra 애플리케이션에서 적절한 테스트를 설정하지 않은 경우`npm test` command from the run section as the default test script will fail and disrupt deployment. If you have working tests, you can keep the test command.
  </StepItem>

  <StepItem>
    "배포용 Zip 아티팩트" 단계를 찾아 zip 명령을 다음으로 바꿉니다.

    ```yaml
    run: (cd .mastra/output && zip ../../release.zip -r .)
    ```

    그러면 배포 패키지에는 다음의 빌드 출력만 포함됩니다.`.mastra/output`.
  </StepItem>

  <StepItem>
    Workflow 수정 사항을 커밋하고 푸시합니다. 빌드는 다음에서 자동으로 트리거됩니다.**Deployment Center** in your Azure dashboard. Monitor the deployment progress until it completes successfully.
  </StepItem>
</Steps>

## 배포 확인 {/* #verify-your-deployment */}

빌드가 성공하면 애플리케이션이 시작될 때까지 잠시 기다립니다. 다음에 제공된 기본 URL을 사용하여 배포된 애플리케이션에 액세스할 수 있습니다.**Overview** tab in the Azure portal. Your application will be available at `https://<your-app-name>.azurewebsites.net`.

Azure Portal에서 URL을 복사하고 방문하세요.`https://<your-app-name>.azurewebsites.net/api/agents` in your browser. You should see a JSON list of your agents.

이제 HTTP를 통해 Mastra 엔드포인트를 호출할 수 있습니다.

:::경고
설정[authentication](/docs/server/auth) before exposing your endpoints publicly.
:::
