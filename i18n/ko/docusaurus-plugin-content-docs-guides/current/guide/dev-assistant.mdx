# 개발자 어시스턴트 구축

이 가이드에서는 모든 작업 공간 기능을 결합한 완전한 개발 도우미를 구축합니다.

* [파일 시스템](/docs/workspace/filesystem)파일 관리를 위해
* [모래 상자](/docs/workspace/sandbox)코드 실행을 위해
* [기술](/docs/workspace/skills)코딩 표준에 대한
* [찾다](/docs/workspace/search)사례를 찾기 위해

샘플 프로젝트로 작업 영역을 설정하고 코딩 표준을 기술로 추가합니다. 그런 다음 TDD 방식에 따라 코드를 작성하는 Agent를 만듭니다. 결국 Agent는 기존 코드를 읽고 새로운 구현을 작성한 다음 샌드박스에서 테스트를 실행하고 결과에 따라 반복할 수 있습니다.

## 전제조건 {/* #prerequisites */}

* Node.js `v22.13.0` 이상 설치
* 지원되는 [Model Provider](/models)의 API 키
* 기존 Mastra 프로젝트(새 프로젝트를 설정하려면 [설치 가이드](/guides/getting-started/quickstart)를 따르세요)
### 바이테스트 설치 {/* #install-vitest */}

개발 어시스턴트는 [Vitest](https://vitest.dev/)를 사용하여 Workspace Sandbox 내에서 테스트를 실행합니다. 프로젝트에 개발 종속성으로 설치하세요.
```bash npm2yarn
npm install -D vitest
```

## 작업공간 설정 {/* #set-up-the-workspace */}

Workspace는 로컬 파일 시스템을 사용하여 문서 파일을 관리합니다. Agent는 Workspace 디렉터리 내의 파일을 읽고 씁니다. `src/mastra/index.ts` 파일에서 [`Workspace`](/reference/workspace/workspace-class), [`LocalFilesystem`](/reference/workspace/local-filesystem), [`LocalSandbox`](/reference/workspace/local-sandbox) 클래스를 가져오세요.
또한 BM25 검색 인덱싱 및 로드 기술을 활성화합니다.`skills` directory.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-start
import { resolve } from 'node:path'
import { Workspace, LocalFilesystem, LocalSandbox } from '@mastra/core/workspace'
// highlight-end

// highlight-start
const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: resolve(import.meta.dirname, '../../workspace') }),
  sandbox: new LocalSandbox({ workingDirectory: resolve(import.meta.dirname, '../../workspace') }),
  skills: ['skills'],
  bm25: true,
  autoIndexPaths: ['docs', 'src'],
})
// highlight-end

export const mastra = new Mastra({
  // highlight-next-line
  workspace,
})
```

프로젝트 루트에 `workspace`라는 새 폴더를 만드세요. 모든 파일은 이 폴더에 저장되고 Agent가 관리합니다.
## 샘플 프로젝트 파일 추가 {/* #add-sample-project-files */}

작업공간은 다음 폴더 구조를 사용합니다.

* `workspace/src/`: 샘플 프로젝트의 소스 코드
* `workspace/tests/`: 테스트 파일
* `workspace/docs/`: 프로젝트 문서
* `workspace/skills/`: 코딩 표준 및 지침[Agent Skills](https://agentskills.io)

먼저 몇 가지 유틸리티 함수가 포함된 `workspace/src/utils/string-helpers.ts` 파일과 이에 대응하는 `workspace/tests/string-helpers.test.ts` 테스트 파일을 만드세요.
```typescript title="workspace/src/utils/string-helpers.ts"
export function capitalize(str: string): string {
  if (!str) return str
  return str.charAt(0).toUpperCase() + str.slice(1)
}

export function slugify(str: string): string {
  return str
    .toLowerCase()
    .replace(/[^\w\s-]/g, '')
    .replace(/\s+/g, '-')
}
```

```typescript title="workspace/tests/string-helpers.test.ts"
import { describe, it, expect } from 'vitest'
import { capitalize, slugify } from '../src/utils/string-helpers'

describe('String Helpers', () => {
  describe('capitalize', () => {
    it('capitalizes first letter', () => {
      expect(capitalize('hello')).toBe('Hello')
    })
  })

  describe('slugify', () => {
    it('converts to lowercase and replaces spaces', () => {
      expect(slugify('Hello World')).toBe('hello-world')
    })
  })
})
```

`workspace/skills/coding-standards/SKILL.md`에 Skill 정의를 만드세요. 이 정의는 Agent에게 코드 작성 및 테스트 방법을 알려 줍니다.
```markdown title="workspace/skills/coding-standards/SKILL.md"
---
name: coding-standards
description: Project coding standards and testing guidelines
---

# Coding Standards

## Code quality

- Functions under 50 lines
- Use descriptive variable names
- Always add TypeScript types

## Testing

- Test all exported functions
- Use AAA pattern: Arrange, Act, Assert
- Cover happy paths and edge cases

## Before committing

1. Write implementation
2. Write comprehensive tests
3. Run tests: `npm test`
4. All tests must pass
```

자세한 테스트 패턴을 포함하는 참조 파일을 `workspace/skills/coding-standards/references/testing-guide.md`에 만드세요.
````markdown title="workspace/skills/coding-standards/references/testing-guide.md"
# Testing Guide

## AAA pattern

```typescript
it('설명적인 테스트 이름', () => {  // Arrange: Set up test data
  const input = 'test'

  // Act: Execute the function
  const result = doSomething(input)
  // Assert: Verify the result
  expect(result).toBe('expected')
})```

## 테스트할 항목
- 정상 경로(일반 입력)
- 엣지 케이스(빈 값, null, 경계값)
- 오류 사례(잘못된 입력, 예외)````

## 개발자 어시스턴트 만들기 {/* #create-the-dev-assistant */}

작업공간 설정이 완료되었으면 이제 개발 보조 Agent를 생성할 차례입니다. 이 Agent에는 TDD(테스트 기반 개발)를 사용하여 새로운 기능을 추가하기 위한 지침이 있습니다.

새 파일 `src/mastra/agents/dev-assistant.ts`를 만들고 Agent를 정의하세요.
```typescript title="src/mastra/agents/dev-assistant.ts"
import { Agent } from '@mastra/core/agent'

export const devAssistant = new Agent({
  id: 'dev-assistant',
  name: 'Dev Assistant',
  instructions: `You are a development assistant.

When adding features:
1. Activate 'coding-standards' skill
2. Search workspace for similar code examples
3. Write the implementation following standards
4. Write comprehensive tests. Leave existing tests in place, only add your new tests
5. Execute the command \`npx vitest run\` to validate that all tests pass
6. Update documentation if needed

For every new feature: Write code → Write tests → Run tests → Update docs

Always explain your reasoning and steps.`,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

`src/mastra/index.ts`에서 Agent를 가져와 `Mastra` 인스턴스에 등록하세요.
```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { resolve } from 'node:path'
import { Workspace, LocalFilesystem, LocalSandbox } from '@mastra/core/workspace'
// highlight-next-line
import { devAssistant } from './agents/dev-assistant'

const workspace = new Workspace({
  filesystem: new LocalFilesystem({ basePath: resolve(import.meta.dirname, '../../workspace') }),
  sandbox: new LocalSandbox({ workingDirectory: resolve(import.meta.dirname, '../../workspace') }),
  skills: ['skills'],
  bm25: true,
  autoIndexPaths: ['docs', 'src'],
})

export const mastra = new Mastra({
  workspace,
  // highlight-next-line
  agents: { devAssistant },
})
```

## 어시스턴트 테스트 {/* #test-the-assistant */}

[Studio](/docs/studio/overview)를 시작하고 Agent와 상호 작용하여 실제 동작을 확인하세요.
```bash npm2yarn
npm run dev
```

[localhost:4111](http://localhost:4111)을 열고 개발 어시스턴트로 이동하세요.
Agent에게 TDD를 사용하여 새 기능을 추가하도록 요청해보세요.

```text
Add a 'truncate' function to string-helpers.ts that shortens strings to a max length. Add '...' if truncated.

TDD를 따르세요. 먼저 테스트를 작성한 다음 구현하세요.```

Agent 응답은 비결정적이므로 정확한 출력은 다양합니다. 그러나 Agent가 다음과 유사한 프로세스를 따르는 것을 볼 수 있습니다.

1. 코딩 표준 기술 활성화

2. 작업 공간에서 유사한 코드 패턴을 검색하세요.

3. 테스트를 먼저 작성하세요. 예를 들면 다음과 같습니다.

   ```typescript
   describe('truncate', () => {
     it('truncates long strings', () => {
       expect(truncate('Hello World', 5)).toBe('He...')
     })

     it('keeps short strings unchanged', () => {
       expect(truncate('Hi', 10)).toBe('Hi')
     })

     it('handles edge cases', () => {
       expect(truncate('', 5)).toBe('')
     })
   })
   ```

4. 구현을 작성합니다. 예를 들면 다음과 같습니다.

   ```typescript
   export function truncate(str: string, maxLength: number): string {
     if (!str || maxLength < 0) return str
     if (str.length <= maxLength) return str
     if (maxLength === 0) return '...'
     return str.slice(0, maxLength - 3) + '...'
   }
   ```

5. 테스트를 실행하고 통과하는지 확인하세요.
