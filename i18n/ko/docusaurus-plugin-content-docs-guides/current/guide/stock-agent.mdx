# AI 주식 Agent 구축

이 가이드에서는 기호에 대한 전날의 종가를 가져오는 Agent를 만듭니다. Tool을 만들어 Agent에 추가한 다음 Agent를 사용하여 주가를 가져옵니다.

## 전제조건 {/* #prerequisites */}

* Node.js`v22.13.0` or later installed
* 지원되는 API 키[Model Provider](/models)
* 기존 Mastra 프로젝트(다음을 따르세요.[installation guide](/guides/getting-started/quickstart) to set up a new project)

## Agent 만들기 {/* #creating-the-agent */}

Mastra에서 Agent를 생성하려면`Agent` 클래스로 정의한 다음 Mastra에 등록합니다.

<Steps>
  <StepItem>
    새 파일 만들기`src/mastra/agents/stockAgent.ts` and define your agent:

    ```ts title="src/mastra/agents/stockAgent.ts"
    import { Agent } from '@mastra/core/agent'

    export const stockAgent = new Agent({
      id: 'stock-agent',
      name: 'Stock Agent',
      instructions:
        'You are a helpful assistant that provides current stock prices. When asked about a stock, use the stock price tool to fetch the stock price.',
      model: '__GATEWAY_OPENAI_MODEL__',
    })
    ```
  </StepItem>

  <StepItem>
    당신의`src/mastra/index.ts` file, register the agent:

    ```ts title="src/mastra/index.ts" {2, 5}
    import { Mastra } from '@mastra/core'
    import { stockAgent } from './agents/stockAgent'

    export const mastra = new Mastra({
      agents: { stockAgent },
    })
    ```
  </StepItem>
</Steps>

## 주가 Tool 만들기 {/* #creating-the-stock-price-tool */}

Stock Agent는 현재 주가에 대해 아직 아무것도 모릅니다. 이를 변경하려면 Tool을 생성하여 Agent에 추가하세요.

<Steps>
  <StepItem>
    새 파일 만들기`src/mastra/tools/stockPrices.ts`. Inside, add a `stockPrices` Tool을 만들어 지정된 symbol의 전일 종가를 가져옵니다:

    ```ts title="src/mastra/tools/stockPrices.ts"
    import { createTool } from '@mastra/core/tools'
    import { z } from 'zod'

    const getStockPrice = async (symbol: string) => {
      const data = await fetch(
        `https://mastra-stock-data.vercel.app/api/stock-data?symbol=${symbol}`,
      ).then(r => r.json())
      return data.prices['4. close']
    }

    export const stockPrices = createTool({
      id: 'Get Stock Price',
      inputSchema: z.object({
        symbol: z.string(),
      }),
      description: `Fetches the last day's closing stock price for a given symbol`,
      execute: async inputData => {
        console.log('Using tool to fetch stock price for', inputData.symbol)
        return {
          symbol: inputData.symbol,
          currentPrice: await getStockPrice(inputData.symbol),
        }
      },
    })
    ```
  </StepItem>

  <StepItem>
    내부에`src/mastra/agents/stockAgent.ts` import your newly created `stockPrices` tool and add it to the agent.

    ```ts title="src/mastra/agents/stockAgent.ts" {9-11}
    import { Agent } from '@mastra/core/agent'
    import { stockPrices } from '../tools/stockPrices'

    export const stockAgent = new Agent({
      id: 'stock-agent',
      name: 'Stock Agent',
      instructions:
        'You are a helpful assistant that provides current stock prices. When asked about a stock, use the stock price tool to fetch the stock price.',
      model: '__GATEWAY_OPENAI_MODEL__',
      tools: {
        stockPrices,
      },
    })
    ```
  </StepItem>
</Steps>

## Agent 서버 실행 {/* #running-the-agent-server */}

Mastra의 API를 통해 Agent와 상호 작용하는 방법을 알아보세요.

<Steps>
  <StepItem>
    다음을 사용하여 Agent를 서비스로 실행할 수 있습니다.`mastra dev` command:

    ```bash
    mastra dev
    ```

    등록된 Agent와 상호 작용하기 위해 엔드포인트를 노출하는 서버가 시작됩니다. 이내에[Studio](/docs/studio/overview) you can test your `stockAgent` and `stockPrices` tool through a UI.
  </StepItem>

  <StepItem>
    기본적으로`mastra dev` runs on `http://localhost:4111`. Your Stock agent will be available at:

    ```
    POST http://localhost:4111/api/agents/stockAgent/generate
    ```
  </StepItem>

  <StepItem>
    다음을 사용하여 Agent와 상호작용할 수 있습니다.`curl` from the command line:

    ```bash
    curl -X POST http://localhost:4111/api/agents/stockAgent/generate \
      -H "Content-Type: application/json" \
      -d '{
        "messages": [
          { "role": "user", "content": "What is the current stock price of Apple (AAPL)?" }
        ]
      }'
    ```

    다음과 유사한 JSON 응답을 받아야 합니다.

    ```json
    {
      "text": "The current price of Apple (AAPL) is $174.55.",
      "agent": "Stock Agent"
    }
    ```

    이는 Agent가 요청을 성공적으로 처리했으며`stockPrices` Tool을 사용해 주가를 가져오고 결과를 반환했습니다.
  </StepItem>
</Steps>
