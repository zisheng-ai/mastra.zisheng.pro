# CLI

배포 명령, 구성 플래그 및 시작 파일을 제거하여 CLI가 단순화되었습니다. 데이터베이스 스키마 업그레이드를 돕기 위해 새로운 마이그레이션 명령이 추가되었습니다.

## 추가됨 {/* #added */}

### `mastra migrate`명령 {/* #mastra-migrate-command */}

새로운`mastra migrate` command helps run database migrations when upgrading Mastra versions. This is particularly useful when upgrading from older versions that may have data incompatibilities.

```bash
npx mastra migrate
```

이 명령은 필요한 마이그레이션을 실행하기 전에 프로젝트를 번들로 묶고 구성된 스토리지에 연결합니다. 현재 고유 제약 조건 생성을 방지할 수 있는 중복 범위 항목 마이그레이션을 지원합니다.

참조[Storage migration guide](/guides/migrations/upgrade-to-v1/storage#duplicate-spans-migration) for details on when this migration is needed.

## 제거됨 {/* #removed */}

### `mastra deploy`명령 {/* #mastra-deploy-command */}

그만큼`mastra deploy` command has been removed from the CLI. This change simplifies the CLI by removing vendor-specific deployment logic.

마이그레이션하려면 다음 중 하나를 선택하십시오.[deployment platforms](/docs/deployment/overview) of your choice.

### `--env`에서 플래그`mastra build` {/* #--env-flag-from-mastra-build */}

그만큼`--env` flag has been removed from the `mastra build` command. This change simplifies the build command.

마이그레이션하려면 다음을 사용하십시오.`mastra start --env <env>` to start the build output with a custom environment.

```diff
- mastra build --env production
+ mastra build
+ mastra start --env production
```

### `--port`에서 플래그`mastra dev` {/* #--port-flag-from-mastra-dev */}

그만큼`--port` flag has been removed from the `mastra dev` command. Port configuration is now handled through the Mastra instance configuration. This change centralizes port configuration.

마이그레이션하려면 다음을 사용하십시오.`server.port` on the Mastra instance instead of the CLI flag.

```ts
const mastra = new Mastra({
  server: {
    port: 3001,
  },
})
```

### CLI의 원격 측정 옵션 {/* #telemetry-options-from-cli */}

그만큼`telemetry` option has been removed from CLI commands including the `--no-telemetry` / `-nt` flag. Telemetry configuration has been removed from the CLI. This change reflects the move of telemetry features to the observability package.

마이그레이션하려면 CLI 명령에서 원격 측정 플래그를 제거하세요. 사용`@mastra/observability` for tracing features.
