# 목소리

업데이트된 클래스 이름과 API 메서드를 사용하여 음성 패키지의 이름이 음성에서 음성으로 변경되었습니다.

## 변경됨 {/* #changed */}

### 음성 구성 속성 이름 {/* #voice-configuration-property-names */}

일관성을 위해 음성 구성 속성의 이름이 변경되었습니다. `speakProvider`는 이제 `output`, `listenProvider`는 이제 `input`, `realtimeProvider`는 이제 `realtime`입니다. 새 이름은 음성 입력 및 출력에서 각 속성이 담당하는 역할과 일치합니다.
마이그레이션하려면 음성 기능이 있는 Agent를 구성할 때 구성 속성 이름을 업데이트하세요.

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip\[코드모드]

Mastra의 codemod CLI를 사용하여 코드를 자동으로 업데이트할 수 있습니다.

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
