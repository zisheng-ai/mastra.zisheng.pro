# 프로세서

일관된 이름 지정 패턴과 데이터베이스 메시지 유형을 사용하도록 프로세서 인터페이스가 업데이트되었습니다.

## 변경됨 {/* #changed */}

### 프로세서 구성`name` to `id` {/* #processor-configuration-from-name-to-id */}

이제 프로세서에는`id` field instead of `name`. The `name`필드는 이제 선택 사항입니다. 이 변경 사항은 득점자 및 Agent와 같은 다른 Mastra 엔터티와의 일관성을 제공합니다.

마이그레이션하려면 사용할 프로세서 정의를 업데이트하세요.`id` as the required field.

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### 프로세서 메시지 유형`MastraMessageV2` to `MastraDBMessage` {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}

프로세서 메시지 유형이 다음에서 변경되었습니다.`MastraMessageV2` to `MastraDBMessage`. Processors and scorers now use the database message format and its types.

마이그레이션하려면 프로세서 메시지 유형 가져오기 및 사용량을 업데이트하세요.

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 제거됨 {/* #removed */}

### 더 이상 사용되지 않는 입력 프로세서 내보내기 {/* #deprecated-input-processor-exports */}

내장 프로세서를 포함하는 더 이상 사용되지 않는 입력 프로세서 내보내기가 다음에서 제거되었습니다.`@mastra/core/agent/input-processors/processors`. Use `@mastra/core/processors` instead. This change consolidates processor types under the unified `Processor` interface.

사용한 적이 있는 경우`InputProcessor`, replace it with `Processor` which implements a `processInput` function.

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory 프로세서 수출이 코어로 이동됨 {/* #memory-processor-exports-moved-to-core */}

그만큼`@mastra/memory/processors` export has been removed. All processors are now exported from `@mastra/core/processors`. This change consolidates all processor exports in a single location.

마이그레이션하려면 다음에서 가져오기 경로를 업데이트하세요.`@mastra/memory/processors` to `@mastra/core/processors`.

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
