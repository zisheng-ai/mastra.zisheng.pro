# 프로세서

일관된 이름 지정 패턴과 데이터베이스 메시지 유형을 사용하도록 프로세서 인터페이스가 업데이트되었습니다.

## 변경됨 {/* #changed */}

### 프로세서 구성을 `name`에서 `id`로 변경 {/* #processor-configuration-from-name-to-id */}
이제 프로세서에는 `name` 대신 `id` 필드가 필요합니다. `name` 필드는 이제 선택 사항입니다. 이 변경으로 채점기 및 Agent 같은 다른 Mastra 엔터티와의 일관성이 향상됩니다.
마이그레이션하려면 `id`를 필수 필드로 사용하도록 프로세서 정의를 업데이트하세요.
```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### 프로세서 메시지 타입을 `MastraMessageV2`에서 `MastraDBMessage`로 변경 {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}
프로세서 메시지 타입이 `MastraMessageV2`에서 `MastraDBMessage`로 변경되었습니다. 이제 프로세서와 채점기는 데이터베이스 메시지 형식 및 해당 타입을 사용합니다.
마이그레이션하려면 프로세서 메시지 유형 가져오기 및 사용량을 업데이트하세요.

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 제거됨 {/* #removed */}

### 더 이상 사용되지 않는 입력 프로세서 내보내기 {/* #deprecated-input-processor-exports */}

내장 프로세서를 포함하는 더 이상 사용되지 않는 입력 프로세서 내보내기가 `@mastra/core/agent/input-processors/processors`에서 제거되었습니다. 대신 `@mastra/core/processors`를 사용하세요. 이 변경으로 프로세서 타입이 통합 `Processor` 인터페이스 아래에 모입니다.
`InputProcessor`를 사용했다면 `processInput` 함수를 구현하는 `Processor`로 바꾸세요.
```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory 프로세서 수출이 코어로 이동됨 {/* #memory-processor-exports-moved-to-core */}

`@mastra/memory/processors` 내보내기가 제거되었습니다. 이제 모든 프로세서는 `@mastra/core/processors`에서 내보냅니다. 이 변경으로 모든 프로세서 내보내기가 한곳에 통합됩니다.
마이그레이션하려면 가져오기 경로를 `@mastra/memory/processors`에서 `@mastra/core/processors`로 업데이트하세요.
```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
