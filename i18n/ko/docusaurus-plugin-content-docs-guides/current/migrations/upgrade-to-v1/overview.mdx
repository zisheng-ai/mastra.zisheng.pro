# Mastra v1로 업그레이드

:::정보\[최신 0.x 버전으로 업데이트]
v1로 업그레이드하기 전에 최신 0.x 버전의 Mastra로 업데이트했는지 확인하세요. 따라가다[upgrade to latest 0.x guide](https://mastra.ai/guides/v0/migrations/upgrade-to-latest-0x)먼저 여기로 돌아와서 v1 마이그레이션을 완료하세요.
:::

Mastra v1은 2026년 1월에 출시되었습니다. Mastra v1을 사용하여 새 프로젝트를 시작하거나 기존 프로젝트를 업그레이드하여 계속 업데이트와 지원을 받는 것이 좋습니다.

이 가이드에서는 Mastra 0.x에서 v1.0으로 업그레이드할 때의 주요 변경 사항을 다룹니다. 마이그레이션은 코드베이스를 체계적으로 업데이트하는 데 도움이 되도록 패키지 및 기능 영역별로 구성됩니다.

:::팁\[도움이 필요하신가요?]
마이그레이션에 도움이 필요하십니까? 우리의[Discord community](https://discord.gg/BTYqqHKUrf) to ask questions.
:::

:::경고\[Mastra Cloud에서 나오나요?]
레거시 Mastra Cloud 제품이 다음으로 대체되었습니다.[Mastra platform](/docs/mastra-platform/overview), which splits hosting into two separate products: **Studio** (visual environment, observability) and **Server** (production API). Old Mastra Cloud access tokens don't work with Mastra platform. Create new ones with `mastra auth tokens create`.

마이그레이션하지 않고 v1 패키지로 업그레이드하는 경우`telemetry:` config to `observability:` and creating a Studio project, observability data will stop flowing. Follow the [Mastra Cloud migration guide](/guides/migrations/mastra-cloud) end to end.
:::

## 마이그레이션 전략 {/* #migration-strategy */}

### 모든 Mastra 패키지를 다음으로 업데이트하세요.`latest` tag {/* #update-all-mastra-packages-to-latest-tag */}

패키지 관리자를 사용하여 프로젝트 버전을 업데이트하세요. 업데이트**all** Mastra packages together to ensure compatibility (all `@mastra/*` packages and `mastra`).

가장 일반적으로 사용되는 패키지를 업데이트하는 방법은 다음과 같습니다.

```bash npm2yarn
npm install @mastra/core@latest @mastra/loggers@latest @mastra/memory@latest mastra@latest
```

다음을 사용하여 다른 Mastra 패키지를 설치하십시오.`@latest` tag and you'll get the latest v1 version available. Be sure to update all Mastra packages (especially if you're in a monorepo) to avoid version mismatches.

### Node.js 버전 업데이트 {/* #update-nodejs-version */}

Mastra v1에는 Node.js가 필요합니다.**22.13.0** or higher. Update your development and production environments accordingly.

### 마이그레이션 체크리스트 살펴보기 {/* #go-through-migration-checklist */}

다음을 통해 작업하세요.[migration checklist](#migration-checklist) below to update your codebase. Each item links to a detailed guide for that specific change.

:::정보\[코드수정]

자동화를 준비했습니다[codemods](https://github.com/mastra-ai/mastra/tree/main/packages/codemod) for you. If you want, you can run all v1 codemods at once:

```bash
npx @mastra/codemod@latest v1
```

:::

:::note\[데이터베이스 마이그레이션 필요]

PostgreSQL 또는 LibSQL 스토리지를 사용하는 경우 데이터베이스 마이그레이션을 실행해야 합니다. 참조[Storage migration guide](/guides/migrations/upgrade-to-v1/storage#database-migration) for details.

:::

## 영역별 주요 변경 사항 {/* #breaking-changes-by-area */}

* **[마스트라 클래스](/guides/migrations/upgrade-to-v1/mastra)**- 구조 조정 및 자산 접근 변경 사항을 가져옵니다.
* **[Agent 클래스](/guides/migrations/upgrade-to-v1/agent)**- 음성 메소드가 네임스페이스로 이동되었으며 스트리밍 API가 업데이트되었습니다.
* **[Tool](/guides/migrations/upgrade-to-v1/tools)**- CreateTool 실행 서명이 입력과 컨텍스트를 분리하도록 변경되었습니다.
* **[Workflow](/guides/migrations/upgrade-to-v1/workflows)**- 기능 이름 변경 및 레거시 기능이 제거되었습니다.
* **[Memory](/guides/migrations/upgrade-to-v1/memory)**- 구성에는 이제 명시적인 매개변수가 필요하며 기본값이 변경되었습니다.
* **[저장](/guides/migrations/upgrade-to-v1/storage)**- 페이지 매김이 표준화되고 메소드 이름이 목록 패턴으로 변경되었습니다.
* **[벡터](/guides/migrations/upgrade-to-v1/vectors)**- 벡터 저장 메소드의 이름이 목록 패턴으로 변경되었습니다.
* **[조각](/guides/migrations/upgrade-to-v1/rag)**- 명확성을 위해 매개변수 이름이 업데이트되었습니다.
* **[MCP](/guides/migrations/upgrade-to-v1/mcp)**- Tool 컨텍스트가 재구성되고 더 이상 사용되지 않는 클라이언트 클래스가 제거되었습니다.
* **[트레이싱](/guides/migrations/upgrade-to-v1/tracing)**- OTEL 원격 측정은 전용 관찰 패키지 및 내보내기로 대체되었습니다.
* **[평가 및 득점자](/guides/migrations/upgrade-to-v1/evals)**- Scorers API가 새로운 명명 규칙으로 통합되었습니다.
* **[CLI](/guides/migrations/upgrade-to-v1/cli)**- 더 간단한 인터페이스를 위해 명령과 플래그가 제거되었습니다.
* **[전개](/guides/migrations/upgrade-to-v1/deployment)**- 표준 wrangler.json 속성 이름을 사용하도록 CloudflareDeployer 구성이 업데이트되었습니다.
* **[클라이언트 SDK](/guides/migrations/upgrade-to-v1/client)**- 일관성을 위해 유형 및 유틸리티 이름이 변경되었습니다.
* **[음성 패키지](/guides/migrations/upgrade-to-v1/voice)**- 패키지 이름이 음성에서 음성으로 변경되었습니다.

## 마이그레이션 체크리스트 {/* #migration-checklist */}

대부분의 애플리케이션에 영향을 미치는 큰 영향을 미치는 변경 사항부터 시작하여 이 체크리스트를 순서대로 진행하세요.

:::정보\[코드수정]

자동화를 준비했습니다[codemods](https://github.com/mastra-ai/mastra/tree/main/packages/codemod) for you. Throughout the migration guide you'll find instructions on how to use them for specific changes.

원하는 경우 모든 v1 codemod를 한 번에 실행할 수 있습니다.

```bash
npx @mastra/codemod@latest v1
```

:::

### 큰 영향을 미치는 변경 사항 {/* #high-impact-changes */}

* 업데이트`createTool` tool signatures to `(inputData, context)` format - [Tools](/guides/migrations/upgrade-to-v1/tools)
* 구조조정`@mastra/core` imports to use subpath imports - [Mastra Class](/guides/migrations/upgrade-to-v1/mastra)
* 다음에서 페이지 매김 업데이트`offset/limit` to `page/perPage` - [Storage](/guides/migrations/upgrade-to-v1/storage)
* 설치하다`@mastra/observability` and wrap configuration with `new Observability()` - [Tracing](/guides/migrations/upgrade-to-v1/tracing)
* 다음에서 마이그레이션`telemetry:` to `observability:` configuration (if upgrading from 0.x OTEL) - [Tracing](/guides/migrations/upgrade-to-v1/tracing)

### 중간 영향 변경 {/* #medium-impact-changes */}

* 이름 바꾸기`RuntimeContext` to `RequestContext` throughout codebase - [Agent Class](/guides/migrations/upgrade-to-v1/agent), [Tools](/guides/migrations/upgrade-to-v1/tools), [Workflows](/guides/migrations/upgrade-to-v1/workflows)
* 저장 방법 업데이트:`get*` to `list*` pattern - [Storage](/guides/migrations/upgrade-to-v1/storage)
* 직접 속성 액세스를 getter 메소드로 대체 -[Mastra Class](/guides/migrations/upgrade-to-v1/mastra), [Agent Class](/guides/migrations/upgrade-to-v1/agent)
* 기본값을 사용하는 경우 Memory 범위 업데이트`thread` scope - [Memory](/guides/migrations/upgrade-to-v1/memory)
* 명명된 인수를 사용하도록 벡터 저장소 호출을 업데이트합니다.[Storage](/guides/migrations/upgrade-to-v1/storage)
* 제거하다`format` parameter from agent methods - [Agent Class](/guides/migrations/upgrade-to-v1/agent)
* 사용할 음성 방법 업데이트`agent.voice` namespace - [Agent Class](/guides/migrations/upgrade-to-v1/agent)
* 구성 속성 이름 바꾸기`processors` to `spanOutputProcessors` (if using custom processors) - [Tracing](/guides/migrations/upgrade-to-v1/tracing)

### 영향이 적은 변경 사항 {/* #low-impact-changes */}

* 이름 바꾸기`keepSeparator` to `separatorPosition` in chunk options - [RAG](/guides/migrations/upgrade-to-v1/rag)
* 이름 바꾸기`createRunAsync` to `createRun` - [Workflows](/guides/migrations/upgrade-to-v1/workflows)
* 다음에서 음성 패키지 이름 업데이트`@mastra/speech-*` to `@mastra/voice-*` - [Voice Packages](/guides/migrations/upgrade-to-v1/voice)
* 채점 방법 업데이트:`runExperiment` → `runEvals`, `getScorerByName` → `getScorerById` - [Evals & Scorers](/guides/migrations/upgrade-to-v1/evals)
* 더 이상 사용되지 않는 CLI 플래그 제거 -[CLI](/guides/migrations/upgrade-to-v1/cli)
* 클라이언트 SDK 유형 업데이트:`Get*` to `List*` - [Client SDKs](/guides/migrations/upgrade-to-v1/client)
* 바꾸다`runCount` with `retryCount` - [Workflows](/guides/migrations/upgrade-to-v1/workflows)
* 맞춤 내보내기 방법 업데이트`exportEvent` to `exportTracingEvent` (if using custom exporters) - [Tracing](/guides/migrations/upgrade-to-v1/tracing)
