# 전개

OpenAPI 사양 엔드포인트가 다음으로 이동되었습니다.`/api/openapi.json`, 그리고`CloudflareDeployer`표준을 사용하도록 구성이 업데이트되었습니다.`wrangler.json`속성 이름.

## 변경됨 {/* #changed */}

### OpenAPI 사양 엔드포인트가 다음으로 이동되었습니다.`/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 사양 엔드포인트가 다음에서 이동되었습니다.`/openapi.json` to `/api/openapi.json` to align with the `/api` prefix used by all built-in Mastra routes.

OpenAPI 사양을 사용하는 스크립트나 Tool가 있는 경우 URL을 업데이트하세요.

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer`표준을 사용한다`wrangler.json` property names {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

그만큼`CloudflareDeployer` constructor now accepts standard `wrangler.json` property names instead of custom camelCase variants. This change aligns the deployer with Cloudflare's official configuration format and provides access to all wrangler configuration options.

더 이상 사용되지 않는 필드는 런타임 시 콘솔 경고와 함께 자동으로 마이그레이션되지만 새 필드 이름을 사용하려면 코드를 업데이트해야 합니다.

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

그만큼`workerNamespace` field has been removed as it's no longer used.

사용 가능한 모든 구성 옵션은 다음을 참조하세요.[Wrangler configuration documentation](https://developers.cloudflare.com/workers/wrangler/configuration/).
