# 조각

RAG 패키지는 청킹 매개변수의 이름을 바꾸고 유형을 좁혔습니다.

## 변경됨 {/* #changed */}

### `keepSeparator`에게`separatorPosition` {/* #keepseparator-to-separatorposition */}

그만큼`keepSeparator` parameter has been renamed to `separatorPosition` with a simplified type. The old parameter had a confusing `boolean | 'start' | 'end'`어디에 입력하세요`true`비밀리에 가명이었습니다`'start'`. 새 매개변수는 명시적 사용`'start' | 'end'`값을 사용하며 매개변수를 생략하면 구분 기호가 삭제됩니다.

마이그레이션하려면 교체하세요.`keepSeparator` with `separatorPosition` using the mapping below:

| 이전 값 | 새로운 가치 |
| - | - |
|`keepSeparator: true` | `separatorPosition: 'start'` |
| `keepSeparator: 'start'` | `separatorPosition: 'start'` |
| `keepSeparator: 'end'` | `separatorPosition: 'end'` |
| `keepSeparator: false` | Remove the parameter |
| Parameter omitted | No change needed |

```diff
  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: true,
+   separatorPosition: 'start',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: 'end',
+   separatorPosition: 'end',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: false,
+   // Parameter removed - separator is discarded by default
  });
```
