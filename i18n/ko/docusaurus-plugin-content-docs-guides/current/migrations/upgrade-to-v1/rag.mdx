# 조각

RAG 패키지는 청킹 매개변수의 이름을 바꾸고 유형을 좁혔습니다.

## 변경됨 {/* #changed */}

### `keepSeparator`에게`separatorPosition` {/* #keepseparator-to-separatorposition */}

`keepSeparator` 매개변수의 이름이 `separatorPosition`으로 변경되고 타입이 단순화되었습니다. 이전 매개변수는 혼동을 일으키는 `boolean | 'start' | 'end'` 타입을 사용했으며, 여기서 `true`는 내부적으로 `'start'`의 별칭이었습니다. 새 매개변수는 명시적인 `'start' | 'end'` 값을 사용하며 매개변수를 생략하면 구분 기호가 제거됩니다.
마이그레이션하려면 아래 매핑을 사용하여 `keepSeparator`를 `separatorPosition`으로 바꾸세요.
| 이전 값 | 새 값 |
| - | - |
|`keepSeparator: true` | `separatorPosition: 'start'` |
| `keepSeparator: 'start'` | `separatorPosition: 'start'` |
| `keepSeparator: 'end'` | `separatorPosition: 'end'` |
| `keepSeparator: false` | 매개변수 제거 |
| 매개변수 생략 | 변경 필요 없음 |
```diff
  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: true,
+   separatorPosition: 'start',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: 'end',
+   separatorPosition: 'end',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: false,
+   // Parameter removed - separator is discarded by default
  });
```
