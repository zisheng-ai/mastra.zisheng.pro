# SDK Agent

SDK Agent를 사용하면 Mastra 내에서 다른 Agent SDK 프레임워크를 사용할 수 있습니다. 공급자 SDK가 자체 런타임, Tool, 권한 및 Agent 루프를 유지하는 동안 이를 사용하여 Mastra 프로젝트에 SDK 지원 Agent를 등록합니다.

## SDK Agent를 사용하는 경우 {/* #when-to-use-sdk-agents */}

* 공급업체 SDK는 이미 Agent 루프, Tool, 권한 또는 로컬 런타임을 소유하고 있습니다.
* Mastra 프로젝트에 해당 SDK 지원 Agent를 등록하려고 합니다.
* Mastra 호환이 필요합니다`generate()` and `stream()` outputs.
* SDK 실행의 사용량, 비용 및 Tool 활동이 Mastra 관측 가능성에 표시되기를 원합니다.

## 지원되는 SDK Agent {/* #supported-sdk-agents */}

* [클로드 Agent SDK](#claude-agent-sdk): 사용`@mastra/claude` to register a Claude SDK agent and call it with Mastra `generate()` and `stream()`.
* [커서 Agent SDK](#cursor-agent-sdk): 사용`@mastra/cursor` to register a Cursor SDK agent and call it with Mastra `generate()` and `stream()`.
* [OpenAI Agent SDK](#openai-agents-sdk): 사용`@mastra/openai` to register an OpenAI SDK agent and call it with Mastra `generate()` and `stream()`.

## 클로드 Agent SDK {/* #claude-agent-sdk */}

사용`@mastra/claude` for Claude Code runtime configuration, permissions, tools, and agent-loop behavior.

### 클로드 패키지 설치 {/* #install-claude-packages */}

Mastra 패키지와 Claude Agent SDK 피어 종속성을 설치합니다.

```bash npm2yarn
npm install @mastra/claude @anthropic-ai/claude-agent-sdk
```

Claude SDK 자격 증명을 설정합니다.

```bash
export ANTHROPIC_API_KEY="..."
```

### Claude SDK Agent 만들기 {/* #create-a-claude-sdk-agent */}

Claude Agent SDK를 다음을 통해 구성하세요.`sdkOptions`.

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { ClaudeSDKAgent } from '@mastra/claude'

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
  },
})
```

### Claude SDK Tool 추가 {/* #add-claude-sdk-tools */}

Claude Agent SDK Tool는 Claude SDK MCP(Model Context Protocol) 서버를 통해 제공됩니다. Claude SDK로 서버를 생성한 후 이를 전달합니다.`sdkOptions.mcpServers`.

```typescript title="src/mastra/agents/claude-sdk-agent.ts"
import { createSdkMcpServer } from '@anthropic-ai/claude-agent-sdk'
import { ClaudeSDKAgent } from '@mastra/claude'
import { getTemperature } from '../tools/get-temperature'

const weatherServer = createSdkMcpServer({
  name: 'weather',
  version: '1.0.0',
  tools: [getTemperature],
})

export const claudeSDKAgent = new ClaudeSDKAgent({
  id: 'claude-sdk-agent',
  name: 'Claude SDK Agent',
  description: 'Use Claude Agent SDK through Mastra.',
  sdkOptions: {
    model: '__AI_SDK_ANTHROPIC_MODEL_SONNET__',
    cwd: process.cwd(),
    mcpServers: {
      weather: weatherServer,
    },
    allowedTools: ['mcp__weather__get_temperature'],
  },
})
```

그만큼`allowedTools` value uses Claude Agent SDK MCP tool naming: `mcp__<server name>__<tool name>`.

## 커서 Agent SDK {/* #cursor-agent-sdk */}

사용`@mastra/cursor` to register a Cursor SDK agent in Mastra while keeping Cursor-specific setup in Cursor SDK options.

### 커서 패키지 설치 {/* #install-cursor-packages */}

Mastra 패키지와 Cursor SDK 피어 종속성을 설치합니다.

```bash npm2yarn
npm install @mastra/cursor @cursor/sdk
```

커서 SDK 자격 증명을 설정합니다.

```bash
export CURSOR_API_KEY="..."
```

### 커서 SDK Agent 만들기 {/* #create-a-cursor-sdk-agent */}

다음을 통해 커서 Agent SDK를 구성합니다.`sdkOptions`.

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
  },
})
```

커서 로컬 Agent에는 명시적 Model이 필요합니다. 설정하세요`sdkOptions.model`.

### 기존 Cursor SDK Agent 사용 {/* #use-an-existing-cursor-sdk-agent */}

앱이 이미 Cursor SDK Agent를 생성한 경우 해당 Agent를`CursorSDKAgent` instead:

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { Agent as CursorAgent } from '@cursor/sdk'
import { CursorSDKAgent } from '@mastra/cursor'

const cursorAgent = CursorAgent.create({
  apiKey: process.env.CURSOR_API_KEY,
  model: {
    id: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
  local: {
    cwd: process.cwd(),
  },
})

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  agent: cursorAgent,
})
```

### 커서 SDK Tool 추가 {/* #add-cursor-sdk-tools */}

커서 Agent SDK Tool는 커서 SDK 옵션으로 구성됩니다. MCP(Model Context Protocol) 서버를 다음을 통해 전달합니다.`sdkOptions.mcpServers`:

```typescript title="src/mastra/agents/cursor-sdk-agent.ts"
import { CursorSDKAgent } from '@mastra/cursor'
import { mcpServers } from '../mcp/cursor'

export const cursorSDKAgent = new CursorSDKAgent({
  id: 'cursor-sdk-agent',
  name: 'Cursor SDK Agent',
  description: 'Use Cursor Agent SDK through Mastra.',
  sdkOptions: {
    apiKey: process.env.CURSOR_API_KEY,
    model: {
      id: '__AI_SDK_OPENAI_MODEL_BASE__',
    },
    local: {
      cwd: process.cwd(),
    },
    mcpServers,
  },
})
```

## OpenAI Agent SDK {/* #openai-agents-sdk */}

사용`@mastra/openai` to register an OpenAI Agents SDK agent in Mastra while keeping OpenAI-specific agent settings in OpenAI SDK options.

### OpenAI 패키지 설치 {/* #install-openai-packages */}

Mastra 패키지와 OpenAI Agents SDK 피어 종속성을 설치합니다.

```bash npm2yarn
npm install @mastra/openai @openai/agents zod
```

OpenAI SDK 자격 증명을 설정합니다.

```bash
export OPENAI_API_KEY="..."
```

### OpenAI SDK Agent 만들기 {/* #create-an-openai-sdk-agent */}

다음을 통해 OpenAI Agent SDK를 구성하세요.`sdkOptions`. `OpenAISDKAgent` creates the OpenAI SDK agent on first use.

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { OpenAISDKAgent } from '@mastra/openai'

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Repository assistant',
    instructions: 'Answer clearly and cite the relevant files.',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
  },
})
```

### 기존 OpenAI SDK Agent 사용 {/* #use-an-existing-openai-sdk-agent */}

앱이 이미 OpenAI SDK Agent를 생성한 경우 해당 Agent를`OpenAISDKAgent` instead:

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { Agent as OpenAIAgent } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'

const sdkAgent = new OpenAIAgent({
  name: 'Repository assistant',
  instructions: 'Answer clearly and cite the relevant files.',
  model: '__AI_SDK_OPENAI_MODEL_BASE__',
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  agent: sdkAgent,
})
```

### OpenAI SDK Tool 추가 {/* #add-openai-sdk-tools */}

OpenAI Agents SDK Tool는 OpenAI SDK 옵션으로 구성됩니다. OpenAI SDK로 Tool를 만든 후 전달하세요.`sdkOptions.tools`.

```typescript title="src/mastra/agents/openai-sdk-agent.ts"
import { tool } from '@openai/agents'
import { OpenAISDKAgent } from '@mastra/openai'
import { z } from 'zod'

const getTemperature = tool({
  name: 'get_temperature',
  description: 'Get the current temperature for a city.',
  parameters: z.object({
    city: z.string(),
  }),
  execute: async ({ city }) => {
    return `${city}: 27 C`
  },
})

export const openaiSDKAgent = new OpenAISDKAgent({
  id: 'openai-sdk-agent',
  name: 'OpenAI SDK Agent',
  description: 'Use OpenAI Agents SDK through Mastra.',
  sdkOptions: {
    name: 'Weather assistant',
    model: '__AI_SDK_OPENAI_MODEL_BASE__',
    tools: [getTemperature],
  },
})
```

## SDK Agent 등록 {/* #register-sdk-agents */}

다른 Agent와 마찬가지로 Mastra 인스턴스에 SDK Agent를 등록합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { claudeSDKAgent } from './agents/claude-sdk-agent'
import { cursorSDKAgent } from './agents/cursor-sdk-agent'
import { openaiSDKAgent } from './agents/openai-sdk-agent'

export const mastra = new Mastra({
  agents: {
    claudeSDKAgent,
    cursorSDKAgent,
    openaiSDKAgent,
  },
})
```

등록 후 전화로 문의하세요`mastra.getAgentById()`:

```typescript title="src/mastra/run-sdk-agent.ts"
import { mastra } from './index'

const agent = mastra.getAgentById('cursor-sdk-agent')
const stream = await agent.stream('Inspect this project and describe the test setup.')

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

## SDK 실행 재개 {/* #resume-sdk-runs */}

SDK Agent는 Mastra를 지원합니다.`resumeGenerate()` and `resumeStream()` with provider-native resume data. Pass the message to continue with and the resume identifier used by the underlying SDK.

Claude SDK Agent는 다음을 통해 알려진 세션을 재개할 수 있습니다.`sessionId`:

```typescript title="src/mastra/resume-claude.ts"
const result = await claudeSDKAgent.resumeGenerate({
  message: 'Continue the previous task.',
  sessionId: 'claude-session-id',
})

console.log(result.text)
```

OpenAI SDK Agent는 이전 응답, 대화 또는 세션을 재개할 수 있습니다.

```typescript title="src/mastra/resume-openai.ts"
const stream = await openaiSDKAgent.resumeStream({
  message: 'Continue the previous task.',
  previousResponseId: 'resp_123',
})

for await (const chunk of stream.textStream) {
  process.stdout.write(chunk)
}
```

커서 SDK Agent는 래핑된 SDK Agent를 계속 사용할 수 있습니다. ID별로 저장된 Cursor SDK Agent를 재개해야 하는 경우`agentId` in `resumeData`.

## 구조화된 출력 {/* #structured-output */}

Claude 및 OpenAI SDK Agent는 Mastra를 지원합니다.`structuredOutput` through their provider-native structured output APIs. The validated value is available on `result.object`.

```typescript title="src/mastra/run-openai-structured-output.ts"
import { z } from 'zod'

const result = await openaiSDKAgent.generate<{ summary: string }>('Summarize this project.', {
  structuredOutput: {
    schema: z.object({
      summary: z.string(),
    }),
  },
})

console.log(result.object.summary)
```

Cursor SDK Agent는 다음과 같은 경우 명확한 오류를 발생시킵니다.`structuredOutput` is requested because the Cursor TypeScript SDK doesn't expose a schema-constrained output API.

## Observability {/* #observability */}

SDK Agent는 다음을 위한 Mastra Agent 및 Model 범위를 생성합니다.`generate()` and `stream()` calls. Mastra records SDK-provided usage, tool activity, and provider metadata when the vendor SDK exposes those events.

Claude SDK 실행에는 Claude 결과 메시지의 SDK 추정 비용이 포함될 수 있습니다. Cursor SDK 실행에는 Cursor 상호 작용 업데이트의 토큰 사용이 포함됩니다. OpenAI SDK 실행에는 OpenAI 실행 상태의 토큰 사용이 포함됩니다.

저장소 및 대시보드 설정에 대해서는 다음을 참조하세요.[Observability](/docs/observability/overview).
