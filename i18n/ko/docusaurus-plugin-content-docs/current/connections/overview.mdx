# 연결 개요

연결을 통해 Mastra는 원격 Agent, 코딩 Agent, 공급자 소프트웨어 개발 키트(SDK) 런타임, 외부 Tool 및 리소스와 함께 작업할 수 있습니다. Agent 런타임을 소유한 시스템과 교환해야 하는 항목에 따라 연결 유형을 선택합니다.

* [**Agent 간(A2A)**](/docs/agents/a2a): 서비스, 프레임워크, 공급업체 및 언어 경계를 넘어 원격 Agent를 노출하거나 사용합니다.
* [**ACP(Agent 클라이언트 프로토콜)**](/docs/agents/acp): 호환되는 코딩 Agent 프로세스를 Mastra Tool 또는 하위 Agent로 실행합니다.
* [**SDK Agent**](/docs/agents/sdk-agents): 공급자 SDK가 런타임, Tool, 권한 및 Agent 루프에 대한 제어를 유지하는 동안 Claude, Cursor 또는 OpenAI SDK 지원 Agent를 등록합니다.
* [**Model 컨텍스트 프로토콜(MCP)**](/docs/mcp/overview): Agent를 외부 Tool 및 리소스에 연결하거나 Mastra Agent, Tool, Workflow, Prompt 및 리소스를 MCP 호환 시스템에 노출합니다.

## 연결을 사용하는 경우 {/* #when-to-use-connections */}

다음이 필요한 경우 연결을 사용하세요.

* 다른 서비스나 런타임에서 실행 중인 Agent에 작업을 위임합니다.
* 프로젝트 작업공간에 대해 코딩 Agent를 실행합니다.
* SDK 런타임이나 Agent 루프를 교체하지 않고 공급자 기반 Agent를 추가합니다.
* Agent를 외부 Tool 및 리소스에 연결하거나 Mastra 기능을 다른 시스템에 게시하세요.

## 시작하기 {/* #get-started */}

먼저 넘어야 할 경계를 파악하세요. 원격 Agent 엔드포인트에는 [A2A](/docs/agents/a2a), 코딩 Agent 프로세스에는 [ACP](/docs/agents/acp), Provider 소유 런타임에는 [SDK Agent](/docs/agents/sdk-agents), Tool과 리소스에는 [MCP](/docs/mcp/overview)를 사용하세요.
<Tabs>
  <TabItem value="a2a" label="A2A">
    ```typescript
    import { A2AAgent } from '@mastra/core/a2a'

    const agent = new A2AAgent({
      url: 'https://agent.example.com/.well-known/agent-card.json',
    })

    const result = await agent.generate('Summarize the latest report')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="acp" label="ACP">
    ```typescript
    import { AcpAgent } from '@mastra/acp'

    const agent = new AcpAgent({
      id: 'coding-agent',
      description: 'Inspects and edits code',
      command: 'claude',
      args: ['--acp'],
      persistSession: false,
    })

    const result = await agent.generate('Review this project')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="sdk-agents" label="SDK agents">
    ```typescript
    import { OpenAISDKAgent } from '@mastra/openai'

    const agent = new OpenAISDKAgent({
      id: 'openai-agent',
      description: 'Answers project questions',
      sdkOptions: {
        name: 'Project assistant',
        model: '__AI_SDK_OPENAI_MODEL_BASE__',
      },
    })

    const result = await agent.generate('Explain agent loops in one sentence')
    console.log(result.text)
    ```
  </TabItem>

  <TabItem value="mcp" label="MCP">
    ```typescript
    import { MCPClient } from '@mastra/mcp'

    const client = new MCPClient({
      id: 'wikipedia-client',
      servers: {
        wikipedia: {
          command: 'npx',
          args: ['-y', 'wikipedia-mcp'],
        },
      },
    })

    try {
      const tools = await client.listTools()
      console.log(Object.keys(tools))
    } finally {
      await client.disconnect()
    }
    ```
  </TabItem>
