# 내구성 있는 Agent

**추가된 항목:** `@mastra/core@1.45.0`

:::경고

지속형 Agent는 현재**beta**. APIs may change in future releases.

:::

내구성 있는 Agent가 일반 Agent를 래핑합니다.[`Agent`](/docs/agents/overview) so the agentic loop runs inside a workflow. Events flow through [PubSub](/docs/server/pubsub), which means a client can disconnect and reconnect without missing chunks. The run state is persisted, so it survives process restarts.

## 내구성 Agent를 사용해야 하는 경우 {/* #when-to-use-durable-agents */}

다음 중 하나에 해당하는 경우 내구성 있는 Agent를 사용하십시오.

* 클라이언트가 중간 스트림(모바일, 불안정한 네트워크, 장시간 실행되는 통화)을 끊었다가 다시 연결할 수 있습니다.
* Agent 루프는 단일 HTTP 요청(백그라운드 조사, 다단계 Tool 사용)보다 오래 지속될 수 있습니다.
* 두 번째 클라이언트가 첫 번째 클라이언트가 시작한 스트림을 선택하는 관찰/재연결 API가 필요합니다.
* 당신이 원하는[Inngest-powered execution](/guides/deployment/inngest) with step memoization, retries, and monitoring.

클라이언트가 연결 상태를 유지하는 단기 요청 범위 호출의 경우 정기적인`Agent` with `stream()` or `generate()` is simpler.

## 빠른 시작 {/* #quickstart */}

기존 Agent를 다음으로 래핑합니다.`createDurableAgent()` from `@mastra/core/agent/durable`:

```typescript title="src/mastra/agents/researcher.ts"
import { Agent } from '@mastra/core/agent'
import { createDurableAgent } from '@mastra/core/agent/durable'

const agent = new Agent({
  id: 'researcher',
  name: 'Researcher',
  instructions: 'You research topics thoroughly.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const durableResearcher = createDurableAgent({ agent })
```

Mastra에 지속형 Agent를 등록하고 호출합니다.`stream()`:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { durableResearcher } from './agents/researcher'

const mastra = new Mastra({
  agents: { durableResearcher },
})

const { output, runId, cleanup } = await durableResearcher.stream(
  'Research quantum computing advances in 2025',
)

for await (const chunk of output.fullStream) {
  // Process each chunk as it arrives
}

// Release PubSub subscriptions and clear the run from the registry.
// If you skip this, an automatic cleanup timer fires after the stream ends.
cleanup()
```

반환된`runId` identifies the execution. Pass it to `observe()` to reconnect from a different client. Visit the [DurableAgent reference](/reference/agents/durable-agent) for the full configuration and method API.

## 작동 원리 {/* #how-it-works */}

지속성 Agent는 일반 Agent 위에 세 개의 레이어를 추가합니다.

1. **Workflow 실행**: `stream()` serializes the messages and options into a workflow input, then triggers the agentic loop inside a durable workflow. The workflow runs the same loop as `Agent.stream()` but each step can be memoized and replayed.

2. **PubSub 스트리밍**: 루프가 실행되면 실행 ID로 키가 지정된 PubSub 주제에 청크가 게시됩니다. 호출자는 이 주제를 구독하고 청크를`ReadableStream`. If the caller disconnects and reconnects, missed chunks are replayed from the cache.

3. **캐시 레이어**: 선택적 캐시(기본적으로 인Memory, Redis 또는 프로덕션의 다른 백엔드)는 늦게 구독자가 따라잡을 수 있도록 게시된 이벤트를 저장합니다.

## 실행 변형 {/* #execution-variants */}

Mastra는 내구성 있는 Agent를 생산하는 세 가지 공장 기능을 제공합니다. Workflow가 실행되는 방식이 다릅니다.

| 공장 | 패키지 | |
| - | - | - |
|`createDurableAgent()` | `@mastra/core` | Local development and single-process servers. You get a stream you can await directly. |
| `createEventedAgent()` | `@mastra/core` | Background execution. The workflow starts without blocking, and you consume chunks through PubSub. |
| `createInngestAgent()` | `@mastra/inngest` | Production deployments. Inngest adds step memoization, retries, and a monitoring dashboard. |

세 가지 모두 등록한 객체를 반환합니다.`Mastra` the same way as a regular agent. `createDurableAgent()` and `createEventedAgent()` return class instances that extend `Agent`. `createInngestAgent()` returns a Proxy-backed object that forwards `Agent` methods to the underlying agent.

### 처리 중`createDurableAgent()` {/* #in-process-with-createdurableagent */}

Agent을 포장하고 전화하세요.`stream()`. You get a `DurableAgentStreamResult` back in the same process. No external infrastructure is required, so this is the fastest way to get started:

```typescript title="src/mastra/agents/durable.ts"
import { Agent } from '@mastra/core/agent'
import { createDurableAgent } from '@mastra/core/agent/durable'

const agent = new Agent({
  id: 'helper',
  instructions: 'You are a helpful assistant.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const durableHelper = createDurableAgent({ agent })
```

### 실행 후 잊어버리세요`createEventedAgent()` {/* #fire-and-forget-with-createeventedagent */}

Workflow는 호출자를 차단하지 않고 백그라운드에서 시작됩니다. 여전히 PubSub를 통해 청크를 수신하므로`stream()` returns a result you can consume. The HTTP handler that triggered the run doesn't need to wait for the workflow to finish:

```typescript title="src/mastra/agents/evented.ts"
import { Agent } from '@mastra/core/agent'
import { createEventedAgent } from '@mastra/core/agent/durable'

const agent = new Agent({
  id: 'writer',
  instructions: 'You write articles.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const eventedWriter = createEventedAgent({ agent })
```

### Ingest 기반`createInngestAgent()` {/* #inngest-powered-with-createinngestagent */}

Workflow를 실행합니다.[Inngest](https://www.inngest.com/docs) platform. Each tool call becomes a memoized step that Inngest can retry independently, and you get a dashboard for monitoring runs:

```typescript title="src/mastra/agents/inngest.ts"
import { Agent } from '@mastra/core/agent'
import { createInngestAgent } from '@mastra/inngest'
import { Inngest } from 'inngest'

const inngest = new Inngest({ id: 'my-app' })

const agent = new Agent({
  id: 'analyst',
  instructions: 'You analyze data.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const inngestAnalyst = createInngestAgent({ agent, inngest })
```

방문[`createInngestAgent()` reference](/reference/agents/inngest-agent) for the full API, including Inngest-specific options like PubSub and cache configuration.

## 재개 가능한 스트림 {/* #resumable-streams */}

지속성 Agent는 PubSub 및 이벤트 캐시를 통해 재개 가능한 스트림을 지원합니다. 클라이언트가 중간 스트림 연결을 끊으면 캐시는 계속해서 이벤트를 저장합니다. 동일한 클라이언트가 호출하여 다시 연결할 수 있습니다.`observe()` with the `runId`:

```typescript title="src/server/reconnect.ts"
const { output, cleanup } = await durableResearcher.observe(runId)

for await (const chunk of output.fullStream) {
  // Chunks from the run, including any missed while disconnected
}

cleanup()
```

`createDurableAgent()`그리고`createEventedAgent()` use an in-memory cache by default, which means resumable streams work within a single process. For production, provide a persistent cache backend (e.g., Redis) so cached events survive process restarts:

```typescript title="src/mastra/agents/durable-with-cache.ts" {2,3,5,9}
import { createDurableAgent } from '@mastra/core/agent/durable'
import { RedisServerCache } from '@mastra/redis'
import Redis from 'ioredis'

const cache = new RedisServerCache({ client: new Redis('redis://localhost:6379') })

export const durableAgent = createDurableAgent({
  agent,
  cache,
})
```

`createInngestAgent()`기본적으로 캐싱을 활성화하지 않습니다. 통과`cache` option or register the agent with a `Mastra` instance that has a `serverCache` configured to enable resumable streams.

## 백그라운드 작업으로 스트리밍 {/* #streaming-with-background-tasks */}

내구성 있는 Agent는 동일한 기능을 지원합니다.[`untilIdle`](/reference/streaming/agents/stream) option as regular agents. When `untilIdle` is set, `stream()` keeps the connection open across background-task continuations until the agent is idle:

```typescript title="src/mastra/run.ts"
const { output, cleanup } = await durableAgent.stream('Research and summarize the topic', {
  untilIdle: true,
  memory: { thread: 'thread-1', resource: 'user-1' },
})

for await (const chunk of output.fullStream) {
  // Chunks from the initial turn AND any follow-up turns triggered by
  // background task completions
}

cleanup()
```

통과하다`{ maxIdleMs }` to customize the idle timeout (defaults to 5 minutes):

```typescript
await durableAgent.stream('Research topic', {
  untilIdle: { maxIdleMs: 30_000 },
  memory: { thread: 'thread-1', resource: 'user-1' },
})
```

방문하다[Background tasks](/docs/long-running-agents/background-tasks) for the full background task guide, including configuration, subagents, and suspend/resume.

## 대청소 {/* #cleanup */}

모든`stream()` and `observe()` call returns a `cleanup` function. Calling it unsubscribes from PubSub and removes the run from the internal registry. If you forget to call it, an automatic timer fires after the stream ends, but calling `cleanup()` yourself frees resources immediately.

## Tool 승인 {/* #tool-approval */}

내구성 있는 Agent는 Tool 승인을 지원합니다(인간 참여형). Tool 호출에 승인이 필요한 경우 Workflow가 일시 중지되고`onSuspended` callback, and waits for the caller to resume with `resume()`:

```typescript title="src/mastra/run.ts" {4}
const { output, runId, cleanup } = await durableAgent.stream('Delete the old records', {
  requireToolApproval: true,
  onSuspended: ({ toolCallId, toolName, args }) => {
    // Notify the user and ask for approval
  },
})
```

승인 후 일시 중단된 실행을 재개합니다.

```typescript
await durableAgent.resume(runId, { approved: true })
```

## 충돌 복구 {/* #crash-recovery */}

지속형 Agent 실행이 진행되는 동안 서버 프로세스가 충돌하는 경우 해당 실행은 그대로 유지됩니다.`running` status in storage with no automatic retry. On the next server start you can re-drive these orphaned runs so they pick up where they left off.

### 자동 복구 {/* #automatic-recovery */}

세트`recovery.durableAgents` to `'auto'` in the Mastra config. The deployer calls `recoverAllDurableAgents()` on boot, right after restarting active workflow runs:

```typescript title="src/mastra/index.ts" {4}
export const mastra = new Mastra({
  agents: { myAgent: durableAgent },
  storage: new PostgresStore({ connectionString: process.env.DATABASE_URL! }),
  recovery: { durableAgents: 'auto' },
})
```

시작 시 실행이 중단된 등록된 모든 내구성 Agent를 검색합니다.`running` status and re-drives them from the last persisted snapshot.

:::경고

복구는 마지막 스냅샷에서 Agent 루프를 다시 실행하여 LLM 호출(실제 비용)을 재발행하고 Tool 호출을 다시 실행합니다. 자동 복구를 활성화하기 전에 Tool가 멱등성인지 확인하세요.

:::

### 수동 복구 {/* #manual-recovery */}

리더 선택 뒤에 복구를 제어하거나 일정에 따라 복구를 실행하는 등 더 세부적인 제어가 필요한 경우 메서드를 직접 호출하세요.

```typescript
// Recover all durable agents
const result = await mastra.recoverAllDurableAgents()
console.log(`Recovered ${result.recovered} runs (${result.succeeded} ok, ${result.failed} failed)`)

// Recover a specific agent
const agentResult = await durableAgent.recoverActiveRuns()

// Recover a single known run
await durableAgent.recoverActiveRuns({ runId: 'run-abc-123' })
```

### 다중 인스턴스 배포 {/* #multi-instance-deployments */}

Mastra는 아직 분산 임대 또는 잠금을 제공하지 않습니다. 다중 복제본 배포에서는 다음으로 시작하는 모든 복제본이`recovery.durableAgents: 'auto'` will race to recover the same runs. For now, either gate recovery behind your own leader election or run it from a single replica.
