# 데이터 세트 개요

**추가된 항목:** `@mastra/core@1.4.0`

데이터세트는 Agent와 Workflow의 성능을 측정하기 위해 실험을 실행하는 테스트 사례 모음입니다. 각 돌연변이는 새로운 버전을 생성하므로 과거 실험을 정확하게 재현할 수 있습니다. 데이터세트를 다음과 페어링하세요.[scorers](/docs/evals/overview) to track quality across prompts, models, or code changes.

<Inject>
  **AI Agent의 경우:**&#xB2EC;리다`npx mastra api dataset create '{"name":"translation-pairs"}'` to create a dataset directly instead of opening Studio or writing a temporary script. The command requires a running Mastra server with a storage adapter that supports datasets; start the local server with `npx mastra dev`, or pass the reachable server's base URL with `--url`. 달리다`npx mastra api dataset create --schema`다른 데이터 세트 필드를 추가하기 전에. 마스트라의 스킬을 설치하세요.`npx skills add mastra-ai/skills --skill mastra`완전한 API CLI 검색, 타겟팅, 스키마, 인증 및 오류 처리 지침을 제공합니다.
</Inject>

## 용법 {/* #usage */}

### 스토리지 구성 {/* #configure-storage */}

Mastra 인스턴스에서 스토리지를 구성합니다. 데이터 세트에는 다음을 제공하는 스토리지 어댑터가 필요합니다.`datasets` domain:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { LibSQLStore } from '@mastra/libsql'

export const mastra = new Mastra({
  storage: new LibSQLStore({
    id: 'my-store',
    url: 'file:./mastra.db',
  }),
})
```

### 데이터 세트 API에 액세스 {/* #accessing-the-datasets-api */}

모든 데이터세트 작업은 다음을 통해 가능합니다.`mastra.datasets`:

```typescript
const datasets = mastra.datasets

// Create a dataset
const dataset = await datasets.create({ name: 'my-dataset' })

// Retrieve an existing dataset
const existing = await datasets.get({ id: 'dataset-id' })

// List all datasets
const { datasets: all } = await datasets.list()
```

방문[`DatasetsManager` reference](/reference/datasets/datasets-manager) for the full list of methods.

## 사진관 {/* #studio */}

다음에서 데이터 세트를 관리할 수도 있습니다.[Studio](/docs/studio/overview). After opening Studio, select **Datasets** from the sidebar to see all your available datasets or create a new one.

시작하려면 다음을 선택하세요.**Create Dataset** and set a name, description, and optional schemas. After confirming, you'll see the dataset details page with two tabs: **Items** and [**Experiments**](/docs/datasets/running-experiments#studio).

에서**Items** view you can add, update, and delete items, and view version history. Select **Add Item** to insert a new item with JSON editors for input and ground truth. From this view you can also import items in bulk from a CSV or JSON file. When importing, map each column to the corresponding dataset field.

선택하다**Versions** to see the full history of changes to the dataset. After selecting **Compare Versions**, choose any two versions and select **Compare** to see a side-by-side diff of all items that were added, changed, or removed between those versions.

## 데이터세트 만들기 {/* #creating-a-dataset */}

부르다[`create()`](/reference/datasets/create) with a name and optional description:

```typescript title="src/mastra/datasets/create-dataset.ts"
import { mastra } from '../index'

const dataset = await mastra.datasets.create({
  name: 'translation-pairs',
  description: 'English to Spanish translation test cases',
})

console.log(dataset.id) // auto-generated UUID
```

### 스키마 정의 {/* #defining-schemas */}

모양을 강제할 수 있습니다.`input` and `groundTruth` by passing a [Standard JSON Schema](https://standardschema.dev/json-schema) ([Zod](https://zod.dev/), [Valibot](https://valibot.dev/), [ArkType](https://arktype.io/), etc.) when creating the dataset:

```typescript title="src/mastra/datasets/create-with-schema.ts"
import { z } from 'zod'
import { mastra } from '../index'

const dataset = await mastra.datasets.create({
  name: 'translation-pairs',
  inputSchema: z.object({
    text: z.string(),
    sourceLang: z.string(),
    targetLang: z.string(),
  }),
  groundTruthSchema: z.object({
    translation: z.string(),
  }),
})
```

스키마와 일치하지 않는 항목은 삽입 시 거부됩니다.

## 항목 추가 {/* #adding-items */}

사용[`addItem()`](/reference/datasets/addItem) for a single item or [`addItems()`](/reference/datasets/addItems) to insert in bulk:

```typescript title="src/mastra/datasets/add-items.ts"
// Single item
await dataset.addItem({
  input: { text: 'Hello', sourceLang: 'en', targetLang: 'es' },
  groundTruth: { translation: 'Hola' },
})

// Bulk insert
await dataset.addItems({
  items: [
    {
      input: { text: 'Goodbye', sourceLang: 'en', targetLang: 'es' },
      groundTruth: { translation: 'Adiós' },
    },
    {
      input: { text: 'Thank you', sourceLang: 'en', targetLang: 'es' },
      groundTruth: { translation: 'Gracias' },
    },
  ],
})
```

## 항목 업데이트 및 삭제 {/* #updating-and-deleting-items */}

[`updateItem()`](/reference/datasets/updateItem), [`deleteItem()`](/reference/datasets/deleteItem), and [`deleteItems()`](/reference/datasets/deleteItems) let you modify or remove existing items by `itemId`:

```typescript title="src/mastra/datasets/update-delete.ts"
await dataset.updateItem({
  itemId: 'item-abc-123',
  groundTruth: { translation: '¡Hola!' },
})

await dataset.deleteItem({ itemId: 'item-abc-123' })

await dataset.deleteItems({ itemIds: ['item-1', 'item-2'] })
```

## 항목 나열 및 검색 {/* #listing-and-searching-items */}

[`listItems()`](/reference/datasets/listItems)페이지 매김 및 전체 텍스트 검색을 지원합니다.

```typescript title="src/mastra/datasets/list-items.ts"
// Paginated list
const { items, pagination } = await dataset.listItems({
  page: 0,
  perPage: 50,
})

// Full-text search
const { items: matches } = await dataset.listItems({
  search: 'Hello',
})

// Search and pagination can be combined with a specific version
const { items: v2Matches } = await dataset.listItems({
  version: 2,
  search: 'Hello',
  page: 0,
  perPage: 50,
})

// Version-only snapshot returns a bare DatasetItem[]
const v2Items = await dataset.listItems({ version: 2 })
```

## 버전 관리 {/* #versioning */}

데이터세트 항목에 대한 모든 변형(추가, 업데이트 또는 삭제)으로 인해 데이터세트 버전이 변경됩니다. 이를 통해 데이터의 특정 스냅샷에 실험을 고정할 수 있습니다.

### 버전 나열 {/* #listing-versions */}

사용[`listVersions()`](/reference/datasets/listVersions) to see the paginated history of versions:

```typescript title="src/mastra/datasets/list-versions.ts"
const { versions, pagination } = await dataset.listVersions()

for (const v of versions) {
  console.log(`Version ${v.version} — created ${v.createdAt}`)
}
```

### 항목 내역 보기 {/* #viewing-item-history */}

호출을 통해 버전에 따라 특정 항목이 어떻게 변경되었는지 확인하세요.[`getItemHistory()`](/reference/datasets/getItemHistory) with the `itemId`:

```typescript title="src/mastra/datasets/item-history.ts"
const history = await dataset.getItemHistory({ itemId: 'item-abc-123' })

for (const row of history) {
  console.log(`Version ${row.datasetVersion}`, row.input, row.groundTruth)
}
```

### 버전에 고정 {/* #pinning-to-a-version */}

이전 버전에 존재했던 정확한 항목을 가져옵니다.

```typescript title="src/mastra/datasets/pin-version.ts"
const items = await dataset.listItems({ version: 2 })
```

실험을 버전에 고정할 수도 있습니다.[running experiments](/docs/datasets/running-experiments). Visit the [`Dataset` reference](/reference/datasets/dataset) for the full list of methods and parameters.
