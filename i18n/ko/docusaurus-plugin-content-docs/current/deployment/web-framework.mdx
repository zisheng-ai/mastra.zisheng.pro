# 웹 프레임워크를 사용하여 배포

Mastra가 웹 프레임워크와 통합되면 프레임워크의 표준 배포 프로세스를 사용하여 애플리케이션과 함께 배포됩니다. Mastra 통합이 올바르게 배포되도록 하려면 아래 지침을 따르세요.

:::warning
클라우드 Provider에 배포할 때는 Mastra 설정에서 [LibSQLStore](/reference/storage/libsql)를 제거하세요. LibSQLStore에는 파일 시스템 접근 권한이 필요하므로 서버리스 플랫폼과 호환되지 않습니다.
:::
통합 가이드:

* [Next.js를 사용하면](/guides/getting-started/next-js)
* [아스트로와 함께](/guides/getting-started/astro)

## Vercel의 Next.js 사용 {/* #with-nextjs-on-vercel */}

[가이드에 따라](/guides/getting-started/next-js) Mastra를 Next.js와 통합했고 Vercel에 배포하려는 경우 `next.config.ts`에 `serverExternalPackages: ["@mastra/*"]`를 추가하세요.
```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## Vercel에서 Astro와 함께 {/* #with-astro-on-vercel */}

[가이드에 따라](/guides/getting-started/astro) Astro와 Mastra를 통합했고 Vercel에 배포하려는 경우 `astro.config.mjs`에 Vercel 어댑터와 서버 출력을 추가하세요.
```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## Astro와 함께 Netlify에서 {/* #with-astro-on-netlify */}

[가이드에 따라](/guides/getting-started/astro) Astro와 Mastra를 통합했고 Netlify에 배포하려는 경우 `astro.config.mjs`에 Netlify 어댑터와 서버 출력을 추가하세요.
```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'

export default defineConfig({
  adapter: netlify(),
  output: 'server',
})
```
