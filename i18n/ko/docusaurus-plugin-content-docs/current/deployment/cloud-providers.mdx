# 클라우드 Provider에 배포

Mastra 애플리케이션은 클라우드 Provider 및 서버리스 플랫폼에 배포될 수 있습니다. Mastra에는 배포 프로세스를 자동화하기 위한 Vercel, Netlify 및 Cloudflare용 기본 제공 배포자가 선택적으로 포함되어 있습니다.

## 마스트라 플랫폼 {/* #mastra-platform */}

Mastra는 서버를 클라우드에 배포할 수 있는 플랫폼을 제공합니다. 자세한 내용은 [Mastra 플랫폼 배포 가이드](/docs/mastra-platform/overview)를 참조하세요.
