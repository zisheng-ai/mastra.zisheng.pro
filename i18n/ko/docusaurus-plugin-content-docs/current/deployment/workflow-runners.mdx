# Workflow 실행자

마스트라[workflows](/docs/workflows/overview)내장된 Workflow 실행기를 사용하여 실행하거나 오케스트레이션, 모니터링 및 안정성을 처리하는 특수 Workflow 실행 플랫폼에 배포할 수 있습니다.

## 섭취 {/* #inngest */}

Inngest는 인프라를 관리하지 않고 백그라운드 Workflow를 실행하기 위한 개발자 플랫폼입니다. Mastra Workflow는 단계 메모, 자동 재시도, 실시간 모니터링 및 일시 중지/재개 기능을 제공하는 Ingest에 배포할 수 있습니다.

설정 방법은 [Inngest 배포 가이드](/guides/deployment/inngest)를, 전체 구현은 [Inngest Workflow 예제](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)를 참조하세요.
## 일시적인 {/* #temporal */}

Temporal은 장기 실행 Workflow를 조정하기 위한 내구성 있는 실행 플랫폼입니다. Mastra Workflow는 Temporal 작업자에서 실행할 수 있으며, 각 `createStep`은 자동 재시도와 내구성 있는 상태를 위해 Temporal 활동에 매핑됩니다.
`@mastra/temporal` 패키지는 실험 단계이므로 프로덕션에서 사용할 준비가 되지 않았습니다. 설정 방법은 [Temporal 배포 가이드](/guides/deployment/temporal)를 참조하세요.
