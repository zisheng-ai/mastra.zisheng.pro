# Workflow 실행자

마스트라[workflows](/docs/workflows/overview)내장된 Workflow 실행기를 사용하여 실행하거나 오케스트레이션, 모니터링 및 안정성을 처리하는 특수 Workflow 실행 플랫폼에 배포할 수 있습니다.

## 섭취 {/* #inngest */}

Inngest는 인프라를 관리하지 않고 백그라운드 Workflow를 실행하기 위한 개발자 플랫폼입니다. Mastra Workflow우는 단계 메모, 자동 재시도, 실시간 모니터링 및 일시 중지/재개 기능을 제공하는 Ingest에 배포할 수 있습니다.

방문[Inngest deployment guide](/guides/deployment/inngest) for setup instructions and the [Inngest workflow example](https://github.com/mastra-ai/mastra/tree/main/examples/inngest) for a complete implementation.

## 일시적인 {/* #temporal */}

Temporal은 장기 실행 Workflow를 조정하기 위한 내구성 있는 실행 플랫폼입니다. Mastra Workflow우는 임시 작업자에서 실행될 수 있습니다.`createStep` mapped to a Temporal activity for automatic retries and durable state.

그만큼`@mastra/temporal` package is experimental and not ready for production use. Visit the [Temporal deployment guide](/guides/deployment/temporal) for setup instructions.
