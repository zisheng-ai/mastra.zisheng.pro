# Mastra 플랫폼의 Observability

Mastra 플랫폼의 Observability은 Mastra 프로젝트 및 배포 전체에서 검색 가능한 추적, 로그 및 메트릭을 위한 독립형 호스팅 제품입니다. Studio를 먼저 배포하거나 로컬 스토리지를 설정하지 않고 관찰성을 원할 때 사용하세요.

사용`mastra init` to configure platform observability while adding Mastra to an existing application, or configure it manually in a newly created Mastra project.

## 빠른 시작 {/* #quickstart */}

프로젝트와 일치하는 설정 경로를 선택하세요.

### 새 프로젝트 {/* #new-project */}

관리형 Mastra 프로젝트를 만듭니다. 메시지가 표시되면 Mastra Platform Observability를 선택하여 자동으로 구성합니다.

```bash npm2yarn
npm create mastra@latest
```

Observability을 선택하면 create 명령이 Mastra 플랫폼으로 인증하고, 플랫폼 프로젝트를 프로비저닝하고, 프로젝트에 자격 증명을 씁니다. 플랫폼 설정을 건너뛰거나 메시지가 표시되지 않는 생성 흐름을 사용하는 경우 다음을 따르세요.[manual setup](#manual-setup) steps instead.

### 기존 비Mastra 프로젝트 {/* #existing-non-mastra-projects */}

Next.js 앱과 같은 애플리케이션이 이미 있지만 아직 Mastra를 추가하지 않은 경우 다음을 실행하세요.`mastra init` and enable Mastra Observability when prompted:

```bash npm2yarn
npx mastra init
```

CLI는 기존 플랫폼 프로젝트를 선택하거나 새 프로젝트를 생성할 수 있습니다.

### 수동 설정 {/* #manual-setup */}

다음에서 프로젝트 만들기[Mastra Platform](https://projects.mastra.ai), add `MASTRA_PLATFORM_ACCESS_TOKEN` and `MASTRA_PROJECT_ID` to `.env`, then register `MastraPlatformExporter` in your Mastra config. Add `MastraStorageExporter` if you also want to persist observability events to your configured Mastra Storage:

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Observability, MastraPlatformExporter } from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraPlatformExporter()],
      },
    },
  }),
})
```

보다[Mastra platform configuration](/docs/mastra-platform/configuration#observability) for the environment variables used by platform observability.

## 관측 가능성 데이터 쿼리 {/* #query-observability-data */}

프로젝트가 추적, 로그 또는 점수를 Mastra Platform Observability에 게시한 후 Mastra CLI 또는 다음을 사용하여 터미널에서 해당 데이터를 쿼리할 수 있습니다.`curl`.

```bash npm2yarn
npx mastra api trace list
```

Observability 명령의 경우 CLI는 호스팅된 Observability API를 대상으로 하며 프로젝트 환경에서 자격 증명을 유추할 수 있습니다. 참조[`mastra api` CLI reference](/reference/cli/mastra#mastra-api) for available observability commands, filtering, pagination, credential resolution, and direct `curl` examples.
