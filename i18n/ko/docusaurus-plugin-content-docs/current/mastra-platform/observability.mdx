# Mastra 플랫폼의 Observability

Mastra 플랫폼의 Observability은 Mastra 프로젝트 및 배포 전체에서 검색 가능한 추적, 로그 및 메트릭을 위한 독립형 호스팅 제품입니다. Studio를 먼저 배포하거나 로컬 스토리지를 설정하지 않고 관찰성을 원할 때 사용하세요.

기존 애플리케이션에 Mastra를 추가하면서 플랫폼 Observability를 구성하려면 `mastra init`을 사용하고, 새로 만든 Mastra 프로젝트에서는 수동으로 구성하세요.
## 빠른 시작 {/* #quickstart */}

프로젝트와 일치하는 설정 경로를 선택하세요.

### 새 프로젝트 {/* #new-project */}

관리형 Mastra 프로젝트를 만듭니다. 메시지가 표시되면 Mastra Platform Observability를 선택하여 자동으로 구성합니다.

```bash npm2yarn
npm create mastra@latest
```

Observability를 선택하면 생성 명령에서 Mastra 플랫폼으로 인증하고, 플랫폼 프로젝트를 프로비저닝하고, 프로젝트에 자격 증명을 작성합니다. 플랫폼 설정을 건너뛰었거나 Prompt가 표시되지 않는 생성 흐름을 사용했다면 대신 [수동 설정](#manual-setup) 단계를 따르세요.
### 기존 비Mastra 프로젝트 {/* #existing-non-mastra-projects */}

Next.js 앱과 같은 기존 애플리케이션에 Mastra를 아직 추가하지 않았다면 `mastra init`을 실행하고 Prompt가 표시될 때 Mastra Observability를 활성화하세요.
```bash npm2yarn
npx mastra init
```

CLI는 기존 플랫폼 프로젝트를 선택하거나 새 프로젝트를 생성할 수 있습니다.

### 수동 설정 {/* #manual-setup */}

[Mastra Platform](https://projects.mastra.ai)에서 프로젝트를 만들고, `MASTRA_PLATFORM_ACCESS_TOKEN`과 `MASTRA_PROJECT_ID`를 `.env`에 추가한 다음 Mastra 구성에 `MastraPlatformExporter`를 등록하세요. 구성된 Mastra Storage에 Observability 이벤트도 유지하려면 `MastraStorageExporter`를 추가하세요.
```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Observability, MastraPlatformExporter } from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraPlatformExporter()],
      },
    },
  }),
})
```

플랫폼 Observability에서 사용하는 환경 변수는 [Mastra 플랫폼 구성](/docs/mastra-platform/configuration#observability)을 확인하세요.
## 관측 가능성 데이터 쿼리 {/* #query-observability-data */}

프로젝트가 추적, 로그 또는 점수를 Mastra Platform Observability에 게시한 후 Mastra CLI 또는 다음을 사용하여 터미널에서 해당 데이터를 쿼리할 수 있습니다.`curl`.

```bash npm2yarn
npx mastra api trace list
```

Observability 명령의 경우 CLI는 호스팅된 Observability API를 대상으로 하며 프로젝트 환경에서 자격 증명을 추론할 수 있습니다. 사용 가능한 Observability 명령, 필터링, 페이지 매김, 자격 증명 결정 및 직접 사용하는 `curl` 예제는 [`mastra api` CLI 참고 문서](/reference/cli/mastra#mastra-api)를 확인하세요.
