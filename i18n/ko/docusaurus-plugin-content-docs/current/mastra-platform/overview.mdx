# 마스트라 플랫폼

 [Mastra 플랫폼](https://projects.mastra.ai)은 Mastra 프레임워크로 구축한 AI 애플리케이션을 배포, 모니터링, 관리하기 위한 세 가지 제품을 제공합니다.

* [**Observability**](/docs/mastra-platform/observability): Mastra 프로젝트 및 배포 전반에 걸쳐 검색 가능한 추적, 로그 및 메트릭을 포함하는 모든 플랫폼 프로젝트의 기본 제품
* [**Studio**](/docs/mastra-platform/studio): Trace를 검사하는 Tool과 함께 Agent를 테스트하고 Workflow를 실행할 수 있는 호스팅형 시각적 환경입니다. Studio를 시작하면 Observability도 제공됩니다.
* [**Server**](/docs/mastra-platform/server): Mastra 애플리케이션을 API 서버로 실행하는 프로덕션 배포 대상입니다. Server를 시작하면 Observability도 제공됩니다.

단일 명령인 [`mastra deploy`](/docs/mastra-platform/deploy)로 배포하거나 GitHub 리포지토리를 연결하여 push-to-deploy를 사용할 수 있습니다. 리포지토리 연결 흐름은 [GitHub 통합](/docs/mastra-platform/github)을 참조하세요.
각 프로젝트는 여러 [**Environment**](/docs/mastra-platform/environments)(예: `production`, `staging`)를 실행할 수 있습니다. CLI 또는 프로젝트 설정에서 [**호스팅 데이터베이스**](/docs/mastra-platform/database)를 프로비저닝하여 애플리케이션 데이터를 유지하고, Environment별로 관리형 [**Workspace**](/docs/mastra-platform/workspaces)를 사용할 수 있습니다. Workspace는 별도 구성 없이 Agent에 파일 시스템과 Sandbox를 제공합니다.
[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence)는 Agent Trace 전반에서 반복되는 목표, 결과, 행동, 감정을 찾습니다. Trace Intelligence는 선택된 프로젝트를 대상으로 비공개 베타로 제공됩니다.
## 시작하기 {/* #get-started */}

수행하려는 작업과 일치하는 경로를 선택하세요.

* **호스팅형 Observability 추가**: [Observability](/docs/mastra-platform/observability)를 사용해 프로젝트와 배포 전반의 검색 가능한 Trace, 로그, 메트릭을 수집합니다. Studio나 Server를 먼저 배포하지 않고 모니터링하려면 여기서 시작하세요.
* **Studio 배포**: [Studio](/docs/mastra-platform/studio)를 사용해 팀을 위한 시각적 개발 환경을 호스팅합니다. Agent 테스트, Workflow 실행, Trace 검사용 공유 UI가 필요하면 여기서 시작하세요.
* **Server 배포**: [Server](/docs/mastra-platform/server)를 사용해 Mastra 애플리케이션을 프로덕션 API 서버로 실행합니다. 클라우드에서 Agent, Tool, Workflow를 제공할 준비가 되었다면 여기서 시작하세요.

## 주요 개념 {/* #key-concepts */}

**프로젝트**는 모든 제품에서 공유되는 상위 엔터티입니다. 단일 프로젝트에는 Observability, Studio, Server를 모두 포함할 수 있습니다. 프로젝트는 팀을 위한 멀티테넌트 컨테이너인 **Organization**에 속합니다.

Mastra 애플리케이션은 세 가지 구성 요소로 구축됩니다.

* [Agent](/docs/agents/overview): Tool을 사용하고, 지시를 따르며, 맥락을 유지할 수 있는 AI Agent
* [Tool](/docs/agents/using-tools): Agent가 사용할 수 있는 호출 가능한 기능 및 통합
* [Workflow](/docs/workflows/overview): Agent와 Tool을 조정하는 다단계 오케스트레이션 파이프라인

## 생산에 들어갑니다 {/* #going-to-production */}

[`mastra dev`](/reference/cli/mastra#mastra-dev)로 로컬에서 프로젝트를 개발하고, [Studio](/docs/studio/overview)를 열어 시각적 환경에서 Agent, Workflow, Tool을 테스트하세요.

애플리케이션을 프로덕션에 배포할 준비가 되면 [`mastra deploy`](/reference/cli/mastra#mastra-deploy)를 실행하여 애플리케이션을 클라우드로 푸시하세요.

[Deploy](/docs/mastra-platform/deploy) 문서에서 단계별 지침을 확인하세요.

자체 인프라에서 Mastra 애플리케이션을 호스팅하는 경우에도 다음을 사용하여 관측 가능성 데이터를 Mastra 플랫폼으로 보낼 수 있습니다.[MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform).
