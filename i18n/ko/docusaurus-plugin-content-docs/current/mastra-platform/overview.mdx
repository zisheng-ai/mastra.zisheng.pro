# 마스트라 플랫폼

그만큼[Mastra platform](https://projects.mastra.ai)Mastra 프레임워크로 구축된 AI 애플리케이션을 배포, 모니터링 및 관리하기 위한 세 가지 제품을 제공합니다.

* [**Observability**](/docs/mastra-platform/observability): Mastra 프로젝트 및 배포 전반에 걸쳐 검색 가능한 추적, 로그 및 메트릭을 포함하는 모든 플랫폼 프로젝트의 기본 제품
* [**사진관**](/docs/mastra-platform/studio): 추적 검사 Tool를 사용하여 Agent를 테스트하고 Workflow를 실행하기 위한 호스팅된 시각적 환경입니다. Studio를 시작하면 Observability도 제공됩니다.
* [**섬기는 사람**](/docs/mastra-platform/server): Mastra 애플리케이션을 API 서버로 실행하는 프로덕션 배포 대상입니다. Server로 시작하면 Observability도 제공됩니다.

단일 명령으로 배포[`mastra deploy`](/docs/mastra-platform/deploy), or connect a GitHub repository for push-to-deploy. See the [GitHub integration](/docs/mastra-platform/github) for the repository-linked flow.

각 프로젝트는 여러 개를 실행할 수 있습니다[**Environments**](/docs/mastra-platform/environments) (for example `production` and `staging`), provision [**Hosted databases**](/docs/mastra-platform/database) from the CLI or project settings to persist application data, and get a managed [**Workspaces**](/docs/mastra-platform/workspaces) per environment that gives agents a filesystem and a sandbox with no manual configuration.

[**추적 인텔리전스**](/docs/mastra-platform/trace-intelligence)Agent 추적 전반에 걸쳐 반복되는 목표, 결과, 행동 및 감정을 찾습니다. Trace Intelligence는 선택된 프로젝트에 대해 비공개 베타 버전으로 제공됩니다.

## 시작하기 {/* #get-started */}

수행하려는 작업과 일치하는 경로를 선택하세요.

* **호스팅된 Observability 추가**: 사용[Observability](/docs/mastra-platform/observability) to collect searchable traces, logs, and metrics
  across projects and deploys. Start here if you want monitoring without deploying Studio or Server first.
* **스튜디오 배포**: 사용[Studio](/docs/mastra-platform/studio) to host the visual development environment for your team. Start here if you
  want a shared UI for testing agents, running workflows, and inspecting traces.
* **서버 배포**: 사용[Server](/docs/mastra-platform/server) to run your Mastra application as a production API server. Start here when
  you’re ready to serve agents, tools, and workflows from the cloud.

## 주요 개념 {/* #key-concepts */}

**프로젝트**모든 제품에서 공유되는 상위 엔터티입니다. 단일 프로젝트에는 Observability, Studio, Server 등 모든 제품이 포함될 수 있습니다. 프로젝트는 다음에 속합니다.**Organization**, which is the multi-tenant container for your team.

Mastra 애플리케이션은 세 가지 구성 요소로 구축됩니다.

* [Agent](/docs/agents/overview): Tool를 사용하고, 지시를 따르며, 맥락을 유지할 수 있는 AI Agent
* [Tool](/docs/agents/using-tools): Agent가 사용할 수 있는 호출 가능한 기능 및 통합
* [Workflow](/docs/workflows/overview): Agent와 Tool를 조정하는 다단계 오케스트레이션 파이프라인

## 생산에 들어갑니다 {/* #going-to-production */}

다음을 사용하여 로컬에서 프로젝트를 개발하세요.[`mastra dev`](/reference/cli/mastra#mastra-dev) and open [Studio](/docs/studio/overview) to test your agents, workflows, and tools in a visual environment.

애플리케이션을 프로덕션에 배포할 준비가 되면 다음을 실행하세요.[`mastra deploy`](/reference/cli/mastra#mastra-deploy) to push your application to the cloud.

따라가다[Deploy](/docs/mastra-platform/deploy) docs for step-by-step instructions.

자체 인프라에서 Mastra 애플리케이션을 호스팅하는 경우에도 다음을 사용하여 관측 가능성 데이터를 Mastra 플랫폼으로 보낼 수 있습니다.[MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform).
