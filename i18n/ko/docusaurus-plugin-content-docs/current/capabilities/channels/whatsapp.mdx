# 왓츠앱

WhatsApp 채널을 통해 Mastra Agent은 WhatsApp Business Cloud를 통해 고객 메시지를 받을 수 있습니다. Mastra는 Agent 연결 및 웹훅 경로를 처리합니다. Chat SDK WhatsApp 어댑터 문서에서는 메타 앱 설정, 자격 증명 및 웹후크 구성을 다룹니다.

## 어댑터 설치 {/* #install-the-adapter */}

Chat SDK에서 WhatsApp 어댑터를 설치합니다.

```bash npm2yarn
npm install @chat-adapter/whatsapp
```

## Agent 구성 {/* #agent-configuration */}

Agent의 `channels.adapters` 객체에 `createWhatsAppAdapter()`를 추가하세요.
```typescript title="src/mastra/agents/whatsapp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createWhatsAppAdapter } from '@chat-adapter/whatsapp'

export const whatsappAgent = new Agent({
  id: 'whatsapp-agent',
  name: 'WhatsApp Agent',
  instructions: 'Answer customer questions and help with tasks in WhatsApp.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      whatsapp: createWhatsAppAdapter(),
    },
  },
})
```

Mastra 인스턴스에 Agent를 등록합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { whatsappAgent } from './agents/whatsapp-agent'

export const mastra = new Mastra({
  agents: { whatsappAgent },
})
```

## 어댑터 설정 {/* #adapter-setup */}

Meta 앱 구성, 액세스 토큰, 전화번호 ID, 웹훅 검증, 메시지 제한을 포함한 WhatsApp 전용 설정은 [Chat SDK WhatsApp 어댑터 문서](https://chat-sdk.dev/adapters/official/whatsapp)를 따르세요.
어댑터는 다음과 같은 환경 변수에서 WhatsApp 자격 증명을 읽습니다.

```bash title=".env"
WHATSAPP_ACCESS_TOKEN=your-meta-access-token
WHATSAPP_APP_SECRET=your-meta-app-secret
WHATSAPP_PHONE_NUMBER_ID=your-whatsapp-phone-number-id
WHATSAPP_VERIFY_TOKEN=your-webhook-verify-token
```

## 웹훅 URL {/* #webhook-url */}

Mastra는 Agent ID 및 어댑터 키에서 WhatsApp Webhook 경로를 생성합니다.

```text
/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

공개 Mastra 서버 URL을 기본 URL로 사용하십시오.

```text
https://your-app.example.com/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

수신되는 WhatsApp 이벤트 전달에 이 URL을 사용하세요. 생성된 Mastra 경로는 WhatsApp의 POST 이벤트를 처리합니다. 메타 콜백 및 웹훅 확인 흐름에 대해서는 Chat SDK WhatsApp 어댑터 문서를 따르세요.
