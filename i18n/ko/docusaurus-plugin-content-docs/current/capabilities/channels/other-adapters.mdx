# 더

Mastra 채널은 Chat SDK 어댑터를 사용하므로 이 섹션의 페이지에는 지원되는 플랫폼의 전체 목록이 없습니다. 호환되는 어댑터 팩토리를 내보내는 Chat SDK 플랫폼 어댑터를 사용하세요.`channels.adapters`.

## 어댑터 카탈로그 {/* #adapter-catalog */}

[Chat SDK 어댑터 카탈로그](https://chat-sdk.dev/adapters)는 사용 가능한 어댑터의 공식 정보 출처입니다. 아래 목록은 특정 시점의 스냅샷일 뿐이며 항상 최신 상태가 아닐 수 있습니다.
작성 당시 Chat SDK에는 다음에 대한 어댑터가 나열되어 있습니다.

* Agent전화
* 베일리스 WhatsApp
* 불화
* 구글 채팅
* GitHub
* 아이메시지
* 캅소
* 종달새 / 페이슈
* 선의
* 라이브블록
* 행렬
* 전령
* 가장 중요한
* 노부
* 재전송
* 센드블루
* 전보
* 트윌리오
* 벨트
* 편물
* 웹엑스
* 위챗
* WhatsApp 비즈니스 클라우드
* 엑스
* 잘로
* 제르니오

패키지 이름, 자격 증명 변수, 웹훅 요구 사항 및 플랫폼별 동작은 어댑터 문서를 확인하세요.

## 동일한 Mastra 배선을 사용하십시오. {/* #use-the-same-mastra-wiring */}

각 Chat SDK 어댑터의 Mastra 측 설정은 동일한 패턴을 따릅니다. 어댑터 패키지를 설치하고 해당 팩토리를 `channels.adapters`에 추가하세요. 그런 다음 플랫폼 자격 증명을 구성하고 웹훅이 생성된 Mastra 경로를 가리키도록 설정하세요.
이 섹션의 플랫폼 페이지 중 하나를 Mastra 배선에 대한 참조로 사용하십시오.

* [느슨하게](/docs/capabilities/channels/slack)
* [마이크로소프트 팀즈](/docs/capabilities/channels/teams)
* [불화](/docs/capabilities/channels/discord)
* [전보](/docs/capabilities/channels/telegram)
* [왓츠앱](/docs/capabilities/channels/whatsapp)

## 어댑터 문서에서 확인할 사항 {/* #what-to-check-in-adapter-docs */}

새 어댑터를 Mastra에 연결하기 전에 어댑터 문서에서 다음 사항을 확인하세요.

* 자격 증명 환경 변수.
* 필수 플랫폼 권한 또는 범위.
* 웹훅 확인 동작.
* 플랫폼에 설정, 이벤트 또는 상호 작용을 위해 별도의 경로가 필요한지 여부.
* 일반 메시지에 장기 실행 수신기 또는 폴링이 필요한지 여부.
* 첨부 파일, 카드, 리치 메시지 지원.
