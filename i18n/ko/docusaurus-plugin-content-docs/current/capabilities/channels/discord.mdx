# 불화

Discord 채널을 사용하면 Mastra Agent가 Discord 상호 작용 및 봇 메시지를 받을 수 있습니다. Mastra는 Agent 연결 및 웹훅 경로를 처리합니다. Chat SDK Discord 어댑터 문서에서는 Discord 애플리케이션 설정, 봇 권한 및 게이트웨이 동작을 다룹니다.

## 어댑터 설치 {/* #install-the-adapter */}

Chat SDK에서 Discord 어댑터를 설치합니다.

```bash npm2yarn
npm install @chat-adapter/discord
```

## Agent 구성 {/* #agent-configuration */}

추가하다`createDiscordAdapter()` to the agent's `channels.adapters` object:

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createDiscordAdapter } from '@chat-adapter/discord'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord Agent',
  instructions: 'Answer questions and help with tasks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      discord: createDiscordAdapter(),
    },
  },
})
```

Mastra 인스턴스에 Agent를 등록합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { discordAgent } from './agents/discord-agent'

export const mastra = new Mastra({
  agents: { discordAgent },
})
```

## 어댑터 설정 {/* #adapter-setup */}

따라가다[Chat SDK Discord adapter docs](https://chat-sdk.dev/adapters/official/discord) for Discord-specific setup, including application creation, bot tokens, interaction endpoints, permissions, and Gateway behavior.

어댑터는 다음과 같은 환경 변수에서 Discord 자격 증명을 읽습니다.

```bash title=".env"
DISCORD_BOT_TOKEN=your-discord-bot-token
DISCORD_PUBLIC_KEY=your-discord-application-public-key
DISCORD_APPLICATION_ID=your-discord-application-id
```

## 웹훅 URL {/* #webhook-url */}

Mastra는 Agent ID 및 어댑터 키에서 Discord 웹훅 경로를 생성합니다.

```text
/api/agents/discord-agent/channels/discord/webhook
```

공개 Mastra 서버 URL을 기본 URL로 사용하십시오.

```text
https://your-app.example.com/api/agents/discord-agent/channels/discord/webhook
```

Discord 어댑터 문서에서 상호 작용 끝점 또는 웹훅 URL을 요청하는 곳이면 어디든 이 URL을 사용하세요. Discord의 일반 메시지 이벤트에는 생성된 웹훅 경로 외부에 게이트웨이 설정이 필요할 수 있습니다. 해당 경로에 대한 Chat SDK 어댑터 문서를 따르세요.
