# 수파베이스

그만큼`@mastra/auth-supabase`패키지는 Supabase Auth를 사용하여 Mastra에 대한 인증을 제공합니다. Supabase의 인증 시스템을 사용하여 들어오는 요청을 확인하고 다음을 사용하여 Mastra 서버와 통합합니다.`auth`옵션.

## 전제조건 {/* #prerequisites */}

이 예에서는 Supabase Auth를 사용합니다. Supabase 자격 증명을`.env` file and ensure your Supabase project is properly configured.

```env title=".env"
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

:::메모

적절한 데이터 액세스 제어를 보장하려면 Superbase 행 수준 보안(RLS) 설정을 검토하세요.

:::

## 설치 {/* #installation */}

사용하기 전에`MastraAuthSupabase` class you have to install the `@mastra/auth-supabase` package.

```bash npm2yarn
npm install @mastra/auth-supabase@latest
```

## 사용예 {/* #usage-example */}

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthSupabase } from '@mastra/auth-supabase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthSupabase({
      url: process.env.SUPABASE_URL,
      anonKey: process.env.SUPABASE_ANON_KEY,
    }),
  },
})
```

:::정보

기본값`authorizeUser` method checks the `isAdmin` column in the `users` table in the `public` schema. To customize user authorization, provide a custom `authorizeUser` function when constructing the provider.

방문하다[MastraAuthSupabase](/reference/auth/supabase) for all available configuration options.

:::

## 클라이언트 측 설정 {/* #client-side-setup */}

Supabase 인증을 사용하는 경우 클라이언트 측 Supabase에서 액세스 토큰을 검색하여 Mastra 요청에 전달해야 합니다.

### 액세스 토큰 검색 {/* #retrieving-the-access-token */}

Supabase 클라이언트를 사용하여 사용자를 인증하고 액세스 토큰을 검색합니다.

```typescript title="lib/auth.ts"
import { createClient } from '@supabase/supabase-js'

const supabase = createClient('<supabase-url>', '<supabase-key>')

const authTokenResponse = await supabase.auth.signInWithPassword({
  email: "<user's email>",
  password: "<user's password>",
})

const accessToken = authTokenResponse.data?.session?.access_token
```

:::메모

다음을 참조하세요.[Supabase documentation](https://supabase.com/docs/guides/auth) for other authentication methods like OAuth, magic links, and more.

:::

## 구성`MastraClient` {/* #configuring-mastraclient */}

언제`auth` is enabled, all requests made with `MastraClient` must include a valid Supabase access token in the `Authorization` header:

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::정보

액세스 토큰 앞에는 다음이 붙어야 합니다.`Bearer` in the Authorization header.

방문하다[Mastra Client SDK](/docs/server/mastra-client) for more configuration options.

:::

### 인증된 요청 만들기 {/* #making-authenticated-requests */}

한 번`MastraClient` is configured with the Supabase access token, you can send authenticated requests:

<Tabs>
  <TabItem value="react" label="React">
    ```tsx title="src/components/test-agent.tsx"
    import { mastraClient } from '../../lib/mastra-client'

    export const TestAgent = () => {
      async function handleClick() {
        const agent = mastraClient.getAgent('weatherAgent')

        const response = await agent.generate("What's the weather like in New York")

        console.log(response)
      }

      return <button onClick={handleClick}>Test Agent</button>
    }
    ```
  </TabItem>

        "messages": "Weather in London"
      }'
