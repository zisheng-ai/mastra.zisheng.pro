# 서버 개요

Mastra는 Agent, Workflow 및 기타 기능을 API 엔드포인트로 노출하는 HTTP 서버로 실행됩니다. 서버는 요청 라우팅, 미들웨어 실행, 인증 및 스트리밍 응답을 처리합니다.

:::정보

이 페이지에서는 다음 내용을 다룹니다.[`server`](/reference/configuration#server-options) configuration options passed to the `Mastra`건설자. 자체 HTTP 서버(Hono, Express 등)로 Mastra를 실행하려면 다음을 방문하세요.[서버 어댑터](/docs/server/server-adapters).

:::

## 서버 기능 {/* #server-features */}

* **[미들웨어](/docs/server/middleware)**: 인증, 로깅, CORS 또는 요청별 컨텍스트 주입에 대한 요청을 차단합니다.
* **[사용자 정의 API 경로](/docs/server/custom-api-routes)**: Mastra 인스턴스에 액세스할 수 있는 자체 HTTP 엔드포인트로 서버를 확장합니다.
* **[요청 컨텍스트](/docs/server/request-context)**: 런타임 조건에 따라 Agent, Tool 및 Workflow에 요청별 값을 전달합니다.
* **[서버 어댑터](/docs/server/server-adapters)**: 생성된 서버 대신 Express, Hono 또는 자체 HTTP 서버를 사용하여 Mastra를 실행합니다.
* **[맞춤형 어댑터](/docs/server/custom-adapters)**: 공식적으로 지원되지 않는 프레임워크용 빌드 어댑터입니다.
* **[마스트라 클라이언트 SDK](/docs/server/mastra-client)**: 브라우저 또는 서버 환경에서 Agent, Workflow 및 Tool를 호출하기 위한 유형이 안전한 클라이언트입니다.
* **[A2A](/docs/agents/a2a)**: A2A Agent 카드, 작업 스트림, 푸시 알림을 통해 Agent를 노출합니다.
* **[입증](/docs/server/auth)**: JWT, Clerk, Supabase, Firebase, Auth0 또는 WorkOS를 사용하여 엔드포인트를 보호합니다.

## 구성 {/* #configuration */}

다음을 전달하여 서버를 구성합니다.`server` object to the `Mastra` constructor:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  server: {
    port: 3000, // Defaults to PORT env var or 4111
    host: '0.0.0.0', // Defaults to MASTRA_HOST env var or 'localhost'
  },
})
```

방문[configuration reference](/reference/configuration#server-options) for a full list of available server options.

## 서버 배포 {/* #deploy-your-server */}

Mastra 서버는 Node.js 호환 환경에 배포할 수 있습니다. 다음을 사용하여 프로덕션에 배포합니다.[Mastra platform](/docs/mastra-platform/overview) or your own infrastructure. Visit the [deployment docs](/docs/deployment/overview) to learn how.

## 서버 아키텍처 {/* #server-architecture */}

마스트라는 다음과 같은 용도로 사용합니다.[Hono](https://hono.dev) as its underlying HTTP server framework. When you build a Mastra application using `mastra build`, it generates a Hono-based HTTP server in the `.mastra` directory.

서버는 다음을 제공합니다.

* 등록된 모든 Agent 및 Workflow에 대한 API 엔드포인트
* 맞춤형 API 경로 및 미들웨어
* 공급자 간 인증
* 런타임 구성을 위한 요청 컨텍스트
* 안전한 응답을 위한 스트림 데이터 수정

## REST API {/* #rest-api */}

OpenAPI 사양에서 사용 가능한 모든 엔드포인트를 다음 위치에서 탐색할 수 있습니다.[http://localhost:4111/api/openapi.json](http://localhost:4111/api/openapi.json), which details every endpoint and its request and response schemas.

API를 대화형으로 탐색하려면 Swagger UI를 방문하세요.[http://localhost:4111/swagger-ui](http://localhost:4111/swagger-ui). Here, you can discover endpoints and test them directly from your browser.

:::메모

OpenAPI 및 Swagger 엔드포인트는 기본적으로 프로덕션에서 비활성화됩니다. 이를 활성화하려면 다음을 설정하십시오.[`server.build.openAPIDocs`](/reference/configuration#serverbuild) and [`server.build.swaggerUI`](/reference/configuration#serverbuild) to `true` respectively.

:::

## OpenAI 응답 API {/* #openai-responses-api */}

Mastra는 Mastra Agent를 응답 API로 사용할 수 있는 OpenAI 호환 응답 및 대화 경로를 공개합니다. 이러한 경로는 Mastra Agent, Memory 및 스토리지에 대한 Agent 지원 어댑터이므로 요청은 원시 공급자 프록시로 작동하는 대신 선택한 Mastra Agent를 통해 실행됩니다.

이러한 API는 현재 실험적입니다.

사용`agent_id` to select the Mastra agent that should handle the request. Initial requests target an agent directly, and stored follow-up turns can continue with `previous_response_id`. You can also pass `model` to override the agent's configured model for a single request. If you omit `model`, Mastra uses the model already configured on the agent.

응답 경로는 스트리밍, 함수 호출(Tool), 저장된 연속을 지원합니다.`previous_response_id`, conversation threads through `conversation_id`, provider-specific passthrough with `providerOptions`, and JSON output through `text.format`.

전체 요청 및 응답 계약은 다음을 참조하세요.[Responses API reference](/reference/client-js/responses) and [Conversations API reference](/reference/client-js/conversations). For the complete list of HTTP routes, see [server routes](/reference/server/routes#responses-api).

## 스트림 데이터 수정 {/* #stream-data-redaction */}

스트리밍 Agent 응답 시 HTTP 계층은 시스템 Prompt, Tool 정의, API 키 및 각 청크의 유사한 데이터를 클라이언트에 보내기 전에 수정합니다. 이는 기본적으로 활성화되어 있습니다.

이 동작은 다음을 사용해서만 구성할 수 있습니다.[server adapters](/docs/server/server-adapters#stream-data-redaction). For server adapters, stream data redaction is enabled by default, too.

## 타입스크립트 구성 {/* #typescript-configuration */}

마스트라는 요구한다`module` and `moduleResolution` settings compatible with modern Node.js. Legacy options like `CommonJS` or `node` aren't supported.

```json {4-5} title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "strict": true,
    "skipLibCheck": true,
    "noEmit": true,
    "outDir": "dist"
  },
  "include": ["src/**/*"]
}
```
