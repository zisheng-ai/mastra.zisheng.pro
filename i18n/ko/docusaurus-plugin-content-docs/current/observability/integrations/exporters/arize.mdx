# 아리제 수출업체

[아리제](https://arize.com/)AI 애플리케이션을 위한 관찰 플랫폼을 제공합니다.[Phoenix](https://phoenix.arize.com/)(오픈 소스) 및[아리제AX](https://arize.com/generative-ai/)(기업). Arize 내보내기는 OpenTelemetry를 사용하여 추적을 보내고[오픈인퍼런스](https://github.com/Arize-ai/openinference/tree/main/spec)OpenInference를 지원하는 모든 OpenTelemetry 플랫폼과 호환되는 의미론적 규칙입니다.

## 설치 {/* #installation */}

```bash npm2yarn
npm install @mastra/arize@latest
```

## 구성 {/* #configuration */}

### 피닉스 설정 {/* #phoenix-setup */}

Phoenix는 자체 호스팅하거나 Phoenix Cloud를 통해 사용할 수 있는 오픈 소스 관찰 플랫폼입니다.

#### 전제조건 {/* #prerequisites */}

1. **피닉스 인스턴스**: Docker를 사용하여 배포하거나 다음 사이트에 가입하세요.[Phoenix Cloud](https://app.phoenix.arize.com/login)
2. **엔드포인트**: Phoenix 엔드포인트 URL(다음으로 끝남)`/v1/traces`)
3. **API 키**: 인증되지 않은 인스턴스의 경우 선택 사항, Phoenix Cloud의 경우 필수
4. **환경 변수**: 구성 설정

```bash title=".env"
# Required
PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces  # Or your Phoenix Cloud URL

# Optional
PHOENIX_API_KEY=your-api-key  # For authenticated Phoenix instances
PHOENIX_PROJECT_NAME=mastra-service  # Defaults to 'mastra-service'
```

#### 제로 구성 설정 {/* #zero-config-setup */}

환경 변수가 설정된 경우 구성 없이 내보내기를 사용합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: 'mastra-service',
        exporters: [new ArizeExporter()],
      },
    },
  }),
})
```

#### 명시적 구성 {/* #explicit-configuration */}

자격 증명을 직접 전달할 수도 있습니다(환경 변수보다 우선 적용됨).

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      arize: {
        serviceName: process.env.PHOENIX_PROJECT_NAME || 'mastra-service',
        exporters: [
          new ArizeExporter({
            endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
            apiKey: process.env.PHOENIX_API_KEY,
            projectName: process.env.PHOENIX_PROJECT_NAME,
          }),
        ],
      },
    },
  }),
})
```

:::info\[Docker로 빠른 시작]

인Memory Phoenix 인스턴스를 사용하여 로컬에서 테스트합니다.

```bash
docker run --pull=always -d --name arize-phoenix -p 6006:6006 \
  -e PHOENIX_SQL_DATABASE_URL="sqlite:///:memory:" \
  arizephoenix/phoenix:latest
```

세트`PHOENIX_COLLECTOR_ENDPOINT=http://localhost:6006/v1/traces` and run your Mastra agent to see traces at [localhost:6006](http://localhost:6006).

:::

### 아리라이즈 AX 설정 {/* #arize-ax-setup */}

Arize AX는 프로덕션 AI 시스템을 위한 고급 기능을 갖춘 엔터프라이즈 관찰 플랫폼입니다.

#### 전제조건 {/* #prerequisites-1 */}

1. **Arize AX 계정**: 가입하세요[app.arize.com](https://app.arize.com/)
2. **공간ID**: 조직의 공간 식별자
3. **API 키**: Arize AX 설정에서 생성
4. **환경 변수**: 자격 증명을 설정하세요

```bash title=".env"
# Required
ARIZE_SPACE_ID=your-space-id
ARIZE_API_KEY=your-api-key

# Optional
ARIZE_PROJECT_NAME=mastra-service
```

#### 제로 구성 설정 {/* #zero-config-setup-1 */}

환경 변수가 설정된 경우 구성 없이 내보내기를 사용합니다.

```typescript title="src/mastra/index.ts"

import { Observability } from '@mastra/observability'
import { ArizeExporter } from '@mastra/arize'

export const mastra = new Mastra({

  }),

```

#### 명시적 구성 {/* #explicit-configuration-1 */}

자격 증명을 직접 전달할 수도 있습니다(환경 변수보다 우선 적용됨).

```typescript title="src/mastra/index.ts"

import { Observability } from '@mastra/observability'
```

## 구성 옵션 {/* #configuration-options */}

Arize 내보내기는 OpenTelemetry 동작을 미세 조정하기 위한 고급 구성을 지원합니다.

### 완전한 구성 {/* #complete-configuration */}

```typescript
new ArizeExporter({
  // Phoenix Configuration
  endpoint: 'https://your-collector.example.com/v1/traces', // Required for Phoenix

  // Arize AX Configuration
  spaceId: 'your-space-id', // Required for Arize AX

  // Shared Configuration
  apiKey: 'your-api-key', // Required for authenticated endpoints
  projectName: 'mastra-service', // Optional project name

  // Optional OTLP settings
  headers: {
    'x-custom-header': 'value', // Additional headers for OTLP requests
  },

  // Debug and performance tuning
  logLevel: 'debug', // Logging: debug | info | warn | error
  batchSize: 512, // Batch size before exporting spans
  timeout: 30000, // Timeout in ms before exporting spans

  // Custom resource attributes
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.version': process.env.APP_VERSION,
  },
})
```

### 일괄 처리 옵션 {/* #batch-processing-options */}

추적을 일괄 처리하고 내보내는 방법을 제어합니다.

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  apiKey: process.env.PHOENIX_API_KEY,

  // Batch processing configuration
  batchSize: 512, // Number of spans to batch (default: 512)
  timeout: 30000, // Max time in ms to wait before export (default: 30000)
})
```

### 자원 속성 {/* #resource-attributes */}

내보낸 모든 범위에 맞춤 속성을 추가합니다.

```typescript
new ArizeExporter({
  endpoint: process.env.PHOENIX_COLLECTOR_ENDPOINT!,
  resourceAttributes: {
    'deployment.environment': process.env.NODE_ENV,
    'service.namespace': 'production',
    'service.instance.id': process.env.HOSTNAME,
    'custom.attribute': 'value',
  },
})
```

### 커스텀 메타데이터 {/* #custom-metadata */}

예약되지 않은 범위 속성은 OpenInference로 직렬화됩니다.`metadata` payload and surface in Arize/Phoenix. You can add them via `tracingOptions.metadata`:

```ts
await agent.generate(input, {
  tracingOptions: {
    metadata: {
      companyId: 'acme-co',
      tier: 'enterprise',
    },
  },
})
```

다음과 같은 예약된 필드`input`, `output`, `sessionId`, thread/user IDs, and OpenInference IDs are excluded automatically.
