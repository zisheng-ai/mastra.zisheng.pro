# 층류 수출업체

[층류](https://laminar.sh/)AI Agent를 위한 오픈 소스 OpenTelemetry 기본 관찰 플랫폼입니다. 단일 Tool로 모든 Mastra Agent 실행, Model 단계, Tool 호출 및 하위 Agent를 추적, 디버깅 및 모니터링합니다.`MastraExporter`당신의`Observability`구성.

## 설치 {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 구성 {/* #configuration */}

### 전제조건 {/* #prerequisites */}

1. **층류 프로젝트**: Laminar에서 프로젝트 생성/선택
2. **프로젝트 API 키**: Laminar 프로젝트 설정에서 복사
3. **환경 변수**: 자격 증명을 설정하세요

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 제로 구성 설정 {/* #zero-config-setup */}

환경 변수가 설정된 경우 구성 없이 내보내기를 사용합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 명시적 구성 {/* #explicit-configuration */}

자격 증명을 직접 전달할 수도 있습니다(환경 변수보다 우선 적용됨).

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::참고
전체 `MastraExporter` 옵션과 다중 Agent Trace 예제를 포함한 고급 사용법은 [Laminar의 Mastra 통합 가이드](https://laminar.sh/docs/tracing/integrations/mastra)를 참조하세요.
:::
Mastra는 `@mastra/laminar`에 OTLP/HTTP로 Span을 전송하는 독립 실행형 [`LaminarExporter`](/reference/observability/tracing/exporters/laminar)도 포함합니다. 이 Exporter는 활성 OTel 컨텍스트를 상속할 수 없고 Mastra Span을 Laminar의 네이티브 형식으로 완전히 매핑하지 않으므로, `observe()` 래퍼, 다중 Agent 루트 Span, 정확한 Laminar 렌더링에는 위의 `@lmnr-ai/lmnr` 통합을 사용하세요.
