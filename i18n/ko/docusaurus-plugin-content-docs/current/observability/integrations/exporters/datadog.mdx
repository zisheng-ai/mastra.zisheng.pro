# Datadog 수출업자

[데이터독](https://datadoghq.com/)전용 LLM 관찰 기능을 갖춘 완벽한 모니터링 플랫폼입니다. Datadog 내보내기 Tool는 추적을 Datadog의 LLM Observability 제품으로 보내 Model 성능, 토큰 사용, 대화 흐름에 대한 통찰력을 제공합니다.

:::정보 또한 사용 중`dd-trace` APM?

당신도 사용하는 경우`dd-trace` APM auto-instrumentation, consider the [Datadog Bridge](/docs/observability/integrations/bridges/datadog) instead. The bridge creates `dd-trace`실시간으로 범위를 확장하므로 Tool 및 프로세서 내부의 HTTP 및 데이터베이스 호출이 상위 Mastra 범위 아래에 올바르게 중첩됩니다. 내보내기는 실행이 완료된 후 자체적으로 LLM 관찰 데이터를 보냅니다. 이는 자동 계측된 APM 범위가 요청 처리기로 대체됨을 의미합니다.

:::

## 설치 {/* #installation */}

```bash npm2yarn
npm install @mastra/datadog@latest
```

## 구성 {/* #configuration */}

### 전제조건 {/* #prerequisites */}

1. **데이터독 계정**: 가입하세요[datadoghq.com](https://datadoghq.com/) with LLM Observability enabled
2. **API 키**: Datadog 조직 설정 → API 키에서 API 키를 받으세요.
3. **환경 변수**: 자격 증명을 설정하세요

```bash title=".env"
DD_API_KEY=your-datadog-api-key
DD_LLMOBS_ML_APP=my-llm-app
DD_SITE=datadoghq.com  # Optional: defaults to datadoghq.com
DD_ENV=production      # Optional: environment name
```

### 제로 구성 설정 {/* #zero-config-setup */}

환경 변수가 설정된 경우 구성 없이 내보내기를 사용합니다.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { DatadogExporter } from '@mastra/datadog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      datadog: {
        serviceName: 'my-service',
        exporters: [new DatadogExporter()],
      },
    },
  }),
})
```

### 명시적 구성 {/* #explicit-configuration */}

자격 증명을 직접 전달할 수도 있습니다(환경 변수보다 우선 적용됨).

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { DatadogExporter } from '@mastra/datadog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      datadog: {
        serviceName: 'my-service',
        exporters: [
          new DatadogExporter({
            mlApp: process.env.DD_LLMOBS_ML_APP!,
            apiKey: process.env.DD_API_KEY!,
          }),
        ],
      },
    },
  }),
})
```

## 구성 옵션 {/* #configuration-options */}

### 완전한 구성 {/* #complete-configuration */}

```typescript
new DatadogExporter({
  // Required settings
  mlApp: process.env.DD_LLMOBS_ML_APP!, // Groups traces under this ML app name
  apiKey: process.env.DD_API_KEY!, // Required for agentless mode (default)

  // Optional settings
  site: 'datadoghq.com', // Datadog site (datadoghq.eu, us3.datadoghq.com, etc.)
  service: 'my-service', // Service name (defaults to mlApp)
  env: 'production', // Environment name
  agentless: true, // true = direct HTTPS, false = local Datadog Agent

  // Advanced settings
  integrationsEnabled: false, // Enable dd-trace auto-instrumentation

  // Diagnostic logging
  logLevel: 'info', // debug | info | warn | error
})
```

### 로컬 Datadog Agent 사용 {/* #with-local-datadog-agent */}

로컬로 실행 중인 Datadog Agent가 있는 경우 직접 HTTPS 대신 이를 통해 추적을 라우팅할 수 있습니다.

```typescript
new DatadogExporter({
  mlApp: process.env.DD_LLMOBS_ML_APP!,
  agentless: false, // Use local Datadog Agent
  env: 'production',
})
```

참고: Agent 모드를 사용하는 경우 로컬 Agent 구성에서 API 키를 읽습니다.

## 스팬 유형 매핑 {/* #span-type-mapping */}

Mastra 범위 유형은 Datadog LLM Observability 범위 종류에 자동으로 매핑됩니다.

| 마스트라 스팬타입 | 데이터독 종류 |
| - | - |
|`AGENT_RUN` | `agent` |
| `MODEL_GENERATION` | `workflow` |
| `MODEL_STEP` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `WORKFLOW_RUN` | `workflow` |
| Other workflow types | `task` |
| `GENERIC` | `task` |

기타/향후 Mastra 범위 유형은 지정하지 않는 한 매핑 시 기본적으로 '작업'으로 설정됩니다.

## 애플리케이션 성능 모니터링 {/* #application-performance-monitoring */}

위 섹션에서는 Mastra의 내용을 다룹니다.[LLM Observability](https://docs.datadoghq.com/llm_observability/) integration. To trace your Mastra HTTP server routes (request latency, error tracking, service maps), use `dd-trace` directly for Datadog Application Performance Monitoring (APM).

### 전제조건 {/* #prerequisites-1 */}

1. **데이터독 Agent**: 설치[Datadog Agent](https://docs.datadoghq.com/agent/) on the same host or accessible via network. The agent receives traces from `dd-trace` on `localhost:8126` and forwards them to Datadog. Follow the [agent installation guide](https://docs.datadoghq.com/agent/) to set it up.
2. **dd-trace 패키지**: 프로젝트에 추적 라이브러리를 설치합니다.

   ```bash npm2yarn
   npm install dd-trace
   ```

:::참고
APM 추적은 항상 Datadog Agent를 통해 라우팅됩니다. 이는 Agent 없는 모드(HTTPS에서 Datadog으로 직접 연결)를 지원하는 LLM Observability와 다릅니다.
:::

### APM 전용 {/* #apm-only */}

가져오기 및 초기화`dd-trace` at the top of your entry file, before any other imports:

```typescript title="src/mastra/index.ts"
import tracer from 'dd-trace'

tracer.init({
  service: process.env.DD_SERVICE || 'my-mastra-app',
  env: process.env.DD_ENV || 'production',
  version: process.env.DD_VERSION,
})

import { Mastra } from '@mastra/core'

export const mastra = new Mastra({
  bundler: {
    externals: [
      'dd-trace',
      '@datadog/native-metrics',
      '@datadog/native-appsec',
      '@datadog/native-iast-taint-tracking',
      '@datadog/pprof',
    ],
  },
})
```

추적기 메타데이터 환경 변수를 설정합니다.

```bash title=".env"
DD_SERVICE=my-mastra-app
DD_ENV=production
DD_VERSION=1.0.0
```

`dd-trace`Mastra의 지원을 포함하여 널리 사용되는 HTTP 프레임워크를 자동 계측합니다.[server adapters](/docs/server/server-adapters). Inbound requests, outbound HTTP calls, and database queries appear as APM traces in Datadog.

### APM 및 LLM Observability {/* #apm-and-llm-observability */}

가져오기 및 초기화`dd-trace` before creating the Mastra instance. The `DatadogExporter` detects the existing tracer and skips re-initialization, adding LLM Observability on top of your APM setup:

```typescript title="src/mastra/index.ts"
import tracer from 'dd-trace'

tracer.init({
  service: process.env.DD_SERVICE || 'my-mastra-app',
  env: process.env.DD_ENV || 'production',
  version: process.env.DD_VERSION,
})

import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { DatadogExporter } from '@mastra/datadog'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      datadog: {
        serviceName: 'my-mastra-app',
        exporters: [
          new DatadogExporter({
            mlApp: process.env.DD_LLMOBS_ML_APP!,
            apiKey: process.env.DD_API_KEY!,
          }),
        ],
      },
    },
  }),
  bundler: {
    externals: [
      'dd-trace',
      '@datadog/native-metrics',
      '@datadog/native-appsec',
      '@datadog/native-iast-taint-tracking',
      '@datadog/pprof',
    ],
  },
})
```

```bash title=".env"
DD_SERVICE=my-mastra-app
DD_ENV=production
DD_VERSION=1.0.0
DD_API_KEY=your-datadog-api-key
DD_LLMOBS_ML_APP=my-llm-app
```

서버 경로는 APM 추적으로 표시되고 LLM 호출은 LLM 관찰 범위로 표시되며 모두 Datadog의 동일한 서비스 아래에 있습니다.

:::참고
가져오기 및 초기화`dd-trace` before all other modules. This allows its auto-instrumentation to patch HTTP, database, and framework libraries at load time.
:::

## 문제 해결 {/* #troubleshooting */}

### 네이티브 모듈 ABI 불일치 {/* #native-module-abi-mismatch */}

다음과 같은 오류가 표시되는 경우:

```
Error: No native build was found for runtime=node abi=137 platform=linuxglibc arch=x64
```

이는 Node.js 버전 호환성 문제를 나타냅니다.`dd-trace`'s native modules. These native modules are **optional** and provide performance monitoring features.

**솔루션:**

1. **Node.js 22.x 사용**: 네이티브 모듈은 Node.js 22.x와 가장 잘 호환됩니다.

2. **네이티브 모듈 경고 무시**: 네이티브 모듈(`@datadog/native-metrics`, `@datadog/native-appsec`, etc.) are optional. If they fail to load, core tracing functionality still works.

### 번들러 외부 구성 {/* #bundler-externals-configuration */}

esbuild, webpack 또는 Mastra CLI 번들러와 같은 번들러를 사용하는 경우 다음을 표시해야 할 수도 있습니다.`dd-trace` and its dependencies as external:

```typescript title="src/mastra/index.ts"
export const mastra = new Mastra({
  bundler: {
    externals: [
      'dd-trace',
      '@datadog/native-metrics',
      '@datadog/native-appsec',
      '@datadog/native-iast-taint-tracking',
      '@datadog/pprof',
    ],
  },
})
```
