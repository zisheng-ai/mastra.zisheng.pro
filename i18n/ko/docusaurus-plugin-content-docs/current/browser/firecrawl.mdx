# 파이어 크롤링

그만큼`@mastra/browser-firecrawl`패키지는 다음을 사용하여 브라우저 자동화를 제공합니다.[Firecrawl 브라우저 샌드박스](https://docs.firecrawl.dev/features/browser). Firecrawl API를 통해 원격 브라우저 세션을 프로비저닝하고 동일한 결정론적 접근성 우선 Tool를 사용하여 이를 구동합니다.[Agent브라우저](/docs/browser/agent-browser).

`FirecrawlBrowser`연장`AgentBrowser`, so agents get the same toolset (`browser_goto`, `browser_snapshot`, `browser_click`등) 브라우저 자체는 Firecrawl의 호스팅 인프라에서 실행됩니다. 로컬 Chromium 설치가 필요하지 않습니다.

## Firecrawl을 사용해야 하는 경우 {/* #when-to-use-firecrawl */}

다음과 같은 경우 Firecrawl을 사용하세요.

* 로컬 Chromium 바이너리를 관리하지 않고 호스팅된 브라우저 세션
* 로컬 브라우저를 실행할 수 없는 환경의 브라우저 자동화
* 자동 세션 정리를 통한 스레드별 샌드박스 격리
* 세션 간 쿠키 및 로그인 상태를 유지하는 명명된 Firecrawl 프로필

## 빠른 시작 {/* #quickstart */}

패키지를 설치합니다:

```bash npm2yarn
npm install @mastra/browser-firecrawl
```

Firecrawl API 키를 설정합니다.

```bash title=".env"
FIRECRAWL_API_KEY=fc-...
```

브라우저 인스턴스를 생성하고 Agent에 할당합니다.

```typescript title="src/mastra/agents/firecrawl-agent.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
})

export const firecrawlAgent = new Agent({
  id: 'firecrawl-agent',
  name: 'Firecrawl Agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
  instructions: `You are a web automation assistant.

When interacting with pages:
1. Use browser_snapshot to get the current page state and element refs
2. Use the refs (like @e1, @e2) to target elements for clicks and typing
3. After actions, take another snapshot to verify the result`,
})
```

만약에`apiKey` is omitted, the provider reads `FIRECRAWL_API_KEY` from the environment.

## 세션 범위 {/* #session-scope */}

`FirecrawlBrowser`같은 것을 따른다`scope` option as `AgentBrowser`:

* `'thread'`(기본값): 각 대화 스레드는 자체 Firecrawl 샌드박스 세션을 갖습니다. 스레드의 브라우저가 닫히면 세션이 삭제됩니다.
* `'shared'`: 하나의 Firecrawl 샌드박스 세션은 모든 스레드에서 공유되며 브라우저가 닫히면 삭제됩니다.

```typescript
const browser = new FirecrawlBrowser({
  scope: 'shared',
})
```

## 세션 옵션 {/* #session-options */}

Firecrawl 관련 세션 옵션을 아래에 전달하세요.`firecrawl` key. These map to the Firecrawl `browser()` API:

```typescript
const browser = new FirecrawlBrowser({
  firecrawl: {
    ttl: 600,
    activityTtl: 120,
    profile: {
      name: 'my-profile',
      saveChanges: true,
    },
  },
})
```

* `ttl`: 최대 세션 수명(초)입니다.
* `activityTtl`: Firecrawl이 세션을 재활용하기 전 유휴 시간 제한(초)입니다.
* `profile`: 쿠키 및 로그인 상태를 유지하는 명명된 Firecrawl 프로필입니다. 세트`saveChanges: true` to save profile changes when the session ends.

:::메모

중첩된`firecrawl.profile` option refers to a profile stored in Firecrawl's infrastructure. It's different from the top-level `profile` option inherited from `AgentBrowser`, which is a local Playwright user-data directory path.

:::

## 자체 호스팅 Firecrawl {/* #self-hosted-firecrawl */}

자체 호스팅 Firecrawl API를 사용하려면 다음을 설정하세요.`apiUrl`:

```typescript
const browser = new FirecrawlBrowser({
  apiUrl: 'https://firecrawl.internal.example.com',
})
```
