Mastra의 Model 라우터를 통해 2개의 Modal Model에 액세스하세요. 인증은 다음을 사용하여 자동으로 처리됩니다.`MODAL_PROXY_TOKEN` environment variable.

자세한 내용은 다음에서 확인하세요.[Modal documentation](https://modal.com/docs/guide/endpoints).

```bash title=".env"
MODAL_PROXY_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "modal/moonshotai/Kimi-K3"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```
