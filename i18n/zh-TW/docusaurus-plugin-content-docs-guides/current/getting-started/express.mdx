# 在你的 Express 專案中整合 Mastra

本指南將帶你使用 Mastra 和 Express 建立可呼叫 Tool 的 AI Agent。透過 [Express server adapter](/reference/server/express-adapter)，你不必自行撰寫路由，也不必另外執行 Mastra 伺服器，就能將 Agent 公開為 HTTP 端點。

## 開始之前

- 你需要受支援[模型 Provider](/models) 的 API 金鑰。如果沒有偏好，請使用 [OpenAI](/models/providers/openai)。
- 安裝 Node.js `v22.13.0` 或更新版本

## 建立新的 Express 應用程式（選用）

如果你已經有 Express 應用程式，請跳到下一個步驟。

複製此[範本儲存庫](https://github.com/mastra-ai/express-ts-boilerplate)並安裝相依套件：

## 初始化 Mastra

在 Express 專案目錄中執行 [`mastra init`](/reference/cli/mastra#mastra-init)。

出現提示時，選擇 Provider（例如 OpenAI）並輸入金鑰：

```bash
npx mastra@latest init
```

這會建立 `src/mastra` 資料夾，其中包含範例天氣 Agent 和下列檔案：

- `index.ts` - Mastra 設定，包含記憶功能
- `tools/weather-tool.ts` - 擷取指定位置天氣資訊的 Tool
- `agents/weather-agent.ts`- 使用該 Tool 的天氣 Agent，並包含提示詞

稍後你會將 `src/mastra/index.ts` 檔案傳遞給 Express server adapter。

## 加入 server adapter

安裝 Express server adapter 套件：

```bash npm2yarn
npm install @mastra/express@latest
```

開啟位於 `src/index.ts` 的 Express 入口檔案，並加入必要的匯入與初始化程式碼：

```typescript {2-3,11-12} title="src/index.ts"
import express, { type Request, type Response } from 'express'
import { MastraServer } from '@mastra/express'
import { mastra } from './mastra'

const app = express()
const PORT = process.env.PORT || 3000

// Middleware
app.use(express.json())

const server = new MastraServer({ app, mastra })
await server.init()

// Routes
app.get('/', (_req: Request, res: Response) => {
  res.json({ message: 'Hello, World!' })
})

// Start server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`)
})
```

⁠`MastraServer` 會使用既有的 Express `app` 和根 ⁠`mastra` 執行個體進行初始化。呼叫 `⁠init()` 會註冊 Mastra middleware，並公開所有可用的 Mastra 端點。

## 測試你的 Agent

Mastra 端點預設會加入 `/api` 子路徑下，並使用 Agent／Workflow ID。由 `mastra init` 建立的預設 `weather-agent` 可在 `/api/agents/weather-agent` 使用。

啟動 Express 伺服器：

```bash
npm run start
```

在另一個終端機視窗中，使用 `curl` 向天氣 Agent 提問：

```bash
curl -X POST http://localhost:3000/api/agents/weather-agent/generate -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"What is the weather like in Seoul?\"}]}"
```
