# Mastra 快速入門

<Inject>
  **供 AI Agent 使用：** 使用 `npm create mastra@latest <project-name> -- --llm <provider>` 以非互動方式建立新的 Mastra 專案，並將 `<provider>` 替換為 `openai`、`anthropic`、`google` 或 `xai`。若要建立不含 Agent 或模型 Provider 的最小專案，請使用 `npm create mastra@latest <project-name> -- --empty`。若要從零開始建立 Mastra 專案，請參閱[手動安裝指南](/guides/getting-started/manual-install)。
</Inject>

`create-mastra` CLI 是建立 Mastra 專案最快的方式。它會建立一個 Agent Harness，其中包含 Workspace Tool、Memory、任務追蹤、網路存取、Schedule、Storage 和 Observability。

若需要更細緻的控制，請參閱[手動安裝指南](/guides/getting-started/manual-install)。若要將 Mastra 加入既有專案，請使用 [`mastra init`](/reference/cli/mastra#mastra-init)。

## 開始之前 {/* #before-you-begin */}

你需要 OpenAI、Anthropic、Google Gemini 或 xAI 的 API 金鑰。你可以在設定過程中略過輸入，稍後再將金鑰加入 `.env`。

## 建立專案 {/* #create-the-project */}

執行互動式設定：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

此指令會要求你輸入專案名稱、模型 Provider，以及選填的 API 金鑰。接著，它會安裝相依套件、為你的 coding assistant 安裝 Mastra Skill，並在你目前不位於既有儲存庫中時建立初始 Git commit。

產生的 `src/mastra` 目錄包含 Mastra 入口點、Agent、Workspace Tool 和相關程式碼。若要了解標準 Mastra 專案結構，請參閱[專案結構參考文件](/reference/project-structure)。

:::tip

使用 `--template <template>` 從範本開始，或使用 `--empty` 建立不含 Provider 的最小專案。使用 `--no-skills` 或 `--no-git` 可略過自動設定。所有旗標請參閱 [`create-mastra` 參考文件](/reference/cli/create-mastra)。

:::

## 測試你的 Agent {/* #test-your-agent */}

按照終端機指示進入專案目錄，並啟動開發伺服器：

```bash npm2yarn
npm run dev
```

開啟 [localhost:4111 上的 Studio](http://localhost:4111)，選擇 Agent 並傳送訊息。如果你在設定過程中略過 API 金鑰，請將 `.env.example` 中指定的 Provider API 金鑰加入 `.env` 檔案。

[Studio](/docs/studio/overview) 讓你不必另外建立 UI，就能建構及測試 Agent。
