# 將 Mastra 部署至 Cloudflare

使用 `@mastra/deployer-cloudflare` 將 Mastra 伺服器部署至 Cloudflare Workers。Deployer 會封裝程式碼，並產生符合 Cloudflare [wrangler 設定](https://developers.cloudflare.com/workers/wrangler/configuration/)的 `wrangler.jsonc` 檔案，不需要額外設定即可部署。

:::info

若你使用[伺服器轉接器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，請依該框架平常的方式部署。

:::

## 開始之前 {/* #before-you-begin */}

你需要一個 [Mastra 應用程式](/guides/getting-started/quickstart)和一個 [Cloudflare](https://cloudflare.com/) 帳號。

:::warning
Cloudflare Workers 使用暫時性檔案系統，因此設定的任何儲存空間（包括可觀測性儲存空間）都必須託管於外部。若你使用的 [LibSQLStore](/reference/storage/libsql) 採用檔案 URL，請改用遠端託管的資料庫。
:::

## 安裝 {/* #installation */}

將 `@mastra/deployer-cloudflare` 套件加入專案：

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

匯入 [`CloudflareDeployer`](/reference/deployer/cloudflare)，並在 Mastra 設定中將其設為 Deployer：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

若要在本機測試 Cloudflare Worker，也請安裝 [`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/)：

```bash npm2yarn
npm install -D wrangler
```

## 使用方式 {/* #usage */}

設定專案後，將專案推送至你選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    將儲存庫連接至 Cloudflare。在「Workers & Pages」控制面板中選取 **Create application**，然後在下一步選擇 Git Provider。繼續完成設定流程，並選取要部署的儲存庫。

    :::note

    請記得設定執行應用程式所需的環境變數（例如[模型 Provider](/models/providers) 的 API 金鑰）。你可以使用 `npx wrangler secret bulk .env` 從 `.env` 檔案上傳密鑰。詳情請參閱[密鑰](/reference/deployer/cloudflare#secrets)。

    :::
  </StepItem>

  <StepItem>
    準備就緒後，按一下 **Deploy** 按鈕，等待第一次部署完成。
  </StepItem>

  <StepItem>
    前往 `https://<your-project-name>.<slug>.workers.dev/api/agents`，試用剛部署的函式。你應會收到列出所有可用 Agent 的 JSON 回應。

    由於 [Mastra 伺服器](/docs/server/mastra-server)會在每個 API 端點前加上 `/api`，因此提出要求時必須將其加入 URL。
  </StepItem>

  <StepItem>
    現在可以透過 HTTP 呼叫 Mastra 端點。

    :::note

    將端點公開前，請先設定[驗證](/docs/server/auth)。

    :::
  </StepItem>
</Steps>
