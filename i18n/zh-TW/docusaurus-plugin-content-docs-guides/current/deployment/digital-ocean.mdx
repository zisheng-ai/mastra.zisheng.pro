# 將 Mastra 部署至 Digital Ocean

本指南涵蓋 Digital Ocean 的 App Platform 與 Droplets。這兩項服務各有優勢，適合不同類型的專案與開發者經驗程度。請閱讀 [Digital Ocean 的比較文章](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets)，瞭解兩者差異並為你的專案選擇最合適的方案。

:::info
本指南說明如何部署 [Mastra server](/docs/server/mastra-server)。如果你使用 [server adapter](/docs/server/server-adapters) 或 [web framework](/docs/deployment/web-framework)，請依照該框架平常的方式部署。
:::

## 開始之前

你需要一個 [Mastra 應用程式](/guides/getting-started/quickstart)和一個 [Digital Ocean](https://www.digitalocean.com/) 帳號。

**App Platform** 使用暫時性檔案系統，因此你設定的任何儲存空間（包含可觀測性儲存空間）都必須託管於外部。如果你使用檔案 URL 搭配 [LibSQLStore](/reference/storage/libsql)，請改用遠端託管的資料庫。

## App Platform

設定好專案後，將專案推送至你選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    依照官方的 [App Platform 快速入門](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app)操作。該指南會引導你連接儲存庫、選擇要部署的分支，並視需要設定來源目錄。
  </StepItem>

  <StepItem>
    確認系統偵測到「Node.js」建置。你需要設定建置指令，請依使用的套件管理工具設定：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    新增 Mastra 應用程式所需的所有環境變數，包括 API 金鑰、資料庫 URL 與其他設定值。
  </StepItem>

  <StepItem>
    應用程式會自動建置並部署。Digital Ocean 會提供一個 URL，讓你存取已部署的應用程式。
  </StepItem>

  <StepItem>
    現在你可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    將端點公開之前，請先設定[驗證](/docs/server/auth)。
    :::
  </StepItem>
</Steps>

## Droplets

### 必要條件

- 執行 Ubuntu 24.04 LTS 或更新版本的 Droplet
- 一個具有指向你 Droplet 之 A 記錄的網域名稱
- 已設定反向 Proxy（例如使用 [nginx](https://nginx.org/)）
- 已設定 SSL 憑證（例如使用 [Let's Encrypt](https://letsencrypt.org/)）
- Droplet 上已安裝 Node.js 22.13.0 或更新版本

### 部署

設定好專案後，將專案推送至你選擇的遠端 Git Provider（例如 GitHub）。連線至 Droplet，並確認已安裝 `git`。

<Steps>
  <StepItem>
    複製你的儲存庫：

    <Tabs>
      <TabItem value="public" label="公開儲存庫">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="私人儲存庫">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    前往儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝專案相依套件：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    設定 Mastra 應用程式所需的環境變數。在專案根目錄建立 `.env` 檔案：

    ```bash
    touch .env
    ```

    編輯 `.env` 檔案並加入環境變數：

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    建置專案：

    ```bash npm2yarn
    npm run build
    ```

    這會在 `.mastra/output` 目錄中建立 Mastra server 的正式環境建置版本。
  </StepItem>

  <StepItem>
    你可以執行 `mastra start` 指令來啟動 [Mastra Server](/docs/deployment/mastra-server)：

    ```bash
    mastra start
    ```

    :::info
    Mastra 應用程式預設會在連接埠 4111 上執行。請確認反向 Proxy 已設定為將請求轉送至此連接埠。
    :::
  </StepItem>

  <StepItem>
    現在你可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    將端點公開之前，請先設定[驗證](/docs/server/auth)。
    :::
  </StepItem>
</Steps>
