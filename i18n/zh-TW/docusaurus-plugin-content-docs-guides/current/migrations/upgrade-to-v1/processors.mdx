# 處理器

處理器介面已更新為使用一致的命名模式與資料庫訊息型別。

## 已變更 {/* #changed */}

### 處理器設定從 `name` 改為 `id` {/* #processor-configuration-from-name-to-id */}

處理器現在必須使用 `id` 欄位，而非 `name`。`name` 欄位現在是選填。這項變更讓它與 scorer 和 Agent 等其他 Mastra 實體保持一致。

遷移時，請更新處理器定義，將 `id` 作為必填欄位。

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### 處理器訊息型別從 `MastraMessageV2` 改為 `MastraDBMessage` {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}

處理器訊息型別已從 `MastraMessageV2` 變更為 `MastraDBMessage`。處理器與 scorer 現在會使用資料庫訊息格式及其型別。

遷移時，請更新處理器訊息型別的匯入與用法。

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 已移除 {/* #removed */}

### 已棄用的輸入處理器匯出項目 {/* #deprecated-input-processor-exports */}

`@mastra/core/agent/input-processors/processors` 中包含內建處理器的已棄用輸入處理器匯出項目已移除。請改用 `@mastra/core/processors`。這項變更將處理器型別整合至統一的 `Processor` 介面之下。

如果你原本使用 `InputProcessor`，請改用實作 `processInput` 函式的 `Processor`。

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory 處理器匯出項目移至 core {/* #memory-processor-exports-moved-to-core */}

`@mastra/memory/processors` 匯出項目已移除。所有處理器現在都從 `@mastra/core/processors` 匯出。這項變更將所有處理器匯出項目整合至單一位置。

遷移時，請將匯入路徑從 `@mastra/memory/processors` 更新為 `@mastra/core/processors`。

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
