# Voice

Voice 套件已從 speech 重新命名為 voice，類別名稱與 API 方法也已更新。

## 已變更 {/* #changed */}

### Voice 設定屬性名稱 {/* #voice-configuration-property-names */}

Voice 設定屬性已重新命名，以保持一致。`speakProvider` 現在是 `output`、`listenProvider` 現在是 `input`，而 `realtimeProvider` 現在是 `realtime`。新名稱與各屬性在語音輸入及輸出中的用途相符。

遷移時，請更新具備 Voice 功能之 Agent 的設定屬性名稱。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip[Codemod]

你可以使用 Mastra 的 codemod CLI 自動更新程式碼：

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
