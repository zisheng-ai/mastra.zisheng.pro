# CLI

CLI 已移除部署命令、設定旗標與起始檔案，因而更加精簡。此外也新增遷移命令，協助處理資料庫結構描述升級。

## 已新增 {/* #added */}

### `mastra migrate` 命令 {/* #mastra-migrate-command */}

新的 `mastra migrate` 命令可在升級 Mastra 版本時協助執行資料庫遷移。從可能存在資料不相容問題的舊版升級時，這項功能特別實用。

```bash
npx mastra migrate
```

此命令會封裝你的專案，連線至已設定的儲存空間，再執行所有必要的遷移。目前支援遷移可能導致無法建立唯一條件約束的重複 span 項目。

如需瞭解何時需要這項遷移，請參閱[儲存空間遷移指南](/guides/migrations/upgrade-to-v1/storage#duplicate-spans-migration)。

## 已移除 {/* #removed */}

### `mastra deploy` 命令 {/* #mastra-deploy-command */}

CLI 已移除 `mastra deploy` 命令。這項變更移除特定廠商的部署邏輯，讓 CLI 更加精簡。

遷移時，請選擇一個你偏好的[部署平台](/docs/deployment/overview)。

### `mastra build` 的 `--env` 旗標 {/* #--env-flag-from-mastra-build */}

`mastra build` 命令已移除 `--env` 旗標。這項變更簡化了建置命令。

遷移時，請使用 `mastra start --env <env>`，以自訂環境啟動建置輸出。

```diff
- mastra build --env production
+ mastra build
+ mastra start --env production
```

### `mastra dev` 的 `--port` 旗標 {/* #--port-flag-from-mastra-dev */}

`mastra dev` 命令已移除 `--port` 旗標。連接埠設定現在透過 Mastra 執行個體設定處理，讓連接埠設定集中於一處。

遷移時，請在 Mastra 執行個體上使用 `server.port`，而非 CLI 旗標。

```ts
const mastra = new Mastra({
  server: {
    port: 3001,
  },
})
```

### CLI 的遙測選項 {/* #telemetry-options-from-cli */}

CLI 命令已移除 `telemetry` 選項，包括 `--no-telemetry` / `-nt` 旗標。CLI 不再提供遙測設定。這項變更反映遙測功能已移至可觀測性套件。

遷移時，請移除 CLI 命令中的遙測旗標。追蹤功能請改用 `@mastra/observability`。
