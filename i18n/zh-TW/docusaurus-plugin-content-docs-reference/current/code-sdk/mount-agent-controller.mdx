# mountAgentControllerOnMastra()

:::experimental

`@mastra/code-sdk` 套件仍處於實驗階段，次要版本可能包含破壞性變更。

:::

`mountAgentControllerOnMastra()` 函式會建立 Mastra Code Agent controller（即 [`mastracode`](https://www.npmjs.com/package/mastracode) CLI 背後的 Coding Agent，包含其模式、Tool、Memory 與 thread 管理），並將其註冊至伺服器擁有的 [Mastra](/reference/core/mastra-class) 執行個體。你可以用它將 Mastra Code Agent 提供給自己的 UI（網頁應用程式、編輯器、bot）：每個使用者端都會透過傳回的 [`AgentController`](/reference/agent-controller/agent-controller-class)，建立或繼續各自隔離的 session。

若要自行建構 `Mastra` 執行個體（例如在可部署的進入點檔案中），請使用相同套件中的 `prepareAgentControllerMount()`；它會傳回建構函式引數與 `finalize()` callback。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

傳入現有 `mastra`，將 controller 掛載至已託管其他 primitive 的 Mastra 執行個體：

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
