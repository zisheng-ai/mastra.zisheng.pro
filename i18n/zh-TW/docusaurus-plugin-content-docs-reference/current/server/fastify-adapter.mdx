# Fastify 轉接器

`@mastra/fastify` 套件提供了一個 Server 轉接器，用於透過 [Fastify](https://fastify.dev) 執行 Mastra。有關通用轉接器概念（建構函式選項、初始化流程等），請參閱 [Server Adapters](/docs/server/server-adapters)。

## 安裝

安裝 Fastify 轉接器和 Fastify 框架：

```bash npm2yarn
npm install @mastra/fastify@latest fastify
```

## 使用範例

```typescript title="server.ts"
import Fastify from 'fastify'
import { MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify({ logger: true })
const server = new MastraServer({ app, mastra })

await server.init()

app.listen({ port: 3000 }, (err, address) => {
  if (err) {
    console.error(err)
    process.exit(1)
  }
  console.log(`Server running on ${address}`)
})
```

## 保護原始路由

若要使用 Mastra 管理的身分驗證和 `requiresAuth` 等路由中繼資料，請優先使用 [`registerApiRoute()`](/reference/server/register-api-route)。對於直接掛載在 app 上的原始 Fastify 路由，請使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import Fastify from 'fastify'
import { createAuthMiddleware, MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', { preHandler: createAuthMiddleware({ mastra }) }, async request => {
  const user = request.requestContext.get('user')
  return { user }
})

app.get(
  '/custom/public',
  { preHandler: createAuthMiddleware({ mastra, requiresAuth: false }) },
  async () => {
    return { ok: true }
  },
)
```

## 手動初始化

如需自訂 middleware 順序，請分別呼叫每個方法，而不是呼叫 `init()`。詳見[手動初始化](/docs/server/server-adapters#manual-initialization)。
