# AWS Nova Sonic Voice

`NovaSonicVoice` 類別提供由 [AWS Bedrock Nova 2 Sonic](https://docs.aws.amazon.com/nova/latest/userguide/speech.html) 支援的即時語音對語音功能。它會開啟與模型之間的雙向資料流，並針對助理音訊、轉錄文字、Tool 呼叫、對話輪次邊界與中斷發出事件。

## 使用範例

```typescript title="src/mastra/voice.ts"
import { NovaSonicVoice } from '@mastra/voice-aws-nova-sonic'
import { playAudio, getMicrophoneStream } from '@mastra/node-audio'

// Initialize using the default AWS credential provider chain
const voice = new NovaSonicVoice({
  region: 'us-east-1',
  speaker: 'matthew',
})

// Or pass explicit credentials
const voiceWithCredentials = new NovaSonicVoice({
  region: 'us-east-1',
  speaker: 'tiffany',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
  },
})

// Establish the bidirectional stream
await voice.connect()

// Listen for assistant audio (Int16Array PCM)
voice.on('speaking', ({ audioData }) => {
  if (audioData) playAudio(audioData)
})

// Listen for transcribed text from the user and assistant
voice.on('writing', ({ text, role, generationStage }) => {
  console.log(`${role} (${generationStage ?? 'FINAL'}): ${text}`)
})

// Stream microphone audio in real time
const microphoneStream = getMicrophoneStream()
await voice.send(microphoneStream)

// Disconnect when done
voice.close()
```

## 驗證

若未傳入 `credentials` 選項，`NovaSonicVoice` 會使用 AWS SDK 認證資訊解析鏈。Mastra 會呼叫 `@aws-sdk/credential-provider-node` 的 `defaultProvider()`，依序檢查環境變數、共用認證資訊檔、EC2 的 IAM 角色、ECS、EKS 及其他標準來源。

若要使用靜態認證資訊，請將其傳入建構函式：

```typescript
new NovaSonicVoice({
  region: 'us-east-1',
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
    sessionToken: process.env.AWS_SESSION_TOKEN,
  },
})
```

此 Voice Provider 絕不會將認證資訊值寫入記錄。

## 方法

### `connect()`

開啟與 AWS Bedrock 之間的雙向資料流，並傳送初始工作階段、提示與系統事件。請先呼叫此方法，再呼叫 `speak`、`listen` 或 `send`。

<PropertiesTable
  content={[
  {
    name: 'options',
    type: '{ requestContext?: RequestContext }',
    description: '選用的請求內容，會傳播至工作階段期間進行的 Tool 呼叫。',
    isOptional: true,
  },
]}/>

回傳：`Promise<void>`

### `speak()`

合成文字提示的語音，並在產生音訊時發出 `speaking` 事件。

<PropertiesTable
  content={[
  {
    name: 'input',
    type: 'string | NodeJS.ReadableStream',
    description: '要合成的文字或文字資料流。',
    isOptional: false,
  },
  {
    name: 'options',
    type: 'NovaSonicVoiceOptions',
    description: '單次呼叫的覆寫設定，例如語音或語言程式碼。',
    isOptional: true,
  },
]}/>

回傳：`Promise<void>`

### `send()`

將麥克風音訊（或任何 PCM 來源）串流傳送至模型。適用於即時且持續的對話。

<PropertiesTable
  content={[
  {
    name: 'audioData',

    description: '要轉送至模型的 16 位元 PCM 音訊。',
    isOptional: false,
  },
]}/>

回傳：`Promise<void>`

### `listen()`

委派給 `send()` 的便利包裝函式。當您要對有限的音訊資料流執行單次轉錄時使用。

<PropertiesTable
  content={[
  {
    name: 'audioData',
    type: 'NodeJS.ReadableStream',
    description: '要轉錄的音訊資料流。',
    isOptional: false,
  },
]}/>

回傳：`Promise<void>`

### `endAudioInput()`

指示目前音訊輪次結束，讓模型完成回應。當使用者停止說話，且 Provider 未設定伺服器端對話輪次偵測時，請呼叫此方法。

回傳：`Promise<void>`

### `addInstructions()`

更新作用中工作階段的系統提示。

<PropertiesTable
  content={[
  {
    name: 'instructions',
    type: 'string',
    description: '要套用至工作階段的系統提示。',
    isOptional: true,
  },
]}/>

回傳：`void`

### `addTools()`

在 Voice 執行個體註冊 Tools。`NovaSonicVoice` 附加至 Agent 時，系統會自動加入 Agent 的 Tools。

<PropertiesTable
  content={[
  {
    name: 'tools',
    type: 'ToolsInput',
    description: '向模型公開的 Tools。',
    isOptional: true,
  },
]}/>

回傳：`void`

### `getSpeakers()`

回傳 Nova 2 Sonic 支援的語音清單。

回傳：`Promise<Array<{ voiceId: string; name: string; language: string; locale: string; gender: 'masculine' | 'feminine'; polyglot: boolean }>>`

### `getListener()`

回傳 Voice 執行個體目前是否維持開啟的資料流。

回傳：`Promise<{ enabled: boolean }>`

### `close()`

關閉雙向資料流並終止底層 Bedrock 使用者端。對話結束時請呼叫此方法。

回傳：`void`

### `on()` / `off()`

註冊及移除事件監聽器。共用事件 API 請參閱 [Voice 事件](./voice.events)。

## 注意事項

- 音訊以 16 位元 PCM 串流傳送。助理音訊會在 `speaking` 事件上以 `Int16Array` 發出。
- Voice 執行個體必須先呼叫 `connect()`，才能呼叫其他串流方法。
- `close()` 會終止底層 `BedrockRuntimeClient`，以釋放 HTTP/2 工作階段。
- Nova 2 Sonic 可在 `us-east-1`、`us-west-2` 與 `ap-northeast-1` 使用。其他區域會在建構期間擲回設定錯誤。
