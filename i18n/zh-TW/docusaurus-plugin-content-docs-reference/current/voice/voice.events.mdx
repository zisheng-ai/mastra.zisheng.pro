# Voice 事件

語音 Provider 會在即時語音互動期間發出事件。你可以使用 [voice.on()](./voice.on) 方法監聽這些事件；在建立互動式語音應用程式時，這些事件尤其重要。

## 注意事項

- 並非所有語音 Provider 都支援所有事件
- 確切的 payload 結構可能因 Provider 而異
- 非即時 Provider 不會發出其中大多數事件
- 這些事件適合用來建立會根據對話狀態做出回應的互動式 UI
- 不再需要事件監聽器時，請考慮使用 [voice.off()](./voice.off) 方法將其移除
