# SemanticRecall

`SemanticRecall` 是一種**混合處理器**，可透過向量嵌入，對對話歷史記錄執行語意搜尋。在輸入時，它會執行語意搜尋來找出相關的歷史訊息；在輸出時，它會為新訊息建立嵌入，以便日後進行語意擷取。

## 使用範例 {/* #usage-example */}

```typescript
import { SemanticRecall } from '@mastra/core/processors'
import { openai } from '@ai-sdk/openai'

const processor = new SemanticRecall({
  storage: memoryStorage,
  vector: vectorStore,
  embedder: openai.embedding('text-embedding-3-small'),
  topK: 5,
  messageRange: 2,
  scope: 'resource',
})
```

## 延伸使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/semantic-memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { SemanticRecall, MessageHistory } from '@mastra/core/processors'
import { PostgresStorage } from '@mastra/pg'
import { PgVector } from '@mastra/pg'
import { openai } from '@ai-sdk/openai'

const storage = new PostgresStorage({
  id: 'pg-storage',
  connectionString: process.env.DATABASE_URL,
})

const vector = new PgVector({
  id: 'pg-vector',
  connectionString: process.env.DATABASE_URL,
})

const semanticRecall = new SemanticRecall({
  storage,
  vector,
  embedder: openai.embedding('text-embedding-3-small'),
  topK: 5,
  messageRange: { before: 2, after: 1 },
  scope: 'resource',
  threshold: 0.7,
})

export const agent = new Agent({
  id: 'semantic-memory-agent',
  name: 'semantic-memory-agent',
  instructions: 'You are a helpful assistant with semantic memory recall',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [semanticRecall, new MessageHistory({ storage, lastMessages: 50 })],
  outputProcessors: [semanticRecall, new MessageHistory({ storage })],
})
```

## 行為 {/* #behavior */}

### 輸入處理 {/* #input-processing */}

1. 從最後一則使用者訊息擷取使用者查詢
1. 為查詢產生嵌入
1. 執行向量搜尋，找出語意相似的訊息
1. 擷取相符訊息及其周圍情境（依 `messageRange` 而定）
1. 若為 `scope: 'resource'`，將跨對話串訊息格式化為附有時間戳記的系統訊息
1. 加入帶有 `source: 'memory'` 標記的回想訊息

### 輸出處理 {/* #output-processing */}

1. 從新的使用者訊息和 assistant 訊息擷取文字內容
1. 為每則訊息產生嵌入
1. 將嵌入連同中繼資料（訊息 ID、對話串 ID、資源 ID、角色、內容、時間戳記）儲存在向量儲存區
1. 對嵌入使用 LRU 快取，以避免重複呼叫 API

### 跨對話串回想 {/* #cross-thread-recall */}

當 `scope` 設為 `'resource'` 時，處理器可以回想其他對話串的訊息。這些跨對話串訊息會格式化為附有時間戳記和對話標籤的系統訊息，提供對話發生時間與位置的情境。
