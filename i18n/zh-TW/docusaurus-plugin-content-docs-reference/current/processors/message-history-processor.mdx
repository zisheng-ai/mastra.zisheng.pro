# MessageHistory

`MessageHistory` 是一種**混合式處理器**，同時負責擷取及保存訊息記錄。處理輸入時，它會從儲存空間擷取歷史訊息，並將其加到對話前方。處理輸出時，它會將新訊息保存至儲存空間。

## 使用範例 {/* #usage-example */}

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
})
```

## 進階使用範例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStorage } from '@mastra/pg'

const storage = new PostgresStorage({
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
    }),
  ],
})
```

## 行為 {/* #behavior */}

### 輸入處理 {/* #input-processing */}

1. 從請求內容中擷取 `threadId`
1. 從儲存空間擷取歷史訊息（依建立日期降冪排列）
1. 篩除系統訊息（這些訊息不應儲存在資料庫中）
1. 將歷史訊息與傳入訊息合併，並依 ID 避免重複
1. 為歷史訊息加入 `source: 'memory'` 標籤

### 輸出處理 {/* #output-processing */}

1. 從請求內容中擷取 `threadId`
1. 若記憶體設定中已設定 `readOnly`，則略過保存
1. 從訊息中篩除未完成的 Tool 呼叫
1. 將新的使用者輸入與助理回應訊息保存至儲存空間
1. 更新討論串的 `updatedAt` 時間戳記
