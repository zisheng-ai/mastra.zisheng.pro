# Observability

Mastra 會透過 `src/mastra/` 正下方的 `observability.ts` 檔案設定 [Observability](/docs/observability/overview)。此檔案會 default export 一個 `Observability` instance，為專案設定 tracing、logging、metrics 與 feedback。

本頁說明檔案式慣例。若要了解 signal model、exporter、Storage 與多設定用法，請參閱 [Observability 概觀](/docs/observability/overview)和 [Observability 設定](/docs/observability/overview#configuration)。

## 快速開始 {/* #quickstart */}

建立 `src/mastra/observability.ts`，並 default export 一個 `Observability` instance：

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability 與 Storage {/* #observability-and-storage */}

`observability.ts` 會設定要收集哪些 signal，以及將它們 export 至何處。[`storage.ts`](/reference/file-based-agents/storage) 則設定可保存 Observability 記錄的專案 store。各 signal 的 Storage 支援情況請參閱 [Observability signal 支援情況](/docs/observability/overview#signal-support)。

## 與程式碼設定的優先順序 {/* #precedence-with-code */}

以程式碼註冊的 Observability 優先於 `observability.ts`。當整個專案使用一份設定即可時，請使用 `observability.ts`；若設定取決於 `src/mastra/index.ts` 中的執行階段接線，請改用程式碼註冊。
