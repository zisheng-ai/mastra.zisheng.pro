# Logger

Mastra 會透過 `src/mastra/` 正下方的 `logger.ts` 檔案設定專案的 [logger](/docs/observability/logging)。此檔案會 default export 一個 logger，取代 Agent、Workflow 與其他元件共用的內建 `ConsoleLogger`。

本頁說明檔案式慣例。若要了解記錄層級、transport 與 Provider 詳細資訊，請參閱 [logging](/docs/observability/logging)。

## 快速開始

建立 `src/mastra/logger.ts`，並 default export 一個 logger，例如 [`PinoLogger`](/reference/logging/pino-logger)：

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 會先註冊 logger，再註冊 Storage、Observability 與檔案式 Agent，因此這些 primitive 在接線過程中都會透過此 logger 記錄訊息。

## 與程式碼設定的優先順序

以程式碼註冊的 logging 優先於 `logger.ts`。如果你在 `src/mastra/index.ts` 中將 `logger` 傳給 `new Mastra({ logger })`（或設定 `logger: false` 停用 logging），系統會忽略 `logger.ts` 並顯示警告。當整個專案使用一個 logger 即可時，請使用 `logger.ts`；若設定取決於執行階段接線，請改用程式碼註冊。
