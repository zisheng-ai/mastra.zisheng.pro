# Agent.streamLegacy()（舊版）

:::warning

**已棄用**：此方法已棄用，且僅適用於 V1 模型。V2 模型請改用新的 [`.stream()`](./stream) 方法。升級詳情請參閱[遷移指南](/guides/migrations/vnext-to-standard-apis)。

:::

`.streamLegacy()` 方法是舊版 Agent 串流 API，用於即時串流 V1 模型 Agent 的回應。此方法接受訊息與選用串流選項。

## 使用範例 {/* #usage-example */}

```typescript
await agent.streamLegacy('message for agent')
```

## 遷移至新 API {/* #migration-to-new-api */}

:::info

新的 `.stream()` 方法提供更多功能，包含 AI SDK v5+ 相容性、更完善的結構化輸出處理，以及改良的回呼系統。詳細遷移指示請參閱[遷移指南](/guides/migrations/vnext-to-standard-apis)。

:::

### 快速遷移範例 {/* #quick-migration-example */}

#### 遷移前（舊版） {/* #before-legacy */}

```typescript
const result = await agent.streamLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```

#### 遷移後（新 API） {/* #after-new-api */}

```typescript
const result = await agent.stream('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```
