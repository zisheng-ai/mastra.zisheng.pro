# Run.resumeStream()

`.resumeStream()` 方法會使用新資料恢復已暫停的 Workflow 執行，讓你能從特定步驟繼續執行並觀察事件串流。

## 使用範例

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

const result = await stream.result

if (result!.status === 'suspended') {
  const resumedStream = await run.resumeStream({
    resumeData: {
      value: 'resume data',
    },
  })
}
```

## 串流事件

串流會在 Workflow 執行期間輸出各種事件類型。每個事件都有 `type` 欄位，以及包含相關資料的 `payload`：

- **`workflow-start`**：Workflow 開始執行
- **`workflow-step-start`**：步驟開始執行
- **`workflow-step-output`**：步驟的自訂輸出
- **`workflow-step-result`**：步驟執行完成並產生結果
- **`workflow-finish`**：Workflow 執行完成，並提供用量統計資料。若執行成功，`payload.finalWorkflowResult` 會包含 Workflow 的最終結果
