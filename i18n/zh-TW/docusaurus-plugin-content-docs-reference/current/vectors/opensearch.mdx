# OpenSearch 向量儲存

OpenSearchVector 類別使用開放原始碼搜尋與分析引擎 [OpenSearch](https://opensearch.org/) 提供向量搜尋。它使用 OpenSearch 的 k-NN 功能執行向量相似度搜尋。

## 建構函式選項

建構函式接受所有 [OpenSearch ClientOptions](https://opensearch.org/docs/latest/clients/javascript/index/)，以及必要的 `id` 欄位。

## 方法

### `createIndex()`

使用指定的設定建立新索引。

<PropertiesTable
  content={[
  {
    name: 'indexName',
    type: 'string',
    description: '要建立的索引名稱',
  },
  {
    name: 'dimension',
    type: 'number',
    description: '要儲存在索引中的向量維度',
  },
  {
    name: 'metric',
    type: "'cosine' | 'euclidean' | 'dotproduct'",
    description: '向量相似度使用的距離度量',
    defaultValue: "'cosine'",
    isOptional: true,
  },
]}
/>

### `listIndexes()`

列出 OpenSearch 執行個體中的所有索引。

傳回：`Promise<string[]>`

### `updateVector()`

依 ID 或中繼資料篩選條件更新單一向量。必須提供 `id` 或 `filter` 其中一項，但不能同時提供兩者。
