# FirecrawlBrowser 類別

`FirecrawlBrowser` 類別提供以 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 為基礎的瀏覽器自動化功能。它會透過 Firecrawl API 佈建遠端瀏覽器 session，並使用 Chrome DevTools Protocol（CDP）連線。

`FirecrawlBrowser` 擴充 [`AgentBrowser`](/reference/browser/agent-browser)，並公開相同的確定性 Tool 集合。需要託管的瀏覽器 session，而不想在本機安裝 Chromium 時，請使用此類別。本機自動化請參閱 [`AgentBrowser`](/reference/browser/agent-browser)。若要使用自然語言進行 AI 驅動的互動，請參閱 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Session 生命週期 {/* #session-lifecycle */}

Session 佈建取決於繼承自 `AgentBrowser` 的 `scope` 選項：

- `'thread'`（預設）：每個對話 thread 都有自己的 Firecrawl Sandbox session，會在首次使用時建立，並在執行緒的瀏覽器 session 銷毀時刪除。
- `'shared'`：瀏覽器啟動時建立一個 Firecrawl Sandbox session，供所有 thread 共用。瀏覽器關閉時會刪除該 session。

無論使用何者，瀏覽器關閉時 `FirecrawlBrowser` 都會刪除遠端 Firecrawl session，包括 session 建立或連線途中失敗的情況。

## Tool {/* #tools */}

`FirecrawlBrowser` 提供與 `AgentBrowser` 相同的 Tool 集合，包括 `browser_goto`、`browser_snapshot`、`browser_click`、`browser_type` 與 `browser_screenshot`。完整清單與 Tool 參數請參閱 [`AgentBrowser` Tool 參考文件](/reference/browser/agent-browser)。
