# SerializedMemoryConfig

`SerializedMemoryConfig` 是 [`Memory`](/reference/memory/memory-class) 設定中可序列化為 JSON、存在已儲存 Agent 記錄上的子集。執行階段會針對已設定的 `Mastra` 執行個體解析 vector 與 embedder ID，將其還原為 `Memory` 執行個體。

這是 [`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 與 `EditorAgentNamespace.create({ memory })` 使用的型別。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
