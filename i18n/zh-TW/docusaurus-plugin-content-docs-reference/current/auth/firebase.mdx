# MastraAuthFirebase 類別

`MastraAuthFirebase` 類別使用 Firebase Authentication 為 Mastra 提供身分驗證。它會使用 Firebase ID token 驗證傳入要求，並透過 `auth` 選項與 Mastra 伺服器整合。

## 使用範例 {/* #usage-examples */}

### 搭配環境變數的基本用法 {/* #basic-usage-with-environment-variables */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

// Automatically uses FIREBASE_SERVICE_ACCOUNT and FIRESTORE_DATABASE_ID env vars
export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase(),
  },
})
```

### 自訂設定 {/* #custom-configuration */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthFirebase } from '@mastra/auth-firebase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthFirebase({
      serviceAccount: '/path/to/service-account-key.json',
      databaseId: 'your-database-id',
    }),
  },
})
```

## 預設授權行為 {/* #default-authorization-behavior */}

`MastraAuthFirebase` 預設使用 Firestore 管理使用者存取權：

1. Firebase ID token 驗證成功後，會呼叫 `authorizeUser` method
1. 它會檢查 `user_access` collection 中是否存在以使用者 UID 為 document ID 的 document
1. 如果 document 存在，使用者即獲授權；否則會拒絕存取
1. 所使用的 Firestore 資料庫取決於 `databaseId` 參數或環境變數

## Firebase 使用者型別 {/* #firebase-user-type */}

`authorizeUser` 函式所使用的 `FirebaseUser` 型別對應至 Firebase 的 `DecodedIdToken` interface，其中包含：

- `uid`：使用者的唯一識別碼
- `email`：使用者的電子郵件地址（若有）
- `email_verified`：電子郵件是否已驗證
- `name`：使用者的顯示名稱（若有）
- `picture`：使用者個人資料圖片的 URL（若有）
- `auth_time`：使用者進行身分驗證的時間
- 其他標準 JWT claim
