# rerank()

`rerank()` 函式結合語意相關性、向量相似度與位置分數，為向量搜尋結果提供進階重新排序功能。

```typescript
function rerank(
  results: QueryResult[],
  query: string,
  modelConfig: ModelConfig,
  options?: RerankerFunctionOptions,
): Promise<RerankResult[]>
```

## 使用範例

```typescript
import { rerank } from '@mastra/rag'

const model = '__GATEWAY_OPENAI_MODEL__'

const rerankedResults = await rerank(vectorSearchResults, 'How do I deploy to production?', model, {
  weights: {
    semantic: 0.5,
    vector: 0.3,
    position: 0.2,
  },
  topK: 3,
})
```

rerank 函式接受 Vercel AI SDK 中的任何 LanguageModel。使用 Cohere 模型 `rerank-v3.5` 時，會自動使用 Cohere 的重新排序功能。

:::note

若要讓語意評分在重新排序期間正常運作，每個結果都必須在 `metadata.text` 欄位中包含文字內容。

:::
