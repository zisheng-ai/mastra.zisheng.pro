# DatabaseConfig

使用向量查詢 Tool 時，`DatabaseConfig` 類型可讓你指定資料庫專屬設定。透過這些設定，你可以運用不同向量儲存區提供的功能與最佳化選項。

## 類型定義 {/* #type-definition */}

```typescript
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  turbopuffer?: TurbopufferConfig
  [key: string]: any // Extensible for future databases
}
```

## 資料庫專屬類型 {/* #database-specific-types */}

### `PgVectorConfig` {/* #pgvectorconfig */}

安裝 pgvector 擴充功能的 PostgreSQL 專用設定選項。

<PropertiesTable

    type: 'number',

    isOptional: true,

  {

      'HNSW 搜尋參數，用來控制搜尋期間動態候選清單的大小。較高的值會以速度為代價提升準確度。通常設在 topK 到 200 之間。',
    isOptional: true,
  },
  {
    name: 'probes',
    type: 'number',
    description: 'IVFFlat probe 參數，用來指定搜尋期間要造訪的索引儲存格數量。較高的值會以速度為代價提升召回率。',
    isOptional: true,
  },
]}
/>

**效能準則：**

- **ef**：以 topK 值的 2–4 倍為起點，若要提高準確度再增加
- **probes**：以 1–10 為起點，若要提高召回率再增加
- **minScore**：依品質需求使用 0.5–0.9 之間的值

**使用情境：**

- 為高負載情境進行效能最佳化
- 透過品質篩選移除不相關的結果
- 微調搜尋準確度與速度之間的取捨

    ### 覆寫執行階段設定 {/* #runtime-configuration-override */}

    ```typescript
    import { RequestContext } from '@mastra/core/request-context'

    // Initial configuration
    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'pinecone',
      indexName: 'documents',
      model: embedModel,
      databaseConfig: {
        pinecone: {
          namespace: 'development',
        },
      },
    })

    // Override at runtime
    const requestContext = new RequestContext()
    requestContext.set('databaseConfig', {
      pinecone: {
        namespace: 'production',
      },
    })

    await vectorTool.execute({ queryText: 'search query' }, { mastra, requestContext })
    ```
  </TabItem>

  <TabItem value="multi-database" label="多資料庫">
    ### 多資料庫設定 {/* #multi-database-configuration */}

    ```typescript
    const vectorTool = createVectorQueryTool({
      vectorStoreName: 'dynamic', // Will be determined at runtime
      indexName: 'documents',
      model: embedModel,
      databaseConfig: {
        pinecone: {
          namespace: 'default',
        },
        pgvector: {
          minScore: 0.8,
          ef: 150,
        },
        chroma: {
          where: { type: 'documentation' },
        },
      },
    })
    ```

    :::note

    **多資料庫支援**：設定多個資料庫時，只會套用符合實際所用向量儲存區的設定。

    :::

      indexName: 'embeddings',

## 擴充性 {/* #extensibility */}

`DatabaseConfig` 類型的設計具有可擴充性。若要新增對其他向量資料庫的支援：

```typescript
// 1. Define the configuration interface
export interface NewDatabaseConfig {
  customParam1?: string
  customParam2?: number
}

// 2. Extend DatabaseConfig type
export type DatabaseConfig = {
  pinecone?: PineconeConfig
  pgvector?: PgVectorConfig
  chroma?: ChromaConfig
  newdatabase?: NewDatabaseConfig
  [key: string]: any
}

// 3. Use in vector query tool
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'newdatabase',
  indexName: 'documents',
  model: embedModel,
  databaseConfig: {
    newdatabase: {
      customParam1: 'value',
      customParam2: 42,
    },
  },
})
```

## 最佳實務 {/* #best-practices */}

1. **環境設定**：不同環境使用不同的 namespace 或設定
1. **效能調校**：從預設值開始，再依具體需求調整
1. **品質篩選**：使用 minScore 排除低品質結果
1. **執行階段彈性**：針對執行階段定義的情境，在執行階段覆寫設定
1. **文件**：記錄具體設定選擇，供團隊成員參考

## 移轉指南 {/* #migration-guide */}

現有的向量查詢 Tool 無須變更即可繼續運作。若要新增資料庫設定：

```diff
const vectorTool = createVectorQueryTool({
  vectorStoreName: 'pinecone',
  indexName: 'documents',
  model: embedModel,
+ databaseConfig: {
+   pinecone: {
+     namespace: 'production'
+   }
+ }
});
```
