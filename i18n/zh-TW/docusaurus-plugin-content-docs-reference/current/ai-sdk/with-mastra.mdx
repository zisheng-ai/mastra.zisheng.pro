# withMastra()

使用 Mastra 處理器及／或記憶體包裝 AI SDK 模型。

## 使用範例 {/* #usage-example */}

```typescript title="src/example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import type { Processor } from '@mastra/core/processors'

const loggingProcessor: Processor<'logger'> = {
  id: 'logger',
  async processInput({ messages }) {
    console.log('Input:', messages.length, 'messages')
    return messages
  },
}

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [loggingProcessor],
})

const { text } = await generateText({
  model,
  prompt: 'What is 2 + 2?',
})
```

## 傳回值 {/* #returns */}

傳回經過包裝的模型，可與 `generateText`、`streamText`、`generateObject` 及 `streamObject` 搭配使用。

## 串流行為 {/* #streaming-behavior */}

實作 `processOutputResult` 的輸出處理器會在串流結束後執行。請完整消耗串流，以保存訊息記錄與語意回想資料。
