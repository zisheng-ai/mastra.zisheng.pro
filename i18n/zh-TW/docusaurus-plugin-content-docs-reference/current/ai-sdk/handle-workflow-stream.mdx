# handleWorkflowStream()

這是與框架無關的處理器，可用於以 AI SDK 相容格式串流 Workflow 執行作業。當你需要在 Hono 或 Mastra 本身的 [apiRoutes](/docs/server/custom-api-routes) 功能之外處理 Workflow 串流時，請直接使用此函式。

`handleWorkflowStream()` 會傳回 `ReadableStream`，你可以使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其包裝。

`handleWorkflowStream()` 會保留現有的 AI SDK v5／預設行為。如果你的應用程式使用 AI SDK v6 型別，請傳入 `version: 'v6'`。

如果想在 Mastra 伺服器內建立 Workflow 路由，請使用 [`workflowRoute()`](/reference/ai-sdk/workflow-route)。

:::tip Workflow 中的 Agent 串流

當 Workflow 步驟將 Agent 的串流管線傳送至 Workflow 寫入器（例如 `await response.fullStream.pipeTo(writer)`）時，即使 Agent 在 Workflow 步驟內執行，其文字區塊與 Tool 呼叫也會即時轉送至 UI 串流。

詳情請參閱 [Workflow 串流](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用範例 {/* #usage-example */}

Next.js App Router 範例：

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
