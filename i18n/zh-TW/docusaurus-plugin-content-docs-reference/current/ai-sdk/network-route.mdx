# networkRoute()

:::warning[已棄用]

Agent 網路已棄用，並將在未來版本中移除。請改用[監督 Agent](/docs/capabilities/subagents) 搭配 `agent.stream()` 或 `agent.generate()`。請參閱[遷移指南](/guides/migrations/network-to-supervisor)進行升級。

:::

建立網路路由處理器，使用 AI SDK 格式串流網路執行作業。此函式會註冊一個 HTTP `POST` 端點，用來接收訊息、執行 Agent 網路，並以 AI SDK 相容格式將回應串流傳回使用者端。Agent 網路可讓路由 Agent 將任務委派給其他 Agent。你必須在[自訂 API 路由](/docs/server/custom-api-routes)中使用此函式。

如果需要與框架無關的處理器，請使用 [`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream)。

`networkRoute()` 會保留現有的 AI SDK v5／預設行為。如果你的應用程式使用 AI SDK v6 型別，請傳入 `version: 'v6'`。

## 使用範例 {/* #usage-example */}

以下範例說明如何在 `/network` 端點設定網路路由，並使用 ID 為 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

你也可以根據 `agentId` 使用執行階段定義的 Agent 路由。URL `/network/weatherAgent` 會解析為 ID 是 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 其他設定 {/* #additional-configuration */}

你可以使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自訂傳送至網路路由的請求，例如將其他設定傳遞給 Agent：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
