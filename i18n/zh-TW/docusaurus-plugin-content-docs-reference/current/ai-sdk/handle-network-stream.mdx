# handleNetworkStream()

:::warning[已棄用]

Agent 網路已棄用，並將在未來版本中移除。請改用[監督 Agent](/docs/capabilities/subagents) 搭配 `agent.stream()` 或 `agent.generate()`。請參閱[遷移指南](/guides/migrations/network-to-supervisor)進行升級。

:::

這是與框架無關的處理器，可用於以 AI SDK 相容格式串流網路執行作業。當你需要在 Hono 或 Mastra 本身的 [apiRoutes](/docs/server/custom-api-routes) 功能之外處理網路串流時，請直接使用此函式。

`handleNetworkStream()` 會傳回 `ReadableStream`，你可以使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其包裝。

`handleNetworkStream()` 會保留現有的 AI SDK v5／預設行為。如果你的應用程式使用 AI SDK v6 型別，請傳入 `version: 'v6'`。

如果想在 Mastra 伺服器內建立網路路由，請使用 [`networkRoute()`](/reference/ai-sdk/network-route)。

## 使用範例 {/* #usage-example */}

Next.js App Router 範例：

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
