# Perplexity Tools

`@mastra/perplexity` 套件會將 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 包裝為相容於 Mastra 的 Tool。它提供一個 factory function，回傳以 [`createTool()`](./create-tool) 建立的 Tool，並包含完整的 Zod 輸入／輸出 schema。

若要使用由 Perplexity 驅動的 chat completion 或 Agent 式 Workflow，請使用 Mastra 內建的 [Perplexity 模型 Provider](/models/providers/perplexity) 或 [Perplexity Agent Provider](/models/providers/perplexity-agent)。這些 Provider 與此 Search Tool 各自獨立。

## 安裝 {/* #installation */}

安裝此套件與 Zod：

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 使用範例 {/* #usage-example */}

下列範例會使用預設設定建立搜尋 Tool。根據預設，此 Tool 會從環境中讀取 `PERPLEXITY_API_KEY`（若無則使用 `PPLX_API_KEY`）。明確傳入 `{ apiKey }` 即可覆寫此值。

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

若要明確傳入 API key：

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 方法 {/* #methods */}

### 工廠函式 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

回傳一個包含所有 Perplexity Tool 的物件，這些 Tool 會共用傳入的設定。

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

回傳值：`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

建立一個使用 Perplexity Search API 搜尋網路的 Tool。它會回傳經過排序的結果，其中包含標題、URL、摘要與選填的發布日期。

此 Tool 會以 ID `perplexity-search` 註冊。

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent 範例 {/* #agent-example */}

下列範例會在 Agent 上註冊搜尋 Tool，讓它在回答前取得最新的網頁結果。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 環境變數 {/* #environment-variables */}

| 變數 | 說明 |
| - | - |
| `PERPLEXITY_API_KEY` | 你的 Perplexity API key。若未將 `apiKey` 傳給 factory function，則預設使用此值。 |
| `PPLX_API_KEY` | 未設定 `PERPLEXITY_API_KEY` 時使用的備援值。 |
