# dataset.startExperimentAsync()

**新增於：** `@mastra/core@1.4.0`

非同步啟動實驗（觸發後即傳回）。立即傳回實驗 ID 和 `'pending'` 狀態，實驗將在背景執行。

## 使用範例

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
console.log(`Current status: ${experiment.status}`)
```

## 參數

接受與 [`dataset.startExperiment()`](/reference/datasets/startExperiment) 相同的 `StartExperimentConfig`。

當 `persistence.experiments` 設為 `'none'` 時，`startExperimentAsync()` 不會持久儲存實驗記錄、進度更新或項目結果。分數持久儲存仍由 `persistence.scores` 單獨控制。如果沒有實驗事件觀察器，本次執行將觸發後即傳回，實驗 API 無法報告執行是已完成還是失敗。

如果呼叫方需要傳回的摘要，請使用同步的 [`startExperiment()`](/reference/datasets/startExperiment)。實驗事件觀察器可以接收生命週期事件和最終摘要。
