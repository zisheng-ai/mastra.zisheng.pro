# Workflow\.branch()

`.branch()` 方法會在 Workflow 步驟之間建立條件分支，讓系統能依據前一個步驟的結果採取不同路徑。

## 使用範例

```typescript
workflow.branch([
  [async ({ context }) => true, step1],
  [async ({ context }) => false, step2],
])
```
