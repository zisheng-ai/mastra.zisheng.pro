# Workflow\.dowhile()

`.dowhile()` 方法會在符合條件期間重複執行步驟。它一律會先執行步驟至少一次，再評估條件。第一次評估條件時，`iterationCount` 為 `1`。

## 使用範例

```typescript
workflow.dowhile(step1, async ({ inputData }) => true)
```
