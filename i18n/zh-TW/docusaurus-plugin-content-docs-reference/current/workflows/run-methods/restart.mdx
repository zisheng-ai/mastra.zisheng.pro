# Run.restart()

`.restart()` 方法會重新啟動與伺服器失去連線的作用中 Workflow run，讓你從失去連線的時間點（最後一個作用中步驟）繼續執行。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const result = await run.start({ inputData: { value: 'initial data' } })

const restartedResult = await run.restart()
```
