# Run.start()

`.start()` 方法會使用輸入資料啟動 Workflow run，讓你從頭開始執行 Workflow。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const result = await run.start({
  inputData: {
    value: 'initial data',
  },
})
```

## 延伸使用範例 {/* #extended-usage-example */}

```typescript
import { RequestContext } from '@mastra/core/request-context'

const run = await workflow.createRun()

const requestContext = new RequestContext()
requestContext.set('variable', false)

const result = await run.start({
  inputData: {
    value: 'initial data',
  },
  requestContext,
})
```
