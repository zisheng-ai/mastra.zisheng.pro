# Run.resume()

`.resume()` 方法會使用新資料繼續已暫停的 Workflow run，讓你能從特定步驟繼續執行。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const result = await run.start({ inputData: { value: 'initial data' } })

if (result.status === 'suspended') {
  const resumedResults = await run.resume({
    resumeData: { value: 'resume data' },
  })
}
```

## 延伸使用範例 {/* #extended-usage-example */}

```typescript
if (result.status === 'suspended') {
  const resumedResults = await run.resume({
    step: result.suspended[0],
    resumeData: { value: 'resume data' },
  })
}
```

:::note

只有一個步驟暫停時，可以省略 `step` 參數，Workflow 會自動繼續該步驟。若 Workflow 中有多個已暫停步驟，則必須明確指定要繼續的步驟。

:::

### 繼續單次 [`.foreach()`](../workflow-methods/foreach) 迭代 {/* #resuming-a-single-foreach-iteration */}

當 [`.foreach()`](../workflow-methods/foreach) 步驟在多個迭代中暫停時，請使用 `forEachIndex`（零起始）逐一以不同的 `resumeData` 繼續迭代。未由 `forEachIndex` 指定的迭代會維持暫停，直到之後繼續。

```typescript
// Resume only the second iteration (index 1) with its own data
await run.resume({
  step: 'approve',
  resumeData: { ok: true },
  forEachIndex: 1,
})

// Later, resume the first iteration with different data
await run.resume({
  step: 'approve',
  resumeData: { ok: false },
  forEachIndex: 0,
})
```

若省略 `forEachIndex`，步驟中所有已暫停的迭代都會使用相同的 `resumeData` 繼續。
