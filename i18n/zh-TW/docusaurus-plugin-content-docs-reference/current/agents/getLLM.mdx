# Agent.getLLM()

`.getLLM()` 方法會取得為 Agent 設定的語言模型執行個體；若設定為函式，也會解析函式。您也可以傳入限定於 request 範圍的 `model` 覆寫值，而不會變更 Agent 已設定的模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
