# Agent.listWorkflows()

`.listWorkflows()` 方法會取得為 Agent 設定的 Workflow；若設定為函式，也會解析函式。這些 Workflow 讓 Agent 能依照已定義的執行路徑，執行複雜的多步驟流程。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
