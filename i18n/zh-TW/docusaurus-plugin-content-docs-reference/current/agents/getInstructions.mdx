# Agent.getInstructions()

`.getInstructions()` 方法會取得為 Agent 設定的指示；若指示為函式，也會解析函式。這些指示會引導 Agent 的行為，並定義其能力與限制。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
