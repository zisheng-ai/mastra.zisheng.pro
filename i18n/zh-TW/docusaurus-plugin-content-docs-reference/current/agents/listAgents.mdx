# Agent.listAgents()

`.listAgents()` 方法會取得為 Agent 設定的子 Agent；若設定為函式，也會解析函式。這些子 Agent 讓 Agent 能夠存取其他 Agent 並執行複雜動作。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
