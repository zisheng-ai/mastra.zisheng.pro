# Agent.listScorers()

`.listScorers()` 方法會取得為 Agent 設定的評分設定；若設定為函式，也會解析函式。此方法可存取用來評估 Agent 回應與效能的評分系統。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
