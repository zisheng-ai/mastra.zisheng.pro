# Agent.getDescription()

`.getDescription()` 方法會取得為 Agent 設定的說明。此方法會回傳字串，用來描述 Agent 的用途與能力。

## 使用範例

```typescript
agent.getDescription()
```

## 參數

此方法不接受任何參數。
