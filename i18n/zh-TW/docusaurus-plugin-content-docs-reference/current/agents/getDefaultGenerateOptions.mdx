# Agent.getDefaultGenerateOptionsLegacy()

:::warning

**已棄用**：此方法已棄用，且僅適用於 V1 模型。若使用 V2 模型，請改用新的 [`.getDefaultOptions()`](./getDefaultOptions) 方法。

:::

您可以為 Agent 設定預設生成選項，以控制模型行為、輸出格式，以及 Tool 與 Workflow 呼叫。`.getDefaultGenerateOptionsLegacy()` 方法會取得這些預設值；若值為函式，也會解析函式。除非另行覆寫，這些選項會套用至所有 `generateLegacy()` 呼叫，並可用來檢視事先不確定的 Agent 預設值。

## 使用範例

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
