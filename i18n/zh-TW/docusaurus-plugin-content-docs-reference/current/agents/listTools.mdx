# Agent.listTools()

`.listTools()` 方法會取得為 Agent 設定的 Tool；若設定為函式，也會解析函式。這些 Tool 可擴充 Agent 的能力，讓它執行特定動作或存取外部系統。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listTools()
```
