# Agent.getDefaultStreamOptionsLegacy()

:::warning

**已棄用**：此方法已棄用，且僅適用於 V1 模型。若使用 V2 模型，請改用新的 [`.getDefaultOptions()`](./getDefaultOptions) 方法。

:::

您可以為 Agent 設定記憶體使用方式與輸出格式的預設串流選項，也可以設定反覆運算步驟。`.getDefaultStreamOptionsLegacy()` 方法會回傳這些預設值；若值為函式，也會解析函式。除非另行覆寫，這些選項會套用至所有 `streamLegacy()` 呼叫，並可用來檢視事先不確定的 Agent 預設值。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
