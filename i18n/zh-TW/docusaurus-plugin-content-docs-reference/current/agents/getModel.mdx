# Agent.getModel()

`.getModel()` 方法會取得為 Agent 設定的語言模型；若設定為函式，也會解析函式。此方法用於存取支援 Agent 各項能力的底層模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getModel()
```
