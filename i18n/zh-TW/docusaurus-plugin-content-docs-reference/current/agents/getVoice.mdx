# Agent.getVoice()

`.getVoice()` 方法會取得為 Agent 設定的語音 Provider；若設定為函式，也會解析函式。此方法用於存取 Agent 的文字轉語音與語音轉文字能力。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
