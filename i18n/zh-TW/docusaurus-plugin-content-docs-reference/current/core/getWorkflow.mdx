# Mastra.getWorkflow()

`.getWorkflow()` 方法用於依註冊鍵取得 Workflow。此方法為 Workflow 輸入和輸出 schema 提供完整的 TypeScript 類型推斷。

## 使用範例

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 類型推斷

為了獲得最佳 TypeScript 支援，請將 Workflow 的**註冊鍵**（將 Workflow 新增到 Mastra 時使用的鍵）傳給 `getWorkflow()`。這樣可對以下內容進行完整的類型推斷：

- 輸入資料 schema
- 輸出資料 schema
- 步驟結果

如果需要依 Workflow 的 `id` 屬性而非註冊鍵取得，可以使用 `getWorkflowById()`，但請注意類型推斷不會同樣精確。
