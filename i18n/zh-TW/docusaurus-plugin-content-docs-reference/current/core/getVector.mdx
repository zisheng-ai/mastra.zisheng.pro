# Mastra.getVector()

`.getVector()` 方法用於依名稱取得 vector store。此方法接受一個 `string` 參數，用於指定 vector store 名稱。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```
