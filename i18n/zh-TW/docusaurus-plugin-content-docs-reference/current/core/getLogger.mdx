# Mastra.getLogger()

`.getLogger()` 方法用於取得 Mastra 執行個體中已設定的 Logger 執行個體。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
