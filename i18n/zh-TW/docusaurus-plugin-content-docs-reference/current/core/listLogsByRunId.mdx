# Mastra.listLogsByRunId()

`.listLogsByRunId()` 方法用於取得指定 run ID 和 transport ID 的日誌。此方法要求設定支援 `listLogsByRunId` 操作的 Logger。

## 使用範例

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
