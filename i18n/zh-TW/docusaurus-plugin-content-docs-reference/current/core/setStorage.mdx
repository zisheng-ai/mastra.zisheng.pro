# Mastra.setStorage()

`.setStorage()` 方法用於設定 Mastra 執行個體的 Storage 執行個體。此方法接受一個 `MastraCompositeStore` 參數。

## 使用範例

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
