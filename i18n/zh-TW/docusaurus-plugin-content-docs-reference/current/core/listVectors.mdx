# Mastra.listVectors()

`.listVectors()` 方法用於取得 Mastra 執行個體中已設定的所有 vector store。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
