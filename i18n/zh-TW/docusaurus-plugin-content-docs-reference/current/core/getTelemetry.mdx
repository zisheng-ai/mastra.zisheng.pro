# Mastra.getTelemetry()

`.getTelemetry()` 方法用於取得 Mastra 執行個體中已設定的 Telemetry 執行個體。

## 使用範例

```typescript
mastra.getTelemetry()
```

## 參數

此方法不接受任何參數。
