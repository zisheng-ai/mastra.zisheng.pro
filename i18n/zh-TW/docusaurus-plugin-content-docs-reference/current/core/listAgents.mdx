# Mastra.listAgents()

`.listAgents()` 方法用於取得 Mastra 執行個體中已設定的所有 Agent。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listAgents()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
