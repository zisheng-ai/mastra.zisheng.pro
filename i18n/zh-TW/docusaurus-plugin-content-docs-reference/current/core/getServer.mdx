# Mastra.getServer()

`.getServer()` 方法用於取得 Mastra 執行個體中已設定的 server 設定。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
