# Mastra.removeWorkspace()

`.removeWorkspace()` 方法從 Mastra 執行階段 registry 中移除 Workspace。傳入 `{ destroy: true }` 可在移除前銷毀 Workspace。

## 使用範例

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 傳回值

<PropertiesTable
  content={[
  {
    name: 'removed',

  },
]}

當 `destroy` 為 `true` 且 `workspace.destroy()` 擲回錯誤時，此呼叫會以該錯誤拒絕，Workspace 仍保持註冊狀態，以便呼叫方重試清理。
