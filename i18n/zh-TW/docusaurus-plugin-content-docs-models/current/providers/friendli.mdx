透過 Mastra 的模型路由器存取 5 個 Friendli 模型。系統會自動使用 `FRIENDLI_TOKEN` 環境變數完成身分驗證。

如需進一步了解，請參閱[Friendli 文件](https://friendli.ai/docs/guides/serverless_endpoints/introduction)。

```bash title=".env"
FRIENDLI_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "friendli/MiniMaxAI/MiniMax-M2.5"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` endpoint。部分 Provider 特有功能可能無法使用，詳情請參閱[Friendli 文件](https://friendli.ai/docs/guides/serverless_endpoints/introduction)。

:::

const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "friendli/zai-org/GLM-5.2"
      : "friendli/MiniMaxAI/MiniMax-M2.5";
  }
});
