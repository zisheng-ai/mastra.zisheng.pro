# <img src="https://models.dev/logos/poolside.svg" alt="Poolside 標誌" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Poolside

透過 Mastra 的模型路由器存取 3 個 Poolside 模型。系統會自動使用 `POOLSIDE_API_KEY` 環境變數完成身分驗證。

如需進一步了解，請參閱[Poolside 文件](https://platform.poolside.ai)。

```bash title=".env"
POOLSIDE_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "poolside/poolside/laguna-m.1"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` endpoint。部分 Provider 特有功能可能無法使用，詳情請參閱[Poolside 文件](https://platform.poolside.ai)。

:::

const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "poolside/poolside/laguna-xs-2.1"
      : "poolside/poolside/laguna-m.1";
  }
});
