# <img src="https://models.dev/logos/meta.svg" alt="Meta 標誌" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Meta

透過 Mastra 的模型路由器存取 3 個 Meta 模型。系統會自動使用 `META_MODEL_API_KEY` 環境變數完成身分驗證。

如需進一步了解，請參閱[Meta 文件](https://dev.meta.ai/docs)。

```bash title=".env"
META_MODEL_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "meta/muse-spark-1.1"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` endpoint。部分 Provider 特有功能可能無法使用，詳情請參閱[Meta 文件](https://dev.meta.ai/docs)。

:::

## 進階設定

### 自訂標頭

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://api.meta.ai/v1",
    id: "meta/muse-spark-1.1",
    apiKey: process.env.META_MODEL_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動態選擇模型

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "meta/muse-spark-1.2-contributor"
      : "meta/muse-spark-1.1";
  }
});
```
