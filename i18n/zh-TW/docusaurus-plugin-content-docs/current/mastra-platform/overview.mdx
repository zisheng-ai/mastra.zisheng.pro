# Mastra platform

[Mastra platform](https://projects.mastra.ai) 提供三項產品，用於部署、監控及管理以 Mastra framework 建構的 AI 應用程式：

- [**Observability**](/docs/mastra-platform/observability)：每個 platform 專案的基礎產品，可搜尋各 Mastra 專案與部署的 Trace、日誌和指標
- [**Studio**](/docs/mastra-platform/studio)：用來測試 Agent、執行 Workflow 及檢查 Trace 的託管視覺化環境。從 Studio 開始也會取得 Observability。
- [**Server**](/docs/mastra-platform/server)：以 API 伺服器形式執行 Mastra 應用程式的正式環境部署目標。從 Server 開始也會取得 Observability。

你可以使用單一指令 [`mastra deploy`](/docs/mastra-platform/deploy) 部署，或連結 GitHub 儲存庫以在推送時部署。儲存庫連結流程請參閱 [GitHub 整合](/docs/mastra-platform/github)。

每個專案都能執行多個 [**Environments**](/docs/mastra-platform/environments)（例如 `production` 與 `staging`）、從 CLI 或專案設定佈建[**託管資料庫**](/docs/mastra-platform/database)以保存應用程式資料，並為每個環境取得受管理的 [**Workspaces**](/docs/mastra-platform/workspaces)，無須手動設定即可為 Agent 提供檔案系統與 Sandbox。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 會從 Agent Trace 中找出重複出現的目標、結果、行為與情緒。Trace Intelligence 目前對獲選專案提供私人測試。

## 開始使用

依照你的目標選擇合適路徑：

- **新增託管 Observability**：使用 [Observability](/docs/mastra-platform/observability) 收集可搜尋的 Trace、日誌與指標。若你想先監控、暫不部署 Studio 或 Server，請從這裡開始。
- **部署 Studio**：使用 [Studio](/docs/mastra-platform/studio) 為團隊託管視覺化開發環境。若需要共用 UI 來測試 Agent、執行 Workflow 及檢查 Trace，請從這裡開始。
- **部署 Server**：使用 [Server](/docs/mastra-platform/server) 將 Mastra 應用程式當成正式環境 API 伺服器執行。準備好從雲端提供 Agent、Tool 與 Workflow 時，請從這裡開始。

## 核心概念

**Projects** 是所有產品共用的上層實體。單一專案可包含 Observability、Studio 與 Server 等所有產品。專案隸屬於 **Organization**，也就是你團隊的多租戶容器。

Mastra 應用程式由三種基本元件構成：

- [Agents](/docs/agents/overview)：可使用 Tool、遵循指示並維持上下文的 AI Agent
- [Tools](/docs/agents/using-tools)：Agent 可呼叫的函式與整合
- [Workflows](/docs/workflows/overview)：協調 Agent 與 Tool 的多步驟編排管線

## 上線至正式環境

使用 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本機開發專案，並開啟 [Studio](/docs/studio/overview)，在視覺化環境中測試 Agent、Workflow 與 Tool。

準備好將應用程式部署至正式環境時，執行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy) 將應用程式推送至雲端。

請依照 [Deploy](/docs/mastra-platform/deploy) 文件中的逐步說明操作。

若在自己的基礎架構上託管 Mastra 應用程式，仍可使用 [MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform) 將 Observability 資料傳送至 Mastra platform。
