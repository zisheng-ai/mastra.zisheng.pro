# Discord

Discord 頻道可讓 Mastra Agent 接收 Discord 互動與機器人訊息。Mastra 會處理 Agent 串接與 webhook 路由；Chat SDK Discord adapter 文件則涵蓋 Discord 應用程式設定、機器人權限與 Gateway 行為。

## 安裝 adapter

從 Chat SDK 安裝 Discord adapter：

```bash npm2yarn
npm install @chat-adapter/discord
```

## Agent 設定

將 `createDiscordAdapter()` 加入 Agent 的 `channels.adapters` 物件：

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createDiscordAdapter } from '@chat-adapter/discord'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord Agent',
  instructions: 'Answer questions and help with tasks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      discord: createDiscordAdapter(),
    },
  },
})
```

在 Mastra instance 上註冊 Agent：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { discordAgent } from './agents/discord-agent'

export const mastra = new Mastra({
  agents: { discordAgent },
})
```

## Adapter 設定

請依照 [Chat SDK Discord adapter 文件](https://chat-sdk.dev/adapters/official/discord)完成 Discord 專屬設定，包括建立應用程式、機器人 token、互動端點、權限與 Gateway 行為。

Adapter 會從下列環境變數讀取 Discord 憑證：

```bash title=".env"
DISCORD_BOT_TOKEN=your-discord-bot-token
DISCORD_PUBLIC_KEY=your-discord-application-public-key
DISCORD_APPLICATION_ID=your-discord-application-id
```

## Webhook URL

Mastra 會根據 Agent ID 與 adapter key 產生 Discord webhook 路由：

```text
/api/agents/discord-agent/channels/discord/webhook
```

使用公開 Mastra 伺服器 URL 作為基底 URL：

```text
https://your-app.example.com/api/agents/discord-agent/channels/discord/webhook
```

當 Discord adapter 文件要求填入互動端點或 webhook URL 時，請使用此 URL。Discord 的一般訊息事件可能需要在產生的 webhook 路由之外設定 Gateway；請依照 Chat SDK adapter 文件完成這部分。
