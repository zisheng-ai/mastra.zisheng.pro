# 更多平台

Mastra 頻道使用 Chat SDK adapter，因此本節頁面並未列出所有支援的平台。只要 Chat SDK 平台 adapter 匯出的 adapter factory 與 `channels.adapters` 相容，即可使用。

## Adapter 目錄

[Chat SDK adapter 目錄](https://chat-sdk.dev/adapters)是查詢可用 adapter 的標準來源。以下清單僅為某個時間點的快照，不一定隨時都是最新內容。

本文撰寫時，Chat SDK 列出的 adapter 包括：

- AgentPhone
- Baileys WhatsApp
- Discord
- Google Chat
- GitHub
- iMessage
- Kapso
- Lark / Feishu
- Linear
- Liveblocks
- Matrix
- Messenger
- Mattermost
- Novu
- Resend
- Sendblue
- Telegram
- Twilio
- Velt
- Web
- Webex
- WeChat
- WhatsApp Business Cloud
- X
- Zalo
- Zernio

請查看 adapter 文件，確認其套件名稱、憑證變數、webhook 需求與平台專屬行為。

## 使用相同的 Mastra 串接方式

每個 Chat SDK adapter 在 Mastra 端的設定方式都相同。安裝 adapter 套件，並將其 factory 加入 `channels.adapters`；接著設定平台憑證，並將 webhook 指向 Mastra 產生的路由。

你可以參考本節任一平台頁面，了解 Mastra 的串接方式：

- [Slack](/docs/capabilities/channels/slack)
- [Microsoft Teams](/docs/capabilities/channels/teams)
- [Discord](/docs/capabilities/channels/discord)
- [Telegram](/docs/capabilities/channels/telegram)
- [WhatsApp](/docs/capabilities/channels/whatsapp)

## Adapter 文件中的檢查項目

將新的 adapter 串接至 Mastra 前，請查看 adapter 文件並確認：

- 憑證環境變數。
- 平台要求的權限或 scope。
- Webhook 驗證行為。
- 平台是否需要分別為設定、事件或互動建立路由。
- 一般訊息是否需要長時間執行的 listener 或輪詢。
- 附件、卡片與 rich message 支援情形。
