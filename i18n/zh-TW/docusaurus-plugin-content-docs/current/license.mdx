# 授權條款

Mastra 採用 Apache License 2.0 授權，這是一種寬鬆的開放原始碼授權條款，賦予使用者廣泛的權利，可使用、修改及散布軟體。

## 什麼是 Apache License 2.0？ {/* #whats-apache-license-20 */}

Apache License 2.0 是一種寬鬆的開放原始碼授權條款，賦予使用者廣泛的權利，可使用、修改及散布軟體。它允許：

- 免費用於任何用途，包括商業用途
- 檢視、修改及重新散布原始碼
- 建立及散布衍生作品
- 不受限制地用於商業用途
- 獲得貢獻者提供的專利保護

Apache License 2.0 是目前最寬鬆且最適合企業採用的開放原始碼授權條款之一。

## 為什麼我們選擇 Apache License 2.0 {/* #why-we-chose-apache-license-20 */}

我們基於幾項重要原因選擇 Apache License 2.0：

1. **真正的開放原始碼**：這是受到認可的開放原始碼授權條款，符合開放原始碼原則與社群期待。

1. **企業友善**：它允許不受限制的商業使用與散布，因此非常適合各種規模的企業。

1. **專利保護**：它明確為使用者提供專利保護，帶來額外的法律保障。

1. **重視社群**：它鼓勵社群不受限制地貢獻與協作。

1. **廣泛採用**：這是業界最普及且最廣為理解的開放原始碼授權條款之一。

## 使用 Mastra 發展你的事業 {/* #building-your-business-with-mastra */}

Apache License 2.0 為使用 Mastra 發展事業提供最大的彈性：

### 允許的商業模式 {/* #allowed-business-models */}

- **建置應用程式**：建立並銷售使用 Mastra 建置的應用程式
- **提供顧問服務**：提供專業知識、導入及客製化服務
- **開發客製化解決方案**：使用 Mastra 為客戶建置量身打造的 AI 解決方案
- **建立附加元件與擴充功能**：開發並銷售可擴充 Mastra 功能的輔助工具
- **培訓與教育**：提供有關如何有效使用 Mastra 的課程與教材
- **託管服務**：以託管或代管服務的形式提供 Mastra
- **SaaS 平台**：建置由 Mastra 驅動的 SaaS 平台

### 合規使用範例 {/* #examples-of-compliant-usage */}

- 公司使用 Mastra 建置由 AI 驅動的客服應用程式，並將其銷售給客戶
- 顧問公司提供 Mastra 的導入與客製化服務
- 開發者使用 Mastra 建立專門的 Agent 與 Tool，並授權其他企業使用
- 新創公司建置由 Mastra 驅動、針對特定垂直領域的解決方案（例如醫療照護 AI 助理）
- 公司向客戶提供 Mastra 託管服務
- SaaS 平台整合 Mastra 作為其 AI 後端

### 合規要求 {/* #compliance-requirements */}

Apache License 2.0 的要求相當少：

- **標示出處**：保留著作權聲明與授權資訊（包括 NOTICE 檔案）
- **說明變更**：若修改軟體，須說明你已進行變更
- **附上授權條款**：散布軟體時，附上一份 Apache License 2.0
