# Workflow 執行器

Mastra [Workflow](/docs/workflows/overview) 可使用內建 Workflow 執行器執行，也可部署至專門處理協調、監控與可靠性的 Workflow 執行平台。

## Inngest

Inngest 是無須管理基礎架構即可執行背景 Workflow 的開發者平台。Mastra Workflow 可部署至 Inngest，並使用步驟記憶化、自動重試、即時監控及暫停／繼續功能。

設定方式請參閱 [Inngest 部署指南](/guides/deployment/inngest)，完整實作則請參閱 [Inngest Workflow 範例](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)。

## Temporal

Temporal 是用來協調長時間執行 Workflow 的持久執行平台。Mastra Workflow 可在 Temporal worker 上執行，每個 `createStep` 都會對應至 Temporal activity，以提供自動重試與持久狀態。

`@mastra/temporal` 套件仍屬實驗性質，尚不適合用於正式環境。設定方式請參閱 [Temporal 部署指南](/guides/deployment/temporal)。
