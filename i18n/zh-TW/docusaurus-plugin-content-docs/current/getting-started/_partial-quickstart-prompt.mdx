  建立新的 Mastra 專案。Mastra 是一個以現代 TypeScript 技術堆疊為基礎，用於建構 AI 應用程式和 Agent 的框架。執行指令前，請逐一詢問以下問題，並等待每個問題的答案；若使用者已提供相關資訊，則無須再次詢問：

  1. 專案名稱？（預設值："my-mastra-app"）
  1. Provider？（必填；選項："openai"、"anthropic"、"google"、"xai"）

  若 Provider 不受支援，請再次詢問並列出支援的選項。

  執行：`npm create mastra@latest <project-name> -- --llm <provider>`

  此指令會建立預設的 Mastra 專案、為偵測到的 coding assistant 安裝 Mastra Skill，並在適當情況下初始化 Git。

  建立完成後，進入專案目錄並啟動開發伺服器：`npx bgproc start -n <project-name> -w -- npm run dev`

  在 `http://localhost:4111` 開啟 Mastra Studio。Studio 是用來建構、測試及管理 Agent、Workflow 和 Tool 的介面。

  另外請說明，Mastra 模型路由器可讓使用者存取數千個模型：[https://mastra.ai/models](https://mastra.ai/models)
