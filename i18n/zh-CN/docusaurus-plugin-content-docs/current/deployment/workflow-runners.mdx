# Workflow runner

Mastra [Workflow](/docs/workflows/overview) 可以使用内置 Workflow runner 执行，也可以部署到负责处理编排、监控和可靠性的专用 Workflow 执行平台。

## Inngest {/* #inngest */}

Inngest 是一个无需管理基础设施即可运行后台 Workflow 的开发者平台。Mastra Workflow 可以部署到 Inngest，它提供步骤记忆、自动重试、实时监控和暂停/恢复功能。

请访问 [Inngest 部署指南](/guides/deployment/inngest)获取设置说明，并查看 [Inngest Workflow 示例](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)了解完整实现。

## Temporal {/* #temporal */}

Temporal 是用于编排长时间运行 Workflow 的持久化执行平台。Mastra Workflow 可以在 Temporal Worker 上运行，每个 `createStep` 都会映射到一个 Temporal activity，从而实现自动重试和持久化 state。

`@mastra/temporal` 包处于实验阶段，尚不适用于生产环境。请访问 [Temporal 部署指南](/guides/deployment/temporal)获取设置说明。
