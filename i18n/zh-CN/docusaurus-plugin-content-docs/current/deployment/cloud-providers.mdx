# 部署到云 Provider

Mastra 应用可以部署到云 Provider 和 serverless 平台。Mastra 为 Vercel、Netlify 和 Cloudflare 提供可选的内置部署器，用于自动执行部署流程。

## Mastra platform

Mastra 提供了一个用于将 Server 部署到云端的平台。阅读 [Mastra platform 部署指南](/docs/mastra-platform/overview)以了解更多信息。
