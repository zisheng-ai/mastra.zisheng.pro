# 许可证

Mastra 采用 Apache License 2.0，这是一种宽松的开源许可证，赋予用户广泛的权利，可以使用、修改和分发软件。

## 什么是 Apache License 2.0？

Apache License 2.0 是一种宽松的开源许可证，赋予用户广泛的权利，可以使用、修改和分发软件。它允许：

- 出于任何目的免费使用，包括商业用途
- 查看、修改和再分发源代码
- 创建和分发衍生作品
- 不受限制地用于商业用途
- 获得贡献者提供的专利保护

Apache License 2.0 是目前最宽松、对企业最友好的开源许可证之一。

## 我们为何选择 Apache License 2.0

我们选择 Apache License 2.0 有几个重要原因：

1. **真正的开源**：它是一种受认可的开源许可证，符合开源原则和社区预期。

1. **对企业友好**：它允许不受限制的商业使用和分发，适合各种规模的企业。

1. **专利保护**：它为用户提供明确的专利保护，带来额外的法律保障。

1. **重视社区**：它鼓励社区不受限制地贡献与协作。

1. **广泛采用**：它是业界最常用、最广为理解的开源许可证之一。

## 使用 Mastra 构建业务

Apache License 2.0 为使用 Mastra 构建业务提供了最大的灵活性：

### 允许的商业模式

- **构建应用**：创建并销售使用 Mastra 构建的应用
- **提供咨询服务**：提供专业知识、实施和定制服务
- **开发定制解决方案**：使用 Mastra 为客户构建量身定制的 AI 解决方案
- **创建附加组件和扩展**：开发并销售用于扩展 Mastra 功能的补充 Tool
- **培训和教育**：提供有关如何高效使用 Mastra 的课程和教学资料
- **托管服务**：将 Mastra 作为托管或代管服务提供
- **SaaS 平台**：构建由 Mastra 提供支持的 SaaS 平台

### 合规使用示例

- 公司使用 Mastra 构建由 AI 驱动的客户服务应用，并将其销售给客户
- 咨询公司提供 Mastra 的实施和定制服务
- 开发者使用 Mastra 创建专用 Agent 和 Tool，并将其许可给其他企业
- 初创公司构建由 Mastra 支持的垂直领域解决方案（例如医疗 AI 助手）
- 公司将 Mastra 作为托管服务提供给客户
- SaaS 平台集成 Mastra 作为 AI 后端

### 合规要求

Apache License 2.0 的要求很少：

- **署名**：保留版权声明和许可证信息（包括 NOTICE 文件）
- **说明更改**：如果修改了软件，请说明你已作出更改
- **包含许可证**：分发时附上 Apache License 2.0 的副本
