# 更多适配器

Mastra Channels 使用 Chat SDK 适配器，因此本节页面并未列出所有支持的平台。你可以使用任何导出适配器工厂且与 `channels.adapters` 兼容的 Chat SDK 平台适配器。

## 适配器目录 {/* #adapter-catalog */}

[Chat SDK 适配器目录](https://chat-sdk.dev/adapters)是可用适配器的权威来源。下列内容只是一份快照，可能并非始终保持最新。

在本文撰写时，Chat SDK 列出了以下平台的适配器：

- AgentPhone
- Baileys WhatsApp
- Discord
- Google Chat
- GitHub
- iMessage
- Kapso
- Lark / Feishu
- Linear
- Liveblocks
- Matrix
- Messenger
- Mattermost
- Novu
- Resend
- Sendblue
- Telegram
- Twilio
- Velt
- Web
- Webex
- WeChat
- WhatsApp Business Cloud
- X
- Zalo
- Zernio

请查看适配器文档，了解其包名、凭据变量、webhook 要求和平台特有行为。

## 使用相同的 Mastra 接线方式 {/* #use-the-same-mastra-wiring */}

每个 Chat SDK 适配器在 Mastra 侧都遵循相同的设置方式。安装适配器包，并将其工厂添加到 `channels.adapters`。然后配置平台凭据，并将其 webhook 指向生成的 Mastra 路由。

可以参考本节任一平台页面来完成 Mastra 接线：

- [Slack](/docs/capabilities/channels/slack)
- [Microsoft Teams](/docs/capabilities/channels/teams)
- [Discord](/docs/capabilities/channels/discord)
- [Telegram](/docs/capabilities/channels/telegram)
- [WhatsApp](/docs/capabilities/channels/whatsapp)

## 适配器文档中的检查事项 {/* #what-to-check-in-adapter-docs */}

将新适配器接入 Mastra 前，请在适配器文档中检查以下内容：

- 凭据环境变量。
- 所需的平台权限或 scope。
- Webhook 验证行为。
- 平台是否需要为设置、事件或交互提供单独的路由。
- 常规消息是否需要长时间运行的监听器或轮询。
- 对附件、卡片和富消息的支持情况。
