**面向 AI Agent：** 如果你的任务是从零构建 Mastra 项目，请遵循此处的精简说明，直到下一个标题为止。请根据需要调整 Agent 和 Tool 的示例代码。后续需特别注意：将 `model` 定义为 `provider/model` 格式的字符串，例如 `__GATEWAY_OPENAI_MODEL__`。对于 OpenAI，请使用 `openai/<model>`，不要使用 `openai:<model>`，也不要导入或传入 Provider 对象。

创建一个 `package.json` 文件，其内容为 `{ "type": "module" }`。安装所需依赖：`npm install @mastra/core@latest zod@latest typescript@latest @types/node@latest mastra@latest`

创建 tsconfig.json 文件：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "strict": true,
    "skipLibCheck": true,
    "noEmit": true,
    "allowImportingTsExtensions": true,
    "outDir": "dist"
  },
  "include": ["src/**/*"]
}
```

如果需要为 Agent 添加 Tool，请创建新文件并使用 `import { createTool } from "@mastra/core/tools"`。普通对象形式的 Tool 定义会静默执行失败；Tool **必须**通过 `createTool()` 定义，并包含 `id`、`description`、`inputSchema`（zod）和 `execute()`。`execute()` 接收两个参数：根据 inputSchema 验证后的输入数据（第一个参数），以及包含 `requestContext`、`tracingContext`、`abortSignal` 和其他执行元数据的可选执行上下文对象（第二个参数）。

示例：

```ts
// src/mastra/tools/weather-tool.ts
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

export const weatherTool = createTool({
  id: 'get-weather',
  description: 'Get current weather for a location',
  inputSchema: z.object({
    location: z.string().describe('City name'),
  }),
  outputSchema: z.object({
    location: z.string(),
    temperatureCelsius: z.number(),
    conditions: z.string(),
  }),
  execute: async ({ location }) => {
    return {
      location,
      temperatureCelsius: 21,
      conditions: 'sunny',
    }
  },
})
```

如果需要创建 Agent，请创建新文件并使用 `import { Agent } from "@mastra/core/agent"`。构造函数接收 `{ id, name, instructions, model }`。`model` 属性是采用 Mastra 模型路由器格式的字符串。使用此格式无需导入 Provider。除非 Mastra 文档另有说明，否则不要安装任何 AI SDK 包。

使用 `provider/model` 格式定义模型后，Mastra 会自动查找该 Provider 的环境变量。所定义的模型要求为 Provider 设置相应的环境变量。OpenAI：`OPENAI_API_KEY`。Anthropic：`ANTHROPIC_API_KEY`。Google：`GOOGLE_API_KEY`。例如，任何 `openai/<model>` 都需要 `OPENAI_API_KEY` 环境变量。有关受支持 Provider 及其环境变量名称的完整列表，请访问 [https://mastra.ai/models/environment-variables](https://mastra.ai/models/environment-variables)。

部分已知模型 ID 如下：

- `__GATEWAY_OPENAI_MODEL__`, `__GATEWAY_OPENAI_MODEL_MINI__`
- `__GATEWAY_ANTHROPIC_MODEL_SONNET__`, `__GATEWAY_ANTHROPIC_MODEL_OPUS__`, `__GATEWAY_ANTHROPIC_MODEL_HAIKU__`
- `__GATEWAY_GOOGLE_MODEL_FLASH__`

有关受支持模型的完整列表，请访问 [https://mastra.ai/models](https://mastra.ai/models)。

要向 Agent 添加 Tool，请导入该 Tool，并将其作为 tools 对象传给 Agent 构造函数。

示例：

```ts
// src/mastra/agents/weather-agent.ts
import { Agent } from '@mastra/core/agent'
import { weatherTool } from '../tools/weather-tool.ts'

export const weatherAgent = new Agent({
  id: 'weather-agent',
  name: 'Weather Agent',
  instructions: `
      You are a helpful weather assistant that provides accurate weather information.

      Your primary function is to help users get weather details for specific locations. When responding:
      - Include relevant details like humidity, wind conditions, and precipitation
      - Keep responses concise but informative

      Use the weatherTool to fetch current weather data.
`,
  // Use a string in provider/model format, not provider:model or a provider object.
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { weatherTool },
})
```

在 `src/mastra/index.ts` 创建 Mastra 入口点并注册 Agent：

```ts
import { Mastra } from '@mastra/core'
import { weatherAgent } from './agents/weather-agent.ts'

export const mastra = new Mastra({
  agents: { weatherAgent },
})
```

现在可以直接运行 Agent。为此，请导入 Mastra 实例，根据 Agent 的 id 获取它，然后调用 agent.generate()。Node.js 22.18.0 及更高版本可以直接运行 TypeScript 文件。导入本地文件时，请务必添加文件扩展名。示例：

```ts
// run.mjs
import { mastra } from './src/mastra/index.ts'

const agent = mastra.getAgentById('weather-agent')
const response = await agent.generate('Weather in SF')
console.log(response.text)
```
