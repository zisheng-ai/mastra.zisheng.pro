# Mastra platform

[Mastra platform](https://projects.mastra.ai) 提供三款产品，用于部署、监控和管理使用 Mastra 框架构建的 AI 应用：

- [**Observability**](/docs/mastra-platform/observability)：每个 platform 项目的基础产品，可跨 Mastra 项目和部署搜索 Trace、日志与指标
- [**Studio**](/docs/mastra-platform/studio)：用于测试 Agent 和运行 Workflow 的托管可视化环境，并提供检查 Trace 的 Tool。选择 Studio 也会同时获得 Observability。
- [**Server**](/docs/mastra-platform/server)：将 Mastra 应用作为 API Server 运行的生产部署目标。选择 Server 也会同时获得 Observability。

使用单条 [`mastra deploy`](/docs/mastra-platform/deploy) 命令进行部署，或连接 GitHub 仓库以便推送时部署。有关关联仓库的流程，请参阅 [GitHub 集成](/docs/mastra-platform/github)。

每个项目都可以运行多个[**环境**](/docs/mastra-platform/environments)（例如 `production` 和 `staging`）、通过 CLI 或项目设置预配[**托管数据库**](/docs/mastra-platform/database)以持久化应用数据，并为每个环境获得托管的 [**Workspace**](/docs/mastra-platform/workspaces)，无需手动配置即可为 Agent 提供文件系统和 Sandbox。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 可以在 Agent Trace 中发现反复出现的目标、结果、行为和情绪。Trace Intelligence 正面向部分项目提供 private beta。

## 开始使用 {/* #get-started */}

选择与你要完成的任务相符的路径：

- **添加托管 Observability**：使用 [Observability](/docs/mastra-platform/observability) 跨项目和部署收集可搜索的 Trace、日志与指标。如果希望先进行监控，而不部署 Studio 或 Server，请从这里开始。
- **部署 Studio**：使用 [Studio](/docs/mastra-platform/studio) 为团队托管可视化开发环境。如果需要共享 UI 来测试 Agent、运行 Workflow 和检查 Trace，请从这里开始。
- **部署 Server**：使用 [Server](/docs/mastra-platform/server) 将 Mastra 应用作为生产 API Server 运行。准备好从云端提供 Agent、Tool 和 Workflow 时，请从这里开始。

## 核心概念 {/* #key-concepts */}

**项目**是所有产品共享的父实体。一个项目可以包含所有产品：Observability、Studio 和 Server。项目归属于**组织**，组织是团队使用的多租户容器。

Mastra 应用由三种构建块组成：

- [Agent](/docs/agents/overview)：可以使用 Tool、遵循指令并维护上下文的 AI Agent
- [Tool](/docs/agents/using-tools)：供 Agent 使用的可调用函数和集成
- [Workflow](/docs/workflows/overview)：用于协调 Agent 和 Tool 的多步骤编排管道

## 进入生产环境 {/* #going-to-production */}

使用 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本地开发项目，并打开 [Studio](/docs/studio/overview)，在可视化环境中测试 Agent、Workflow 和 Tool。

准备好将应用部署到生产环境后，运行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy) 将应用推送到云端。

按照[部署](/docs/mastra-platform/deploy)文档中的分步说明进行操作。

如果在自己的基础设施上托管 Mastra 应用，仍可通过 [MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform) 将 Observability 数据发送到 Mastra platform。
