# Laminar exporter

[Laminar](https://laminar.sh/) 是一个开源、原生支持 OpenTelemetry 的 AI Agent 可观测性平台。只需在 `Observability` 配置中接入一个 `MastraExporter`，即可追踪、调试和监控每次 Mastra Agent 运行、模型步骤、Tool 调用和子 Agent。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## 配置 {/* #configuration */}

### 前提条件 {/* #prerequisites */}

1. **Laminar 项目**：在 Laminar 中创建或选择一个项目
1. **项目 API key**：从 Laminar Project Settings 复制
1. **环境变量**：设置凭据

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### 零配置设置 {/* #zero-config-setup */}

设置环境变量后，无需任何配置即可使用 exporter：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### 显式配置 {/* #explicit-configuration */}

你也可以直接传入凭据（优先于环境变量）：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::note
有关完整 `MastraExporter` 选项和多 Agent Trace 示例等高级用法，请参阅 [Laminar 的 Mastra 集成指南](https://laminar.sh/docs/tracing/integrations/mastra)。
:::

Mastra 的 `@mastra/laminar` 中还包含一个独立的 [`LaminarExporter`](/reference/observability/tracing/exporters/laminar)，可通过 OTLP/HTTP 发送 span。它无法继承活跃的 OTel 上下文，也不能将 Mastra span 完整映射到 Laminar 原生格式。因此，如果使用 `observe()` wrapper、多 Agent 根 span，并希望在 Laminar 中准确呈现，请使用上面的 `@lmnr-ai/lmnr` 集成。
