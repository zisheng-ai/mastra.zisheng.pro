# 集成概览

Mastra 可观测性集成决定可观测性数据的去向，以及数据在导出过程中如何转换。你可以使用集成将数据存储到 Mastra Storage、发送到 Mastra 平台、连接外部可观测性 Provider，或对导出的 span 数据进行脱敏。

## 何时使用集成

- 使用 `MastraStorageExporter`，让 Studio 中始终可以查看可观测性数据。
- 使用 `MastraPlatformExporter`，将托管的可观测性数据发送到 Mastra 平台。
- 将 Trace 转发到 Datadog、Langfuse 或 OpenTelemetry 后端等外部 Provider。
- 在敏感值离开运行时之前将其脱敏。

## 选择集成方式

- Studio 工作流：从 [Mastra Storage](/docs/observability/integrations/exporters/mastra-storage) 开始。
- 托管 Mastra 工作流：添加 [Mastra 平台](/docs/observability/integrations/exporters/mastra-platform)。
- 外部可观测性技术栈：在侧边栏的 `Exporters` 部分选择一个或多个 exporter 页面。
- 现有分布式 Trace 上下文：使用 bridge，然后按需添加 exporter。

## Exporter

Exporter 将可观测性数据发送到目标位置：

- [Mastra Storage](/docs/observability/integrations/exporters/mastra-storage)：持久化可观测性数据，供 Studio 使用。
- [Mastra 平台](/docs/observability/integrations/exporters/mastra-platform)：将托管的可观测性数据发送到 Mastra 平台。
- 外部 Provider：使用 Datadog、Langfuse、OpenTelemetry 及其他受支持平台的 exporter 页面。

## Bridge

Bridge 将 Mastra 连接到现有的分布式 Trace 上下文：

- [OpenTelemetry bridge](/docs/observability/integrations/bridges/otel)：将 Mastra 与现有 OpenTelemetry Trace 集成。
- [Datadog bridge](/docs/observability/integrations/bridges/datadog)：将 Mastra Trace 发送到 Datadog 及其 LLM Observability 产品。

## Processor

Processor 在导出前转换 span 或对其进行脱敏：

- [Sensitive Data Filter](/docs/observability/integrations/processors/sensitive-data-filter)：在 span 离开运行时之前对敏感字段进行脱敏。
