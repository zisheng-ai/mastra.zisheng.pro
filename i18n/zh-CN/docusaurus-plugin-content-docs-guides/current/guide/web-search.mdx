# 构建可搜索网页的 Agent

构建网页搜索 Agent 时，主要有两种策略可供选择：

1. **LLM 的原生搜索 Tool**：某些语言模型内置开箱即用的网页搜索能力。
1. **实现自定义搜索 Tool**：自行与搜索 Provider API 集成，以处理查询并检索结果。

## 前提条件

- 已安装 Node.js `v22.13.0` 或更高版本
- 受支持的 [Model Provider](/models) 提供的 API 密钥
- 现有的 Mastra 项目（按照[安装指南](/guides/getting-started/quickstart)设置新项目）

## 使用原生搜索 Tool

一些 LLM Provider 包含内置的网页搜索功能，无需额外集成 API 即可直接使用。OpenAI 和 Google 的模型都提供原生搜索 Tool，模型可以在生成过程中调用它们。

    安装依赖项

        ```bash npm2yarn
        npm install @ai-sdk/openai
        ```
      </TabItem>

      <TabItem value="gemini" label="Gemini">

        ```bash npm2yarn
        npm install @ai-sdk/google
        ```
      </TabItem>
    </Tabs>
  </StepItem>

  <StepItem title="定义 Agent">
    新建文件 `src/mastra/agents/searchAgent.ts` 并定义 Agent：

    <Tabs>

        ```ts title="src/mastra/agents/searchAgent.ts"
        export const searchAgent = new Agent({
          id: 'search-agent',
          name: 'Search Agent',
          instructions: 'You are a search agent that can search the web for information.',
          model: '__GATEWAY_OPENAI_MODEL__',
        })
        ```
      </TabItem>

      <TabItem value="gemini" label="Gemini">
        ```ts title="src/mastra/agents/searchAgent.ts"
        import { Agent } from '@mastra/core/agent'

        export const searchAgent = new Agent({
          id: 'search-agent',
          name: 'Search Agent',
          instructions: 'You are a search agent that can search the web for information.',
          model: 'google/gemini-2.5-flash',
        })
        ```
      </TabItem>
    </Tabs>
  </StepItem>

  <StepItem title="设置 Tool">
    设置 Tool：

    <Tabs>
      <TabItem value="openai" label="OpenAI">
        ```ts title="src/mastra/agents/searchAgent.ts" {1,9-12}
        import { openai } from '@ai-sdk/openai'
        import { Agent } from '@mastra/core/agent'

          id: 'search-agent',
          name: 'Search Agent',
          instructions: 'You are a search agent that can search the web for information.',
          model: '__GATEWAY_OPENAI_MODEL__',
          tools: {
            webSearch: openai.tools.webSearch(),
          },
        })
        ```
      </TabItem>

      <TabItem value="gemini" label="Gemini">
        ```ts title="src/mastra/agents/searchAgent.ts" {1,9-14}
        import { google } from '@ai-sdk/google'
        import { Agent } from '@mastra/core/agent'

        export const searchAgent = new Agent({
          id: 'search-agent',
          name: 'Search Agent',
          instructions: 'You are a search agent that can search the web for information.',
          model: 'google/gemini-2.5-flash',
          tools: {
            webSearch: google.tools.googleSearch({
              mode: 'MODE_DYNAMIC',
            }),
          },
        })
        ```

      </TabItem>
    </Tabs>
  </StepItem>

  <StepItem title="向 Mastra 注册 Agent">

    ```ts title="src/mastra/index.ts" {2, 5}
    import { searchAgent } from './agents/searchAgent'

      agents: { searchAgent },
    ```

  </StepItem>

## 使用搜索 API

如需更精细地控制搜索行为，可以将外部搜索 API 集成为自定义 Tool。[Exa](https://exa.ai/) 是一个专为 AI 应用构建的搜索引擎，提供语义搜索、可配置的筛选条件（类别、域名、日期范围），并且能够检索完整页面内容。搜索 API 封装在一个 Mastra Tool 中，该 Tool 定义输入 schema、输出格式和执行逻辑。

<Steps>
  <StepItem title="安装依赖项">
    安装依赖项

    ```bash npm2yarn
    npm install exa-js
    ```
  </StepItem>

  <StepItem title="定义 Agent">
    新建文件 `src/mastra/agents/searchAgent.ts` 并定义 Agent：

    ```ts title="src/mastra/agents/searchAgent.ts"
    import { Agent } from '@mastra/core/agent'

    export const searchAgent = new Agent({
      id: 'search-agent',
      name: 'Search Agent',
      instructions: 'You are a search agent that can search the web for information.',
      model: '__GATEWAY_OPENAI_MODEL__',
    })
    ```
  </StepItem>

  <StepItem title="设置 Tool">
    设置 Tool

    ```ts title="src/mastra/tools/searchTool.ts"
    import { createTool } from '@mastra/core/tools'
    import z from 'zod'
    import Exa from 'exa-js'

    export const exa = new Exa(process.env.EXA_API_KEY)

    export const webSearch = createTool({
      id: 'exa-web-search',
      description: 'Search the web',
      inputSchema: z.object({
        query: z.string().min(1).max(50).describe('The search query'),
      }),
      outputSchema: z.array(
        z.object({
          title: z.string().nullable(),
          url: z.string(),
          content: z.string(),
          publishedDate: z.string().optional(),
        }),
      ),
      execute: async inputData => {
        const { results } = await exa.searchAndContents(inputData.query, {
          livecrawl: 'always',
          numResults: 2,
        })

        return results.map(result => ({
          title: result.title,
          url: result.url,
          content: result.text.slice(0, 500),
          publishedDate: result.publishedDate,
        }))
      },
    })
    ```
  </StepItem>

  <StepItem title="添加到 Agent">
    添加到 Agent

    ```ts title="src/mastra/agents/searchAgent.ts"
    import { webSearch } from './tools/searchTool'

    export const searchAgent = new Agent({
      id: 'search-agent',
      name: 'Search Agent',
      instructions: 'You are a search agent that can search the web for information.',
      model: '__GATEWAY_OPENAI_MODEL__',
      tools: {
        webSearch,
      },
    })
    ```
  </StepItem>

  <StepItem title="向 Mastra 注册 Agent">
    在 `src/mastra/index.ts` 文件中注册 Agent：

    ```ts title="src/mastra/index.ts" {2, 5}
    import { Mastra } from '@mastra/core'
    import { searchAgent } from './agents/searchAgent'

    export const mastra = new Mastra({
      agents: { searchAgent },
    })
    ```
  </StepItem>

  <StepItem title="测试 Agent">
    你可以使用 `mastra dev` 命令，在 [Studio](/docs/studio/overview) 中测试 Agent：

    ```bash
    mastra dev
    ```

    在 Studio 中转到 **“Search Agent”** 并询问：“上周 AI 新闻中发生了什么？”
  </StepItem>
</Steps>
