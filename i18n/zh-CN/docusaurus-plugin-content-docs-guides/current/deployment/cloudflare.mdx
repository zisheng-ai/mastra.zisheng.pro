# 将 Mastra 部署到 Cloudflare

使用 `@mastra/deployer-cloudflare` 将 Mastra Server 部署到 Cloudflare Workers。该 deployer 会打包代码并生成符合 Cloudflare [wrangler 配置](https://developers.cloudflare.com/workers/wrangler/configuration/)的 `wrangler.jsonc` 文件，无需额外配置即可部署。

:::info

如果你使用的是 [Server 适配器](/docs/server/server-adapters)或 [Web 框架](/docs/deployment/web-framework)，请按该框架的常规方式进行部署。

:::

## 开始之前

你需要一个 [Mastra 应用](/guides/getting-started/quickstart)和一个 [Cloudflare](https://cloudflare.com/) 账户。

:::warning
Cloudflare Workers 使用临时文件系统，因此配置的所有 Storage（包括 observability Storage）都必须在外部托管。如果你将 [LibSQLStore](/reference/storage/libsql) 与文件 URL 配合使用，请改用远程托管的数据库。
:::

## 安装

将 `@mastra/deployer-cloudflare` 包添加到项目：

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

导入 [`CloudflareDeployer`](/reference/deployer/cloudflare)，并在 Mastra 配置中将其设置为 deployer：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

如需在本地测试 Cloudflare Worker，还要安装 [`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/)：

```bash npm2yarn
npm install -D wrangler
```

## 使用方法

设置项目后，将其推送到你选择的远程 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    将仓库连接到 Cloudflare。在“Workers & Pages”仪表盘中选择 **Create application（创建应用）**，并在下一步选择 Git Provider。继续完成设置流程，然后选择要部署的仓库。

    :::note

    请设置运行应用所需的环境变量（例如[模型 Provider](/models/providers) API Key）。你可以使用 `npx wrangler secret bulk .env` 从 `.env` 文件上传 secret。详情请参阅 [Secret](/reference/deployer/cloudflare#secrets)。

    :::
  </StepItem>

  <StepItem>
    准备就绪后，单击 \*\*Deploy（部署）\*\*按钮，等待首次部署完成。
  </StepItem>

  <StepItem>
    访问 `https://<your-project-name>.<slug>.workers.dev/api/agents`，试用刚部署的函数。你应该会收到列出所有可用 Agent 的 JSON 响应。

    由于 [Mastra Server](/docs/server/mastra-server) 会为每个 API 端点添加 `/api` 前缀，因此发出请求时必须将其添加到 URL 中。
  </StepItem>

  <StepItem>
    现在可以通过 HTTP 调用 Mastra 端点。

    :::note

    在公开暴露端点之前，请设置[身份验证](/docs/server/auth)。

    :::
  </StepItem>
</Steps>
