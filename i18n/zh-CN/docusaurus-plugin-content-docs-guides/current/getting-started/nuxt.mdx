# 在 Nuxt 项目中集成 Mastra

本指南将介绍如何使用 Mastra 构建一个可调用 Tool 的 AI Agent，然后通过服务器路由直接导入并调用该 Agent，将其连接到 Nuxt。

你将使用 [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview) 和 Vue 创建美观的交互式聊天体验。

## 开始之前 {/* #before-you-begin */}

- 你需要受支持的[模型 Provider](/models/)所提供的 API 密钥。如果没有偏好，请使用 [OpenAI](/models/providers/openai)。
- 安装 Node.js `v22.13.0` 或更高版本

## 创建新的 Nuxt 应用（可选） {/* #create-a-new-nuxt-app-optional */}

如果已有 Nuxt 应用，请跳到下一步。

运行以下命令以[创建新的 Nuxt 应用](https://nuxt.com/docs/getting-started/installation)：

```bash npm2yarn
npm create nuxt@latest mastra-nuxt -- --template minimal --packageManager npm --gitInit --modules
```

这会创建名为 `mastra-nuxt` 的项目，你也可以将其替换为任意名称。

## 初始化 Mastra {/* #initialize-mastra */}

进入 Nuxt 项目：

```bash
cd mastra-nuxt
```

运行 [`mastra init`](/reference/cli/mastra#mastra-init)。出现提示时，选择 Provider（例如 OpenAI）并输入密钥：

```bash npm2yarn
npx mastra@latest init
```

这会创建一个 `mastra` 文件夹，其中包含示例天气 Agent 和以下文件：

- `index.ts` - Mastra 配置，包括 memory
- `tools/weather-tool.ts` - 获取指定位置天气的 Tool
- `agents/weather-agent.ts`- 使用该 Tool 的天气 Agent 及其提示词

接下来，你会从 Nuxt 服务器路由调用 `weather-agent.ts`。

## 安装 AI SDK UI {/* #install-ai-sdk-ui */}

安装 AI SDK UI 和 Mastra adapter：

```bash npm2yarn
npm install @mastra/ai-sdk@latest @ai-sdk/vue ai
```

## 创建聊天路由 {/* #create-a-chat-route */}

创建 `server/api/chat.ts`：

```ts title="server/api/chat.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { toAISdkV5Messages } from '@mastra/ai-sdk/ui'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '../../src/mastra'

const THREAD_ID = 'example-user-id'
const RESOURCE_ID = 'weather-chat'

export default defineEventHandler(async event => {
  const method = event.method

  if (method === 'POST') {
    const params = await readBody(event)
    const stream = await handleChatStream({
      mastra,
      agentId: 'weather-agent',
      params: {
        ...params,
        memory: {
          ...params.memory,
          thread: THREAD_ID,
          resource: RESOURCE_ID,
        },
      },
    })

    return createUIMessageStreamResponse({ stream })
  }

  if (method === 'GET') {
    const memory = await mastra.getAgentById('weather-agent').getMemory()
    let response = null

    try {
      response = await memory?.recall({
        threadId: THREAD_ID,
        resourceId: RESOURCE_ID,
      })
    } catch {
      console.log('No previous messages found.')
    }

    const uiMessages = toAISdkV5Messages(response?.messages || [])

    return uiMessages
  }
})
```

`POST` handler 接受提示词，并以 AI SDK 格式流式返回 Agent 响应；`GET` handler 则从 memory 获取消息历史，以便客户端重新加载时恢复 UI 状态。

## 添加聊天 UI {/* #add-the-chat-ui */}

将 `app/app.vue` 的内容替换为以下代码：

```html title="app/app.vue"
<script setup lang="ts">
  import { ref, onMounted } from 'vue'
  import { Chat } from '@ai-sdk/vue'
  import { DefaultChatTransport, type ToolUIPart } from 'ai'

  const chat = new Chat({
    transport: new DefaultChatTransport({
      api: '/api/chat',
    }),
  })

  const STATE_TO_LABEL_MAP: Record<string, string> = {
    'input-streaming': 'Pending',
    'input-available': 'Running',
    'output-available': 'Completed',
    'output-error': 'Error',
    'output-denied': 'Denied',
  }

  const input = ref('')

  onMounted(async () => {
    const res = await fetch('/api/chat')
    const data = await res.json()
    chat.messages = [...data]
  })

  function handleSubmit() {
    if (!input.value.trim()) return

    chat.sendMessage({ text: input.value })
    input.value = ''
  }
</script>

<template>

    <div class="messages">
      <div v-for="message in chat.messages" :key="message.id" class="message-wrapper">
        <div v-for="(part, i) in message.parts" :key="`${message.id}-${i}`">
          <div v-if="part.type === 'text'" :class="['message', message.role]">
            <div class="message-content">{{ part.text }}</div>
          </div>

          <details v-else-if="part.type?.startsWith('tool-')" class="tool">
            <summary class="tool-header">
              {{ (part as ToolUIPart).type?.split('-').slice(1).join('-') }} - {{
              STATE_TO_LABEL_MAP[(part as ToolUIPart).state ?? 'output-available'] }}
            </summary>
            <div class="tool-content">
              <div class="tool-section">
                <div class="tool-label">Parameters</div>
                <pre><code>{{ JSON.stringify((part as ToolUIPart).input, null, 2) }}</code></pre>
              </div>
              <div class="tool-section">
                <div class="tool-label">
                  {{ (part as ToolUIPart).errorText ? 'Error' : 'Result' }}
                </div>
                <pre><code>{{ JSON.stringify((part as ToolUIPart).output, null, 2) }}</code></pre>
                <div v-if="(part as ToolUIPart).errorText" class="tool-error">
                  {{ (part as ToolUIPart).errorText }}
                </div>
              </div>
            </div>
          </details>
        </div>
      </div>
    </div>

    <form class="input-form" @submit.prevent="handleSubmit">

        v-model="input"
        type="text"
        placeholder="Ask about the weather..."
        :disabled="chat.status !== 'ready'"
        class="chat-input"
      />
      <button type="submit" class="submit-button" :disabled="chat.status !== 'ready'">Send</button>
    </form>
  </div>
</template>
```

它使用自定义消息样式渲染响应文本，并在可折叠的 details 元素中显示所有 Tool 调用。

## 测试 Agent {/* #test-your-agent */}

1. 使用 `npm run dev` 运行 Nuxt 应用
1. 打开聊天页面：[http://localhost:3000](http://localhost:3000)
1. 尝试询问天气。如果 API 密钥配置正确，你会收到响应
