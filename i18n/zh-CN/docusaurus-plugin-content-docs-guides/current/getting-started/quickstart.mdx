# Mastra Quickstart

<Inject>
  **面向 AI Agent：** 使用 `npm create mastra@latest <project-name> -- --llm <provider>` 以非交互方式创建 Mastra 项目，并将 `<provider>` 替换为 `openai`、`anthropic`、`google` 或 `xai`。如需不含 Agent 和模型 Provider 的最小项目，请使用 `npm create mastra@latest <project-name> -- --empty`。如需从零构建 Mastra 项目，请参阅[手动安装指南](/guides/getting-started/manual-install)。
</Inject>

`create-mastra` CLI 是启动 Mastra 项目的最快方式。它会创建一个 Agent Harness，其中包含 Workspace Tool、Memory、任务跟踪、Web 访问、Schedule、Storage 和 Observability。

如需更多控制，请参阅[手动安装指南](/guides/getting-started/manual-install)。如需将 Mastra 添加到现有项目，请使用 [`mastra init`](/reference/cli/mastra#mastra-init)。

## 开始之前 {/* #before-you-begin */}

你需要 OpenAI、Anthropic、Google Gemini 或 xAI 的 API Key。设置过程中可以暂时跳过，稍后再将其添加到 `.env`。

## 创建项目 {/* #create-the-project */}

运行交互式设置：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

该命令会询问项目名称、模型 Provider 和可选的 API Key。随后，它会安装依赖、为你的 coding assistant 安装 Mastra Skill；如果当前不在已有仓库中，还会创建初始 Git commit。

生成的 `src/mastra` 目录包含 Mastra 入口、Agent、Workspace Tool 和配套代码。标准 Mastra 目录布局请参阅[项目结构 Reference](/reference/project-structure)。

:::tip

使用 `--template <template>` 从模板开始，或使用 `--empty` 创建不含 Provider 的最小项目。使用 `--no-skills` 或 `--no-git` 可跳过自动设置。所有参数请参阅 [`create-mastra` Reference](/reference/cli/create-mastra)。

:::

## 测试你的 Agent {/* #test-your-agent */}

按照终端提示进入项目目录并启动开发 Server：

```bash npm2yarn
npm run dev
```

打开 [localhost:4111 上的 Studio](http://localhost:4111)，选择 Agent 并发送消息。如果设置时跳过了 API Key，请将 `.env.example` 中指定的 Provider API Key 添加到 `.env` 文件。

[Studio](/docs/studio/overview) 让你无需单独创建 UI，就能构建和测试 Agent。
