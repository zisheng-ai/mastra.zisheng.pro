# Voice

Voice 包已从 speech 重命名为 voice，同时更新了类名和 API 方法。

## 已变更

### Voice 配置属性名

为保持一致，Voice 配置属性已重命名。`speakProvider` 现为 `output`，`listenProvider` 现为 `input`，`realtimeProvider` 现为 `realtime`。新名称与各属性在语音输入和输出中的作用相匹配。

迁移时，请在为 Agent 配置 Voice 功能时更新配置属性名。

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip[Codemod]

你可以使用 Mastra 的 codemod CLI 自动更新代码：

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
