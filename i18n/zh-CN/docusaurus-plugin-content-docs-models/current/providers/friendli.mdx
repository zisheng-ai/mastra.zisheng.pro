# <img src="https://models.dev/logos/friendli.svg" alt="Friendli 标志" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Friendli

通过 Mastra 的模型路由器访问 5 个 Friendli 模型。系统会自动使用 `FRIENDLI_TOKEN` 环境变量完成身份验证。

更多信息请参阅[Friendli 文档](https://friendli.ai/docs/guides/serverless_endpoints/introduction)。

```bash title=".env"
FRIENDLI_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'friendli/MiniMaxAI/MiniMax-M2.5',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra 使用兼容 OpenAI 的 `/chat/completions` endpoint。部分 Provider 特有功能可能不可用，详情请参阅[Friendli 文档](https://friendli.ai/docs/guides/serverless_endpoints/introduction)。

:::
