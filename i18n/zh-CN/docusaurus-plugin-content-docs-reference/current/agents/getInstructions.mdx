# Agent.getInstructions()

`.getInstructions()` 方法用于获取为 Agent 配置的指令；如果指令是函数，则会解析该函数。这些指令用于指导 Agent 的行为，并定义其能力和约束。

## 用法示例 {/* #usage-example */}

```typescript
await agent.getInstructions()
```
