# Agent.listScorers()

`.listScorers()` 方法检索为 Agent 配置的评分配置；如果配置是函数，则会先解析该函数。该方法提供对评分系统的访问，用于评估 Agent 的响应和性能。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listScorers()
```
