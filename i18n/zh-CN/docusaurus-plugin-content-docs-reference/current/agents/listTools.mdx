# Agent.listTools()

`.listTools()` 方法检索为 Agent 配置的 Tool；如果配置是函数，则会先解析该函数。这些 Tool 扩展了 Agent 的能力，使其能够执行特定操作或访问外部系统。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listTools()
```
