# Agent.getDescription()

`.getDescription()` 方法用于获取为 Agent 配置的描述。该方法返回一个字符串，用于描述 Agent 的用途和能力。

## 用法示例

```typescript
agent.getDescription()
```

## 参数

该方法不接受任何参数。
