# Agent.getModel()

`.getModel()` 方法用于获取为 Agent 配置的语言模型；如果模型是函数，则会解析该函数。该方法用于访问为 Agent 能力提供支持的底层模型。

## 用法示例

```typescript
await agent.getModel()
```
