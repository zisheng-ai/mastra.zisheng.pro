# Agent.listWorkflows()

`.listWorkflows()` 方法检索为 Agent 配置的 Workflow；如果配置是函数，则会先解析该函数。这些 Workflow 使 Agent 能够按照定义好的执行路径运行复杂的多步骤流程。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
