# Agent.getLLM()

`.getLLM()` 方法用于获取为 Agent 配置的语言模型实例；如果该实例是函数，则会解析该函数。你还可以传入请求范围的 `model` 覆盖，而不会修改 Agent 配置的模型。

## 用法示例

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
