# Agent.getDefaultOptions()

可以为 Agent 配置 memory 使用方式和输出格式的默认选项，也可以配置迭代步骤。`.getDefaultOptions()` 方法会返回这些默认值；如果默认值是函数，则会解析函数。这些选项会应用于所有 `stream()` 和 `generate()` 调用，除非被覆盖；它们也适合用于检查 Agent 的未知默认值。

## 用法示例 {/* #usage-example */}

```typescript
await agent.getDefaultOptions()
```
