# Agent.listAgents()

`.listAgents()` 方法检索为 Agent 配置的 subagent；如果配置是函数，则会先解析该函数。这些 subagent 使 Agent 能够访问其他 Agent 并执行复杂操作。

## 使用示例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
