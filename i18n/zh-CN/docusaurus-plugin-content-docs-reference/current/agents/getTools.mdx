# Agent.getTools()

`.getTools()` 方法用于获取为 Agent 配置的 Tool；如果 Tool 是函数，则会解析该函数。这些 Tool 扩展了 Agent 的能力，使其能够执行特定操作或访问外部系统。

## 用法示例

```typescript
await agent.getTools()
```
