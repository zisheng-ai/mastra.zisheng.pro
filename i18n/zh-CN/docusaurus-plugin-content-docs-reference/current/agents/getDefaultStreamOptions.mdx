# Agent.getDefaultStreamOptionsLegacy()

:::warning

**已弃用**：此方法已弃用，并且仅适用于 V1 模型。对于 V2 模型，请改用新的 [`.getDefaultOptions()`](./getDefaultOptions) 方法。

:::

可以为 Agent 配置 memory 使用方式和输出格式的默认流式选项，也可以配置迭代步骤。`.getDefaultStreamOptionsLegacy()` 方法会返回这些默认值；如果默认值是函数，则会解析函数。这些选项会应用于所有 `streamLegacy()` 调用，除非被覆盖；它们也适合用于检查 Agent 的未知默认值。

## 用法示例

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
