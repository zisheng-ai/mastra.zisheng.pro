# Agent.getVoice()

`.getVoice()` 方法用于获取为 Agent 配置的语音 Provider；如果 Provider 是函数，则会解析该函数。该方法用于访问 Agent 的语音能力，以实现文本转语音和语音转文本功能。

## 用法示例 {/* #usage-example */}

```typescript
await agent.getVoice()
```
