# Workflow\.branch()

`.branch()` 方法在 workflow 步骤之间创建条件分支，使其可以根据前一个步骤的结果采用不同路径。

## 使用示例

```typescript
workflow.branch([
  [async ({ context }) => true, step1],
  [async ({ context }) => false, step2],
])
```
