# Workflow\.createRun()

`.createRun()` 方法创建新的 workflow run 实例，让你能够使用特定输入数据执行 workflow。这是当前返回 `Run` 实例的 API。

## 使用示例 {/* #usage-example */}

```typescript
await workflow.createRun()
```

## 扩展示例 {/* #extended-usage-example */}

```typescript
const workflow = mastra.getWorkflow('workflow')

const run = await workflow.createRun()

const result = await run.start({
  inputData: {
    value: 10,
  },
})
```

## 使用 `resourceId` {/* #using-resourceid */}

`resourceId` 参数会将 workflow run 与特定资源关联，例如用户或租户。当你需要构建多租户应用，或跟踪由哪个用户启动 workflow 时，这很有用。

```typescript
const workflow = mastra.getWorkflow('workflow')

// Create a run associated with a specific user
const run = await workflow.createRun({
  resourceId: 'user-123',
})

const result = await run.start({
  inputData: {
    value: 10,
  },
})

// Later, retrieve the run and access the resourceId
const storedRun = await workflow.getWorkflowRunById(run.runId)
console.log(storedRun.resourceId) // "user-123"
```
