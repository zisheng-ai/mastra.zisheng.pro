# Workflow\.dowhile()

`.dowhile()` 方法会在满足条件时执行一个步骤。它始终会在评估条件前至少运行该步骤一次。首次评估条件时，`iterationCount` 为 `1`。

## 使用示例 {/* #usage-example */}

```typescript
workflow.dowhile(step1, async ({ inputData }) => true)
```
