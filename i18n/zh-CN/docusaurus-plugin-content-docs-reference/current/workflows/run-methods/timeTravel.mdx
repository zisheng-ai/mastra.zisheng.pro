# Run.timeTravel()

`.timeTravel()` 方法从任意指定步骤开始重新执行 workflow，可使用已存储的快照数据，也可使用你提供的自定义上下文。它可用于调试失败的 workflow、使用不同输入测试单个步骤，还能在不重新运行整个 workflow 的情况下从错误中恢复。

## 使用示例

```typescript
const run = await workflow.createRun()

const result = await run.timeTravel({
  step: 'step2',
  inputData: { value: 10 },
})
```

## 扩展使用示例

### 使用自定义上下文进行 Time Travel

```typescript
const result = await run.timeTravel({
  step: 'step2',
  context: {
    step1: {
      status: 'success',
      payload: { value: 0 },
      output: { step1Result: 2 },
      startedAt: Date.now(),
      endedAt: Date.now(),
    },
  },
})
```

### Time Travel 到嵌套 workflow 步骤

```typescript
// Using dot notation
const result = await run.timeTravel({
  step: 'nestedWorkflow.step3',
  inputData: { value: 10 },
})

// Using array of step IDs
const result = await run.timeTravel({
  step: ['nestedWorkflow', 'step3'],
  inputData: { value: 10 },
})
```

### 使用初始状态进行 Time Travel

```typescript
const result = await run.timeTravel({
  step: 'step2',
  inputData: { value: 10 },
  initialState: {
    counter: 5,
    metadata: { source: 'time-travel' },
  },
})
```

### 使用嵌套 workflow 上下文进行 Time Travel

```typescript
const result = await run.timeTravel({
  step: 'nestedWorkflow.step3',
  context: {
    step1: {
      status: 'success',
      payload: { value: 0 },
      output: { step1Result: 2 },
      startedAt: Date.now(),
      endedAt: Date.now(),
    },
    nestedWorkflow: {
      status: 'running',
      payload: { step1Result: 2 },
      startedAt: Date.now(),
    },
  },
  nestedStepsContext: {
    nestedWorkflow: {
      step2: {
        status: 'success',
        payload: { step1Result: 2 },
        output: { step2Result: 3 },
        startedAt: Date.now(),
        endedAt: Date.now(),
      },
    },
  },
})
```

## 注意事项

- Time Travel 依赖已持久化的 workflow 快照，因此需要配置存储
- 重新执行 workflow 时，workflow 会从存储中加载现有快照（如果有）
- 目标步骤之前的步骤结果会从快照或提供的上下文中重建
- 使用提供或重建的输入数据，从指定步骤开始执行
- workflow 会从该处继续执行直至完成
- 如果提供自定义上下文或起始步骤的输入数据，也可以对尚未运行过的 workflow 使用 Time Travel。
