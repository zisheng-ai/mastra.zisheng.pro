# Mastra.setLogger()

`.setLogger()` 方法用于为 Mastra 实例中的所有组件（Agent、Workflow 等）设置 Logger。此方法接受一个包含 logger 属性的对象参数。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
