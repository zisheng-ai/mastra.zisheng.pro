# Mastra.getWorkflow()

`.getWorkflow()` 方法用于按注册键获取 Workflow。此方法为 Workflow 输入和输出 schema 提供完整的 TypeScript 类型推断。

## 使用示例

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## 类型推断

为了获得最佳 TypeScript 支持，请将 Workflow 的**注册键**（将 Workflow 添加到 Mastra 时使用的键）传给 `getWorkflow()`。这样可对以下内容进行完整的类型推断：

- 输入数据 schema
- 输出数据 schema
- 步骤结果

如果需要按 Workflow 的 `id` 属性而非注册键获取，可以使用 `getWorkflowById()`，但请注意类型推断不会同样精确。
