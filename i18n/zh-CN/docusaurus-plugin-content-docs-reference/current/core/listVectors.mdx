# Mastra.listVectors()

`.listVectors()` 方法用于获取 Mastra 实例中已配置的所有 vector store。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listVectors()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
