# Mastra.removeWorkspace()

`.removeWorkspace()` 方法从 Mastra 运行时注册表中移除 Workspace。传入 `{ destroy: true }` 可在移除前销毁 Workspace。

## 使用示例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 参数 {/* #parameters */}

<PropertiesTable
  content={[

    name: 'options',

    isOptional: true,

]}
/>

## 返回值 {/* #returns */}

<PropertiesTable
  content={[
  {
    name: 'removed',
    type: 'Promise<boolean>',
    description: '成功移除 Workspace 时为 `true`。不存在具有该 ID 的 Workspace 时为 `false`。',
  },
]}
/>

当 `destroy` 为 `true` 且 `workspace.destroy()` 抛出错误时，此调用会以该错误拒绝，Workspace 仍保持注册状态，以便调用方重试清理。
