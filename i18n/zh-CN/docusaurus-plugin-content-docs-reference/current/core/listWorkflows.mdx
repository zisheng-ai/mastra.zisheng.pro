# Mastra.listWorkflows()

`.listWorkflows()` 方法用于获取 Mastra 实例中已配置的所有 Workflow。此方法接受一个可选的 options 对象。

## 使用示例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```

## 参数 {/* #parameters */}

<PropertiesTable
  content={[
  {
    name: 'options',
    type: '{ serialized?: boolean }',
    description:
      '可选配置对象。当 `serialized` 为 true 时，返回仅包含 name 属性的简化 Workflow 对象，而非完整的 Workflow 实例。',
    optional: true,
  },
]}
/>

## 返回值 {/* #returns */}

<PropertiesTable
  content={[
  {

  },
]}
/>
