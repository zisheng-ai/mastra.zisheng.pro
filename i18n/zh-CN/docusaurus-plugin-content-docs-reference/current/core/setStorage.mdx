# Mastra.setStorage()

`.setStorage()` 方法用于设置 Mastra 实例的 Storage 实例。此方法接受一个 `MastraCompositeStore` 参数。

## 使用示例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
