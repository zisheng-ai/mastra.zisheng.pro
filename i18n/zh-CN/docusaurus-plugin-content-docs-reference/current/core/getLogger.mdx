# Mastra.getLogger()

`.getLogger()` 方法用于获取 Mastra 实例中已配置的 Logger 实例。

## 使用示例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 参数 {/* #parameters */}

此方法不接受任何参数。
