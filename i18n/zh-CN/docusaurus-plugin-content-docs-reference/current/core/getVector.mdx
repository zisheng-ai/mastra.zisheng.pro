# Mastra.getVector()

`.getVector()` 方法用于按名称获取 vector store。此方法接受一个 `string` 参数，用于指定 vector store 名称。

## 使用示例

```typescript
mastra.getVector('testVectorStore')
```

## 参数

<PropertiesTable
  content={[
  {
    name: 'name',
    type: 'TVectorName extends keyof TVectors',
    description:
      '要获取的 vector store 名称。必须是 Mastra 配置中存在的有效 vector store 名称。',
  },
]}
/>
