# Mastra.listLogsByRunId()

`.listLogsByRunId()` 方法用于获取指定 run ID 和 transport ID 的日志。此方法要求配置支持 `listLogsByRunId` 操作的 Logger。

## 使用示例

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
