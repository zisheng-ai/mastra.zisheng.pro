# Span 过滤

Span 过滤用于控制从可观测性配置导出哪些 Span。你可以用它来减少干扰或降低按 Span 计费的成本，也可以仅保留对特定 Exporter 或环境有意义的 Span。

有关 Tracing 配置的简要概览，请参阅 [Tracing](/docs/observability/tracing/overview)。

## 用法示例

以下示例演示如何在一项可观测性配置中结合使用 `excludeSpanTypes` 和 `spanFilter`：

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SpanType } from '@mastra/core/observability'
import { Observability, MastraStorageExporter } from '@mastra/observability'
import { LangfuseExporter } from '@mastra/langfuse'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'my-app',
        exporters: [new MastraStorageExporter(), new LangfuseExporter()],
        excludeSpanTypes: [SpanType.MODEL_CHUNK, SpanType.MODEL_STEP],
        spanFilter: span => {
          if (span.type === SpanType.TOOL_CALL && span.attributes?.success) {
            return false
          }

          return true
        },
      },
    },
  }),
})
```

### `excludeSpanTypes`

如果希望以最少的配置排除整个 Span 类别，请使用 `excludeSpanTypes`。

有关当前支持的值，请参阅 [`SpanType` 枚举](https://github.com/mastra-ai/mastra/blob/main/packages/core/src/observability/types/tracing.ts)。

```ts title="src/mastra/index.ts"
import { SpanType } from '@mastra/core/observability'

excludeSpanTypes: [SpanType.MODEL_CHUNK, SpanType.MODEL_STEP, SpanType.WORKFLOW_SLEEP]
```

### `spanFilter`

当过滤条件取决于导出的 Span 内容时，请使用 `spanFilter`。

```ts title="src/mastra/index.ts"
import { SpanType } from '@mastra/core/observability'

spanFilter: span => {
  if (span.type === SpanType.MODEL_CHUNK) return false
  if (span.type === SpanType.TOOL_CALL && span.attributes?.success) return false

  return true
}
```

其他示例：

```ts title="src/mastra/index.ts"
// Only export spans from production
spanFilter: span => span.metadata?.environment === 'production'

// Exclude spans from a specific entity
spanFilter: span => span.entityId !== 'noisy-agent'
```

## 处理顺序

Span 过滤会在导出时按以下顺序进行：

1. 除非 `includeInternalSpans` 为 `true`，否则丢弃内部 Span。
1. `excludeSpanTypes` 移除类型匹配的 Span。
1. `spanOutputProcessors` 转换其余 Span。
1. `spanFilter` 决定是否保留最终导出的 Span。

如果 `spanFilter` 抛出错误，Mastra 会保留该 Span 并记录错误，以免数据在没有提示的情况下丢失。
