# dataset.startExperimentAsync()

**添加于：** `@mastra/core@1.4.0`

异步启动实验（触发后即返回）。立即返回实验 ID 和 `'pending'` 状态，实验将在后台运行。

## 使用示例

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
console.log(`Current status: ${experiment.status}`)
```

## 参数

接受与 [`dataset.startExperiment()`](/reference/datasets/startExperiment) 相同的 `StartExperimentConfig`。

当 `persistence.experiments` 设为 `'none'` 时，`startExperimentAsync()` 不会持久化实验记录、进度更新或条目结果。分数持久化仍由 `persistence.scores` 单独控制。如果没有实验事件观察器，本次运行将触发后即返回，实验 API 无法报告运行是已完成还是失败。

如果调用方需要返回的摘要，请使用同步的 [`startExperiment()`](/reference/datasets/startExperiment)。实验事件观察器可以接收生命周期事件和最终摘要。
