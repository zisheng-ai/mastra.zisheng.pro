# dataset.deleteItems()

**添加于：** `@mastra/core@1.4.0`

通过一次批量操作从数据集中删除多个条目。

## 使用示例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

await dataset.deleteItems({
  itemIds: ['item-1', 'item-2', 'item-3'],
})
```
