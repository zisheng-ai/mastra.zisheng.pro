# FirecrawlBrowser 类

`FirecrawlBrowser` 类提供由 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 支持的浏览器自动化。它通过 Firecrawl API 预配远程浏览器 session，并通过 Chrome DevTools Protocol（CDP）连接这些 session。

`FirecrawlBrowser` 扩展了 [`AgentBrowser`](/reference/browser/agent-browser)，并公开相同的确定性工具集。需要托管的浏览器 session，而不是本地 Chromium 安装时，请使用它。对于本地自动化，请参阅 [`AgentBrowser`](/reference/browser/agent-browser)。如需使用自然语言的 AI 驱动交互，请参阅 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 用法示例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Session 生命周期 {/* #session-lifecycle */}

Session 预配取决于从 `AgentBrowser` 继承的 `scope` 选项：

- `'thread'`（默认）：每个对话线程都有自己的 Firecrawl Sandbox session。该 session 在首次使用时创建，并在线程的浏览器 session 被销毁时删除。
- `'shared'`：浏览器启动时创建一个 Firecrawl Sandbox session，并由所有线程共享。浏览器关闭时删除该 session。

在这两种情况下，浏览器关闭时，`FirecrawlBrowser` 都会删除远程 Firecrawl session，包括 session 创建或连接中途失败的情况。

## 工具 {/* #tools */}

`FirecrawlBrowser` 提供与 `AgentBrowser` 相同的工具集，包括 `browser_goto`、`browser_snapshot`、`browser_click`、`browser_type` 和 `browser_screenshot`。有关完整列表和工具参数，请参阅 [`AgentBrowser` 工具参考](/reference/browser/agent-browser)。
