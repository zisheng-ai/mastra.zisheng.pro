# mountAgentControllerOnMastra()

:::experimental

`@mastra/code-sdk` 包处于实验阶段，次要版本中可能包含破坏性变更。

:::

`mountAgentControllerOnMastra()` 函数会构建 Mastra Code Agent Controller（即 [`mastracode`](https://www.npmjs.com/package/mastracode) CLI 背后的 Coding Agent，包含其模式、Tool、Memory 和 Thread 管理功能），并将其注册到由服务器持有的 [Mastra](/reference/core/mastra-class) 实例上。你可以用它将 Mastra Code Agent 提供给自己的 UI（Web 应用、编辑器、Bot）：每个客户端都通过返回的 [`AgentController`](/reference/agent-controller/agent-controller-class) 创建或恢复各自隔离的 Session。

如需自行构造 `Mastra` 实例（例如在可部署的入口文件中），请使用同一包中的 `prepareAgentControllerMount()`。它会返回构造函数参数以及一个 `finalize()` 回调。

## 用法示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

传入现有的 `mastra`，可将 Controller 挂载到已经托管其他原语的 Mastra 实例上：

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
