# 错误处理

Mastra Client SDK 包含内置的重试机制和错误处理能力。

## 错误处理

所有 API 方法都可能抛出错误，你可以捕获并处理这些错误：

```typescript
try {
  const agent = mastraClient.getAgent('agent-id')
  const response = await agent.generate('Hello')
} catch (error) {
  console.error('An error occurred:', error.message)
}
```
