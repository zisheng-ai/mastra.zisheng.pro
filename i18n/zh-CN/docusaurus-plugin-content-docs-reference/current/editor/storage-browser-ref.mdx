# StorageBrowserRef

`StorageBrowserRef` 是附加到已存储 Agent 的内联 browser 配置。实例化时，会根据在 [`MastraEditor.browsers`](/reference/editor/mastra-editor) 上注册的 [`BrowserProvider`](/reference/editor/browser-provider) 解析 `provider` id。

[`BuilderAgentDefaults.browser`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 和已存储 Agent 记录均使用此类型。

## 使用示例

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { stagehandBrowserProvider } from '@mastra/stagehand'

new MastraEditor({
  browsers: { [stagehandBrowserProvider.id]: stagehandBrowserProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        browser: {
          type: 'inline',
          config: {
            provider: 'stagehand',
            headless: true,
            viewport: { width: 1280, height: 720 },
          },
        },
      },
    },
  },
})
```

## 类型

```typescript
type StorageBrowserRef = { type: 'inline'; config: StorageBrowserConfig }
```

Browser 不支持 `{ type: 'id' }` 变体：它们始终以内联方式存储。

## 实例化

`StorageBrowserRef` 会在调用 `mastra.editor.agent.getById()` 时延迟解析。Editor 在 `MastraEditor.browsers` 中查找 `config.provider`，然后调用 `provider.createBrowser(config)`。如果 Provider 未注册，Editor 会记录警告并返回 `undefined`：Agent 仍会加载，但不包含 browser。
