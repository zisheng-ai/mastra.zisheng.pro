# Qdrant Vector 存储

QdrantVector 类使用 Vector 相似度搜索引擎 [Qdrant](https://qdrant.tech/) 提供 Vector 搜索。
它提供可用于生产环境的服务，并提供便捷的 API 来存储、搜索和管理 Vector，同时支持额外的 payload 和扩展筛选功能。

#### 创建命名 Vector collection {/* #creating-a-named-vectors-collection */}

```typescript
// Create a collection with multiple named vector spaces
await store.createIndex({
  indexName: 'multi_modal',
  dimension: 768, // fallback
  namedVectors: {
    text: { size: 768, distance: 'cosine' },
    image: { size: 512, distance: 'euclidean' },
  },
})
```

#### 命名 Vector {/* #named-vectors */}

Qdrant 支持[每个 collection 包含多个 Vector](https://qdrant.tech/documentation/concepts/vectors/#named-vectors)，每个 Vector 字段都有一个名称。使用 `using` 参数选择要查询的 Vector 字段：

```typescript
const results = await store.query({
  indexName: 'my_index',
  queryVector: embedding,
  topK: 10,
  using: 'title_embedding', // Query against a specific named vector
})
```

### `createPayloadIndex()` {/* #createpayloadindex */}

在 collection 字段上创建 payload（元数据）索引，以实现高效筛选。对于 Qdrant Cloud 以及任何设置了 `strict_mode_config = true` 的 Qdrant 实例，此操作为**必需**。

<PropertiesTable
  content={[
  {
    name: 'indexName',
    type: 'string',
    description: '要在其上创建 payload 索引的 collection 名称',
  },
  {
    name: 'fieldName',
    type: 'string',
    description: '要建立索引的 payload 字段名称',
  },
  {
    name: 'fieldSchema',
    type: "'keyword' | 'integer' | 'float' | 'geo' | 'text' | 'bool' | 'datetime' | 'uuid'",
    description: 'payload 字段的 schema 类型',
  },
  {
    name: 'wait',
    type: 'boolean',
    isOptional: true,
    defaultValue: 'true',
    description: '是否等待操作完成',
  },
]}
/>

```typescript
// Create a keyword index for filtering by source
await store.createPayloadIndex({
  indexName: 'my_index',
  fieldName: 'source',
  fieldSchema: 'keyword',
})

const results = await store.query({
  indexName: 'my_index',
  queryVector: queryVector,
  filter: { source: 'document-a' },
})
```

```typescript
interface QueryResult {
  id: string
  score: number
  metadata: Record<string, any>

```

## 错误处理 {/* #error-handling */}

存储会抛出可捕获的类型化错误：

```typescript
try {
  await store.query({
    indexName: 'index_name',
    queryVector: queryVector,
  })
} catch (error) {
  if (error instanceof VectorStoreError) {
    console.log(error.code) // 'connection_failed' | 'invalid_dimension' | etc
    console.log(error.details) // Additional error context
  }
}
```
