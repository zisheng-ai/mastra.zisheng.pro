# Agent.streamLegacy()（旧版）

:::warning

**已弃用**：此方法已弃用，并且只适用于 V1 模型。V2 模型请改用新的 [`.stream()`](./stream) 方法。升级详情请参阅[迁移指南](/guides/migrations/vnext-to-standard-apis)。

:::

`.streamLegacy()` 是旧版 Agent Stream API，用于即时Stream V1 模型 Agent 的回应。此方法接受讯息及选用的Stream选项。

## 使用范例

```typescript
await agent.streamLegacy('message for agent')
```

## 迁移至新 API

:::info

新的 `.stream()` 方法提供更强的功能，包括 AI SDK v5+ 兼容性、更完善的结构化输出处理，以及改良的回呼系统。详细迁移指示请参阅[迁移指南](/guides/migrations/vnext-to-standard-apis)。

:::

### 快速迁移范例

#### 迁移前（旧版）

```typescript
const result = await agent.streamLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```

#### 迁移后（新 API）

```typescript
const result = await agent.stream('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```
