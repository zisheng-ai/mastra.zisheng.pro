# Run.stream()

`.stream()` 方法支持从 Workflow 实时流式传输响应。它会直接返回事件的 `ReadableStream`。

## 用法示例

```typescript
const run = await workflow.createRun()

const stream = await run.stream({
  inputData: {
    value: 'initial data',
  },
})

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 扩展用法示例

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

// Iterate over stream events (you can iterate over stream directly or use stream.fullStream)
for await (const chunk of stream) {
  console.log(chunk)
}

// Access the final result
const result = await stream.result
console.log('Final result:', result)

// Access token usage
const usage = await stream.usage
console.log('Token usage:', usage)

// Check current status
console.log('Status:', stream.status)
```

## Stream 事件

Stream 会在 Workflow 执行期间发出不同类型的事件。每个事件都有一个 `type` 字段，以及一个包含相关数据的 `payload`：

- **`workflow-start`**：Workflow 开始执行
- **`workflow-step-start`**：步骤开始执行
- **`workflow-step-output`**：步骤的自定义输出
- **`workflow-step-progress`**：foreach 步骤报告每次迭代的进度（包括 `completedCount`、`totalCount`、`currentIndex`、`iterationStatus` 以及可选的 `iterationOutput`）
- **`workflow-step-result`**：步骤完成并产生结果
- **`workflow-finish`**：Workflow 执行完成，并附带用量统计信息。对于成功的运行，`payload.finalWorkflowResult` 包含 Workflow 的最终结果，因此 Stream 使用方无需后续获取
