# Run.observeStream()

`.observeStream()` 方法会为当前正在运行的 Workflow 打开一个新的 `ReadableStream`。如果原始 Stream 已不可用，你仍可借此观察事件 Stream。

## 用法示例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 返回值 {/* #returns */}

`ReadableStream<ChunkType>`

## Stream 事件 {/* #stream-events */}

Stream 会在 Workflow 执行期间发出不同类型的事件。每个事件都有一个 `type` 字段，以及一个包含相关数据的 `payload`：

- **`workflow-start`**：Workflow 开始执行
- **`workflow-step-start`**：步骤开始执行
- **`workflow-step-output`**：步骤的自定义输出
- **`workflow-step-result`**：步骤完成并产生结果
- **`workflow-finish`**：Workflow 执行完成，并附带用量统计信息。对于成功的运行，`payload.finalWorkflowResult` 包含 Workflow 的最终结果
