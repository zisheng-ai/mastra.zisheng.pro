# S3Filesystem

将文件存储在 Amazon S3 或兼容 S3 的存储服务中，例如 Cloudflare R2、MinIO、DigitalOcean Spaces 和 Tigris。有关接口的详细信息，请参阅 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)。

## 安装 {/* #installation */}

```bash npm2yarn
npm install @mastra/s3
```

## 使用方法 {/* #usage */}

将 `S3Filesystem` 添加到 Workspace 并分配给 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'

const workspace = new Workspace({
  filesystem: new S3Filesystem({
    bucket: 'my-bucket',
    region: 'us-east-1',
    accessKeyId: process.env.AWS_ACCESS_KEY_ID,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### AWS 凭证 Provider 链 {/* #aws-credential-provider-chain */}

未提供凭证时，`S3Filesystem` 使用 AWS SDK 的默认凭证 Provider 链。该链会自动从环境变量、`~/.aws` 配置文件、ECS 容器凭证、EC2 实例配置文件及其他标准来源中发现凭证。

```typescript
import { S3Filesystem } from '@mastra/s3'

// SDK discovers credentials from the environment automatically
const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'us-east-1',
})
```

传入凭证 Provider 函数可自动刷新凭证。这适用于部署到 ECS、Lambda 的情况，也适用于使用 SSO/AssumeRole 时临时凭证会过期并需要刷新的情况。

直接调用 `fromNodeProviderChain()` 时，请安装 AWS SDK 凭证 Provider 包：

```bash npm2yarn
npm install @aws-sdk/credential-providers
```

```typescript
import { S3Filesystem } from '@mastra/s3'
import { fromNodeProviderChain } from '@aws-sdk/credential-providers'

const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'us-east-1',
  credentials: fromNodeProviderChain(),
})
```

Provider 函数仅适用于 `S3Filesystem` API 调用。将文件系统挂载到 E2B Sandbox 时，挂载配置仅支持静态的 `accessKeyId`、`secretAccessKey` 和 `sessionToken` 值，因此凭证刷新必须在挂载外部处理。

### Cloudflare R2 {/* #cloudflare-r2 */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'my-r2-bucket',
  region: 'auto',
  endpoint: `https://${process.env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com`,
  accessKeyId: process.env.R2_ACCESS_KEY_ID,
  secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
})
```

### MinIO {/* #minio */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'us-east-1',
  endpoint: 'http://localhost:9000',
  accessKeyId: 'minioadmin',
  secretAccessKey: 'minioadmin',
})
```

### Tigris {/* #tigris */}

```typescript
import { S3Filesystem } from '@mastra/s3'

const filesystem = new S3Filesystem({
  bucket: 'my-bucket',
  region: 'auto',
  endpoint: 'https://t3.storage.dev',
  accessKeyId: process.env.TIGRIS_ACCESS_KEY_ID,
  secretAccessKey: process.env.TIGRIS_SECRET_ACCESS_KEY,
  forcePathStyle: false,
})
```

Tigris 使用虚拟主机样式寻址，因此必须将 `forcePathStyle` 设置为 `false`（提供自定义端点时，默认为 `true`）。请从 [Tigris Dashboard](https://console.tigris.dev/) 创建凭证。访问密钥以 `tid_` 为前缀，机密以 `tsec_` 为前缀。

## 方法 {/* #methods */}

S3Filesystem 实现了 [WorkspaceFilesystem 接口](/reference/workspace/filesystem)，提供所有标准文件系统方法：

- `readFile(path, options?)` - 读取文件内容
- `writeFile(path, content, options?)` - 将内容写入文件
- `appendFile(path, content)` - 将内容追加到文件
- `deleteFile(path, options?)` - 删除文件
- `copyFile(src, dest, options?)` - 复制文件
- `moveFile(src, dest, options?)` - 移动文件或重命名
- `mkdir(path, options?)` - 创建目录
- `rmdir(path, options?)` - 删除目录
- `readdir(path, options?)` - 列出目录内容
- `exists(path)` - 检查路径是否存在
- `stat(path)` - 获取文件或目录元数据

### `init()` {/* #init */}

初始化文件系统。验证存储桶访问权限和凭证。

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

返回有关此文件系统实例的元数据。

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'S3Filesystem', provider: 's3', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

返回支持挂载此文件系统类型的 Sandbox 所需的挂载配置。

```typescript
const config = filesystem.getMountConfig()
// { type: 's3', bucket: 'my-bucket', region: 'us-east-1', ... }
```

## 挂载到 E2B Sandbox {/* #mounting-in-e2b-sandboxes */}

可以将 S3Filesystem 挂载到 E2B Sandbox，使存储桶能以本地目录的形式访问：

```typescript
import { Workspace } from '@mastra/core/workspace'
import { S3Filesystem } from '@mastra/s3'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new S3Filesystem({
      bucket: 'my-bucket',
      region: 'us-east-1',
      accessKeyId: process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

有关挂载的更多详细信息，请参阅 [E2BSandbox 参考文档](/reference/workspace/e2b-sandbox)。
