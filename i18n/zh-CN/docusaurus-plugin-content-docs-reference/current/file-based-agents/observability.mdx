# Observability

Mastra 通过 `src/mastra/` 目录下的 `observability.ts` 文件配置[可观测性](/docs/observability/overview)。该文件默认导出一个 `Observability` 实例，为项目设置 tracing、日志记录、指标和反馈。

本页介绍基于文件的约定。有关信号模型、exporter、storage 和多配置设置，请参阅[可观测性概览](/docs/observability/overview)和[可观测性配置](/docs/observability/overview#configuration)。

## 快速开始

创建 `src/mastra/observability.ts` 并默认导出一个 `Observability` 实例：

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability 与 storage

`observability.ts` 配置要收集哪些信号以及将它们导出到何处。[`storage.ts`](/reference/file-based-agents/storage) 配置可持久化可观测性记录的项目 store。有关各类信号的 storage 支持情况，请参阅[可观测性信号支持](/docs/observability/overview#signal-support)。

## 与代码配置的优先级

代码中注册的 observability 优先于 `observability.ts`。当一个项目级配置足以满足需求时，请使用 `observability.ts`；当设置依赖 `src/mastra/index.ts` 中的运行时连接时，请使用代码注册。
