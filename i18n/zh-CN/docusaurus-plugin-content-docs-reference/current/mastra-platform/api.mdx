# API 参考

## 成员 API

以下端点的根 URL 为：`/v1/org/members`

| 方法 | 端点 | 描述 |
| - | - | - |
| GET | `/` | 列出成员 |
| POST | `/invitations` | 发送邀请 |
| GET | `/invitations` | 列出邀请 |
| DELETE | `/invitations/:id` | 撤销邀请 |
| PATCH | `/:id` | 更新成员角色 |
| DELETE | `/:id` | 移除成员 |

## API token

以下端点的根 URL 为：`/v1/auth/tokens`

| 方法 | 端点 | 描述 |
| - | - | - |
| POST | `/` | 创建 API token |
| GET | `/` | 列出 API token |
| DELETE | `/:id` | 删除 API token |

## Studio API

以下端点的根 URL 为：`/v1/studio`

| 方法 | 端点 | 描述 |
| - | - | - |
| GET | `/projects` | 列出 Studio 项目 |
| POST | `/projects` | 创建项目 |
| GET | `/projects/:id` | 获取项目详情和部署记录 |
| DELETE | `/projects/:id` | 删除项目 |
| POST | `/deploys` | 创建部署 |
| POST | `/deploys/:id/upload-complete` | 确认制品上传完成 |
| GET | `/deploys/:id` | 获取部署状态 |
| GET | `/deploys/:id/logs` | 获取部署日志 |
| GET | `/deploys/:id/logs/stream` | 流式传输部署日志（SSE） |

## Server API

以下端点的根 URL 为：`/v1/server`

| 方法 | 端点 | 描述 |
| - | - | - |
| GET | `/projects` | 列出 server 项目 |
| POST | `/projects` | 创建项目 |
| GET | `/projects/:id` | 获取项目详情 |
| DELETE | `/projects/:id` | 删除项目 |
| PUT | `/projects/:id/env` | 设置环境变量 |
| GET | `/projects/:id/env` | 获取环境变量 |
| POST | `/projects/:id/env/restart` | 环境变量变更后重启 |
| GET | `/projects/:id/domains` | 列出域名 |
| POST | `/projects/:id/domains` | 添加自定义域名 |
| GET | `/projects/:id/runtime-logs` | 获取运行时日志 |
| POST | `/projects/:id/redeploy` | 触发重新部署 |
| POST | `/projects/:id/always-on` | 启用 always-on |
| DELETE | `/projects/:id/always-on` | 禁用 always-on |
| POST | `/deploys` | 创建部署 |
| POST | `/deploys/:id/upload-complete` | 确认制品上传完成 |
| GET | `/deploys/:id` | 获取部署状态 |
| GET | `/deploys/:id/logs` | 获取部署日志 |
| POST | `/deploys/:id/cancel` | 取消排队中或进行中的部署 |
| DELETE | `/deploys/:id` | 停止运行中的部署 |

## Gateway API

以下端点的根 URL 为：`/v1/gateway`

| 方法 | 端点 | 描述 |
| - | - | - |
| GET | `/projects` | 列出 Gateway 项目 |
| GET | `/projects/:id` | 获取项目详情 |
| PATCH | `/projects/:id` | 更新项目设置 |
| DELETE | `/projects/:id` | 删除项目 |
| POST | `/projects/provision` | 配置新的 Gateway 项目 |
| GET | `/projects/:id/keys` | 列出 API key |
| POST | `/projects/:id/keys` | 创建 API key |
| DELETE | `/projects/:id/keys/:keyId` | 撤销 API key |
| GET | `/projects/:id/keys/:keyId/bindings` | 列出 key 级 Provider 绑定 |
| POST | `/projects/:id/keys/:keyId/bindings` | 添加 key 级 Provider 绑定（BYOK） |
| DELETE | `/projects/:id/keys/:keyId/bindings/:provider` | 移除 key 级绑定 |
| GET | `/projects/:id/bindings` | 列出项目级 Provider 绑定 |
| POST | `/projects/:id/bindings` | 添加项目级 Provider 绑定（BYOK） |
| DELETE | `/projects/:id/bindings/:provider` | 移除项目级绑定 |
| GET | `/projects/:id/usage/has-activity` | 检查项目是否收到过请求 |
| GET | `/projects/:id/usage/activity` | 获取汇总的用量活动 |
| GET | `/projects/:id/usage/memory-activity` | 获取某一时间范围内的 memory token 总数 |
| GET | `/projects/:id/usage/logs` | 获取请求日志 |
| GET | `/projects/:id/usage/logs/facets` | 获取日志筛选分面 |
| GET | `/projects/:id/usage/logs/:requestId` | 获取指定请求的详情 |
| GET | `/projects/:id/memory/threads` | 列出 thread（dashboard） |
| POST | `/projects/:id/memory/threads` | 创建 thread（dashboard） |
| GET | `/projects/:id/memory/threads/:threadId` | 获取 thread（dashboard） |
| PATCH | `/projects/:id/memory/threads/:threadId` | 更新 thread（dashboard） |
| DELETE | `/projects/:id/memory/threads/:threadId` | 删除 thread（dashboard） |
| POST | `/projects/:id/memory/threads/:threadId/clone` | 克隆 thread（dashboard） |
| GET | `/projects/:id/memory/threads/:threadId/messages` | 列出消息（dashboard） |
| POST | `/projects/:id/memory/threads/:threadId/messages` | 保存消息（dashboard） |
| DELETE | `/projects/:id/memory/threads/:threadId/messages` | 删除消息（dashboard） |
| GET | `/projects/:id/memory/threads/:threadId/observations/history` | 观察历史记录（dashboard） |
| GET | `/models` | 列出可用模型 |
