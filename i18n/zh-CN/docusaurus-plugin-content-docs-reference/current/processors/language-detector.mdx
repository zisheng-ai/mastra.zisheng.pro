# LanguageDetector

`LanguageDetector` 是一个**输入 Processor**，用于识别输入文本的语言，并可选择将其翻译为目标语言，以便统一处理。此 Processor 通过检测传入消息的语言，并提供灵活的多语言内容处理策略来帮助保持语言一致性，其中包括自动翻译，以确保所有内容都使用目标语言进行处理。

## 用法示例

```typescript
import { LanguageDetector } from '@mastra/core/processors'

const processor = new LanguageDetector({
  model: 'openrouter/openai/gpt-oss-safeguard-20b',
  targetLanguages: ['English', 'en'],
  threshold: 0.8,
  strategy: 'translate',
  lastMessageOnly: true,
})
```

## 扩展用法示例

```typescript title="src/mastra/agents/multilingual-agent.ts"
import { Agent } from '@mastra/core/agent'
import { LanguageDetector } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'multilingual-agent',
  name: 'multilingual-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new LanguageDetector({
      model: 'openrouter/openai/gpt-oss-safeguard-20b',
      targetLanguages: ['English', 'en'],
      threshold: 0.8,
      strategy: 'translate',
      preserveOriginal: true,
      instructions:
        'Detect language and translate non-English content to English while preserving original intent',
      minTextLength: 10,
      includeDetectionDetails: true,
      translationQuality: 'quality',
    }),
  ],
})
```
