# MessageHistory

`MessageHistory` 是一个**混合 Processor**，负责消息历史的检索和持久化。处理输入时，它从存储中获取历史消息，并将其添加到对话开头。处理输出时，它将新消息持久化到存储中。

## 用法示例 {/* #usage-example */}

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
})
```

## 扩展用法示例 {/* #extended-usage-example */}

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStorage } from '@mastra/pg'

const storage = new PostgresStorage({
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
    }),
  ],
})
```

## 行为 {/* #behavior */}

### 输入处理 {/* #input-processing */}

1. 从 request context 中检索 `threadId`
1. 从存储中获取历史消息（按创建日期降序排列）
1. 筛除 system 消息（它们不应存储在数据库中）
1. 将历史消息与传入消息合并，并按 ID 避免重复
1. 为历史消息添加 `source: 'memory'` 标签

### 输出处理 {/* #output-processing */}

1. 从 request context 中检索 `threadId`
1. 如果 memory 配置中设置了 `readOnly`，则跳过持久化
1. 从消息中筛除未完成的 Tool 调用
1. 将新的用户输入和 assistant 响应消息持久化到存储中
1. 更新线程的 `updatedAt` 时间戳
