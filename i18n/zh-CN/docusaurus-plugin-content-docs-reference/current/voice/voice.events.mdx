# Voice 事件

Voice Provider 会在实时 Voice 交互期间发出事件。可以使用 [voice.on()](./voice.on) 方法监听这些事件；在构建交互式 Voice 应用时，它们尤其重要。

## 注意事项 {/* #notes */}

- 并非所有 Voice Provider 都支持全部事件
- payload 的确切结构可能因 Provider 而异
- 对于非实时 Provider，大多数此类事件不会发出
- 事件有助于构建能响应对话状态的交互式 UI
- 不再需要事件监听器时，建议使用 [voice.off()](./voice.off) 方法将其移除
