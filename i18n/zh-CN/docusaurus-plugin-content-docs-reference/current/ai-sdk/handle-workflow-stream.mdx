# handleWorkflowStream()

与框架无关的处理程序，用于以 AI SDK 兼容格式流式传输 Workflow 执行。当需要在 Hono 或 Mastra 自有的 [apiRoutes](/docs/server/custom-api-routes) 功能之外处理 Workflow stream 时，请直接使用此函数。

`handleWorkflowStream()` 返回一个 `ReadableStream`，可使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 对其进行封装。

`handleWorkflowStream()` 保留现有的 AI SDK v5 默认行为。如果应用使用 AI SDK v6 类型，请传入 `version: 'v6'`。

如果要在 Mastra server 中创建 Workflow 路由，请使用 [`workflowRoute()`](/reference/ai-sdk/workflow-route)。

:::tip Workflow 中的 Agent 流式传输

当 Workflow step 将 Agent stream pipe 到 Workflow writer（例如 `await response.fullStream.pipeTo(writer)`）时，即使 Agent 在 Workflow step 内运行，其文本 chunk 和 Tool 调用也会实时转发到 UI stream。

详情请参阅 [Workflow 流式传输](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用示例

Next.js App Router 示例：

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
