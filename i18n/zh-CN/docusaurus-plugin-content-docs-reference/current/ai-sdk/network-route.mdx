# networkRoute()

:::warning[已弃用]

Agent network 已弃用，并将在未来版本中移除。请改用搭配 `agent.stream()` 或 `agent.generate()` 的 [supervisor Agent](/docs/capabilities/subagents)。升级方法请参阅[迁移指南](/guides/migrations/network-to-supervisor)。

:::

创建使用 AI SDK 格式流式传输 network 执行的路由处理程序。此函数会注册一个 HTTP `POST` endpoint，用于接收消息、执行 Agent network，并以 AI SDK 兼容格式将响应流式传回客户端。Agent network 允许路由 Agent 将任务委派给其他 Agent。必须在[自定义 API 路由](/docs/server/custom-api-routes)中使用它。

如果需要与框架无关的处理程序，请使用 [`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream)。

`networkRoute()` 保留现有的 AI SDK v5 默认行为。如果应用使用 AI SDK v6 类型，请传入 `version: 'v6'`。

## 使用示例 {/* #usage-example */}

此示例展示如何在 `/network` endpoint 设置 network 路由，并使用 ID 为 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

也可以根据 `agentId` 使用运行时定义的 Agent 路由。URL `/network/weatherAgent` 将解析为 ID 为 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 其他配置 {/* #additional-configuration */}

可以使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自定义发送到 network 路由的请求，例如向 Agent 传递其他配置：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
