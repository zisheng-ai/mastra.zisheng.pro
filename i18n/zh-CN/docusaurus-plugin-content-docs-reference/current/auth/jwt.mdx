# MastraJwtAuth 类

`MastraJwtAuth` 类使用 JSON Web Token（JWT）为 Mastra 提供轻量级身份验证机制。它基于共享密钥验证传入请求，并通过 `auth` 选项与 Mastra server 集成。

## 使用示例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```
