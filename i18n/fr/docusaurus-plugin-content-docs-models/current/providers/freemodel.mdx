Accédez à 10 modèles FreeModel via le routeur de modèles de Mastra. L’authentification est gérée automatiquement à l’aide de la variable d’environnement `FREEMODEL_API_KEY`.

Pour en savoir plus, consultez la [documentation FreeModel](https://freemodel.dev).

```bash title=".env"
FREEMODEL_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "freemodel/claude-fable-5"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "freemodel/gpt-5.5"

  }
});
