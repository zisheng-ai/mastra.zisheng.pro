Accédez à 2 modèles Modal via le routeur de modèles de Mastra. L’authentification est gérée automatiquement à l’aide de la variable d’environnement `MODAL_PROXY_TOKEN`.

Pour en savoir plus, consultez la [documentation Modal](https://modal.com/docs/guide/endpoints).

```bash title=".env"
MODAL_PROXY_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "modal/moonshotai/Kimi-K3"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```
