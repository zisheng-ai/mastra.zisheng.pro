# <img src="https://models.dev/logos/synthetic.svg" alt="Synthetic logo" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Synthetic

Accédez à 8 modèles Synthetic via le routeur de modèles de Mastra. L’authentification est gérée automatiquement à l’aide de la variable d’environnement `SYNTHETIC_API_KEY`.

Pour en savoir plus, consultez la [documentation Synthetic](https://synthetic.new/pricing).

```bash title=".env"
SYNTHETIC_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "synthetic/hf:MiniMaxAI/MiniMax-M3"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra utilise le point de terminaison `/chat/completions` compatible avec OpenAI. Certaines fonctionnalités propres au Provider peuvent ne pas être disponibles. Consultez la [documentation Synthetic](https://synthetic.new/pricing) pour plus de détails.

:::

  name: "Dynamic Agent",
  model: ({ requestContext }) => {

    return useAdvanced
      ? "synthetic/hf:zai-org/GLM-5.2"

  }
});
