# <img src="https://mastra.ai/brand/logo.svg" alt="Mastra logo" className="inline w-8 h-8 mr-2 align-middle invert dark:invert-0" />Mastra

La Gateway est un proxy d’API compatible OpenAI qui intègre la [mémoire observationnelle](https://gateway.mastra.ai/docs/features#observational-memory). Dirigez n’importe quel client HTTP, SDK ou framework vers la passerelle, et chaque conversation est mémorisée automatiquement sans code de gestion de la mémoire.

Pour en savoir plus, consultez la [documentation Gateway](https://gateway.mastra.ai/docs).

## Obtenir une clé API {/* #get-an-api-key */}

Accédez à [gateway.mastra.ai](https://gateway.mastra.ai) et créez un compte Mastra. Lors de l’intégration, vous recevrez votre clé API personnelle pour authentifier vos requêtes.

## Utilisation {/* #usage */}

Définissez votre clé API comme variable d’environnement :

```bash title=".env"
MASTRA_GATEWAY_API_KEY=your-gateway-key
```

Définissez l’ID de votre modèle de passerelle :

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "mastra/openai/gpt-5-mini"
});
```

Utilisez le même préfixe pour les modèles d’embedding qui doivent passer par la passerelle :

```typescript title="src/mastra/rag/embed.ts"
import { ModelRouterEmbeddingModel } from "@mastra/core/llm";

const embedder = new ModelRouterEmbeddingModel("mastra/__GATEWAY_OPENAI_EMBEDDING_MODEL__");
```

Transmettez `memory.thread` et `memory.resource` lorsque vous générez ou streamez des réponses pour activer la mémoire observationnelle :

```typescript title="src/mastra/run.ts"
import { weatherAgent } from "./agents/weather-agent";

const memory = {
  thread: "assistant-thread-1",
  resource: "user-42",
};

const result = await weatherAgent.stream("My name is Alex and I prefer concise answers.", {
  memory,
});

for await (const chunk of result.textStream) {
  process.stdout.write(chunk);
}
```
