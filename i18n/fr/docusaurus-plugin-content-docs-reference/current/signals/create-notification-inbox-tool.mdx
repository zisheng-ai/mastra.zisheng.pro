# createNotificationInboxTool()

**Ajouté dans :** `@mastra/core@1.39.0`

`createNotificationInboxTool()` crée un Tool Mastra qui permet à un Agent d’inspecter et de gérer les enregistrements de la boîte de réception de notifications du fil de discussion actuel.

Utilisez ce Tool avec des Signals de notification durables. Pour envoyer des enregistrements de notification, consultez [`Agent.sendNotificationSignal()`](/reference/agents/agent#sendnotificationsignalnotification-options).

## Exemple d’utilisation {/* #usage-example */}

L’exemple suivant ajoute le Tool de boîte de réception à un Agent.

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createNotificationInboxTool } from '@mastra/core/notifications'

const notificationsStorage = await storage.getStore('notifications')

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Help the user triage updates.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: {
    notificationInbox: createNotificationInboxTool({ storage: notificationsStorage }),
  },
})
```

## Actions {/* #actions */}

| Action | Description |
| - | - |
| `list` | Renvoie les notifications correspondantes. |
| `read` | Transmet le contenu lisible des notifications sous forme de Signals et marque les enregistrements distribués comme vus. |
| `markSeen` | Marque une notification comme vue. |
| `dismiss` | Marque une notification comme ignorée. |
| `archive` | Marque une notification comme archivée. |
| `search` | Recherche des notifications selon une requête et des filtres facultatifs. |

Lorsque `read` trouve des notifications en attente ou distribuées, le Tool transmet leur contenu sous forme de Signals de notification au lieu de renvoyer leur contenu intégral comme une sortie de Tool normale. Utilisez cette action après un Signal `<notification-summary>` lorsque l’Agent a besoin des enregistrements complets à l’origine du récapitulatif.
