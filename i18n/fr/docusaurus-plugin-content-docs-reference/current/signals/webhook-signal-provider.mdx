# WebhookSignalProvider

**Ajouté dans :** `@mastra/core@1.39.0`

Provider de Signal concret pour la distribution d'événements par envoi push. Achemine les charges utiles des webhooks entrants vers les threads d'Agent abonnés en recherchant une correspondance au moyen d'un extracteur configurable d'identifiant de ressource.

Étend [`SignalProvider`](/reference/signals/signal-provider) avec une gestion publique des abonnements et une implémentation intégrée de `handleWebhook()`.

## Exemple d'utilisation {/* #usage-example */}

Acheminez les événements des webhooks GitHub vers les threads abonnés :

```typescript title="src/signals/webhook.ts"
import { WebhookSignalProvider } from '@mastra/core/signals'

const webhookProvider = new WebhookSignalProvider({
  extractResourceId: payload => `${payload.repository?.full_name}`,
  buildNotification: (payload, subscription) => ({
    source: 'github-webhook',
    kind: payload.action ?? 'event',
    summary: `${payload.action} on ${subscription.externalResourceId}`,
    payload,
  }),
})
```

Enregistrez le Provider auprès d'un Agent et abonnez un thread :

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'agent',
  signals: [webhookProvider],
})

// subscribe a thread to a specific repo
webhookProvider.subscribeThread({ threadId: 'thread-1', resourceId: 'user-1' }, 'mastra-ai/mastra')

// handle an incoming webhook
const result = await webhookProvider.handleWebhook({
  body: { repository: { full_name: 'mastra-ai/mastra' }, action: 'push' },
  headers: {},
})
// result.matched === 1
```

## Méthodes {/* #methods */}

### Gestion des abonnements {/* #subscription-management */}

#### `subscribeThread(target, externalResourceId, metadata?)` {/* #subscribethreadtarget-externalresourceid-metadata */}

Abonne un thread aux événements des webhooks d'une ressource externe précise.

```typescript prettier:false
webhookProvider.subscribeThread(
  { threadId: 'thread-1', resourceId: 'user-1' },
  'mastra-ai/mastra',
  { watchType: 'push' },
)
```

Renvoie : `SignalSubscription`

#### `unsubscribeThread(target, externalResourceId)` {/* #unsubscribethreadtarget-externalresourceid */}

Désabonne un thread d'une ressource externe précise.

```typescript prettier:false
const removed = webhookProvider.unsubscribeThread(
  { threadId: 'thread-1', resourceId: 'user-1' },

```

Renvoie : `boolean`

### Gestion des webhooks {/* #webhook-handling */}

#### `handleWebhook(request)` {/* #handlewebhookrequest */}

Traite une requête de webhook entrante. Extrait l'identifiant de ressource de la charge utile, recherche les abonnements correspondants, construit une notification pour chacun, puis appelle `notify()`.

```typescript prettier:false
const result = await webhookProvider.handleWebhook({
  body: { repository: { full_name: 'mastra-ai/mastra' }, action: 'push' },
  headers: { 'x-github-event': 'push' },
})
```

Renvoie : `Promise<{ status: number; body: { matched: number } }>`

Renvoie `{ status: 200, body: { matched: N } }`, où `N` correspond au nombre d'abonnements qui ont reçu des notifications. Renvoie `matched: 0` lorsqu'aucun identifiant de ressource n'a pu être extrait ou qu'aucun abonnement ne correspond.

### Fabriques de Signals statiques {/* #static-signal-factories */}

#### `WebhookSignalProvider.signals.subscribe(externalResourceId)` {/* #webhooksignalprovidersignalssubscribeexternalresourceid */}

Crée une entrée de Signal réactive qui abonne le thread actuel à une ressource externe.

```typescript prettier:false
const signal = WebhookSignalProvider.signals.subscribe('mastra-ai/mastra')
```

Renvoie : `{ type: 'reactive'; tagName: string; contents: string; attributes: { resource: string } }`

#### `WebhookSignalProvider.signals.unsubscribe(externalResourceId)` {/* #webhooksignalprovidersignalsunsubscribeexternalresourceid */}

Crée une entrée de Signal réactive qui désabonne le thread actuel d'une ressource externe.

```typescript prettier:false
const signal = WebhookSignalProvider.signals.unsubscribe('mastra-ai/mastra')
```

Renvoie : `{ type: 'reactive'; tagName: string; contents: string; attributes: { resource: string } }`
