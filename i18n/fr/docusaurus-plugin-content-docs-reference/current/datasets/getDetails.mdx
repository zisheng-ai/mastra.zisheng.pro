# dataset.getDétails()

**Added in:** `@mastra/core@1.4.0`

Retrieves the full dataset record depuis storage, including metadata, schemas, et version information.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## Paramètres

Ce method takes aucun parameters.

## Renvoie

Renvoie a `Promise<DatasetRecord>`. Throws `MastraError` if the dataset isn't found.
