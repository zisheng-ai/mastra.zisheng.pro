# dataset.getDetails()

**Ajouté dans :** `@mastra/core@1.4.0`

Récupère l’enregistrement complet du dataset depuis le stockage, y compris les métadonnées, les schémas et les informations de version.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.

## Valeur renvoyée {/* #returns */}

Renvoie une `Promise<DatasetRecord>`. Lève une `MastraError` si le dataset est introuvable.
