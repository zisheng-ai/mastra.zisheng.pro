# Jeu de données class

**Added in:** `@mastra/core@1.4.0`

The `Dataset` class provides methods pour item CRUD, versioning, et experiment management sur a unique dataset. Obtained via `mastra.datasets.get()` ou `mastra.datasets.create()`.

## Exemples d’utilisation

### Ajouter items et exécute an experiment

```typescript title="src/mastra/datasets/usage.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.create({
  name: 'QA pairs',
})

// Add items
await dataset.addItems({
  items: [
    { input: { question: 'What is AI?' }, groundTruth: { answer: 'Artificial Intelligence' } },
    { input: { question: 'What is ML?' }, groundTruth: { answer: 'Machine Learning' } },
  ],
})

// Run an experiment
const summary = await dataset.startExperiment({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`${summary.succeededCount}/${summary.totalItems} succeeded`)
```

### Gérer versions et history

```typescript title="src/mastra/datasets/versioning.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// List versions
const { versions } = await dataset.listVersions()

// List items at a specific version
const items = await dataset.listItems({ version: 2 })

// Get item change history
const history = await dataset.getItemHistory({ itemId: 'item-id' })
```

## Access

`Dataset` isn't instantiated directly. Obtain un via `DatasetsManager`:

```typescript
const dataset = await mastra.datasets.get({ id: 'dataset-id' })
// or
const dataset = await mastra.datasets.create({ name: 'My dataset' })
```
