# dataset.getItemHistory()

**Ajouté dans :** `@mastra/core@1.4.0`

Récupère l’historique complet SCD-2 (dimension à variation lente de type 2) d’un élément précis dans toutes les versions du dataset.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

const history = await dataset.getItemHistory({ itemId: 'item-id' })

for (const row of history) {
  console.log(`Version ${row.datasetVersion}: ${row.isDeleted ? 'deleted' : 'active'}`)
}
```
