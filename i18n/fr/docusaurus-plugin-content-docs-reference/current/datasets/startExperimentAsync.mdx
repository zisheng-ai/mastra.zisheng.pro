# dataset.startExperimentAsync()

**Added in:** `@mastra/core@1.4.0`

Démarre an experiment asynchronously (fire-and-forget). Renvoie immediately avec the experiment ID et a `'pending'` status. The experiment runs dans the background.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
console.log(`Current status: ${experiment.status}`)
```

## Paramètres

Takes the same `StartExperimentConfig` comme [dataset.startExperiment()](/reference/datasets/startExperiment).

When `persistence.experiments` est définit à `'none'`, `startExperimentAsync()` doesn't persist an experiment record, progress updates, ou item results. Score persistence remains controlled separately par `persistence.scores`. Without an experiment event observer, the exécute est fire-and-forget, et the experiment API can't report whether it completed ou failed.

Use synchronous [dataset.startExperiment()](/reference/datasets/startExperiment) when the caller needs the returned summary. Un experiment event observer peut reçoit lifecycle events et the terminal summary.
