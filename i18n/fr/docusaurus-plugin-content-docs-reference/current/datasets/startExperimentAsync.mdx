# dataset.startExperimentAsync()

**Ajouté dans :** `@mastra/core@1.4.0`

Démarre une expérience de manière asynchrone (fire-and-forget). Renvoie immédiatement l’ID de l’expérience et le statut `'pending'`. L’expérience s’exécute en arrière-plan.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Start experiment without waiting
const { experimentId, status } = await dataset.startExperimentAsync({
  targetType: 'agent',
  targetId: 'my-agent',
  scorers: ['accuracy'],
})

console.log(`Experiment ${experimentId} started with status: ${status}`)

// Check progress later
const experiment = await dataset.getExperiment({ experimentId })
console.log(`Current status: ${experiment.status}`)
```

## Paramètres

Accepte le même `StartExperimentConfig` que [`dataset.startExperiment()`](/reference/datasets/startExperiment).

Lorsque `persistence.experiments` vaut `'none'`, `startExperimentAsync()` ne persiste ni enregistrement d’expérience, ni mises à jour de progression, ni résultats d’éléments. La persistance des scores reste contrôlée séparément par `persistence.scores`. Sans observateur d’événements d’expérience, l’exécution est fire-and-forget et l’API d’expérience ne peut pas indiquer si elle a réussi ou échoué.

Utilisez [`startExperiment()`](/reference/datasets/startExperiment) de manière synchrone lorsque l’appelant a besoin du résumé renvoyé. Un observateur d’événements d’expérience peut recevoir les événements de cycle de vie et le résumé final.
