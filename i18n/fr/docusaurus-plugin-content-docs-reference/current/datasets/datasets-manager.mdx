# DatasetsManager

**Ajouté dans :** `@mastra/core@1.4.0`

La classe `DatasetsManager` fournit l'API publique de gestion des datasets, notamment les opérations CRUD et les comparaisons d'expériences entre plusieurs datasets. Vous y accédez via `mastra.datasets`.

## Exemples d'utilisation {/* #usage-examples */}

### Créer et répertorier des datasets {/* #create-and-list-datasets */}

```typescript title="src/mastra/datasets/manage.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Create a dataset
const dataset = await mastra.datasets.create({
  name: 'QA pairs',
  description: 'Question-answer evaluation set',
})

// List all datasets
const { datasets } = await mastra.datasets.list()
```

### Récupérer et supprimer un dataset {/* #get-and-delete-a-dataset */}

```typescript title="src/mastra/datasets/get-delete.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Get by ID
const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Delete by ID
await mastra.datasets.delete({ id: 'dataset-id' })
```

### Récupérer une expérience {/* #get-experiment */}

Récupère une expérience (un run) précise par son ID. Contrairement à `dataset.getExperiment()`, cette méthode fonctionne sur l'ensemble des datasets sans qu'il soit nécessaire d'obtenir d'abord une référence à un dataset.

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

// Get experiment directly without knowing the dataset
const experiment = await mastra.datasets.getExperiment({
  experimentId: 'exp-id',
})

console.log(`Dataset: ${experiment.datasetId}`)
console.log(`Status: ${experiment.status}`)
```

### Comparer des expériences {/* #compare-experiments */}

```typescript title="src/mastra/datasets/compare.ts"
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const comparison = await mastra.datasets.compareExperiments({
  experimentIds: ['exp-1', 'exp-2'],
  baselineId: 'exp-1',
})
```

## Accès {/* #access */}

`DatasetsManager` n'est pas instancié directement. Accédez-y depuis une instance de `Mastra` :

```typescript
const mastra = new Mastra({/* storage config */})
const datasetsManager = mastra.datasets
```
