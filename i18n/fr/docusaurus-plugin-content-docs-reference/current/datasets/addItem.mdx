# dataset.addItem()

**Added in:** `@mastra/core@1.4.0`

Ajoute a unique item à the dataset. Chaque item possède an input et facultatif ground truth. Metadata est also optional.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

const item = await dataset.addItem({
  input: { question: 'What is TypeScript?' },
  groundTruth: { answer: 'A typed superset of JavaScript' },
  metadata: { source: 'manual' },
})

console.log(item.id)
```
