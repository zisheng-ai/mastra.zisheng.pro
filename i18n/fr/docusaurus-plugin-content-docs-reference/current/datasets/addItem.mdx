# dataset.addItem()

**Ajouté dans :** `@mastra/core@1.4.0`

Ajoute un seul élément au dataset. Chaque élément possède des données d’entrée et peut comporter une vérité terrain. Les métadonnées sont également facultatives.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

const item = await dataset.addItem({
  input: { question: 'What is TypeScript?' },
  groundTruth: { answer: 'A typed superset of JavaScript' },
  metadata: { source: 'manual' },
})

console.log(item.id)
```
