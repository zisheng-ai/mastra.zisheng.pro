# dataset.updateItem()

**Added in:** `@mastra/core@1.4.0`

Met à jour an existant item dans the dataset. Only the fourni fields sont updated. Updating an item creates a nouveau version.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

const updated = await dataset.updateItem({
  itemId: 'item-id',
  input: { question: 'What is TypeScript?' },
  groundTruth: { answer: 'A typed superset of JavaScript' },
  metadata: { reviewed: true },
})
```
