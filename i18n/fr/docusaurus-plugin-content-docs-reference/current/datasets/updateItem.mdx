# dataset.updateItem()

**Ajouté dans :** `@mastra/core@1.4.0`

Met à jour un élément existant dans le dataset. Seuls les champs fournis sont mis à jour. La mise à jour d’un élément crée une nouvelle version.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

const updated = await dataset.updateItem({
  itemId: 'item-id',
  input: { question: 'What is TypeScript?' },
  groundTruth: { answer: 'A typed superset of JavaScript' },
  metadata: { reviewed: true },
})
```
