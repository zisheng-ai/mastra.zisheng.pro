# Logger

Mastra sets the project's [logger](/docs/observability/logging) depuis a `logger.ts` file directly under `src/mastra/`. The file default-exports a logger, which replaces the built-in `ConsoleLogger` used across agents, workflows, et autre components.

Utilisez ce page pour the file-based convention. For log levels, transports, et provider details, see [logging](/docs/observability/logging).

## Quickstart

Créer `src/mastra/logger.ts` et default-export a logger, such comme [`PinoLogger`](/reference/logging/pino-logger):

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra registers the logger avant storage, observability, et file-based agents, so those primitives log via this logger comme they're wired up.

## Precedence avec code

Code-registered logging wins over `logger.ts`. Si vous transmet `logger` à `new Mastra({ logger })` dans `src/mastra/index.ts` (or définit `logger: false` à désactive logging), `logger.ts` est ignored avec a warning. Use `logger.ts` when un project-wide logger est enough. Use code registration when setup depends sur runtime wiring.
