# Observability

Mastra configures [observability](/docs/observability/overview) depuis an `observability.ts` file directly under `src/mastra/`. The file default-exports an `Observability` instance that sets up tracing, logging, metrics, et feedback pour the project.

Utilisez ce page pour the file-based convention. For the signal model, exporters, storage, et multi-config setup, see the [observability overview](/docs/observability/overview) et [observability configuration](/docs/observability/overview#configuration).

## Quickstart

Créer `src/mastra/observability.ts` et default-export an `Observability` instance:

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observability et storage

`observability.ts` configures which signals sont collected et where they're exported. [`storage.ts`](/reference/file-based-agents/storage) configures the project store that peut persist observability records. For storage support par signal, see [observability signal support](/docs/observability/overview#signal-support).

## Precedence avec code

Code-registered observability wins over `observability.ts`. Use `observability.ts` when un project-wide configuration est enough. Use code registration when setup depends sur runtime wiring dans `src/mastra/index.ts`.
