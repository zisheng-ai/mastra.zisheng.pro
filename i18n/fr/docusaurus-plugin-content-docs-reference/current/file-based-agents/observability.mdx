# Observability

Mastra configure l’[observabilité](/docs/observability/overview) à partir d’un fichier `observability.ts` placé directement dans `src/mastra/`. Le fichier exporte par défaut une instance `Observability` qui configure le traçage, la journalisation, les métriques et les retours pour le projet.

Utilisez cette page pour la convention basée sur les fichiers. Pour le modèle de signaux, les exportateurs, le stockage et la configuration multiple, consultez la [présentation de l’observabilité](/docs/observability/overview) et la [configuration de l’observabilité](/docs/observability/overview#configuration).

## Démarrage rapide {/* #quickstart */}

Créez `src/mastra/observability.ts` et exportez par défaut une instance `Observability` :

```typescript title="src/mastra/observability.ts"
import { MastraStorageExporter, Observability } from '@mastra/observability'

export default new Observability({
  configs: {
    default: {
      serviceName: 'mastra',
      exporters: [new MastraStorageExporter()],
    },
  },
})
```

## Observabilité et stockage {/* #observability-and-storage */}

`observability.ts` configure les signaux collectés et leur destination d’exportation. [`storage.ts`](/reference/file-based-agents/storage) configure le magasin du projet qui peut conserver les enregistrements d’observabilité. Pour la prise en charge du stockage par signal, consultez la [prise en charge des signaux d’observabilité](/docs/observability/overview#signal-support).

## Priorité du code {/* #precedence-with-code */}

L’observabilité enregistrée dans le code est prioritaire sur `observability.ts`. Utilisez `observability.ts` lorsqu’une seule configuration à l’échelle du projet suffit. Utilisez l’enregistrement dans le code lorsque la configuration dépend du câblage au moment de l’exécution dans `src/mastra/index.ts`.
