# Processors

Un Agent basé sur des fichiers découvre les [Processors](/docs/agents/processors) dans son répertoire `processors/`. Utilisez cette page pour la convention basée sur les fichiers ; consultez le guide des Processors pour les Processors intégrés, les Processors personnalisés, le comportement de streaming et les modèles avancés.

Les fichiers dans `processors/input/` s’exécutent avant que les messages atteignent le modèle. Les fichiers dans `processors/output/` s’exécutent après la réponse du modèle. Chaque fichier exporte par défaut un [`Processor`](/reference/processors/processor-interface) et le nom du fichier devient sa clé de découverte.

## Démarrage rapide

Ajoutez un Processor d’entrée en plaçant un fichier de Processor dans `processors/input/` :

```typescript title="src/mastra/agents/weather/processors/input/pii.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'block',
})
```

Ce Processor s’exécute avant que les messages utilisateur atteignent le modèle.

## Ajouter un Processor de sortie

Les Processors de sortie permettent de filtrer ou de transformer les réponses du modèle avant leur renvoi. Cet exemple masque les PII de la réponse finale.

```typescript title="src/mastra/agents/weather/processors/output/redact.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'redact',
})
```

## Ordre d’exécution

Les Processors découverts sont ajoutés après ceux définis dans [`config.ts`](/reference/file-based-agents/config). Les Processors de config s’exécutent donc d’abord.

```text title="Ordering"
config.inputProcessors → processors/input/* → model
model → config.outputProcessors → processors/output/* → response
```

Si `config.inputProcessors` ou `config.outputProcessors` est une fonction, les Processors découverts de ce type sont ignorés avec un avertissement, car les Processors définis par une fonction ne peuvent pas être fusionnés statiquement.

## Priorité par rapport à config

Utilisez `config.ts` pour les Processors devant être créés à l’exécution ou partagés entre Agents. Utilisez les Processors basés sur des fichiers pour les Processors statiques propres à chaque Agent, qui doivent être révisés avec l’Agent.

La priorité est la suivante :

1. `config.inputProcessors` ou `config.outputProcessors` défini par une fonction
1. `config.inputProcessors` ou `config.outputProcessors` défini par un tableau
1. Fichiers découverts dans `processors/input/` ou `processors/output/`

Consultez la [référence de `Processor`](/reference/processors/processor-interface) pour l’interface complète.
