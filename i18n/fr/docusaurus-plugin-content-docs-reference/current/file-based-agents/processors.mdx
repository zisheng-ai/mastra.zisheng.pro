# Processors

Un file-based agent discovers [processors](/docs/agents/processors) depuis its `processors/` directory. Utilisez ce page pour the file-based convention; utilise the processors guide pour built-in processors, personnalisé processors, streaming behavior, et advanced patterns.

Fichiers under `processors/input/` exécute avant messages reach the model. Fichiers under `processors/output/` exécute après the modèle responds. Chaque file default-exports un [`Processor` reference](/reference/processors/processor-interface), et the filename becomes its discovery key.

## Quickstart

Ajouter an input processor par placing a processor file under `processors/input/`:

```typescript title="src/mastra/agents/weather/processors/input/pii.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'block',
})
```

Ce processor runs avant utilisateur messages reach the model.

## Ajouter an output processor

Sortie processors sont good pour filtering ou transforming modèle responses avant they're returned. Ce example redacts PII depuis the final response.

```typescript title="src/mastra/agents/weather/processors/output/redact.ts"
import { PIIDetector } from '@mastra/core/processors'

export default new PIIDetector({
  strategy: 'redact',
})
```

## Ordering

Discovered processors sont added après tout processors defined dans [`config.ts`](/reference/file-based-agents/config). That means config processors exécute first.

```text title="Ordering"
config.inputProcessors → processors/input/* → model
model → config.outputProcessors → processors/output/* → response
```

If `config.inputProcessors` ou `config.outputProcessors` est a function, discovered processors de that type sont ignored avec a warning car function-valued processors can't be statically merged.

## Precedence avec config

Use `config.ts` pour processors that need à be created à runtime ou shared across agents. Use file-based processors pour static, per-agent processors that doit be reviewed alongside the agent.

Precedence is:

1. Function-valued `config.inputProcessors` ou `config.outputProcessors`
1. Array-valued `config.inputProcessors` ou `config.outputProcessors`
1. Discovered files under `processors/input/` ou `processors/output/`

Visit the [Processor interface reference](/reference/processors/processor-interface) pour the full interface.
