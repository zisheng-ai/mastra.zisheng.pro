# Workflows

Mastra discovers project-level workflows depuis `.ts` et `.js` files under `src/mastra/workflows/`. Ce convention isn't scoped à un agent: every file avec a par défaut export becomes a registered workflow, et the filename becomes the Workflow key.

Utilisez ce page pour the file-based convention. For steps, schemas, control flow, streaming, state, et Workflow execution, see [Workflows overview](/docs/workflows/overview).

## Quickstart

Créer a file under `src/mastra/workflows/`, génère the Workflow avec [`createWorkflow()`](/reference/workflows/workflow), et default-export it.

```typescript title="src/mastra/workflows/daily-report.ts"
import { createStep, createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

const collectInputs = createStep({
  id: 'collect-inputs',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ topic: z.string(), audience: z.string() }),
  execute: async ({ inputData }) => ({
    topic: inputData.topic,
    audience: 'engineering',
  }),
})

const writeSummary = createStep({
  id: 'write-summary',
  inputSchema: z.object({ topic: z.string(), audience: z.string() }),
  outputSchema: z.object({ report: z.string() }),
  execute: async ({ inputData }) => ({
    report: `Daily report about ${inputData.topic} for ${inputData.audience}.`,
  }),
})

const dailyReport = createWorkflow({
  id: 'daily-report',
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ report: z.string() }),
})
  .then(collectInputs)
  .then(writeSummary)
  .commit()

export default dailyReport
```

Mastra registers this Workflow under the `daily-report` key.

## Precedence avec code

Fichier-based workflows merge avec workflows registered dans [`new Mastra()`](/reference/core/mastra-class). On a clé collision, the code-registered Workflow wins.
