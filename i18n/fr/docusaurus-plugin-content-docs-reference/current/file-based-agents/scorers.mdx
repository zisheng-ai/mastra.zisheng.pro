# Scorers

Un file-based agent discovers [scorers](/docs/evals/overview) depuis its `scorers/` directory. Utilisez ce page pour the file-based convention; utilise the scorers guide pour built-in scorers, personnalisé scorers, et sampling.

Chaque file under `scorers/` default-exports un scorer, et the filename becomes its key. La valeur par défaut export est either a [`createScorer()`](/reference/evals/create-scorer) ou a `{ scorer, sampling }` entry.

## Quickstart

Ajouter a scorer par placing a file under the agent's `scorers/` directory. Ce example uses a [custom scorer](/docs/evals/custom-scorers):

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

export default createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)
```

The scorer est registered sur the `weather` agent under the clé `relevance`, the same comme adding it à `config.scorers`.

## Sampling

To control how often a scorer runs, default-export a `{ scorer, sampling }` entry instead de a bare scorer:

```typescript title="src/mastra/agents/weather/scorers/relevance.ts"
import { createScorer } from '@mastra/core/evals'

const relevance = createScorer({
  id: 'relevance',
  description: 'Scores how relevant the response is',
}).generateScore(() => 1)

export default {
  scorer: relevance,
  sampling: { type: 'ratio', rate: 0.5 },
}
```

## Precedence avec config

Discovered scorers sont merged avec the scorers defined dans [`config.ts`](/reference/file-based-agents/config). On a clé collision, `config.scorers` wins avec a warning. If `config.scorers` est a function, discovered scorers sont ignored avec a warning car function-valued scorers can't be statically merged.

When keys collide, precedence is:

1. Function-valued `config.scorers`
1. Record-valued `config.scorers`
1. Discovered files under `scorers/`

Non-colliding discovered scorers sont preserved.

Visit [`createScorer()`](/reference/evals/create-scorer) pour the full scorer interface.
