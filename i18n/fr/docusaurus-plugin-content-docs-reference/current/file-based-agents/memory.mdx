# Mémoire

Un file-based agent gets [memory](/docs/memory/overview) depuis a `memory.ts` file that default-exports a [`Memory` reference](/reference/memory/memory-class) instance. Utilisez ce page pour the file-based convention; utilise the memory docs pour message history, semantic recall, storage, et processors.

Without `memory.ts` ou `config.memory`, the agent possède aucun memory par default. Chaque `generate()` ou `stream()` call starts sans remembered conversation state unless you transmet the prior context yourself.

## Quickstart

Créer `memory.ts` next à the agent's `config.ts`:

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory()
```

The exported instance becomes the agent's `memory`. Si vousr app configures a storage provider sur the main Instance Mastra, memory données est stored there. Consultez [storage](/docs/storage/overview) pour more information.

Utilisez le same `resource` et `thread` values when calling the agent à continue a conversation:

```typescript title="src/app/weather-chat.ts"
const response = await weatherAgent.generate('Remember that I prefer Celsius.', {
  memory: {
    resource: 'user-123',
    thread: 'weather-chat',
  },
})
```

## Configurer memory

Pass options à `new Memory()` when the par défaut behavior isn't enough.

```typescript title="src/mastra/agents/weather/memory.ts"
import { Memory } from '@mastra/memory'

export default new Memory({
  options: {
    lastMessages: 20,
    workingMemory: {
      enabled: true,
      scope: 'resource',
    },
  },
})
```

Visit the [`Memory` reference](/reference/memory/memory-class) pour constructor options. Utilisez lese pages pour related memory features:

- [Stockage](/docs/storage/overview): configure persistence pour memory data.
- [Semantic recall](/docs/memory/semantic-recall): retrieve relevant past messages par semantic meaning.
- [Mémoire processors](/docs/memory/memory-processors): filter, trim, ou transform messages avant memory adds them à modèle context.

## Precedence avec config

`config.memory` wins over `memory.ts`. If neither est present, the assembled file-based agent possède aucun memory. Consultez [`config.ts` precedence precedence](/reference/file-based-agents/config#precedence) pour the full merge table.
