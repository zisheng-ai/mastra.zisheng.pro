# Skills

Un file-based agent discovers skills depuis its `skills/` directory et bundles them à génère time. Skills sont reusable procedures ou reference material that the agent peut charge when relevant, instead de putting every detail dans the always-on prompt.

Utilisez ce page pour the file-based convention. For code-defined skills, see [Agent skills](/docs/agents/skills). For the `SKILL.md` package format, see [Workspace skills](/docs/workspace/skills).

## Quickstart

The simplest skill est un markdown file under `skills/`. The filename becomes the skill name, et `description` tells the agent when à charge it.

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## Skills vs tools vs instructions

| Need | Use | Why |
| - | - | - |
| Always-on identity, tone, ou rules | [`instructions.md`](/reference/file-based-agents/instructions) | Le modèle doit see the guidance every turn. |
| Callable action avec inputs et outputs | [`tools/`](/reference/file-based-agents/tools) | Le modèle needs à exécute code, call APIs, ou perform side effects. |
| Detailed reference ou procedure loaded when relevant | `skills/` | Le modèle only needs the full guidance pour specific tasks. |

## Skill formats

Mastra supports three file-based skill formats:

| Format | Use it when |
| - | - |
| TypeScript/JavaScript module | You want à default-export a [`createSkill()`](/reference/agents/createSkill) résultat depuis code. |
| Packaged `SKILL.md` directory | The skill possède instructions plus supporting files under `references/`. |
| Flat markdown file | The skill est un markdown file avec frontmatter et instructions. |

For packaged skills, `description` est requis dans `SKILL.md` frontmatter. Flat markdown skills also require `description` dans frontmatter. Write when à utilise the skill, ne pas only what the skill contains.

## What gets loaded

Fichier-based Agent skills sont added à the generated bundle à génère time, so the deployed agent doesn't read them depuis disk.

For packaged skills, Mastra reads:

- `SKILL.md` pour metadata et instructions.
- Fichiers directly under `references/` comme supporting reference content.

Reference files sont keyed par filename. Symlinked files et directories under `references/` sont skipped during discovery.

## Precedence avec config

Discovered skills merge avec tout `skills` dans [`config.ts`](/reference/file-based-agents/config). On a nom collision, `config.skills` wins et a warning est logged.

If `config.skills` est a function, discovered skills sont ignored avec a warning car function-valued skills can't be statically merged.
