# Skills

Un Agent basé sur des fichiers découvre les Skills dans son répertoire `skills/` et les regroupe lors de la compilation. Les Skills sont des procédures réutilisables ou du matériel de référence que l’Agent peut charger lorsque cela est pertinent, au lieu de placer tous les détails dans le prompt toujours actif.

Utilisez cette page pour la convention basée sur les fichiers. Pour les Skills définis dans le code, consultez les [Skills d’Agent](/docs/agents/skills). Pour le format de package `SKILL.md`, consultez les [Skills de Workspace](/docs/workspace/skills).

## Démarrage rapide

Le Skill le plus simple est un fichier Markdown dans `skills/`. Le nom de fichier devient le nom du Skill et `description` indique à l’Agent quand le charger.

```markdown title="src/mastra/agents/weather/skills/temperature-units.md"
---
description: Use when reporting temperatures or comparing forecast units.
---

Always report temperatures in Celsius and Fahrenheit. Include the user's preferred unit first when known.
```

## Skills, Tools et instructions

| Besoin | Utiliser | Pourquoi |
| - | - | - |
| Identité, ton ou règles toujours actifs | [`instructions.md`](/reference/file-based-agents/instructions) | Le modèle doit consulter les consignes à chaque tour. |
| Action appelable avec entrées et sorties | [`tools/`](/reference/file-based-agents/tools) | Le modèle doit exécuter du code, appeler des API ou produire des effets de bord. |
| Référence détaillée ou procédure chargée lorsqu’elle est pertinente | `skills/` | Le modèle n’a besoin des consignes complètes que pour des tâches spécifiques. |

## Formats de Skill

Mastra prend en charge trois formats de Skill basés sur des fichiers :

| Format | À utiliser lorsque |
| - | - |
| Module TypeScript/JavaScript | Vous souhaitez exporter par défaut depuis le code le résultat de [`createSkill()`](/reference/agents/createSkill). |
| Répertoire `SKILL.md` empaqueté | Le Skill contient des instructions et des fichiers auxiliaires dans `references/`. |
| Fichier Markdown plat | Le Skill consiste en un fichier Markdown avec frontmatter et instructions. |

Pour les Skills empaquetés, `description` est obligatoire dans le frontmatter de `SKILL.md`. Les Skills Markdown plats exigent aussi `description` dans le frontmatter. Indiquez quand utiliser le Skill, et non seulement ce qu’il contient.

## Éléments chargés

Les Skills d’Agent basés sur des fichiers sont ajoutés au bundle généré lors de la compilation ; l’Agent déployé ne les lit donc pas depuis le disque.

Pour les Skills empaquetés, Mastra lit :

- `SKILL.md` pour les métadonnées et les instructions.
- Les fichiers directement placés dans `references/` comme contenu de référence auxiliaire.

Les fichiers de référence sont indexés par leur nom de fichier. Les fichiers et répertoires liés symboliquement dans `references/` sont ignorés lors de la découverte.

## Priorité par rapport à config

Les Skills découverts sont fusionnés avec les `skills` de [`config.ts`](/reference/file-based-agents/config). En cas de conflit de noms, `config.skills` est prioritaire et un avertissement est consigné.

Si `config.skills` est une fonction, les Skills découverts sont ignorés avec un avertissement, car les Skills définis par une fonction ne peuvent pas être fusionnés statiquement.
