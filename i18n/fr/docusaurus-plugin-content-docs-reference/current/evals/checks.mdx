# Quick Checks

Quick Checks regroupe des micro-Scorers composables sans LLM destinés aux assertions courantes. Ils s'intègrent au tableau `scorers: [...]` existant partout où des Scorers sont utilisés : dans `runEvals`, le scoring en direct, les expériences et Studio.

En interne, il s'agit d'instances standard de `createScorer()` ; elles bénéficient donc de la même observabilité, du même stockage et de la même intégration au pipeline que tout autre Scorer.

## Exemple d'utilisation {/* #usage-example */}

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    checks.includes('sunny'),
    checks.calledTool('get_weather'),
    checks.toolOrder(['get_weather', 'summarize']),
    checks.noToolErrors(),
  ],
})

console.log(result.scores)
```

## Vérifications de texte {/* #text-checks */}

### `checks.includes(expected, options?)` {/* #checksincludesexpected-options */}

Attribue un score de 1 si le texte de sortie de l'agent contient la sous-chaîne attendue, et de 0 dans le cas contraire.

```typescript
checks.includes('sunny')
checks.includes('Sunny', { ignoreCase: false })
```

```typescript
checks.excludes('Error', { ignoreCase: false })
```

```typescript
checks.equals('Hello', { ignoreCase: false })
```

### `checks.similarity(expected, options?)` {/* #checkssimilarityexpected-options */}

Renvoie le score de similarité des chaînes (0-1) entre la sortie et une chaîne attendue en utilisant le coefficient de Dice. Lorsqu'un `threshold` est défini, renvoie à la place une valeur binaire 1/0.


## Vérifications des appels de Tools {/* #tool-call-checks */}

### `checks.calledTool(toolName, options?)` {/* #checkscalledtooltoolname-options */}

Attribue un score de 1 si l'agent a appelé le Tool indiqué au moins le nombre de fois requis.

```typescript

checks.calledTool('search', { times: 2 })
```

### `checks.toolOrder(expectedOrder)` {/* #checkstoolorderexpectedorder */}

Attribue un score de 1 si les Tools ont été appelés dans l'ordre indiqué. Utilise une correspondance souple : d'autres appels de Tools sont autorisés entre les Tools attendus.

```typescript
checks.toolOrder(['search', 'summarize', 'respond'])
```

Renvoie : `1` si l'ordre attendu est respecté, `0` dans le cas contraire.

### `checks.maxToolCalls(max)` {/* #checksmaxtoolcallsmax */}

Attribue un score de 1 si l'agent n'a pas effectué plus de `max` appels de Tools.

```typescript

```

Renvoie : `1` si la limite est respectée, `0` dans le cas contraire.

### `checks.usedNoTools()` {/* #checksusednotools */}

Attribue un score de 1 si l'agent n'a effectué aucun appel de Tool.

```typescript
checks.usedNoTools()
```

Renvoie : `1` si aucun Tool n'a été appelé, `0` dans le cas contraire.

### `checks.noToolErrors()` {/* #checksnotoolerrors */}

Attribue un score de 1 si aucun appel de Tool n'a produit d'état d'erreur. Détecte aussi bien les résultats en erreur (`result.error` présent) que les appels de Tools incomplets (`state === 'call'`).

```typescript
checks.noToolErrors()
```

Renvoie : `1` si tous les appels de Tools ont réussi, `0` dans le cas contraire.

## Combiner les vérifications avec d'autres Scorers {/* #combining-checks-with-other-scorers */}

Les vérifications se combinent avec des Scorers fondés sur un LLM ou sur du code dans le même tableau `scorers` :

```typescript title="src/evals/combined-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createAnswerRelevancyScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    // Zero-LLM checks
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.noToolErrors(),
    // LLM-based scorer
    createAnswerRelevancyScorer({ model: '__GATEWAY_OPENAI_MODEL_MINI__' }),
  ],
})
```
