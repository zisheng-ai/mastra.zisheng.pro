# Quick Checks

Quick Vérifie sont zero-LLM, composable micro-scorers pour common assertions. They plug dans the existant `scorers: [...]` tableau anywhere scorers sont used: dans `runEvals`, live scoring, experiments, et Studio.

Internely they're standard `createScorer()` instances, so they ont the same observability, storage, et pipeline integration comme tout autre scorer.

## Exemple d’utilisation

```typescript title="src/evals/weather-checks.ts"
import { checks } from '@mastra/evals/checks'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    checks.includes('sunny'),
    checks.calledTool('get_weather'),
    checks.toolOrder(['get_weather', 'summarize']),
    checks.noToolErrors(),
  ],
})

console.log(result.scores)
```

## Text checks

### `checks.includes(expected, options?)`

Scores 1 if the agent's output text contains the expected substring, 0 otherwise.

```typescript
checks.includes('sunny')
checks.includes('Sunny', { ignoreCase: false })
```

### `checks.excludes(unwanted, options?)`

### `checks.similarity(expected, options?)`

Renvoie the chaîne similarity score (0-1) entre the output et an expected chaîne using the Dice coefficient. Lorsqu’un `threshold` est set, returns binary 1/0 instead.


## Tool call checks

### `checks.calledTool(toolName, options?)`

Scores 1 if the agent called the specified Tool à least the requis nombre de times.

```typescript
checks.calledTool('get_weather')
checks.calledTool('search', { times: 2 })
```

  content={[

  {

    description: 'Minimum nombre de times the Tool doit be called.',
  },
]}
/>

Renvoie: `1` if called à least `times` times, `0` otherwise.

### `checks.didNotCall(toolName)`

Scores 1 if the agent didn't call the specified tool.

```typescript
checks.didNotCall('delete_user')
```

<PropertiesTable
  content={[
  {
    name: 'toolName',
    type: 'string',

  },
]}
/>

Renvoie: `1` if the Tool wasn't called, `0` otherwise.

### `checks.toolOrder(expectedOrder)`

Scores 1 if the tools étaient called dans the specified order. Uses relaxed matching. Other Tool calls entre the expected tools sont allowed.

```typescript
checks.toolOrder(['search', 'summarize', 'respond'])
```

<PropertiesTable
  content={[
  {
    name: 'expectedOrder',
    type: 'string[]',
    description: 'Tool names dans the expected calling sequence. Must appear comme a subsequence de the actual Tool calls.',
  },
]}
/>

Renvoie: `1` if the expected order est satisfied, `0` otherwise.

### `checks.maxToolCalls(max)`

Scores 1 if the agent used aucun more than `max` Tool calls.

```typescript
checks.maxToolCalls(5)
```

<PropertiesTable
  content={[
  {
    name: 'max',
    type: 'number',
    description: 'Maximum nombre de Tool calls allowed.',
  },
]}
/>

Renvoie: `1` if within the limit, `0` otherwise.

### `checks.usedNoTools()`

Scores 1 if the agent made aucun Tool calls à all.

```typescript
checks.usedNoTools()
```

Renvoie: `1` if aucun tools étaient called, `0` otherwise.

### `checks.noToolErrors()`

Scores 1 if none de the Tool invocations resulted dans an error state. Detects both error results (`result.error` present) et incomplete Tool calls (`state === 'call'`).

```typescript
checks.noToolErrors()
```

Renvoie: `1` if tous les Tool calls succeeded, `0` otherwise.

## Combining checks avec autre scorers

Vérifie compose avec LLM-based et code-based scorers dans the same `scorers` array:

```typescript title="src/evals/combined-eval.ts"
import { checks } from '@mastra/evals/checks'
import { createAnswerRelevancyScorer } from '@mastra/evals/scorers/prebuilt'
import { runEvals } from '@mastra/core/evals'
import { myAgent } from '../agents'

const result = await runEvals({
  data: [{ input: 'What is the weather in Brooklyn?' }],
  target: myAgent,
  scorers: [
    // Zero-LLM checks
    checks.includes('Brooklyn'),
    checks.calledTool('get_weather'),
    checks.noToolErrors(),
    // LLM-based scorer
    createAnswerRelevancyScorer({ model: '__GATEWAY_OPENAI_MODEL_MINI__' }),
  ],
})
```
