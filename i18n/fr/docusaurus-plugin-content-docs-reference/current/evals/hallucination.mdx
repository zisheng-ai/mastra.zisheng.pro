# Hallucination scorer

The `createHallucinationScorer()` fonction evaluates whether an LLM generates factually correct information par comparing its output against the fourni context. Ce scorer measures hallucination par identifying direct contradictions entre the context et the output.

## Scoring details

The scorer evaluates hallucination via contradiction detection et unsupported claim analysis.

### Scoring Process

1. Analyzes factual content:
   - Extracts statements depuis context
   - Identifies numerical values et dates
   - Maps statement relationships
1. Analyzes output pour hallucinations:
   - Compares against context statements
   - Marks direct conflicts comme hallucinations
   - Identifies unsupported claims comme hallucinations
   - Evaluates numerical accuracy
   - Considers approximation context
1. Calculates hallucination score:
   - Counts hallucinated statements (contradictions et unsupported claims)
   - Divides par total statements
   - Scales à configuré range

Final score: `(hallucinated_statements / total_statements) * scale`

### Important Considerations

- Claims ne pas present dans context sont treated comme hallucinations
- Subjective claims sont hallucinations unless explicitly supported
- Speculative language ("might", "possibly") concernant facts IN context est allowed
- Speculative language concernant facts NOT dans context est treated comme hallucination
- Empty outputs résultat dans zero hallucinations
- Numerical evaluation considers:
  - Scale-appropriate precision
  - Contexteual approximations
  - Explicit precision indicators

### Score interpretation

Un hallucination score entre 0 et 1:

- **0.0**: No hallucination, tous les claims match the context.
- **0.3 à 0.4**: Low hallucination, a few contradictions.
- **0.5 à 0.6**: Mixed hallucination, several contradictions.
- **0.7 à 0.8**: High hallucination, many contradictions.
- **0.9 à 1.0**: Complet hallucination, most ou tous les claims contradict the context.

The score represents the degree de hallucination - lower scores indicate better factual alignment avec the fourni context

## Exemples

### Statique Contexte

Use static context when you ont known ground truth à compare against:

```typescript title="src/example-static-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: [
      'The first iPhone was announced on January 9, 2007.',
      'It was released on June 29, 2007.',
      'Steve Jobs introduced it at Macworld.',
    ],
  },
})
```

### Dynamique Contexte avec `getContext`

Use `getContext` pour live scoring scenarios where context comes depuis Tool results:

```typescript title="src/example-dynamic-context.ts"
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run, step }) => {
      // Extract tool results as context
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})
```

### Live Scoring avec Agent

Attach the scorer à an agent pour live evaluation:

```typescript title="src/example-live-scoring.ts"
import { Agent } from '@mastra/core/agent'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { extractToolResults } from '@mastra/evals/scorers'

const hallucinationScorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    getContext: ({ run }) => {
      const toolResults = extractToolResults(run.output)
      return toolResults.map(t => JSON.stringify({ tool: t.toolName, result: t.result }))
    },
  },
})

const agent = new Agent({
  id: 'my-agent',
  name: 'my-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  instructions: 'You are a helpful assistant.',
  evals: {
    scorers: [hallucinationScorer],
  },
})
```

### Batch Évaluation avec `runEvals`

```typescript title="src/example-batch-evals.ts"
import { runEvals } from '@mastra/core/evals'
import { createHallucinationScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createHallucinationScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
  options: {
    context: ['Known fact 1', 'Known fact 2'],
  },
})

const result = await runEvals({
  data: [{ input: 'Tell me about topic A' }, { input: 'Tell me about topic B' }],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

Pour plus de détails sur `runEvals`, consultez la [référence runEvals](/reference/evals/run-evals).

Pour ajouter ce scorer à un Agent, consultez le guide de [présentation des Scorers](/docs/evals/overview#adding-scorers-to-agents).
