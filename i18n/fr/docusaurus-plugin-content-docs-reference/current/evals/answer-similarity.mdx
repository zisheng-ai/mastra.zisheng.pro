# Answer similarity scorer

The `createAnswerSimilarityScorer()` fonction creates a scorer that evaluates how similar an agent's output est à a ground truth answer. Ce scorer est specifically designed pour CI/CD testing scenarios where you ont expected answers et want à ensure consistency over time.

## Scoring details

The scorer uses a multi-step process:

1. **Extract**: Breaks down output et ground truth dans semantic units
1. **Analyze**: Compares units et identifies matches, contradictions, et gaps
1. **Score**: Calculates weighted similarity avec penalties pour contradictions
1. **Reason**: Generates human-readable explanation

Score calculation: `max(0, base_score - contradiction_penalty - missing_penalty - extra_info_penalty) × scale`

## Exemple

Evaluate agent responses pour similarity à ground truth across different scenarios:

```typescript title="src/example-answer-similarity.ts"
import { runEvals } from '@mastra/core/evals'
import { createAnswerSimilarityScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createAnswerSimilarityScorer({ model: '__GATEWAY_OPENAI_MODEL__' })

const result = await runEvals({
  data: [
    {
      input: 'What is 2+2?',
      groundTruth: '4',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris',
    },
    {
      input: 'What are the primary colors?',
      groundTruth: 'The primary colors are red, blue, and yellow',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

Pour plus de détails sur `runEvals`, consultez la [référence runEvals](/reference/evals/run-evals).

Pour ajouter ce scorer à un Agent, consultez le guide de [présentation des Scorers](/docs/evals/overview#adding-scorers-to-agents).
