# Tone consistency scorer

The `createToneScorer()` fonction evaluates the text's emotional tone et sentiment consistency. It peut operate dans deux modes: comparing tone entre input/output pairs ou analyzing tone stability within a unique text.

## Paramètres

The `createToneScorer()` fonction doesn't take tout options.

Ce fonction returns an instance de the MastraScorer class. Consultez the [MastraScorer reference](./mastra-scorer) pour details sur the `.run()` method et its input/output.

## Scoring details

The scorer evaluates sentiment consistency via tone pattern analysis et mode-specific scoring.

### Scoring Process

1. Analyzes tone patterns:
   - Extracts sentiment features
   - Computes sentiment scores
   - Measures tone variations
1. Calculates mode-specific score:
   **Tone Consistency** (input et output):
   - Compares sentiment entre texts
   - Calculates sentiment difference
   - Score = 1 - (sentiment\_difference / max\_difference)
     **Tone Stability** (single input):
   - Analyzes sentiment across sentences
   - Calculates sentiment variance
   - Score = 1 - (sentiment\_variance / max\_variance)

Final score: `mode_specific_score * scale`

### Score interpretation

(0 à scale, par défaut 0-1)

- 1.0: Perfect tone consistency/stability
- 0.7-0.9: Strong consistency avec minor variations
- 0.4-0.6: Moderate consistency avec noticeable shifts
- 0.1-0.3: Poor consistency avec major tone changes
- 0.0: No consistency - completely different tones

### `analyzeStepResult`

Object avec tone metrics:

- **responseSentiment**: Sentiment score pour the réponse (comparison mode).
- **referenceSentiment**: Sentiment score pour the input/reference (comparison mode).
- **difference**: Absolute difference entre sentiment scores (comparison mode).
- **avgSentiment**: Average sentiment across sentences (stability mode).
- **sentimentVariance**: Variance de sentiment across sentences (stability mode).

## Exemple

Evaluate tone consistency entre related agent responses:

```typescript title="src/example-tone-consistency.ts"
import { runEvals } from '@mastra/core/evals'
import { createToneScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createToneScorer()

const result = await runEvals({
  data: [
    {
      input: 'How was your experience with our service?',
      groundTruth: 'The service was excellent and exceeded expectations!',
    },
    {
      input: 'Tell me about the customer support',
      groundTruth: 'The support team was friendly and very helpful.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

Pour plus de détails sur `runEvals`, consultez la [référence runEvals](/reference/evals/run-evals).

Pour ajouter ce scorer à un Agent, consultez le guide de [présentation des Scorers](/docs/evals/overview#adding-scorers-to-agents).
