# Faithfulness scorer

The `createFaithfulnessScorer()` fonction evaluates how factually accurate an LLM's output est compared à the fourni context. It extracts claims depuis the output et verifies them against the context, making it essential à measure RAG pipeline responses' reliability.

## Scoring details

The scorer evaluates faithfulness via claim verification against fourni context.

### Scoring Process

1. Analyzes claims et context:
   - Extracts tous les claims (factual et speculative)
   - Verifies chaque claim against context
   - Assigns un de three verdicts:
     - "yes" - claim pris en charge par context
     - "no" - claim contradicts context
     - "unsure" - claim unverifiable
1. Calculates faithfulness score:
   - Counts pris en charge claims
   - Divides par total claims
   - Scales à configuré range

Final score: `(supported_claims / total_claims) * scale`

### Score interpretation

Un faithfulness score entre 0 et 1:

- **1.0**: Tous les claims sont accurate et directly pris en charge par the context.
- **0.7 à 0.9**: Most claims sont correct, avec minor additions ou omissions.
- **0.4 à 0.6**: Some claims sont supported, mais others sont unverifiable.
- **0.1 à 0.3**: Most de the content est inaccurate ou unsupported.
- **0.0**: Tous les claims sont false ou contradict the context.

## Exemple

Evaluate agent responses pour faithfulness à fourni context:

```typescript title="src/example-faithfulness.ts"
import { runEvals } from '@mastra/core/evals'
import { createFaithfulnessScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

// Context is typically populated from agent tool calls or RAG retrieval
const scorer = createFaithfulnessScorer({
  model: '__GATEWAY_OPENAI_MODEL__',
})

const result = await runEvals({
  data: [
    {
      input: 'Tell me about the Tesla Model 3.',
    },
    {
      input: 'What are the key features of this electric vehicle?',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      reason: scorerResults[scorer.id].reason,
    })
  },
})

console.log(result.scores)
```

Pour plus de détails sur `runEvals`, consultez la [référence runEvals](/reference/evals/run-evals).

Pour ajouter ce scorer à un Agent, consultez le guide de [présentation des Scorers](/docs/evals/overview#adding-scorers-to-agents).
