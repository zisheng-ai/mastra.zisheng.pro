# Keyword coverage scorer

The `createKeywordCoverageScorer()` fonction evaluates how well an LLM's output covers the important keywords depuis the input. It analyzes keyword presence et matches tandis que ignoring common words et arrête words.

## Paramètres

The `createKeywordCoverageScorer()` fonction doesn't take tout options.

Ce fonction returns an instance de the MastraScorer class. Consultez the [MastraScorer reference](./mastra-scorer) pour details sur the `.run()` method et its input/output.

## Scoring details

The scorer evaluates keyword coverage par matching keywords avec the following features:

- Courant word et arrête word filtering (e.g., "the", "a", "and")
- Case-insensitive matching
- Word form variation handling
- Special handling de technical terms et compound words

### Scoring Process

1. Processes keywords depuis input et output:
   - Filtres out common words et arrête words
   - Normalizes case et word forms
   - Gère special terms et compounds
1. Calculates keyword coverage:
   - Matches keywords entre texts
   - Counts successful matches
   - Computes coverage ratio

Final score: `(matched_keywords / total_keywords) * scale`

### Score interpretation

Un coverage score entre 0 et 1:

- **1.0**: Complet coverage, tous les keywords present.
- **0.7 à 0.9**: High coverage, most keywords included.
- **0.4 à 0.6**: Partial coverage, certains keywords present.
- **0.1 à 0.3**: Low coverage, few keywords matched.
- **0.0**: La réponse contains none de the keywords.

### Special Cases

The scorer handles several special cases:

- Empty input/output: Renvoie score de 1.0 if both empty, 0.0 if only un est empty
- Single word: Treated comme a unique keyword
- Technical terms: Preserves compound technical terms (e.g., "React.js", "machine learning")
- Case differences: "JavaScript" matches "javascript"
- Courant words: Ignored dans scoring à focus sur useful keywords

## Exemple

Evaluate keyword coverage entre input queries et agent responses:

```typescript title="src/example-keyword-coverage.ts"
import { runEvals } from '@mastra/core/evals'
import { createKeywordCoverageScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createKeywordCoverageScorer()

const result = await runEvals({
  data: [
    {
      input: 'JavaScript frameworks like React and Vue',
    },
    {
      input: 'TypeScript offers interfaces, generics, and type inference',
    },
    {
      input:
        'Machine learning models require data preprocessing, feature engineering, and hyperparameter tuning',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
    })
  },
})

console.log(result.scores)
```

Pour plus de détails sur `runEvals`, consultez la [référence runEvals](/reference/evals/run-evals).

Pour ajouter ce scorer à un Agent, consultez le guide de [présentation des Scorers](/docs/evals/overview#adding-scorers-to-agents).
