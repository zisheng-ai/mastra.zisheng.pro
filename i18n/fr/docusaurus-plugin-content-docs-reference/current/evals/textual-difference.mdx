# Textual difference scorer

The `createTextualDifferenceScorer()` fonction uses sequence matching à measure the textual differences entre deux strings. It provides detailed information concernant changes, including the nombre de operations needed à transform un text dans another.

## Paramètres

The `createTextualDifferenceScorer()` fonction doesn't take tout options.

Ce fonction returns an instance de the MastraScorer class. Consultez the [MastraScorer reference](./mastra-scorer) pour details sur the `.run()` method et its input/output.

## Scoring details

The scorer calculates several measures:

- **Similarity Ratio**: Based sur sequence matching entre texts (0-1)
- **Changes**: Count de non-matching operations needed
- **Length Difference**: Normalized difference dans text lengths
- **Confidence**: Inversely proportional à length difference

### Scoring Process

1. Analyzes textual differences:
   - Performs sequence matching entre input et output
   - Counts the nombre de change operations required
   - Measures length differences
1. Calculates metrics:
   - Computes similarity ratio
   - Détermine confidence score
   - Combines dans weighted score

Final score: `(similarity_ratio * confidence) * scale`

### Score interpretation

Un textual difference score entre 0 et 1:

- **1.0**: The texts sont identical.
- **0.7 à 0.9**: Minor differences, few changes needed.
- **0.4 à 0.6**: Moderate differences, noticeable changes required.
- **0.1 à 0.3**: Major differences, extensive changes needed.
- **0.0**: Completly different texts.

## Exemple

Measure textual differences entre expected et actual agent outputs:

```typescript title="src/example-textual-difference.ts"
import { runEvals } from '@mastra/core/evals'
import { createTextualDifferenceScorer } from '@mastra/evals/scorers/prebuilt'
import { myAgent } from './agent'

const scorer = createTextualDifferenceScorer()

const result = await runEvals({
  data: [
    {
      input: 'Summarize the concept of recursion',
      groundTruth:
        'Recursion is when a function calls itself to solve a problem by breaking it into smaller subproblems.',
    },
    {
      input: 'What is the capital of France?',
      groundTruth: 'The capital of France is Paris.',
    },
  ],
  scorers: [scorer],
  target: myAgent,
  onItemComplete: ({ scorerResults }) => {
    console.log({
      score: scorerResults[scorer.id].score,
      groundTruth: scorerResults[scorer.id].groundTruth,
    })
  },
})

console.log(result.scores)
```

Pour plus de détails sur `runEvals`, consultez la [référence runEvals](/reference/evals/run-evals).

Pour ajouter ce scorer à un Agent, consultez le guide de [présentation des Scorers](/docs/evals/overview#adding-scorers-to-agents).
