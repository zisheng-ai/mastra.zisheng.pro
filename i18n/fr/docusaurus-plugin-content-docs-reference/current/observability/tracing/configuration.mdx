## `SamplingStrategy` {/* #samplingstrategy */}

```typescript
type SamplingStrategy =
  | { type: 'always' }
  | { type: 'never' }
  | { type: 'ratio'; probability: number }
  | { type: 'custom'; sampler: (options?: TracingOptions) => boolean }
```

## Méthodes du registre {/* #registry-methods */}

La classe Observability fournit des méthodes permettant de gérer les instances d’observabilité :

### `registerInstance` {/* #registerinstance */}

```typescript prettier:false
registerInstance(
  name: string,
  instance: ObservabilityInstance,
  isDefault?: boolean
): void;
```

Enregistre une instance d’observabilité dans le registre.

### `getInstance` {/* #getinstance */}

```typescript prettier:false
getInstance(name: string): ObservabilityInstance | undefined;
```

Récupère une instance d’observabilité par son nom.

### `getDefaultInstance` {/* #getdefaultinstance */}

```typescript prettier:false
getDefaultInstance(): ObservabilityInstance | undefined;
```

Renvoie l’instance d’observabilité par défaut.

### `getSelectedInstance` {/* #getselectedinstance */}

```typescript prettier:false
getSelectedInstance(
  options: ConfigSelectorOptions
): ObservabilityInstance | undefined;
```

Renvoie l’instance d’observabilité sélectionnée par le sélecteur de configuration ou celle par défaut.

### `listInstances` {/* #listinstances */}

```typescript prettier:false
listInstances(): ReadonlyMap<string, ObservabilityInstance>;
```

Renvoie toutes les instances d’observabilité enregistrées.

### `hasInstance` {/* #hasinstance */}

```typescript prettier:false
hasInstance(name: string): boolean;
```

Vérifie si une instance d’observabilité existe.

### `setConfigSelector` {/* #setconfigselector */}

```typescript prettier:false
setConfigSelector(selector: ConfigSelector): void;
```

Définit la fonction de sélection de configuration.

### `unregisterInstance` {/* #unregisterinstance */}

```typescript prettier:false
unregisterInstance(name: string): boolean;
```

Supprime une instance d’observabilité du registre.

### clear {/* #clear */}

```typescript prettier:false
clear(): void;
```

Efface toutes les instances sans les arrêter.

### shutdown {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>;
```

Arrête toutes les instances d’observabilité et efface le registre.
