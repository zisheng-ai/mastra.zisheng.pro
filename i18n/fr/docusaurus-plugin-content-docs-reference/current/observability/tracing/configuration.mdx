## Registry methods

The Observability class provides methods pour managing observability instances:

### `registerInstance`

```typescript prettier:false
registerInstance(
  name: string,
  instance: ObservabilityInstance,
  isDefault?: boolean
): void;
```

Registers an observability instance dans the registry.

### `getInstance`

```typescript prettier:false
getInstance(name: string): ObservabilityInstance | undefined;
```

Retrieves an observability instance par name.

### `getDefaultInstance`

```typescript prettier:false
getDefaultInstance(): ObservabilityInstance | undefined;
```

Renvoie the par défaut observability instance.

### `getSelectedInstance`

```typescript prettier:false
getSelectedInstance(
  options: ConfigSelectorOptions
): ObservabilityInstance | undefined;
```

Renvoie the observability instance sélectionné par the config selector ou default.

### `listInstances`

```typescript prettier:false
listInstances(): ReadonlyMap<string, ObservabilityInstance>;
```

Renvoie tous les registered observability instances.

### `hasInstance`

```typescript prettier:false
hasInstance(name: string): boolean;
```

Vérifie if an observability instance exists.

### `setConfigSelector`

```typescript prettier:false
setConfigSelector(selector: ConfigSelector): void;
```

Définit the config selector function.

### `unregisterInstance`

```typescript prettier:false
unregisterInstance(name: string): boolean;
```

Supprime an observability instance depuis the registry.

### clear

```typescript prettier:false
clear(): void;
```

Clears tous les instances sans shutdown.

### shutdown

```typescript prettier:false
async shutdown(): Promise<void>;
```

Shuts down tous les observability instances et clears the registry.
