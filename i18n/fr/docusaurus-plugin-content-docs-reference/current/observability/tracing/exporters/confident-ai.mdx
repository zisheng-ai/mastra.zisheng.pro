# DeepEvalExporter

Envoie les données de Tracing à [Confident AI](https://www.confident-ai.com/) à des fins d’évaluation et d’observabilité. Cette classe est exportée par `@mastra/deepeval`, qui repose sur le SDK DeepEval.

Consultez la page consacrée à l’[exportateur Confident AI](/docs/observability/integrations/exporters/confident-ai) pour en savoir plus sur sa configuration et son utilisation.

## Constructeur {/* #constructor */}

```typescript prettier:false
new DeepEvalExporter(config?: DeepEvalExporterConfig)
```

## `DeepEvalExporterConfig` {/* #deepevalexporterconfig */}

```typescript

  apiKey?: string

  turnId?: string
```

Étend `BaseExporterConfig`, qui comprend :

- `logger?: IMastraLogger` - Instance du logger
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - Niveau de log (valeur par défaut : INFO)

## Méthodes {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

Exporte un événement de tracing vers Confident AI. Construit l’arborescence de la Trace à partir du flux de spans Mastra, puis envoie la Trace lorsque le span racine se termine.

### `flush` {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Attend la fin de tous les envois de Traces en cours sans arrêter l’exportateur.

### `shutdown` {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

Finalise toutes les Traces ouvertes et envoie les publications en attente.

## Utilisation {/* #usage */}

### Sans configuration (avec des variables d’environnement) {/* #zero-config-using-environment-variables */}

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

// Reads from CONFIDENT_API_KEY, CONFIDENT_TRACE_ENVIRONMENT
const exporter = new DeepEvalExporter()
```

### Configuration explicite {/* #explicit-configuration */}

```typescript
import { DeepEvalExporter } from '@mastra/deepeval'

const exporter = new DeepEvalExporter({
  apiKey: process.env.CONFIDENT_API_KEY,
  environment: 'production',
})
```

## Correspondance des types de spans {/* #span-type-mapping */}

| Type de span Mastra | Type de span Confident AI |
| - | - |
| `AGENT_RUN`, `WORKFLOW_RUN` | `AGENT` |
| `MODEL_GENERATION` | `LLM` |
| `TOOL_CALL`, `MCP_TOOL_CALL`, `PROVIDER_TOOL_CALL`, `CLIENT_TOOL_CALL` | `TOOL` |
| `RAG_EMBEDDING`, `RAG_VECTOR_OPERATION` | `RETRIEVER` |
| Tous les autres types de spans exportés | `CUSTOM` |

Les spans d’événement, par exemple `MODEL_CHUNK`, sont abandonnés.
