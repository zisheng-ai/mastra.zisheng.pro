# LaminarExporter

Envoie les données de Tracing à Laminar via OTLP/HTTP (protobuf).

## Constructor {/* #constructor */}

```typescript prettier:false
new LaminarExporter(config?: LaminarExporterConfig)
```

## `LaminarExporterConfig` {/* #laminarexporterconfig */}

```typescript
interface LaminarExporterConfig extends BaseExporterConfig {
  apiKey?: string
  baseUrl?: string
  endpoint?: string
  headers?: Record<string, string>
  realtime?: boolean
  disableBatch?: boolean
  batchSize?: number
  timeoutMillis?: number
}
```

Étend `BaseExporterConfig`, qui comprend :

- `logger?: IMastraLogger` - Instance du logger
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - Niveau de journalisation (valeur par défaut : INFO)

## Méthodes {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

Exporte un événement de Tracing vers Laminar.

### flush {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Force l’envoi à Laminar de tous les spans en mémoire tampon sans arrêter l’Exporter. Utile dans les environnements serverless où vous devez vous assurer que les spans sont exportés avant la fin du runtime.

### shutdown {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

Envoie les données en attente et arrête l’Exporter.

## Utilisation {/* #usage */}

### Configuration automatique avec les variables d’environnement {/* #zero-config-using-environment-variables */}

```typescript
import { LaminarExporter } from '@mastra/laminar'

// Reads from LMNR_PROJECT_API_KEY, LMNR_BASE_URL, LAMINAR_ENDPOINT
const exporter = new LaminarExporter()
```

### Configuration explicite {/* #explicit-configuration */}

```typescript
import { LaminarExporter } from '@mastra/laminar'

const exporter = new LaminarExporter({
  apiKey: process.env.LMNR_PROJECT_API_KEY,
  baseUrl: 'https://api.lmnr.ai',
  realtime: true,
})
```
