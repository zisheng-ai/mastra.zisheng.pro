# DatadogExporter

Envoie les données de Tracing au produit LLM Observability de Datadog à des fins de surveillance et d'analyse.

:::info
Si vous utilisez également l'auto-instrumentation APM de `dd-trace` et devez la rattacher correctement aux spans Mastra, utilisez plutôt [DatadogBridge](/reference/observability/tracing/bridges/datadog). L'Exporter envoie les données LLM Observability à la fin de l'exécution ; il ne participe donc pas à la portée active de `dd-trace`.
:::

## Constructeur {/* #constructor */}

```typescript prettier:false
new DatadogExporter(config: DatadogExporterConfig)
```

## Méthodes {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

Exporte un événement de Tracing vers Datadog LLM Observability.

### flush {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Force l'envoi à Datadog de tous les spans en mémoire tampon sans arrêter l'Exporter. Cette méthode est utile dans les environnements serverless où vous devez vous assurer que les spans sont exportés avant la fin de l'environnement d'exécution.

### shutdown {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

Envoie les données en attente et arrête l'Exporter. Annule tous les minuteurs de nettoyage en attente et désactive LLM Observability.

## Utilisation {/* #usage */}

### Sans configuration (au moyen de variables d'environnement) {/* #zero-config-using-environment-variables */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

// Reads from DD_LLMOBS_ML_APP, DD_API_KEY, DD_SITE, DD_ENV
const exporter = new DatadogExporter()
```

### Configuration explicite {/* #explicit-configuration */}

```typescript
import { DatadogExporter } from '@mastra/datadog'

const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  apiKey: process.env.DD_API_KEY,
  site: 'datadoghq.com',
  env: 'production',
})
```

### Avec l'Agent Datadog local {/* #with-local-datadog-agent */}

```typescript
const exporter = new DatadogExporter({
  mlApp: 'my-llm-app',
  agentless: false, // Use local Datadog Agent
  env: 'production',
})
```

## Mappage des spans {/* #span-mapping */}

Les types de spans Mastra sont associés aux catégories de spans de Datadog LLM Observability :

| SpanType Mastra | Catégorie Datadog |
| - | - |
| `AGENT_RUN` | `agent` |
| `MODEL_GENERATION` | `workflow` |
| `MODEL_STEP` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_RUN` | `workflow` |
| Tous les autres types | `task` |

Tous les types de spans sans correspondance (notamment `MODEL_CHUNK`, `WORKFLOW_STEP`, `GENERIC` et les futurs types de spans) utilisent automatiquement `task` par défaut.

## Variables d'environnement {/* #environment-variables */}

L'Exporter lit sa configuration dans les variables d'environnement suivantes :

| Variable | Description |
| - | - |
| `DD_API_KEY` | Clé d'API Datadog |
| `DD_LLMOBS_ML_APP` | Nom de l'application ML |
| `DD_SITE` | Site Datadog |
| `DD_ENV` | Nom de l'environnement |
| `DD_LLMOBS_AGENTLESS_ENABLED` | Définissez cette variable sur 'false' ou '0' pour utiliser l'Agent local |
