# BraintrustExporter

Envoie les données de Tracing à Braintrust pour les Evals et l’Observability.

## Constructor {/* #constructor */}

```typescript prettier:false
new BraintrustExporter(config: BraintrustExporterConfig)
```

## `BraintrustExporterConfig` {/* #braintrustexporterconfig */}

```typescript
interface BraintrustExporterConfig extends BaseExporterConfig {
  apiKey?: string
  endpoint?: string
  projectName?: string
  braintrustLogger?: Logger<true>
  currentSpan?: () => Span | undefined
  tuningParameters?: Record<string, any>
}
```

Étend `BaseExporterConfig`, qui comprend :

- `logger?: IMastraLogger` - Instance du logger
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - Niveau de journalisation (valeur par défaut : INFO)

## Méthodes {/* #methods */}

### `exportTracingEvent` {/* #exporttracingevent */}

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

Exporte un événement de Tracing vers Braintrust.

### export {/* #export */}

```typescript prettier:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

Exporte des spans par lots vers Braintrust.

### flush {/* #flush */}

```typescript prettier:false
async flush(): Promise<void>
```

Force l’envoi à Braintrust de tous les spans en mémoire tampon sans arrêter l’Exporter. Utile dans les environnements serverless où vous devez vous assurer que les spans sont exportés avant la fin du runtime.

### shutdown {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

Envoie les données en attente et arrête le client.

## Utilisation {/* #usage */}

### Configuration automatique avec les variables d’environnement {/* #zero-config-using-environment-variables */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

// Reads from BRAINTRUST_API_KEY, BRAINTRUST_ENDPOINT
const exporter = new BraintrustExporter()
```

### Configuration explicite {/* #explicit-configuration */}

```typescript
import { BraintrustExporter } from '@mastra/braintrust'

const exporter = new BraintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-ai-project',
})
```

## Correspondance des types de spans {/* #span-type-mapping */}

| Type de span | Type Braintrust |
| - | - |
| `MODEL_GENERATION` | `llm` |
| `MODEL_CHUNK` | `llm` |
| `TOOL_CALL` | `tool` |
| `MCP_TOOL_CALL` | `tool` |
| `PROVIDER_TOOL_CALL` | `tool` |
| `WORKFLOW_CONDITIONAL_EVAL` | `function` |
| `WORKFLOW_WAIT_EVENT` | `function` |
| Tous les autres | `task` |
