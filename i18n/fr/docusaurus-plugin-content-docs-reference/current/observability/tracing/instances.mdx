# Instances d’observabilité

## `DefaultObservabilityInstance` {/* #defaultobservabilityinstance */}

Implémentation par défaut de l’interface ObservabilityInstance.

### Constructeur {/* #constructor */}

```typescript prettier:false
new DefaultObservabilityInstance(config: ObservabilityInstanceConfig)
```

Crée une nouvelle instance de DefaultObservabilityInstance avec la configuration spécifiée.

### Propriétés {/* #properties */}

Hérite de toutes les propriétés et méthodes de BaseObservabilityInstance.

## `BaseObservabilityInstance` {/* #baseobservabilityinstance */}

Classe de base pour les implémentations personnalisées de ObservabilityInstance.

### Méthodes {/* #methods */}

#### `getConfig` {/* #getconfig */}

```typescript prettier:false
getConfig(): Readonly<Required<ObservabilityInstanceConfig>>
```

Renvoie la configuration d’observabilité actuelle.

#### `getExporters` {/* #getexporters */}

```typescript prettier:false
getExporters(): readonly ObservabilityExporter[]
```

Renvoie tous les exportateurs configurés.

#### `getSpanOutputProcessors` {/* #getspanoutputprocessors */}

```typescript prettier:false
getSpanOutputProcessors(): readonly SpanOutputProcessor[]
```

Renvoie tous les processeurs de sortie des spans configurés.

#### `getLogger` {/* #getlogger */}

```typescript prettier:false
getLogger(): IMastraLogger
```

Renvoie l’instance du logger utilisée par les exportateurs et les autres composants.

#### `startSpan` {/* #startspan */}

```typescript prettier:false
startSpan<TType extends SpanType>(
  options: StartSpanOptions<TType>
): Span<TType>
```

#### shutdown {/* #shutdown */}

```typescript prettier:false
async shutdown(): Promise<void>
```

Arrête tous les exportateurs et processeurs, puis libère les ressources.

## Implémentation personnalisée {/* #custom-implementation */}

Pour créer une implémentation personnalisée de ObservabilityInstance, étendez BaseObservabilityInstance :

```typescript
class CustomObservabilityInstance extends BaseObservabilityInstance {
  constructor(config: ObservabilityInstanceConfig) {
    super(config)
    // Custom initialization
  }

  // Override methods as needed
  startSpan<TType extends SpanType>(options: StartSpanOptions<TType>): Span<TType> {
    // Custom span creation logic
    return super.startSpan(options)
  }
}
```
