# Mastra.getTelemetry()

La méthode `.getTelemetry()` permet de récupérer l’instance de télémétrie configurée dans l’instance Mastra.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.getTelemetry()
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
