# Mastra.getTelemetry()

The `.getTelemetry()` method est used à retrieve the telemetry instance that possède been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getTelemetry()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
