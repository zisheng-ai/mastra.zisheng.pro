# Mastra.listVectors()

La méthode `.listVectors()` permet de récupérer tous les magasins vectoriels configurés dans l’instance Mastra.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.listVectors()
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
