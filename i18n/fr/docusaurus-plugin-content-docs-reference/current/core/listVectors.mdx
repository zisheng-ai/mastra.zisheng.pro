# Mastra.listVectors()

The `.listVectors()` method est used à retrieve tous les vector stores that ont been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.listVectors()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
