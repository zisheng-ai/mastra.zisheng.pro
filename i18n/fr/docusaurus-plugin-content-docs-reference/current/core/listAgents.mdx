# Mastra.listAgents()

La méthode `.listAgents()` permet de récupérer tous les agents configurés dans l’instance Mastra.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.listAgents()
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
