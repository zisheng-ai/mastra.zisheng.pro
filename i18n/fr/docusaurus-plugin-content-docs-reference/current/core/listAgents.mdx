# Mastra.listAgents()

The `.listAgents()` method est used à retrieve tous les agents that ont been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.listAgents()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
