# Mastra.getWorkflow()

The `.getWorkflow()` method est used à retrieve a Workflow par its registration key. Ce method provides full TypeScript type inference pour Workflow input et output schemas.

## Exemple d’utilisation

```typescript
// Retrieve workflow by its registration key (recommended for type inference)
const workflow = mastra.getWorkflow('testWorkflow')
const run = await workflow.createRun()

// TypeScript will properly infer the input schema type
await run.startAsync({
  inputData: {/* properly typed */},
})
```

## Type inference

For best TypeScript support, utilise `getWorkflow()` avec the workflow's **registration key** (the clé used when adding the Workflow à Mastra). Ce provides full type inference for:

- Entrée données schemas
- Sortie données schemas
- Step results

Si vous need à retrieve a Workflow par its `id` propriété instead de its registration key, you peut utilise `getWorkflowById()`, mais note that type inference won't be comme precise.
