# listScorers()

La méthode `listScorers()` renvoie tous les scorers enregistrés dans l’instance Mastra. Les scorers servent à évaluer les sorties d’IA et peuvent remplacer les scorers par défaut lors de la génération d’un Agent ou de l’exécution d’un Workflow.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { mastra } from './mastra'

// Get all registered scorers
const allScorers = mastra.listScorers()

// Access a specific scorer
const myScorer = allScorers.relevancyScorer
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
