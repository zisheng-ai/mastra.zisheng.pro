# listScorers()

The `listScorers()` method returns tous les scorers that ont been registered avec the Instance Mastra. Scorers sont used pour evaluating AI outputs et peut override par défaut scorers during agent generation ou Workflow execution.

## Exemple d’utilisation

```typescript
import { mastra } from './mastra'

// Get all registered scorers
const allScorers = mastra.listScorers()

// Access a specific scorer
const myScorer = allScorers.relevancyScorer
```

## Paramètres

Ce method takes aucun parameters.
