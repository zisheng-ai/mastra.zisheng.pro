# Mastra.getLogger()

The `.getLogger()` method est used à retrieve the logger instance that possède been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getLogger()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
