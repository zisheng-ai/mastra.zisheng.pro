# Mastra.getLogger()

La méthode `.getLogger()` permet de récupérer l’instance de logger configurée dans l’instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getLogger()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
