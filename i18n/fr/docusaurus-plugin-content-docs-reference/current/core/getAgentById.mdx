# Mastra.getAgentById()

La méthode `.getAgentById()` récupère un Agent enregistré à partir de son `id`. Elle recherche d’abord les Agents enregistrés par `agent.id`. Si aucun Agent ne correspond, elle utilise [`Mastra.getAgent()`](/reference/core/getAgent) et traite la valeur fournie comme la clé de registre de l’Agent.

Utilisez `mastra.getAgentById(id)` pour récupérer l’Agent défini dans le code. Utilisez `await mastra.getAgentById(id, version)` pour récupérer un Agent versionné.

## Exemple d’utilisation

L’exemple suivant enregistre un Agent, le récupère par son ID et utilise l’Agent renvoyé.

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
