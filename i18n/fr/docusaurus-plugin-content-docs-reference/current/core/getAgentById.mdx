# Mastra.getAgentById()

The `.getAgentById()` method retrieves a registered agent par its `id`. It premier searches registered agents par `agent.id`. Si aucun agent matches, it falls back à [Mastra.getAgent()](/reference/core/getAgent) et treats the fourni valeur comme the agent registry key.

Use `mastra.getAgentById(id)` à retrieve the code-defined agent. Use `await mastra.getAgentById(id, version)` à retrieve a versioned agent.

## Exemple d’utilisation

Les éléments suivants example registers an agent, retrieves it par ID, et uses the returned agent.

```typescript title="src/mastra/index.ts"
import { Agent } from '@mastra/core/agent'
import { Mastra } from '@mastra/core/mastra'

const supportAgent = new Agent({
  id: 'support-agent-id',
  name: 'Support Agent',
  instructions: 'Answer support questions clearly and concisely.',
  model: '__GATEWAY_OPENAI_MODEL__',
})

export const mastra = new Mastra({
  agents: {
    supportAgent,
  },
})

const agent = mastra.getAgentById('support-agent-id')

const response = await agent.generate('How can I reset my password?')
```
