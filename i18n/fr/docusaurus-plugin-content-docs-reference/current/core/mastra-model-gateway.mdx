# MastraModelGateway

Classe de base abstraite permettant d'implémenter des gateways de modèles personnalisées. Les gateways gèrent la logique propre au Provider pour accéder aux modèles de langage, notamment la configuration du Provider, l'authentification, la construction des URL et l'instanciation des modèles.

Utilisez `MastraModelGatewayInterface` lorsque vous souhaitez fournir une gateway sous forme d'objet simple au lieu d'étendre la classe de base.

## Présentation de la classe {/* #class-overview */}

```typescript
import { MastraModelGateway, type ProviderConfig } from '@mastra/core/llm'
import { createOpenAICompatible } from '@ai-sdk/openai-compatible-v5'
import type { LanguageModelV2 } from '@ai-sdk/provider-v5'

class MyCustomGateway extends MastraModelGateway {
  readonly id = 'custom'
  readonly name = 'My Custom Gateway'

  async fetchProviders(): Promise<Record<string, ProviderConfig>> {
    return {
      'my-provider': {
        name: 'My Provider',
        models: ['__GATEWAY_OPENAI_MODEL__', '__GATEWAY_ANTHROPIC_MODEL_SONNET__'],
        apiKeyEnvVar: 'MY_API_KEY',
        gateway: this.id,
      },
    }
  }

  buildUrl(modelId: string, envVars?: Record<string, string>): string {
    return 'https://api.my-provider.com/v1'
  }

  async getApiKey(modelId: string): Promise<string> {
    const apiKey = process.env.MY_API_KEY
    if (!apiKey) throw new Error('MY_API_KEY not set')
    return apiKey
  }

  async resolveLanguageModel({
    modelId,
    providerId,
    apiKey,
  }: {
    modelId: string
    providerId: string
    apiKey: string
  }): Promise<LanguageModelV2> {
    const baseURL = this.buildUrl(`${providerId}/${modelId}`)
    return createOpenAICompatible({
      name: providerId,
      apiKey,
      baseURL,
    }).chatModel(modelId)
  }
}
```

### `resolveAuth()` {/* #resolveauth */}

Résout les identifiants avant que Mastra ne crée le modèle de langage. Implémentez ce hook facultatif lorsque la gateway gère l'authentification. En cas d'omission, Mastra se rabat sur `getApiKey()`.

**Paramètres :**

<PropertiesTable
  content={[
  {

/>

**Renvoie :** `GatewayAuthResult | undefined | Promise<GatewayAuthResult | undefined>`

Un `GatewayAuthResult` peut comprendre `apiKey`, `bearerToken`, `headers` ainsi qu'un champ facultatif `source` permettant de retracer l'origine de l'authentification.

## Format des identifiants de modèles {/* #model-id-format */}

Pour les véritables gateways, l'identifiant de la gateway sert de préfixe et les modèles sont accessibles au format suivant :

```
[gateway-id]/[provider]/[model]
```

Exemples :

- Gateway avec `id = 'custom'` : `'custom/my-provider/model-1'`
