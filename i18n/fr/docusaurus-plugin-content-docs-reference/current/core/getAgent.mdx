# Mastra.getAgent()

La méthode `.getAgent()` permet de récupérer un Agent. Elle accepte un seul paramètre `string` correspondant au nom de l’Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.getAgent('testAgent')
```
