# Mastra.getÉditeur()

The `.getEditor()` method est used à retrieve the editor instance that possède been configuré sur the Instance Mastra. The editor exposes CRUD namespaces pour managing stored agents, prompt blocks, MCP clients, scorers, skills, et workspaces programmatically.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'

const mastra = new Mastra({
  editor: new MastraEditor(),
})

const editor = mastra.getEditor()

const agent = await editor?.agent.create({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Help customers with their questions.',
})
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
