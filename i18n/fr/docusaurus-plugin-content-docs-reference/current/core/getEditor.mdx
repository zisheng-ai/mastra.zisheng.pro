# Mastra.getEditor()

La méthode `.getEditor()` permet de récupérer l’instance Editor configurée dans l’instance Mastra. L’Editor expose des espaces de noms CRUD pour gérer par programmation les agents stockés, les blocs de prompt, les clients MCP, les Scorers, les Skills et les espaces de travail.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'

const mastra = new Mastra({
  editor: new MastraEditor(),
})

const editor = mastra.getEditor()

const agent = await editor?.agent.create({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'Help customers with their questions.',
})
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
