# Mastra.getMCPServer()

La méthode `.getMCPServer()` récupère une instance de serveur MCP à partir de sa clé de registre (la clé utilisée lors de l’enregistrement du serveur dans la configuration `mcpServers`). Pour récupérer un serveur par sa propriété `id` intrinsèque, utilisez plutôt `.getMCPServerById()`.

## Exemple d’utilisation {/* #usage-example */}

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by registry key
const server = mastra.getMCPServer('customKey')

// Alternatively, retrieve by intrinsic ID
const serverById = mastra.getMCPServerById('my-mcp-server')
```
