# Mastra.getMCPServeur()

The `.getMCPServer()` method retrieves an MCP server instance par its registry clé (the clé used when registering the server dans the `mcpServers` configuration). For retrieving par the server's intrinsic `id` property, utilise `.getMCPServerById()` instead.

## Exemple d’utilisation

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by registry key
const server = mastra.getMCPServer('customKey')

// Alternatively, retrieve by intrinsic ID
const serverById = mastra.getMCPServerById('my-mcp-server')
```
