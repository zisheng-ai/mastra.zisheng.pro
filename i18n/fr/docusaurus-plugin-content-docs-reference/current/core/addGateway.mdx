# Mastra.addGateway()

Ajoute dynamiquement une passerelle à l’instance Mastra. Peut être utilisée pendant ou après l’initialisation.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra()

// Add with explicit key
mastra.addGateway(new MyCustomGateway(), 'myGateway')

// Add using gateway's ID as the key
mastra.addGateway(new MyCustomGateway())
// Stored with key 'my-custom-gateway' (the gateway's id)
```

## Valeur renvoyée

Ne renvoie aucune valeur. La passerelle est ajoutée au registre interne.

## Comportement

- Si une passerelle avec la même clé existe déjà, l’ajout est ignoré
- En mode développement (`MASTRA_DEV=true`), déclenche automatiquement la génération des types pour les passerelles personnalisées
- La passerelle devient immédiatement disponible pour la résolution des modèles
