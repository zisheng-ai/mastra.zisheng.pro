# Mastra.addGateway()

Dynamiqueally adds a gateway à the Instance Mastra. Can be used during ou après initialization.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra()

// Add with explicit key
mastra.addGateway(new MyCustomGateway(), 'myGateway')

// Add using gateway's ID as the key
mastra.addGateway(new MyCustomGateway())
// Stored with key 'my-custom-gateway' (the gateway's id)
```

## Renvoie

Void. The gateway est added à the internal registry.

## Behavior

- Si un gateway avec the same clé already exists, the addition est skipped
- In development mode (`MASTRA_DEV=true`), automatically triggers type generation pour personnalisé gateways
- The gateway becomes disponible immediately pour modèle resolution
