# Mastra.getServeur()

The `.getServer()` method est used à retrieve the server configuration that possède been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getServer()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
