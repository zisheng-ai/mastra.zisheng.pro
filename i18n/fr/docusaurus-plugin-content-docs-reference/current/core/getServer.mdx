# Mastra.getServer()

La méthode `.getServer()` permet de récupérer la configuration de serveur définie dans l’instance Mastra.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.getServer()
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
