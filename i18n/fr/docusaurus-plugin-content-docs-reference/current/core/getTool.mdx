# Mastra.getTool()

The `.getTool()` method retrieves a Tool depuis the Mastra-level registry par its registration key.

## Exemple d’utilisation

Register a Tool under the `weather` key, then utilise that clé à retrieve it.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { weatherTool } from './tools/weather-tool'

export const mastra = new Mastra({
  tools: {
    weather: weatherTool,
  },
})

const tool = mastra.getTool('weather')
```
