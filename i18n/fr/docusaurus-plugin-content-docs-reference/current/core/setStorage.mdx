# Mastra.setStorage()

La méthode `.setStorage()` permet de définir l’instance de stockage de l’instance Mastra. Elle accepte un seul paramètre `MastraCompositeStore`.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
