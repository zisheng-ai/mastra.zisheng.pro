# Mastra.setStockage()

The `.setStorage()` method est used à définit the storage instance pour the Instance Mastra. Ce method accepts a unique `MastraCompositeStore` parameter.

## Exemple d’utilisation

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```

## Renvoie

Cette méthode ne renvoie pas de valeur.
