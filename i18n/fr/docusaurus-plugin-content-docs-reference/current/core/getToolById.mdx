# Mastra.getToolById()

The `.getToolById()` method premier searches the Mastra-level registry pour a Tool avec a matching intrinsic `id`. Si aucun intrinsic ID matches, it treats the valeur comme a registration key.

## Exemple d’utilisation

Ce example uses `weather` comme the registration clé et `weather-tool` comme the tool's intrinsic ID.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

const weatherTool = createTool({
  id: 'weather-tool',
  description: 'Fetches weather for a location',
  inputSchema: z.object({
    location: z.string(),
  }),
  outputSchema: z.object({
    weather: z.string(),
  }),
  execute: async ({ location }) => ({
    weather: `Weather for ${location}`,
  }),
})

export const mastra = new Mastra({
  tools: {
    weather: weatherTool,
  },
})

const toolById = mastra.getToolById('weather-tool')
```
