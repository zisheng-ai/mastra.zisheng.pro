# Mastra.getVector()

La méthode `.getVector()` permet de récupérer un magasin vectoriel par son nom. Elle accepte un unique paramètre `string` correspondant au nom du magasin vectoriel.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```
