# Mastra.listTools()

The `.listTools()` method returns the tools configuré sur a Instance Mastra. La valeur renvoyée record uses Mastra registration keys et Tool instances comme values.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { weatherTool } from './tools/weather-tool'

export const mastra = new Mastra({
  tools: {
    weather: weatherTool,
  },
})

const tools = mastra.listTools()
const weather = tools?.weather
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
