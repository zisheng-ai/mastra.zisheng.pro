# Mastra.listTools()

La méthode `.listTools()` renvoie les Tools configurés dans une instance Mastra. L’enregistrement renvoyé utilise les clés d’enregistrement Mastra et les instances de Tool comme valeurs.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { weatherTool } from './tools/weather-tool'

export const mastra = new Mastra({
  tools: {
    weather: weatherTool,
  },
})

const tools = mastra.listTools()
const weather = tools?.weather
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.

## Valeur renvoyée {/* #returns */}

Cette méthode liste le registre au niveau de Mastra. Elle n’inclut pas les Tools qui n’existent que dans une fonction de rappel `tools` d’un Agent fondé sur une fonction.
