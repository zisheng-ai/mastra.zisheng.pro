# Mastra.removeWorkspace()

The `.removeWorkspace()` method removes a workspace depuis the Mastra runtime registry. Pass `{ destroy: true }` à destroy the workspace avant it's removed.

## Exemple d’utilisation

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## Renvoie

<PropertiesTable
  content={[
  {
    name: 'removed',
    type: 'Promise<boolean>',
    description: '`true` when a workspace était removed. `false` when aucun workspace exists pour the ID.',
  },
]}
/>

When `destroy` est `true` et `workspace.destroy()` throws, the call rejects avec that error et the workspace remains registered so the caller peut retry cleanup.
