# Mastra.removeWorkspace()

La méthode `.removeWorkspace()` supprime un espace de travail du registre d’exécution Mastra. Passez `{ destroy: true }` pour détruire l’espace de travail avant sa suppression.

## Exemple d’utilisation

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## Valeur renvoyée

<PropertiesTable
  content={[
  {
    name: 'removed',
    type: 'Promise<boolean>',
    description: '`true` lorsqu’un espace de travail a été supprimé. `false` lorsqu’aucun espace de travail n’existe pour cet ID.',
  },
]}
/>

Lorsque `destroy` vaut `true` et que `workspace.destroy()` génère une erreur, l’appel est rejeté avec cette erreur et l’espace de travail reste enregistré afin que l’appelant puisse réessayer le nettoyage.
