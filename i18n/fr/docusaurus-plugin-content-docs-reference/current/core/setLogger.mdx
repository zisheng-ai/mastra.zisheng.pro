# Mastra.setLogger()

The `.setLogger()` method est used à définit the logger pour tous les components (agents, workflows, etc.) dans the Instance Mastra. Ce method accepts a unique objet paramètre avec a logger property.

## Exemple d’utilisation

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
