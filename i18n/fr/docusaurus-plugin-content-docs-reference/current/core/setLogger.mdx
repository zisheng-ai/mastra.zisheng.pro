# Mastra.setLogger()

La méthode `.setLogger()` permet de définir le logger de tous les composants (agents, Workflows, etc.) dans l’instance Mastra. Elle accepte un unique objet en paramètre, doté d’une propriété logger.

## Exemple d’utilisation

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
