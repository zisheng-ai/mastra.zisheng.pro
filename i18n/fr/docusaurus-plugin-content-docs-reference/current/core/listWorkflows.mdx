# Mastra.listWorkflows()

La méthode `.listWorkflows()` permet de récupérer tous les Workflows configurés dans l’instance Mastra. Elle accepte un objet d’options facultatif.

## Exemple d’utilisation

```typescript
mastra.listWorkflows()
```

## Paramètres

<PropertiesTable
  content={[
  {
    name: 'options',
    type: '{ serialized?: boolean }',
    description:
      'Objet de configuration facultatif. Lorsque `serialized` est true, renvoie des objets Workflow simplifiés ne contenant que la propriété name au lieu d’instances complètes de Workflow.',
    optional: true,
  },
]}
/>

## Valeur renvoyée

<PropertiesTable
  content={[
  {
    name: 'workflows',
    type: 'Record<string, Workflow>',
    description:
      'Enregistrement de tous les Workflows configurés, dont les clés sont les ID de Workflow et les valeurs des instances de Workflow (ou des objets simplifiés si serialized est true).',
  },
]}
/>
