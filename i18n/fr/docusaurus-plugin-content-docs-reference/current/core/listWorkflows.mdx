# Mastra.listWorkflows()

The `.listWorkflows()` method est used à retrieve tous les workflows that ont been configuré dans the Instance Mastra. La méthode accepts an facultatif options object.

## Exemple d’utilisation

```typescript
mastra.listWorkflows()
```

## Paramètres

<PropertiesTable
  content={[
  {
    name: 'options',
    type: '{ serialized?: booléen }',
    description:
      'Facultatif configuration object. When `serialized` est true, returns simplified Workflow objects avec only the nom propriété instead de full Workflow instances.',
    optional: true,
  },
]}
/>

  },
]}
