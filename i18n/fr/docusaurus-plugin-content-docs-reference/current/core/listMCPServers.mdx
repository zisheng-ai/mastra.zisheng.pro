# Mastra.listMCPServers()

La méthode `.listMCPServers()` permet de récupérer toutes les instances de serveur MCP enregistrées dans l’instance Mastra. L’enregistrement renvoyé utilise comme clés les clés de registre (les clés de la configuration `mcpServers`).

## Exemple d’utilisation {/* #usage-example */}

```typescript
// Register MCP servers
const server1 = new MCPServer({
  id: 'server-one',
  name: 'Server One',
  version: '1.0.0',
  tools: {/* ... */},
})

const server2 = new MCPServer({
  id: 'server-two',
  name: 'Server Two',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    firstServer: server1, // Registry key: 'firstServer'
    secondServer: server2, // Registry key: 'secondServer'
  },
})

// List all registered servers
const servers = mastra.listMCPServers()
// Returns: { firstServer: MCPServerBase, secondServer: MCPServerBase }
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
