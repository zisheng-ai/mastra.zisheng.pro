# Mastra.listMCPServeurs()

The `.listMCPServers()` method est used à retrieve tous les MCP server instances that ont been registered dans the Instance Mastra. La valeur renvoyée record uses registry keys (the keys depuis the `mcpServers` configuration) comme keys.

## Exemple d’utilisation

```typescript
// Register MCP servers
const server1 = new MCPServer({
  id: 'server-one',
  name: 'Server One',
  version: '1.0.0',
  tools: {/* ... */},
})

const server2 = new MCPServer({
  id: 'server-two',
  name: 'Server Two',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    firstServer: server1, // Registry key: 'firstServer'
    secondServer: server2, // Registry key: 'secondServer'
  },
})

// List all registered servers
const servers = mastra.listMCPServers()
// Returns: { firstServer: MCPServerBase, secondServer: MCPServerBase }
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
