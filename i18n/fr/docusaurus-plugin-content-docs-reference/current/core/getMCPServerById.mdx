# Mastra.getMCPServeurById()

The `.getMCPServerById()` method retrieves an MCP server instance par its intrinsic `id` property. For retrieving par registry clé (the clé used dans configuration), utilise `.getMCPServer()` instead.

## Exemple d’utilisation

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by intrinsic ID
const server = mastra.getMCPServerById('my-mcp-server')

// Alternatively, retrieve by registry key
const serverByKey = mastra.getMCPServer('customKey')
```

## Remarques

- The server's `id` est slugified during construction, so `'myMcpServer'` becomes `'my-mcp-server'`
- If plusieurs servers ont the same `id` mais different versions, you doit fournit the `version` paramètre à disambiguate
- Si aucun `version` est fourni et plusieurs versions exist, the method returns the premier match
