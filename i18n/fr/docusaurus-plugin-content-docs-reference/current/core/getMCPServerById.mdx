# Mastra.getMCPServerById()

La méthode `.getMCPServerById()` récupère une instance de serveur MCP à partir de sa propriété `id` intrinsèque. Pour récupérer un serveur par clé de registre (la clé utilisée dans la configuration), utilisez plutôt `.getMCPServer()`.

## Exemple d’utilisation {/* #usage-example */}

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by intrinsic ID
const server = mastra.getMCPServerById('my-mcp-server')

// Alternatively, retrieve by registry key
const serverByKey = mastra.getMCPServer('customKey')
```

## Remarques {/* #notes */}

- L’`id` du serveur est transformé en slug lors de sa construction ; `'myMcpServer'` devient donc `'my-mcp-server'`
- Si plusieurs serveurs ont le même `id` mais des versions différentes, vous devez fournir le paramètre `version` pour les distinguer
- Si aucun `version` n’est fourni et que plusieurs versions existent, la méthode renvoie la première correspondance
