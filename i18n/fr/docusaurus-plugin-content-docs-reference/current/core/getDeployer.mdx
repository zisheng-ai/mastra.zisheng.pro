# Mastra.getDeployer()

The `.getDeployer()` method is used to retrieve the deployer instance that has been configured in the Mastra instance.

## Usage example

```typescript
mastra.getDeployer()
```

## Parameters

Cette méthode n’accepte aucun paramètre.
