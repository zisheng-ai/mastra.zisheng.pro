# Mastra.getDéployeur()

The `.getDeployer()` method est used à retrieve the deployer instance that possède been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getDeployer()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
