# Mastra.getDeployer()

La méthode `.getDeployer()` permet de récupérer l’instance de deployer configurée dans l’instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getDeployer()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
