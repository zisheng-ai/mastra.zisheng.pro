# Mastra.getGatewayById()

Retrieves a gateway par its unique ID (the `id` propriété de the gateway instance). Ce est useful when you need à find a gateway par its intrinsic identifiant rather than its registration key.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  gateways: {
    customKey: new MyCustomGateway(), // id = 'my-custom-gateway'
  },
})

// Retrieve by ID (not registration key)
const gateway = mastra.getGatewayById('my-custom-gateway')
console.log(gateway.name) // 'My Custom Gateway'
```

## Cas d’utilisation

- Gateway versioning: Different versions avec unique IDs (`'gateway-v1'`, `'gateway-v2'`)
- Finding gateways when registration keys sont unknown
- Identifying gateways across different Instance Mastras
