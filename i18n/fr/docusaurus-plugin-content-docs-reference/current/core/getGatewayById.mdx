# Mastra.getGatewayById()

Récupère une passerelle à partir de son ID unique (la propriété `id` de l’instance de passerelle). Cette méthode est utile pour rechercher une passerelle par son identifiant intrinsèque plutôt que par sa clé d’enregistrement.

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  gateways: {
    customKey: new MyCustomGateway(), // id = 'my-custom-gateway'
  },
})

// Retrieve by ID (not registration key)
const gateway = mastra.getGatewayById('my-custom-gateway')
console.log(gateway.name) // 'My Custom Gateway'
```

## Cas d’utilisation

- Versionnement des passerelles : différentes versions avec des ID uniques (`'gateway-v1'`, `'gateway-v2'`)
- Recherche de passerelles lorsque les clés d’enregistrement sont inconnues
- Identification de passerelles entre différentes instances Mastra
