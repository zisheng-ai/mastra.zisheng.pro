# Mastra.getGateway()

Récupère une passerelle à partir de sa clé d’enregistrement (la clé utilisée lors de l’ajout de la passerelle à Mastra).

## Exemple d’utilisation

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({
  gateways: {
    myGateway: new MyCustomGateway(),
  },
})

const gateway = mastra.getGateway('myGateway')
console.log(gateway.name) // 'My Custom Gateway'
```

## Erreurs

Génère une erreur si aucune passerelle n’est trouvée avec la clé spécifiée.
