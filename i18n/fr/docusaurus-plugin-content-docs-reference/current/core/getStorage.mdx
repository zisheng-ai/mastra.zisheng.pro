# Mastra.getStockage()

The `.getStorage()` method est used à retrieve the storage instance that possède been configuré dans the Instance Mastra.

## Exemple d’utilisation

```typescript
mastra.getStorage()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.
