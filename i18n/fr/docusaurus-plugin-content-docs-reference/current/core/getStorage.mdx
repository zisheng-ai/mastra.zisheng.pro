# Mastra.getStorage()

La méthode `.getStorage()` permet de récupérer l’instance de stockage configurée dans l’instance Mastra.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.getStorage()
```

## Paramètres {/* #parameters */}

Cette méthode n’accepte aucun paramètre.
