# Mastra.listLogs()

The `.listLogs()` method est used à retrieve tous les logs pour a specific transport ID. Ce method requires a configuré logger that supports the `listLogs` operation.

## Exemple d’utilisation

```typescript
mastra.listLogs('456')
```
