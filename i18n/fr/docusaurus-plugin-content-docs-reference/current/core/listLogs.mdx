# Mastra.listLogs()

La méthode `.listLogs()` permet de récupérer tous les journaux associés à un ID de transport précis. Elle nécessite un logger configuré qui prend en charge l’opération `listLogs`.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.listLogs('456')
```
