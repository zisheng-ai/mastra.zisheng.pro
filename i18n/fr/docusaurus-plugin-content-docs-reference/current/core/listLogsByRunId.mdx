# Mastra.listLogsByRunId()

La méthode `.listLogsByRunId()` permet de récupérer les logs pour un ID d’exécution et un ID de transport spécifiques. Elle exige un logger configuré qui prend en charge l’opération `listLogsByRunId`.

## Exemple d’utilisation {/* #usage-example */}

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
