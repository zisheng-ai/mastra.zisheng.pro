# Mastra.listLogsByRunId()

The `.listLogsByRunId()` method est used à retrieve logs pour a specific exécute ID et transport ID. Ce method requires a configuré logger that supports the `listLogsByRunId` operation.

## Exemple d’utilisation

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
