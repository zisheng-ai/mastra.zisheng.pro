# Structure du projet

Votre nouveau projet Mastra, créé avec la commande `create mastra`, comprend un ensemble prédéfini de fichiers et de dossiers pour vous aider à démarrer.

Mastra est un framework, mais il reste largement **agnostique** quant à la façon dont vous organisez ou colocalisez vos fichiers. La CLI fournit une structure par défaut judicieuse qui convient à la plupart des projets, mais vous pouvez l’adapter à votre flux de travail ou aux conventions de votre équipe. Vous pouvez même construire l’intégralité de votre projet dans un seul fichier si vous le souhaitez ! Quelle que soit la structure choisie, restez cohérent afin que votre code demeure maintenable et facile à parcourir.

## Structure de projet par défaut

Un projet créé avec la commande `create mastra` se présente ainsi :

```bash
src/
├── mastra/
│   ├── agents/
│   │   └── weather-agent.ts
│   ├── tools/
│   │   └── weather-tool.ts
│   ├── workflows/
│   │   └── weather-workflow.ts
│   ├── scorers/
│   │   └── weather-scorer.ts
│   └── index.ts
├── .env.example
├── package.json
└── tsconfig.json
```

Utilisez les fichiers prédéfinis comme modèles. Dupliquez-les et adaptez-les pour créer rapidement vos propres agents, outils, workflows, etc.

### Dossiers

Mastra recommande d’organiser votre code dans les dossiers suivants :

| Dossier | Description |
| - | - |
| `src/mastra` | Point d’entrée de tout le code et de toute la configuration liés à Mastra. |
| `src/mastra/agents` | Définissez et configurez vos agents : leur comportement, leurs objectifs et leurs outils. |
| `src/mastra/workflows` | Définissez des workflows à plusieurs étapes qui orchestrent conjointement les agents et les outils. |
| `src/mastra/tools` | Créez des outils réutilisables que vos agents peuvent appeler. |
| `src/mastra/mcp` | Implémentez des serveurs MCP personnalisés pour partager vos outils avec des agents externes. |
| `src/mastra/scorers` | Définissez des scorers pour évaluer les performances des agents au fil du temps. |

Mastra comporte deux conventions particulières pour les dossiers :

- `src/mastra/agents/<name>`: Vous pouvez définir un agent par convention de fichier plutôt que de le construire dans le code. Pour en savoir plus, consultez la documentation [Agents basés sur des fichiers](/docs/getting-started/develop#file-based-agents).
- `src/mastra/public`: Son contenu est copié dans le répertoire `.build/output` pendant le processus de compilation, ce qui le rend disponible au moment de l’exécution.

### Fichiers de premier niveau

Les fichiers de premier niveau définissent la façon dont votre projet Mastra est configuré, compilé et connecté à son environnement.

| Fichier | Description |
| - | - |
| `src/mastra/index.ts` | Point d’entrée central où vous configurez et initialisez Mastra. |
| `.env.example` | Modèle pour les variables d’environnement : copiez-le et renommez-le en `.env` pour ajouter les clés secrètes de votre [fournisseur de modèles](/models). |
| `package.json` | Définit les métadonnées du projet, les dépendances et les scripts npm disponibles. |
| `tsconfig.json` | Configure les options TypeScript telles que les alias de chemin, les paramètres du compilateur et la sortie de compilation. |
