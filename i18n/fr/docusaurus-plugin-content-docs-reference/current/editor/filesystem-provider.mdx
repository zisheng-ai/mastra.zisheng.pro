# FilesystemProvider

`FilesystemProvider` est l’interface qu’un package implémente pour enregistrer un système de fichiers auprès de [`MastraEditor`](/reference/editor/mastra-editor). L’Editor appelle `createFilesystem(config)` lors de l’hydratation du Workspace et utilise comme clé de recherche l’ID `provider` de la configuration du système de fichiers enregistrée dans [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref).

Le fournisseur de système de fichiers `local` intégré est enregistré automatiquement. Les fournisseurs externes, tels que S3 ou GCS, sont transmis au moyen de `MastraEditorConfig.filesystems`.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { s3FilesystemProvider } from '@mastra/s3'

new MastraEditor({
  filesystems: {
    [s3FilesystemProvider.id]: s3FilesystemProvider,
  },
})
```

## Implémenter un fournisseur {/* #implementing-a-provider */}

```typescript title="src/providers/my-filesystem.ts"
import type { FilesystemProvider, WorkspaceFilesystem } from '@mastra/core/editor'

export const myFilesystemProvider: FilesystemProvider<{ bucket: string; region: string }> = {
  id: 'my-fs',
  name: 'My Filesystem',
  description: 'Object-store-backed filesystem.',
  configSchema: {
    type: 'object',
    required: ['bucket', 'region'],
    properties: {
      bucket: { type: 'string' },
      region: { type: 'string' },
    },
  },
  async createFilesystem(config): Promise<WorkspaceFilesystem> {
    return createMyFilesystem({ bucket: config.bucket, region: config.region })
  },
}
```

Une fois le fournisseur enregistré, les administrateurs peuvent le référencer depuis une configuration de Workspace intégrée ou un objet [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) enregistré.
