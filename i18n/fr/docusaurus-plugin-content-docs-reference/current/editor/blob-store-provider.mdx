# BlobStoreProvider

`BlobStoreProvider` est l’interface qu’un package implémente pour enregistrer un stockage de blobs auprès de [`MastraEditor`](/reference/editor/mastra-editor). Les stockages de blobs contiennent des blobs de Skills adressables par leur contenu ainsi que d’autres artefacts volumineux produits par Editor.

Le Provider `storage` intégré utilise le domaine `blobs` du backend de stockage configuré. Les Providers externes, par exemple S3, sont fournis par l’intermédiaire de `MastraEditorConfig.blobStores`.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { s3BlobStoreProvider } from '@mastra/s3'

new MastraEditor({
  blobStores: {
    [s3BlobStoreProvider.id]: s3BlobStoreProvider,
  },
})
```

## Implémenter un Provider {/* #implementing-a-provider */}

```typescript title="src/providers/my-blob-store.ts"
import type { BlobStore, BlobStoreProvider } from '@mastra/core/editor'

export const myBlobStoreProvider: BlobStoreProvider<{ bucket: string; region: string }> = {
  id: 'my-blob-store',
  name: 'My Blob Store',
  description: 'Object-store-backed blob storage.',
  configSchema: {
    type: 'object',
    required: ['bucket', 'region'],
    properties: {
      bucket: { type: 'string' },
      region: { type: 'string' },
    },
  },
  async createBlobStore(config): Promise<BlobStore> {
    return createMyBlobStore({ bucket: config.bucket, region: config.region })
  },
}
```

Lorsqu’aucun `providerId` n’est transmis à `MastraEditor.resolveBlobStore()`, Editor utilise par défaut le domaine `blobs` du backend de stockage.
