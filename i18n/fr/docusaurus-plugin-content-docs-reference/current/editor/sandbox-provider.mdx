# SandboxProvider

`SandboxProvider` est l'interface qu'un package implémente pour enregistrer un Sandbox auprès de [`MastraEditor`](/reference/editor/mastra-editor). Lors de l'hydratation du Workspace, l'éditeur appelle `createSandbox(config)` en utilisant comme clé de recherche l'ID `provider` de la configuration du Sandbox stockée dans [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref).

Le fournisseur de Sandbox `local` intégré est enregistré automatiquement. Les fournisseurs externes, comme E2B, sont transmis via `MastraEditorConfig.sandboxes`.

## Exemple d'utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { e2bSandboxProvider } from '@mastra/e2b'

new MastraEditor({
  sandboxes: {
    [e2bSandboxProvider.id]: e2bSandboxProvider,
  },
})
```

## Implémenter un fournisseur {/* #implementing-a-provider */}

```typescript title="src/providers/my-sandbox.ts"
import type { SandboxProvider, WorkspaceSandbox } from '@mastra/core/editor'

export const mySandboxProvider: SandboxProvider<{ apiKey: string }> = {
  id: 'my-sandbox',
  name: 'My Sandbox',
  description: 'Cloud sandbox for command execution.',
  configSchema: {
    type: 'object',
    required: ['apiKey'],
    properties: {
      apiKey: { type: 'string' },
    },
  },
  async createSandbox(config): Promise<WorkspaceSandbox> {
    return createMySandbox({ apiKey: config.apiKey })
  },
}
```

Une fois le fournisseur enregistré, les administrateurs peuvent le référencer depuis une configuration de Workspace en ligne ou depuis un [`StorageWorkspaceRef`](/reference/editor/storage-workspace-ref) stocké.
