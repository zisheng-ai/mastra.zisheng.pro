# StorageBrowserRef

`StorageBrowserRef` est la configuration de navigateur intégrée associée à un Agent enregistré. L’ID `provider` est résolu lors de l’hydratation par rapport au [`BrowserProvider`](/reference/editor/browser-provider) enregistré dans [`MastraEditor.browsers`](/reference/editor/mastra-editor).

Il s’agit du type utilisé par [`BuilderAgentDefaults.browser`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) et par les enregistrements d’Agents stockés.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { stagehandBrowserProvider } from '@mastra/stagehand'

new MastraEditor({
  browsers: { [stagehandBrowserProvider.id]: stagehandBrowserProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        browser: {
          type: 'inline',
          config: {
            provider: 'stagehand',
            headless: true,
            viewport: { width: 1280, height: 720 },
          },
        },
      },
    },
  },
})
```

## Type {/* #type */}

```typescript
type StorageBrowserRef = { type: 'inline'; config: StorageBrowserConfig }
```

Aucune variante `{ type: 'id' }` n’est disponible pour les navigateurs : leur configuration est toujours intégrée.

## Hydratation {/* #hydration */}

`StorageBrowserRef` est résolu de manière différée lors de l’appel de `mastra.editor.agent.getById()`. L’Editor recherche `config.provider` dans `MastraEditor.browsers` et appelle `provider.createBrowser(config)`. Si le fournisseur n’est pas enregistré, l’Editor consigne un avertissement et renvoie `undefined` : l’Agent est tout de même chargé, mais sans navigateur.
