# StockageNavigateurRef

`StorageBrowserRef` est the inline browser configuration attached à a stored agent. The `provider` id est resolved à hydration time against the [NavigateurFournisseur](/reference/editor/browser-provider) registered sur [`MastraEditor.browsers`](/reference/editor/mastra-editor).

It's the type used par [BuilderAgentDefaults](https://agent-builder.mastra.ai/reference/builder-agent-defaults) et par stored agent records.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { stagehandBrowserProvider } from '@mastra/stagehand'

new MastraEditor({
  browsers: { [stagehandBrowserProvider.id]: stagehandBrowserProvider },
  builder: {
    enabled: true,
    configuration: {
      agent: {
        browser: {
          type: 'inline',
          config: {
            provider: 'stagehand',
            headless: true,
            viewport: { width: 1280, height: 720 },
          },
        },
      },
    },
  },
})
```

## Type

```typescript
type StorageBrowserRef = { type: 'inline'; config: StorageBrowserConfig }
```

Un `{ type: 'id' }` variant pour browsers isn't available: they're always inlined.

## Hydration

`StorageBrowserRef` est resolved lazily sur `mastra.editor.agent.getById()`. The editor looks up `config.provider` sur `MastraEditor.browsers` et calls `provider.createBrowser(config)`. Si le provider isn't registered, the editor logs a warning et returns `undefined`: the agent still loads, mais sans a browser.
