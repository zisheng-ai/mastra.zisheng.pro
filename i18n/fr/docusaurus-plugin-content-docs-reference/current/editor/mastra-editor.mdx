# Classe MastraEditor

La classe `MastraEditor` configure le système d’édition. Transmettez-la au constructeur `Mastra` pour activer les fonctionnalités de l’éditeur, telles que les blocs de prompt, la surcharge du code des agents, le versionnage et les fournisseurs d’outils.

Consultez [Editor](/docs/editor/overview) pour une présentation des fonctions de l’éditeur.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'

export const mastra = new Mastra({
  agents: {/* your agents */},
  editor: new MastraEditor(),
})
```

## Agent Builder {/* #agent-builder */}

Le champ `builder` active [Agent Builder](https://agent-builder.mastra.ai/), une interface utilisateur web permettant de créer et modifier des agents stockés. Consultez :

- [Présentation d’Agent Builder](https://agent-builder.mastra.ai/) : concepts et prise en main.
- [AgentBuilderOptions](https://agent-builder.mastra.ai/reference/agent-builder-options) : schéma complet des options.
- [BuilderAgentDefaults](https://agent-builder.mastra.ai/reference/builder-agent-defaults) : valeurs par défaut épinglées par l’administrateur pour les nouveaux agents.
- [builder.configuration.agent.models](https://agent-builder.mastra.ai/reference/builder-models) : liste autorisée de modèles et modèle par défaut.

### Enregistrer l’agent Builder {/* #registering-the-builder-agent */}

L’interface de Builder s’exécute avec un agent créé par la fabrique `createBuilderAgent()` de `@mastra/editor/ee`. Importez la fabrique, appelez-la, puis enregistrez l’agent renvoyé dans `agents` sur votre instance Mastra :

```typescript filename="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraEditor } from '@mastra/editor'
import { createBuilderAgent } from '@mastra/editor/ee'

export const mastra = new Mastra({
  agents: { builderAgent: createBuilderAgent() },
  editor: new MastraEditor({
    builder: { enabled: true },
  }),
})
```

Le nom de clé (`builderAgent`) est une convention. Toute clé convient. Le sous-chemin `@mastra/editor/ee` est contrôlé à l’exécution par la licence Mastra Enterprise Edition.

Consultez la [présentation d’Agent Builder](https://agent-builder.mastra.ai/#prerequisites) pour la liste complète des étapes de configuration.

## Espaces de noms {/* #namespaces */}

L’éditeur expose des espaces de noms permettant de gérer différents types d’entités. Accédez-y depuis toute instance Mastra avec `mastra.getEditor()` et appelez directement les méthodes CRUD dans le code de l’application, ou utilisez les routes du serveur Mastra qui s’en servent en interne.

Tous les espaces de noms étendent une classe de base CRUD commune ; ils exposent donc les mêmes méthodes `create`, `getById`, `update`, `delete`, `list`, `listResolved` et `clearCache`. ### Exemples d’espace de noms d’agent {/* #agent-namespace-examples */}

Créez un remplacement stocké pour un agent existant défini dans le code :

```typescript title="src/scripts/seed-agent.ts"
import { mastra } from '../mastra'

const editor = mastra.getEditor()!

await editor.agent.create({
  id: 'support-agent',
  instructions: 'You are a friendly support agent for Acme.',
  tools: {
    search_kb: { description: 'Search the Acme knowledge base' },
  },
})
```

## Méthodes {/* #methods */}

### Accès aux fournisseurs {/* #provider-access */}

#### `getToolProvider(id)` {/* #gettoolproviderid */}

Renvoie un fournisseur d’outils enregistré à partir de son ID.

```typescript
const composio = mastra.getEditor()?.getToolProvider('composio')
```

#### `getToolProviders()` {/* #gettoolproviders */}

Renvoie tous les fournisseurs d’outils enregistrés sous la forme d’un `Record<string, ToolProvider>`.

#### `getProcessorProvider(id)` {/* #getprocessorproviderid */}

Renvoie un fournisseur de processeurs enregistré à partir de son ID.

#### `getProcessorProviders()` {/* #getprocessorproviders */}

Renvoie tous les fournisseurs de processeurs enregistrés.

#### `getFilesystemProviders()` {/* #getfilesystemproviders */}

Renvoie tous les fournisseurs de systèmes de fichiers enregistrés.

#### `getSandboxProviders()` {/* #getsandboxproviders */}

Renvoie tous les fournisseurs de sandbox enregistrés.

#### `getBlobStoreProviders()` {/* #getblobstoreproviders */}

Renvoie tous les fournisseurs de magasins blob enregistrés.

### Source {/* #source */}

#### `getSource()` {/* #getsource */}

Renvoie la source configurée (`'code'` ou `'db'`), ou `undefined` lorsque l’éditeur a été construit sans `source` explicite.

```typescript
const source = mastra.getEditor()?.getSource()
```

Valeur renvoyée : `'code' | 'db' | undefined`

Lorsque `source` est omise, Editor utilise le stockage de base de données configuré même si `getSource()` renvoie `undefined`. Consultez les [options de stockage d’Editor](/docs/editor/overview#choose-where-changes-are-stored) pour les flux de stockage et le [versionnage de la source de code](/reference/editor/versioning#code-source) pour l’activation et le comportement de l’historique Git.
