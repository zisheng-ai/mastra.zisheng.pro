# ProcessorProvider

`ProcessorProvider` est l’interface qu’un package implémente pour enregistrer un Processor configurable auprès de [`MastraEditor`](/reference/editor/mastra-editor). Les fournisseurs de Processor remplissent deux fonctions :

1. **Découverte :** l’interface utilisateur emploie `info`, `configSchema` et `availablePhases` pour afficher les formulaires de configuration.
1. **Exécution :** l’Editor appelle `createProcessor(config)` lors de l’hydratation de l’Agent afin d’instancier les Processors à partir de la configuration enregistrée.

Les fournisseurs sont transmis au moyen de `MastraEditorConfig.processorProviders`.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { moderationProcessorProvider } from '@mastra/processors/moderation'

new MastraEditor({
  processorProviders: {
    moderation: moderationProcessorProvider,
  },
})
```

## Implémenter un fournisseur {/* #implementing-a-provider */}

```typescript title="src/providers/my-processor.ts"
import type { ProcessorProvider } from '@mastra/core/processor-provider'
import { z } from 'zod'
import { MyProcessor } from './my-processor-impl'

export const myProcessorProvider: ProcessorProvider = {
  info: {
    id: 'my-processor',
    name: 'My Processor',
    description: 'Filters output for sensitive content.',
  },
  configSchema: z.object({
    threshold: z.number().min(0).max(1),
  }),
  availablePhases: ['processOutputStream', 'processOutputResult'],
  createProcessor(config) {
    return new MyProcessor(config as { threshold: number })
  },
}
```
