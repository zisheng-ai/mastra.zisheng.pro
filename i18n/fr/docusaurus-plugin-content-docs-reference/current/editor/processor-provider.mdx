# ProcessorFournisseur

`ProcessorProvider` est the interface a package implements à register a configurable processor avec [MastraÉditeur class](/reference/editor/mastra-editor). Processor providers serve deux purposes:

1. **Discovery:** The UI uses `info`, `configSchema`, et `availablePhases` à affiche configuration forms.
1. **Runtime:** The editor calls `createProcessor(config)` during agent hydration à instantiate processors depuis stored configuration.

Fournisseurs sont supplied via `MastraEditorConfig.processorProviders`.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { moderationProcessorProvider } from '@mastra/processors/moderation'

new MastraEditor({
  processorProviders: {
    moderation: moderationProcessorProvider,
  },
})
```

## Implementing a provider

```typescript title="src/providers/my-processor.ts"
import type { ProcessorProvider } from '@mastra/core/processor-provider'
import { z } from 'zod'
import { MyProcessor } from './my-processor-impl'

export const myProcessorProvider: ProcessorProvider = {
  info: {
    id: 'my-processor',
    name: 'My Processor',
    description: 'Filters output for sensitive content.',
  },
  configSchema: z.object({
    threshold: z.number().min(0).max(1),
  }),
  availablePhases: ['processOutputStream', 'processOutputResult'],
  createProcessor(config) {
    return new MyProcessor(config as { threshold: number })
  },
}
```
