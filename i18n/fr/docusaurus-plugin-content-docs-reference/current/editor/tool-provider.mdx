# ToolProvider

L'interface `ToolProvider` définit la manière dont l'éditeur découvre et résout les tools d'intégration provenant de plateformes externes. Mastra comprend deux implémentations intégrées : `ComposioToolProvider` et `ArcadeToolProvider`.

Consultez les [tools de l'Editor](/docs/editor/overview#tools) pour configurer le Provider et découvrir le workflow de Studio. Consultez la [configuration des tools](/reference/editor/tools) pour en savoir plus sur les sélections enregistrées et le comportement de résolution.

## ComposioToolProvider {/* #composiotoolprovider */}

Se connecte à [Composio](https://composio.dev) pour accéder à des centaines de tools d'intégration.

### Exemple d'utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { ComposioToolProvider } from '@mastra/editor/composio'

const editor = new MastraEditor({
  toolProviders: {
    composio: new ComposioToolProvider({
      apiKey: process.env.COMPOSIO_API_KEY!,
    }),
  },
})
```

### Slugs des tools {/* #tool-slugs */}

Les tools Composio utilisent des slugs en majuscules : `GITHUB_CREATE_ISSUE`, `SLACK_SEND_MESSAGE`.

### Authentification {/* #authentication */}

Par défaut, les connexions utilisent la portée par auteur. Définissez `defaultScope: 'caller-supplied'` pour regrouper les autorisations selon l'identité de l'appelant déterminée à partir de `MASTRA_RESOURCE_ID_KEY` dans le contexte de la requête. Veillez à ce que chaque requête authentifiée fournisse un identifiant de ressource stable et unique. Lorsque vous utilisez `MastraAuthWorkos`, configurez `mapUserToResourceId` afin de définir cette valeur à partir de l'utilisateur authentifié.

### Tools de gestion des connexions {/* #connection-management-tools */}

Composio fournit des tools permettant de démarrer et de surveiller l'autorisation depuis une conversation avec un agent. Lorsque `allowedToolkits` est défini, incluez `composio` pour rendre ces tools disponibles :

```typescript title="src/mastra/index.ts"
const editor = new MastraEditor({
  toolProviders: {
    composio: new ComposioToolProvider({
      apiKey: process.env.COMPOSIO_API_KEY!,
      allowedToolkits: ['composio', 'gmail'],
      defaultScope: 'caller-supplied',
    }),
  },
})
```

Ajoutez uniquement les tools de gestion des connexions dont l'agent a besoin :

| Tool | Comportement |
| - | - |
| `COMPOSIO_MANAGE_CONNECTIONS` | Crée un lien d'autorisation dans la conversation par l'intermédiaire d'une session appartenant à l'appelant. |
| `COMPOSIO_WAIT_FOR_CONNECTIONS` | Attend que l'appelant termine l'autorisation avant que l'agent poursuive. |

`COMPOSIO_WAIT_FOR_CONNECTIONS` est facultatif. Sans ce tool, terminez l'autorisation et revenez à la conversation. Demandez ensuite à l'agent de poursuivre. Le compte connecté reste associé à l'identifiant de ressource de l'appelant pour les requêtes ultérieures.

## ArcadeToolProvider {/* #arcadetoolprovider */}

Se connecte à [Arcade](https://arcade.dev) pour accéder à un catalogue de tools sélectionnés avec authentification intégrée.

### Exemple d'utilisation {/* #usage-example-1 */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'
import { ArcadeToolProvider } from '@mastra/editor/arcade'

const editor = new MastraEditor({
  toolProviders: {
    arcade: new ArcadeToolProvider({
      apiKey: process.env.ARCADE_API_KEY!,
    }),
  },
})
```

### Slugs des tools {/* #tool-slugs-1 */}

Les tools Arcade utilisent le format `Toolkit.ToolName` : `Github.GetRepository`, `Slack.SendMessage`.

### Authentification {/* #authentication-1 */}

L'ancien résolveur Arcade utilise `resourceId` depuis le contexte de la requête lorsqu'il est disponible. Sinon, il se rabat sur le `userId` fourni, puis sur une identité `default` partagée. N'utilisez `default` que pour les intégrations volontairement partagées. Dans les déploiements où les locataires sont isolés, fournissez un `resourceId` fiable et stable ou un `userId` explicite. Omettre les deux n'isole pas les appelants.
