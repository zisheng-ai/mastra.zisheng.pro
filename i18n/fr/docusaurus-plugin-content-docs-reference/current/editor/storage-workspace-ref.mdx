# StockageWorkspaceRef

`StorageWorkspaceRef` est the discriminated union used à attach a workspace à a stored agent. It either points à a workspace registered sur the Mastra runtime par ID, ou embeds a workspace snapshot inline.

It's the type used par [BuilderAgentDefaults](https://agent-builder.mastra.ai/reference/builder-agent-defaults) et par stored agent records.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

// Variant 1 — reference a runtime workspace by id
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: { type: 'id', workspaceId: 'builder-workspace' },
      },
    },
  },
})

// Variant 2 — inline a workspace snapshot
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'inline',
          config: {
            name: 'inline-builder-workspace',
            filesystem: {
              provider: 'local',
              config: { basePath: './agent-files' },
            },
          },
        },
      },
    },
  },
})
```

## Hydration

`StorageWorkspaceRef` est resolved lazily sur `mastra.editor.agent.getById()`, ne pas sur `list()`. The editor looks up filesystem et sandbox providers sur `MastraEditor.filesystems` / `MastraEditor.sandboxes` et materializes a runtime `Workspace`. Missing providers surface comme a warning et the workspace est omitted.
