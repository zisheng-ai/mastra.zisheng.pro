# StorageWorkspaceRef

`StorageWorkspaceRef` est l'union discriminée utilisée pour associer un Workspace à un Agent stocké. Elle désigne soit un Workspace enregistré par identifiant dans l'environnement d'exécution Mastra, soit un instantané de Workspace intégré en ligne.

Il s'agit du type utilisé par [`BuilderAgentDefaults.workspace`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) et par les enregistrements d'Agents stockés.

## Exemple d'utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

// Variant 1 — reference a runtime workspace by id
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: { type: 'id', workspaceId: 'builder-workspace' },
      },
    },
  },
})

// Variant 2 — inline a workspace snapshot
new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        workspace: {
          type: 'inline',
          config: {
            name: 'inline-builder-workspace',
            filesystem: {
              provider: 'local',
              config: { basePath: './agent-files' },
            },
          },
        },
      },
    },
  },
})
```

## Hydratation {/* #hydration */}

`StorageWorkspaceRef` est résolu de manière différée lors de l'appel à `mastra.editor.agent.getById()`, et non lors de l'appel à `list()`. L'Editor recherche les Providers de système de fichiers et de Sandbox dans `MastraEditor.filesystems` / `MastraEditor.sandboxes`, puis matérialise un `Workspace` d'exécution. Les Providers manquants donnent lieu à un avertissement et le Workspace est omis.
