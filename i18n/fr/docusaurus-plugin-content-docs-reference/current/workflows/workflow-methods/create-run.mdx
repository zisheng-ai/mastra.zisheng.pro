# Workflow\.createRun()

La méthode `.createRun()` crée une nouvelle instance d’exécution de Workflow, ce qui permet d’exécuter le Workflow avec des données d’entrée spécifiques. Il s’agit de l’API actuelle qui renvoie une instance `Run`.

## Exemple d’utilisation

```typescript
await workflow.createRun()
```

## Exemple d’utilisation avancé

```typescript
const workflow = mastra.getWorkflow('workflow')

const run = await workflow.createRun()

const result = await run.start({
  inputData: {
    value: 10,
  },
})
```

## Utiliser `resourceId`

Le paramètre `resourceId` associe une exécution de Workflow à une ressource spécifique, comme un utilisateur ou un tenant. Cela est utile pour les applications multitenant ou lorsque vous devez savoir quel utilisateur a démarré un Workflow.

```typescript
const workflow = mastra.getWorkflow('workflow')

// Create a run associated with a specific user
const run = await workflow.createRun({
  resourceId: 'user-123',
})

const result = await run.start({
  inputData: {
    value: 10,
  },
})

// Later, retrieve the run and access the resourceId
const storedRun = await workflow.getWorkflowRunById(run.runId)
console.log(storedRun.resourceId) // "user-123"
```
