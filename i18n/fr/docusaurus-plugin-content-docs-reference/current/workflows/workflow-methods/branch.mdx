# Workflow\.branch()

La méthode `.branch()` crée des branches conditionnelles entre les étapes du Workflow, ce qui permet d’emprunter différents chemins selon le résultat d’une étape précédente.

## Exemple d’utilisation {/* #usage-example */}

```typescript
workflow.branch([
  [async ({ context }) => true, step1],
  [async ({ context }) => false, step2],
])
```
