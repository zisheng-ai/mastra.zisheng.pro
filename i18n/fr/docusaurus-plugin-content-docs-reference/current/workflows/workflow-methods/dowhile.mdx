# Workflow\.dowhile()

La méthode `.dowhile()` exécute une étape tant qu’une condition est remplie. Elle exécute toujours l’étape au moins une fois avant d’évaluer la condition. Lors de la première évaluation de la condition, `iterationCount` vaut `1`.

## Exemple d’utilisation {/* #usage-example */}

```typescript
workflow.dowhile(step1, async ({ inputData }) => true)
```
