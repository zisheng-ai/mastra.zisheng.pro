# Workflow\.sleep()

La méthode `.sleep()` suspend l’exécution pendant un nombre de millisecondes spécifié. Elle accepte un nombre statique ou une fonction de rappel pour les délais définis au moment de l’exécution.

## Exemple d’utilisation

```typescript
workflow.sleep(5000)
```

## Exemple d’utilisation avancé

```typescript prettier:false
import { createWorkflow, createStep } from "@mastra/core/workflows";

const step1 = createStep({...});
const step2 = createStep({...});

export const testWorkflow = createWorkflow({...})
  .then(step1)
  .sleep(async ({ inputData }) => {
    const { delayInMs } = inputData;
    return delayInMs;
  })
  .then(step2)
  .commit();
```
