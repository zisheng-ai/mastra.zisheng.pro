# Workflow\.dountil()

La méthode `.dountil()` exécute une étape jusqu’à ce qu’une condition soit remplie. Elle exécute toujours l’étape au moins une fois avant d’évaluer la condition. Lors de la première évaluation de la condition, `iterationCount` vaut `1`.

## Exemple d’utilisation

```typescript
workflow.dountil(step1, async ({ inputData }) => true)
```
