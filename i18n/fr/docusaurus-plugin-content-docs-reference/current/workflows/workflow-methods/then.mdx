# Workflow\.then()

La méthode `.then()` crée une dépendance séquentielle entre les étapes du Workflow, garantissant qu’elles s’exécutent dans un ordre spécifique.

## Exemple d’utilisation

```typescript
workflow.then(step1).then(step2)
```
