# Workflow\.agent()

La méthode `.agent()` ajoute un Agent comme étape déclarative. L’étape accepte `{ prompt: string }` comme entrée et renvoie `{ text: string }` par défaut. Utilisez `.map()` avant l’Agent pour construire le prompt à partir des données du Workflow.

Contrairement à l’encapsulation d’un Agent avec `createStep()`, `.agent()` enregistre une entrée déclarative dans le graphe du Workflow. Le Workflow devient ainsi portable : le même graphe peut être sérialisé et conservé comme [Workflow dynamique](/docs/workflows/dynamic-workflows).

## Exemple d’utilisation {/* #usage-example */}

```typescript filename="src/mastra/workflows/test-workflow.ts" prettier:false
workflow
  .map({ prompt: mapVariable({ initData: workflow, path: "topic" }) })
  .agent(testAgent)
  .commit();
```

## Sortie structurée {/* #structured-output */}

Par défaut, la sortie de l’étape est `{ text: string }`. Transmettez `structuredOutput.schema` pour que l’étape renvoie plutôt cette forme. Le schéma devient le schéma de sortie de l’étape, ce qui permet aux étapes ultérieures de s’y chaîner avec une sécurité de type complète :

```typescript filename="src/mastra/workflows/test-workflow.ts" prettier:false
workflow
  .agent(testAgent, {
    structuredOutput: {
      schema: z.object({
        subtopics: z.array(z.string()),
      }),
    },
  })
  .commit();
```

## Référencer un Agent par ID {/* #referencing-an-agent-by-id */}

Transmettez une chaîne pour référencer un Agent enregistré sans l’importer. L’Agent doit être enregistré dans l’instance Mastra lorsque le Workflow s’exécute :

```typescript filename="src/mastra/workflows/test-workflow.ts" prettier:false
workflow.agent("test-agent", { maxSteps: 3 }).commit();
```

## Conserver les étapes d’Agent {/* #persisting-agent-steps */}

Les Workflows construits avec `.agent()` se sérialisent dans les mêmes entrées déclaratives que les [Workflows dynamiques](/docs/workflows/dynamic-workflows). Seuls `retries` et `metadata` effectuent un aller-retour via le stockage. Les options qui contiennent des fonctions, telles que `onFinish` ou un `toolChoice` dont la valeur est une fonction, lèvent une erreur lorsque le Workflow est conservé.
