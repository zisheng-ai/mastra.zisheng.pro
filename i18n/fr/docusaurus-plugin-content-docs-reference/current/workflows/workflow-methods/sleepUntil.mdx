# Workflow\.sleepUntil()

La méthode `.sleepUntil()` suspend l’exécution jusqu’à une date spécifiée.

## Exemple d’utilisation {/* #usage-example */}

```typescript
workflow.sleepUntil(new Date(Date.now() + 5000))
```

## Exemple d’utilisation avancé {/* #extended-usage-example */}

```typescript prettier:false
import { createWorkflow, createStep } from "@mastra/core/workflows";

const step1 = createStep({...});
const step2 = createStep({...});

export const testWorkflow = createWorkflow({...})
  .then(step1)
  .sleepUntil(async ({ inputData }) => {
    const { delayInMs } = inputData;
    return new Date(Date.now() + delayInMs);
  })
  .then(step2)
  .commit();
```
