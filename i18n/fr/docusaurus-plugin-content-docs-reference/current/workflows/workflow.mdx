# Classe Workflow

La classe `Workflow` permet de créer des machines à états pour des séquences complexes d’opérations avec branchement conditionnel et validation des données.

## Exemple d’utilisation

```typescript title="src/mastra/workflows/test-workflow.ts"
import { createWorkflow } from '@mastra/core/workflows'
import { z } from 'zod'

export const workflow = createWorkflow({
  id: 'test-workflow',
  inputSchema: z.object({
    value: z.string(),
  }),
  outputSchema: z.object({
    value: z.string(),
  }),
})
```

## Définir des schémas

Vous pouvez définir les `inputSchema` et `outputSchema` du Workflow avec toute bibliothèque prenant en charge [Standard JSON Schema](https://standardschema.dev/json-schema), notamment [Zod](https://zod.dev/), [Valibot](https://valibot.dev/) et [ArkType](https://arktype.io/).

## Exécuter avec un état initial

Lors du démarrage d’une exécution de Workflow, vous pouvez transmettre `initialState` pour définir les valeurs de départ de l’état du Workflow :

```typescript
const run = await workflow.createRun()

const result = await run.start({
  inputData: { value: 'hello' },
  initialState: {
    counter: 0,
    items: [],
  },
})
```

L’objet `initialState` doit correspondre à la structure définie dans le `stateSchema` du Workflow. Consultez [État du Workflow](/docs/workflows/workflow-state) pour plus de détails.

### Gérer l’état tripwire

Lorsqu’un Workflow contient une étape d’Agent qui déclenche un tripwire, le Workflow renvoie `status: 'tripwire'` et inclut les détails du tripwire :

```typescript
const run = await workflow.createRun()
const result = await run.start({ inputData: { message: 'Hello' } })

if (result.status === 'tripwire') {
  console.log('Workflow terminated by tripwire:', result.tripwire?.reason)
  console.log('Processor ID:', result.tripwire?.processorId)
  console.log('Retry requested:', result.tripwire?.retry)
}
```

Cela diffère de `status: 'failed'`, qui indique une erreur inattendue. Un état tripwire signifie qu’un processeur a intentionnellement arrêté l’exécution (par exemple, pour la modération du contenu).
