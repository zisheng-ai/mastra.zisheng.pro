# Classe Run

La classe `Run` représente une instance d’exécution de Workflow et fournit des méthodes pour démarrer, reprendre, streamer et surveiller l’exécution d’un Workflow.

## Exemple d’utilisation

```typescript
const run = await workflow.createRun()

const result = await run.start({
  inputData: { value: 'initial data' },
})

if (result.status === 'suspended') {
  const resumedResult = await run.resume({
    resumeData: { value: 'resume data' },
  })
}
```

## État de Run

Le `status` d’une exécution de Workflow indique son état d’exécution actuel. Les valeurs possibles sont :

  content={[
  {
