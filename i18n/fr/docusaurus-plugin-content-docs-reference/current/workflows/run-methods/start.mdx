# Run.start()

La méthode `.start()` démarre une exécution de Workflow avec des données d’entrée, ce qui permet d’exécuter le Workflow depuis le début.

## Exemple d’utilisation

```typescript
const run = await workflow.createRun()

const result = await run.start({
  inputData: {
    value: 'initial data',
  },
})
```

## Exemple d’utilisation avancé

```typescript
import { RequestContext } from '@mastra/core/request-context'

const run = await workflow.createRun()

const requestContext = new RequestContext()
requestContext.set('variable', false)

const result = await run.start({
  inputData: {
    value: 'initial data',
  },
  requestContext,
})
```
