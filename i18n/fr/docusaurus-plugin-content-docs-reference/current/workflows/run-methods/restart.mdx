# Run.restart()

La méthode `.restart()` redémarre une exécution de Workflow active ayant perdu la connexion au serveur, ce qui permet de poursuivre l’exécution à partir du moment de cette perte de connexion (la dernière étape active).

## Exemple d’utilisation {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const result = await run.start({ inputData: { value: 'initial data' } })

const restartedResult = await run.restart()
```
