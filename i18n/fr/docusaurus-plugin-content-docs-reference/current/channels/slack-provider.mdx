# SlackFournisseur

`SlackProvider` est the managed path pour connecting agents à Slack. Register it sur `Mastra.channels` et it provisions Slack apps via the Manifest API, runs the OAuth install flow, rotates configuration tokens, et routes Slack events à your agents. Use it when you want Mastra à own app creation et installation. For the lower-level path where you crée the Slack app et configure scopes et webhooks yourself, utilise [`createSlackAdapter`](/docs/capabilities/channels/slack) sur the agent's `channels.adapters` instead.

## Exemple d’utilisation

Register the provider sur the `Mastra` constructor. The refresh token est single-use et rotates sur startup. Le résultating access tokens sont persisted à `Mastra.storage`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  storage,
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

When credentials aren't disponible à construction time (for example, entered via the Éditeur UI ou loaded depuis a vault), construct the provider sans them et call [`configure()`](#configurecredentials) later:

```typescript title="src/mastra/index.ts"
const slack = new SlackProvider()

await slack.configure({
  refreshToken: process.env.SLACK_APP_CONFIG_REFRESH_TOKEN,
})
```

## Méthodes

### Agent connections

#### `connect(agentId, options?)`

Crée a nouveau Slack app pour the agent via the Manifest API et returns an OAuth résultat avec the authorization URL à redirect the utilisateur to. Requires `baseUrl` à be set. Si un pending installation already exists pour the agent, returns its existant authorization URL instead de creating a duplicate app.

```typescript
const result = await slack.connect('support-agent', {
  name: 'Support Bot',
})

// Redirect the user to result.authorizationUrl to install the app
```

Renvoie: `Promise<ChannelConnectResult>`

```typescript
interface ChannelConnectResult {
  type: 'oauth'
  installationId: string
  authorizationUrl: string
}
```

#### `disconnect(agentId)`

Disconnects an agent depuis Slack par deleting its app et removing the installation depuis storage.

```typescript
await slack.disconnect('support-agent')
```

Renvoie: `Promise<void>`

#### `getInstallation(agentId)`

Renvoie the Slack installation pour an agent, ou `null` if none exists.

```typescript
const installation = await slack.getInstallation('support-agent')
```

Renvoie: `Promise<SlackInstallation | null>`

#### `listInstallations()`

Liste tous les Slack installations (public info only), including active et pending.

```typescript
const installations = await slack.listInstallations()
```

Renvoie: `Promise<ChannelInstallationInfo[]>`

### Configuration

#### `configure(credentials)`

Fournit ou clears Slack App Configuration credentials à runtime. Utilisez ce when credentials aren't disponible à construction time. Pass `null` à clear credentials et supprime stored tokens.

```typescript
// Provide credentials (persists to storage immediately)
await slack.configure({ refreshToken: 'xoxe-1-...' })

// Clear credentials and stored tokens
await slack.configure(null)
```

Renvoie: `Promise<void>`

#### `setBaseUrl(baseUrl)`

Définit the public base URL used pour webhook et OAuth callbacks. Utilisez ce when the URL isn't known à construction time et can't be auto-detected depuis the server config.

```typescript
slack.setBaseUrl('https://abc123.trycloudflare.com')
```

#### `initialize()`

Recreates a `SlackAdapter` pour chaque active installation dans storage et injects `AgentChannels` dans the corresponding agent so it receives Slack events sur startup. Doesn't auto-provision nouveau apps. Use `connect()` à crée one. Mastra calls this automatically, so you rarely call it directly.

```typescript
await slack.initialize()
```

Renvoie: `Promise<void>`

## Accessing the provider

Access the registered provider via the typed `channels` getter, keyed par the id you registered it under:

```typescript
const result = await mastra.channels.slack.connect('support-agent')
```

Lorsque le clé est only known à runtime, look it up par chaîne id et transmet the concrete type:

```typescript
const slack = mastra.getChannelProvider<SlackProvider>('slack')
const result = await slack.connect('support-agent')
```

## Stockage requirement

`SlackProvider` requires persistent storage sur `Mastra` à encrypt et persist installations et rotating configuration tokens. The constructor throws if aucun persistent storage est disponible et aucun personnalisé `storage` est passed.
