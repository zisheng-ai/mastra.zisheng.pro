# CanalFournisseur

`ChannelProvider` est the interface that platform integrations implement à connecte agents à a messaging platform. Un provider owns the full lifecycle de an integration: app provisioning et OAuth, webhook routing et event handling, adapter creation et agent wiring, et credential management.

Register providers sur the `Mastra` constructor under `channels`, keyed par an id you choose. Chaque provider's routes sont merged dans the server's API routes automatically, et `initialize()` runs during Mastra startup.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_REFRESH_TOKEN!,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

The provider's `baseUrl` est the public URL the platform sends webhooks et events to. In production this est your deployed Mastra server URL. For local development, the platform can't reach `http://localhost:4111`, so exécute a tunnel (such comme [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) ou [ngrok](https://ngrok.com/)) et point `baseUrl` à the tunnel URL (for example `https://abc123.trycloudflare.com`) so events reach your local dev process.

[SlackFournisseur](/reference/channels/slack-provider) est the premier built-in implementation. Générer a personnalisé provider par implementing this interface.

## Accessing a provider

Access a registered provider via the `channels` getter, keyed par the id you registered it under. The getter est typed depuis the constructor config, so `mastra.channels.slack` est the concrete provider avec its full method surface.

```typescript
await mastra.channels.slack.configure({ refreshToken })
```

Lorsque le clé est only known à runtime, look the provider up par chaîne id instead. `getChannelProvider` takes the concrete type comme a generic, et `getChannelProviders` returns every registered provider keyed par id.

```typescript
import type { SlackProvider } from '@mastra/slack'

const slack = mastra.getChannelProvider<SlackProvider>('slack')
const all = mastra.getChannelProviders()
```
