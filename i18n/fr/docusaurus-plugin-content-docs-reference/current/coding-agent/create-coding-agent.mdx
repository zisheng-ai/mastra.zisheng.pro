# createCodingAgent()

`createCodingAgent()` builds a coding [`Agent`](/reference/agents/agent) avec portable defaults pour the pieces a coding agent always needs: a local workspace, the task-list signal provider, network-retry error processors, et the goal judge prompt. Supply only `model`, `instructions`, et `tools` à obtient a working agent, ou override tout default.

La valeur renvoyée valeur est a standard `Agent`, so it works anywhere an `Agent` does: including comme the agent passed à an [`AgentController`](/reference/agent-controller/agent-controller-class).

## Exemple d’utilisation

Pass a model, instructions, et tools. The factory fills dans the workspace, task signal, error processors, et goal prompt:

```typescript title="src/mastra/coding-agent.ts"
import { createCodingAgent } from '@mastra/core/coding-agent'

const agent = createCodingAgent({
  id: 'my-coding-agent',
  name: 'My Coding Agent',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  instructions: 'You are a helpful coding assistant.',
  tools: {},
})
```

## Par défauts

The factory only fills a par défaut when you don't fournit the corresponding field. Caller-provided values always win.

| Field | Par défaut when omitted |
| - | - |
| `workspace` | Un [`Workspace`](/reference/workspace/workspace-class) backed par `LocalFilesystem` et `LocalSandbox` rooted à the base path. |
| `signals` | Un unique [`TaskSignalProvider`](/reference/signals/task-signal-provider). |
| `errorProcessors` | Unknown stream-error retries avec specialized ECONNRESET et bad-request policies, plus `PrefillErrorHandler` et `ProviderHistoryCompat`. |
| `goal.prompt` | `DEFAULT_GOAL_JUDGE_PROMPT` (only when a `goal` est configured). |

### Workspace

Lorsque le `workspace` clé est omitted, the factory builds a local workspace rooted à `basePath` (default `process.cwd()`):

```typescript
import { Workspace, LocalFilesystem, LocalSandbox } from '@mastra/core/workspace'

new Workspace({
  filesystem: new LocalFilesystem({ basePath }),
  sandbox: new LocalSandbox({ workingDirectory: basePath }),
})
```

To opt out (for example, when the workspace est injected à the [`AgentController`](/reference/agent-controller/agent-controller-class) level), transmet `workspace: undefined` explicitly:

```typescript
const agent = createCodingAgent({
  id: 'my-coding-agent',
  name: 'My Coding Agent',
  model: '__GATEWAY_OPENAI_MODEL_BASE__',
  instructions: 'You are a helpful coding assistant.',
  tools: {},
  workspace: undefined, // opt out of the default workspace
})
```

### Erreur processors

La valeur par défaut [`StreamErrorRetryProcessor`](/reference/processors/stream-error-retry-processor) applies these retry policies:

- Unknown errors left unmatched par provider metadata ou a specific matcher retry up à twice avec a `3000ms` delay. Known authorization failures surface immediately.
- Network resets (`ECONNRESET` / `socket hang up`) retry up à twice avec exponential backoff (`1000ms * 2^retryCount`, capped à `30000ms`).
- Bad-request errors retry once après `2000ms`.

Specific network-reset et bad-request policies take precedence over the unknown-error policy. Passing `errorProcessors` replaces the par défaut processor stack. `PrefillErrorHandler` et `ProviderHistoryCompat` sont also included pour provider compatibility.
