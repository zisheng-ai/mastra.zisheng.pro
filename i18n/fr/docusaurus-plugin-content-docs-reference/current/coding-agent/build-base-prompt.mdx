# buildBasePrompt()

`buildBasePrompt()` construit le prompt système de base partagé d’un Coding Agent : les instructions de comportement qui font de l’Agent un bon assistant de programmation. La fonction reçoit un `PromptContext` décrivant l’environnement actuel (projet, plateforme, branche git, mode et modèle), puis renvoie le prompt sous forme de chaîne.

Les chaînes propres au produit sont paramétrées au moyen de `productName`, `coAuthorName` et `coAuthorEmail`. Vous pouvez ainsi modifier la marque du prompt et du pied de commit sans créer de fork. Leurs valeurs par défaut sont `"Mastra Code"` / `"noreply@mastra.ai"`, ce qui permet aux appelants existants de conserver une sortie identique.

Utilisez cette fonction avec [`createCodingAgent()`](/reference/coding-agent/create-coding-agent) lorsque vous construisez des instructions définies au moment de l’exécution pour l’Agent.

## Exemple d’utilisation {/* #usage-example */}

Construisez le prompt de base à partir d’un `PromptContext` :

```typescript title="src/mastra/prompt.ts"
import { buildBasePrompt } from '@mastra/core/coding-agent'

const prompt = buildBasePrompt({
  projectPath: process.cwd(),
  projectName: 'my-app',
  gitBranch: 'main',
  platform: process.platform,
  date: new Date().toDateString(),
  mode: 'build',
  modelId: '__GATEWAY_OPENAI_MODEL_BASE__',
  toolGuidance: '',
})
```

Pour modifier la marque du prompt, transmettez les champs du produit et du co-auteur :

```typescript
const prompt = buildBasePrompt({
  // ...environment fields
  productName: 'Acme Coder',
  coAuthorName: 'Acme Bot',
  coAuthorEmail: 'bot@acme.dev',
})
```
