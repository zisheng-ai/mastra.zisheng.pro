# handleNetworkFlux()

:::warning[Deprecated]

Agent networks sont deprecated et va be removed dans a future release. Use [supervisor agents](/docs/capabilities/subagents) avec `agent.stream()` ou `agent.generate()` instead. Consultez the [migration guide](/guides/migrations/network-to-supervisor) à upgrade.

:::

Framework-agnostic handler pour streaming network execution dans AI SDK-compatible format. Utilisez ce fonction directly when you need à gère network streaming outside Hono ou Mastra's own [apiRoutes](/docs/server/custom-api-routes) feature.

`handleNetworkStream()` returns a `ReadableStream` that you peut wrap avec [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleNetworkStream()` keeps the existant AI SDK v5/default behavior. Si vousr app est typed against AI SDK v6, transmet `version: 'v6'`.

Use [`networkRoute()`](/reference/ai-sdk/network-route) if you want à crée a network route inside a Mastra server.

## Exemple d’utilisation

Next.js App Router example:

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
