# handleNetworkStream()

:::warning[Obsolète]

Les réseaux d’Agents sont obsolètes et seront supprimés dans une prochaine version. Utilisez plutôt des [Agents superviseurs](/docs/capabilities/subagents) avec `agent.stream()` ou `agent.generate()`. Consultez le [guide de migration](/guides/migrations/network-to-supervisor) pour effectuer la mise à niveau.

:::

Gestionnaire indépendant du framework permettant de diffuser l’exécution d’un réseau dans un format compatible avec AI SDK. Utilisez directement cette fonction lorsque vous devez gérer la diffusion d’un réseau en dehors de Hono ou de la fonctionnalité [apiRoutes](/docs/server/custom-api-routes) de Mastra.

`handleNetworkStream()` renvoie un `ReadableStream` que vous pouvez encapsuler avec [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleNetworkStream()` conserve le comportement par défaut existant d’AI SDK v5. Si votre application est typée pour AI SDK v6, transmettez `version: 'v6'`.

Utilisez [`networkRoute()`](/reference/ai-sdk/network-route) si vous souhaitez créer une route de réseau dans un serveur Mastra.

## Exemple d’utilisation {/* #usage-example */}

Exemple avec l’App Router de Next.js :

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
