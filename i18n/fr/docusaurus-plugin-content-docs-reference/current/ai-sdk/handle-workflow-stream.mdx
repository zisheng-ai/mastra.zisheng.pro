# handleWorkflowFlux()

Framework-agnostic handler pour streaming Workflow execution dans AI SDK-compatible format. Utilisez ce fonction directly when you need à gère Workflow streaming outside Hono ou Mastra's own [apiRoutes](/docs/server/custom-api-routes) feature.

`handleWorkflowStream()` returns a `ReadableStream` that you peut wrap avec [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleWorkflowStream()` keeps the existant AI SDK v5/default behavior. Si vousr app est typed against AI SDK v6, transmet `version: 'v6'`.

Use [`workflowRoute()`](/reference/ai-sdk/workflow-route) if you want à crée a Workflow route inside a Mastra server.

:::tip Agent streaming dans workflows

Lorsqu’un Workflow step pipes an agent's stream à the Workflow writer (e.g., `await response.fullStream.pipeTo(writer)`), the agent's text chunks et Tool calls sont forwarded à the UI stream dans real time, even when the agent runs inside Workflow steps.

See [Workflow Fluxing](/docs/workflows/overview#inspecting-workflow-stream-payloads) pour more details.

:::

## Exemple d’utilisation

Next.js App Router example:

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
