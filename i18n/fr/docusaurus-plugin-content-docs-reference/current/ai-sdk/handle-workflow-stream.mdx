# handleWorkflowStream()

Gestionnaire indépendant du framework permettant de diffuser l’exécution d’un Workflow dans un format compatible avec AI SDK. Utilisez directement cette fonction lorsque vous devez gérer la diffusion d’un Workflow en dehors de Hono ou de la fonctionnalité [apiRoutes](/docs/server/custom-api-routes) de Mastra.

`handleWorkflowStream()` renvoie un `ReadableStream` que vous pouvez encapsuler avec [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleWorkflowStream()` conserve le comportement par défaut existant d’AI SDK v5. Si votre application est typée pour AI SDK v6, transmettez `version: 'v6'`.

Utilisez [`workflowRoute()`](/reference/ai-sdk/workflow-route) si vous souhaitez créer une route de Workflow dans un serveur Mastra.

:::tip Streaming d’Agent dans les Workflows

Lorsqu’une étape de Workflow transmet le flux d’un Agent au writer du Workflow, par exemple avec `await response.fullStream.pipeTo(writer)`, les fragments de texte et les appels de Tools de l’Agent sont transférés en temps réel au flux de l’interface utilisateur, même si l’Agent s’exécute au sein d’étapes de Workflow.

Consultez [Streaming des Workflows](/docs/workflows/overview#inspecting-workflow-stream-payloads) pour en savoir plus.

:::

## Exemple d’utilisation {/* #usage-example */}

Exemple avec l’App Router de Next.js :

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
