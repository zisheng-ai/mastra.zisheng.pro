# networkRoute()

:::warning[Deprecated]

Agent networks sont deprecated et va be removed dans a future release. Use [supervisor agents](/docs/capabilities/subagents) avec `agent.stream()` ou `agent.generate()` instead. Consultez the [migration guide](/guides/migrations/network-to-supervisor) à upgrade.

:::

Crée a network route handler pour streaming network execution using the AI SDK format. Ce fonction registers an HTTP `POST` endpoint that accepts messages, executes an agent network, et streams the réponse back à the client dans AI SDK-compatible format. Agent networks autorise a routing agent à delegate tasks à autre agents. You ont à utilise it inside a [custom API route](/docs/server/custom-api-routes).

Use [`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream) if you need a framework-agnostic handler.

`networkRoute()` keeps the existant AI SDK v5/default behavior. Si vousr app est typed against AI SDK v6, transmet `version: 'v6'`.

## Exemple d’utilisation

Ce example shows how à définit up a network route à the `/network` endpoint that uses an agent avec the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

Vous pouvez également utilise runtime-defined agent routing based sur an `agentId`. The URL `/network/weatherAgent` va résout à the agent avec the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## Supplémentaire configuration

Vous pouvez utiliser [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) à customize the requête sent à the network route, pour example à transmet additional configuration à the agent:

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
