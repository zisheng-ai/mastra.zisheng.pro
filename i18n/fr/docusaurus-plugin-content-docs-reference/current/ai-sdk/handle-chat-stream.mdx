# handleChatFlux()

Framework-agnostic handler pour streaming agent chat dans AI SDK-compatible format. Utilisez ce fonction directly when you need à gère chat streaming outside Hono ou Mastra's own [apiRoutes](/docs/server/custom-api-routes) feature.

`handleChatStream()` returns a `ReadableStream` that you peut wrap avec [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response).

`handleChatStream()` keeps the existant AI SDK v5/default behavior. Si vousr app est typed against AI SDK v6, transmet `version: 'v6'`.

Use [`chatRoute()`](/reference/ai-sdk/chat-route) if you want à crée a chat route inside a Mastra server.

## Structured output dans UI streams

Lorsque vous transmet `structuredOutput` à the underlying agent execution, the final structured output objet est emitted dans the AI SDK-compatible UI stream comme a personnalisé données part:

```json
{
  "type": "data-structured-output",
  "data": {
    "object": {}
  }
}
```

The `object` field contains your full structured output value. Mastra emits this event pour the final structured output objet only. Partial structured output chunks aren't exposed dans the UI stream.

Read this event avec AI SDK UI's personnalisé données handling, such comme `onData`, ou affiche it depuis message données parts.

## Exemple d’utilisation

Next.js App Router example:

```typescript title="app/api/chat/route.ts"
import { handleChatStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleChatStream({
    mastra,
    agentId: 'weatherAgent',
    params,
    messageMetadata: () => ({ createdAt: new Date().toISOString() }),
  })
  return createUIMessageStreamResponse({ stream })
}
```
