# withMastra()

Wraps an AI SDK modèle avec Mastra processors and/or memory.

## Exemple d’utilisation

```typescript title="src/example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import type { Processor } from '@mastra/core/processors'

const loggingProcessor: Processor<'logger'> = {
  id: 'logger',
  async processInput({ messages }) {
    console.log('Input:', messages.length, 'messages')
    return messages
  },
}

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [loggingProcessor],
})

const { text } = await generateText({
  model,
  prompt: 'What is 2 + 2?',
})
```

## Renvoie

Un wrapped modèle compatible avec `generateText`, `streamText`, `generateObject`, et `streamObject`.

## Fluxing behavior

Sortie processors that implement `processOutputResult` exécute après the stream finishes. Consume the stream à completion à persist message history et semantic recall.
