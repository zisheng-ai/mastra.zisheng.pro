# withMastra()

Encapsule un modèle AI SDK avec des Processors Mastra et/ou une mémoire.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/example.ts"
import { openai } from '@ai-sdk/openai'
import { generateText } from 'ai'
import { withMastra } from '@mastra/ai-sdk'
import type { Processor } from '@mastra/core/processors'

const loggingProcessor: Processor<'logger'> = {
  id: 'logger',
  async processInput({ messages }) {
    console.log('Input:', messages.length, 'messages')
    return messages
  },
}

const model = withMastra(openai('gpt-5.4'), {
  inputProcessors: [loggingProcessor],
})

const { text } = await generateText({
  model,
  prompt: 'What is 2 + 2?',
})
```

## Valeur renvoyée {/* #returns */}

Un modèle encapsulé compatible avec `generateText`, `streamText`, `generateObject` et `streamObject`.

## Comportement du streaming {/* #streaming-behavior */}

Les Processors de sortie qui implémentent `processOutputResult` s’exécutent une fois le flux terminé. Consommez le flux jusqu’à son terme afin de conserver l’historique des messages et le rappel sémantique.
