# chatRoute()

Crée un gestionnaire de route de chat pour diffuser les conversations des Agents au format AI SDK. Cette fonction enregistre un endpoint HTTP `POST` qui accepte des messages, exécute un Agent et diffuse la réponse au client dans un format compatible avec AI SDK. Vous devez l’utiliser dans une [route d’API personnalisée](/docs/server/custom-api-routes).

Utilisez [`handleChatStream()`](/reference/ai-sdk/handle-chat-stream) si vous avez besoin d’un gestionnaire indépendant du framework.

`chatRoute()` conserve le comportement existant, correspondant à AI SDK v5 et utilisé par défaut. Si votre application est typée pour AI SDK v6, transmettez `version: 'v6'`.

:::note Comportement en cas de déconnexion

`chatRoute()` transmet l’`AbortSignal` de la requête entrante à `agent.stream()`. Si le client se déconnecte, Mastra interrompt la génération en cours.

Si vous souhaitez que le serveur poursuive la génération et conserve la réponse finale après la déconnexion, créez une [route d’API personnalisée](/docs/server/custom-api-routes#continue-generation-after-client-disconnect) autour de `agent.stream()`, puis appelez `consumeStream()` sur le `MastraModelOutput` renvoyé.

:::

## Exemple d’utilisation {/* #usage-example */}

Cet exemple montre comment configurer, sur l’endpoint `/chat`, une route de chat qui utilise l’Agent dont l’ID est `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

Vous pouvez également définir au moment de l’exécution le routage des Agents à partir d’un `agentId`. L’URL `/chat/weatherAgent` sera associée à l’Agent dont l’ID est `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## Configuration supplémentaire {/* #additional-configuration */}

Vous pouvez utiliser [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) pour personnaliser la requête envoyée à la route de chat, par exemple afin de transmettre une configuration supplémentaire à l’Agent :

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/chat',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
