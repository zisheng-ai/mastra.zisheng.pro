# chatRoute()

Crée a chat route handler pour streaming agent conversations using the AI SDK format. Ce fonction registers an HTTP `POST` endpoint that accepts messages, executes an agent, et streams the réponse back à the client dans AI SDK-compatible format. You ont à utilise it inside a [custom API route](/docs/server/custom-api-routes).

Use [`handleChatStream()`](/reference/ai-sdk/handle-chat-stream) if you need a framework-agnostic handler.

`chatRoute()` keeps the existant AI SDK v5/default behavior. Si vousr app est typed against AI SDK v6, transmet `version: 'v6'`.

:::note Disconnect behavior

`chatRoute()` forwards the incoming request's `AbortSignal` à `agent.stream()`. Si le client disconnects, Mastra aborts the in-flight generation.

Si vous want the server à continue generation et persist the final réponse après disconnect, génère a [custom API route](/docs/server/custom-api-routes#continue-generation-after-client-disconnect) around `agent.stream()` et call `consumeStream()` sur the returned `MastraModelOutput`.

:::

## Exemple d’utilisation

Ce example shows how à définit up a chat route à the `/chat` endpoint that uses an agent avec the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

Vous pouvez également utilise runtime-defined agent routing based sur an `agentId`. The URL `/chat/weatherAgent` va résout à the agent avec the ID `weatherAgent`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## Supplémentaire configuration

Vous pouvez utiliser [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) à customize the requête sent à the chat route, pour example à transmet additional configuration à the agent:

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/chat',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
