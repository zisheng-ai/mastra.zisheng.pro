# toAISdkV4Messages()

Convertit des messages de différents formats d’entrée au format de message d’interface utilisateur AI SDK V4. Cette fonction accepte plusieurs formats de message, notamment des chaînes, des messages AI SDK V4/V5 et des messages Mastra DB, puis les normalise au format `UIMessage` d’AI SDK V4, adapté aux composants d’interface utilisateur d’AI SDK tels que `useChat()`.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="app/chat/page.tsx"
import { toAISdkV4Messages } from '@mastra/ai-sdk'
import { useChat } from 'ai/react' // AI SDK V4

// Stored messages from your database, memory or API
const storedMessages = [
  { id: '1', role: 'user', parts: [{ type: 'text', text: 'Hello' }] },
  { id: '2', role: 'assistant', parts: [{ type: 'text', text: 'Hi there!' }] },
]

export default function Chat() {
  const { messages } = useChat({
    initialMessages: toAISdkV4Messages(storedMessages),
  })

  return (
    <div>
      {messages.map(message => (
        <div key={message.id}>
          {message.role}: {message.content}
        </div>
      ))}
    </div>
  )
}
```

## Exemples {/* #examples */}

### Convertir des messages texte {/* #converting-text-messages */}

```typescript
import { toAISdkV4Messages } from '@mastra/ai-sdk'

const messages = toAISdkV4Messages(['Hello', 'How can I help you today?'])
// Returns array of UIMessage objects with user role and content string
```

### Charger des messages avec le client Mastra {/* #loading-messages-with-mastra-client */}

```typescript
import { MastraClient } from '@mastra/client-js'
import { toAISdkV4Messages } from '@mastra/ai-sdk'

const client = new MastraClient()

const { messages } = await client.listThreadMessages('thread-id', { agentId: 'myAgent' })
const uiMessages = toAISdkV4Messages(messages)
```
