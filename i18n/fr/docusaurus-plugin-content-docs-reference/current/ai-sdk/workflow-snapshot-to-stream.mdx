# workflowSnapshotToStream()

Convertit un objet `WorkflowState` (renvoyé par `workflow.getWorkflowRunById()`) en `ReadableStream` de parties de données UIMessage de l’AI SDK. Le flux contient les mêmes fragments `WorkflowDataPart` et `WorkflowStepDataPart` que produit [`workflowRoute()`](/reference/ai-sdk/workflow-route) en direct.

Utilisez cette fonction pour afficher une exécution de Workflow terminée ou suspendue avec les mêmes composants d’interface qui affichent les flux de Workflow en direct.

## Exemple d’utilisation {/* #usage-example */}

Point de terminaison Next.js App Router qui rejoue une exécution antérieure de Workflow sous forme de flux :

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## Valeur renvoyée {/* #returns */}

`ReadableStream` : flux de parties de données UIMessage de l’AI SDK contenant :

- Un marqueur `start`
- Un `WorkflowDataPart` avec le statut du Workflow et les résumés de toutes les étapes
- Un `WorkflowStepDataPart` pour chaque étape avec sa sortie complète
- Un marqueur `finish`

Transmettez ce flux à [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) ou à `createUIMessageStream()` de l’AI SDK.
