# workflowSnapshotToFlux()

Convertit a `WorkflowState` objet (as returned par `workflow.getWorkflowRunById()`) dans a `ReadableStream` de AI SDK UIMessage données parts. The stream contains the same `WorkflowDataPart` et `WorkflowStepDataPart` chunks that the live [`workflowRoute()`](/reference/ai-sdk/workflow-route) produces.

Utilisez ce when you want à affiche a completed ou suspended Workflow exécute using the same UI components that affiche live Workflow streams.

## Exemple d’utilisation

Next.js App Router endpoint that replays a past Workflow exécute comme a stream:

```typescript title="app/api/workflow-replay/route.ts"
import { workflowSnapshotToStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function GET(req: Request) {
  const { searchParams } = new URL(req.url)
  const runId = searchParams.get('runId')!

  const workflowRun = await mastra.getWorkflow('myWorkflow').getWorkflowRunById(runId)

  if (!workflowRun) {
    return new Response('Not found', { status: 404 })
  }

  const stream = workflowSnapshotToStream(workflowRun)
  return createUIMessageStreamResponse({ stream })
}
```

## Renvoie

`ReadableStream`: Un stream de AI SDK UIMessage données parts containing:

- Un `start` marker
- Un `WorkflowDataPart` avec the Workflow status et tous les step summaries
- Un `WorkflowStepDataPart` pour chaque step avec its full output
- Un `finish` marker

Pass this stream à [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) ou `createUIMessageStream()` depuis the AI SDK.
