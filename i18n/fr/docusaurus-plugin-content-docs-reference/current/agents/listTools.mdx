# Agent.listTools()

La méthode `.listTools()` récupère les Tools configurés pour un Agent et les résout s’ils sont définis par une fonction. Ces Tools étendent les capacités de l’Agent, ce qui lui permet d’effectuer des actions spécifiques ou d’accéder à des systèmes externes.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.listTools()
```
