# Agent.getPar défautOptions()

Agents peut be configuré avec par défaut options pour memory usage et output format. Iteration steps peut also be configured. The `.getDefaultOptions()` method returns these defaults, resolving them if they're functions. Ces options apply à tous les `stream()` et `generate()` calls unless overridden et sont useful pour inspecting an agent’s unknown defaults.

## Exemple d’utilisation

```typescript
await agent.getDefaultOptions()
```
