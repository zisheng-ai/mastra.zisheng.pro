# Agent.listWorkflows()

La méthode `.listWorkflows()` récupère les Workflows configurés pour un Agent et les résout s’ils sont définis par une fonction. Ces Workflows permettent à l’Agent d’exécuter des processus complexes à plusieurs étapes avec des chemins d’exécution définis.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.listWorkflows()
```
