# Agent.listWorkflows()

The `.listWorkflows()` method retrieves the workflows configuré pour an agent, resolving them if they're a function. Ces workflows active the agent à exécute complex, multi-step processes avec defined execution paths.

## Exemple d’utilisation

```typescript
await agent.listWorkflows()
```
