# Agent.getModèle()

La méthode `.getModel()` récupère le modèle de langage configuré pour un agent et le résout s'il s'agit d'une fonction. Cette méthode permet d'accéder au modèle sous-jacent qui alimente les capacités de l’agent.

## Exemple d'utilisation

```typescript
await agent.getModel()
```
