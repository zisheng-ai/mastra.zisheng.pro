# Agent.getModel()

La méthode `.getModel()` récupère le modèle de langage configuré pour un Agent et le résout s’il est défini par une fonction. Elle permet d’accéder au modèle sous-jacent qui alimente les capacités de l’Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.getModel()
```
