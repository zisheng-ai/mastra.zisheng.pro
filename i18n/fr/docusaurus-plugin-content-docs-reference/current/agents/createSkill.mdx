# `createSkill()`

Crée un Skill inline qui peut être transmis directement à la configuration `skills` d’un Agent, sans système de fichiers ni Workspace.

L’objet renvoyé implémente l’interface `Skill` et fonctionne partout où un Skill découvert dans le système de fichiers peut être utilisé.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

const reviewSkill = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness
    2. Check for style consistency
    3. Look for potential bugs
  `,
  references: {
    'checklist.md': '# Review Checklist\n- No unused imports\n- Error handling present',
  },
})
```

## Valeur renvoyée {/* #return-value */}

Renvoie un objet `InlineSkill` qui implémente l’interface `Skill` :

```typescript
interface InlineSkill extends Skill {
  __inline: true
  __referenceContents: Record<string, string>
}
```

Le Skill reçoit un chemin synthétique de la forme `inline/<name>`, par exemple `inline/code-review`.

## Validation {/* #validation */}

`createSkill()` valide les entrées selon les mêmes règles que les Skills du système de fichiers :

- `name` est requis et doit être un slug valide
- `description` est requis
- `instructions` est requis et ne doit pas être vide

Si la validation échoue, une `Error` est levée avec des informations sur les champs non valides.

```typescript
// Throws: Invalid skill "": name is required
createSkill({ name: '', description: 'test', instructions: 'test' })
```
