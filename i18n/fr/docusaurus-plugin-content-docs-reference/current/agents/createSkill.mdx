# `createSkill()`

Crée an inline skill that peut be passed directly à an agent's `skills` config sans a filesystem ou workspace.

La valeur renvoyée objet implements the `Skill` interface et works anywhere a filesystem-discovered skill works.

## Exemple d’utilisation

```typescript title="src/mastra/skills.ts"
import { createSkill } from '@mastra/core/skills'

const reviewSkill = createSkill({
  name: 'code-review',
  description: 'Use when reviewing code changes.',
  instructions: `
    When reviewing code:
    1. Check for correctness
    2. Check for style consistency
    3. Look for potential bugs
  `,
  references: {
    'checklist.md': '# Review Checklist\n- No unused imports\n- Error handling present',
  },
})
```

## Valeur renvoyée

Renvoie an `InlineSkill` objet that implements the `Skill` interface:

```typescript
interface InlineSkill extends Skill {
  __inline: true
  __referenceContents: Record<string, string>
}
```

The skill est assigned a synthetic path de `inline/<name>` (e.g., `inline/code-review`).

## Validation

`createSkill()` validates inputs using the same rules comme filesystem skills:

- `name` est requis et doit be a valid slug
- `description` est required
- `instructions` est requis et non-empty

If validation fails, an `Error` est thrown avec details concernant the invalid fields.

```typescript
// Throws: Invalid skill "": name is required
createSkill({ name: '', description: 'test', instructions: 'test' })
```
