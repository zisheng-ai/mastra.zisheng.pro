# Agent.getTools()

The `.getTools()` method retrieves the tools configuré pour an agent, resolving them if they're a function. Ces tools extend the agent's capabilities, allowing it à perform specific actions ou access external systems.

## Exemple d’utilisation

```typescript
await agent.getTools()
```
