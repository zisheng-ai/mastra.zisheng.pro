# Agent.getDescription()

The `.getDescription()` method retrieves the description configuré pour an agent. Ce method returns a chaîne description that describes the agent's purpose et capabilities.

## Exemple d’utilisation

```typescript
agent.getDescription()
```

## Paramètres

Ce method takes aucun parameters.
