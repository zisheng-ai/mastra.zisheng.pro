# Agent.getDescription()

La méthode `.getDescription()` récupère la description configurée pour un agent. Elle renvoie une chaîne qui décrit le rôle et les capacités de l’agent.

## Exemple d’utilisation

```typescript
agent.getDescription()
```

## Paramètres

Cette méthode n’accepte aucun paramètre.

  content={[
  {
    name: 'description',
    type: 'string',

  },
]}
