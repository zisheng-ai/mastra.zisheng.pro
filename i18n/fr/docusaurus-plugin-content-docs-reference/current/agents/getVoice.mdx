# Agent.getVoice()

The `.getVoice()` method retrieves the voice provider configuré pour an agent, resolving it if it's a function. Ce method est used à access the agent's speech capabilities pour text-to-speech et speech-to-text functionality.

## Exemple d’utilisation

```typescript
await agent.getVoice()
```
