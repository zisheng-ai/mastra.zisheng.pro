# Agent.getVoice()

La méthode `.getVoice()` récupère le fournisseur Voice configuré pour un Agent et le résout s’il est défini par une fonction. Elle permet d’accéder aux capacités vocales de l’Agent pour la synthèse et la reconnaissance vocales.

## Exemple d’utilisation

```typescript
await agent.getVoice()
```
