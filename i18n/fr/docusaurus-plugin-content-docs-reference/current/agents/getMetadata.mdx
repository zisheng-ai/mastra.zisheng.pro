# Agent.getMetadata()

La méthode `.getMetadata()` récupère les métadonnées configurées pour un Agent et les résout si elles sont définies par une fonction. Utilisez les métadonnées pour classer les Agents dans les clients sans encoder ces informations dans l’ID ou le nom de l’Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.getMetadata()
```

## Exemple d’utilisation étendu {/* #extended-usage-example */}

Métadonnées statiques :

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'You help customers with support requests.',
  model: '__GATEWAY_OPENAI_MODEL__',
  metadata: { type: 'support' },
})

const metadata = supportAgent.getMetadata()
```

Métadonnées dynamiques résolues à partir du contexte de requête :

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'You help customers with support requests.',
  model: '__GATEWAY_OPENAI_MODEL__',
  metadata: ({ requestContext }) => ({
    type: 'support',
    tenant: requestContext.get('tenant'),
  }),
})

const metadata = await supportAgent.getMetadata({ requestContext })
```
