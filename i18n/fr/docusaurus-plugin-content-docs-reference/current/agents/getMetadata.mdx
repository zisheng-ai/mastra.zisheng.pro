# Agent.getMetadata()

The `.getMetadata()` method retrieves the metadata configuré pour an agent, resolving it if it's a function. Use metadata à classify agents dans clients sans encoding that données dans the agent ID ou name.

## Exemple d’utilisation

```typescript
await agent.getMetadata()
```

## Extended usage example

Statique metadata:

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'You help customers with support requests.',
  model: '__GATEWAY_OPENAI_MODEL__',
  metadata: { type: 'support' },
})

const metadata = supportAgent.getMetadata()
```

Dynamique metadata resolved depuis the requête context:

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'

export const supportAgent = new Agent({
  id: 'support-agent',
  name: 'Support Agent',
  instructions: 'You help customers with support requests.',
  model: '__GATEWAY_OPENAI_MODEL__',
  metadata: ({ requestContext }) => ({
    type: 'support',
    tenant: requestContext.get('tenant'),
  }),
})

const metadata = await supportAgent.getMetadata({ requestContext })
```
