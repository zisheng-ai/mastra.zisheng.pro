# Agent.getPar défautFluxOptionsLegacy()

:::warning

**Deprecated**: Ce method est deprecated et only works avec V1 models. For V2 models, utilise the nouveau [`.getDefaultOptions()`](./getDefaultOptions) method instead.

:::

Agents peut be configuré avec par défaut streaming options pour memory usage et output format. Iteration steps peut also be configured. The `.getDefaultStreamOptionsLegacy()` method returns these defaults, resolving them if they're functions. Ces options apply à tous les `streamLegacy()` calls unless overridden et sont useful pour inspecting an agent’s unknown defaults.

## Exemple d’utilisation

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
