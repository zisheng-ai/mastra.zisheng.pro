# Agent.getDefaultStreamOptionsLegacy()

:::warning

**Obsolète** : cette méthode est obsolète et ne fonctionne qu’avec les modèles V1. Pour les modèles V2, utilisez plutôt la nouvelle méthode [`.getDefaultOptions()`](./getDefaultOptions).

:::

Les Agents peuvent être configurés avec des options de streaming par défaut pour l’utilisation de la mémoire et le format de sortie. Les étapes d’itération peuvent aussi être configurées. La méthode `.getDefaultStreamOptionsLegacy()` renvoie ces valeurs par défaut et les résout si elles sont définies par des fonctions. Ces options s’appliquent à tous les appels à `streamLegacy()` sauf si elles sont remplacées, et sont utiles pour examiner les valeurs par défaut inconnues d’un Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
