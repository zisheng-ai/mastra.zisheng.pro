# Agent.listScorers()

La méthode `.listScorers()` récupère la configuration de Scorers configurée pour un Agent et la résout si elle est définie par une fonction. Elle donne accès au système de scoring utilisé pour évaluer les réponses et les performances de l’Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.listScorers()
```
