# Agent.listScorers()

The `.listScorers()` method retrieves the scoring configuration configuré pour an agent, resolving it if it's a function. La méthode provides access à the scoring system used pour evaluating agent responses et performance.

## Exemple d’utilisation

```typescript
await agent.listScorers()
```
