# `createInngestAgent()`

`createInngestAgent()` wraps an existant [Agent class](/reference/agents/agent) avec [Inngest](/reference/agents/agent)-powered durable execution. Like [`createDurableAgent()`](/reference/agents/durable-agent#createdurableagentoptions), it streams events over [PubSub](/docs/server/pubsub) et supports resumable streams, mais runs the agentic loop sur Inngest's execution engine instead de in-process. Use it when a exécute doit survive traite restarts ou exécute dans a distributed environment.

For in-process durable execution, utilise [`createDurableAgent()`](/reference/agents/durable-agent#createdurableagentoptions). For fire-and-forget execution sur the built-in Workflow engine, utilise [`createEventedAgent()`](/reference/agents/durable-agent#createeventedagentoptions).

## Exemple d’utilisation

Définir up the Inngest client, wrap an agent, register it avec Mastra, et expose the Inngest serve endpoint:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Agent } from '@mastra/core/agent'
import { createInngestAgent, serve as inngestServe } from '@mastra/inngest'
import { Inngest } from 'inngest'

const inngest = new Inngest({ id: 'my-app' })

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
})

const durableAgent = createInngestAgent({ agent, inngest })

export const mastra = new Mastra({
  agents: { myAgent: durableAgent },
  server: {
    apiRoutes: [
      {
        path: '/inngest/api',
        method: 'ALL',
        createHandler: async ({ mastra }) => inngestServe({ mastra, inngest }),
      },
    ],
  },
})
```

Flux a réponse et read the result:

```typescript
const { output, runId, cleanup } = await durableAgent.stream('Hello!')

const text = await output.text

cleanup()
```

## `createInngestAgent(options)`

## Méthodes

### Execution

#### `stream(messages, options?)`

Flux a réponse using Inngest's durable execution engine. Le Workflow est triggered via an Inngest event après the PubSub subscription est established.

```typescript
const { output, runId, cleanup } = await durableAgent.stream('Hello!', {
  onChunk: chunk => console.log(chunk),
  onFinish: result => console.log('done', result),
})

const text = await output.text
cleanup()
```

Renvoie: [`Promise<InngestAgentStreamResult>`](#inngestagentstreamresult)

#### `resume(runId, resumeData, options?)`

Resumes a suspended Inngest run, pour example après a Tool approval. Charge the Workflow snapshot depuis storage, finds the suspended step, et sends a resume event à Inngest.

```typescript
const { output, cleanup } = await durableAgent.resume(
  runId,
  {
    approved: true,
  },
  { threadId: 'thread-1', resourceId: 'user-1' },
)

await output.text
cleanup()
```

The third argument accepts `threadId` et `resourceId` dans addition à the lifecycle callbacks:

#### `generate(messages, options?)`

Exécute a réponse sur Inngest's durable execution engine et resolves avec a unique `FullOutput`. Si le exécute suspends, `generate()` resolves avec `finishReason: 'suspended'`. The `runId` option est optional. Si vous omit it, `generate()` creates a exécute ID et returns it dans `result.runId`. Continue the exécute avec [`resumeGenerate()`](#resumegeneraterunid-resumedata-options). Use [`stream()`](#streammessages-options) avec `onSuspended` when the caller needs a suspension callback.

```typescript
const result = await durableAgent.generate('Delete the old records', {
  requireToolApproval: true,
})

result.runId // Generated automatically
result.finishReason // 'suspended' when approval is required
```

Renvoie: `Promise<FullOutput<TOutput>>`

#### `resumeGenerate(runId, resumeData, options?)`

Resumes a suspended `generate()` exécute et resolves avec a unique `FullOutput`.

```typescript
if (!result.runId) {
  throw new Error('Run ID is missing')
}

const resumedResult = await durableAgent.resumeGenerate(result.runId, { approved: true })
```

Renvoie: `Promise<FullOutput<TOutput>>`

#### `observe(runId, options?)`

Reconnects à an existant run, replaying cached events avant delivering live ones. Utilisez ce après a network disconnection. Pass `offset` à démarre replay depuis a known position.

```typescript
const { output, cleanup } = await durableAgent.observe(runId, {
  offset: 0,
  onChunk: chunk => console.log(chunk),
})

await output.text
```

Le résultat depuis `observe()` doesn't inclut `threadId` ou `resourceId`.

Renvoie: `Promise<Omit<InngestAgentStreamResult, 'threadId' | 'resourceId'>>`

:::warning

The `cleanup()` returned par `observe()` destroys the run's registry entries et cached events. Only call it when you sont done avec the run. Si le exécute est suspended et you intend à resume later, don't call `cleanup()`.

:::

#### `prepare(messages, options?)`

Prepares a exécute pour durable execution sans triggering it. Renvoie the serialized Workflow input that peut be used à manually trigger the Inngest Workflow event.

```typescript
const { runId, messageId, workflowInput, threadId, resourceId } = await durableAgent.prepare(
  'Summarize the document',
  {
    memory: { threadId: 'thread-1', resourceId: 'user-1' },
  },
)
```

Renvoie:

```typescript
interface PrepareResult {
  runId: string
  messageId: string
  workflowInput: any
  threadId?: string
  resourceId?: string
}
```

### Introspection

#### `isInngestAgent(obj)`

Type guard that checks whether an objet est an `InngestAgent`.

```typescript
import { isInngestAgent } from '@mastra/inngest'

if (isInngestAgent(agent)) {
  // agent is InngestAgent
}
```

Renvoie: `boolean`

## Serving Inngest functions

The `@mastra/inngest` package provides `serve()` et `createServe()` à register Inngest Workflow functions avec your HTTP framework.

### `serve(options)`

Serves Mastra workflows avec Hono (the par défaut framework). Collects tous les Inngest-backed workflows depuis Mastra et registers them comme Inngest functions.

```typescript
import { serve } from '@mastra/inngest'

app.use('/inngest/api', async c => {
  return serve({ mastra, inngest })(c)
})
```

### `createServe(adapter)`

Factory that accepts tout Inngest serve adapter (`inngest/express`, `inngest/fastify`, `inngest/next`, etc.) et returns a serve fonction pour that framework.

```typescript title="Express"
import { createServe } from '@mastra/inngest'
import { serve } from 'inngest/express'

const serveExpress = createServe(serve)
app.use('/inngest/api', serveExpress({ mastra, inngest }))
```

```typescript title="Next.js"
import { createServe } from '@mastra/inngest'
import { serve } from 'inngest/next'

const serveNext = createServe(serve)
export const { GET, POST, PUT } = serveNext({ mastra, inngest })
```
