# Agent.generate()

The `.generate()` method enables non-streaming réponse generation depuis an agent avec enhanced capabilities. It accepts messages et facultatif generation options.

## Exemple d’utilisation

Call the agent avec a message à generate a response:

```ts
const result = await agent.generate('message for agent')
```

## Réponse structure

`Agent.generate()` returns the final données collected during execution. `steps` est an tableau de step objects. Le Tool arrays dans the result, including top-level `toolCalls` et `toolResults` et the nested `step.toolCalls` et `step.toolResults` arrays, utilise Mastra's chunk format.

That means Tool données est wrapped dans `payload`:

```ts
const response = await agent.generate('Check the weather in Lagos')

for (const toolCall of response.toolCalls) {
  console.log(toolCall.type) // 'tool-call'
  console.log(toolCall.runId)
  console.log(toolCall.from)
  console.log(toolCall.payload.toolName)
  console.log(toolCall.payload.args)
}

for (const step of response.steps) {
  for (const toolResult of step.toolResults) {
    console.log(toolResult.type) // 'tool-result'
    console.log(toolResult.payload.toolName)
    console.log(toolResult.payload.result)
  }
}
```

For the streaming version de the same chunk shape, see the [ChunkType reference](/reference/streaming/ChunkType).

## More examples

### With modèle settings

Exemple de limiting output tokens et setting temperature:

```ts
const limitedResult = await agent.generate('Write a short poem about coding', {
  modelSettings: {
    maxOutputTokens: 50,
    temperature: 0.7,
  },
})
```

### With memory

Give your agent access à conversation history et persistence par configuring memory options. It allows the agent à remember previous interactions et maintain context across messages.

```ts
const memoryResult = await agent.generate('Remember my favorite color is blue', {
  memory: {
    thread: 'user-123-thread',
    resource: 'user-123',
  },
})
```

### Accessing réponse headers

Some modèle providers renvoie useful information dans réponse headers, such comme remaining token counts ou rate limit status. Vous pouvez access these headers depuis the résultat objet après generation completes.

```ts
const result = await agent.generate('Hello!')
const remainingRequests = result.response?.headers?.['anthropic-ratelimit-requests-remaining']
const remainingTokens = result.response?.headers?.['x-ratelimit-remaining-tokens']
console.log(`Remaining requests: ${remainingRequests}, Remaining tokens: ${remainingTokens}`)
```

### Analyzing images

Agents peut analyze et describe images par processing both the visual content et tout text within them. Pour activer image analysis, transmet an objet avec `type: 'image'` et the image URL dans the `content` array. Vous pouvez combine image content avec text prompts à guide the agent's analysis.

```typescript
const response = await agent.generate([
  {
    role: 'user',
    content: [
      {
        type: 'image',
        image: 'https://placebear.com/cache/395-205.jpg',
        mimeType: 'image/jpeg',
      },
      {
        type: 'text',
        text: 'Describe the image in detail, and extract all the text in the image.',
      },
    ],
  },
])

console.log(response.text)
```

### Using `maxSteps`

The `maxSteps` paramètre controls the maximum nombre de sequential LLM calls an agent peut make. Chaque step generates a réponse et executes tout Tool calls avant processing the result. Limiting steps helps empêche infinite loops et reduce latency. It also controls token usage pour agents that utilise tools. La valeur par défaut est 5, mais peut be increased:

```typescript
const response = await agent.generate('Help me organize my day', {
  maxSteps: 10,
})

console.log(response.text)
```

### Using `onStepFinish`

Vous pouvez monitor the progress de multi-step operations using the `onStepFinish` callback. Ce est useful pour debugging ou providing progress updates à users.

`onStepFinish` est only disponible when streaming ou generating text sans structured output.

```typescript
const response = await agent.generate('Help me organize my day', {
  onStepFinish: ({ text, toolCalls, toolResults, finishReason, usage }) => {
    console.log({ text, toolCalls, toolResults, finishReason, usage })
  },
})
```

### Using `onTitleGenerated`

When `generateTitle` est activé dans memory options, title generation runs asynchronously après the réponse completes. Use `onTitleGenerated` à react when the title est ready, pour example par pushing it à the client via SSE.

```typescript
const response = await agent.generate('What is quantum computing?', {
  memory: {
    thread: threadId,
    resource: userId,
    onTitleGenerated: title => {
      console.log('Thread title:', title)
    },
  },
})
```
