# Agent.getDefaultGenerateOptionsLegacy()

:::warning

**Obsolète** : cette méthode est obsolète et ne fonctionne qu’avec les modèles V1. Pour les modèles V2, utilisez plutôt la nouvelle méthode [`.getDefaultOptions()`](./getDefaultOptions).

:::

Les Agents peuvent être configurés avec des options de génération par défaut pour contrôler le comportement du modèle, le formatage de la sortie et les appels de Tools et de Workflows. La méthode `.getDefaultGenerateOptionsLegacy()` récupère ces valeurs par défaut et les résout si elles sont définies par des fonctions. Ces options s’appliquent à tous les appels à `generateLegacy()` sauf si elles sont remplacées, et sont utiles pour examiner les valeurs par défaut inconnues d’un Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.getDefaultGenerateOptionsLegacy()
```
