# `.listSkills()`

Renvoie les métadonnées de tous les Skills disponibles pour l’Agent, y compris les Skills au niveau de l’Agent et de l’espace de travail.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## Valeur renvoyée {/* #return-value */}

Renvoie `Promise<SkillMetadata[]>`.

Chaque entrée contient les métadonnées d’un Skill découvert :

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  source: { type: string; projectPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: string[]
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## Comportement de fusion {/* #merging-behavior */}

Lorsque des Skills au niveau de l’Agent et de l’espace de travail sont configurés, `.listSkills()` renvoie l’ensemble fusionné. Les Skills au niveau de l’Agent sont prioritaires en cas de conflit de noms. Si les deux définissent un Skill nommé `code-review`, seule la version au niveau de l’Agent est renvoyée.
