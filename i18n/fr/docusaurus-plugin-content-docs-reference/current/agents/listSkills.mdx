# `.listSkills()`

Renvoie metadata pour tous les skills disponible à the agent, including both agent-level et workspace skills.

## Exemple d’utilisation

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skills = await agent.listSkills()

for (const skill of skills) {
  console.log(`${skill.name}: ${skill.description}`)
}
```

## Valeur renvoyée

Renvoie `Promise<SkillMetadata[]>`.

Chaque entry contains the metadata pour a discovered skill:

```typescript
interface SkillMetadata {
  name: string
  description: string
  path: string
  source: { type: string; projectPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: string[]
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## Merging behavior

When both agent-level skills et workspace skills sont configured, `.listSkills()` returns the merged set. Agent-level skills take precedence sur nom conflicts. If both define a skill called `code-review`, only the agent-level version est returned.
