# Agent.generateLegacy() (Legacy)

:::warning

**Deprecated**: Ce method est deprecated et only works avec legacy modèle adapters. For actuel modèle adapters, utilise [New .generate() method](./generate) instead.

:::

The `.generateLegacy()` method est the legacy version de the agent generation API, used avec legacy modèle adapters à produce text ou structured responses. Ce method accepts messages et facultatif generation options.

## Exemple d’utilisation

```typescript
await agent.generateLegacy('message for agent')
```

## Processor retry support

`generateLegacy()` doesn't exécute error processors ou `maxProcessorRetries`. It uses the legacy AI SDK generation path instead.

Scorer judges avec legacy modèle adapters call `generateLegacy()`. They don't reçoit the coordinated `StreamErrorRetryProcessor` budget disponible à scorer judges that utilise Mastra’s actuel generation API. Utilisez un actuel modèle adapter when you need error-processor retries. The legacy `maxRetries` option remains separate et defaults à `2`.

## Migration à nouveau API

:::info

Le nouveau `.generate()` method offers enhanced capabilities including AI SDK v5+ compatibility, better structured output handling, et improved streaming support. Consultez the [migration guide](/guides/migrations/vnext-to-standard-apis) pour detailed migration instructions.

:::

### Quick Migration Exemple

#### Before (Legacy)

```typescript
const result = await agent.generateLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
})
```

#### After (New API)

```typescript
const result = await agent.generate('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
})
```

## Extended usage example

```typescript
import { z } from 'zod'
import { ModerationProcessor, TokenLimiterProcessor } from '@mastra/core/processors'

await agent.generateLegacy(
  [
    { role: 'user', content: 'message for agent' },
    {
      role: 'user',
      content: [
        {
          type: 'text',
          text: 'message for agent',
        },
        {
          type: 'image',
          imageUrl: 'https://example.com/image.jpg',
          mimeType: 'image/jpeg',
        },
      ],
    },
  ],
  {
    temperature: 0.7,
    maxSteps: 3,
    memory: {
      thread: 'user-123',
      resource: 'test-app',
    },
    toolChoice: 'auto',
    providerOptions: {
      openai: {
        reasoningEffort: 'high',
      },
    },
    // Structured output with better DX
    structuredOutput: {
      schema: z.object({
        sentiment: z.enum(['positive', 'negative', 'neutral']),
        confidence: z.number(),
      }),
      model: '__GATEWAY_OPENAI_MODEL__',
      errorStrategy: 'warn',
    },
    // Output processors for response validation
    outputProcessors: [
      new ModerationProcessor({ model: '__GATEWAY_OPENAI_MODEL_MINI__' }),
      new TokenLimiterProcessor({ maxTokens: 1000 }),
    ],
  },
)
```
