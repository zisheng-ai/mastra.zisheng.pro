# `.getSkill()`

Retrieves a specific skill par nom depuis the agent's configuré skills (both agent-level et workspace skills).

## Exemple d’utilisation

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skill = await agent.getSkill('code-review')

if (skill) {
  console.log(skill.name) // "code-review"
  console.log(skill.description) // "Use when reviewing code changes."
  console.log(skill.instructions) // Full markdown instructions
}
```

## Valeur renvoyée

Renvoie `Promise<Skill | null>`.

Renvoie the `Skill` objet if found, ou `null` if aucun skill avec that nom exists.

```typescript
interface Skill {
  name: string
  description: string
  instructions: string
  path: string
  source: { type: string; projectPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: string[]
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## Merging behavior

When both agent-level skills et workspace skills sont configured, `.getSkill()` searches the merged set. Agent-level skills take precedence sur nom conflicts.
