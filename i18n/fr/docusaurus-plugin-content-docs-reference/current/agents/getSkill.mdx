# `.getSkill()`

Récupère un Skill précis à partir de son nom parmi les Skills configurés pour l’Agent, qu’ils soient définis au niveau de l’Agent ou du Workspace.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/routes/skills.ts"
import { agent } from '../mastra/agents'

const skill = await agent.getSkill('code-review')

if (skill) {
  console.log(skill.name) // "code-review"
  console.log(skill.description) // "Use when reviewing code changes."
  console.log(skill.instructions) // Full markdown instructions
}
```

## Valeur renvoyée {/* #return-value */}

Renvoie `Promise<Skill | null>`.

Renvoie l’objet `Skill` s’il est trouvé, ou `null` s’il n’existe aucun Skill portant ce nom.

```typescript
interface Skill {
  name: string
  description: string
  instructions: string
  path: string
  source: { type: string; projectPath: string }
  references: string[]
  scripts: string[]
  assets: string[]
  license?: string
  compatibility?: string[]
  'user-invocable'?: boolean
  metadata?: Record<string, unknown>
}
```

## Comportement de fusion {/* #merging-behavior */}

Lorsque des Skills sont configurés à la fois au niveau de l’Agent et du Workspace, `.getSkill()` effectue sa recherche dans l’ensemble fusionné. En cas de conflit de noms, les Skills définis au niveau de l’Agent sont prioritaires.
