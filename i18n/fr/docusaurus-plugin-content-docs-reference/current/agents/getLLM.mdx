# Agent.getLLM()

La méthode `.getLLM()` récupère l’instance de modèle de langage configurée pour un Agent et la résout si elle est définie par une fonction. Vous pouvez aussi transmettre un remplacement `model` limité à la requête sans modifier le modèle configuré de l’Agent.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
