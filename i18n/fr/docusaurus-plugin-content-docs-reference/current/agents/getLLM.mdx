# Agent.getLLM()

The `.getLLM()` method retrieves the language modèle instance configuré pour an agent, resolving it if it's a function. Vous pouvez également transmet a request-scoped `model` override sans mutating the agent's configuré model.

## Exemple d’utilisation

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
