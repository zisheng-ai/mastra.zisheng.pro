# Agent.listAgents()

The `.listAgents()` method retrieves the subagents configuré pour an agent, resolving them if they're a function. Ces subagents active the agent à access autre agents et perform complex actions.

## Exemple d’utilisation

```typescript
await agent.listAgents()
```
