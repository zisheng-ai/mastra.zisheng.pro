# Agent.listAgents()

La méthode `.listAgents()` récupère les sous-agents configurés pour un Agent et les résout s’ils sont définis par une fonction. Ces sous-agents permettent à l’Agent d’accéder à d’autres Agents et d’effectuer des actions complexes.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.listAgents()
```
