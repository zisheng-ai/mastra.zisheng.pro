# DurableAgent

`DurableAgent` wraps an existant [Agent class](/reference/agents/agent) avec durable execution et resumable streams. It runs the agentic loop so that a client peut déconnecte et reconnect sans missing events, et it streams those events over [PubSub](/docs/server/pubsub). Use it when a exécute doit outlive a unique requête ou survive a dropped connection.

Créer un avec the [`createDurableAgent`](#createdurableagentoptions) factory, ou utilise [`createEventedAgent`](#createeventedagentoptions) pour fire-and-forget execution sur the built-in Workflow engine. For Inngest-powered execution, utilise [`createInngestAgent()`](/reference/agents/inngest-agent) depuis `@mastra/inngest`.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Agent } from '@mastra/core/agent'
import { createDurableAgent } from '@mastra/core/agent/durable'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
})

const durableAgent = createDurableAgent({ agent })

export const mastra = new Mastra({
  agents: { myAgent: durableAgent },
})
```

Flux a réponse et read the result. The `cleanup` fonction unsubscribes depuis PubSub when you sont done avec the run:

```typescript
const { output, runId, cleanup } = await durableAgent.stream('Hello!')

const text = await output.text

cleanup()
```

### Using the `durable` config flag

Définir `durable: true` sur `AgentConfig` et the agent est automatically wrapped avec `createDurableAgent` when it's attached à a `Mastra` instance. Utilisez un objet à forward advanced options such comme `cache`, `pubsub`, `maxSteps`, ou `cleanupTimeoutMs`.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Agent } from '@mastra/core/agent'

const myAgent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  durable: true, // or: { maxSteps: 10, cleanupTimeoutMs: 60_000 }
})

export const mastra = new Mastra({
  agents: { myAgent },
})
```

`mastra.getAgent('myAgent')` returns the wrapped `DurableAgent`. Standalone agents (constructed mais never registered sur a `Mastra` instance) don't become durable. The wrapping est applied à registration.

## `createEventedAgent(options)`

Wraps an `Agent` avec fire-and-forget durable execution sur the built-in Workflow engine. Like `createDurableAgent`, it returns a résultat you stream from, mais the underlying Workflow runs non-blocking (via `startAsync`) instead de running à completion avant the stream est wired up. Use it when you want the exécute à progress independently de the caller. It doesn't accept `id` ou `name` overrides.

```typescript
import { createEventedAgent } from '@mastra/core/agent/durable'

const eventedAgent = createEventedAgent({ agent })
```

Renvoie: `EventedAgent` (a subclass de `DurableAgent`)

## Méthodes

### Execution

#### `stream(messages, options?)`

Flux a réponse using durable execution. Renvoie immediately avec a résultat whose `output` produces events comme the exécute progresses.

```typescript
const { output, runId, cleanup } = await durableAgent.stream('Hello!', {
  onChunk: chunk => console.log(chunk),
  onFinish: result => console.log('done', result),
})

const text = await output.text
cleanup()
```

Renvoie: [`Promise<DurableAgentStreamResult>`](#durableagentstreamresult)

#### `resume(runId, resumeData, options?)`

Resumes a suspended run, pour example après a Tool approval. Pass the `runId` depuis the original stream et the données the exécute était waiting on. Throws if aucun registry entry exists pour the run.

```typescript
const { output, cleanup } = await durableAgent.resume(runId, {
  approved: true,
})

await output.text
cleanup()
```

Renvoie: [`Promise<DurableAgentStreamResult>`](#durableagentstreamresult)

#### `observe(runId, options?)`

Reconnects à an existant run, replaying cached events avant delivering live ones. Utilisez ce après a network disconnection. Pass `offset` à démarre replay depuis a known position.

```typescript
const { output, cleanup } = await durableAgent.observe(runId, {
  offset: 0,
  onChunk: chunk => console.log(chunk),
})

await output.text
```

Par défaut `observe()` waits indefinitely pour events. Si le traite running the exécute stops unexpectedly, the exécute stops producing events mais never emits a completion event, so the observed stream would wait forever. Pass `idleTimeoutMs` à bound that wait: après that many milliseconds de silence the stream ends. Un facultatif `isAlive` check est consulted first. Renvoyer `true` tandis que the exécute est still being worked sur (for example a long-running Tool call, ou a exécute paused waiting pour human input) à keep waiting. Returning `false`, ou omitting `isAlive`, ends the stream avec an error. Un transient throw depuis `isAlive` est treated comme "still alive", so a momentary check failure never ends a live stream.

```typescript
const { output } = await durableAgent.observe(runId, {
  idleTimeoutMs: 30_000,
  isAlive: () => runHeartbeat.isFresh(runId),
})
```

Ending a exécute sur idle timeout runs the same cleanup comme a exécute that errors (see the warning below), so its cached state est released rather than retained. Both options sont opt-in. Omit them pour the previous wait-indefinitely behavior.

Renvoie: `Promise<DurableAgentStreamResult>`

:::warning

The `cleanup()` returned par `observe()` destroys the run's registry entries et cached events. Only call it when you sont done avec the run. Si le exécute est suspended et you intend à resume later, don't call `cleanup()`. Let the auto-cleanup timer gère it après the exécute finishes ou errors. Auto-cleanup doesn't fire sur suspended events.

:::

#### `prepare(messages, options?)`

Prepares a exécute pour durable execution sans starting it. Registers the exécute dans the internal registry et returns the serialized Workflow input. Utilisez ce when you need à control when et how the Workflow est triggered.

```typescript
const { runId, messageId, workflowInput, threadId, resourceId } = await durableAgent.prepare(
  'Summarize the document',
  {
    memory: { threadId: 'thread-1', resourceId: 'user-1' },
  },
)
```

Renvoie:

```typescript
interface PrepareResult {
  runId: string
  messageId: string
  workflowInput: any
  registryEntry: object
  threadId?: string
  resourceId?: string
}
```

### Recovery

#### `recoverActiveRuns(options?)`

Discovers runs stuck dans `running` status pour this agent et re-drives them depuis the dernier persisted snapshot. Recovers up à `options.limit` runs (default: 100). Renvoie a summary de what était recovered.

```typescript
const result = await durableAgent.recoverActiveRuns()
// { recovered: [{ runId, status }], succeeded: 2, failed: 0 }
```

Pass a `runId` à recover a unique known run:

```typescript
await durableAgent.recoverActiveRuns({ runId: 'run-abc-123' })
```

Renvoie:

```typescript
interface DurableAgentRecoverActiveRunsResult {
  recovered: Array<{ runId: string; status: 'success' | 'failed'; error?: Error }>
  succeeded: number
  failed: number
}
```

#### `recover(runId, options?)`

Recovers a unique exécute par ID. Renvoie a streamable résultat avec the same shape comme `stream()`. Utilisez ce when you need à observe the recovery stream dans real time.

```typescript
const { output, cleanup } = await durableAgent.recover('run-abc-123', {
  onChunk: chunk => console.log(chunk),
  onError: ({ error }) => console.error(error),
})

await output.text
cleanup()
```

Renvoie: [`Promise<DurableAgentStreamResult>`](#durableagentstreamresult)
