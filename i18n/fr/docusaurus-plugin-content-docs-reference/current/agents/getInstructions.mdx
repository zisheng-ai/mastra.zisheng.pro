# Agent.getInstructions()

The `.getInstructions()` method retrieves the instructions configuré pour an agent, resolving them if they're a function. Ces instructions guide the agent's behavior et define its capabilities et constraints.

## Exemple d’utilisation

```typescript
await agent.getInstructions()
```
