# Agent.getInstructions()

La méthode `.getInstructions()` récupère les instructions configurées pour un Agent et les résout si elles sont définies par une fonction. Ces instructions guident le comportement de l’Agent et définissent ses capacités et ses contraintes.

## Exemple d’utilisation

```typescript
await agent.getInstructions()
```
