# Agent.getMemory()

La méthode `.getMemory()` récupère le système de mémoire associé à un Agent. Elle permet d’accéder aux capacités de mémoire de l’Agent afin de stocker et récupérer des informations entre les conversations.

## Exemple d’utilisation {/* #usage-example */}

```typescript
await agent.getMemory()
```
