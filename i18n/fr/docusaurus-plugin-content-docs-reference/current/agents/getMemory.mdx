# Agent.getMémoire()

The `.getMemory()` method retrieves the memory system associated avec an agent. Ce method est used à access the agent's memory capabilities pour storing et retrieving information across conversations.

## Exemple d’utilisation

```typescript
await agent.getMemory()
```
