# mountAgentControllerOnMastra()

:::experimental

Le package `@mastra/code-sdk` est expérimental et susceptible de subir des changements incompatibles dans les versions mineures.

:::

La fonction `mountAgentControllerOnMastra()` construit le contrôleur d'Agent Mastra Code (l'Agent de programmation sur lequel repose la CLI [`mastracode`](https://www.npmjs.com/package/mastracode), avec ses modes, ses Tools, sa mémoire et sa gestion des threads) et l'enregistre sur une instance [Mastra](/reference/core/mastra-class) appartenant au serveur. Utilisez-la pour mettre l'Agent Mastra Code à la disposition de votre propre interface utilisateur (application web, éditeur ou bot) : chaque client crée ou reprend sa propre session isolée au moyen de l'[`AgentController`](/reference/agent-controller/agent-controller-class) renvoyé.

Pour construire vous-même l'instance `Mastra` (par exemple dans un fichier d'entrée déployable), utilisez `prepareAgentControllerMount()` du même package. Cette fonction renvoie les arguments du constructeur ainsi qu'une fonction de rappel `finalize()`.

## Exemple d'utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

Transmettez un objet `mastra` existant pour monter le contrôleur sur une instance Mastra qui héberge déjà d'autres primitives :

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
