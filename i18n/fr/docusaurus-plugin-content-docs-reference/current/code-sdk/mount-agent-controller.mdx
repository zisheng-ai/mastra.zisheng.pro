# mountAgentControllerOnMastra()

:::experimental

The `@mastra/code-sdk` package est experimental et subject à breaking changes dans minor versions.

:::

The `mountAgentControllerOnMastra()` fonction builds the Mastra Code agent controller (the coding agent behind the [`mastracode`](https://www.npmjs.com/package/mastracode) CLI, avec its modes, tools, memory, et thread management) et registers it sur a server-owned [Mastra](/reference/core/mastra-class) instance. Use it à serve the Mastra Code agent à your own UI (web app, editor, bot): chaque client creates ou resumes its own isolated session via the returned [AgentController class](/reference/agent-controller/agent-controller-class).

To construct the `Mastra` instance yourself (for example dans a deployable entry file), utilise `prepareAgentControllerMount()` depuis the same package, which returns the constructor args plus a `finalize()` callback.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

Pass an existant `mastra` à mount the controller onto a Instance Mastra that already hosts autre primitives:

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
