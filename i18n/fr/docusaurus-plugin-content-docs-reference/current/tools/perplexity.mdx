# Tools Perplexity

Le package `@mastra/perplexity` encapsule l’[API Perplexity Search](https://docs.perplexity.ai/docs/search/quickstart) sous forme de Tool compatible avec Mastra. Il expose une fonction de fabrique qui renvoie un Tool créé avec [`createTool()`](./create-tool) et doté de schémas Zod complets pour les entrées et les sorties.

Pour les complétions de chat ou les Workflows agentiques propulsés par Perplexity, utilisez le [Provider de modèles Perplexity](/models/providers/perplexity) ou le [Provider Perplexity Agent](/models/providers/perplexity-agent) intégrés à Mastra. Ils sont distincts de ce Tool Search.

## Installation {/* #installation */}

Installez le package avec Zod :

```sh npm2yarn
npm install @mastra/perplexity zod
```

## Exemple d’utilisation {/* #usage-example */}

L’exemple suivant crée le Tool de recherche avec la configuration par défaut. Par défaut, le Tool lit `PERPLEXITY_API_KEY` dans l’environnement, avec `PPLX_API_KEY` comme solution de remplacement. Transmettez explicitement `{ apiKey }` pour remplacer cette valeur.

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

Pour transmettre explicitement une clé d’API :

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## Méthodes {/* #methods */}

### Fonctions de fabrique {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

Renvoie un objet contenant tous les Tools Perplexity qui partagent la configuration fournie.

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

Renvoie : `{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

Crée un Tool qui effectue des recherches sur le Web au moyen de l’API Perplexity Search. Renvoie des résultats classés comprenant des titres, des URL, des extraits et, éventuellement, des dates de publication.

Le Tool est enregistré avec l’ID `perplexity-search`.

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Exemple d’Agent {/* #agent-example */}

L’exemple suivant enregistre le Tool de recherche auprès d’un Agent afin qu’il puisse récupérer des résultats Web récents avant de répondre.

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## Variables d’environnement {/* #environment-variables */}

| Variable | Description |
| - | - |
| `PERPLEXITY_API_KEY` | Votre clé d’API Perplexity. Utilisée par défaut lorsque `apiKey` n’est pas transmis à une fonction de fabrique. |
| `PPLX_API_KEY` | Solution de remplacement utilisée lorsque `PERPLEXITY_API_KEY` n’est pas défini. |
