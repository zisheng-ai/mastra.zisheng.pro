# submitPlanTool

Tool intégré indépendant de l’Agent, qui soumet un plan d’implémentation à l’examen de l’utilisateur. L’Agent écrit un plan dans un fichier Markdown et transmet son chemin à ce Tool. Le Tool suspend l’exécution jusqu’à ce que l’utilisateur approuve ou rejette le plan.

Le Tool se met en pause au moyen de la primitive native de [suspension des Tools](/docs/agents/agent-approval#runtime-suspension-with-suspend) : il appelle `suspend({ path })`, ce qui amène l’Agent à émettre un événement `tool-call-suspended`. L’hôte lit le fichier de plan et le présente à l’utilisateur. Il reprend ensuite l’exécution avec une approbation ou un rejet.

Lorsqu’il est exécuté en dehors de l’exécution d’un Agent, sans `suspend` disponible, le Tool renvoie une chaîne de repli lisible contenant le chemin du fichier.

## Exemple d’utilisation {/* #usage-example */}

Ajoutez `submitPlanTool` à l’ensemble de Tools d’un Agent :

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

Gérez la suspension et la reprise :

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

Pour rejeter le plan en fournissant un commentaire :

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## Comportement de l’approbation {/* #approval-behavior */}

- **Approuvé :** le Tool renvoie `"Plan approved. Proceed with implementation following the approved plan."` au modèle.
- **Rejeté avec un commentaire :** le Tool renvoie le commentaire et demande au modèle de réviser le plan, puis de le soumettre à nouveau.
- **Rejeté sans commentaire :** le Tool indique au modèle d’attendre le prochain message de l’utilisateur avant de réviser le plan.

Lorsqu’il est utilisé dans un [AgentController](/docs/harness/agent-controller), l’approbation du plan remplace le mode actuel par celui configuré avec `transitionsTo`. Lorsqu’aucun `transitionsTo` n’est configuré, le contrôleur passe à son mode par défaut résolu. Consultez les [modes](/docs/harness/agent-controller#switch-modes-and-models) pour plus de détails.
