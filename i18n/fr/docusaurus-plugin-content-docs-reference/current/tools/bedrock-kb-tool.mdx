# createBedrockKBTool()

La fonction `createBedrockKBTool()` crée un Tool qui récupère des documents pertinents dans une base de connaissances Amazon Bedrock. Elle prend en charge à la fois la configuration de recherche gérée et la récupération agentique (décomposition des requêtes et reclassement géré), avec un repli automatique vers la récupération standard.

## Exemple d'utilisation {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### Avec un Agent {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

### BedrockKBResult {/* #bedrockkbresult */}

| Champ | Type | Description |
| - | - | - |
| `content` | `string` | Contenu textuel du passage récupéré. |
| `source` | `string \| undefined` | URI de la source lorsque Bedrock en fournit un. La récupération agentique inclut ce champ uniquement lorsque les métadonnées du résultat contiennent `_source_uri`. |
| `score` | `number \| undefined` | Score de pertinence renvoyé par la récupération standard. L'API agentique ne renvoie pas de score pour les éléments du résultat. |
| `metadata` | `Record<string, unknown>` | Métadonnées supplémentaires provenant du résultat de la récupération. |

## Modes de récupération {/* #retrieval-modes */}

### Récupération agentique (par défaut) {/* #agentic-retrieval-default */}

Lorsque `useAgenticRetrieval` vaut `true` (par défaut), le Tool utilise `AgenticRetrieveStreamCommand`, qui :

- Décompose les requêtes complexes en sous-requêtes
- Effectue la récupération en plusieurs passes
- Applique un reclassement géré afin d'améliorer les résultats

Si la récupération agentique échoue (par exemple en raison d'une ancienne version du SDK ou des autorisations), le Tool se replie automatiquement sur la récupération gérée standard.

### Récupération gérée standard {/* #standard-managed-retrieval */}

Lorsque `useAgenticRetrieval` vaut `false`, le Tool utilise `RetrieveCommand` avec `managedSearchConfiguration` pour effectuer une récupération directe en une seule passe.

## Contrôle d'accès par utilisateur {/* #user-based-access-control */}

Définissez `userId` dans le contexte de requête Mastra afin de le transmettre comme `userContext.userId` de Bedrock. Cette fonctionnalité permet d'utiliser les bases de connaissances qui appliquent un contrôle d'accès au niveau des documents. La valeur du contexte de requête remplace le `userId` par défaut configuré sur le Tool.

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```

## Prérequis du SDK {/* #sdk-requirements */}

- `@aws-sdk/client-bedrock-agent-runtime` >= 3.1000 (AgenticRetrieveStreamCommand nécessite la version \~3.1000 ou ultérieure)
