# Tools Bright Data

Le package `@mastra/brightdata` encapsule le [SDK Bright Data](https://github.com/brightdata/bright-data-sdk-node) sous la forme de Tools compatibles avec Mastra. Il expose des fonctions de fabrique pour la recherche et la récupération web. Chaque fonction renvoie un Tool créé avec [`createTool()`](./create-tool), qui comprend des schémas Zod complets d'entrée et de sortie.

Le Tool de recherche repose sur [SERP API](https://brightdata.com/products/serp-api) de Bright Data, et le Tool de récupération sur [Web Unlocker](https://brightdata.com/products/web-unlocker). Tous deux contournent la détection des bots et les CAPTCHA.

## Installation {/* #installation */}

```sh npm2yarn
npm install @mastra/brightdata zod
```

## Démarrage rapide {/* #quick-start */}

Utilisez `createBrightDataTools()` pour obtenir les deux Tools avec une configuration commune :

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()
// Or pass an explicit API key:
// const { webSearch, webFetch } = createBrightDataTools({ apiKey: 'brd-...' })
```

Chaque Tool peut également être créé séparément :

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataSearchTool, createBrightDataFetchTool } from '@mastra/brightdata'

const searchTool = createBrightDataSearchTool()
const fetchTool = createBrightDataFetchTool({ apiKey: 'brd-...' })
```

Par défaut, tous les Tools lisent `BRIGHTDATA_API_TOKEN` dans l'environnement. Vous pouvez transmettre explicitement `{ apiKey }` pour remplacer cette valeur.

## `createBrightDataTools()` {/* #createbrightdatatools */}

Renvoie un objet contenant les deux Tools avec une configuration commune.

```typescript
import { createBrightDataTools } from '@mastra/brightdata'

const tools = createBrightDataTools({ apiKey: 'brd-...' })
// tools.webSearch, tools.webFetch
```

**Renvoie :** `{ webSearch, webFetch }`

## Exemple avec un Agent {/* #agent-example */}

L'exemple suivant présente un Agent de recherche qui combine la recherche et la récupération :

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the search tool to find relevant pages, then use the fetch tool to read full Markdown content from the best results.',
  tools: {
    webSearch,
    webFetch,
  },
})
```
