# PinoLogger

Une instance de Logger est créée avec `new PinoLogger()` et fournit des méthodes pour enregistrer des événements à différents niveaux de gravité.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

export const mastra = new Mastra({
  logger: new PinoLogger({
    name: 'Mastra',
    level: 'info',
  }),
})
```

## Enrichissement des journaux avec `mixin`

Utilisez `mixin` lorsque vous souhaitez inclure les mêmes champs structurés dans chaque ligne (afin de les corréler avec le reste de vos services) :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

function getTraceContext() {
  return { traceId: 'abc-123' }
}

export const mastra = new Mastra({
  logger: new PinoLogger({
    name: 'Mastra',
    level: 'info',
    mixin() {
      return getTraceContext()
    },
  }),
})
```

## Niveaux personnalisés

`customLevels` est transmis à Pino. `PinoLogger` n’expose que `debug`, `info`, `warn` et `error` ; pour tout nom de niveau supplémentaire (par exemple `audit`), créez une sous-classe et transmettez l’appel à l’instance Pino sous-jacente :

```typescript title="src/mastra/logger.ts"
import { Mastra } from '@mastra/core'
import { PinoLogger } from '@mastra/loggers'

type AuditLevel = 'audit'

class MastraPinoWithAudit extends PinoLogger<AuditLevel> {
  audit(message: string, meta: Record<string, unknown> = {}) {
    this.logger.audit(meta, message)
  }
}

const logger = new MastraPinoWithAudit({
  name: 'Mastra',
  level: 'info',
  customLevels: { audit: 35 },
})

export const mastra = new Mastra({ logger })
```

Les valeurs numériques suivent l’ordre de Pino (les niveaux intégrés vont de 10 à 60). Le niveau `35` se situe entre `info` (30) et `warn` (40) ; avec `level: 'info'`, les lignes `info` et `audit` sont donc toutes deux émises.

## Transport de fichier (journaux structurés)

Écrit des journaux structurés dans un fichier à l’aide de `FileTransport`. Le logger accepte un message simple comme premier argument et des métadonnées structurées comme second argument. Ils sont convertis en interne en `BaseLogMessage` et conservés dans le chemin de fichier configuré.

```typescript title="src/mastra/loggers/file-transport.ts"
import { FileTransport } from '@mastra/loggers/file'
import { PinoLogger } from '@mastra/loggers/pino'

export const fileLogger = new PinoLogger({
  name: 'Mastra',
  transports: { file: new FileTransport({ path: 'test-dir/test.log' }) },
  level: 'warn',
})
```

### Utilisation du transport de fichier

```typescript
fileLogger.warn('Low disk space', {
  destinationPath: 'system',
  type: 'WORKFLOW',
})
```

## Transport Upstash (collecte distante des journaux)

Transmet des journaux structurés à une liste Redis distante avec `UpstashTransport`. Le logger accepte un message sous forme de chaîne et un objet de métadonnées structurées. Il permet une journalisation centralisée pour les environnements distribués, avec filtrage par `destinationPath`, `type` et `runId`.

```typescript title="src/mastra/loggers/upstash-transport.ts"
import { UpstashTransport } from '@mastra/loggers/upstash'
import { PinoLogger } from '@mastra/loggers/pino'

export const upstashLogger = new PinoLogger({
  name: 'Mastra',
  transports: {
    upstash: new UpstashTransport({
      listName: 'production-logs',
      upstashUrl: process.env.UPSTASH_URL!,
      upstashToken: process.env.UPSTASH_TOKEN!,
    }),
  },
  level: 'info',
})
```

### Utilisation du transport Upstash

```typescript
upstashLogger.info('User signed in', {
  destinationPath: 'auth',
  type: 'AGENT',
  runId: 'run_123',
})
```

## Transport personnalisé

Vous pouvez créer des transports personnalisés avec l’utilitaire `createCustomTransport` afin de vous intégrer à n’importe quel service ou flux de journalisation.

### Exemple de transport Sentry

Crée un transport personnalisé avec `createCustomTransport` et l’intègre à un flux de journalisation tiers tel que `pino-sentry-transport`. Cela permet de transférer les journaux vers un système externe tel que Sentry pour une supervision et une observabilité avancées.

```typescript title="src/mastra/loggers/sentry-transport.ts"
import { createCustomTransport } from '@mastra/core/loggers'
import { PinoLogger } from '@mastra/loggers/pino'
import pinoSentry from 'pino-sentry-transport'

const sentryStream = await pinoSentry({
  sentry: {
    dsn: 'YOUR_SENTRY_DSN',
    _experiments: {
      enableLogs: true,
    },
  },
})

const customTransport = createCustomTransport(sentryStream)

export const sentryLogger = new PinoLogger({
  name: 'Mastra',
  level: 'info',
  transports: { sentry: customTransport },
})
```
