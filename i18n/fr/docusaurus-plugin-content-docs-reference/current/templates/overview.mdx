# Présentation

Cette référence explique comment utiliser les modèles Mastra existants et créer les vôtres. Elle explique également comment contribuer des modèles à l’écosystème communautaire.

Les modèles Mastra sont des structures de projet préconfigurées qui illustrent des cas d’utilisation et des modèles spécifiques. Ils fournissent :

- **Exemples fonctionnels** : des applications Mastra complètes et opérationnelles
- **Bonnes pratiques** : une structure de projet et des conventions de code appropriées
- **Ressources pédagogiques** : découvrez les modèles Mastra grâce à des implémentations concrètes
- **Démarrages rapides** : initialisez des projets plus vite qu’en partant de zéro

## Modèles disponibles

Les modèles suivants présentent des applications Mastra centrées sur Gateway :

- `template-docs-expert`: Répond aux questions sur la documentation avec la recherche web Gateway, des citations, la mémoire et des réponses structurées.
- `template-browser-agent`: Utilise AgentBrowser pour parcourir, inspecter et manipuler des pages web.
- `template-meeting-notes`: Transforme des transcriptions Zoom ou importées en notes structurées contenant les décisions et les actions à mener.
- `template-company-knowledge`: Indexe le contenu de Linear et Notion dans pgvector et répond aux questions sur les connaissances internes.
- `template-claw-assistant`: Utilise un espace de travail avec des outils de système de fichiers, de sandbox, de navigateur et de recherche web.

## Utiliser les modèles

### Installation

Installez un modèle avec la commande `create-mastra` :

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```

Cette commande crée un projet complet et installe ses dépendances. L’auteur du modèle contrôle les modèles, les dépendances de fournisseurs, les variables d’environnement et le code source.

### Processus de configuration

Après l’installation :

1. **Accédez au répertoire du projet** :

   ```bash
   cd your-project-name
   ```

1. **Configurez les variables d’environnement** :

   ```bash
   cp .env.example .env
   ```

   Modifiez `.env` avec les clés d’API requises, comme indiqué dans le README du modèle.

1. **Démarrez le serveur de développement** :

   ```sh npm2yarn
   npm run dev
   ```

### Structure d’un modèle

Tous les modèles suivent cette structure standardisée :

```
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
