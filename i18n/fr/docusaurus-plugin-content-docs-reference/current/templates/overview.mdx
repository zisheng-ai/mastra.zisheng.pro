# Présentation

Cette référence explique comment utiliser les templates Mastra existants et créer les vôtres. Elle aborde aussi la contribution de templates à l’écosystème communautaire.

Les templates Mastra sont des structures de projet préconstruites qui présentent des cas d’utilisation et modèles spécifiques. Ils fournissent :

- **Exemples fonctionnels** : applications Mastra complètes et opérationnelles
- **Bonnes pratiques** : structure de projet et conventions de code appropriées
- **Ressources pédagogiques** : découvrez les modèles Mastra au travers d’implémentations réelles
- **Démarrages rapides** : initialisez des projets plus rapidement qu’en partant de zéro

## Templates disponibles {/* #available-templates */}

Les templates suivants présentent des applications Mastra centrées sur Gateway :

- `template-docs-expert`: répond aux questions de documentation avec la recherche web Gateway, des citations, de la mémoire et des réponses structurées.
- `template-browser-agent`: utilise AgentBrowser pour naviguer, inspecter et interagir avec des pages web.
- `template-meeting-notes`: transforme des transcriptions Zoom ou importées en notes structurées avec décisions et actions à effectuer.
- `template-company-knowledge`: indexe du contenu Linear et Notion dans pgvector et répond aux questions de connaissances internes.
- `template-claw-assistant`: exploite un espace de travail avec des Tools de système de fichiers, bac à sable, navigateur et recherche web.

## Utiliser les templates {/* #using-templates */}

### Installation {/* #installation */}

Installez un template avec la commande `create-mastra` :

```sh npm2yarn
npx create-mastra@latest my-project --template template-name
```

Cette commande crée un projet complet et installe ses dépendances. L’auteur du template contrôle les modèles, dépendances de fournisseur, variables d’environnement et code source.

### Processus de configuration {/* #setup-process */}

Après l’installation :

1. **Accédez au répertoire du projet** :

   ```bash
   cd your-project-name
   ```

1. **Configurez les variables d’environnement** :

   ```bash
   cp .env.example .env
   ```

   Modifiez `.env` avec les clés d’API requises, comme indiqué dans le README du template.

1. **Démarrez le serveur de développement** :

   ```sh npm2yarn
   npm run dev
   ```

### Structure d’un template {/* #template-structure */}

Tous les templates suivent cette structure standardisée :

```
your-template/
├── src/
│   └── mastra/
│       ├── agents/       # Agent definitions
│       ├── tools/        # Tool definitions
│       ├── workflows/    # Workflow definitions
│       └── index.ts      # Main Mastra config
├── .env.example          # Required environment variables
├── package.json
├── tsconfig.json
└── README.md
```
