# Référence de l'API

## API des membres {/* #members-api */}

L'URL racine des endpoints ci-dessous est : `/v1/org/members`

| Méthode | Endpoint | Description |
| - | - | - |
| GET | `/` | Répertorier les membres |
| POST | `/invitations` | Envoyer une invitation |
| GET | `/invitations` | Répertorier les invitations |
| DELETE | `/invitations/:id` | Révoquer une invitation |
| PATCH | `/:id` | Mettre à jour le rôle d'un membre |
| DELETE | `/:id` | Supprimer un membre |

## API tokens {/* #api-tokens */}

L'URL racine des endpoints ci-dessous est : `/v1/auth/tokens`

| Méthode | Endpoint | Description |
| - | - | - |
| POST | `/` | Créer un jeton d'API |
| GET | `/` | Répertorier les jetons d'API |
| DELETE | `/:id` | Supprimer un jeton d'API |

## Studio API {/* #studio-api */}

L'URL racine des endpoints ci-dessous est : `/v1/studio`

| Méthode | Endpoint | Description |
| - | - | - |
| GET | `/projects` | Répertorier les projets Studio |
| POST | `/projects` | Créer un projet |
| GET | `/projects/:id` | Récupérer les détails et les déploiements d'un projet |
| DELETE | `/projects/:id` | Supprimer un projet |
| POST | `/deploys` | Créer un déploiement |
| POST | `/deploys/:id/upload-complete` | Confirmer l'import de l'artefact |
| GET | `/deploys/:id` | Récupérer l'état du déploiement |
| GET | `/deploys/:id/logs` | Récupérer les logs du déploiement |
| GET | `/deploys/:id/logs/stream` | Diffuser les logs du déploiement (SSE) |

## Server API {/* #server-api */}

L'URL racine des endpoints ci-dessous est : `/v1/server`

| Méthode | Endpoint | Description |
| - | - | - |
| GET | `/projects` | Répertorier les projets Server |
| POST | `/projects` | Créer un projet |
| GET | `/projects/:id` | Récupérer les détails d'un projet |
| DELETE | `/projects/:id` | Supprimer un projet |
| PUT | `/projects/:id/env` | Définir les variables d'environnement |
| GET | `/projects/:id/env` | Récupérer les variables d'environnement |
| POST | `/projects/:id/env/restart` | Redémarrer après une modification de l'environnement |
| GET | `/projects/:id/domains` | Répertorier les domaines |
| POST | `/projects/:id/domains` | Ajouter un domaine personnalisé |
| GET | `/projects/:id/runtime-logs` | Récupérer les logs d'exécution |
| POST | `/projects/:id/redeploy` | Déclencher un redéploiement |
| POST | `/projects/:id/always-on` | Activer le mode always-on |
| DELETE | `/projects/:id/always-on` | Désactiver le mode always-on |
| POST | `/deploys` | Créer un déploiement |
| POST | `/deploys/:id/upload-complete` | Confirmer l'import de l'artefact |
| GET | `/deploys/:id` | Récupérer l'état du déploiement |
| GET | `/deploys/:id/logs` | Récupérer les logs du déploiement |
| POST | `/deploys/:id/cancel` | Annuler un déploiement en attente ou en cours |
| DELETE | `/deploys/:id` | Arrêter un déploiement en cours |

## Gateway API {/* #gateway-api */}

L'URL racine des endpoints ci-dessous est : `/v1/gateway`

| Méthode | Endpoint | Description |
| - | - | - |
| GET | `/projects` | Répertorier les projets Gateway |
| GET | `/projects/:id` | Récupérer les détails d'un projet |
| PATCH | `/projects/:id` | Mettre à jour les paramètres d'un projet |
| DELETE | `/projects/:id` | Supprimer un projet |
| POST | `/projects/provision` | Provisionner un nouveau projet Gateway |
| GET | `/projects/:id/keys` | Répertorier les clés d'API |
| POST | `/projects/:id/keys` | Créer une clé d'API |
| DELETE | `/projects/:id/keys/:keyId` | Révoquer une clé d'API |
| GET | `/projects/:id/keys/:keyId/bindings` | Répertorier les liaisons de fournisseurs au niveau de la clé |
| POST | `/projects/:id/keys/:keyId/bindings` | Ajouter une liaison de fournisseur au niveau de la clé (BYOK) |
| DELETE | `/projects/:id/keys/:keyId/bindings/:provider` | Supprimer une liaison au niveau de la clé |
| GET | `/projects/:id/bindings` | Répertorier les liaisons de fournisseurs au niveau du projet |
| POST | `/projects/:id/bindings` | Ajouter une liaison de fournisseur au niveau du projet (BYOK) |
| DELETE | `/projects/:id/bindings/:provider` | Supprimer une liaison au niveau du projet |
| GET | `/projects/:id/usage/has-activity` | Vérifier si le projet a reçu des requêtes |
| GET | `/projects/:id/usage/activity` | Récupérer l'activité d'utilisation agrégée |
| GET | `/projects/:id/usage/memory-activity` | Récupérer le total des tokens de mémoire sur une période |
| GET | `/projects/:id/usage/logs` | Récupérer les logs des requêtes |
| GET | `/projects/:id/usage/logs/facets` | Récupérer les facettes de filtrage des logs |
| GET | `/projects/:id/usage/logs/:requestId` | Récupérer le détail d'une requête précise |
| GET | `/projects/:id/memory/threads` | Répertorier les threads (tableau de bord) |
| POST | `/projects/:id/memory/threads` | Créer un thread (tableau de bord) |
| GET | `/projects/:id/memory/threads/:threadId` | Récupérer un thread (tableau de bord) |
| PATCH | `/projects/:id/memory/threads/:threadId` | Mettre à jour un thread (tableau de bord) |
| DELETE | `/projects/:id/memory/threads/:threadId` | Supprimer un thread (tableau de bord) |
| POST | `/projects/:id/memory/threads/:threadId/clone` | Cloner un thread (tableau de bord) |
| GET | `/projects/:id/memory/threads/:threadId/messages` | Répertorier les messages (tableau de bord) |
| POST | `/projects/:id/memory/threads/:threadId/messages` | Enregistrer des messages (tableau de bord) |
| DELETE | `/projects/:id/memory/threads/:threadId/messages` | Supprimer des messages (tableau de bord) |
| GET | `/projects/:id/memory/threads/:threadId/observations/history` | Historique des observations (tableau de bord) |
| GET | `/models` | Répertorier les modèles disponibles |
