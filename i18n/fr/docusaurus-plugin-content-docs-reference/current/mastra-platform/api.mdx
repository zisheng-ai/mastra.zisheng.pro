# Référence d’API

## API des membres

L’URL racine des points de terminaison ci-dessous est : `/v1/org/members`

| Méthode | Point de terminaison | Description |
| - | - | - |
| GET | `/` | Lister les membres |
| POST | `/invitations` | Envoyer une invitation |
| GET | `/invitations` | Lister les invitations |
| DELETE | `/invitations/:id` | Révoquer une invitation |
| PATCH | `/:id` | Mettre à jour le rôle d’un membre |
| DELETE | `/:id` | Supprimer un membre |

## Jetons d’API

L’URL racine des points de terminaison ci-dessous est : `/v1/auth/tokens`

| Méthode | Point de terminaison | Description |
| - | - | - |
| POST | `/` | Créer un jeton d’API |
| GET | `/` | Lister les jetons d’API |
| DELETE | `/:id` | Supprimer un jeton d’API |

## API Studio

L’URL racine des points de terminaison ci-dessous est : `/v1/studio`

| Méthode | Point de terminaison | Description |
| - | - | - |
| GET | `/projects` | Lister les projets Studio |
| POST | `/projects` | Créer un projet |
| GET | `/projects/:id` | Obtenir les détails et les déploiements du projet |
| DELETE | `/projects/:id` | Supprimer un projet |
| POST | `/deploys` | Créer un déploiement |
| POST | `/deploys/:id/upload-complete` | Confirmer l’importation de l’artefact |
| GET | `/deploys/:id` | Obtenir l’état du déploiement |
| GET | `/deploys/:id/logs` | Obtenir les journaux du déploiement |
| GET | `/deploys/:id/logs/stream` | Diffuser les journaux du déploiement (SSE) |

L’URL racine des points de terminaison ci-dessous est : `/v1/server`

| Méthode | Point de terminaison | Description |
| - | - | - |
| GET | `/projects` | Lister les projets Server |
| POST | `/projects` | Créer un projet |
| GET | `/projects/:id` | Obtenir les détails du projet |
| DELETE | `/projects/:id` | Supprimer un projet |

| GET | `/projects/:id/env` | Obtenir les variables d’environnement |
| POST | `/projects/:id/env/restart` | Redémarrer après une modification de l’environnement |
| GET | `/projects/:id/domains` | Lister les domaines |

| GET | `/projects/:id/runtime-logs` | Obtenir les journaux d’exécution |

## API Gateway

L’URL racine des points de terminaison ci-dessous est : `/v1/gateway`

| Méthode | Point de terminaison | Description |
| - | - | - |
| GET | `/projects` | Lister les projets Gateway |
| GET | `/projects/:id` | Obtenir les détails du projet |
| PATCH | `/projects/:id` | Mettre à jour les paramètres du projet |
| DELETE | `/projects/:id` | Supprimer un projet |
| POST | `/projects/provision` | Provisionner un nouveau projet Gateway |
| GET | `/projects/:id/keys` | Lister les clés d’API |
| POST | `/projects/:id/keys` | Créer une clé d’API |
| DELETE | `/projects/:id/keys/:keyId` | Révoquer une clé d’API |
| GET | `/projects/:id/keys/:keyId/bindings` | Lister les liaisons de fournisseurs au niveau de la clé |
| POST | `/projects/:id/keys/:keyId/bindings` | Ajouter une liaison de fournisseur au niveau de la clé (BYOK) |
| DELETE | `/projects/:id/keys/:keyId/bindings/:provider` | Supprimer une liaison au niveau de la clé |
| GET | `/projects/:id/bindings` | Lister les liaisons de fournisseurs au niveau du projet |
| POST | `/projects/:id/bindings` | Ajouter une liaison de fournisseur au niveau du projet (BYOK) |
| DELETE | `/projects/:id/bindings/:provider` | Supprimer une liaison au niveau du projet |
| GET | `/projects/:id/usage/has-activity` | Vérifier si le projet a reçu des requêtes |
| GET | `/projects/:id/usage/activity` | Obtenir l’activité d’utilisation agrégée |
| GET | `/projects/:id/usage/memory-activity` | Obtenir le total des jetons de mémoire sur une période |
| GET | `/projects/:id/usage/logs` | Obtenir les journaux des requêtes |
| GET | `/projects/:id/usage/logs/facets` | Obtenir les facettes de filtre des journaux |
| GET | `/projects/:id/usage/logs/:requestId` | Obtenir les détails d’une requête spécifique |
| GET | `/projects/:id/memory/threads` | Lister les threads (tableau de bord) |
| POST | `/projects/:id/memory/threads` | Créer un thread (tableau de bord) |
| GET | `/projects/:id/memory/threads/:threadId` | Obtenir un thread (tableau de bord) |
| PATCH | `/projects/:id/memory/threads/:threadId` | Mettre à jour un thread (tableau de bord) |
| DELETE | `/projects/:id/memory/threads/:threadId` | Supprimer un thread (tableau de bord) |
| POST | `/projects/:id/memory/threads/:threadId/clone` | Cloner un thread (tableau de bord) |
| GET | `/projects/:id/memory/threads/:threadId/messages` | Lister les messages (tableau de bord) |
| POST | `/projects/:id/memory/threads/:threadId/messages` | Enregistrer les messages (tableau de bord) |
| DELETE | `/projects/:id/memory/threads/:threadId/messages` | Supprimer les messages (tableau de bord) |
| GET | `/projects/:id/memory/threads/:threadId/observations/history` | Historique des observations (tableau de bord) |
| GET | `/models` | Lister les modèles disponibles |
