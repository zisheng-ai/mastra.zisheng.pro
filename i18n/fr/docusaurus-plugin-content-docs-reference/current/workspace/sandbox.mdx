# WorkspaceSandbox

**Ajouté dans :** `@mastra/core@1.1.0`

L'interface `WorkspaceSandbox` définit la manière dont les Workspaces exécutent des commandes et gèrent les processus en arrière-plan.

## Méthodes {/* #methods */}

### `start()` {/* #start */}

Démarre le Sandbox. Cette méthode est appelée automatiquement par `workspace.init()` ou lors du premier appel à `executeCommand()`.

```typescript
await sandbox.start()
```

Cette méthode prépare le Sandbox à l'exécution de commandes.

### `stop()` {/* #stop */}

Arrête le Sandbox.

```typescript
await sandbox.stop?.()
```

### `destroy()` {/* #destroy */}

Nettoie les ressources du Sandbox. Cette méthode est appelée par `workspace.destroy()`.

```typescript
await sandbox.destroy()
```

### `executeCommand(command, args?, options?)` {/* #executecommandcommand-args-options */}

Exécute une commande shell.

```typescript
const result = await sandbox.executeCommand('ls', ['-la', '/docs'])
const result = await sandbox.executeCommand('npm', ['install', 'lodash'])
```

### `getInfo()` {/* #getinfo */}

Renvoie l'état du Sandbox et les informations sur ses ressources.

```typescript
const info = await sandbox.getInfo()
// { status: 'running', resources: { memoryMB: 512, cpuPercent: 5 } }
```

### `getInstructions(opts?)` {/* #getinstructionsopts */}

Renvoie une description du fonctionnement de ce Sandbox. Elle est injectée dans le message système de l'Agent lorsque le Workspace lui est attribué.

```typescript
const instructions = sandbox.getInstructions?.()
// 'Local command execution. Working directory: "/workspace".'
```
