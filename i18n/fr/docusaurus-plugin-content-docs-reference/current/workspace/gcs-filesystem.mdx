# GCSFilesystem

Stocke des fichiers dans Google Cloud Storage. Pour plus de détails sur l'interface, consultez [l'interface WorkspaceFilesystem](/reference/workspace/filesystem).

## Installation {/* #installation */}

```bash npm2yarn
npm install @mastra/gcs
```

## Utilisation {/* #usage */}

Ajoutez un `GCSFilesystem` à un Workspace et attribuez-le à un Agent :

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'

const workspace = new Workspace({
  filesystem: new GCSFilesystem({
    bucket: 'my-gcs-bucket',
    projectId: 'my-project-id',
    credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

### Utilisation des Application Default Credentials {/* #using-application-default-credentials */}

Si votre application s'exécute sur Google Cloud ou si la CLI `gcloud` est configurée, vous pouvez omettre les identifiants :

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  // Uses Application Default Credentials automatically
})
```

Les [Application Default Credentials (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials) détectent automatiquement les identifiants dans l'ordre suivant :

1. Variable d'environnement `GOOGLE_APPLICATION_CREDENTIALS` (chemin vers un fichier de clé de compte de service)
1. Compte de service par défaut lors de l'exécution sur GCP (Compute Engine, Cloud Run, GKE, etc.)
1. Identifiants utilisateur provenant de `gcloud auth application-default login` (pour le développement local)

### Utilisation du chemin d'un fichier de clé {/* #using-a-key-file-path */}

Vous pouvez également fournir le chemin d'un fichier de clé de compte de service :

```typescript
import { GCSFilesystem } from '@mastra/gcs'

const filesystem = new GCSFilesystem({
  bucket: 'my-gcs-bucket',
  projectId: 'my-project-id',
  credentials: '/path/to/service-account-key.json',
})
```

## Méthodes {/* #methods */}

GCSFilesystem implémente [l'interface WorkspaceFilesystem](/reference/workspace/filesystem) et fournit toutes les méthodes standard d'un système de fichiers :

- `readFile(path, options?)` - Lit le contenu d'un fichier
- `writeFile(path, content, options?)` - Écrit du contenu dans un fichier
- `appendFile(path, content)` - Ajoute du contenu à un fichier
- `deleteFile(path, options?)` - Supprime un fichier
- `copyFile(src, dest, options?)` - Copie un fichier
- `moveFile(src, dest, options?)` - Déplace ou renomme un fichier
- `mkdir(path, options?)` - Crée un répertoire
- `rmdir(path, options?)` - Supprime un répertoire
- `readdir(path, options?)` - Répertorie le contenu d'un répertoire
- `exists(path)` - Vérifie si un chemin existe
- `stat(path)` - Récupère les métadonnées d'un fichier ou d'un répertoire

### `init()` {/* #init */}

Initialise le système de fichiers. Vérifie l'accès au bucket et les identifiants.

```typescript
await filesystem.init()
```

### `getInfo()` {/* #getinfo */}

Renvoie les métadonnées de cette instance de système de fichiers.

```typescript
const info = filesystem.getInfo()
// { id: '...', name: 'GCSFilesystem', provider: 'gcs', status: 'ready' }
```

### `getMountConfig()` {/* #getmountconfig */}

Renvoie la configuration de montage pour les Sandboxes prenant en charge le montage de ce type de système de fichiers.

```typescript
const config = filesystem.getMountConfig()
// { type: 'gcs', bucket: 'my-bucket', ... }
```

## Montage dans des Sandboxes E2B {/* #mounting-in-e2b-sandboxes */}

GCSFilesystem peut être monté dans des Sandboxes E2B afin de rendre le bucket accessible comme un répertoire local :

```typescript
import { Workspace } from '@mastra/core/workspace'
import { GCSFilesystem } from '@mastra/gcs'
import { E2BSandbox } from '@mastra/e2b'

const workspace = new Workspace({
  mounts: {
    '/data': new GCSFilesystem({
      bucket: 'my-gcs-bucket',
      projectId: 'my-project-id',
      credentials: JSON.parse(process.env.GCS_SERVICE_ACCOUNT_KEY),
    }),
  },
  sandbox: new E2BSandbox({ id: 'dev-sandbox' }),
})
```

Consultez la [référence d'E2BSandbox](/reference/workspace/e2b-sandbox) pour en savoir plus sur le montage.
