# WorkspaceFilesystem

**Ajouté dans :** `@mastra/core@1.1.0`

L’interface `WorkspaceFilesystem` définit la manière dont les espaces de travail interagissent avec le stockage de fichiers.

## Méthodes {/* #methods */}

### `readFile(path, options?)` {/* #readfilepath-options */}

Lit le contenu d’un fichier.

```typescript
const content = await filesystem.readFile('/docs/guide.md')
const buffer = await filesystem.readFile('/image.png', { encoding: 'binary' })
```

### `exists(path)` {/* #existspath */}

Vérifie si un chemin existe.

```typescript

```

**Renvoie :** `Promise<boolean>`

### `stat(path)` {/* #statpath */}

Obtient les métadonnées d’un fichier ou d’un répertoire.

```typescript
const stat = await filesystem.stat('/docs/guide.md')
// { name: 'guide.md', path: '/docs/guide.md', type: 'file', size: 1234, createdAt: Date, modifiedAt: Date }
```

**Renvoie :** `Promise<FileStat>`

```typescript
interface FileStat {
  name: string // File or directory name (basename only)
  path: string // Path relative to the filesystem basePath
  type: 'file' | 'directory'
  size: number
  createdAt: Date
  modifiedAt: Date
  mimeType?: string
}
```

## Méthodes facultatives {/* #optional-methods */}

### `init()` {/* #init */}

Initialise le système de fichiers. Appelée par `workspace.init()`.

```typescript
await filesystem.init?.()
```

### `destroy()` {/* #destroy */}

Libère les ressources. Appelée par `workspace.destroy()`.

```typescript
await filesystem.destroy?.()
```

### `getInfo()` {/* #getinfo */}

Obtient les métadonnées du système de fichiers.

```typescript
const info = await filesystem.getInfo?.()
// { id, name, provider, basePath, readOnly, status, storage? }
```

**Renvoie :** `Promise<FilesystemInfo>`

```typescript
interface FilesystemInfo {
  id: string
  name: string
  provider: string
  basePath?: string
  readOnly?: boolean
  status?: string
  storage?: {
    totalBytes?: number
    usedBytes?: number
    availableBytes?: number
  }
}
```

### `getInstructions(opts?)` {/* #getinstructionsopts */}

Renvoie une description du fonctionnement de ce système de fichiers. Elle est injectée dans le message système de l’agent lorsque l’espace de travail est attribué à un agent.

```typescript
const instructions = filesystem.getInstructions?.()
// 'Local filesystem at "/workspace". Files at workspace path "/foo" are stored at "/workspace/foo" on disk.'
```

**Paramètres :**

<PropertiesTable
  content={[

    isOptional: true,
  },
]}
/>

**Renvoie :** `string`
