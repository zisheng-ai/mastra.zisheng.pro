# AgentFSFilesystem

Stocke les fichiers dans une base de données Turso/SQLite par l’intermédiaire du SDK [AgentFS](https://github.com/nichochar/agentfs). Les fichiers sont conservés d’une session à l’autre dans une base de données SQLite locale, ce qui fournit aux Agents un stockage durable sans service cloud externe. Pour plus de détails sur l’interface, consultez l’[interface WorkspaceFilesystem](/reference/workspace/filesystem).

## Installation {/* #installation */}

```bash npm2yarn
npm install @mastra/agentfs
```

## Utilisation {/* #usage */}

Ajoutez un `AgentFSFilesystem` à un Workspace et attribuez-le à un Agent. Vous devez fournir au moins l’une des valeurs `agentId`, `path` ou `agent` lors de l’instanciation de la classe `AgentFSFilesystem`.

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { AgentFSFilesystem } from '@mastra/agentfs'

const workspace = new Workspace({
  filesystem: new AgentFSFilesystem({
    agentId: 'my-agent',
  }),
})

const agent = new Agent({
  id: 'file-agent',
  name: 'file-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
})
```

### Utiliser un chemin de base de données explicite {/* #using-an-explicit-database-path */}

Par défaut, les bases de données sont stockées dans le répertoire `.agentfs`, avec l’`agentId` comme nom de fichier. Vous pouvez indiquer un chemin de base de données personnalisé :

```typescript
import { AgentFSFilesystem } from '@mastra/agentfs'

const filesystem = new AgentFSFilesystem({
  path: '/data/my-agent.db',
})
```

### Utiliser une instance AgentFS déjà ouverte {/* #using-a-pre-opened-agentfs-instance */}

Si vous devez gérer vous-même le cycle de vie d’AgentFS :

```typescript
import { AgentFS } from 'agentfs-sdk'
import { AgentFSFilesystem } from '@mastra/agentfs'

const agent = await AgentFS.open({ id: 'my-agent' })

const filesystem = new AgentFSFilesystem({
  agent, // caller manages open/close
})
```
