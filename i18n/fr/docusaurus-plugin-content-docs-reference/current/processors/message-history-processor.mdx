# MessageHistory

`MessageHistory` est un **Processor hybride** qui gère à la fois la récupération et la persistance de l’historique des messages. En entrée, il récupère les anciens messages depuis le stockage et les ajoute au début de la conversation. En sortie, il conserve les nouveaux messages dans le stockage.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
})
```

## Exemple d’utilisation avancée {/* #extended-usage-example */}

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStorage } from '@mastra/pg'

const storage = new PostgresStorage({
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
    }),
  ],
})
```

## Comportement {/* #behavior */}

### Traitement de l’entrée {/* #input-processing */}

1. Récupère `threadId` depuis le contexte de requête.
1. Récupère les anciens messages depuis le stockage, classés par date de création décroissante.
1. Exclut les messages système, qui ne doivent pas être stockés dans la base de données.
1. Fusionne les anciens messages avec les messages entrants en évitant les doublons d’ID.
1. Ajoute les anciens messages avec le tag `source: 'memory'`.

### Traitement de la sortie {/* #output-processing */}

1. Récupère `threadId` depuis le contexte de requête.
1. Ignore la persistance si `readOnly` est défini dans la configuration de Memory.
1. Exclut des messages les appels de Tools incomplets.
1. Conserve dans le stockage les nouveaux messages d’entrée de l’utilisateur et de réponse de l’assistant.
1. Met à jour l’horodatage `updatedAt` du fil de discussion.
