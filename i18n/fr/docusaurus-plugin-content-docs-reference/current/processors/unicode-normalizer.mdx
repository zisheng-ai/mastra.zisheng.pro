# UnicodeNormalizer

`UnicodeNormalizer` est un **Processor d’entrée** qui normalise le texte Unicode afin d’uniformiser sa mise en forme et de supprimer les caractères potentiellement problématiques avant l’envoi des messages au modèle de langage. Ce Processor traite les représentations Unicode et supprime les caractères de contrôle. Il normalise également la mise en forme des espaces blancs.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { UnicodeNormalizer } from '@mastra/core/processors'

const processor = new UnicodeNormalizer({
  stripControlChars: true,
  collapseWhitespace: true,
})
```

## Exemple d’utilisation étendu {/* #extended-usage-example */}

```typescript title="src/mastra/agents/normalized-agent.ts"
import { Agent } from '@mastra/core/agent'
import { UnicodeNormalizer } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'normalized-agent',
  name: 'normalized-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new UnicodeNormalizer({
      stripControlChars: true,
      preserveEmojis: true,
      collapseWhitespace: true,
      trim: true,
    }),
  ],
})
```
