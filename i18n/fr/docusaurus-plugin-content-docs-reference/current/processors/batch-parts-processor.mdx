# BatchPartsProcessor

`BatchPartsProcessor` est un **Processor de sortie** qui regroupe plusieurs segments de flux afin de réduire la fréquence des émissions pendant le streaming. Ce Processor permet de réduire la surcharge réseau, d’améliorer l’expérience utilisateur en regroupant les petits fragments de texte et d’optimiser les performances du streaming en contrôlant le moment où les segments sont émis vers le client.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { BatchPartsProcessor } from '@mastra/core/processors'

const processor = new BatchPartsProcessor({
  batchSize: 5,
  maxWaitTime: 100,
  emitOnNonText: true,
})
```
