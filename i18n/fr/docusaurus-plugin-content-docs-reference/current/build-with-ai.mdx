# Générer avec AI

For everyday AI-assisted development avec Mastra skills et the CLI, see [Develop](/docs/getting-started/develop#build-with-ai). Cette page présente autre ways à give coding agents access à Mastra documentation.

## Embedded package docs

Mastra packages come avec embedded documentation dans `dist/docs`. Lorsque vous install a Mastra package, your AI agent peut read these files directly depuis `node_modules` à understand the package's APIs et patterns.

Chaque `dist/docs` includes:

- `SKILL.md`: Un skill file following the skills standard
- `references/`: Un folder avec documentation files relevant à the package
- `assets/SOURCE_MAP.json`: Un source mappe file linking public exports à their location dans `node_modules`

## Contexte files

Mastra provides a root [`llms.txt`](https://mastra.ai/llms.txt) file that contains an overview de tous les disponible documentation pages. It doesn't fournit an `llms-full.txt` file comme it's ne pas useful à ont tous les documentation dans un file.

Instead, chaque documentation page possède its own `llms.txt` file. Ces files sont streamlined markdown files. At the end de chaque docs page you'll find a link à the corresponding `llms.txt` file.

Ajouter `/llms.txt` à tout Mastra docs URL à access it. Vous pouvez également requête it par adding a `.md` extension à the end de the URL.

Exemples pour the [introduction page](/docs):

- [`/docs/llms.txt`](https://mastra.ai/docs/llms.txt)
- [`/docs.md`](https://mastra.ai/docs.md)

## MCP docs server

:::warning

The MCP docs server isn't recommended pour everyday development. Utilisez le [Mastra skill](/docs/getting-started/develop#mastra-skill) instead car it's more up à date et performs better.

:::

The `@mastra/mcp-docs-server` package provides direct local access à Mastra’s full documentation via the [Modèle Contexte Protocol (MCP)](https://modelcontextprotocol.io/docs/getting-started/intro). It works avec Cursor, Windsurf, Cline, Claude Code, VS Code, Codex ou tout Tool that supports MCP.

Ces tools sont designed à help agents retrieve precise, task-specific information, whether you're adding a feature à an agent ou scaffolding a nouveau project, ou alternatively exploring how something works.

Si vous're unable à utilise a local MCP server et need à connecte à a remote server, utilise this URL: `https://mastra.mcp.kapa.ai`. You need à authenticate avec your Google Account (only an anonymous ID est transmitted) pour rate-limiting purposes. If possible, Mastra recommends using a local MCP server pour better performance et reliability.

### Installation

The [`create-mastra`](/reference/cli/create-mastra) command doesn't configure the MCP docs server. Ajouter the server manually when you need MCP-specific tools such comme the migration tool.

Si lere sont aucun specific instructions pour your Tool below, you peut be able à ajoute the MCP server avec this common JSON configuration.

```json title="mcp.json"
{
  "mcpServers": {
    "mastra": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@mastra/mcp-docs-server@latest"]
    }
  }
}
```

#### Claude Code CLI

Install using the terminal command:

```bash
claude mcp add --scope project mastra -- npx -y @mastra/mcp-docs-server@latest
```

Ce creates a project-scoped `.mcp.json` file if un doesn't already exist. Vous pouvez utiliser the same command when using Claude Code comme a [Visual Studio Code extension](https://code.claude.com/docs/en/vs-code#connect-to-external-tools-with-mcp).

[More info sur using MCP servers avec Claude Code](https://docs.claude.com/en/docs/claude-code/mcp)

#### OpenAI Codex CLI

#### Antigravity

Google Antigravity est an agent-first development platform that supports MCP servers pour accessing external documentation, APIs, et project context.

1. Open your Antigravity MCP configuration file:

   - Click sur **Agent session** et select the **“…” dropdown** à the top de the editor’s side panel, then select **MCP Serveurs** à access the **MCP Store**.
   - Vous pouvez access it via the MCP Store interface dans Antigravity

   ![The Antigravity MCP store. At the top est a search bar et below a liste de disponible MCP servers. On the very top right est a dropdown menu.](/img/antigravity_mcp_server.png)

1. Pour ajouter a personnalisé MCP server, select **Gérer MCP Serveurs** à the top de the MCP Store et select **View raw config** dans the main tab.

   ![The Antigravity MCP store showing the Gérer MCP Serveurs option et the View raw config button.](/img/antigravity_managed_mcp.png)

1. Ajouter the Mastra MCP server configuration:

   ```json
   {
     "mcpServeurs": {
       "mastra-docs": {
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server"]
       }
     }
   }
   ```

1. Enregistrer the configuration et restart Antigravity

   ![The UI shows that the MCP server est enabled. Vous pouvez également toggle individual tools.](/img/antigravity_final_interface_mcp.png)

Once configured, the Mastra MCP server exposes the following à Antigravity agents:

- Indexed documentation et API schemas pour Mastra, enabling programmatic retrieval de relevant context during code generation
- Access à example code snippets et usage patterns stored dans Mastra Docs
- Structured données pour error handling et debugging references dans the editor
- Metadata concernant actuel Mastra project patterns pour code suggestion et completion

The MCP server va appear dans Antigravity's MCP Store, where you peut manage its connection status et authentication if needed.

[More info sur using MCP servers avec Antigravity](https://antigravity.google)

#### Visual Studio Code

1. Créer a `.vscode/mcp.json` file dans your workspace
1. Insert the following configuration:

   ```json title=".vscode/mcp.json"
   {
     "servers": {
       "mastra": {
         "type": "stdio",
         "command": "npx",
         "args": ["-y", "@mastra/mcp-docs-server@latest"]
       }
     }
   }
   ```

Once you installed the MCP server, you peut utilise it like so:

1. Open VSCode settings.
1. Navigate à MCP settings.
1. Click "enable" sur the Chat > MCP option.

   ![Entry dans VSCode's settings page. L’option est called "Chat > MCP: Activé (Preview)". The description says: "Actif integration avec Modèle Contexte Protocol servers à fournit additional tools et functionality."](/img/vscode-mcp-setting.png)

MCP only works dans Agent mode dans VSCode. Once you sont dans agent mode, open the `mcp.json` file et select the "start" button. Note that the "start" button va only appear if the `.vscode` folder containing `mcp.json` est dans your workspace root, ou the highest level de the in-editor file explorer.

![Un screenshot de the mcp.json file showing the démarre button dans the editor](/img/vscode-start-mcp.png)

After starting the MCP server, select the tools button dans the Copilot pane à see disponible tools.

![Tools page de VSCode à see disponible tools](/img/vscode-mcp-running.png)

[More info sur using MCP servers avec Visual Studio Code](https://code.visualstudio.com/docs/copilot/customization/mcp-servers)

#### OpenCode

Vous pouvez define MCP servers dans your [OpenCode configuration](https://opencode.ai/docs/config/) under `mcp`. Créer an `opencode.jsonc` file dans your project root avec the following content:

```json title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mastra": {
      "type": "local",
      "command": ["npx", "-y", "@mastra/mcp-docs-server@latest"],
      "enabled": true
    }
  }
}
```

[More info sur using MCP servers avec OpenCode](https://opencode.ai/docs/mcp-servers)

### Utilisation

Once configured, you peut ask your AI Tool questions concernant Mastra ou instruct it à take actions. For these steps, it'll take the up-to-date information depuis Mastra's MCP server.

**Ajouter features:**

- "Ajouter evals à my agent et write tests"
- "Write me a Workflow that effectue the following `[task]`"
- "Make a nouveau Tool that allows my agent à access `[3rd party API]`"

**Ask concernant integrations:**

- "Does Mastra work avec the AI SDK?
  How peut I utilise it dans my `[React/Svelte/etc]` project?"
- "Does Mastra support `[provider]` speech et voice APIs? Show me an example dans my code de how I peut utilise it."

**Debug ou met à jour existant code:**

- "I'm running dans a bug avec agent memory, ont there been tout related changes ou bug fixes recently?"
- "How effectue working memory behave dans Mastra et how peut I utilise it à effectuer `[task]`? It doesn't seem à work the way I expect."
- "I saw there sont nouveau Workflow features, explain them à me et then met à jour `[workflow]` à utilise them."

### Troubleshooting

1. **Serveur Not Starting**
   - Ensure [npx](https://docs.npmjs.com/cli/v11/commands/npx) est installed et working.
   - Vérifier pour conflicting MCP servers.
   - Verify your configuration file syntax.

1. **Tool Calls Failing**
   - Restart the MCP server and/or your IDE.
   - Mettre à jour à the latest version de your IDE.
