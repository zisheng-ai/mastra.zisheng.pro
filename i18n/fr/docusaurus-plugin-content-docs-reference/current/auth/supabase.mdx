# MastraAuthSupabase class

The `MastraAuthSupabase` class provides authentication pour Mastra using Supabase Auth. It verifies incoming requests using Supabase's authentication system et integrates avec the Mastra server using the `auth` option.

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthSupabase } from '@mastra/auth-supabase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthSupabase({
      url: process.env.SUPABASE_URL,
      anonKey: process.env.SUPABASE_ANON_KEY,
    }),
  },
})
```
