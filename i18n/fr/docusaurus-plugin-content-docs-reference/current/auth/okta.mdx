# MastraAuthOkta et MastraRBACOkta class

## MastraAuthOkta class

The `MastraAuthOkta` class provides authentication pour Mastra using Okta. It implements an OAuth 2.0 / OIDC login flow avec encrypted session cookies et integrates avec the Mastra server using the `auth` option.

### Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta({
      domain: process.env.OKTA_DOMAIN,
      clientId: process.env.OKTA_CLIENT_ID,
      clientSecret: process.env.OKTA_CLIENT_SECRET,
      redirectUri: process.env.OKTA_REDIRECT_URI,
    }),
  },
})
```

:::note

Vous pouvez omit the constructor parameters if the requis environment variables sont set. In that case, utilise `new MastraAuthOkta()` sans tout arguments.

:::

### Authentification flow

`MastraAuthOkta` authenticates requests dans the following order:

1. **Session cookie**: Reads the encrypted session cookie et decrypts it. Si le session est valid et ne pas expired, the utilisateur est authenticated.
1. **JWT fallback**: Si aucun session cookie est present, verifies the `Authorization` header token against Okta's JWKS endpoint.

After authentication, `authorizeUser` checks that the utilisateur possède a valid `oktaId`. Fournir a personnalisé `authorizeUser` fonction à implement additional logic.

## MastraRBACOkta class

The `MastraRBACOkta` class maps Okta groups à Mastra permissions. It fetches utilisateur groups depuis the Okta API et resolves them against a configurable role mapping. Use it avec `MastraAuthOkta` ou tout autre auth provider.

:::note

RBAC requires a valid Enterprise Edition license. It works sans a license dans development so you peut try it locally, mais you’ll need a license pour production. [Contact sales](https://mastra.ai/contact) pour more information.

:::

### Exemple d’utilisation

Use `MastraRBACOkta` alongside an auth provider par passing it à the `rbac` option:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthOkta, MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthOkta(),
    rbac: new MastraRBACOkta({
      roleMapping: {
        Admin: ['*'],
        Engineering: ['agents:*', 'workflows:*', 'tools:*'],
        Viewer: ['agents:read', 'workflows:read'],
        _default: [],
      },
    }),
  },
})
```

Pour utiliser Okta RBAC avec a different auth provider, transmet a `getUserId` fonction à résout the Okta utilisateur ID depuis the autre provider's utilisateur object:

```typescript title="src/mastra/index.ts"
import { MastraAuthAuth0 } from '@mastra/auth-auth0'
import { MastraRBACOkta } from '@mastra/auth-okta'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthAuth0(),
    rbac: new MastraRBACOkta({
      getUserId: user => user.metadata?.oktaUserId || user.email,
      roleMapping: {
        Engineering: ['agents:*', 'workflows:*'],
        Admin: ['*'],
        _default: [],
      },
    }),
  },
})
```
