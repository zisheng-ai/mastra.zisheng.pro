# voice.updateConfig()

La méthode `updateConfig()` permet de mettre à jour la configuration d’un fournisseur Voice au moment de l’exécution. Elle est utile pour modifier les paramètres vocaux, les clés d’API ou d’autres options propres au fournisseur sans créer de nouvelle instance.

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'

// Initialize a real-time voice provider
const voice = new OpenAIRealtimeVoice({
  realtimeConfig: {
    model: 'gpt-5.1-realtime',
    apiKey: process.env.OPENAI_API_KEY,
  },
  speaker: 'alloy',
})

// Connect to the real-time service
await voice.connect()

// Later, update the configuration
voice.updateConfig({
  voice: 'nova', // Change the default voice
  turn_detection: {
    type: 'server_vad',
    threshold: 0.5,
    silence_duration_ms: 1000,
  },
})

// The next speak() call will use the new configuration
await voice.speak('Hello with my new voice!')
```

## Remarques {/* #notes */}

- L’implémentation par défaut consigne un avertissement si le fournisseur ne prend pas en charge cette méthode.
- Les mises à jour de la configuration s’appliquent généralement aux opérations suivantes, et non à celles qui sont déjà en cours.
- Toutes les propriétés définissables dans le constructeur ne peuvent pas nécessairement être mises à jour au moment de l’exécution.
- Le comportement précis dépend de l’implémentation du fournisseur Voice.
- Pour les fournisseurs Voice en temps réel, certaines modifications de configuration peuvent nécessiter une reconnexion au service.
