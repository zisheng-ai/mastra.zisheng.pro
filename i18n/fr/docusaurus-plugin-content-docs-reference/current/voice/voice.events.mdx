# Événements Voice

Les fournisseurs Voice émettent des événements lors des interactions vocales en temps réel. Ces événements peuvent être écoutés avec la méthode [voice.on()](./voice.on) et sont particulièrement importants pour créer des applications vocales interactives.

## Remarques {/* #notes */}

- Tous les événements ne sont pas pris en charge par tous les fournisseurs Voice
- La structure exacte du payload peut varier selon les fournisseurs
- Pour les fournisseurs hors temps réel, la plupart de ces événements ne sont pas émis
- Les événements sont utiles pour créer des interfaces interactives réagissant à l’état de la conversation
- Envisagez d’utiliser la méthode [voice.off()](./voice.off) pour supprimer les écouteurs d’événements lorsqu’ils ne sont plus nécessaires
