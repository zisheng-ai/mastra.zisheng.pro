# voice.addInstructions()

La méthode `addInstructions()` dote un fournisseur Voice d’instructions qui guident le comportement du modèle lors des interactions en temps réel. Elle est particulièrement utile pour les fournisseurs Voice en temps réel qui conservent le contexte au fil d’une conversation.

## Exemple d’utilisation

```typescript
import { OpenAIRealtimeVoice } from '@mastra/voice-openai-realtime'
import { Agent } from '@mastra/core/agent'

// Initialize a real-time voice provider
const voice = new OpenAIRealtimeVoice({
  realtimeConfig: {
    model: 'gpt-5.1-realtime',
    apiKey: process.env.OPENAI_API_KEY,
  },
})

// Create an agent with the voice provider
const agent = new Agent({
  id: 'customer-support-agent',
  name: 'Customer Support Agent',
  instructions: 'You are a helpful customer support agent for a software company.',
  model: '__GATEWAY_OPENAI_MODEL__',
  voice,
})

// Add additional instructions to the voice provider
voice.addInstructions(`
  When speaking to customers:
  - Always introduce yourself as the customer support agent
  - Speak clearly and concisely
  - Ask clarifying questions when needed
  - Summarize the conversation at the end
`)

// Connect to the real-time service
await voice.connect()
```

## Valeur renvoyée

Cette méthode ne renvoie aucune valeur.

## Remarques

- Les instructions sont plus efficaces lorsqu’elles sont claires, spécifiques et pertinentes pour l’interaction vocale
- Cette méthode est principalement utilisée avec les fournisseurs Voice en temps réel qui conservent le contexte de conversation
- Si elle est appelée sur un fournisseur Voice ne prenant pas en charge les instructions, elle consigne un avertissement et ne fait rien
- Les instructions ajoutées avec cette méthode sont généralement combinées à celles fournies par un Agent associé
- Pour de meilleurs résultats, ajoutez les instructions avant de démarrer une conversation (avant d’appeler `connect()`)
- Plusieurs appels à `addInstructions()` peuvent remplacer ou ajouter des instructions existantes, selon l’implémentation du fournisseur
