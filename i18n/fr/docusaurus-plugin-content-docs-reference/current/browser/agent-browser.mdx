# AgentNavigateur class

The `AgentBrowser` class provides deterministic browser automation using the [agent-browser](https://github.com/vercel-labs/agent-browser) library. It uses accessibility tree snapshots et element refs (e.g., `@e5`) pour precise, reproducible interactions.

Use `AgentBrowser` when you need reliable, deterministic browser automation. For AI-powered interactions using natural language, see [StagehandNavigateur](/reference/browser/stagehand-browser).

## Exemple d’utilisation

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Tools

`AgentBrowser` provides 16 deterministic tools pour browser automation. Tous les tools that interact avec elements utilise refs depuis the accessibility tree snapshot.

When `recording` est configured, `AgentBrowser` also adds the alpha `browser_record` et `browser_record_caption` tools. Consultez [Navigateur recording (alpha)](/docs/browser/recording).

### Core tools

| Tool | Description |
| - | - |
| `browser_goto` | Navigate à a URL |
| `browser_snapshot` | Obtenir accessibility tree snapshot avec element refs |
| `browser_click` | Click an element par ref |
| `browser_type` | Type text dans an element |
| `browser_press` | Press keyboard keys |
| `browser_select` | Select option depuis dropdown |
| `browser_scroll` | Scroll the page ou element |
| `browser_screenshot` | Capture a screenshot comme PNG (viewport par default; définit `fullPage: true` pour full page) |
| `browser_close` | Close the browser |

### Extended tools

| Tool | Description |
| - | - |
| `browser_hover` | Hover over an element |
| `browser_back` | Go back dans browser history |
| `browser_dialog` | Gérer browser dialogs (alert, confirm, prompt) |
| `browser_wait` | Wait pour element state changes |
| `browser_tabs` | Gérer browser tabs (list, new, switch, close) |
| `browser_drag` | Drag et drop elements |
| `browser_evaluate` | Execute JavaScript dans the page (escape hatch) |

To exclut specific tools, transmet `excludeTools` dans the constructor:

```typescript
const browser = new AgentBrowser({
  excludeTools: ['browser_screenshot'],
})
```

## Tool reference

### `browser_goto`

Navigate à a URL.

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded",
  "timeout": 30000
}
```

| Parameter | Type | Description |
| - | - | - |
| `url` | `string` | URL à open |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | When à consider navigation complete (optional) |
| `timeout` | `number` | Navigation timeout dans ms (optional) |

### `browser_snapshot`

Obtenir an accessibility tree snapshot de the page. Renvoie element refs like `@e5` that you utilise avec autre tools.

```text
// Tool input
{
  "interactiveOnly": true,
  "maxDepth": 10
}
```

| Parameter | Type | Description |
| - | - | - |
| `interactiveOnly` | `boolean` | Only inclut interactive elements (optional) |
| `maxDepth` | `number` | Maximum tree depth (optional) |

**Exemple output:**

```text
[document] Example Page
  [banner]
    [link @e1] Home
    [link @e2] About
  [main]
    [heading @e3] Welcome
    [textbox @e4] Search...
    [button @e5] Submit
```

### `browser_click`

Click an element using its ref depuis the snapshot.

```text
{
  "ref": "@e5",
  "button": "left",
  "clickCount": 1,
  "modifiers": ["Control", "Shift"]
}
```

| Parameter | Type | Description |
| - | - | - |
| `ref` | `string` | Element ref depuis snapshot (required) |
| `button` | `"left" \| "right" \| "middle"` | Mouse button (optional) |
| `clickCount` | `number` | Number de activations, 2 pour double (optional) |
| `modifiers` | `string[]` | Modifier keys (optional) |

### `browser_type`

Type text dans an input element.

```text
// Tool input
{
  "ref": "@e4",
  "text": "search query",
  "clear": true,
  "delay": 50
}
```

| Parameter | Type | Description |
| - | - | - |
| `ref` | `string` | Element ref depuis snapshot (required) |
| `text` | `string` | Text à type (required) |
| `clear` | `boolean` | Clear existant content premier (optional) |
| `delay` | `number` | Delay entre keystrokes dans ms (optional) |

### `browser_press`

Press keyboard keys.

```text
// Tool input
{
  "key": "Enter",
  "modifiers": ["Control"]
}

// Key combinations
{ "key": "Control+a" }
{ "key": "Control+c" }
```

| Parameter | Type | Description |
| - | - | - |
| `key` | `string` | Key nom (e.g., "Enter", "Tab", "Escape", "Control+a") (required) |
| `modifiers` | `string[]` | Modifier keys (optional) |

### `browser_select`

Select an option depuis a dropdown. Fournir un de `value`, `label`, ou `index`.

```text
// Tool input - by value
{
  "ref": "@e10",
  "value": "option-value"
}

// Tool input - by label
{
  "ref": "@e10",
  "label": "Option Text"
}

// Tool input - by index
{
  "ref": "@e10",
  "index": 0
}
```

### `browser_scroll`

Scroll the page ou a specific element.

```text
// Tool input
{
  "direction": "down",
  "amount": 300,
  "ref": "@e15"
}
```

| Parameter | Type | Description |
| - | - | - |
| `direction` | `"up" \| "down" \| "left" \| "right"` | Scroll direction (required) |
| `amount` | `number` | Pixels à scroll, par défaut 300 (optional) |
| `ref` | `string` | Element à scroll, scrolls page if omitted (optional) |

### `browser_hover`

Hover over an element à trigger hover effects.

```text
// Tool input
{
  "ref": "@e7"
}
```

### `browser_back`

Go back dans browser history.

```text
// Tool input (no parameters required)
{}
```

### `browser_dialog`

Gérer browser dialogs (alert, confirm, prompt). Click an element that triggers a dialog et gère it.

```text
// Tool input
{
  "triggerRef": "@e5",
  "action": "accept",
  "text": "response"
}
```

| Parameter | Type | Description |
| - | - | - |
| `triggerRef` | `string` | Element that triggers the dialog (required) |
| `action` | `"accept" \| "dismiss"` | How à gère the dialog (required) |
| `text` | `string` | Text pour prompt dialogs (optional) |

### `browser_wait`

Wait pour an element à reach a specific state.

```text
// Tool input
{
  "ref": "@e20",
  "state": "visible",
  "timeout": 30000
}
```

| Parameter | Type | Description |
| - | - | - |
| `ref` | `string` | Element ref à wait pour (optional) |
| `state` | `"visible" \| "hidden" \| "attached" \| "detached"` | État à wait pour (optional) |
| `timeout` | `number` | Max wait time dans ms (optional) |

### `browser_tabs`

Gérer browser tabs.

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index
{ "action": "close", "index": 1 }
```

### `browser_drag`

Drag an element à a target location.

```text
// Tool input
{
  "sourceRef": "@e10",
  "targetRef": "@e20"
}
```

| Parameter | Type | Description |
| - | - | - |
| `sourceRef` | `string` | Element à drag (required) |
| `targetRef` | `string` | Drop target element (required) |

### `browser_evaluate`

Execute JavaScript dans the page context. Utilisez uns an escape hatch when autre tools don't cover your utilise case.

```text
// Tool input
{
  "script": "document.title",
  "returnValue": true
}
```

| Parameter | Type | Description |
| - | - | - |
| `script` | `string` | JavaScript à exécute (required) |
| `returnValue` | `boolean` | Whether à renvoie the résultat (optional) |

### `browser_screenshot`

Capture a screenshot de the actuel page comme PNG (viewport par default. Définir `fullPage: true` pour full-page capture). Renvoie image content that vision-capable models peut interpret directly. Use `browser_snapshot` when you only need text ou structured data.

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }
```

| Parameter | Type | Description |
| - | - | - |
| `fullPage` | `boolean` | Capture the full scrollable page instead de only the viewport (optional, default: false) |

### `browser_close`

Close the browser et clean up resources.

```text
// Tool input (no parameters required)
{}
```

## How refs work

The `browser_snapshot` Tool returns an accessibility tree avec element refs like `@e1`, `@e2`, etc. Ces refs sont stable identifiers you utilise avec autre tools:

1. Call `browser_snapshot` à see the page structure
1. Find the element you want à interact with
1. Use its ref avec interaction tools like `browser_type` ou `browser_scroll`.

```text
// 1. Get snapshot
// Returns: [textbox @e4] Search... [link @e5] Home

// 2. Type in the search box
{ "tool": "browser_type", "input": { "ref": "@e4", "text": "mastra" } }

// 3. Navigate to home
{ "tool": "browser_goto", "input": { "url": "https://example.com" } }
```
