# Classe FirecrawlBrowser

La classe `FirecrawlBrowser` fournit une automatisation de navigateur fondée sur le [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser). Elle provisionne des sessions de navigateur distantes au moyen de l’API Firecrawl et s’y connecte par le Chrome DevTools Protocol (CDP).

`FirecrawlBrowser` étend [`AgentBrowser`](/reference/browser/agent-browser) et expose le même ensemble de Tools déterministes. Utilisez-le lorsque vous souhaitez des sessions de navigateur hébergées plutôt qu’une installation locale de Chromium. Pour l’automatisation locale, consultez [`AgentBrowser`](/reference/browser/agent-browser). Pour les interactions en langage naturel assistées par l’IA, consultez [`StagehandBrowser`](/reference/browser/stagehand-browser).

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Cycle de vie des sessions {/* #session-lifecycle */}

Le provisionnement des sessions dépend de l’option `scope` héritée d’`AgentBrowser` :

- `'thread'` (par défaut) : chaque fil de discussion dispose de sa propre session de Sandbox Firecrawl, créée lors de la première utilisation et supprimée lorsque la session de navigateur du fil est détruite.
- `'shared'` : une session de Sandbox Firecrawl est créée au lancement du navigateur et partagée entre tous les fils de discussion. La session est supprimée à la fermeture du navigateur.

Dans les deux cas, `FirecrawlBrowser` supprime la session Firecrawl distante lorsque le navigateur se ferme, y compris si la création de la session ou la connexion échoue en cours de route.

## Tools {/* #tools */}

`FirecrawlBrowser` fournit le même ensemble de Tools qu’`AgentBrowser`, notamment `browser_goto`, `browser_snapshot`, `browser_click`, `browser_type` et `browser_screenshot`. Consultez la [référence des Tools d’`AgentBrowser`](/reference/browser/agent-browser) pour obtenir la liste complète et les paramètres des Tools.
