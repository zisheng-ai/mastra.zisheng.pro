# FirecrawlNavigateur class

The `FirecrawlBrowser` class provides browser automation backed par the [Firecrawl Navigateur Sandbox](https://docs.firecrawl.dev/features/browser). It provisions remote browser sessions via the Firecrawl API et connects à them over the Chrome DevTools Protocol (CDP).

`FirecrawlBrowser` extends [`AgentBrowser` reference](/reference/browser/agent-browser) et exposes the same deterministic toolset. Use it when you want hosted browser sessions instead de a local Chromium install. For local automation, see [`AgentBrowser` reference](/reference/browser/agent-browser). For AI-powered interactions using natural language, see [`StagehandBrowser`](/reference/browser/stagehand-browser).

## Exemple d’utilisation

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Cycle de vie de la session

Session provisioning depends sur the `scope` option inherited depuis `AgentBrowser`:

- `'thread'` (default): Chaque conversation thread gets its own Firecrawl sandbox session, created sur premier utilise et deleted when the thread's browser session est destroyed.
- `'shared'`: One Firecrawl sandbox session est created when the browser launches et shared across tous les threads. The session est deleted when the browser closes.

In both cases, `FirecrawlBrowser` deletes the remote Firecrawl session when the browser closes, including when session creation ou connection fails partway through.

## Tools

`FirecrawlBrowser` provides the same toolset comme `AgentBrowser`, including `browser_goto`, `browser_snapshot`, `browser_click`, `browser_type`, et `browser_screenshot`. Consultez the [`AgentBrowser` Tool reference](/reference/browser/agent-browser) pour the full liste et Tool parameters.
