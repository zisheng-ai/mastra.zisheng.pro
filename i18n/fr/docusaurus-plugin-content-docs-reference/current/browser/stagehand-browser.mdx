# StagehandNavigateur class

The `StagehandBrowser` class provides AI-powered browser automation using [Stagehand](https://github.com/browserbase/stagehand). It uses natural language instructions pour interactions instead de element refs.

Use `StagehandBrowser` when you want AI à interpret et exécute browser actions depuis natural language. For deterministic automation using element refs, see [AgentNavigateur](/reference/browser/agent-browser).

## Exemple d’utilisation

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { StagehandBrowser } from '@mastra/stagehand'

const browser = new StagehandBrowser({
  headless: true,
  model: '__GATEWAY_OPENAI_MODEL__',
  selfHeal: true,
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web using natural language.
Use stagehand_act to perform actions like "click the login button".
Use stagehand_extract to get data from pages.`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Tools

`StagehandBrowser` provides 7 AI-powered tools pour browser automation.

When `recording` est configured, `StagehandBrowser` also adds the alpha `browser_record` et `browser_record_caption` tools. Consultez [Navigateur recording (alpha)](/docs/browser/recording).

Core tools:

| Tool | Description |
| - | - |
| `stagehand_act` | Perform actions using natural language instructions |
| `stagehand_extract` | Extract structured données depuis pages |
| `stagehand_observe` | Discover useful elements sur a page |
| `stagehand_navigate` | Navigate à a URL |
| `stagehand_tabs` | Gérer browser tabs |
| `stagehand_screenshot` | Capture a screenshot comme PNG (viewport par default; définit `fullPage: true` pour full page) |
| `stagehand_close` | Close the browser |

To exclut specific tools, transmet `excludeTools` dans the constructor:

```typescript
const browser = new StagehandBrowser({
  excludeTools: ['stagehand_screenshot'],
})
```

## Tool reference

### `stagehand_act`

Perform an action using natural language instructions. The AI interprets your instruction et executes the appropriate browser action.

```text
// Tool input
{
  "instruction": "click the login button",
  "variables": { "username": "john" },
  "useVision": true,
  "timeout": 30000
}

// With variable substitution
{
  "instruction": "type %email% into the email field",
  "variables": { "email": "user@example.com" }
}
```

| Parameter | Type | Description |
| - | - | - |
| `instruction` | `string` | Natural language instruction (required) |
| `variables` | `Record<string, string>` | Variables pour %variableNom% substitution (optional) |
| `useVision` | `boolean` | Actifr vision capabilities (optional) |
| `timeout` | `number` | Timeout dans ms (optional) |

**Renvoie:**

```typescript
interface ActResult {
  success: boolean
  message?: string
  action?: string
  url?: string
}
```

### `stagehand_extract`

Extract structured données depuis a page using natural language instructions.

```text
// Basic extraction
{
  "instruction": "extract all product names and prices"
}

// With schema for structured output
{
  "instruction": "extract the product information",
  "schema": {
    "type": "object",
    "properties": {
      "name": { "type": "string" },
      "price": { "type": "number" },
      "inStock": { "type": "boolean" }
    }
  }
}
```

**Renvoie:**

```typescript
interface ExtractResult<T = unknown> {
  success: boolean
  data?: T
  hint?: string
  error?: string
  url?: string
}
```

### `stagehand_observe`

Discover useful elements sur a page. Renvoie a liste de elements avec their selectors et descriptions.

```text
// Find specific elements
{
  "instruction": "find all buttons related to checkout"
}

// Find all interactive elements
{
  "onlyVisible": true
}
```

| Parameter | Type | Description |
| - | - | - |
| `instruction` | `string` | Natural language instruction (optional, omit à find all) |
| `onlyVisible` | `boolean` | Only inclut visible elements (optional) |
| `timeout` | `number` | Timeout dans ms (optional) |

**Renvoie:**

```typescript
interface ObserveResult {
  success: boolean
  actions: StagehandAction[]
  url?: string
}

interface StagehandAction {
  selector: string
  description: string
  method?: string
  arguments?: string[]
}
```

### `stagehand_navigate`

Navigate à a URL.

```text
// Tool input
{
  "url": "https://example.com",
  "waitUntil": "domcontentloaded"
}
```

| Parameter | Type | Description |
| - | - | - |
| `url` | `string` | URL à open (required) |
| `waitUntil` | `"load" \| "domcontentloaded" \| "networkidle"` | When à consider navigation complete (optional) |

### `stagehand_tabs`

Gérer browser tabs.

```text
// List all tabs
{ "action": "list" }

// Open new tab
{ "action": "new", "url": "https://example.com" }

// Switch to tab by index
{ "action": "switch", "index": 0 }

// Close tab by index (or current if omitted)
{ "action": "close", "index": 1 }
```

### `stagehand_screenshot`

Capture a screenshot de the actuel page comme PNG (viewport par default. Définir `fullPage: true` pour full-page capture). Renvoie image content that vision-capable models peut interpret directly. Use `stagehand_observe` ou `stagehand_extract` when you only need text ou structured data.

```text
// Viewport only (default)
{}

// Full scrollable page
{ "fullPage": true }
```

| Parameter | Type | Description |
| - | - | - |
| `fullPage` | `boolean` | Capture the full scrollable page instead de only the viewport (optional, default: false) |

### `stagehand_close`

Close the browser et clean up resources.

```text
// Tool input (no parameters required)
{}
```

## Using Navigateurbase

Exécuter Stagehand dans the cloud using Navigateurbase:

```typescript
const browser = new StagehandBrowser({
  env: 'BROWSERBASE',
  apiKey: process.env.BROWSERBASE_API_KEY,
  projectId: process.env.BROWSERBASE_PROJECT_ID,
  model: '__GATEWAY_OPENAI_MODEL__',
})
```

## Modèle configuration

Configurer the AI modèle pour Stagehand operations:

```typescript
// String format: "provider/model"
const browser = new StagehandBrowser({
  model: '__GATEWAY_OPENAI_MODEL__',
})

// Object format for custom configuration
const browser = new StagehandBrowser({
  model: {
    modelName: 'gpt-5.4',
    apiKey: process.env.OPENAI_API_KEY,
    baseURL: 'https://api.openai.com/v1',
  },
})
```

## AgentNavigateur vs StagehandNavigateur

| Aspect | AgentNavigateur | StagehandNavigateur |
| - | - | - |
| **Approach** | Deterministic refs (`@e5`) | Natural language |
| **Precision** | Exact element targeting | AI interpretation |
| **Flexibility** | Requires a snapshot premier | Direct instructions |
| **Use case** | Reproducible automation | Adaptive automation |
| **Speed** | Faster (no AI inference) | Slower (AI inference) |

Choose `AgentBrowser` pour precise, reproducible automation. Choose `StagehandBrowser` pour flexible, natural language interactions.
