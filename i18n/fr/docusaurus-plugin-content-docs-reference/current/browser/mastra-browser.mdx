# MastraNavigateur class

The `MastraBrowser` class est the abstract base class pour browser automation providers. Its common interface covers browser launch et thread isolation, plus screencast streaming et input events.

You don't instantiate `MastraBrowser` directly. Instead, utilise a provider implementation:

- [AgentNavigateur](/reference/browser/agent-browser): Deterministic browser automation using refs
- [StagehandNavigateur](/reference/browser/stagehand-browser): AI-powered browser automation using natural language
- [`BrowserViewer`](/reference/browser/browser-viewer): CLI-based browser automation avec CDP URL injection

## Exemple d’utilisation

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { AgentBrowser } from '@mastra/agent-browser'

const browser = new AgentBrowser({
  headless: true,
  viewport: { width: 1280, height: 720 },
  scope: 'thread',
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: 'You can browse the web to find information.',
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## Méthodes

### Lifecycle

#### `ensureReady()`

Ensures the browser est launched et ready pour use. Automatically called avant Tool execution. Implemented dans the base class.

```typescript
await browser.ensureReady()
```

#### `close()`

Closes the browser et cleans up tous les resources. Implemented dans the base class avec race-condition-safe handling.

```typescript
await browser.close()
```

#### `isBrowserRunning()`

Vérifie if the browser est currently running.

```typescript
const isRunning = browser.isBrowserRunning()
```

**Renvoie:** `boolean`

### Thread management

#### `setCurrentThread(threadId)`

Définit the actuel thread ID pour browser operations. Used internally par the agent runtime.

```typescript
browser.setCurrentThread('thread-123')
```

#### `getCurrentThread()`

Obtient the actuel thread ID.

```typescript
const threadId = browser.getCurrentThread()
```

**Renvoie:** `string`

#### `hasThreadSession(threadId)`

Vérifie if a thread possède an active browser session.

```typescript
const hasSession = browser.hasThreadSession('thread-123')
```

**Renvoie:** `boolean`

#### `closeThreadSession(threadId)`

Closes a specific thread's browser session. With 'thread' scope, it closes that thread's browser instance. With 'shared' scope, it clears the thread state.

```typescript
await browser.closeThreadSession('thread-123')
```

### Tools

#### `getTools()`

Renvoie the browser tools pour utilise avec agents. Chaque provider returns different tools based sur its model.

```typescript
const tools = browser.getTools()
```

**Renvoie:** `Record<string, Tool>`

### Screencast

#### `startScreencast(options?, threadId?)`

Démarre streaming browser frames. Renvoie a `ScreencastStream` that emits frame events.

```typescript
const stream = await browser.startScreencast({ format: 'jpeg', quality: 80 }, 'thread-123')

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

**Renvoie:** `Promise<ScreencastStream>`

### Entrée injection

#### `injectMouseEvent(params, threadId?)`

Injects a mouse event dans the browser. Used par Studio pour live interaction.

```typescript
await browser.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)`

Injects a keyboard event dans the browser. Used par Studio pour live interaction.

```typescript
await browser.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

### État

#### `getState(threadId?)`

Obtient the actuel browser state including URL et tabs.

```typescript
const state = await browser.getState('thread-123')
console.log('Current URL:', state.currentUrl)
console.log('Tabs:', state.tabs)
```

**Renvoie:** `Promise<BrowserState>`

```typescript
interface BrowserState {
  currentUrl: string | null
  tabs: BrowserTabState[]
  activeTabIndex: number
}

interface BrowserTabState {
  id: string
  url: string
  title: string
}
```

#### `getCurrentUrl(threadId?)`

Obtient the actuel page URL.

```typescript
const url = await browser.getCurrentUrl()
```

**Renvoie:** `Promise<string | null>`

## Navigateur scope

The `scope` option controls how browser instances sont shared across conversation threads:

| Scope | Description | Use case |
| - | - | - |
| `'shared'` | Tous les threads share a unique browser instance | Cost-efficient pour non-conflicting tasks |
| `'thread'` | Chaque thread gets its own browser instance | Full isolation pour concurrent users |

```typescript
// Shared browser for all threads
const sharedBrowser = new AgentBrowser({
  scope: 'shared',
})

// Isolated browser per thread
const isolatedBrowser = new AgentBrowser({
  scope: 'thread',
})
```

Lorsque vous utilisez `cdpUrl` à connecte à an external browser, the scope automatically falls back à `'shared'` since you can't spawn nouveau browser instances.

## Cloud browser providers

Connect à cloud browser services using the `cdpUrl` option:

```typescript
// Static CDP URL
const browser = new AgentBrowser({
  cdpUrl: 'wss://browser.example.com/ws',
})

// Dynamic CDP URL (e.g., session-based)
const browser = new AgentBrowser({
  cdpUrl: async () => {
    const session = await createBrowserSession()
    return session.wsUrl
  },
})
```
