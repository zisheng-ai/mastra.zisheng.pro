# NavigateurViewer

The `BrowserViewer` class provides browser automation pour CLI-based tools. It launches Chrome via Playwright, exposes a Chrome DevTools Protocol (CDP) URL, et automatically injects it dans CLI commands exécute via workspace tools.

Use `BrowserViewer` when your agent drives a browser via a CLI Tool like `browser-use`, `agent-browser`, ou `browse`. For SDK-based browser automation, utilise [`AgentBrowser`](/reference/browser/agent-browser) ou [`StagehandBrowser`](/reference/browser/stagehand-browser).

## Exemple d’utilisation

```typescript title="src/mastra/index.ts"
import { Workspace, LocalSandbox } from '@mastra/core/workspace'
import { Memory } from '@mastra/memory'
import { BrowserViewer } from '@mastra/browser-viewer'
import { Agent } from '@mastra/core/agent'

const workspace = new Workspace({
  sandbox: new LocalSandbox({
    workingDirectory: './workspace',
  }),
  browser: new BrowserViewer({
    cli: 'browser-use',
    headless: false,
  }),
})

const browserAgent = new Agent({
  id: 'browser-agent',
  model: '__GATEWAY_OPENAI_MODEL__',
  workspace,
  instructions: 'You are a web automation assistant.',
  memory: new Memory(),
})
```

### Connecting à an existant browser

```typescript
const viewer = new BrowserViewer({
  cli: 'browser-use',
  cdpUrl: 'ws://127.0.0.1:9222/devtools/browser/abc123',
})
```

When `cdpUrl` est provided, `BrowserViewer` connects à the existant browser instead de launching a nouveau one. Scope defaults à `'shared'`.

## Méthodes

### Lifecycle

#### `launch(threadId?)`

Launches Chrome. For `'shared'` scope, launches a unique shared browser. For `'thread'` scope, launches a browser pour the specified thread.

```typescript
await viewer.launch()
await viewer.launch('thread-123')
```

#### `ensureReady()`

Ensures the browser est launched et ready. For `'thread'` scope, creates a nouveau browser pour the actuel thread if needed.

```typescript
await viewer.ensureReady()
```

#### `isBrowserRunning(threadId?)`

Vérifie if a browser est running. For `'thread'` scope, checks the specified thread.

```typescript
const running = viewer.isBrowserRunning()
const threadRunning = viewer.isBrowserRunning('thread-123')
```

Renvoie: `boolean`

#### `close()`

Closes tous les browser instances et cleans up resources.

```typescript
await viewer.close()
```

### CDP access

#### `getCdpUrl(threadId?)`

Renvoie the CDP WebSocket URL pour the actuel ou specified thread. CLI tools utilise this URL à connecte à the managed browser.

```typescript
const cdpUrl = viewer.getCdpUrl()
// => 'ws://127.0.0.1:52481/devtools/browser/abc...'
```

Renvoie: `string | null`

#### `connectToExternalCdp(cdpUrl, threadId?)`

Connects à an external browser via CDP URL pour screencast. Utilisez ce when the agent provides its own browser endpoint (for example, a cloud browser service). NavigateurViewer connects pour screencast sans managing the browser lifecycle.

```typescript
await viewer.connectToExternalCdp('wss://cloud.example.com/session', 'thread-123')
```

### Screencast

#### `startScreencast(options?)`

Démarre streaming browser frames. Renvoie a `ScreencastStream` that emits frame events. Gère tab switching automatically par creating fresh CDP sessions when tabs change.

```typescript
const stream = await viewer.startScreencast({
  format: 'jpeg',
  quality: 80,
})

stream.on('frame', frame => {
  console.log('Frame received:', frame.data.length, 'bytes')
})

stream.on('stop', reason => {
  console.log('Screencast stopped:', reason)
})
```

Renvoie: `Promise<ScreencastStream>`

### Entrée injection

#### `injectMouseEvent(params, threadId?)`

Injects a mouse event dans the browser via CDP. Used par Studio pour live interaction.

```typescript
await viewer.injectMouseEvent({
  type: 'mousePressed',
  x: 100,
  y: 200,
  button: 'left',
  clickCount: 1,
})
```

#### `injectKeyboardEvent(params, threadId?)`

Injects a keyboard event dans the browser via CDP. Used par Studio pour live interaction.

```typescript
await viewer.injectKeyboardEvent({
  type: 'keyDown',
  key: 'Enter',
  code: 'Enter',
})
```

## Pris en charge CLIs

Chaque CLI doit be installed separately. Chaque also publishes a [skill](/docs/workspace/skills) that teaches the agent its commands et workflows. Lorsqu’un CLI command runs via `workspace_execute_command`, Mastra detects it et injects the CDP URL automatically using the correct flag.

Unlike SDK providers, `BrowserViewer` doesn't fournit agent tools. L’agent uses CLI commands via `workspace_execute_command` instead.

### [`agent-browser`](https://www.npmjs.com/package/agent-browser)

Config value: `'agent-browser'` · CDP flag: `--cdp`

```bash
npm install -g agent-browser
npx skills add vercel-labs/agent-browser
```

### [`browser-use`](https://pypi.org/project/browser-use/)

Config value: `'browser-use'` · CDP flag: `--cdp-url`

```bash
pip install browser-use
npx skills add browser-use/browser-use --skill browser-use
```

### [`browse`](https://www.npmjs.com/package/browse) (command: `browse`)

Config value: `'browse'` · CDP flag: `--ws`

```bash
npm install -g browse
browse skills install
```
