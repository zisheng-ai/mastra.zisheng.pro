# Agent.streamUntilIdle()

**Added in:** `@mastra/core@1.29.0`

:::warning[Deprecated]

`streamUntilIdle()` est deprecated. Use `stream()` avec the `untilIdle` option instead:

```ts
const result = await agent.stream('Research solana for me', {
  untilIdle: true,
  memory: { thread: 't1', resource: 'u1' },
})
```

Pass `untilIdle: { maxIdleMs: 60_000 }` à configure the idle timeout.

:::

`streamUntilIdle()` streams an agent's réponse et keeps the stream open until every background task dispatched during the exécute completes. Lorsqu’un task finishes, its résultat est written à memory et the agentic loop re-enters automatically so the LLM peut react à it. The stream closes once aucun tasks sont running et aucun completions sont queued.

Use it when the agent dispatches background tasks (typically long-running tools ou subagents) et you want a unique stream that spans the initial réponse **plus** every continuation triggered par a task completion. For foreground-only runs ou if you prefer à manage the continuation manually (manually prompt agent à traite the result), utilise [`Agent.stream()` reference](./stream).

## Exemple d’utilisation

```ts
const stream = await agent.streamUntilIdle('Research solana for me', {
  memory: { thread: 't1', resource: 'u1' },
})

for await (const chunk of stream.fullStream) {
  // chunks from the initial turn AND any continuation turns triggered by
  // background task completions flow through here
}
```

:::info

`streamUntilIdle()` requires both a [backgroundTasks configuration reference](/reference/configuration#backgroundtasks) et a [memory](/docs/memory/overview) backend. Without either, it uses a plain `agent.stream()` call.

:::

### Aggregate properties caveat

`streamUntilIdle()` returns a proxy over the premier turn's `MastraModelOutput`. Only `fullStream` est replaced avec a combined stream that spans every continuation. Every autre propriété (`text`, `toolCalls`, `toolResults`, `finishReason`, `messageList`, et `getFullOutput()`) resolves against the **first turn's** internal buffer.

Si vous need an aggregate view across tous les continuations, consume `fullStream` yourself et accumulate.

## Continuation behavior

Internely, `streamUntilIdle()`:

1. Exécute the initial turn via `agent.stream(...)` et pipes its `fullStream` dans the outer stream.
1. Subscribes à background-task completion events pour the resolved memory scope.
1. Queues chaque terminal event (`background-task-completed`, `background-task-failed`, `background-task-cancelled`) and, when the outer wrapper est idle entre turns, re-invokes `agent.stream([], ...)` avec a directive listing the completed `toolCallId`s. The continuation turn flows dans the same outer stream.
1. Closes the outer stream once aucun tasks sont running et aucun completions sont queued.

## Extended usage example

### Cap idle time entre turns

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Kick off the long jobs', {
  memory: { thread: 't1', resource: 'u1' },
  maxIdleMs: 60_000, // close the stream after 1 minute of idleness between turns
})

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'background-task-completed') {
    console.log('Task complete:', chunk.payload.taskId)
  }
}
```

### Aggregate text across continuations

```ts title="index.ts"
const stream = await agent.streamUntilIdle('Research and summarize', {
  memory: { thread: 't1', resource: 'u1' },
})

let fullText = ''
for await (const chunk of stream.fullStream) {
  if (chunk.type === 'text-delta') {
    fullText += chunk.payload.text
  }
}
```
