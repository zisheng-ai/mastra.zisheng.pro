# Agent.streamLegacy() (Legacy)

:::warning

**Deprecated**: Ce method est deprecated et only works avec V1 models. For V2 models, utilise the nouveau [New .stream() method](./stream) method instead. Consultez the [migration guide](/guides/migrations/vnext-to-standard-apis) pour details sur upgrading.

:::

The `.streamLegacy()` method est the legacy version de the agent streaming API, used pour real-time streaming de responses depuis V1 modèle agents. Ce method accepts messages et facultatif streaming options.

## Exemple d’utilisation

```typescript
await agent.streamLegacy('message for agent')
```

## Migration à nouveau API

:::info

Le nouveau `.stream()` method offers enhanced capabilities including AI SDK v5+ compatibility, better structured output handling, et improved rappel system. Consultez the [migration guide](/guides/migrations/vnext-to-standard-apis) pour detailed migration instructions.

:::

### Quick Migration Exemple

#### Before (Legacy)

```typescript
const result = await agent.streamLegacy('message', {
  temperature: 0.7,
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```

#### After (New API)

```typescript
const result = await agent.stream('message', {
  modelSettings: {
    temperature: 0.7,
  },
  maxSteps: 3,
  onFinish: result => console.log(result),
})
```
