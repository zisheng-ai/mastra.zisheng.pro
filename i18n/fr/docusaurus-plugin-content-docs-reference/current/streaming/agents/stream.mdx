# Agent.stream()

The `.stream()` method enables real-time streaming de responses depuis an agent avec enhanced capabilities et format flexibility. Ce method accepts messages et facultatif streaming options, providing a actuel streaming experience avec support pour both Mastra's native format et AI SDK v5+ compatibility.

## Exemple d’utilisation

```ts
const stream = await agent.stream('message for agent')
```

:::info

**Modèle Compatibility**: Ce method est designed pour V2 models. V1 models doit utilise the [`.streamLegacy()`](./streamLegacy) method. The framework automatically detects your modèle version et va throw an error if there's a mismatch.

:::

## Extended usage example

### Mastra Format (Par défaut)

```ts title="index.ts"
import { stepCountIs } from 'ai-v5'

const stream = await agent.stream('Tell me a story', {
  stopWhen: stepCountIs(3), // Stop after 3 steps
  modelSettings: {
    temperature: 0.7,
  },
})

// Access text stream
for await (const chunk of stream.textStream) {
  console.log(chunk)
}

// or access full stream
for await (const chunk of stream.fullStream) {
  console.log(chunk)
}

// Get full text after streaming
const fullText = await stream.text
```

### AI SDK v5+ Format

Pour utiliser the stream avec AI SDK v5 (and later), you peut convert it using our utility fonction `toAISdkStream`.

```ts title="index.ts"
import { stepCountIs, createUIMessageStreamResponse } from 'ai'
import { toAISdkStream } from '@mastra/ai-sdk'

const stream = await agent.stream('Tell me a story', {
  stopWhen: stepCountIs(3), // Stop after 3 steps
  modelSettings: {
    temperature: 0.7,
  },
})

// In an API route for frontend integration
return createUIMessageStreamResponse({
  stream: toAISdkStream(stream, { from: 'agent' }),
})
```

### Using Callbacks

Tous les rappel functions sont now disponible comme top-level properties pour a cleaner API experience.

```ts title="index.ts"
const stream = await agent.stream('Tell me a story', {
  onFinish: result => {
    console.log('Streaming finished:', result)
  },
  onStepFinish: step => {
    console.log('Step completed:', step)
  },
  onChunk: chunk => {
    console.log('Received chunk:', chunk)
  },
  onError: ({ error }) => {
    console.error('Streaming error:', error)
  },
  onAbort: event => {
    console.log('Stream aborted:', event)
  },
})

// Process the stream
for await (const chunk of stream.textStream) {
  console.log(chunk)
}
```

## Réponses WebSocket transport

Opt dans Réponses WebSocket streaming avec provider options. Ce only applies à streaming calls et est pris en charge pour direct OpenAI models et Azure OpenAI Réponses deployments. If WebSocket streaming est unavailable, Mastra falls back à HTTP streaming. Par défaut, Mastra closes the WebSocket when the stream finishes.

```ts title="index.ts"
const stream = await agent.stream('Hello', {
  providerOptions: {
    openai: {
      transport: 'websocket', // 'websocket' | 'fetch' | 'auto'
      websocket: {
        url: 'wss://api.openai.com/v1/responses',
        closeOnFinish: true, // default
      },
    },
  },
})
```

For Azure OpenAI, configure the gateway avec `useResponsesAPI: true`, then utilise `providerOptions.azure.transport`.

```ts title="index.ts"
const stream = await agent.stream('Hello', {
  providerOptions: {
    azure: {
      transport: 'websocket',
      store: false,
      websocket: { closeOnFinish: true },
    },
  },
})
```

To keep the connection open après the stream finishes, définit `closeOnFinish: false` et close it manually.

```ts title="index.ts"
const stream = await agent.stream('Hello', {
  providerOptions: {
    openai: {
      transport: 'websocket',
      websocket: { closeOnFinish: false },
    },
  },
})

// Later, when you're done with the connection:
stream.transport?.close()
```

Réponses WebSocket connections exécute un réponse à a time. Mastra rejects overlapping continuation requests that inclut `previous_response_id` sur the same WebSocket transport. Wait pour the active stream à finish avant sending the next turn dans the réponse chain.
