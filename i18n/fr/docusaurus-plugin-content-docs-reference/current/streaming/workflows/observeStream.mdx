# Run.observeStream()

La méthode `.observeStream()` ouvre un nouveau `ReadableStream` pour une exécution de Workflow en cours, ce qui permet d’observer le flux d’événements si le flux initial n’est plus accessible.

## Exemple d’utilisation

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## Valeur renvoyée

`ReadableStream<ChunkType>`

## Événements du flux

Le flux émet des types d’événements pendant l’exécution du Workflow. Chaque événement possède un champ `type` et un `payload` contenant les données pertinentes :

- **`workflow-start`**: l’exécution du Workflow commence
- **`workflow-step-start`**: une étape commence à s’exécuter
- **`workflow-step-output`**: sortie personnalisée d’une étape
- **`workflow-step-result`**: une étape se termine avec des résultats
- **`workflow-finish`**: l’exécution du Workflow se termine avec des statistiques d’utilisation. Pour les exécutions réussies, `payload.finalWorkflowResult` contient le résultat final du Workflow
