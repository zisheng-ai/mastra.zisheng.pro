# Run.resumeStream()

La méthode `.resumeStream()` reprend l'exécution suspendue d'un Workflow avec de nouvelles données. Vous pouvez ainsi poursuivre l'exécution à partir d'une étape précise et observer le flux d'événements.

## Exemple d'utilisation {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

const result = await stream.result

if (result!.status === 'suspended') {
  const resumedStream = await run.resumeStream({
    resumeData: {
      value: 'resume data',
    },
  })
}
```

## Événements du flux {/* #stream-events */}

Le flux émet différents types d'événements pendant l'exécution du Workflow. Chaque événement possède un champ `type` et un `payload` contenant les données pertinentes :

- **`workflow-start`** : l'exécution du Workflow commence
- **`workflow-step-start`** : l'exécution d'une étape commence
- **`workflow-step-output`** : sortie personnalisée d'une étape
- **`workflow-step-result`** : une étape se termine avec des résultats
- **`workflow-finish`** : l'exécution du Workflow se termine avec les statistiques d'utilisation. Pour les exécutions réussies, `payload.finalWorkflowResult` contient le résultat final du Workflow
