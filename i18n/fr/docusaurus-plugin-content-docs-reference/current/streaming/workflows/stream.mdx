# Run.stream()

La méthode `.stream()` permet de diffuser en temps réel les réponses d’un Workflow. Elle renvoie directement un `ReadableStream` d’événements.

## Exemple d’utilisation {/* #usage-example */}

```typescript
const run = await workflow.createRun()

const stream = await run.stream({
  inputData: {
    value: 'initial data',
  },
})

for await (const chunk of stream) {
  console.log(chunk)
}
```

## Exemple d’utilisation avancée {/* #extended-usage-example */}

```typescript
const run = await workflow.createRun()

const stream = run.stream({
  inputData: {
    value: 'initial data',
  },
})

// Iterate over stream events (you can iterate over stream directly or use stream.fullStream)
for await (const chunk of stream) {
  console.log(chunk)
}

// Access the final result
const result = await stream.result
console.log('Final result:', result)

// Access token usage
const usage = await stream.usage
console.log('Token usage:', usage)

// Check current status
console.log('Status:', stream.status)
```

## Événements du flux {/* #stream-events */}

Le flux émet différents types d’événements pendant l’exécution du Workflow. Chaque événement possède un champ `type` et un `payload` contenant les données pertinentes :

- **`workflow-start`** : l’exécution du Workflow commence
- **`workflow-step-start`** : une étape commence son exécution
- **`workflow-step-output`** : sortie personnalisée d’une étape
- **`workflow-step-progress`** : une étape foreach signale la progression de chaque itération (comprend `completedCount`, `totalCount`, `currentIndex`, `iterationStatus` et, éventuellement, `iterationOutput`)
- **`workflow-step-result`** : une étape se termine avec des résultats
- **`workflow-finish`** : l’exécution du Workflow se termine avec des statistiques d’utilisation. Pour les exécutions réussies, `payload.finalWorkflowResult` contient le résultat final du Workflow, ce qui évite aux consommateurs du flux d’effectuer une récupération supplémentaire
