# rerankWithScorer()

La fonction `rerankWithScorer()` fournit des fonctionnalités avancées de reclassement des résultats de recherche vectorielle en combinant la pertinence sémantique, la similarité vectorielle et une notation fondée sur la position.

```typescript prettier:false
function rerankWithScorer({
  results: QueryResult[],
  query: string,
  scorer: RelevanceScoreProvider,
  options?: RerankerFunctionOptions,
}): Promise<RerankResult[]>;
```

## Exemple d’utilisation {/* #usage-example */}

```typescript
import { rerankWithScorer as rerank, CohereRelevanceScorer } from '@mastra/rag'

const scorer = new CohereRelevanceScorer('rerank-v3.5')

const rerankedResults = await rerank({
  results: vectorSearchResults,
  query: 'How do I deploy to production?',
  scorer,
  options: {
    weights: {
      semantic: 0.5,
      vector: 0.3,
      position: 0.2,
    },
    topK: 3,
  },
})
```

La fonction `rerankWithScorer` accepte tout `RelevanceScoreProvider` provenant de @mastra/rag.

:::note

Pour que la notation sémantique fonctionne correctement pendant le reclassement, chaque résultat doit inclure le contenu textuel dans son champ `metadata.text`.

:::
