# AgentController

:::experimental

The `AgentController` feature est dans beta stage et subject à breaking changes dans minor versions until it graduates depuis its beta status.

:::

The `AgentController` class est a shared host pour un ou more [Session reference](/reference/agent-controller/session) instances. Initialize the controller, crée a session, then utilise `session.*` APIs pour conversation state et exécute control.

For a guided introduction, see the [AgentController overview](/docs/harness/agent-controller).

## Exemple d’utilisation

Les éléments suivants example initializes a controller et creates a session. It subscribes à session events avant sending a message.

```typescript title="src/mastra/agent-controller.ts"
import { Agent } from '@mastra/core/agent'
import { AgentController } from '@mastra/core/agent-controller'
import { Workspace } from '@mastra/core/workspace'

const agent = new Agent({
  id: 'coding-agent',
  name: 'Coding agent',
  instructions: 'Help with software engineering tasks.',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
})

const controller = new AgentController({
  id: 'coding-controller',
  agent,
  workspace: new Workspace({ id: 'coding-workspace' }),
  modes: [{ id: 'build', name: 'Build', metadata: { default: true } }],
})

await controller.init()

const session = await controller.createSession({ resourceId: 'project-42' })
const unsubscribe = session.subscribe(event => {
  if (event.type === 'message_update') {
    console.log(event.message)
  }
})

await session.sendMessage({ content: 'Review the project structure.' })
unsubscribe()
```

## Méthodes

### Sessions

#### `createSession(options)`

Obtenir ou crée the live session registered pour the `(resourceId, scope)` pair. Call `init()` avant this method.

```typescript
const session = await controller.createSession({
  resourceId: 'project-42',
  scope: 'editor-window-1',
  threadId: 'thread-7',
})
```

Le même `resourceId` et `scope` renvoie the same `Session` instance. Un different scope creates an isolated session pour the same resource. When `threadId` est supplied, the method switches a cached session à that thread ou creates the thread when it doesn't exist.

Renvoie: `Promise<Session<TState>>`

#### `getSessionByResource(resourceId, scope?)`

Renvoyer the live session registered pour a resource et facultatif scope.

```typescript
const session = await controller.getSessionByResource('project-42', 'editor-window-1')
```

Renvoie: `Promise<Session<TState> | undefined>`

#### `setResourceId(session, { resourceId })`

Move a live session à un autre resource et clear its active thread binding.

```typescript
await controller.setResourceId(session, { resourceId: 'project-43' })
```

#### `getKnownResourceIds(session)`

Lister resource identifiers present dans stored threads.

```typescript
const resourceIds = await controller.getKnownResourceIds(session)
```

Renvoie: `Promise<string[]>`

### Lifecycle

#### `init()`

Initialize shared storage, workspace services, et configuré interval handlers. Repeated calls reuse the same initialization promise.

```typescript
await controller.init()
```

#### `destroy()`

Arrêter controller-owned interval handlers. Ce doesn't destroy Sessions created par the controller.

```typescript
await controller.destroy()
```

### Modes et agents

#### `listModes()`

Renvoyer the configuré mode definitions.

```typescript
const modes = controller.listModes()
```

Renvoie: `AgentControllerMode[]`

#### `getCurrentAgent(session)`

Renvoyer the backing agent pour the session's active mode.

```typescript
const agent = controller.getCurrentAgent(session)
```

Renvoie: `Agent`

### Workspace et browser

#### `hasWorkspace()`

Report whether the controller possède a static, dynamic, ou object-based workspace configuration.

```typescript
if (controller.hasWorkspace()) {
  console.log('Workspace configured')
}
```

Renvoie: `boolean`

#### `isWorkspaceReady()`

Report whether the controller-level workspace est ready.

```typescript
const ready = controller.isWorkspaceReady()
```

Renvoie: `boolean`

#### `getWorkspace()`

Renvoyer a static controller workspace. Dynamique workspace factories renvoie `undefined` until resolved.

```typescript
const workspace = controller.getWorkspace()
```

Renvoie: `Workspace | undefined`

#### `resolveWorkspace({ session, requestContext? })`

Resolve a dynamic workspace pour a session et cache the résultat sur the controller.

```typescript
const workspace = await controller.resolveWorkspace({ session, requestContext })
```

Renvoie: `Promise<Workspace | undefined>`

#### `setBrowser(browser)`

Replace the controller browser et propagate it à the backing agents.

```typescript
controller.setBrowser(browser)
```

### Mastra et channels

#### `getMastra()`

Renvoyer the parent Instance Mastra ou the internal instance created par `init()`.

```typescript
const mastra = controller.getMastra()
```

Renvoie: `Mastra | undefined`

#### `getChannels()`

Renvoyer the configuré chat channel integration.

```typescript
const channels = controller.getChannels()
```

Renvoie: `AgentControllerChannels | null`

### Modèles

#### `getCurrentModelAuthStatus(session)`

Renvoyer authentication status pour the session's sélectionné model.

```typescript
const status = await controller.getCurrentModelAuthStatus(session)
```

Renvoie: `Promise<ModelAuthStatus>`

#### `listAvailableModels()`

Lister models depuis the configuré et built-in gateways. Résultats sont cached briefly et sorted avec usage données when `modelUseCountProvider` est configured.

```typescript
const models = await controller.listAvailableModels()
```

Renvoie: `Promise<AvailableModel[]>`

#### `invalidateAvailableModelsCache()`

Clear the available-model cache.

```typescript
controller.invalidateAvailableModelsCache()
```

### Observational memory et permissions

#### `loadOMProgress(session)`

Charger stored observational memory progress pour the active thread et emit an `om_status` event.

```typescript
await controller.loadOMProgress(session)
```

#### `getObservationalMemoryRecord(session)`

Renvoyer the observational memory record pour the active thread.

```typescript
const record = await controller.getObservationalMemoryRecord(session)
```

Renvoie: `Promise<ObservationalMemoryRecord | null>`

#### `getToolCategory({ toolName })`

Resolve the permission category pour a tool.

```typescript
const category = controller.getToolCategory({ toolName: 'execute_command' })
```

Renvoie: `ToolCategory | null`

### Intervals

#### `registerInterval(handler)`

Démarrer ou replace a periodic handler.

```typescript
controller.registerInterval({
  id: 'refresh',
  intervalMs: 60_000,
  handler: async () => refreshData(),
})
```

#### `removeInterval({ id })`

Arrêter un interval et exécute its facultatif shutdown callback.

```typescript
await controller.removeInterval({ id: 'refresh' })
```

#### `stopIntervals()`

Arrêter tous les intervals et exécute their facultatif shutdown callbacks.

```typescript
await controller.stopIntervals()
```
