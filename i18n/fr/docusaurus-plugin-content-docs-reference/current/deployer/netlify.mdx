# NetlifyDeployer

La classe `NetlifyDeployer` gère le packaging, la configuration et le déploiement en adaptant la sortie de Mastra pour créer une version optimisée de votre serveur. Elle étend la classe [`Deployer`](/reference/deployer/) de base avec des fonctionnalités propres à Netlify. Elle permet d’exécuter Mastra dans des fonctions serverless ou des fonctions edge de Netlify.

## Installation {/* #installation */}

Pour utiliser `NetlifyDeployer`, vous devez installer le package `@mastra/deployer-netlify` :

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## Exemple d’utilisation {/* #usage-example */}

Importez `NetlifyDeployer` et définissez-le comme Deployer dans votre configuration Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## Options du constructeur {/* #constructor-options */}

- `target?: 'serverless' | 'edge'` : cible de déploiement pour Netlify. La valeur par défaut est `'serverless'`.
  - `'serverless'` : [Netlify Functions](https://docs.netlify.com/functions/overview/) standard (environnement d’exécution Node.js, délai d’expiration de 60 s par défaut).
  - `'edge'` : [Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) (environnement d’exécution fondé sur Deno, exécuté au point edge le plus proche des utilisateurs, sans délai d’expiration fixe).

### Exemple avec les fonctions edge {/* #edge-functions-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## Sortie {/* #output */}

Après l’exécution de `mastra build`, le Deployer génère un dossier `.netlify`. La sortie de compilation comprend tous les Agents, Tools et Workflows de votre projet, ainsi qu’un fichier `config.json` qui configure la [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/).

### Sortie serverless (par défaut) {/* #serverless-output-default */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

Le fichier `config.json` contient :

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### Sortie edge {/* #edge-output */}

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

Le fichier `config.json` contient :

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
