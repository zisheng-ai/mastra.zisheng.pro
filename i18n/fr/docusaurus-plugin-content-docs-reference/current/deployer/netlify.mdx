# NetlifyDéployeur

The `NetlifyDeployer` class handles packaging, configuration, et deployment par adapting Mastra's output à crée an optimized version de your server. It extends the base [`Deployer`](/reference/deployer/) class avec Netlify-specific functionality. It enables you à exécute Mastra within Netlify serverless functions ou edge functions.

## Installation

Pour utiliser `NetlifyDeployer`, you need à install the `@mastra/deployer-netlify` package:

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

## Exemple d’utilisation

Import `NetlifyDeployer` et définit it comme the deployer dans your Mastra configuration:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

## Options du constructeur

- `target?: 'serverless' | 'edge'`: Deploy target pour Netlify. Par défauts à `'serverless'`.
  - `'serverless'`: Standard [Netlify Functions](https://docs.netlify.com/functions/overview/) (Node.js runtime, 60s par défaut timeout).
  - `'edge'`: [Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) (Deno-based runtime, runs à the edge closest à users, sans a fixed timeout).

### Edge functions example

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

## Sortie

After running `mastra build`, the deployer generates a `.netlify` folder. The génère output includes tous les agents, tools, et workflows de your project, alongside a `config.json` file that configures the [Netlify Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/).

### Serveurless output (default)

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── functions/
            └── api/
                ├── index.mjs
                ├── package.json
                └── node_modules/
```

The `config.json` file contains:

```json
{
  "functions": {
    "directory": ".netlify/v1/functions",
    "node_bundler": "none",
    "included_files": [".netlify/v1/functions/**"]
  },
  "redirects": [
    {
      "force": true,
      "from": "/*",
      "to": "/.netlify/functions/api/:splat",
      "status": 200
    }
  ]
}
```

### Edge output

```bash
your-project/
└── .netlify/
    └── v1/
        ├── config.json
        └── edge-functions/
            ├── index.mjs
            ├── package.json
            └── node_modules/
```

The `config.json` file contains:

```json
{
  "edge_functions": [
    {
      "function": "index",
      "path": "/*"
    }
  ]
}
```
