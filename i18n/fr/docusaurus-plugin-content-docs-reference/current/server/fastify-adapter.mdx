# Adaptateur Fastify

Le package `@mastra/fastify` fournit un adaptateur de serveur permettant d’exécuter Mastra avec [Fastify](https://fastify.dev). Pour en savoir plus sur les concepts généraux des adaptateurs, tels que les options du constructeur ou le processus d’initialisation, consultez la page [Adaptateurs de serveur](/docs/server/server-adapters).

## Installation {/* #installation */}

Installez l’adaptateur Fastify et le framework Fastify :

```bash npm2yarn
npm install @mastra/fastify@latest fastify
```

## Exemple d’utilisation {/* #usage-example */}

```typescript title="server.ts"
import Fastify from 'fastify'
import { MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify({ logger: true })
const server = new MastraServer({ app, mastra })

await server.init()

app.listen({ port: 3000 }, (err, address) => {
  if (err) {
    console.error(err)
    process.exit(1)
  }
  console.log(`Server running on ${address}`)
})
```

## Protection des routes brutes {/* #protecting-raw-routes */}

Lorsque vous souhaitez bénéficier de l’authentification gérée par Mastra et de métadonnées de route telles que `requiresAuth`, privilégiez [`registerApiRoute()`](/reference/server/register-api-route). Pour les routes Fastify brutes montées directement sur l’application, utilisez `createAuthMiddleware()` :

```typescript title="server.ts"
import Fastify from 'fastify'
import { createAuthMiddleware, MastraServer } from '@mastra/fastify'
import { mastra } from './mastra'

const app = Fastify()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', { preHandler: createAuthMiddleware({ mastra }) }, async request => {
  const user = request.requestContext.get('user')
  return { user }
})

app.get(
  '/custom/public',
  { preHandler: createAuthMiddleware({ mastra, requiresAuth: false }) },
  async () => {
    return { ok: true }
  },
)
```
