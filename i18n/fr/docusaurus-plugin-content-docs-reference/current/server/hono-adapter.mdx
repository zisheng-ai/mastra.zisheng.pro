# Adaptateur Hono

Le package `@mastra/hono` fournit un adaptateur de serveur permettant d'exécuter Mastra avec [Hono](https://hono.dev). Pour en savoir plus sur les concepts généraux des adaptateurs (options du constructeur, déroulement de l'initialisation, etc.), consultez les [adaptateurs de serveur](/docs/server/server-adapters).

## Installation {/* #installation */}

Installez l'adaptateur Hono et le framework Hono :

```bash npm2yarn
npm install @mastra/hono@latest hono
```

## Exemple d'utilisation {/* #usage-example */}

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

## Ajout de routes personnalisées {/* #adding-custom-routes */}

Ajoutez des routes directement à l'application Hono :

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', c => c.json({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', c => {
  const mastraInstance = c.get('mastra')
  return c.json({ agents: Object.keys(mastraInstance.listAgents()) })
})
```

:::tip

Les routes ajoutées avant `init()` s'exécutent sans contexte Mastra. Ajoutez les routes après `init()` pour accéder à l'instance Mastra et au contexte de requête.

:::

Lorsque vous souhaitez utiliser l'authentification gérée par Mastra et des métadonnées de route telles que `requiresAuth`, privilégiez [`registerApiRoute()`](/reference/server/register-api-route). Pour les routes Hono brutes montées directement sur `app`, utilisez `createAuthMiddleware()` :

```typescript title="server.ts"
import { Hono } from 'hono'
import { createAuthMiddleware, HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', createAuthMiddleware({ mastra }), c => {
  const user = c.get('requestContext').get('user')
  return c.json({ user })
})

app.get('/custom/public', createAuthMiddleware({ mastra, requiresAuth: false }), c => {
  return c.json({ ok: true })
})
```

## Accès au contexte {/* #accessing-context */}

Dans les middlewares Hono et les gestionnaires de routes, accédez au contexte Mastra au moyen de `c.get()` :

```typescript
app.get('/custom', async c => {
  const mastra = c.get('mastra')
  const requestContext = c.get('requestContext')
  const abortSignal = c.get('abortSignal')

  const agent = mastra.getAgent('myAgent')
  return c.json({ agent: agent.name })
})
```

Clés de contexte disponibles :

| Clé | Description |
| - | - |
| `mastra` | Instance Mastra |
| `requestContext` | Map du contexte de requête |
| `abortSignal` | Signal d'annulation de la requête |
| `tools` | Tools disponibles |
| `taskStore` | Stockage des tâches pour les opérations A2A |
| `customRouteAuthConfig` | Remplacements de l'authentification propres à chaque route |
| `user` | Utilisateur authentifié (si l'authentification est configurée) |

## Ajout de middlewares {/* #adding-middleware */}

Ajoutez les middlewares Hono avant ou après `init()` :

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()

// Middleware before init
app.use('*', async (c, next) => {
  console.log(`${c.req.method} ${c.req.url}`)
  await next()
})

const server = new MastraServer({ app, mastra })
await server.init()

// Middleware after init has access to Mastra context
app.use('*', async (c, next) => {
  const mastra = c.get('mastra')
  await next()
})
```
