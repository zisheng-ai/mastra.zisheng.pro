# MastraServer

La classe abstraite `MastraServer` est la base de tous les adaptateurs de serveur. Étendez cette classe pour créer des adaptateurs pour des frameworks autres que Hono ou Express.

## Importation {/* #import */}

```typescript
import { MastraServer } from '@mastra/server/server-adapter'
```

## Paramètres de type {/* #type-parameters */}

```typescript
MastraServer<TApp, TRequest, TResponse>
```

| Paramètre | Description |
| - | - |
| `TApp` | Type d'application du framework (par exemple, `Hono`, `Application`) |
| `TRequest` | Type de requête du framework |
| `TResponse` | Type de réponse/contexte du framework |

## Constructeur {/* #constructor */}

```typescript prettier:false
constructor(options: MastraServerOptions<TApp>)
```

## Méthodes abstraites {/* #abstract-methods */}

Ces méthodes doivent être implémentées par les adaptateurs :

### `registerContextMiddleware()` {/* #registercontextmiddleware */}

Attache le contexte Mastra à chaque requête.

```typescript prettier:false
abstract registerContextMiddleware(): void
```

**Contexte à attacher :**

- `mastra` - instance Mastra
- `requestContext` - contexte limité à la requête
- `tools` - outils disponibles
- `abortSignal` - signal d'annulation de la requête

### `registerAuthMiddleware()` {/* #registerauthmiddleware */}

Exécute le hook d'authentification de l'adaptateur pendant l'initialisation. Les adaptateurs officiels peuvent l'implémenter comme une opération vide lorsque l'authentification est appliquée par route.

```typescript prettier:false
abstract registerAuthMiddleware(): void
```

### `registerRoute()` {/* #registerroute */}

Enregistre une seule route auprès du framework.

```typescript prettier:false
abstract registerRoute(
  app: TApp,
  route: ServerRoute,
  options: { prefix?: string }
): Promise<void>
```

### `getParams()` {/* #getparams */}

Extrait les paramètres de la requête.

```typescript prettier:false
abstract getParams(
  route: ServerRoute,
  request: TRequest
): Promise<{
  urlParams: Record<string, string>;
  queryParams: Record<string, string>;
  body: unknown;
}>
```

### `sendResponse()` {/* #sendresponse */}

Envoie une réponse en fonction du type de route.

```typescript prettier:false
abstract sendResponse(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

### `stream()` {/* #stream */}

Gère les réponses en flux continu.

```typescript prettier:false
abstract stream(
  route: ServerRoute,
  response: TResponse,
  result: unknown
): Promise<unknown>
```

## Méthodes d'instance {/* #instance-methods */}

### `init()` {/* #init */}

Initialise le serveur en enregistrant tous les middlewares et toutes les routes.

```typescript prettier:false
async init(): Promise<void>
```

Appelle, dans l'ordre :

1. `registerContextMiddleware()`
1. `registerAuthMiddleware()`
1. `registerRoutes()`

### `registerRoutes()` {/* #registerroutes */}

Enregistre toutes les routes Mastra.

```typescript prettier:false
async registerRoutes(): Promise<void>
```

### `getApp()` {/* #getapp */}

```typescript prettier:false
getApp<T = TApp>(): T
```

### MCPOptions {/* #mcpoptions */}

```typescript
interface MCPOptions {
  serverless?: boolean
  sessionIdGenerator?: () => string
}
```

| Propriété | Description |
| - | - |
| `serverless` | Lorsque la valeur est `true`, exécute MCP en mode sans état, sans gestion des sessions. À utiliser pour des environnements serverless tels que Cloudflare Workers ou Vercel Edge. |
| `sessionIdGenerator` | Fonction personnalisée qui génère des ID de session. |

```typescript
  registerContextMiddleware(): void {
    this.app.use('*', (req, res, next) => {
      res.locals.mastra = this.mastra
      next()
    })
  }

  registerAuthMiddleware(): void {
    const auth = this.mastra.getServer()?.auth
    if (!auth) return
    // Register global auth middleware, or leave this empty and

    }
  }

    return response.json(result)
  }

}
```
