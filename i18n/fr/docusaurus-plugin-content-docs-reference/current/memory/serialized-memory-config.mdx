# SerializedMemoryConfig

`SerializedMemoryConfig` est le sous-ensemble sérialisable en JSON de la configuration de [`Memory`](/reference/memory/memory-class) qui se trouve dans l’enregistrement d’un Agent stocké. Au moment de l’exécution, Mastra le réhydrate en instance de `Memory` en résolvant les ID du stockage vectoriel et de l’embedder à partir de l’instance `Mastra` configurée.

Il s’agit du type utilisé par [`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) et par `EditorAgentNamespace.create({ memory })`.

## Exemple d’utilisation {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
