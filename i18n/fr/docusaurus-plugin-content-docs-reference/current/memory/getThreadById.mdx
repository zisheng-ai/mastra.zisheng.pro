# Memory.getThreadById()

La méthode `.getThreadById()` récupère un fil de discussion spécifique à partir de son ID.

## Exemple d’utilisation

```typescript
await memory?.getThreadById({ threadId: 'thread-123' })
```

  {

  },
]}
