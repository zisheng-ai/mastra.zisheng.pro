# API Tools

L’API Tools fournit des méthodes pour interagir avec les Tools disponibles sur la plateforme Mastra et les exécuter.

## Récupérer tous les Tools

Récupérez la liste de tous les Tools disponibles :

```typescript
const tools = await mastraClient.listTools()
```

## Utiliser un Tool spécifique

Récupérez une instance d’un Tool spécifique :

```typescript
const tool = mastraClient.getTool('tool-id')
```

## Méthodes de Tool

### Obtenir les détails d’un Tool

Récupérez des informations détaillées sur un Tool :

```typescript
const details = await tool.details()
```

### Exécuter un Tool

Exécutez un Tool avec des arguments spécifiques :

```typescript
const result = await tool.execute({
  args: {
    param1: 'value1',
    param2: 'value2',
  },
  threadId: 'thread-1', // Optional: Thread context
  resourceId: 'resource-1', // Optional: Resource identifier
})
```
