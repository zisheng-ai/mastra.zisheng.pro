# Tools API

The Tools API provides methods à interact avec et exécute tools disponible dans the Mastra platform.

## Getting tous les tools

Retrieve a liste de tous les disponible tools:

```typescript
const tools = await mastraClient.listTools()
```

## Working avec a specific tool

Obtenir an instance de a specific tool:

```typescript
const tool = mastraClient.getTool('tool-id')
```

## Tool methods

### Obtenir Tool Détails

Retrieve detailed information concernant a tool:

```typescript
const details = await tool.details()
```

### Execute Tool

Execute a Tool avec specific arguments:

```typescript
const result = await tool.execute({
  args: {
    param1: 'value1',
    param2: 'value2',
  },
  threadId: 'thread-1', // Optional: Thread context
  resourceId: 'resource-1', // Optional: Resource identifier
})
```
