# API Logs

L’API Logs fournit des méthodes pour accéder aux journaux système et aux informations de débogage dans Mastra, ainsi que pour les interroger.

## Récupérer les journaux

Récupérez les journaux système avec un filtrage facultatif :

```typescript
const logs = await mastraClient.listLogs({
  transportId: 'transport-1',
})
```

## Récupérer les journaux d’une exécution spécifique

Récupérez les journaux d’une exécution spécifique :

```typescript
const runLogs = await mastraClient.getLogForRun({
  runId: 'run-1',
  transportId: 'transport-1',
})
```
