# API Vectors

L’API Vectors fournit des méthodes pour utiliser les embeddings vectoriels pour la recherche sémantique et la correspondance de similarité dans Mastra.

## Utiliser les vecteurs {/* #working-with-vectors */}

Récupérez une instance de magasin vectoriel :

```typescript
const vector = mastraClient.getVector('vector-name')
```

## Méthodes de vecteur {/* #vector-methods */}

### Obtenir les détails d’un index vectoriel {/* #get-vector-index-details */}

Récupérez les informations sur un index vectoriel spécifique :

```typescript
const details = await vector.details('index-name')
```

### Créer un index vectoriel {/* #create-vector-index */}

Créez un nouvel index vectoriel :

```typescript
const result = await vector.createIndex({
  indexName: 'new-index',
  dimension: 128,
  metric: 'cosine', // 'cosine', 'euclidean', or 'dotproduct'
})
```

### Mettre à jour ou insérer des vecteurs {/* #upsert-vectors */}

Ajoutez ou mettez à jour des vecteurs dans un index :

```typescript
const ids = await vector.upsert({
  indexName: 'my-index',
  vectors: [
    [0.1, 0.2, 0.3], // First vector
    [0.4, 0.5, 0.6], // Second vector
  ],
  metadata: [{ label: 'first' }, { label: 'second' }],
  ids: ['id1', 'id2'], // Optional: Custom IDs
})
```

### Interroger des vecteurs {/* #query-vectors */}

Recherchez des vecteurs similaires :

```typescript
const results = await vector.query({
  indexName: 'my-index',
  queryVector: [0.1, 0.2, 0.3],
  topK: 10,
  filter: { label: 'first' }, // Optional: Metadata filter
  includeVector: true, // Optional: Include vectors in results
})
```

### Obtenir tous les index {/* #get-all-indexes */}

Listez tous les index disponibles :

```typescript
const indexes = await vector.getIndexes()
```

### Supprimer un index {/* #delete-index */}

Supprimez un index vectoriel :

```typescript
const result = await vector.delete('index-name')
```
