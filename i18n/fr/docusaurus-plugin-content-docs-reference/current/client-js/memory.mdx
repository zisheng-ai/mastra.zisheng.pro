# Mémoire API

The Mémoire API provides methods à manage conversation threads et message history dans Mastra.

## Obtenir tous les threads

Retrieve tous les memory threads pour a specific resource:

```typescript
const threads = await mastraClient.listMemoryThreads({
  resourceId: 'resource-1',
  agentId: 'agent-1', // Optional - can be omitted if storage is configured
})
```

When `agentId` est omitted et storage est configuré sur the server, threads va be retrieved using storage directly. Ce est useful when plusieurs agents share the same threads (e.g., dans workflows avec plusieurs agent steps).

## Créer a nouveau thread

Créer a nouveau memory thread:

```typescript
const thread = await mastraClient.createMemoryThread({
  title: 'New Conversation',
  metadata: { category: 'support' },
  resourceId: 'resource-1',
  agentId: 'agent-1',
})
```

## Working avec a specific thread

Obtenir an instance de a specific memory thread:

```typescript
const thread = mastraClient.getMemoryThread({ threadId: 'thread-id', agentId: 'agent-id' })
```

## Thread methods

### Obtenir Thread Détails

Retrieve details concernant a specific thread:

```typescript
const details = await thread.get()
```

### Mettre à jour Thread

Mettre à jour thread properties:

```typescript
const updated = await thread.update({
  title: 'Updated Title',
  metadata: { status: 'resolved' },
  resourceId: 'resource-1',
})
```

### Supprimer Thread

Supprimer a thread et its messages:

```typescript
await thread.delete()
```

### Clone Thread

Créer a copy de a thread avec tous les its messages:

```typescript
const { thread: clonedThread, clonedMessages } = await thread.clone()
```

Clone avec options:

```typescript
const { thread: clonedThread, clonedMessages } = await thread.clone({
  newThreadId: 'custom-clone-id',
  title: 'Cloned Conversation',
  metadata: { branch: 'experiment-1' },
  options: {
    messageLimit: 10, // Only clone last 10 messages
  },
})
```

Clone avec message filtering:

```typescript
const { thread: clonedThread } = await thread.clone({
  options: {
    messageFilter: {
      startDate: new Date('2024-01-01'),
      endDate: new Date('2024-01-31'),
    },
  },
})
```

The clone réponse includes:

- `thread`: Le nouveauly created cloned thread avec clone metadata
- `clonedMessages`: Array de the cloned messages avec nouveau IDs

## Message operations

### Enregistrer Messages

Enregistrer messages à memory:

```typescript
const result = await mastraClient.saveMessageToMemory({
  messages: [
    {
      role: 'user',
      content: 'Hello!',
      id: '1',
      threadId: 'thread-1',
      resourceId: 'resource-1',
      createdAt: new Date(),
      format: 2,
    },
  ],
  agentId: 'agent-1',
})

// result.messages contains the saved messages
console.log(result.messages)
```

### Retrieve Thread Messages

Obtenir messages associated avec a memory thread:

```typescript
// Get all messages in the thread (paginated)
const result = await thread.listMessages()
console.log(result.messages) // Array of messages
console.log(result.total) // Total count
console.log(result.hasMore) // Whether more pages exist

// Get messages with pagination
const result = await thread.listMessages({
  page: 0,
  perPage: 20,
})

// Get messages with ordering
const result = await thread.listMessages({
  orderBy: { field: 'createdAt', direction: 'ASC' },
})

// Get messages with shallow metadata filters
const result = await thread.listMessages({
  filter: {
    metadata: {
      category: 'billing',
      escalated: true,
      priority: 2,
      archivedAt: null,
    },
  },
})
```

Filtres de métadonnées match shallow scalar values only: `string`, finite `number`, `boolean`, et `null`. Every key-value pair doit match avec AND semantics. `null` matches only keys explicitly définit à `null`. Metadata keys doit démarre avec a letter ou underscore et contain only alphanumeric ou underscore characters. The limit est 128 characters. Reserved prototype keys such comme `__proto__`, `constructor`, et `prototype` aren't allowed. Performance depends sur the server storage backend, et arbitrary metadata filters peut scan candidate messages.

### Supprimer Messages

Supprimer un ou more messages depuis a thread:

```typescript
// Delete a single message
const result = await thread.deleteMessages('message-id')

// Delete multiple messages
const result = await thread.deleteMessages(['message-1', 'message-2', 'message-3'])

// Returns: { success: true, message: "Message deleted successfully" }
```

## Working memory

Working memory allows agents à maintain persistent information concernant users across interactions. It peut be scoped à either a specific thread ou across tous les threads pour a resource (user).

### Obtenir Working Mémoire

Retrieve the actuel working memory pour a thread:

```typescript
const workingMemory = await mastraClient.getWorkingMemory({
  agentId: 'agent-1',
  threadId: 'thread-1',
  resourceId: 'user-123', // Optional, required for resource-scoped memory
})
```

La réponse includes:

- `workingMemory`: L’actuel working memory content (string ou null)
- `source`: Whether the memory est depuis `"thread"` ou `"resource"` scope
- `workingMemoryTemplate`: The template used pour working memory (if configured)
- `threadExists`: Whether the thread exists

### Mettre à jour Working Mémoire

Mettre à jour the working memory content pour a thread:

```typescript
await mastraClient.updateWorkingMemory({
  agentId: 'agent-1',
  threadId: 'thread-1',
  workingMemory: `# User Profile
- Name: John Doe
- Location: New York
- Preferences: Prefers formal communication
`,
  resourceId: 'user-123', // Optional, required for resource-scoped memory
})

// Returns: { success: true }
```

For resource-scoped working memory, you doit fournit the `resourceId` parameter. It allows the memory à persist across tous les conversation threads pour that user.

### Obtenir Mémoire Status

Vérifier the status de the memory system:

```typescript
const status = await mastraClient.getMemoryStatus('agent-id')
```
