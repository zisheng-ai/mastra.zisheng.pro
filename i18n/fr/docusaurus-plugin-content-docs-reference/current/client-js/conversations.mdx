# OpenAI Responses API Conversations

L'interface OpenAI Responses API Conversations expose les fonctionnalités de gestion des conversations des Agents Mastra sous la forme d'une Responses API. Elle fournit des méthodes permettant de créer, récupérer, supprimer et inspecter des conversations de Mastra adossées à des threads.

Cette API complète l'[OpenAI Responses API](/reference/client-js/responses). Les appels Responses stockés renvoient `conversation_id` ; dans Mastra, cette valeur correspond au `threadId` brut de la mémoire. Utilisez `client.conversations` lorsque vous souhaitez manipuler directement ce thread.

Cette API est actuellement expérimentale.

## Relation avec OpenAI Responses {/* #relationship-to-openai-responses */}

Utilisez l'OpenAI Responses API pour la génération et la poursuite d'une conversation :

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

console.log(response.conversation_id)
```

Utilisez la Conversations API pour inspecter ou gérer ce thread stocké :

```typescript
const conversation = await client.conversations.retrieve(response.conversation_id!)
const items = await client.conversations.items.list(response.conversation_id!)
```

## Exemple d'utilisation {/* #usage-example */}

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const conversation = await client.conversations.create({
  agent_id: 'support-agent',
})

console.log(conversation.id)
```

## Méthodes {/* #methods */}

### Cycle de vie {/* #lifecycle */}

#### `create(params)` {/* #createparams */}

Crée un nouveau thread de conversation pour l'Agent sélectionné.

```typescript
const conversation = await client.conversations.create({
  agent_id: 'support-agent',
  title: 'Billing support',
})
```

**Renvoie :** `Promise<Conversation>`.

#### `retrieve(conversationId, requestContext?)` {/* #retrieveconversationid-requestcontext */}

Récupère une conversation à partir de l'identifiant de son thread.

```typescript
const conversation = await client.conversations.retrieve('thread_123')

console.log(conversation.thread)
```

**Renvoie :** `Promise<Conversation>`.

#### `delete(conversationId, requestContext?)` {/* #deleteconversationid-requestcontext */}

Supprime une conversation à partir de l'identifiant de son thread.

```typescript
const deleted = await client.conversations.delete('thread_123')

console.log(deleted.deleted)
```

**Renvoie :** `Promise<ConversationDeleted>`.

### Éléments {/* #items */}

#### `items.list(conversationId, requestContext?)` {/* #itemslistconversationid-requestcontext */}

Répertorie les éléments stockés pour une conversation.

```typescript
const items = await client.conversations.items.list('thread_123')

console.log(items.data)
```

**Renvoie :** `Promise<ConversationItemsPage>`.

## Structure de la réponse {/* #response-shape */}

`create()` et `retrieve()` renvoient un objet de conversation contenant :

- `id` : l'identifiant brut du thread
- `object` : toujours `'conversation'`
- `thread` : l'enregistrement du thread stocké

`delete()` renvoie :

- `id` : l'identifiant brut du thread
- `object` : toujours `'conversation.deleted'`
- `deleted` : toujours `true`

`items.list()` renvoie :

- `object` : toujours `'list'`
- `data` : éléments de la conversation tels que `message`, `function_call` et `function_call_output`
- `first_id` : identifiant du premier élément de la page
- `last_id` : identifiant du dernier élément de la page
- `has_more` : indique s'il existe d'autres éléments après la page actuelle
