# OpenAI Réponses API Conversations

The OpenAI Réponses API Conversations surface gives you the conversation-management side de Mastra Agents comme a Réponses API. It provides methods à create, retrieve, delete, et inspect thread-backed conversations dans Mastra.

Ce API follows up sur the [OpenAI Réponses API](/reference/client-js/responses). Stored Réponses calls renvoie `conversation_id`, et dans Mastra that valeur est the raw memory `threadId`. Use `client.conversations` when you want à work avec that thread directly.

Ce API est currently experimental.

## Relationship à OpenAI Réponses

Utilisez le OpenAI Réponses API pour generation et continuation:

```typescript
const response = await client.responses.create({
  agent_id: 'support-agent',
  input: 'Start a support thread',
  store: true,
})

console.log(response.conversation_id)
```

Utilisez le Conversations API when you want à inspect ou manage that stored thread:

```typescript
const conversation = await client.conversations.retrieve(response.conversation_id!)
const items = await client.conversations.items.list(response.conversation_id!)
```

## Exemple d’utilisation

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

const conversation = await client.conversations.create({
  agent_id: 'support-agent',
})

console.log(conversation.id)
```

## Méthodes

### Lifecycle

#### `create(params)`

Crée a nouveau conversation thread pour the sélectionné agent.

```typescript
const conversation = await client.conversations.create({
  agent_id: 'support-agent',
  title: 'Billing support',
})
```

**Renvoie:** `Promise<Conversation>`.

#### `retrieve(conversationId, requestContext?)`

Retrieves a conversation par its thread ID.

```typescript
const conversation = await client.conversations.retrieve('thread_123')

console.log(conversation.thread)
```

**Renvoie:** `Promise<Conversation>`.

#### `delete(conversationId, requestContext?)`

Supprime a conversation par its thread ID.

```typescript
const deleted = await client.conversations.delete('thread_123')

console.log(deleted.deleted)
```

**Renvoie:** `Promise<ConversationDeleted>`.

### Items

#### `items.list(conversationId, requestContext?)`

Liste the stored items pour a conversation.

```typescript
const items = await client.conversations.items.list('thread_123')

console.log(items.data)
```

**Renvoie:** `Promise<ConversationItemsPage>`.

## Réponse shape

`create()` et `retrieve()` renvoie a conversation objet with:

- `id`: The raw thread ID
- `object`: Always `'conversation'`
- `thread`: The stored thread record

`delete()` returns:

- `id`: The raw thread ID
- `object`: Always `'conversation.deleted'`
- `deleted`: Always `true`

`items.list()` returns:

- `object`: Always `'list'`
- `data`: Conversation items such comme `message`, `function_call`, et `function_call_output`
- `first_id`: Le premier item ID dans the page
- `last_id`: The dernier item ID dans the page
- `has_more`: Whether more items exist beyond the actuel page
