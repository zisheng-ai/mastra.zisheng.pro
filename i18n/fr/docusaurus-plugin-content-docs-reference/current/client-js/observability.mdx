# Observability API

The Observability API provides methods à retrieve traces, monitor application performance, score traces pour evaluation, et record feedback linked à traces et spans.

## Getting a specific trace

Retrieve a specific trace par its ID, including tous les its spans et details:

```typescript
const trace = await mastraClient.getTrace('trace-id-123')
```

## Getting traces avec filtering

Retrieve a paginated liste de trace root spans avec facultatif filtering:

```typescript
const traces = await mastraClient.getTraces({
  pagination: {
    page: 1,
    perPage: 20,
    dateRange: {
      start: new Date('2024-01-01'),
      end: new Date('2024-01-31'),
    },
  },
  filters: {
    name: 'weather-agent', // Filter by trace name
    spanType: 'agent', // Filter by span type
    entityId: 'weather-agent-id', // Filter by entity ID
    entityType: 'agent', // Filter by entity type
  },
})

console.log(`Found ${traces.spans.length} root spans`)
console.log(`Total pages: ${traces.pagination.totalPages}`)

// To get the complete trace with all spans, use getTrace
const completeTrace = await mastraClient.getTrace(traces.spans[0].traceId)
```

## Listing traces pour a liste view

`listTracesLight()` returns the same rows comme a trace list, sans the `input`, `output` et `attributes` payloads. Chaque row carries a short `inputPreview` chaîne instead, so a liste peut affiche a preview column sans transferring the whole prompt.

Prefer it whenever you sont rendering many traces à once, et fetch the full record only when a row est opened:

```typescript
const list = await mastraClient.listTracesLight({
  pagination: { page: 0, perPage: 25 },
  filters: { entityType: 'agent' },
})

for (const span of list.spans) {
  console.log(span.name, span.inputPreview)
}

// Fetch the full payload only for the trace the user selects
const selected = await mastraClient.getTrace(list.spans[0].traceId)
```

It accepts the same filtering, ordering et delta-polling arguments comme `listTraces()`. Use `listTraces()` when you actually need the full span payloads.

## Scoring traces

Score specific traces using registered scorers pour evaluation:

```typescript
const result = await mastraClient.score({
  scorerName: 'answer-relevancy',
  targets: [
    { traceId: 'trace-1', spanId: 'span-1' }, // Score specific span
    { traceId: 'trace-2' }, // Score specific span which defaults to the parent span
  ],
})
```

## Getting scores par span

Retrieve scores pour a specific span within a trace:

```typescript
const scores = await mastraClient.listScoresBySpan({
  traceId: 'trace-123',
  spanId: 'span-456',
  page: 1,
  perPage: 20,
})
```

## Feedback

Feedback methods create, list, et query human-in-the-loop signals such comme ratings, thumbs, comments, et corrections. Consultez the [feedback guide](/docs/observability/feedback) pour examples et the [feedback reference](/reference/observability/feedback) pour full schemas.

### Creating feedback

Créer a feedback record linked à a trace ou span:

```typescript
const response = await mastraClient.createFeedback({
  feedback: {
    traceId: 'trace-123',
    spanId: 'span-456',
    feedbackSource: 'user',
    feedbackType: 'rating',
    value: 1,
    comment: 'Helpful answer.',
  },
})
```

### Listing feedback

Retrieve paginated feedback records avec facultatif filters:

```typescript
const feedback = await mastraClient.listFeedback({
  filters: {
    feedbackType: 'rating',
    feedbackSource: 'studio',
  },
  pagination: { page: 0, perPage: 20 },
  orderBy: { field: 'timestamp', direction: 'DESC' },
})
```

### Aggregating feedback

Aggregate numeric feedback values, such comme ratings ou thumbs encoded comme `1` et `-1`:

```typescript
const averageRating = await mastraClient.getFeedbackAggregate({
  feedbackType: 'rating',
  aggregation: 'avg',
  comparePeriod: 'previous_day',
})
```

### Grouping feedback

Group numeric feedback par observability dimensions:

```typescript
const ratingsByAgent = await mastraClient.getFeedbackBreakdown({
  feedbackType: 'rating',
  groupBy: ['entityName'],
  aggregation: 'avg',
})
```

### Requêteing feedback over time

Bucket numeric feedback par interval:

```typescript
const ratingsOverTime = await mastraClient.getFeedbackTimeSeries({
  feedbackType: 'rating',
  interval: '1h',
  aggregation: 'avg',
  groupBy: ['feedbackSource'],
})
```

### Requêteing feedback percentiles

Renvoyer percentile series pour numeric feedback values:

```typescript
const ratingPercentiles = await mastraClient.getFeedbackPercentiles({
  feedbackType: 'rating',
  percentiles: [0.5, 0.95],
  interval: '1d',
})
```
