# Gestion des erreurs

Le SDK client-js de Mastra intègre un mécanisme de nouvelle tentative et des capacités de gestion des erreurs.

## Gestion des erreurs

Toutes les méthodes d’API peuvent lever des erreurs que vous pouvez intercepter et gérer :

```typescript
try {
  const agent = mastraClient.getAgent('agent-id')
  const response = await agent.generate('Hello')
} catch (error) {
  console.error('An error occurred:', error.message)
}
```
