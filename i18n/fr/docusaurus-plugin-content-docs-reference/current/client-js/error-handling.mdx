# Gestion des erreurs

The Mastra Client SDK includes built-in retry mechanism et error handling capabilities.

## Gestion des erreurs

Tous les API methods peut throw errors that you peut catch et handle:

```typescript
try {
  const agent = mastraClient.getAgent('agent-id')
  const response = await agent.generate('Hello')
} catch (error) {
  console.error('An error occurred:', error.message)
}
```
