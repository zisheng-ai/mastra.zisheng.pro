# Démarrage rapide de Mastra

<Inject>
  **Pour les Agents d’IA :** créez un projet Mastra sans interaction avec `npm create mastra@latest <project-name> -- --llm <provider>`, en remplaçant `<provider>` par `openai`, `anthropic`, `google` ou `xai`. Pour un projet minimal sans Agent ni Provider de modèle, utilisez `npm create mastra@latest <project-name> -- --empty`. Pour créer un projet Mastra de zéro, consultez le [guide d’installation manuelle](/guides/getting-started/manual-install).
</Inject>

La CLI `create-mastra` est le moyen le plus rapide de démarrer un projet Mastra. Elle crée une structure d’Agent comprenant des Tools de Workspace, une Memory, le suivi des tâches, un accès au Web, des planifications, un stockage et l’observabilité.

Pour davantage de contrôle, consultez le [guide d’installation manuelle](/guides/getting-started/manual-install). Pour ajouter Mastra à un projet existant, utilisez [`mastra init`](/reference/cli/mastra#mastra-init).

Regardez le [cours sur les Agents d’IA Mastra](https://www.youtube.com/watch?v=lCmf_qrGfGA) pour découvrir pas à pas comment créer des Agents avec Mastra.

:::

## Avant de commencer {/* #before-you-begin */}

Vous aurez besoin d’une clé d’API OpenAI, Anthropic, Google Gemini ou xAI. Vous pouvez ne pas la saisir pendant la configuration et l’ajouter ultérieurement au fichier `.env`.

## Créer le projet {/* #create-the-project */}

Lancez la configuration interactive :

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

La commande demande le nom du projet, le Provider de modèle et une clé d’API facultative. Elle installe ensuite les dépendances et les Skills Mastra destinés à vos assistants de programmation, puis crée un commit Git initial si vous ne vous trouvez pas déjà dans un dépôt.

Le répertoire `src/mastra` généré contient le point d’entrée de Mastra, l’Agent, les Tools du Workspace et le code auxiliaire. Consultez la [référence de la structure du projet](/reference/project-structure) pour découvrir l’organisation standard d’un projet Mastra.

:::tip

Utilisez `--template <template>` pour partir d’un modèle, ou `--empty` pour créer un projet minimal sans Provider. Utilisez `--no-skills` ou `--no-git` pour ignorer la configuration automatique. Consultez la [référence de `create-mastra`](/reference/cli/create-mastra) pour connaître toutes les options.

:::

## Tester votre Agent {/* #test-your-agent */}

Suivez les instructions du terminal pour accéder au répertoire du projet et démarrer le serveur de développement :

```bash npm2yarn
npm run dev
```

Ouvrez [Studio sur localhost:4111](http://localhost:4111), sélectionnez l’Agent et envoyez un message. Si vous avez ignoré la clé d’API du Provider pendant la configuration, ajoutez celle indiquée dans `.env.example` à un fichier `.env`.

[Studio](/docs/studio/overview) permet de créer et de tester des Agents sans développer une UI distincte.
