# Déployer Mastra sur Digital Ocean

Ce guide présente l'App Platform et les Droplets de Digital Ocean. Chacune de ces offres possède ses propres atouts et convient à différents types de projets et niveaux d'expertise. Consultez le [comparatif de Digital Ocean](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets) pour comprendre leurs différences et choisir l'option la mieux adaptée à votre projet.

:::info
Ce guide décrit le déploiement du [serveur Mastra](/docs/server/mastra-server). Si vous utilisez un [adaptateur de serveur](/docs/server/server-adapters) ou un [framework web](/docs/deployment/web-framework), suivez la procédure de déploiement habituelle de ce framework.
:::

## Avant de commencer {/* #before-you-begin */}

Vous aurez besoin d'une [application Mastra](/guides/getting-started/quickstart) et d'un compte [Digital Ocean](https://www.digitalocean.com/).

L'**App Platform** utilise un système de fichiers éphémère. Tout stockage que vous configurez, y compris celui de l'observabilité, doit donc être hébergé à l'extérieur. Si vous utilisez [LibSQLStore](/reference/storage/libsql) avec une URL de fichier, passez à une base de données hébergée à distance.

## App Platform {/* #app-platform */}

Après avoir configuré votre projet, envoyez-le vers le fournisseur Git distant de votre choix, par exemple GitHub.

<Steps>
  <StepItem>
    Suivez le [guide de démarrage rapide de l'App Platform](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app). Il vous accompagnera pour connecter votre dépôt, choisir la branche à déployer et, si nécessaire, configurer le répertoire source.
  </StepItem>

  <StepItem>
    Vérifiez qu'un build « Node.js » est détecté. Vous devrez configurer une commande de build en fonction de votre gestionnaire de packages :

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    Ajoutez toutes les variables d'environnement requises par votre application Mastra, notamment les clés d'API, les URL de bases de données et les autres valeurs de configuration.
  </StepItem>

  <StepItem>
    Votre application sera construite et déployée automatiquement. Digital Ocean vous fournira une URL permettant d'accéder à l'application déployée.
  </StepItem>

  <StepItem>
    Vous pouvez maintenant appeler vos endpoints Mastra via HTTP.

    :::warning
    Configurez l'[authentification](/docs/server/auth) avant d'exposer publiquement vos endpoints.
    :::
  </StepItem>
</Steps>

## Droplets {/* #droplets */}

### Prérequis {/* #prerequisites */}

- Un Droplet exécutant Ubuntu 24.04 LTS ou une version ultérieure
- Un nom de domaine dont l'enregistrement A pointe vers votre Droplet
- Un proxy inverse configuré, par exemple avec [nginx](https://nginx.org/)
- Un certificat SSL configuré, par exemple avec [Let's Encrypt](https://letsencrypt.org/)
- Node.js 22.13.0 ou une version ultérieure installé sur votre Droplet

### Déployer {/* #deploy */}

Après avoir configuré votre projet, envoyez-le vers le fournisseur Git distant de votre choix, par exemple GitHub. Connectez-vous à votre Droplet et vérifiez que `git` est installé.

<Steps>
  <StepItem>
    Clonez votre dépôt :

    <Tabs>
      <TabItem value="public" label="Dépôt public">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="Dépôt privé">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    Accédez au répertoire du dépôt :

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    Installez les dépendances du projet :

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    Définissez les variables d'environnement requises par votre application Mastra. Créez un fichier `.env` à la racine du projet :

    ```bash
    touch .env
    ```

    Modifiez le fichier `.env` et ajoutez vos variables d'environnement :

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    Construisez le projet :

    ```bash npm2yarn
    npm run build
    ```

    Cette commande crée un build de production du serveur Mastra dans le répertoire `.mastra/output`.
  </StepItem>

  <StepItem>
    Vous pouvez lancer le [serveur Mastra](/docs/deployment/mastra-server) en exécutant la commande `mastra start` :

    ```bash
    mastra start
    ```

    :::info
    Par défaut, votre application Mastra s'exécute sur le port 4111. Vérifiez que votre proxy inverse est configuré pour transférer les requêtes vers ce port.
    :::
  </StepItem>

  <StepItem>
    Vous pouvez maintenant appeler vos endpoints Mastra via HTTP.

    :::warning
    Configurez l'[authentification](/docs/server/auth) avant d'exposer publiquement vos endpoints.
    :::
  </StepItem>
</Steps>
