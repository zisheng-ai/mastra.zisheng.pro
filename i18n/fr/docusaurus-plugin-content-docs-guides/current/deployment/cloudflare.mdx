# Déployer Mastra sur Cloudflare

Utilisez `@mastra/deployer-cloudflare` pour déployer votre serveur Mastra sur Cloudflare Workers. Le déployeur regroupe votre code et génère un fichier `wrangler.jsonc` conforme à la [configuration de wrangler](https://developers.cloudflare.com/workers/wrangler/configuration/) de Cloudflare, prêt à être déployé sans configuration supplémentaire.

:::info

Si vous utilisez un [adaptateur de serveur](/docs/server/server-adapters) ou un [framework web](/docs/deployment/web-framework), déployez votre application comme vous le feriez habituellement avec ce framework.

:::

## Avant de commencer

Vous aurez besoin d’une [application Mastra](/guides/getting-started/quickstart) et d’un compte [Cloudflare](https://cloudflare.com/).

:::warning
Cloudflare Workers utilise un système de fichiers éphémère ; tout stockage que vous configurez, y compris celui d’observabilité, doit donc être hébergé à l’extérieur. Si vous utilisez [LibSQLStore](/reference/storage/libsql) avec une URL de fichier, passez à une base de données hébergée à distance.
:::

## Installation

Ajoutez le package `@mastra/deployer-cloudflare` à votre projet :

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

Importez [`CloudflareDeployer`](/reference/deployer/cloudflare) et définissez-le comme déployeur dans votre configuration Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

Pour tester votre Cloudflare Worker localement, installez également la [CLI `wrangler`](https://developers.cloudflare.com/workers/wrangler/install-and-update/) :

```bash npm2yarn
npm install -D wrangler
```

## Utilisation

Après avoir configuré votre projet, poussez-le vers le fournisseur Git distant de votre choix, par exemple GitHub.

<Steps>
  <StepItem>
    Connectez votre dépôt à Cloudflare. Dans le tableau de bord « Workers & Pages », sélectionnez **Create application**, puis choisissez votre fournisseur Git à l’étape suivante. Poursuivez le processus de configuration et sélectionnez le dépôt que vous souhaitez déployer.

    :::note

    N’oubliez pas de définir les variables d’environnement nécessaires à l’exécution de votre application, par exemple la clé API de votre [fournisseur de modèles](/models/providers). Vous pouvez importer des secrets depuis votre fichier `.env` avec `npx wrangler secret bulk .env`. Consultez [Secrets](/reference/deployer/cloudflare#secrets) pour plus de détails.

    :::
  </StepItem>

  <StepItem>
    Lorsque vous êtes prêt, cliquez sur le bouton **Deploy** et attendez que le premier déploiement se termine.
  </StepItem>

  <StepItem>
    Testez votre fonction fraîchement déployée en accédant à `https://<your-project-name>.<slug>.workers.dev/api/agents`. Vous devriez obtenir une réponse JSON qui répertorie tous les Agents disponibles.

    Puisque le [serveur Mastra](/docs/server/mastra-server) préfixe chaque endpoint API par `/api`, vous devez l’ajouter à vos URL lorsque vous effectuez des requêtes.
  </StepItem>

  <StepItem>
    Vous pouvez maintenant appeler vos endpoints Mastra via HTTP.

    :::note

    Configurez l’[authentification](/docs/server/auth) avant d’exposer publiquement vos endpoints.

    :::
  </StepItem>
</Steps>
