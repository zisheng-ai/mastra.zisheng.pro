# Déployer Mastra sur Netlify

Utilisez `@mastra/deployer-netlify` pour déployer votre serveur Mastra sur Netlify. Le deployer regroupe votre code et génère un répertoire `.netlify` conforme à la [Frameworks API](https://docs.netlify.com/build/frameworks/frameworks-api/) de Netlify, prêt à être déployé. Vous pouvez effectuer le déploiement sous forme de fonctions serverless (par défaut) ou de [fonctions Edge](https://docs.netlify.com/build/edge-functions/overview/) afin de réduire la latence et d'allonger la durée d'exécution.

:::info
Ce guide décrit le déploiement du [serveur Mastra](/docs/server/mastra-server). Si vous utilisez un [adaptateur de serveur](/docs/server/server-adapters) ou un [framework web](/docs/deployment/web-framework), suivez la procédure de déploiement habituelle de ce framework.
:::

## Avant de commencer

Vous aurez besoin d'une [application Mastra](/guides/getting-started/quickstart) et d'un compte [Netlify](https://www.netlify.com/).

:::warning
Les fonctions Netlify utilisent un système de fichiers éphémère. Tout stockage que vous configurez, y compris celui de l'observabilité, doit donc être hébergé à l'extérieur. Si vous utilisez [LibSQLStore](/reference/storage/libsql) avec une URL de fichier, passez à une base de données hébergée à distance.
:::

## Installation

Ajoutez le package `@mastra/deployer-netlify` à votre projet :

```bash npm2yarn
npm install @mastra/deployer-netlify@latest
```

Importez [`NetlifyDeployer`](/reference/deployer/netlify) et définissez-le comme deployer dans votre configuration Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  // highlight-next-line
  deployer: new NetlifyDeployer(),
})
```

Pour déployer plutôt sous forme de fonctions Edge, transmettez `{ target: 'edge' }` :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { NetlifyDeployer } from '@mastra/deployer-netlify'

export const mastra = new Mastra({
  deployer: new NetlifyDeployer({
    target: 'edge',
  }),
})
```

Les fonctions Edge s'exécutent sur Deno au point de présence le plus proche de vos utilisateurs. Elles ne sont soumises à aucun délai d'exécution strict, mais uniquement à une limite de temps CPU, ce qui les rend mieux adaptées aux workflows d'IA de longue durée. Consultez les [options du constructeur](/reference/deployer/netlify#constructor-options) pour plus de détails.

Créez à la racine de votre projet un fichier `netlify.toml` avec le contenu suivant :

```toml
[build]
command = "mastra build"
```

## Déployer

Après avoir configuré votre projet, envoyez-le vers le fournisseur Git distant de votre choix, par exemple GitHub.

<Steps>
  <StepItem>
    Connectez votre dépôt à Netlify. Pendant la configuration, Netlify détectera votre fichier `netlify.toml` et définira la commande de build sur `mastra build`.

    :::note

    Pensez à définir les variables d'environnement nécessaires à l'exécution de votre application, par exemple la clé d'API de votre [fournisseur de modèles](/models/providers).

    :::
  </StepItem>

  <StepItem>
    Lorsque tout est prêt, cliquez sur le bouton **Deploy** et attendez la fin du premier déploiement. Netlify vous indiquera qu'une
    fonction a été déployée.
  </StepItem>

  <StepItem>
    Vérifiez votre déploiement à l'adresse `https://<random-slug>.netlify.app/api/agents`, qui doit renvoyer une liste JSON de vos agents.

    Comme le [serveur Mastra](/docs/server/mastra-server) préfixe chaque endpoint d'API par `/api`, vous devez ajouter ce préfixe à vos URL lorsque vous envoyez des requêtes.

    :::info

    Les fonctions Netlify sont généralement déployées à l'adresse `https://<random-slug>.netlify.app/.netlify/functions/api`. `NetlifyDeployer` redirige toute requête de `/*` vers `/.netlify/functions/api/:splat` ; il n'est donc pas nécessaire d'inclure le préfixe `.netlify/functions` dans vos URL.

    :::
  </StepItem>

  <StepItem>
    Vous pouvez maintenant appeler vos endpoints Mastra via HTTP.

    :::warning
    Configurez l'[authentification](/docs/server/auth) avant d'exposer publiquement vos endpoints.
    :::
  </StepItem>
</Steps>
