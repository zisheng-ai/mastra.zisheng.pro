# Voix

Les packages ont été renommés de « speech » à « voice », avec de nouveaux noms de classes et de méthodes d’API.

## Modifications {/* #changed */}

### Noms des propriétés de configuration vocale {/* #voice-configuration-property-names */}

Les propriétés de configuration vocale ont été renommées par souci de cohérence. `speakProvider` devient `output`, `listenProvider` devient `input` et `realtimeProvider` devient `realtime`. Les nouveaux noms correspondent au rôle de chaque propriété dans l’entrée et la sortie vocales.

Pour effectuer la migration, mettez à jour les noms des propriétés lorsque vous configurez des Agents dotés de fonctionnalités vocales.

```diff
  const agent = new Agent({
    id: 'agent',
    voice: {
-     speakProvider: murfVoice,
-     listenProvider: deepgramVoice,
-     realtimeProvider: openaiRealtime,
+     output: murfVoice,
+     input: deepgramVoice,
+     realtime: openaiRealtime,
    },
  });
```

:::tip[Codemod]

Vous pouvez utiliser la CLI codemod de Mastra pour mettre à jour votre code automatiquement :

```bash
npx @mastra/codemod@latest v1/voice-property-names .
```

:::
