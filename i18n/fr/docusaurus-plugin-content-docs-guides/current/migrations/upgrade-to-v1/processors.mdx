# Processors

Les interfaces de Processor ont été mises à jour pour utiliser des conventions de nommage cohérentes et des types de messages de base de données.

## Modifié {/* #changed */}

### Processor configuration from `name` to `id` {/* #processor-configuration-from-name-to-id */}

Les Processors requièrent désormais un champ `id` au lieu de `name`. Le champ `name` est désormais facultatif. Ce changement assure la cohérence avec d’autres entités Mastra comme les scorers et les Agents.

Pour migrer, mettez à jour les définitions de Processor afin d’utiliser `id` comme champ requis.

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### Processor message types from `MastraMessageV2` to `MastraDBMessage` {/* #processor-message-types-from-mastramessagev2-to-mastradbmessage */}

Les types de message de Processor sont passés de `MastraMessageV2` à `MastraDBMessage`. Les Processors et scorers utilisent désormais le format de message de base de données et ses types.

Pour migrer, mettez à jour les imports et l’utilisation des types de message de Processor.

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## Supprimé {/* #removed */}

### Deprecated input processor exports {/* #deprecated-input-processor-exports */}

Les exports obsolètes d’input processor, qui incluent les Processors intégrés, ont été supprimés de `@mastra/core/agent/input-processors/processors`. Utilisez plutôt `@mastra/core/processors`. Ce changement regroupe les types de Processor sous l’interface unifiée `Processor`.

Si vous utilisiez `InputProcessor`, remplacez-le par `Processor`, qui implémente une fonction `processInput`.

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory processor exports moved to core {/* #memory-processor-exports-moved-to-core */}

L’export `@mastra/memory/processors` a été supprimé. Tous les Processors sont désormais exportés depuis `@mastra/core/processors`. Ce changement regroupe tous les exports de Processor en un seul emplacement.

Pour migrer, mettez à jour vos chemins d’import de `@mastra/memory/processors` vers `@mastra/core/processors`.

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
