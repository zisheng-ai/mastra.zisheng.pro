# Vectors

Les constructeurs de vector store requièrent désormais une propriété `id`, et les méthodes de vector store ont été renommées pour respecter des conventions de nommage cohérentes.

## Modifications

### Propriété `id` obligatoire pour les instances de vector store

Les instances de vector store requièrent désormais une propriété `id`. Cet identifiant unique sert à suivre et gérer les instances de vector store dans Mastra. La valeur de `id` doit être une chaîne descriptive et unique pour chaque vector store de votre application.

Pour migrer, ajoutez un champ `id` au constructeur de votre vector store.

```diff
  const vectorStore = new PgVector({
+   id: 'main-vector-store',
    connectionString: process.env.POSTGRES_CONNECTION_STRING,
  });

  const chromaStore = new ChromaVector({
+   id: 'chroma-embeddings',
    url: process.env.CHROMA_URL,
  });

  const pineconeStore = new PineconeVector({
+   id: 'pinecone-production',
    apiKey: process.env.PINECONE_API_KEY,
  });
```

### `getVectors` to `listVectors`

La méthode `getVectors()` a été renommée en `listVectors()`. Cette modification s’aligne sur la convention de nommage utilisée dans l’API, où les méthodes getter au pluriel utilisent le préfixe `list`.

Pour migrer, remplacez tous les appels à `getVectors()` par `listVectors()`.

```diff
  const vectorStore = new VectorStore({ ... });

- const vectors = await vectorStore.getVectors({ ... });
+ const vectors = await vectorStore.listVectors({ ... });
```

### `LibSQLVector`: `connectionUrl` to `url`

Le paramètre `connectionUrl` a été renommé en `url` afin de s’aligner sur l’API `@libsql/client` et de correspondre à LibSQLStorage.

```diff
  const vectorStore = new LibSQLVector({
    id: 'my-vector',
-   connectionUrl: 'file:./db.sqlite',
+   url: 'file:./db.sqlite',
  });
```

### `OpenSearchVector`: `url` to `node`

Le paramètre `url` a été renommé en `node` pour correspondre à l’API OpenSearch `ClientOptions`. Le constructeur accepte désormais toutes les options du client OpenSearch, notamment l’authentification, SSL et la compression.

```diff
  const vectorStore = new OpenSearchVector({
    id: 'my-vector',
-   url: 'http://localhost:9200',
+   node: 'http://localhost:9200',
  });
```

### `PineconeVector`: `environment` removed

Le paramètre `environment` a été supprimé. Utilisez plutôt `controllerHostUrl` si vous devez spécifier un hôte de contrôleur personnalisé. Le constructeur accepte désormais toutes les options de configuration Pinecone.

```diff
  const vectorStore = new PineconeVector({
    id: 'my-vector',
    apiKey: process.env.PINECONE_API_KEY,
-   environment: process.env.PINECONE_ENVIRONMENT,
  });
```

Si vous avez besoin d’un hôte de contrôleur personnalisé :

```ts
const vectorStore = new PineconeVector({
  id: 'my-vector',
  apiKey: process.env.PINECONE_API_KEY,
  controllerHostUrl: 'https://api.pinecone.io',
})
```
