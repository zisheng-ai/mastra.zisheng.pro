# MCP

Le contexte d’exécution des Tools MCP (Model Context Protocol) a été réorganisé et les classes clientes obsolètes ont été supprimées.

## Modifications {/* #changed */}

### De `getMCPServers` à `listMCPServers` {/* #getmcpservers-to-listmcpservers */}

La méthode `mastra.getMCPServers()` a été renommée `mastra.listMCPServers()`. Cette modification respecte la convention de nommage de l’ensemble de l’API, selon laquelle les méthodes de récupération au pluriel utilisent le préfixe `list`.

Pour effectuer la migration, remplacez tous les appels à `mastra.getMCPServers()` par `mastra.listMCPServers()`.

```diff
- const servers = await mastra.getMCPServers();
+ const servers = await mastra.listMCPServers();
```

:::tip[Codemod]

Vous pouvez utiliser la CLI codemod de Mastra pour mettre à jour votre code automatiquement :

```bash
npx @mastra/codemod@latest v1/mastra-plural-apis .
```

:::

### Organisation des propriétés de contexte des Tools MCP {/* #mcp-tool-context-properties-organization */}

Les propriétés de contexte des Tools MCP sont désormais regroupées sous l’espace de noms `context.mcp`. Cette modification améliore l’organisation et clarifie la surface d’API des fonctionnalités propres à MCP.

Pour effectuer la migration, accédez aux propriétés propres à MCP, telles que `elicitation` et `extra`, via `context.mcp` plutôt que directement depuis le paramètre de contexte.

```diff
  createTool({
    id: 'account-balance',
-   execute: async ({ context, elicitation, extra }) => {
-     await checkAuth(extra.authInfo);
-     const result = await elicitation.sendRequest({
-       message: `Is it ok to fetch account ${context.accountId}?`,
-     });
-   },
+   execute: async (inputData, context) => {
+     await checkAuth(context?.mcp?.extra.authInfo);
+     const result = await context?.mcp?.elicitation.sendRequest({
+       message: `Is it ok to fetch account ${inputData.accountId}?`,
+     });
+   },
  });
```

## Suppressions {/* #removed */}

### Classes clientes MCP obsolètes {/* #deprecated-mcp-client-classes */}

`MastraMCPClient` et les API obsolètes associées ont été supprimés de `@mastra/mcp`. Cette modification unifie l’utilisation autour de la nouvelle API cliente MCP.

Pour effectuer la migration, utilisez la nouvelle classe `MCPClient` à la place des classes obsolètes.

```diff
- import { MastraMCPClient, MCPConfiguration } from '@mastra/mcp/client';
+ import { MCPClient } from '@mastra/mcp/client';

- const client = new MastraMCPClient({ ... });
- const config = new MCPConfiguration({ ... });
+ const client = new MCPClient({ ... });
```
