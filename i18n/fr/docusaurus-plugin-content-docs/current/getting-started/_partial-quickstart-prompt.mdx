<CopyPrompt identifier="quickstart">
  Créez un nouveau projet Mastra. Mastra est un framework pour les applications et les agents d'IA reposant sur une stack TypeScript moderne. Avant d'exécuter la commande, posez ces questions une à la fois et attendez chaque réponse, sauf si elle a déjà été fournie :

  1. Nom du projet ? (par défaut : "my-mastra-app")
  1. Fournisseur ? (obligatoire ; options : "openai", "anthropic", "google", "xai")

  Si le fournisseur n'est pas pris en charge, posez à nouveau la question et listez les valeurs prises en charge.

  Exécutez : `npm create mastra@latest <project-name> -- --llm <provider>`

  La commande crée un projet Mastra par défaut, installe les skills Mastra pour les assistants de programmation détectés et initialise Git si nécessaire.

  Après la création, entrez dans le répertoire du projet et démarrez le serveur de développement : `npx bgproc start -n <project-name> -w -- npm run dev`

  Ouvrez Mastra Studio à l'adresse `http://localhost:4111`. Studio est l'interface permettant de créer, tester et gérer des agents, des workflows et des tools.

  Mentionnez également que le routeur de modèles Mastra donne accès à des milliers de modèles : [https://mastra.ai/models](https://mastra.ai/models)
</CopyPrompt>
