# Déployer avec un framework web

Lorsque Mastra est intégré à un framework web, il se déploie avec votre application à l’aide du processus de déploiement standard du framework. Suivez les instructions ci-dessous afin de vérifier que votre intégration Mastra se déploie correctement.

:::warning
Si vous déployez auprès d’un fournisseur cloud, supprimez toute utilisation de [LibSQLStore](/reference/storage/libsql) de votre configuration Mastra. LibSQLStore nécessite un accès au système de fichiers et n’est pas compatible avec les plateformes serverless.
:::

Guides d’intégration :

- [Avec Next.js](/guides/getting-started/next-js)
- [Avec Astro](/guides/getting-started/astro)

## Avec Next.js sur Vercel {/* #with-nextjs-on-vercel */}

Si vous avez intégré Mastra à Next.js [en suivant notre guide](/guides/getting-started/next-js) et prévoyez un déploiement sur Vercel, ajoutez `serverExternalPackages: ["@mastra/*"]` à votre fichier `next.config.ts` :

```typescript {4} title="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@mastra/*'],
}

export default nextConfig
```

## Avec Astro sur Vercel {/* #with-astro-on-vercel */}

Si vous avez intégré Mastra à Astro [en suivant notre guide](/guides/getting-started/astro) et prévoyez un déploiement sur Vercel, ajoutez l’adaptateur Vercel et la sortie serveur à votre fichier `astro.config.mjs` :

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import vercel from '@astrojs/vercel'

export default defineConfig({
  adapter: vercel(),
  output: 'server',
})
```

## Avec Astro sur Netlify {/* #with-astro-on-netlify */}

Si vous avez intégré Mastra à Astro [en suivant notre guide](/guides/getting-started/astro) et prévoyez un déploiement sur Netlify, ajoutez l’adaptateur Netlify et la sortie serveur à votre fichier `astro.config.mjs` :

```javascript {2,5-6} title="astro.config.mjs"
import { defineConfig } from 'astro/config'
import netlify from '@astrojs/netlify'
```
