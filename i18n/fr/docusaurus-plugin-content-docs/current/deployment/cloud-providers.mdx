# Déployer sur des fournisseurs cloud

Les applications Mastra peuvent être déployées auprès de fournisseurs cloud et sur des plateformes serverless. Mastra inclut des déployeurs intégrés facultatifs pour Vercel, Netlify et Cloudflare afin d'automatiser le processus de déploiement.

## Mastra platform

Mastra fournit une plateforme permettant de déployer votre serveur dans le cloud. Lisez le [guide de déploiement de la plateforme Mastra](/docs/mastra-platform/overview) pour en savoir plus.
