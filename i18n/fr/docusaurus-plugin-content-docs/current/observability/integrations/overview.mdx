# Vue d’ensemble des intégrations

Les intégrations d’observabilité Mastra déterminent où les données d’observabilité sont envoyées et comment elles sont transformées à leur sortie. Utilisez-les pour stocker les données dans le stockage Mastra, les envoyer à la plateforme Mastra, vous connecter à des fournisseurs d’observabilité externes ou supprimer les données sensibles des spans exportés.

## Quand utiliser les intégrations

- Conservez l’observabilité disponible dans Studio avec `MastraStorageExporter`.
- Envoyez les données d’observabilité hébergées à la plateforme Mastra avec `MastraPlatformExporter`.
- Transmettez les traces à des fournisseurs externes tels que Datadog, Langfuse ou des backends OpenTelemetry.
- Masquez les valeurs sensibles avant qu’elles ne quittent l’environnement d’exécution.

## Choisir un parcours d’intégration

- Workflow Studio : commencez par [Mastra Storage](/docs/observability/integrations/exporters/mastra-storage).
- Workflow Mastra hébergé : ajoutez la [plateforme Mastra](/docs/observability/integrations/exporters/mastra-platform).
- Stack d’observabilité externe : choisissez une ou plusieurs pages d’exporter dans la section `Exporters` de la barre latérale.
- Contexte de trace distribuée existant : utilisez un bridge, puis ajoutez les exporters nécessaires.

## Exporters

Les exporters envoient les données d’observabilité vers une destination :

- [Mastra Storage](/docs/observability/integrations/exporters/mastra-storage) : conserve les données d’observabilité pour Studio.
- [Plateforme Mastra](/docs/observability/integrations/exporters/mastra-platform) : envoie les données d’observabilité hébergées à la plateforme Mastra.
- Fournisseurs externes : utilisez les pages d’exporter pour Datadog, Langfuse, OpenTelemetry et les autres plateformes prises en charge.

## Bridges

Les bridges connectent Mastra à un contexte de traçage distribué existant :

- [Bridge OpenTelemetry](/docs/observability/integrations/bridges/otel) : intégrez Mastra à une trace OpenTelemetry existante.
- [Bridge Datadog](/docs/observability/integrations/bridges/datadog) : envoyez les traces Mastra à Datadog et à son produit LLM Observability.

## Processors

Les processors transforment ou masquent les spans avant leur export :

- [Filtre de données sensibles](/docs/observability/integrations/processors/sensitive-data-filter) : masquez les champs sensibles avant que les spans ne quittent l’environnement d’exécution.
