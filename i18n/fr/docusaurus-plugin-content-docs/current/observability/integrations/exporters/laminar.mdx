# Exporter Laminar

[Laminar](https://laminar.sh/) est une plateforme d’observabilité open source, native OpenTelemetry, destinée aux agents d’IA. Tracez, déboguez et surveillez chaque exécution d’agent Mastra, étape de modèle, appel de tool et sous-agent grâce à un unique `MastraExporter` branché dans votre configuration `Observability`.

## Installation

```bash npm2yarn
npm install @lmnr-ai/lmnr
```

## Configuration

### Prérequis

1. **Projet Laminar** : créez ou sélectionnez un projet dans Laminar.
1. **Clé d’API du projet** : copiez-la depuis les paramètres du projet Laminar.
1. **Variables d’environnement** : définissez vos identifiants.

```bash title=".env"
# Required
LMNR_PROJECT_API_KEY=lmnr_...

# Optional
LMNR_BASE_URL=https://api.lmnr.ai
```

### Configuration sans paramétrage

Une fois les variables d’environnement définies, utilisez l’exporter sans configuration :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize()

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [new MastraExporter()],
      },
    },
  }),
})
```

### Configuration explicite

Vous pouvez également transmettre les identifiants directement ; ils prévalent sur les variables d’environnement :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Observability } from '@mastra/observability'
import { Laminar, MastraExporter } from '@lmnr-ai/lmnr'

Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY!,
  baseUrl: process.env.LMNR_BASE_URL, // Optional
  // ...other options
})

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      laminar: {
        serviceName: 'my-service',
        exporters: [
          new MastraExporter({
            realtime: process.env.NODE_ENV === 'development', // Optional
          }),
        ],
      },
    },
  }),
})
```

:::note
Pour un usage avancé, y compris les options complètes de `MastraExporter` et des exemples de traces multi-agents, consultez le [guide d’intégration Mastra de Laminar](https://laminar.sh/docs/tracing/integrations/mastra).
:::

Mastra inclut également un [`LaminarExporter`](/reference/observability/tracing/exporters/laminar) autonome dans `@mastra/laminar`, qui envoie les spans via OTLP/HTTP. Il ne peut pas hériter d’un contexte OTel actif et ne mappe pas entièrement les spans Mastra au format natif de Laminar ; utilisez donc l’intégration `@lmnr-ai/lmnr` ci-dessus pour les wrappers `observe()`, les spans racine multi-agents et un rendu Laminar fidèle.
