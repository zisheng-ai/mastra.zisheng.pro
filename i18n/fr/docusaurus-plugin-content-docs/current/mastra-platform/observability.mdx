# Observability sur la plateforme Mastra

Observability sur la plateforme Mastra est un produit hébergé autonome qui fournit des traces, journaux et métriques consultables dans les projets et déploiements Mastra. Utilisez-le lorsque vous souhaitez disposer de l’observabilité sans déployer d’abord Studio ni configurer un stockage local.

Utilisez `mastra init` pour configurer l’observabilité de la plateforme lorsque vous ajoutez Mastra à une application existante, ou configurez-la manuellement dans un nouveau projet Mastra.

## Démarrage rapide {/* #quickstart */}

Choisissez le parcours de configuration adapté à votre projet.

### Nouveau projet {/* #new-project */}

Créez un projet Mastra géré. Lorsque vous y êtes invité, choisissez Mastra Platform Observability pour le configurer automatiquement :

```bash npm2yarn
npm create mastra@latest
```

Lorsque vous sélectionnez Observability, la commande de création s’authentifie auprès de la plateforme Mastra, provisionne un projet sur la plateforme et écrit les identifiants dans votre projet. Si vous ignorez la configuration de la plateforme ou utilisez un flux de création sans prompt, suivez plutôt les étapes de [configuration manuelle](#manual-setup).

### Projets existants qui n’utilisent pas Mastra {/* #existing-non-mastra-projects */}

Si vous avez déjà une application, telle qu’une application Next.js, mais n’avez pas encore ajouté Mastra, exécutez `mastra init` et activez Mastra Observability lorsque vous y êtes invité :

```bash npm2yarn
npx mastra init
```

La CLI peut sélectionner un projet de plateforme existant ou en créer un nouveau.

### Configuration manuelle {/* #manual-setup */}

Créez un projet dans [Mastra Platform](https://projects.mastra.ai), ajoutez `MASTRA_PLATFORM_ACCESS_TOKEN` et `MASTRA_PROJECT_ID` à `.env`, puis enregistrez `MastraPlatformExporter` dans votre configuration Mastra. Ajoutez `MastraStorageExporter` si vous souhaitez également conserver les événements d’observabilité dans le Mastra Storage configuré :

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Observability, MastraPlatformExporter } from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraPlatformExporter()],
      },
    },
  }),
})
```

Consultez la [configuration de la plateforme Mastra](/docs/mastra-platform/configuration#observability) pour connaître les variables d’environnement utilisées par l’observabilité de la plateforme.

## Interroger les données d’observabilité {/* #query-observability-data */}

Une fois que votre projet publie des traces, journaux ou scores vers Mastra Platform Observability, vous pouvez interroger ces données depuis votre terminal avec la CLI Mastra ou avec `curl`.

```bash npm2yarn
npx mastra api trace list
```

Pour les commandes d’observabilité, la CLI cible l’API d’observabilité hébergée et peut déduire les identifiants de l’environnement de votre projet. Consultez la [référence de la CLI `mastra api`](/reference/cli/mastra#mastra-api) pour connaître les commandes d’observabilité disponibles, le filtrage, la pagination, la résolution des identifiants et les exemples directs avec `curl`.
