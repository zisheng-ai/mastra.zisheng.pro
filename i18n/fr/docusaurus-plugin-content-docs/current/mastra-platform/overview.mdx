# Plateforme Mastra

La [plateforme Mastra](https://projects.mastra.ai) propose trois produits pour déployer, surveiller et gérer des applications d'IA créées avec le framework Mastra :

- [**Observability**](/docs/mastra-platform/observability) : Le produit de base pour chaque projet de la plateforme, avec des traces, des journaux et des métriques consultables dans l'ensemble des projets et des déploiements Mastra
- [**Studio**](/docs/mastra-platform/studio) : Un environnement visuel hébergé pour tester des agents et exécuter des workflows, avec des tools permettant d'inspecter les traces. Commencer avec Studio vous donne également accès à Observability.
- [**Server**](/docs/mastra-platform/server) : Une cible de déploiement en production qui exécute votre application Mastra en tant que serveur API. Commencer avec Server vous donne également accès à Observability.

Déployez avec une seule commande, [`mastra deploy`](/docs/mastra-platform/deploy), ou connectez un dépôt GitHub pour effectuer un déploiement par push. Consultez l'[intégration GitHub](/docs/mastra-platform/github) pour le flux associé à un dépôt.

Chaque projet peut exécuter plusieurs [**environnements**](/docs/mastra-platform/environments) (par exemple `production` et `staging`), provisionner des [**bases de données hébergées**](/docs/mastra-platform/database) depuis la CLI ou les paramètres du projet afin de conserver les données de l'application, et obtenir un [**workspace**](/docs/mastra-platform/workspaces) géré par environnement qui offre aux agents un système de fichiers et un sandbox sans configuration manuelle.

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) identifie les objectifs, résultats, comportements et sentiments récurrents dans les traces de vos agents. Trace Intelligence est disponible en bêta privée pour certains projets sélectionnés.

## Premiers pas

Choisissez le parcours qui correspond à ce que vous souhaitez faire :

- **Ajouter l'observabilité hébergée** : Utilisez [Observability](/docs/mastra-platform/observability) pour collecter des traces, des journaux et des métriques consultables
  dans l'ensemble des projets et des déploiements. Commencez ici si vous souhaitez bénéficier de la surveillance sans déployer d'abord Studio ou Server.
- **Déployer Studio** : Utilisez [Studio](/docs/mastra-platform/studio) pour héberger l'environnement de développement visuel de votre équipe. Commencez ici si vous
  souhaitez une interface utilisateur partagée pour tester les agents, exécuter les workflows et inspecter les traces.
- **Déployer Server** : Utilisez [Server](/docs/mastra-platform/server) pour exécuter votre application Mastra en tant que serveur API de production. Commencez ici lorsque
  vous êtes prêt à fournir des agents, des tools et des workflows depuis le cloud.

## Concepts clés

Les **projets** constituent l'entité parente partagée par tous les produits. Un seul projet peut inclure tous les produits : Observability, Studio et Server. Les projets appartiennent à une **organisation**, qui est le conteneur mutualisé de votre équipe.

Votre application Mastra repose sur trois éléments fondamentaux :

- [Agents](/docs/agents/overview) : Des agents d'IA capables d'utiliser des tools, de suivre des instructions et de conserver le contexte
- [Tools](/docs/agents/using-tools) : Des fonctions appelables et des intégrations à la disposition de vos agents
- [Workflows](/docs/workflows/overview) : Des pipelines d'orchestration en plusieurs étapes qui coordonnent les agents et les tools

## Passage en production

Développez votre projet localement avec [`mastra dev`](/reference/cli/mastra#mastra-dev) et ouvrez [Studio](/docs/studio/overview) pour tester vos agents, workflows et tools dans un environnement visuel.

Lorsque vous êtes prêt à déployer votre application en production, exécutez [`mastra deploy`](/reference/cli/mastra#mastra-deploy) pour envoyer votre application dans le cloud.

Consultez la documentation [Deploy](/docs/mastra-platform/deploy) pour obtenir des instructions étape par étape.

Si vous hébergez votre application Mastra sur votre propre infrastructure, vous pouvez toujours envoyer des données d'observabilité à la plateforme Mastra à l'aide de [MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform).
