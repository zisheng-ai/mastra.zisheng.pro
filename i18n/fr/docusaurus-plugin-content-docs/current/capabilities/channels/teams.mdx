# Microsoft Teams

Les canaux Microsoft Teams permettent à un Agent Mastra de recevoir des mentions et des événements de conversation depuis Teams. Mastra gère le raccordement de l’Agent et la route de webhook ; la documentation de l’adaptateur Teams du Chat SDK couvre la configuration de l’application Teams, l’authentification et les autorisations.

## Installer l’adaptateur {/* #install-the-adapter */}

Installez l’adaptateur Teams depuis le Chat SDK :

```bash npm2yarn
npm install @chat-adapter/teams
```

## Configuration de l’Agent {/* #agent-configuration */}

Ajoutez `createTeamsAdapter()` à l’objet `channels.adapters` de l’Agent :

```typescript title="src/mastra/agents/teams-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTeamsAdapter } from '@chat-adapter/teams'

export const teamsAgent = new Agent({
  id: 'teams-agent',
  name: 'Teams Agent',
  instructions: 'Answer questions and help with tasks in Microsoft Teams.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      teams: createTeamsAdapter({
        appType: 'SingleTenant',
      }),
    },
  },
})
```

Enregistrez l’Agent sur l’instance Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { teamsAgent } from './agents/teams-agent'

export const mastra = new Mastra({
  agents: { teamsAgent },
})
```

## Configuration de l’adaptateur {/* #adapter-setup */}

Consultez la [documentation de l’adaptateur Teams du Chat SDK](https://chat-sdk.dev/adapters/official/teams) pour la configuration propre à Teams, notamment l’enregistrement du bot Azure, l’utilisation de Teams CLI, les options d’authentification et les autorisations requises.

L’adaptateur lit les identifiants Teams depuis des variables d’environnement telles que :

```bash title=".env"
TEAMS_APP_ID=your-azure-bot-app-id
TEAMS_APP_PASSWORD=your-azure-bot-app-password
TEAMS_APP_TENANT_ID=your-azure-tenant-id
```

## URL du webhook {/* #webhook-url */}

Mastra génère la route de webhook Teams à partir de l’ID de l’Agent et de la clé de l’adaptateur :

```text
/api/agents/teams-agent/channels/teams/webhook
```

Utilisez l’URL publique de votre serveur Mastra comme URL de base :

```text
https://your-app.example.com/api/agents/teams-agent/channels/teams/webhook
```

Utilisez cette URL partout où la documentation de l’adaptateur Teams demande le point de terminaison du bot ou l’URL du webhook. Pour le développement local, exposez le serveur de développement Mastra avec un tunnel et utilisez l’URL du tunnel comme URL de base.
