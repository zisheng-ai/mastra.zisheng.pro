# Telegram

Les canaux Telegram permettent à un Agent Mastra de recevoir des messages directs, des messages de groupe et des mentions de bot depuis Telegram. Mastra gère le raccordement de l’Agent et la route de webhook ; la documentation de l’adaptateur Telegram du Chat SDK couvre la configuration du bot, l’enregistrement du webhook et le comportement de polling.

## Installer l’adaptateur {/* #install-the-adapter */}

Installez l’adaptateur Telegram depuis le Chat SDK :

```bash npm2yarn
npm install @chat-adapter/telegram
```

## Configuration de l’Agent {/* #agent-configuration */}

Ajoutez `createTelegramAdapter()` à l’objet `channels.adapters` de l’Agent :

```typescript title="src/mastra/agents/telegram-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTelegramAdapter } from '@chat-adapter/telegram'

export const telegramAgent = new Agent({
  id: 'telegram-agent',
  name: 'Telegram Agent',
  instructions: 'Answer questions and help with tasks in Telegram.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      telegram: createTelegramAdapter(),
    },
  },
})
```

Enregistrez l’Agent sur l’instance Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { telegramAgent } from './agents/telegram-agent'

export const mastra = new Mastra({
  agents: { telegramAgent },
})
```

## Configuration de l’adaptateur {/* #adapter-setup */}

Consultez la [documentation de l’adaptateur Telegram du Chat SDK](https://chat-sdk.dev/adapters/official/telegram) pour la configuration propre à Telegram, notamment BotFather, l’enregistrement du webhook, les jetons secrets et le mode polling.

L’adaptateur lit les identifiants Telegram depuis des variables d’environnement telles que :

```bash title=".env"
TELEGRAM_BOT_TOKEN=your-telegram-bot-token
TELEGRAM_WEBHOOK_SECRET_TOKEN=your-webhook-secret-token
TELEGRAM_BOT_USERNAME=your_bot_username
```

## URL du webhook {/* #webhook-url */}

Mastra génère la route de webhook Telegram à partir de l’ID de l’Agent et de la clé de l’adaptateur :

```text
/api/agents/telegram-agent/channels/telegram/webhook
```

Utilisez l’URL publique de votre serveur Mastra comme URL de base :

```text
https://your-app.example.com/api/agents/telegram-agent/channels/telegram/webhook
```

Utilisez cette URL partout où la documentation de l’adaptateur Telegram demande l’URL du webhook. Telegram prend aussi en charge le mode polling ; consultez la documentation de l’adaptateur Chat SDK si vous souhaitez utiliser le polling en développement local.
