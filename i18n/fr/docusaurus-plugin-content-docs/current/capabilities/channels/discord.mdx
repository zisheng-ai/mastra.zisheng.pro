# Discord

Les channels Discord permettent à un agent Mastra de recevoir les interactions Discord et les messages de bot. Mastra gère le câblage de l’agent et la route de webhook ; la documentation de l’adaptateur Discord de Chat SDK couvre la configuration de l’application Discord, les autorisations du bot et le comportement de Gateway.

## Installer l’adaptateur {/* #install-the-adapter */}

Installez l’adaptateur Discord depuis Chat SDK :

```bash npm2yarn
npm install @chat-adapter/discord
```

## Configuration de l’agent {/* #agent-configuration */}

Ajoutez `createDiscordAdapter()` à l’objet `channels.adapters` de l’agent :

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createDiscordAdapter } from '@chat-adapter/discord'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord Agent',
  instructions: 'Answer questions and help with tasks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      discord: createDiscordAdapter(),
    },
  },
})
```

Enregistrez l’agent dans l’instance Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { discordAgent } from './agents/discord-agent'

export const mastra = new Mastra({
  agents: { discordAgent },
})
```

## Configuration de l’adaptateur {/* #adapter-setup */}

Suivez la [documentation de l’adaptateur Discord de Chat SDK](https://chat-sdk.dev/adapters/official/discord) pour la configuration propre à Discord, notamment la création d’application, les tokens de bot, les endpoints d’interaction, les autorisations et le comportement de Gateway.

L’adaptateur lit les identifiants Discord depuis des variables d’environnement telles que :

```bash title=".env"
DISCORD_BOT_TOKEN=your-discord-bot-token
DISCORD_PUBLIC_KEY=your-discord-application-public-key
DISCORD_APPLICATION_ID=your-discord-application-id
```

## URL du webhook {/* #webhook-url */}

Mastra génère la route de webhook Discord à partir de l’ID de l’agent et de la clé de l’adaptateur :

```text
/api/agents/discord-agent/channels/discord/webhook
```

Utilisez l’URL publique de votre serveur Mastra comme URL de base :

```text
https://your-app.example.com/api/agents/discord-agent/channels/discord/webhook
```

Utilisez cette URL partout où la documentation de l’adaptateur Discord demande l’endpoint des interactions ou l’URL du webhook. Les événements de messages Discord ordinaires peuvent nécessiter une configuration Gateway en dehors de la route de webhook générée ; suivez la documentation de l’adaptateur Chat SDK pour cette procédure.
