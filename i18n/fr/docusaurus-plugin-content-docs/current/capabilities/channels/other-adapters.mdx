# Autres adaptateurs

Les channels Mastra utilisent des adaptateurs Chat SDK ; les pages de cette section ne constituent donc pas la liste complète des plateformes prises en charge. Utilisez tout adaptateur de plateforme Chat SDK qui exporte une factory d’adaptateur compatible avec `channels.adapters`.

## Catalogue d’adaptateurs

Le [catalogue d’adaptateurs Chat SDK](https://chat-sdk.dev/adapters) est la source de référence des adaptateurs disponibles. La liste ci-dessous n’est qu’un aperçu et peut ne pas toujours être à jour.

Au moment de la rédaction, Chat SDK répertorie des adaptateurs pour :

- Google Chat

- Matrix

- X
- Zalo

Consultez la documentation de l’adaptateur pour connaître son nom de package, ses variables d’identifiants, les exigences de webhook et le comportement propre à la plateforme.

## Utiliser le même câblage Mastra

La partie Mastra de chaque adaptateur Chat SDK suit la même configuration. Installez le package de l’adaptateur et ajoutez sa factory à `channels.adapters`. Configurez ensuite les identifiants de la plateforme et dirigez son webhook vers la route Mastra générée.

Utilisez l’une des pages de plateforme de cette section comme référence pour le câblage Mastra :

- [Slack](/docs/capabilities/channels/slack)
- [Microsoft Teams](/docs/capabilities/channels/teams)
- [Discord](/docs/capabilities/channels/discord)
- [Telegram](/docs/capabilities/channels/telegram)
- [WhatsApp](/docs/capabilities/channels/whatsapp)

## Éléments à vérifier dans la documentation de l’adaptateur

Avant de raccorder un nouvel adaptateur à Mastra, vérifiez dans sa documentation :

- Les variables d’environnement d’identifiants.
- Les autorisations ou scopes requis par la plateforme.
- Le comportement de vérification des webhooks.
- Si la plateforme a besoin de routes distinctes pour la configuration, les événements ou les interactions.
- Si les messages courants nécessitent des listeners de longue durée ou un polling.
- La prise en charge des pièces jointes, cartes et messages enrichis.
