# WhatsApp

Les channels WhatsApp permettent à un agent Mastra de recevoir les messages des clients via WhatsApp Business Cloud. Mastra gère le câblage de l’agent et la route de webhook ; la documentation de l’adaptateur WhatsApp de Chat SDK couvre la configuration de l’application Meta, les identifiants et la configuration du webhook.

## Installer l’adaptateur

Installez l’adaptateur WhatsApp depuis Chat SDK :

```bash npm2yarn
npm install @chat-adapter/whatsapp
```

## Configuration de l’agent

Ajoutez `createWhatsAppAdapter()` à l’objet `channels.adapters` de l’agent :

```typescript title="src/mastra/agents/whatsapp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createWhatsAppAdapter } from '@chat-adapter/whatsapp'

export const whatsappAgent = new Agent({
  id: 'whatsapp-agent',
  name: 'WhatsApp Agent',
  instructions: 'Answer customer questions and help with tasks in WhatsApp.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      whatsapp: createWhatsAppAdapter(),
    },
  },
})
```

Enregistrez l’agent dans l’instance Mastra :

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { whatsappAgent } from './agents/whatsapp-agent'

export const mastra = new Mastra({
  agents: { whatsappAgent },
})
```

## Configuration de l’adaptateur

Suivez la [documentation de l’adaptateur WhatsApp de Chat SDK](https://chat-sdk.dev/adapters/official/whatsapp) pour la configuration propre à WhatsApp, notamment celle de l’application Meta, les tokens d’accès, les ID de numéros de téléphone, la vérification de webhook et les limites de messages.

L’adaptateur lit les identifiants WhatsApp depuis des variables d’environnement telles que :

```bash title=".env"
WHATSAPP_ACCESS_TOKEN=your-meta-access-token
WHATSAPP_APP_SECRET=your-meta-app-secret
WHATSAPP_PHONE_NUMBER_ID=your-whatsapp-phone-number-id
WHATSAPP_VERIFY_TOKEN=your-webhook-verify-token
```

## URL du webhook

Mastra génère la route de webhook WhatsApp à partir de l’ID de l’agent et de la clé de l’adaptateur :

```text
/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

Utilisez l’URL publique de votre serveur Mastra comme URL de base :

```text
https://your-app.example.com/api/agents/whatsapp-agent/channels/whatsapp/webhook
```

Utilisez cette URL pour la livraison des événements WhatsApp entrants. La route Mastra générée gère les événements POST provenant de WhatsApp ; suivez la documentation de l’adaptateur WhatsApp de Chat SDK pour le flux de rappel Meta et de vérification du webhook.
