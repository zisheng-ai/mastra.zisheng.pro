# FirecrawlBrowser 類別 {/* #firecrawlbrowser-class */}

`FirecrawlBrowser` 類別提供由 [Firecrawl Browser Sandbox](https://docs.firecrawl.dev/features/browser) 支援的瀏覽器自動化功能。它會透過 Firecrawl API 建立遠端瀏覽器工作階段，並使用 Chrome DevTools Protocol (CDP) 連線。

`FirecrawlBrowser` 擴充了 [`AgentBrowser`](/reference/browser/agent-browser)，並提供相同的確定性 Tool 集。想使用託管瀏覽器工作階段，而非在本機安裝 Chromium 時，請使用它。如需本機自動化，請參閱 [`AgentBrowser`](/reference/browser/agent-browser)。如需使用自然語言的 AI 互動，請參閱 [`StagehandBrowser`](/reference/browser/stagehand-browser)。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { FirecrawlBrowser } from '@mastra/browser-firecrawl'

const browser = new FirecrawlBrowser({
  apiKey: process.env.FIRECRAWL_API_KEY,
  firecrawl: {
    ttl: 600,
  },
})

export const browserAgent = new Agent({
  id: 'browser-agent',
  name: 'Browser Agent',
  instructions: `You can browse the web. Use browser_snapshot to see the page structure,
then interact with elements using their refs (e.g., @e5).`,
  model: '__GATEWAY_OPENAI_MODEL__',
  browser,
})
```

## 工作階段生命週期 {/* #session-lifecycle */}

工作階段的建立方式取決於從 `AgentBrowser` 繼承的 `scope` 選項：

- `'thread'`（預設）：每個對話執行緒都有自己的 Firecrawl Sandbox 工作階段。工作階段會在首次使用時建立，並在該執行緒的瀏覽器工作階段銷毀時刪除。
- `'shared'`：瀏覽器啟動時會建立一個 Firecrawl Sandbox 工作階段，供所有執行緒共用。瀏覽器關閉時，工作階段亦會刪除。

無論是哪種情況，瀏覽器關閉時，`FirecrawlBrowser` 都會刪除遠端 Firecrawl 工作階段；即使建立工作階段或連線期間發生失敗，亦會如此。

## Tool {/* #tools */}

`FirecrawlBrowser` 提供與 `AgentBrowser` 相同的 Tool 集，包括 `browser_goto`、`browser_snapshot`、`browser_click`、`browser_type` 及 `browser_screenshot`。如需完整清單及 Tool 參數，請參閱 [`AgentBrowser` Tool 參考](/reference/browser/agent-browser)。
