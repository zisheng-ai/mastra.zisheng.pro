# mountAgentControllerOnMastra()

:::experimental

`@mastra/code-sdk` 套件屬實驗性質，次要版本可能包含重大變更。

:::

`mountAgentControllerOnMastra()` 函數會建立 Mastra Code Agent 控制器（即 [`mastracode`](https://www.npmjs.com/package/mastracode) CLI 背後的編程 Agent，並包含其模式、Tool、記憶及對話串管理功能），並將其註冊至由伺服器擁有的 [Mastra](/reference/core/mastra-class) 實例。你可用此函數將 Mastra Code Agent 提供予自己的介面（網頁應用程式、編輯器或機械人）：每個用戶端都可透過傳回的 [`AgentController`](/reference/agent-controller/agent-controller-class)，建立或恢復各自獨立的工作階段。

如要自行建構 `Mastra` 實例（例如在可部署的入口檔案中），請使用同一套件的 `prepareAgentControllerMount()`。它會傳回建構函數參數及 `finalize()` 回呼函數。

## 使用範例

```typescript title="src/mastra/index.ts"
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const { mastra, controller } = await mountAgentControllerOnMastra({
  cwd: process.cwd(),
})

// Each client drives its own session
const session = await controller.createSession({ resourceId: 'user-123' })
```

傳入現有的 `mastra`，即可將控制器掛載至已託管其他基本元件的 Mastra 實例：

```typescript
import { Mastra } from '@mastra/core/mastra'
import { mountAgentControllerOnMastra } from '@mastra/code-sdk'

const mastra = new Mastra({/* ... */})

const { controller } = await mountAgentControllerOnMastra({ mastra })
```
