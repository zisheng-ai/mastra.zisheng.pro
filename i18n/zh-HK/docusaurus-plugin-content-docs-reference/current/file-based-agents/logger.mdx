# Logger

Mastra 會透過 `src/mastra/` 直屬的 `logger.ts` 檔案設定項目的 [logger](/docs/observability/logging)。該檔案會預設匯出一個 logger，取代 Agent、Workflow 及其他元件所使用的內置 `ConsoleLogger`。

本頁說明檔案式慣例。如需了解日誌層級、傳輸方式及 Provider 詳情，請參閱[日誌記錄](/docs/observability/logging)。

## 快速開始 {/* #quickstart */}

建立 `src/mastra/logger.ts`，並預設匯出一個 logger，例如 [`PinoLogger`](/reference/logging/pino-logger)：

```typescript title="src/mastra/logger.ts"
import { PinoLogger } from '@mastra/loggers'

export default new PinoLogger({
  name: 'Mastra',
  level: 'info',
})
```

Mastra 會先註冊 logger，然後才註冊儲存空間、可觀測性及檔案式 Agent，因此連接這些基礎功能時，都會透過此 logger 記錄日誌。

## 與程式碼設定的優先次序 {/* #precedence-with-code */}

以程式碼註冊的日誌設定優先於 `logger.ts`。如果你在 `src/mastra/index.ts` 中將 `logger` 傳給 `new Mastra({ logger })`（或設定 `logger: false` 停用日誌記錄），系統會忽略 `logger.ts` 並顯示警告。如果整個項目使用一個 logger 已足夠，請使用 `logger.ts`；如果設定取決於執行階段的連接方式，請使用程式碼註冊。
