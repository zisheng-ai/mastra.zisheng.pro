# 儲存空間

Mastra 會透過 `src/mastra/` 直屬的 `storage.ts` 檔案設定項目的預設[儲存空間](/docs/storage/overview)。該檔案會預設匯出一個儲存空間，取代記憶體、Workflow、可觀測性及其他儲存領域所使用的內置記憶體內儲存空間。

本頁說明檔案式慣例。如需了解後端選擇、儲存領域、保留政策及 Provider 詳情，請參閱[儲存空間概覽](/docs/storage/overview)。

## 快速開始 {/* #quickstart */}

使用 [`LibSQLStore`](/reference/storage/libsql) 建立由本機檔案支援的儲存空間：

```typescript title="src/mastra/storage.ts"
import { LibSQLStore } from '@mastra/libsql'

export default new LibSQLStore({
  id: 'mastra-storage',
  url: 'file:./mastra.db',
})
```

Mastra 會先註冊此儲存空間，然後才註冊檔案式 Agent 和 Workflow，因此依賴儲存空間的基礎功能會連接至此儲存空間，而非預設的記憶體內儲存空間。

## 生產環境後端 {/* #production-backends */}

`storage.ts` 可以匯出任何 Mastra 儲存適配器，例如 LibSQL、PostgreSQL 或 MongoDB。如需設定模式、Provider 支援及結構描述詳情，請參閱[儲存空間概覽](/docs/storage/overview)、[可觀測性訊號支援](/docs/observability/overview#signal-support)及[儲存空間參考](/reference/storage/overview)。

## 與程式碼設定的優先次序 {/* #precedence-with-code */}

以程式碼註冊的儲存空間優先於 `storage.ts`。如果整個項目使用一個儲存空間已足夠，請使用 `storage.ts`；如果設定取決於 `src/mastra/index.ts` 中的執行階段連接方式，請使用程式碼註冊。
