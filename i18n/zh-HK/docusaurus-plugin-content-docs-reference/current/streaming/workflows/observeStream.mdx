# Run.observeStream() {/* #runobservestream */}

`.observeStream()` 方法會為目前正在執行的 Workflow run 開啟新的 `ReadableStream`，讓你在原有串流已無法使用時，仍可觀察事件串流。

## 使用範例 {/* #usage-example */}

```typescript
const run = await workflow.createRun()

run.stream({
  inputData: {
    value: 'initial data',
  },
})

const stream = await run.observeStream()

for await (const chunk of stream) {
  console.log(chunk)
}
```

## 傳回值 {/* #returns */}

`ReadableStream<ChunkType>`

## 串流事件 {/* #stream-events */}

串流會在 Workflow 執行期間發出不同類型的事件。每個事件都有一個 `type` 欄位，以及包含相關資料的 `payload`：

- **`workflow-start`**：Workflow 開始執行
- **`workflow-step-start`**：步驟開始執行
- **`workflow-step-output`**：步驟的自訂輸出
- **`workflow-step-result`**：步驟完成並產生結果
- **`workflow-finish`**：Workflow 執行完成，並附有用量統計資料。執行成功時，`payload.finalWorkflowResult` 會包含 Workflow 的最終結果
