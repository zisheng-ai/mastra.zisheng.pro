# dataset.getDetails()

**新增於：** `@mastra/core@1.4.0`

從儲存空間取得完整資料集記錄，包括元資料、結構描述及版本資料。

## 使用範例 {/* #usage-example */}

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

const dataset = await mastra.datasets.get({ id: 'dataset-id' })

// Get dataset details
const details = await dataset.getDetails()
console.log(details.name, details.version)
```

## 參數 {/* #parameters */}

此方法不接受任何參數。

## 傳回值 {/* #returns */}

傳回 `Promise<DatasetRecord>`。如果找不到資料集，便會拋出 `MastraError`。
