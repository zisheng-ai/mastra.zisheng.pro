# API 參考

## 會員 API

以下 endpoint 的根 URL 是：`/v1/org/members`

| 方法 | Endpoint | 說明 |
| - | - | - |
| GET | `/` | 列出會員 |
| POST | `/invitations` | 傳送邀請 |
| GET | `/invitations` | 列出邀請 |
| DELETE | `/invitations/:id` | 撤銷邀請 |
| PATCH | `/:id` | 更新會員角色 |
| DELETE | `/:id` | 移除會員 |

## API 權杖

以下 endpoint 的根 URL 是：`/v1/auth/tokens`

| 方法 | Endpoint | 說明 |
| - | - | - |
| POST | `/` | 建立 API 權杖 |
| GET | `/` | 列出 API 權杖 |
| DELETE | `/:id` | 刪除 API 權杖 |

## Studio API

以下 endpoint 的根 URL 是：`/v1/studio`

| 方法 | Endpoint | 說明 |
| - | - | - |
| GET | `/projects` | 列出 Studio 項目 |
| POST | `/projects` | 建立項目 |
| GET | `/projects/:id` | 取得項目詳情及部署記錄 |
| DELETE | `/projects/:id` | 刪除項目 |
| POST | `/deploys` | 建立部署 |
| POST | `/deploys/:id/upload-complete` | 確認成品上載完成 |
| GET | `/deploys/:id` | 取得部署狀態 |
| GET | `/deploys/:id/logs` | 取得部署日誌 |
| GET | `/deploys/:id/logs/stream` | 串流傳送部署日誌（SSE） |

## 伺服器 API

以下 endpoint 的根 URL 是：`/v1/server`

| 方法 | Endpoint | 說明 |
| - | - | - |
| GET | `/projects` | 列出伺服器項目 |
| POST | `/projects` | 建立項目 |
| GET | `/projects/:id` | 取得項目詳情 |
| DELETE | `/projects/:id` | 刪除項目 |
| PUT | `/projects/:id/env` | 設定環境變數 |
| GET | `/projects/:id/env` | 取得環境變數 |
| POST | `/projects/:id/env/restart` | 在環境變數變更後重新啟動 |
| GET | `/projects/:id/domains` | 列出網域 |
| POST | `/projects/:id/domains` | 新增自訂網域 |
| GET | `/projects/:id/runtime-logs` | 取得執行階段日誌 |
| POST | `/projects/:id/redeploy` | 觸發重新部署 |
| POST | `/projects/:id/always-on` | 啟用常時運行 |
| DELETE | `/projects/:id/always-on` | 停用常時運行 |
| POST | `/deploys` | 建立部署 |
| POST | `/deploys/:id/upload-complete` | 確認成品上載完成 |
| GET | `/deploys/:id` | 取得部署狀態 |
| GET | `/deploys/:id/logs` | 取得部署日誌 |
| POST | `/deploys/:id/cancel` | 取消排隊中或進行中的部署 |
| DELETE | `/deploys/:id` | 停止執行中的部署 |

## Gateway API

以下 endpoint 的根 URL 是：`/v1/gateway`

| 方法 | Endpoint | 說明 |
| - | - | - |
| GET | `/projects` | 列出 Gateway 項目 |
| GET | `/projects/:id` | 取得項目詳情 |
| PATCH | `/projects/:id` | 更新項目設定 |
| DELETE | `/projects/:id` | 刪除項目 |
| POST | `/projects/provision` | 佈建新的 Gateway 項目 |
| GET | `/projects/:id/keys` | 列出 API 金鑰 |
| POST | `/projects/:id/keys` | 建立 API 金鑰 |
| DELETE | `/projects/:id/keys/:keyId` | 撤銷 API 金鑰 |
| GET | `/projects/:id/keys/:keyId/bindings` | 列出金鑰層級的 Provider 綁定 |
| POST | `/projects/:id/keys/:keyId/bindings` | 新增金鑰層級的 Provider 綁定（BYOK） |
| DELETE | `/projects/:id/keys/:keyId/bindings/:provider` | 移除金鑰層級的綁定 |
| GET | `/projects/:id/bindings` | 列出項目層級的 Provider 綁定 |
| POST | `/projects/:id/bindings` | 新增項目層級的 Provider 綁定（BYOK） |
| DELETE | `/projects/:id/bindings/:provider` | 移除項目層級的綁定 |
| GET | `/projects/:id/usage/has-activity` | 檢查項目是否收到任何請求 |
| GET | `/projects/:id/usage/activity` | 取得彙總用量活動 |
| GET | `/projects/:id/usage/memory-activity` | 取得一段時間內的記憶體 token 總數 |
| GET | `/projects/:id/usage/logs` | 取得請求日誌 |
| GET | `/projects/:id/usage/logs/facets` | 取得日誌篩選面向 |
| GET | `/projects/:id/usage/logs/:requestId` | 取得指定請求的詳情 |
| GET | `/projects/:id/memory/threads` | 列出 thread（儀表板） |
| POST | `/projects/:id/memory/threads` | 建立 thread（儀表板） |
| GET | `/projects/:id/memory/threads/:threadId` | 取得 thread（儀表板） |
| PATCH | `/projects/:id/memory/threads/:threadId` | 更新 thread（儀表板） |
| DELETE | `/projects/:id/memory/threads/:threadId` | 刪除 thread（儀表板） |
| POST | `/projects/:id/memory/threads/:threadId/clone` | 複製 thread（儀表板） |
| GET | `/projects/:id/memory/threads/:threadId/messages` | 列出訊息（儀表板） |
| POST | `/projects/:id/memory/threads/:threadId/messages` | 儲存訊息（儀表板） |
| DELETE | `/projects/:id/memory/threads/:threadId/messages` | 刪除訊息（儀表板） |
| GET | `/projects/:id/memory/threads/:threadId/observations/history` | 觀察記錄（儀表板） |
| GET | `/models` | 列出可用模型 |
