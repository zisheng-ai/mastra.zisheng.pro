# Mastra.getStorage() {/* #mastragetstorage */}

`.getStorage()` 方法用於擷取 Mastra 實例中已設定的儲存空間實例。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getStorage()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
