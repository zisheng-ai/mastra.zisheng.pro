# Mastra.setLogger()

`.setLogger()` 方法用於為 Mastra 實例中的所有組件（Agent、Workflow 等）設定日誌記錄器。此方法接受一個包含 logger 屬性的物件參數。

## 使用範例

```typescript
mastra.setLogger({ logger: new PinoLogger({ name: 'testLogger' }) })
```
