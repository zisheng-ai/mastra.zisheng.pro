# Mastra.listLogsByRunId()

`.listLogsByRunId()` 方法用於擷取特定 run ID 及 transport ID 的日誌。此方法需要已配置且支援 `listLogsByRunId` 操作的 logger。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listLogsByRunId({ runId: '123', transportId: '456' })
```
