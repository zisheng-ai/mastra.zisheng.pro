# Mastra.getAgent()

`.getAgent()` 方法用於擷取 Agent。此方法接受一個代表 Agent 名稱的 `string` 參數。

## 使用範例

```typescript
mastra.getAgent('testAgent')
```

## 參數

<PropertiesTable
  content={[
  {

  },
]}
/>
