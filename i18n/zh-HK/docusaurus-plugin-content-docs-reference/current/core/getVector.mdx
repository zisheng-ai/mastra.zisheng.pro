# Mastra.getVector()

`.getVector()` 方法用於按名稱擷取向量儲存。此方法接受一個代表向量儲存名稱的 `string` 參數。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getVector('testVectorStore')
```
