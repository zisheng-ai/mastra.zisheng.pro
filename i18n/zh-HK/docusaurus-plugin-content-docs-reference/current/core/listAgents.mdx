# Mastra.listAgents()

`.listAgents()` 方法用於擷取 Mastra 實例中所有已設定的 Agent。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listAgents()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
