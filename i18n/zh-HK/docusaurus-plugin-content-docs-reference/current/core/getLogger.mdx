# Mastra.getLogger()

`.getLogger()` 方法用於擷取 Mastra 實例中已設定的 logger 實例。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getLogger()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
