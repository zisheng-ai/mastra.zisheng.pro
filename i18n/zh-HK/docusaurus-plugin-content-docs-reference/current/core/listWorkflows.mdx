# Mastra.listWorkflows()

`.listWorkflows()` 方法用於擷取 Mastra 實例中所有已配置的 Workflow。此方法接受一個可選的選項物件。

## 使用範例 {/* #usage-example */}

```typescript
mastra.listWorkflows()
```
