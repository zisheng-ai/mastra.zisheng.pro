# listScorers()

`listScorers()` 方法傳回所有已在 Mastra 實例註冊的評分器。評分器用於評估 AI 輸出，並可在 Agent 生成或 Workflow 執行期間覆寫預設評分器。

## 使用範例 {/* #usage-example */}

```typescript
import { mastra } from './mastra'

// Get all registered scorers
const allScorers = mastra.listScorers()

// Access a specific scorer
const myScorer = allScorers.relevancyScorer
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
