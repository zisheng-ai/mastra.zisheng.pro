# Mastra.getServer() {/* #mastragetserver */}

`.getServer()` 方法用於擷取 Mastra 實例中已設定的伺服器設定。

## 使用範例 {/* #usage-example */}

```typescript
mastra.getServer()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
