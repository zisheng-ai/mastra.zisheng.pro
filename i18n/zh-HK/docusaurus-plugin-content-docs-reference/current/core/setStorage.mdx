# Mastra.setStorage() {/* #mastrasetstorage */}

`.setStorage()` 方法用於為 Mastra 實例設定儲存空間實例。此方法接受單一 `MastraCompositeStore` 參數。

## 使用範例 {/* #usage-example */}

```typescript
mastra.setStorage(
  new LibSQLStore({
    id: 'mastra-storage',
    url: ':memory:',
  }),
)
```
