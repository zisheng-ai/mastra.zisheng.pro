# Mastra.removeWorkspace() {/* #mastraremoveworkspace */}

`.removeWorkspace()` 方法會從 Mastra 執行階段登錄中移除 Workspace。傳入 `{ destroy: true }`，即可在移除 Workspace 前將其銷毀。

## 使用範例 {/* #usage-example */}

```typescript
await mastra.removeWorkspace('workspace-123', { destroy: true })
```

## 傳回值 {/* #returns */}

<PropertiesTable
  content={[
  {

當 `destroy` 為 `true` 且 `workspace.destroy()` 擲回錯誤時，呼叫會因該錯誤而被拒絕，而 Workspace 仍會保留在登錄中，讓呼叫者可再次嘗試清理。
