# SerializedMemoryConfig

`SerializedMemoryConfig` 是 [`Memory`](/reference/memory/memory-class) 設定中可序列化為 JSON 的子集，儲存於已保存的 agent 記錄上。runtime 會根據已設定的 `Mastra` instance 解析 vector 及 embedder ID，將其還原為 `Memory` instance。

這是 [`BuilderAgentDefaults.memory`](https://agent-builder.mastra.ai/reference/builder-agent-defaults) 及 `EditorAgentNamespace.create({ memory })` 所使用的類型。

## 使用範例

```typescript title="src/mastra/index.ts"
import { MastraEditor } from '@mastra/editor'

new MastraEditor({
  builder: {
    enabled: true,
    configuration: {
      agent: {
        memory: {
          observationalMemory: true,
          options: { lastMessages: 50 },
        },
      },
    },
  },
})
```
