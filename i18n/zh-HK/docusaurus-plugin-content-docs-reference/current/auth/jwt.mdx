# MastraJwtAuth 類別 {/* #mastrajwtauth-class */}

`MastraJwtAuth` 類別提供輕量的 Mastra 驗證機制，並使用 JSON Web Token（JWT）。此類別根據共享密鑰驗證傳入的請求，並透過 `auth` 選項與 Mastra 伺服器整合。

## 使用範例 {/* #usage-example */}

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraJwtAuth } from '@mastra/auth'

export const mastra = new Mastra({
  server: {
    auth: new MastraJwtAuth({
      secret: '<your-secret>',
    }),
  },
})
```
