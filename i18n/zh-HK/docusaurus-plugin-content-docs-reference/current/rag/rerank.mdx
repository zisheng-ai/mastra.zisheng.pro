# rerank()

`rerank()` 函數結合語意相關性、向量相似度及按位置評分，為向量搜尋結果提供進階重新排序功能。

```typescript
function rerank(
  results: QueryResult[],
  query: string,
  modelConfig: ModelConfig,
  options?: RerankerFunctionOptions,
): Promise<RerankResult[]>
```

## 使用範例

```typescript
import { rerank } from '@mastra/rag'

const model = '__GATEWAY_OPENAI_MODEL__'

const rerankedResults = await rerank(vectorSearchResults, 'How do I deploy to production?', model, {
  weights: {
    semantic: 0.5,
    vector: 0.3,
    position: 0.2,
  },
  topK: 3,
})
```

rerank 函數接受 Vercel AI SDK 的任何 LanguageModel。使用 Cohere 模型 `rerank-v3.5` 時，函數會自動使用 Cohere 的重新排序功能。

:::note

要讓語意評分在重新排序期間正常運作，每項結果都必須在其 `metadata.text` 欄位中包含文字內容。

:::
