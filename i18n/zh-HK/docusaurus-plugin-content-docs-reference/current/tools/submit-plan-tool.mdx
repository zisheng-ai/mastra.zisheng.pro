# submitPlanTool {/* #submitplantool */}

這是一個與 Agent 無關的內置 Tool，可提交實作計劃供用戶審閱。Agent 會將計劃寫入 markdown 檔案，並把檔案路徑傳給此 Tool。此 Tool 會暫停執行，直至用戶核准或拒絕計劃。

此 Tool 透過原生的 [Tool 暫停](/docs/agents/agent-approval#runtime-suspension-with-suspend)原語來暫停：它會呼叫 `suspend({ path })`，令 Agent 發出 `tool-call-suspended` 事件。主機會讀取計劃檔案並向用戶顯示，然後根據核准或拒絕結果恢復執行。

在 Agent 執行以外的環境執行時（沒有可用的 `suspend`），此 Tool 會傳回包含檔案路徑、清晰易讀的後備字串。

## 用法範例 {/* #usage-example */}

將 `submitPlanTool` 加入 Agent 的 Tool 集合：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { submitPlanTool } from '@mastra/core/tools'

const agent = new Agent({
  id: 'planner',
  name: 'Planner',
  instructions: 'Write a plan to a file before starting work, then submit it for approval.',
  model,
  tools: { submitPlanTool },
})
```

處理暫停並恢復執行：

```typescript title="src/run.ts"
import fs from 'node:fs'

const stream = await agent.stream('Refactor the auth module')

for await (const chunk of stream.fullStream) {
  if (chunk.type === 'tool-call-suspended' && chunk.payload.toolName === 'submit_plan') {
    const { path } = chunk.payload.suspendPayload
    const plan = fs.readFileSync(path, 'utf-8')
    console.log(plan)

    // Approve:
    const resumed = await agent.resumeStream({ action: 'approved' }, { runId: stream.runId })
    for await (const c of resumed.textStream) process.stdout.write(c)
  }
}
```

如要拒絕並提供意見：

```typescript
await agent.resumeStream(
  { action: 'rejected', feedback: 'Add error handling steps' },
  { runId: stream.runId },
)
```

## 核准行為 {/* #approval-behavior */}

- **已核准：** 此 Tool 會將 `"Plan approved. Proceed with implementation following the approved plan."` 傳回模型。
- **拒絕並提供意見：** 此 Tool 會傳回意見，並要求模型修改計劃後再次提交。
- **拒絕但沒有提供意見：** 此 Tool 會指示模型先等待用戶的下一則訊息，然後才修改計劃。

在 [AgentController](/docs/harness/agent-controller) 內使用時，計劃獲核准後，會由目前模式切換至 `transitionsTo` 設定的模式。如果未設定 `transitionsTo`，控制器會切換至其解析後的預設模式。詳情請參閱[模式](/docs/harness/agent-controller#switch-modes-and-models)。
