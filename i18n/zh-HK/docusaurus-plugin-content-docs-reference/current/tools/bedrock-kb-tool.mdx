# createBedrockKBTool()

`createBedrockKBTool()` 函數會建立一個 Tool，從 Amazon Bedrock Knowledge Base 擷取相關文件。它同時支援受管理搜尋配置及代理式擷取（查詢分解和受管理重新排序），並可自動回退至標準擷取。

## 使用範例 {/* #usage-example */}

```typescript
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
  region: 'us-west-2',
  numberOfResults: 5,
  useAgenticRetrieval: true,
})
```

### 配合 Agent 使用 {/* #with-an-agent */}

```typescript
import { Agent } from '@mastra/core/agent'
import { createBedrockKBTool } from '@mastra/rag'

const kbTool = createBedrockKBTool({
  knowledgeBaseId: 'YOUR_KB_ID',
})

const agent = new Agent({
  name: 'KnowledgeAssistant',
  instructions: 'Use the knowledge base tool to answer questions.',
  model: myModel,
  tools: { kb: kbTool },
})
```

### BedrockKBResult {/* #bedrockkbresult */}

| 欄位 | 類型 | 說明 |
| - | - | - |
| `content` | `string` | 所擷取段落的文字內容。 |
| `source` | `string \| undefined` | Bedrock 有提供時的來源 URI。只有當結果 metadata 包含 `_source_uri` 時，代理式擷取才會包含此欄位。 |
| `score` | `number \| undefined` | 標準擷取傳回的相關性分數。代理式 API 不會為結果項目傳回分數。 |
| `metadata` | `Record<string, unknown>` | 擷取結果的其他 metadata。 |

## 擷取模式 {/* #retrieval-modes */}

### 代理式擷取（預設） {/* #agentic-retrieval-default */}

當 `useAgenticRetrieval` 為 `true`（預設值）時，此 Tool 會使用 `AgenticRetrieveStreamCommand`，它會：

- 將複雜查詢分解為子查詢
- 分多輪擷取資料
- 套用受管理重新排序，以改善結果

如果代理式擷取失敗（例如 SDK 較舊或權限不足），它會自動回退至標準受管理擷取。

### 標準受管理擷取 {/* #standard-managed-retrieval */}

當 `useAgenticRetrieval` 為 `false` 時，此 Tool 會使用配備 `managedSearchConfiguration` 的 `RetrieveCommand` 直接執行單輪擷取。

## 以使用者為基礎的存取控制 {/* #user-based-access-control */}

在 Mastra 請求 context 中設定 `userId`，即可將其作為 Bedrock `userContext.userId` 轉送。這可支援強制執行文件層級存取控制的 Knowledge Base。請求 context 的值會覆寫此 Tool 上配置的預設 `userId`。

```typescript
import { RequestContext } from '@mastra/core/request-context'

const requestContext = new RequestContext()
requestContext.set('userId', 'user-123')

await agent.generate('Find my private documents', { requestContext })
```

## 所需 IAM 權限 {/* #required-iam-permissions */}

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["bedrock:Retrieve", "bedrock:AgenticRetrieveStream"],
      "Resource": "arn:aws:bedrock:*:*:knowledge-base/*"
    }
  ]
}
```

## SDK 要求 {/* #sdk-requirements */}

- `@aws-sdk/client-bedrock-agent-runtime` >= 3.1000（AgenticRetrieveStreamCommand 需要 \~3.1000+）
