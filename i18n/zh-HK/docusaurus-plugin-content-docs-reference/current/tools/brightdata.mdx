# Bright Data tools

`@mastra/brightdata` 套件將 [Bright Data SDK](https://github.com/brightdata/bright-data-sdk-node) 包裝成與 Mastra 相容的 Tool。它公開用於網絡搜尋和網頁擷取的工廠函數。每個函數都會傳回一個以 [`createTool()`](./create-tool) 建立並包含完整 Zod 輸入／輸出 Schema 的 Tool。

搜尋 Tool 由 Bright Data 的 [SERP API](https://brightdata.com/products/serp-api) 支援，而擷取 Tool 則由 [Web Unlocker](https://brightdata.com/products/web-unlocker) 支援。兩者都可繞過機械人偵測和 CAPTCHA。

## 安裝 {/* #installation */}

```sh npm2yarn
npm install @mastra/brightdata zod
```

## 快速開始 {/* #quick-start */}

使用 `createBrightDataTools()` 取得共用配置的兩個 Tool：

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()
// Or pass an explicit API key:
// const { webSearch, webFetch } = createBrightDataTools({ apiKey: 'brd-...' })
```

每個 Tool 也可以個別建立：

```typescript title="src/mastra/tools/index.ts"
import { createBrightDataSearchTool, createBrightDataFetchTool } from '@mastra/brightdata'

const searchTool = createBrightDataSearchTool()
const fetchTool = createBrightDataFetchTool({ apiKey: 'brd-...' })
```

所有 Tool 預設會從環境讀取 `BRIGHTDATA_API_TOKEN`。你可以明確傳入 `{ apiKey }` 來覆寫。

## `createBrightDataTools()` {/* #createbrightdatatools */}

傳回一個包含兩個共用配置 Tool 的物件。

```typescript
import { createBrightDataTools } from '@mastra/brightdata'

const tools = createBrightDataTools({ apiKey: 'brd-...' })
// tools.webSearch, tools.webFetch
```

**傳回：** `{ webSearch, webFetch }`

## `createBrightDataSearchTool()` {/* #createbrightdatasearchtool */}

建立一個透過 Bright Data SERP API 搜尋 Google 的 Tool。傳回已剖析的自然搜尋結果。

**Tool ID：** `brightdata-search`

const searchTool = createBrightDataSearchTool()

## Agent 範例 {/* #agent-example */}

以下範例示範一個結合搜尋和擷取功能的研究 Agent：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createBrightDataTools } from '@mastra/brightdata'

const { webSearch, webFetch } = createBrightDataTools()

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the search tool to find relevant pages, then use the fetch tool to read full Markdown content from the best results.',
  tools: {
    webSearch,
    webFetch,
  },
})
```
