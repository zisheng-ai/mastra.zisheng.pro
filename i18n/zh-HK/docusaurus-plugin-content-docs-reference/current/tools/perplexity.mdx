# Perplexity tools {/* #perplexity-tools */}

`@mastra/perplexity` 套件將 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 包裝成與 Mastra 相容的 Tool。它公開一個工廠函數，傳回以 [`createTool()`](./create-tool) 建立並附有完整 Zod 輸入／輸出 Schema 的 Tool。

如要使用由 Perplexity 驅動的聊天補全或代理式 Workflow，請使用 Mastra 內置的 [Perplexity 模型 Provider](/models/providers/perplexity) 或 [Perplexity Agent Provider](/models/providers/perplexity-agent)。它們與此 Search Tool 分開運作。

## 安裝 {/* #installation */}

安裝此套件及 Zod：

```sh npm2yarn
npm install @mastra/perplexity zod
```

## 使用範例 {/* #usage-example */}

以下範例使用預設配置建立搜尋 Tool。此 Tool 預設會從環境讀取 `PERPLEXITY_API_KEY`（並以 `PPLX_API_KEY` 作為後備）。明確傳入 `{ apiKey }` 即可覆寫。

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

如要明確傳入 API 金鑰：

```typescript title="src/mastra/tools/index.ts"
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool({ apiKey: 'pplx-...' })
```

## 方法 {/* #methods */}

### 工廠函數 {/* #factory-functions */}

#### `createPerplexityTools(config?)` {/* #createperplexitytoolsconfig */}

傳回一個包含所有 Perplexity tools 的物件，這些 Tool 共用所提供的配置。

```typescript
import { createPerplexityTools } from '@mastra/perplexity'

const tools = createPerplexityTools({ apiKey: 'pplx-...' })
// tools.perplexitySearch
```

傳回：`{ perplexitySearch }`

#### `createPerplexitySearchTool(config?)` {/* #createperplexitysearchtoolconfig */}

建立一個使用 Perplexity Search API 搜尋網絡的 Tool。傳回包含標題、URL、摘要和可選發佈日期的排序結果。

此 Tool 以 ID `perplexity-search` 註冊。

```typescript
import { createPerplexitySearchTool } from '@mastra/perplexity'

const searchTool = createPerplexitySearchTool()
```

## Agent 範例 {/* #agent-example */}

以下範例在 Agent 上註冊搜尋 Tool，讓它在回答前可擷取最新的網絡結果。

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createPerplexitySearchTool } from '@mastra/perplexity'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use the perplexity-search tool to find up-to-date information from the web before answering.',
  tools: {
    search: createPerplexitySearchTool(),
  },
})
```

## 環境變數 {/* #environment-variables */}

| 變數 | 說明 |
| - | - |
| `PERPLEXITY_API_KEY` | 你的 Perplexity API 金鑰。未有將 `apiKey` 傳入工廠函數時，會用作預設值。 |
| `PPLX_API_KEY` | 未有設定 `PERPLEXITY_API_KEY` 時使用的後備值。 |
