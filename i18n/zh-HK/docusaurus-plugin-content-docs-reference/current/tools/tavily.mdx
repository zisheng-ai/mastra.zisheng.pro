# Tavily tools

`@mastra/tavily` 套件將 [Tavily](https://app.tavily.com) API 封裝成與 Mastra 兼容的 tools。它提供用於搜尋、擷取、爬取及建立網站地圖的 factory functions。每個 function 都會傳回以 [`createTool()`](./create-tool) 建立的 Tool，並包含完整的 Zod 輸入／輸出 schema。

## 安裝

```sh npm2yarn
npm install @mastra/tavily @tavily/core zod
```

## 快速開始

使用 `createTavilyTools()` 以共用設定取得全部四個 tools：

```typescript title="src/mastra/tools/index.ts"
import { createTavilyTools } from '@mastra/tavily'

const tools = createTavilyTools()
// Or pass an explicit API key:
// const tools = createTavilyTools({ apiKey: 'tvly-...' })
```

每個 Tool 亦可個別建立：

```typescript title="src/mastra/tools/index.ts"
import { createTavilySearchTool, createTavilyExtractTool } from '@mastra/tavily'

const searchTool = createTavilySearchTool()
const extractTool = createTavilyExtractTool({ apiKey: 'tvly-...' })
```

所有 tools 預設會從環境讀取 `TAVILY_API_KEY`。你可以明確傳入 `{ apiKey }` 以覆寫此設定。

## `createTavilyTools()`

傳回包含全部四個 tools 並共用設定的 object。

```typescript
import { createTavilyTools } from '@mastra/tavily'

const tools = createTavilyTools({ apiKey: 'tvly-...' })
// tools.tavilySearch, tools.tavilyExtract, tools.tavilyCrawl, tools.tavilyMap
```

**傳回：** `{ tavilySearch, tavilyExtract, tavilyCrawl, tavilyMap }`

## Agent 範例

以下範例示範結合搜尋和擷取功能的研究 Agent：

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createTavilySearchTool, createTavilyExtractTool } from '@mastra/tavily'

const agent = new Agent({
  id: 'web-search-agent',
  name: 'Web Search Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a web search assistant. Use search tool to find relevant pages, then use extract tool to get full content from the best results.',
  tools: {
    search: createTavilySearchTool(),
    extract: createTavilyExtractTool(),
  },
})
```
