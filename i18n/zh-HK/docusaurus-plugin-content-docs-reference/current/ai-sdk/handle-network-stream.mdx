# handleNetworkStream()

:::warning[已棄用]

Agent 網絡已棄用，並會在日後版本中移除。請改用[監督 Agent](/docs/capabilities/subagents)，並配合 `agent.stream()` 或 `agent.generate()`。請參閱[遷移指南](/guides/migrations/network-to-supervisor)進行升級。

:::

這是一個與框架無關的處理器，用於以 AI SDK 兼容格式串流網絡執行。當你需要在 Hono 或 Mastra 自有的 [apiRoutes](/docs/server/custom-api-routes) 功能以外處理網絡串流時，可直接使用此函數。

`handleNetworkStream()` 會傳回一個 `ReadableStream`，你可以使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其包裝。

`handleNetworkStream()` 保留現有的 AI SDK v5／預設行為。如果你的應用程式以 AI SDK v6 型別為準，請傳入 `version: 'v6'`。

如要在 Mastra 伺服器內建立網絡路由，請使用 [`networkRoute()`](/reference/ai-sdk/network-route)。

## 使用範例

Next.js App Router 範例：

```typescript title="app/api/network/route.ts"
import { handleNetworkStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleNetworkStream({
    mastra,
    agentId: 'routingAgent',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
