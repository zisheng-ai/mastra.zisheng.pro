# networkRoute()

:::warning[已棄用]

Agent 網絡已棄用，並將於日後版本移除。請改用[監督 Agent](/docs/capabilities/subagents)，並配合 `agent.stream()` 或 `agent.generate()`。升級方法請參閱[遷移指南](/guides/migrations/network-to-supervisor)。

:::

建立網絡路由處理程式，使用 AI SDK 格式串流執行網絡。此函數會註冊一個 HTTP `POST` 端點，用於接收訊息、執行 Agent 網絡，並以 AI SDK 相容格式將回應串流傳回用戶端。Agent 網絡可讓路由 Agent 將工作委派給其他 Agent。你必須在[自訂 API 路由](/docs/server/custom-api-routes)中使用此函數。

如需與框架無關的處理程式，請使用 [`handleNetworkStream()`](/reference/ai-sdk/handle-network-stream)。

`networkRoute()` 會保留現有的 AI SDK v5／預設行為。如果你的應用程式以 AI SDK v6 型別定義，請傳入 `version: 'v6'`。

## 使用範例 {/* #usage-example */}

以下範例說明如何在 `/network` 端點設定網絡路由，並使用 ID 為 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

你亦可根據 `agentId` 使用執行階段定義的 Agent 路由。URL `/network/weatherAgent` 會解析為 ID 是 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { networkRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      networkRoute({
        path: '/network/:agentId',
      }),
    ],
  },
})
```

## 其他設定 {/* #additional-configuration */}

你可以使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自訂傳送至網絡路由的要求，例如向 Agent 傳入其他設定：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/network',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
