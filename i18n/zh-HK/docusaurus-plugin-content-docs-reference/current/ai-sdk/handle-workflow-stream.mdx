# handleWorkflowStream()

此處理程式與框架無關，能以 AI SDK 相容格式串流執行 Workflow。如需在 Hono 或 Mastra 本身的 [apiRoutes](/docs/server/custom-api-routes) 功能以外處理 Workflow 串流，請直接使用此函數。

`handleWorkflowStream()` 會傳回 `ReadableStream`，你可以使用 [`createUIMessageStreamResponse()`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/create-ui-message-stream-response) 將其封裝。

`handleWorkflowStream()` 會保留現有的 AI SDK v5／預設行為。如果你的應用程式以 AI SDK v6 型別定義，請傳入 `version: 'v6'`。

如果你想在 Mastra 伺服器內建立 Workflow 路由，請使用 [`workflowRoute()`](/reference/ai-sdk/workflow-route)。

:::tip Workflow 中的 Agent 串流

當 Workflow 步驟將 Agent 的串流傳送至 Workflow writer（例如 `await response.fullStream.pipeTo(writer)`）時，即使 Agent 在 Workflow 步驟內執行，其文字區塊和 Tool 呼叫亦會即時轉送至 UI 串流。

詳情請參閱 [Workflow 串流](/docs/workflows/overview#inspecting-workflow-stream-payloads)。

:::

## 使用範例

Next.js App Router 範例：

```typescript title="app/api/workflow/route.ts"
import { handleWorkflowStream } from '@mastra/ai-sdk'
import { createUIMessageStreamResponse } from 'ai'
import { mastra } from '@/src/mastra'

export async function POST(req: Request) {
  const params = await req.json()
  const stream = await handleWorkflowStream({
    mastra,
    workflowId: 'weatherWorkflow',
    params,
  })
  return createUIMessageStreamResponse({ stream })
}
```
