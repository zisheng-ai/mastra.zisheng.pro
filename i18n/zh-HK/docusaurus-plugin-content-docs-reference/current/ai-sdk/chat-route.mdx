# chatRoute()

建立聊天路由處理器，以 AI SDK 格式串流 Agent 對話。此函數會註冊 HTTP `POST` 端點；端點會接收訊息、執行 Agent，並以 AI SDK 相容格式將回應串流傳回 client。你必須在[自訂 API 路由](/docs/server/custom-api-routes)內使用此函數。

如需與框架無關的處理器，請使用 [`handleChatStream()`](/reference/ai-sdk/handle-chat-stream)。

`chatRoute()` 會保留現有的 AI SDK v5／預設行為。如果你的應用程式是按 AI SDK v6 定型，請傳入 `version: 'v6'`。

:::note 中斷連線時的行為

`chatRoute()` 會將連入請求的 `AbortSignal` 轉送至 `agent.stream()`。如果 client 中斷連線，Mastra 會中止正在進行的生成作業。

如果你希望伺服器在中斷連線後繼續生成並持久保存最終回應，請圍繞 `agent.stream()` 建立[自訂 API 路由](/docs/server/custom-api-routes#continue-generation-after-client-disconnect)，並對傳回的 `MastraModelOutput` 呼叫 `consumeStream()`。

:::

## 使用範例

以下範例說明如何在 `/chat` 端點設定聊天路由，並使用 ID 為 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat',
        agent: 'weatherAgent',
      }),
    ],
  },
})
```

你亦可根據 `agentId` 使用執行階段定義的 Agent 路由。URL `/chat/weatherAgent` 會解析至 ID 為 `weatherAgent` 的 Agent。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { chatRoute } from '@mastra/ai-sdk'

export const mastra = new Mastra({
  server: {
    apiRoutes: [
      chatRoute({
        path: '/chat/:agentId',
      }),
    ],
  },
})
```

## 其他設定

你可使用 [`prepareSendMessagesRequest`](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat#transport.default-chat-transport.prepare-send-messages-request) 自訂傳至聊天路由的請求，例如向 Agent 傳入額外設定：

```typescript
const { error, status, sendMessage, messages, regenerate, stop } = useChat({
  transport: new DefaultChatTransport({
    api: 'http://localhost:4111/chat',
    prepareSendMessagesRequest({ messages }) {
      return {
        body: {
          messages,
          // Pass memory config
          memory: {
            thread: 'user-1',
            resource: 'user-1',
          },
        },
      }
    },
  }),
})
```
