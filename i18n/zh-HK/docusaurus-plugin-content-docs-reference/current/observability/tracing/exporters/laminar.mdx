# LaminarExporter

透過 OTLP/HTTP (protobuf) 將 Tracing 資料傳送至 Laminar。

## 建構函數

```typescript prettier:false
new LaminarExporter(config?: LaminarExporterConfig)
```

## `LaminarExporterConfig`

```typescript
interface LaminarExporterConfig extends BaseExporterConfig {
  apiKey?: string
  baseUrl?: string
  endpoint?: string
  headers?: Record<string, string>
  realtime?: boolean
  disableBatch?: boolean
  batchSize?: number
  timeoutMillis?: number
}
```

擴充 `BaseExporterConfig`，當中包括：

- `logger?: IMastraLogger` - Logger 實例
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - 日誌層級（預設：INFO）

## 方法

### `exportTracingEvent`

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將 Tracing 事件匯出至 Laminar。

### flush

```typescript prettier:false
async flush(): Promise<void>
```

強制將緩衝區內的所有 span 匯出至 Laminar，而不關閉匯出器。這適用於無伺服器環境，讓你可確保 span 在執行階段終止前已匯出。

### shutdown

```typescript prettier:false
async shutdown(): Promise<void>
```

清空待處理資料並關閉匯出器。

## 用法

### 零設定（使用環境變數）

```typescript
import { LaminarExporter } from '@mastra/laminar'

// Reads from LMNR_PROJECT_API_KEY, LMNR_BASE_URL, LAMINAR_ENDPOINT
const exporter = new LaminarExporter()
```

### 明確設定

```typescript
import { LaminarExporter } from '@mastra/laminar'

const exporter = new LaminarExporter({
  apiKey: process.env.LMNR_PROJECT_API_KEY,
  baseUrl: 'https://api.lmnr.ai',
  realtime: true,
})
```
