# ArthurExporter

使用 OpenTelemetry 及 OpenInference 語意慣例，將 Tracing 資料傳送至 [Arthur Engine](https://github.com/arthur-ai/arthur-engine)。

## 建構函式

```typescript prettier:false
new ArthurExporter(config: ArthurExporterConfig)
```

## `ArthurExporterConfig`

```typescript
type ArthurExporterConfig = Omit<OtelExporterConfig, 'provider' | 'exporter'> & {
  apiKey?: string
  endpoint?: string
  taskId?: string
  headers?: Record<string, string>
}
```

繼承自 `OtelExporterConfig`（不包括 `provider` 及 `exporter`），當中包括：

- `timeout?: number` - 匯出逾時毫秒數（預設：30000）
- `batchSize?: number` - 每批的 span 數量（預設：512）
- `logLevel?: LogLevel | 'debug' | 'info' | 'warn' | 'error'` - Log 級別（預設：WARN）
- `resourceAttributes?: Record<string, any>` - 自訂資源屬性

### Metadata 傳遞

非保留的 span 屬性會序列化至 OpenInference `metadata` payload。透過 `tracingOptions.metadata` 加入這些屬性（例如 `companyId`、`tier`）。`input`、`output`、`sessionId`、thread/user ID 及 OpenInference ID 等保留欄位會自動排除。

## 方法

### `exportTracingEvent`

```typescript prettier:false
async exportTracingEvent(event: TracingEvent): Promise<void>
```

將 tracing 事件匯出至已設定的 endpoint。

### export

```typescript prettier:false
async export(spans: ReadOnlySpan[]): Promise<void>
```

使用 OpenTelemetry 及 OpenInference 語意慣例批次匯出 span。

### flush

```typescript prettier:false
async flush(): Promise<void>
```

在不關閉 exporter 的情況下，強制將任何已緩衝的 span 排清至已設定的 endpoint。這在 serverless 環境中十分實用，可確保在 runtime 終止前匯出 span。

### shutdown

```typescript prettier:false
async shutdown(): Promise<void>
```

排清待處理資料並關閉 client。

## 用法

### 零設定（使用環境變數）

```typescript
import { ArthurExporter } from '@mastra/arthur'

// Set ARTHUR_API_KEY and ARTHUR_BASE_URL (optionally ARTHUR_TASK_ID)
const exporter = new ArthurExporter()
```

### 明確設定

```typescript
import { ArthurExporter } from '@mastra/arthur'

const exporter = new ArthurExporter({
  apiKey: process.env.ARTHUR_API_KEY!,
  endpoint: 'http://localhost:3030',
  taskId: process.env.ARTHUR_TASK_ID, // Optional
})
```

## `OpenInference` 語意慣例

ArthurExporter 為生成式 AI 應用程式實作 [OpenInference 語意慣例](https://github.com/Arize-ai/openinference/tree/main/spec)，在不同可觀測性平台之間提供標準化的 trace 結構。

## Tag 支援

ArthurExporter 支援使用 trace tag 進行分類及篩選。Tag 只會套用至根 span，並對應至原生 OpenInference `tag.tags` 語意慣例。

### 用法

```typescript
const result = await agent.generate('Hello', {
  tracingOptions: {
    tags: ['production', 'experiment-v2', 'user-request'],
  },
})
```

### Tag 的儲存方式

Tag 使用 OpenInference `tag.tags` 屬性儲存：

```json
{
  "tag.tags": ["production", "experiment-v2", "user-request"]
}
```
