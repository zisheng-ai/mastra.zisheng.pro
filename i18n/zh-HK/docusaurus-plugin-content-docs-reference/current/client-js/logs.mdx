# Logs API

Logs API 提供存取及查詢 Mastra 系統日誌與除錯資料的方法。

## 取得日誌 {/* #getting-logs */}

取得系統日誌，並可選擇篩選條件：

```typescript
const logs = await mastraClient.listLogs({
  transportId: 'transport-1',
})
```

## 取得指定執行的日誌 {/* #getting-logs-for-a-specific-run */}

取得指定執行作業的日誌：

```typescript
const runLogs = await mastraClient.getLogForRun({
  runId: 'run-1',
  transportId: 'transport-1',
})
```
