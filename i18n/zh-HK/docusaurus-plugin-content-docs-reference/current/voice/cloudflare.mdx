# Cloudflare

Mastra 的 CloudflareVoice class 使用 Cloudflare Workers AI 提供文字轉語音功能。此 Provider 專為高效、低延遲的語音合成而設，適用於邊緣運算環境。

## 使用範例 {/* #usage-example */}

```typescript
import { CloudflareVoice } from '@mastra/voice-cloudflare'

// Initialize with configuration
const voice = new CloudflareVoice({
  speechModel: {
    name: '@cf/meta/m2m100-1.2b',
    apiKey: 'your-cloudflare-api-token',
    accountId: 'your-cloudflare-account-id',
  },
  speaker: 'en-US-1', // Default voice
})

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?', {
  speaker: 'en-US-2', // Override default voice
})

// Get available voices
const speakers = await voice.getSpeakers()
console.log(speakers)
```

## 注意事項 {/* #notes */}

- 可透過建構函式選項或環境變數（CLOUDFLARE\_API\_TOKEN 和 CLOUDFLARE\_ACCOUNT\_ID）提供 API token
- Cloudflare Workers AI 針對低延遲的邊緣運算進行了最佳化
- 此 Provider 只支援文字轉語音（TTS）功能，不支援語音轉文字（STT）
- 此服務可與其他 Cloudflare Workers 產品良好整合
- 在正式環境中使用前，請確保你的 Cloudflare 帳戶已有合適的 Workers AI 訂閱
- 與部分其他 Provider 相比，語音選項較有限，但其邊緣運算效能非常出色
