# Voice 事件 {/* #voice-events */}

Voice provider 會在實時語音互動期間發出事件。你可以使用 [voice.on()](./voice.on) 方法監聽這些事件，而這些事件對建立互動式語音應用程式尤其重要。

## 注意事項 {/* #notes */}

- 並非所有 voice provider 都支援全部事件
- 確切的 payload 結構可能因 provider 而異
- 對於非實時 provider，大部分這些事件都不會發出
- 事件有助建立可回應對話狀態的互動式 UI
- 不再需要事件監聽器時，可考慮使用 [voice.off()](./voice.off) 方法將其移除
