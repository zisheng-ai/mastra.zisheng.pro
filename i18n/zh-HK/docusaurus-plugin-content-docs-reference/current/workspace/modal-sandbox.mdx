# ModalSandbox

在隔離的 [Modal](https://modal.com) 雲端 Sandbox 中執行指令。提供由 Modal 基礎設施支援的安全、暫時性環境。有關介面詳情，請參閱 [WorkspaceSandbox 介面](/reference/workspace/sandbox)。

## 安裝

```bash npm2yarn
npm install @mastra/modal
```

## 用法

將 `ModalSandbox` 加入 Workspace，並指派給 Agent：

```typescript
import { Agent } from '@mastra/core/agent'
import { Workspace } from '@mastra/core/workspace'
import { ModalSandbox } from '@mastra/modal'

const workspace = new Workspace({
  sandbox: new ModalSandbox({
    id: 'dev-sandbox',
    baseImage: 'ubuntu:22.04',
    timeoutMs: 60_000,
  }),
})

const agent = new Agent({
  id: 'dev-agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_OPUS__',
  workspace,
})
```

## 驗證

透過環境變數或建構函式選項設定 Modal 憑證：

```bash
MODAL_TOKEN_ID=ak-...
MODAL_TOKEN_SECRET=as-...
```

或者直接傳入憑證：

```typescript
const sandbox = new ModalSandbox({
  tokenId: process.env.MODAL_TOKEN_ID,
  tokenSecret: process.env.MODAL_TOKEN_SECRET,
})
```

前往 [Modal 控制台](https://modal.com/settings/tokens)取得憑證。

## Sandbox 生命週期

- **`_start()`**：嘗試重新連線至現有且正在運行的 Sandbox。若找不到，則從最新快照（如先前的 `_stop()` 有建立快照）或 `baseImage` 建立 Sandbox。
- **`_stop()`**：建立檔案系統快照，然後終止 Sandbox。快照會保留在同一實例的記憶體中，以供日後啟動使用。
- **`_destroy()`**：終止 Sandbox 並捨棄所有快照。

```typescript
const sandbox = new ModalSandbox({
  id: 'dev-sandbox',
  baseImage: 'ubuntu:22.04',
  timeoutMs: 300_000,
})

await sandbox._start()
await sandbox.processes.spawn('npm install')
await sandbox._stop()
await sandbox._start()
```

## 背景程序

`ModalSandbox` 內置程序管理器，用於產生及管理背景程序。每次呼叫 `spawn()`，都會透過 Modal SDK 的 `Sandbox.exec()` API 建立新的 `ContainerProcess`。

```typescript
const sandbox = new ModalSandbox({ id: 'dev-sandbox' })
await sandbox._start()

// Spawn a background process
const handle = await sandbox.processes.spawn('node script.js', {
  env: { PORT: '3000' },
  onStdout: data => console.log(data),
})

// Wait for the process to complete
const result = await handle.wait()
console.log(result.exitCode)

// Kill the process
await handle.kill()
```

:::note

不支援 `sendStdin()`。Modal JS SDK 並未在 `Sandbox.exec()` 上公開 stdin。

:::

完整 API 請參閱 [`SandboxProcessManager` 參考](/reference/workspace/process-manager)。
