# Hono adapter

`@mastra/hono` 套件提供 server adapter，讓 Mastra 可配合 [Hono](https://hono.dev) 運行。有關一般 adapter 概念（constructor 選項、初始化流程等），請參閱 [Server adapter](/docs/server/server-adapters)。

## 安裝 {/* #installation */}

安裝 Hono adapter 及 Hono framework：

```bash npm2yarn
npm install @mastra/hono@latest hono
```

## 使用範例 {/* #usage-example */}

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

export default app
```

## 新增自訂 route {/* #adding-custom-routes */}

直接將 route 新增至 Hono app：

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

// Before init - runs before Mastra middleware
app.get('/early-health', c => c.json({ status: 'ok' }))

await server.init()

// After init - has access to Mastra context
app.get('/custom', c => {
  const mastraInstance = c.get('mastra')
  return c.json({ agents: Object.keys(mastraInstance.listAgents()) })
})
```

:::tip

在 `init()` 前新增的 route 會在沒有 Mastra context 的情況下運行。如要存取 Mastra instance 及 request context，請在 `init()` 後新增 route。

:::

如需 Mastra 管理的 auth，以及 `requiresAuth` 等 route metadata，建議使用 [`registerApiRoute()`](/reference/server/register-api-route)。對於直接掛載到 `app` 的原始 Hono route，請使用 `createAuthMiddleware()`：

```typescript title="server.ts"
import { Hono } from 'hono'
import { createAuthMiddleware, HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'
import { mastra } from './mastra'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()
const server = new MastraServer({ app, mastra })

await server.init()

app.get('/custom/protected', createAuthMiddleware({ mastra }), c => {
  const user = c.get('requestContext').get('user')
  return c.json({ user })
})

app.get('/custom/public', createAuthMiddleware({ mastra, requiresAuth: false }), c => {
  return c.json({ ok: true })
})
```

## 存取 context {/* #accessing-context */}

在 Hono middleware 及 route handler 中，透過 `c.get()` 存取 Mastra context：

```typescript
app.get('/custom', async c => {
  const mastra = c.get('mastra')
  const requestContext = c.get('requestContext')
  const abortSignal = c.get('abortSignal')

  const agent = mastra.getAgent('myAgent')
  return c.json({ agent: agent.name })
})
```

可用的 context key：

| Key | 說明 |
| - | - |
| `mastra` | Mastra instance |
| `requestContext` | Request context map |
| `abortSignal` | Request 取消訊號 |
| `tools` | 可用的 Tool |
| `taskStore` | A2A 操作的 task store |
| `customRouteAuthConfig` | 各 route 的 auth 覆寫設定 |
| `user` | 已驗證的使用者（如已設定 auth） |

## 新增 middleware {/* #adding-middleware */}

在 `init()` 前或後新增 Hono middleware：

```typescript title="server.ts"
import { Hono } from 'hono'
import { HonoBindings, HonoVariables, MastraServer } from '@mastra/hono'

const app = new Hono<{ Bindings: HonoBindings; Variables: HonoVariables }>()

// Middleware before init
app.use('*', async (c, next) => {
  console.log(`${c.req.method} ${c.req.url}`)
  await next()
})

const server = new MastraServer({ app, mastra })
await server.init()

// Middleware after init has access to Mastra context
app.use('*', async (c, next) => {
  const mastra = c.get('mastra')
  await next()
})
```

## 手動初始化 {/* #manual-initialization */}

如要自訂 middleware 順序，請分別呼叫各個 method，而非使用 `init()`。詳情請參閱[手動初始化](/docs/server/server-adapters#manual-initialization)。
