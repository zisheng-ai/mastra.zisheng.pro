# Workflow\.dountil()

`.dountil()` 方法會執行步驟，直至符合條件。評估條件前，步驟一定會至少執行一次。首次評估條件時，`iterationCount` 為 `1`。

## 使用範例

```typescript
workflow.dountil(step1, async ({ inputData }) => true)
```
