# Agent.listScorers()

`.listScorers()` 方法會取得為 Agent 設定的評分設定；如設定為函數，則會先解析函數。此方法可存取用於評估 Agent 回應及表現的評分系統。

## 使用範例

```typescript
await agent.listScorers()
```
