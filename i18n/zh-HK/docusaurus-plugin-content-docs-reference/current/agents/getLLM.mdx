# Agent.getLLM()

`.getLLM()` 方法會擷取為 Agent 設定的語言模型實例；如設定值為函式，則會先解析。你亦可以傳入請求範圍的 `model` 覆寫，而不會改動 Agent 已設定的模型。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getLLM()
```

```typescript
await agent.getLLM({
  model: '__GATEWAY_OPENAI_MODEL__',
})
```
