# Agent.getTools()

`.getTools()` 方法會取得為 Agent 設定的 Tool；如設定為函數，則會先解析函數。這些 Tool 可擴充 Agent 的能力，讓它執行特定操作或存取外部系統。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getTools()
```
