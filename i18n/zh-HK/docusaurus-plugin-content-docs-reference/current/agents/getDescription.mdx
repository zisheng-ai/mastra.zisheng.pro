# Agent.getDescription()

`.getDescription()` 方法會取得為 Agent 設定的描述。此方法會傳回一個字串描述，說明 Agent 的用途及能力。

## 使用範例 {/* #usage-example */}

```typescript
agent.getDescription()
```

## 參數 {/* #parameters */}

此方法不接受任何參數。
