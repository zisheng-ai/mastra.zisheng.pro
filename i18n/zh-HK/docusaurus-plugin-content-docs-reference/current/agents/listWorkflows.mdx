# Agent.listWorkflows()

`.listWorkflows()` 方法會取得為 Agent 設定的 Workflow；如設定為函數，則會先解析函數。這些 Workflow 讓 Agent 可按照已定義的執行路徑，執行複雜的多步驟流程。

## 使用範例

```typescript
await agent.listWorkflows()
```
