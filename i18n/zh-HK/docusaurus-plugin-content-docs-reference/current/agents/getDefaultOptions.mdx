# Agent.getDefaultOptions()

你可為 Agent 設定記憶體使用及輸出格式的預設選項，亦可設定反覆運算步驟。`.getDefaultOptions()` 方法會傳回這些預設值；如設定為函數，則會先解析函數。除非另行覆寫，否則這些選項會套用至所有 `stream()` 及 `generate()` 呼叫，並可用於檢查 Agent 中未知的預設值。

## 使用範例

```typescript
await agent.getDefaultOptions()
```
