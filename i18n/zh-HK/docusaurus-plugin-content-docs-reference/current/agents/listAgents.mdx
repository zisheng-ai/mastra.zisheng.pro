# Agent.listAgents() {/* #agentlistagents */}

`.listAgents()` 方法會取得為 Agent 設定的子 Agent；如設定為函數，則會先解析函數。這些子 Agent 讓 Agent 可存取其他 Agent 並執行複雜操作。

## 使用範例 {/* #usage-example */}

```typescript
await agent.listAgents()
```
