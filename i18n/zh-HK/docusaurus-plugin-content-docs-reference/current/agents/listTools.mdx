# Agent.listTools()

`.listTools()` 方法會擷取為 Agent 設定的 Tool；如設定值為函式，則會先解析。這些 Tool 可擴充 Agent 的能力，讓它執行特定動作或存取外部系統。

## 使用範例

```typescript
await agent.listTools()
```
