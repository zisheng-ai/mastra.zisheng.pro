# Agent.getMemory() {/* #agentgetmemory */}

`.getMemory()` 方法會取得與 Agent 關聯的記憶體系統。此方法用於存取 Agent 的記憶體功能，以便跨對話儲存及擷取資訊。

## 使用範例 {/* #usage-example */}

```typescript
await agent.getMemory()
```
