# Agent.getDefaultStreamOptionsLegacy()

:::warning

**已棄用**：此方法已棄用，而且只適用於 V1 模型。對於 V2 模型，請改用新的 [`.getDefaultOptions()`](./getDefaultOptions) 方法。

:::

你可以為 Agent 設定預設串流選項，以控制記憶體使用方式和輸出格式，亦可設定迭代步驟。`.getDefaultStreamOptionsLegacy()` 方法會傳回這些預設值；如設定值為函式，則會先解析。除非被覆寫，否則這些選項會套用至所有 `streamLegacy()` 呼叫，並可用於檢查 Agent 的未知預設值。

## 使用範例

```typescript
await agent.getDefaultStreamOptionsLegacy()
```
