# Agent.getVoice()

`.getVoice()` 方法會取得為 Agent 設定的語音 Provider；如設定為函數，則會先解析函數。此方法用於存取 Agent 的語音功能，包括文字轉語音及語音轉文字。

## 使用範例

```typescript
await agent.getVoice()
```
