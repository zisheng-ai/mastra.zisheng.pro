# ChannelProvider

`ChannelProvider` 是平台整合用來將 Agent 連接至訊息平台的介面。Provider 負責整個整合生命週期：應用程式佈建及 OAuth、webhook 路由及事件處理、建立 adapter 並連接 Agent，以及憑證管理。

在 `Mastra` 建構函數的 `channels` 下註冊 Provider，並以你選擇的 id 作為鍵。每個 Provider 的路由都會自動合併至伺服器的 API 路由，而 `initialize()` 會在 Mastra 啟動期間執行。

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { SlackProvider } from '@mastra/slack'

export const mastra = new Mastra({
  channels: {
    slack: new SlackProvider({
      refreshToken: process.env.SLACK_REFRESH_TOKEN!,
      baseUrl: process.env.MASTRA_BASE_URL,
    }),
  },
})
```

Provider 的 `baseUrl` 是平台傳送 webhook 及事件的公開 URL。在生產環境中，這是你已部署的 Mastra 伺服器 URL。在本機開發時，平台無法連線至 `http://localhost:4111`，因此請運行隧道（例如 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 或 [ngrok](https://ngrok.com/)），並將 `baseUrl` 指向隧道 URL（例如 `https://abc123.trycloudflare.com`），讓事件能夠送達本機開發程序。

[`SlackProvider`](/reference/channels/slack-provider) 是首個內置實作。你亦可透過實作此介面來建立自訂 Provider。

## 存取 Provider

透過 `channels` getter 存取已註冊的 Provider，並以註冊時所用的 id 作為鍵。Getter 的類型由建構函數設定推斷，因此 `mastra.channels.slack` 是具備完整方法介面的具體 Provider。

```typescript
await mastra.channels.slack.configure({ refreshToken })
```

如果只有在運行期間才知道鍵，可改為以字串 id 查找 Provider。`getChannelProvider` 接受具體類型作為泛型，而 `getChannelProviders` 會傳回所有已註冊的 Provider，並以 id 作為鍵。

```typescript
import type { SlackProvider } from '@mastra/slack'

const slack = mastra.getChannelProvider<SlackProvider>('slack')
const all = mastra.getChannelProviders()
```
