# 將 Mastra 部署至 Cloudflare

使用 `@mastra/deployer-cloudflare` 將 Mastra 伺服器部署至 Cloudflare Workers。部署工具會封裝你的程式碼，並產生符合 Cloudflare [wrangler 設定](https://developers.cloudflare.com/workers/wrangler/configuration/)的 `wrangler.jsonc` 檔案，無需額外設定即可部署。

:::info

如果你使用[伺服器 adapter](/docs/server/server-adapters) 或[網絡框架](/docs/deployment/web-framework)，請按該框架的一般方式部署。

:::

## 開始之前 {/* #before-you-begin */}

你需要一個 [Mastra 應用程式](/guides/getting-started/quickstart)和一個 [Cloudflare](https://cloudflare.com/) 帳戶。

:::warning
Cloudflare Workers 使用臨時檔案系統，因此你設定的任何儲存空間（包括可觀測性儲存空間）都必須託管於外部。如果你透過檔案 URL 使用 [LibSQLStore](/reference/storage/libsql)，請改用遠端託管的資料庫。
:::

## 安裝 {/* #installation */}

將 `@mastra/deployer-cloudflare` 依賴套件加入你的項目：

```bash npm2yarn
npm install @mastra/deployer-cloudflare@latest
```

匯入 [`CloudflareDeployer`](/reference/deployer/cloudflare)，並在 Mastra 設定中將其設為部署工具：

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
// highlight-next-line
import { CloudflareDeployer } from '@mastra/deployer-cloudflare'

export const mastra = new Mastra({
  // highlight-start
  deployer: new CloudflareDeployer({
    name: 'your-project-name',
    vars: {
      NODE_ENV: 'production',
    },
  }),
  // highlight-end
})
```

如要在本機測試 Cloudflare Worker，亦請安裝 [`wrangler` CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/)：

```bash npm2yarn
npm install -D wrangler
```

## 使用方式 {/* #usage */}

設定好項目後，將它推送至你選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    將你的儲存庫連接至 Cloudflare。在「Workers & Pages」控制台選擇 **Create application**，然後在下一步選擇你的 Git Provider。繼續完成設定程序，並選擇要部署的儲存庫。

    :::note

    請記得設定執行應用程式所需的環境變數（例如你的[模型 Provider](/models/providers) API 金鑰）。你可以使用 `npx wrangler secret bulk .env`，從 `.env` 檔案上載機密資料。詳情請參閱[機密資料](/reference/deployer/cloudflare#secrets)。

    :::
  </StepItem>

  <StepItem>
    準備好後，按一下 **Deploy** 按鈕，等待首次部署完成。
  </StepItem>

  <StepItem>
    前往 `https://<your-project-name>.<slug>.workers.dev/api/agents`，試用你剛部署的函數。你應會收到列出所有可用 Agent 的 JSON 回應。

    由於 [Mastra 伺服器](/docs/server/mastra-server)會為每個 API 端點加上 `/api` 前綴，因此發出請求時必須將它加入 URL。
  </StepItem>

  <StepItem>
    你現在可以透過 HTTP 呼叫 Mastra 端點。

    :::note

    在公開端點前，請先設定[身份驗證](/docs/server/auth)。

    :::
  </StepItem>
</Steps>
