# 將 Mastra 部署至 Digital Ocean

本指南涵蓋 Digital Ocean 的 App Platform 和 Droplets。這兩種服務各有所長，適合不同類型的項目和具備不同專業水平的開發人員。請閱讀 [Digital Ocean 的比較](https://www.digitalocean.com/community/conceptual-articles/digitalocean-app-platform-vs-doks-vs-droplets)，了解兩者的分別，並為你的項目選擇最合適的方案。

:::info
本指南涵蓋如何部署 [Mastra 伺服器](/docs/server/mastra-server)。如果你使用[伺服器 adapter](/docs/server/server-adapters) 或[網絡框架](/docs/deployment/web-framework)，請按該框架的一般方式部署。
:::

## 開始之前

你需要一個 [Mastra 應用程式](/guides/getting-started/quickstart)和一個 [Digital Ocean](https://www.digitalocean.com/) 帳戶。

**App Platform** 使用臨時檔案系統，因此你設定的任何儲存空間（包括可觀測性儲存空間）都必須託管於外部。如果你透過檔案 URL 使用 [LibSQLStore](/reference/storage/libsql)，請改用遠端託管的資料庫。

## App Platform

設定好項目後，將它推送至你選擇的遠端 Git Provider（例如 GitHub）。

<Steps>
  <StepItem>
    按照官方的 [App Platform 快速入門](https://docs.digitalocean.com/products/app-platform/getting-started/quickstart/#create-an-app)操作。當中會引導你連接儲存庫、選擇要部署的分支，並在有需要時設定來源目錄。
  </StepItem>

  <StepItem>
    確保系統偵測到「Node.js」構建。你需要設定構建命令，並按所用的依賴套件管理工具設定：

    ```bash npm2yarn
    npm run build
    ```
  </StepItem>

  <StepItem>
    加入 Mastra 應用程式所需的所有環境變數，包括 API 金鑰、資料庫 URL 和其他設定值。
  </StepItem>

  <StepItem>
    系統會自動構建並部署你的應用程式。Digital Ocean 會提供 URL，讓你存取已部署的應用程式。
  </StepItem>

  <StepItem>
    你現在可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    在公開端點前，請先設定[身份驗證](/docs/server/auth)。
    :::
  </StepItem>
</Steps>

## Droplets

### 先決條件

- 執行 Ubuntu 24.04 LTS 或更新版本的 Droplet
- 一個已有 A 記錄指向 Droplet 的網域名稱
- 已設定反向代理（例如使用 [nginx](https://nginx.org/)）
- 已設定 SSL 憑證（例如使用 [Let's Encrypt](https://letsencrypt.org/)）
- Droplet 已安裝 Node.js 22.13.0 或更新版本

### 部署

設定好項目後，將它推送至你選擇的遠端 Git Provider（例如 GitHub）。連接至 Droplet，並確保已安裝 `git`。

<Steps>
  <StepItem>
    複製你的儲存庫：

    <Tabs>
      <TabItem value="public" label="公開儲存庫">
        ```bash
        git clone https://github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>

      <TabItem value="private" label="私人儲存庫">
        ```bash
        git clone https://<your-username>:<your-personal-access-token>@github.com/<your-username>/<your-repository>.git
        ```
      </TabItem>
    </Tabs>

    前往儲存庫目錄：

    ```bash
    cd "<your-repository>"
    ```
  </StepItem>

  <StepItem>
    安裝項目的依賴套件：

    ```bash npm2yarn
    npm install
    ```
  </StepItem>

  <StepItem>
    設定 Mastra 應用程式所需的環境變數。在項目根目錄建立 `.env` 檔案：

    ```bash
    touch .env
    ```

    編輯 `.env` 檔案，並加入環境變數：

    ```bash title=".env"
    OPENAI_API_KEY=your-api-key
    ```
  </StepItem>

  <StepItem>
    構建項目：

    ```bash npm2yarn
    npm run build
    ```

    這會在 `.mastra/output` 目錄建立 Mastra 伺服器的正式版本構建。
  </StepItem>

  <StepItem>
    你可以執行 `mastra start` 命令來啟動 [Mastra 伺服器](/docs/deployment/mastra-server)：

    ```bash
    mastra start
    ```

    :::info
    Mastra 應用程式預設會在連接埠 4111 執行。請確保反向代理已設定為將請求轉送至此連接埠。
    :::
  </StepItem>

  <StepItem>
    你現在可以透過 HTTP 呼叫 Mastra 端點。

    :::warning
    在公開端點前，請先設定[身份驗證](/docs/server/auth)。
    :::
  </StepItem>
</Steps>
