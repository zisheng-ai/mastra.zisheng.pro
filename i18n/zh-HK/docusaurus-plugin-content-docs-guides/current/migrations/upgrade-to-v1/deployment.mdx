# 部署

OpenAPI 規格端點已移至 `/api/openapi.json`，而 `CloudflareDeployer` 設定亦已更新，改用標準 `wrangler.json` 屬性名稱。

## 已變更 {/* #changed */}

### OpenAPI 規格端點移至 `/api/openapi.json` {/* #openapi-spec-endpoint-moved-to-apiopenapijson */}

OpenAPI 規格端點已從 `/openapi.json` 移至 `/api/openapi.json`，以配合所有 Mastra 內置路由使用的 `/api` 前綴。

如果你有使用 OpenAPI 規格的指令碼或 Tool，請更新 URL：

```diff
- GET /openapi.json
+ GET /api/openapi.json
```

### `CloudflareDeployer` 使用標準 `wrangler.json` 屬性名稱 {/* #cloudflaredeployer-uses-standard-wranglerjson-property-names */}

`CloudflareDeployer` 建構函式現在接受標準 `wrangler.json` 屬性名稱，而非自訂的 camelCase 變體。這項變更使部署器與 Cloudflare 官方設定格式一致，並可使用所有 wrangler 設定選項。

已棄用的欄位會在執行階段自動遷移，並在控制台顯示警告；不過，你仍應更新程式碼以使用新的欄位名稱。

```diff
  const deployer = new CloudflareDeployer({
-   projectName: 'my-worker',
+   name: 'my-worker',
-   d1Databases: [
+   d1_databases: [
      {
        binding: 'DB',
        database_name: 'my-db',
        database_id: 'xxx',
      },
    ],
-   kvNamespaces: [
+   kv_namespaces: [
      {
        binding: 'KV',
        id: 'yyy',
      },
    ],
  });
```

`workerNamespace` 欄位已移除，因為不再使用。

如要查看所有可用設定選項，請參閱 [Wrangler 設定文件](https://developers.cloudflare.com/workers/wrangler/configuration/)。
