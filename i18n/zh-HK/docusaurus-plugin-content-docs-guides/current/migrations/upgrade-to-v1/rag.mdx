# RAG

RAG 套件已重新命名分塊參數，並收窄其類型。

## 已變更 {/* #changed */}

### `keepSeparator` 改為 `separatorPosition` {/* #keepseparator-to-separatorposition */}

`keepSeparator` 參數已重新命名為 `separatorPosition`，類型亦有所簡化。舊參數使用容易令人混淆的 `boolean | 'start' | 'end'` 類型，當中 `true` 實際上是 `'start'` 的別名。新參數使用明確的 `'start' | 'end'` 值；省略此參數則會捨棄分隔符號。

如要遷移，請按照下表的對應關係，以 `separatorPosition` 取代 `keepSeparator`：

| 舊值 | 新值 |
| - | - |
| `keepSeparator: true` | `separatorPosition: 'start'` |
| `keepSeparator: 'start'` | `separatorPosition: 'start'` |
| `keepSeparator: 'end'` | `separatorPosition: 'end'` |
| `keepSeparator: false` | 移除參數 |
| 省略參數 | 不需變更 |

```diff
  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: true,
+   separatorPosition: 'start',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: 'end',
+   separatorPosition: 'end',
  });

  await doc.chunk({
    strategy: 'character',
    separator: '.',
-   keepSeparator: false,
+   // Parameter removed - separator is discarded by default
  });
```
