# Processor

Processor 介面已更新，統一使用一致的命名模式及資料庫訊息類型。

## 已變更

### Processor 設定由 `name` 改為 `id`

Processor 現在必須提供 `id` 欄位，而非 `name`。`name` 欄位現在是選填欄位。這項變更令其與 scorer 和 Agent 等其他 Mastra 實體保持一致。

如要遷移，請更新 Processor 定義，改用 `id` 作為必填欄位。

```diff
  import type { InputProcessor } from '@mastra/core/processors';

  const processor: InputProcessor = {
-   name: 'my-processor',
+   id: 'my-processor',
+   name: 'My Processor', // optional
    processInput: async ({ messages }) => {
      // ...
    },
  };
```

### Processor 訊息類型由 `MastraMessageV2` 改為 `MastraDBMessage`

Processor 訊息類型已由 `MastraMessageV2` 改為 `MastraDBMessage`。Processor 和 scorer 現在都使用資料庫訊息格式及其類型。

如要遷移，請更新 Processor 訊息類型的 import 及用法。

```diff
  import type { InputProcessor } from '@mastra/core/processors';
- import type { MastraMessageV2 } from '@mastra/core/agent';
+ import type { MastraDBMessage } from '@mastra/core/agent';

  const processor: InputProcessor = {
    id: 'my-processor',
-   processInput: async ({ messages }: { messages: MastraMessageV2[] }) => {
+   processInput: async ({ messages }: { messages: MastraDBMessage[] }) => {
      // ...
    },
  };
```

## 已移除

### 已棄用的輸入 Processor export

`@mastra/core/agent/input-processors/processors` 中包含內置 Processor 的已棄用輸入 Processor export 已移除。請改用 `@mastra/core/processors`。這項變更把 Processor 類型整合至統一的 `Processor` 介面之下。

如果你曾使用 `InputProcessor`，請以實作 `processInput` 函式的 `Processor` 取代。

```diff
- import { InputProcessor, ModerationProcessor } from '@mastra/core/agent/input-processors/processors';
+ import { Processor, ModerationProcessor } from '@mastra/core/processors';
```

### Memory Processor export 已移至 core

`@mastra/memory/processors` export 已移除。所有 Processor 現在均由 `@mastra/core/processors` export。這項變更把所有 Processor export 整合至同一位置。

如要遷移，請把 import 路徑由 `@mastra/memory/processors` 更新為 `@mastra/core/processors`。

```diff
- import { TokenLimiter, ToolCallFilter } from '@mastra/memory/processors';
+ import { TokenLimiter, ToolCallFilter } from '@mastra/core/processors';
```
