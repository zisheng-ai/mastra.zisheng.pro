# CLI {/* #cli */}

CLI 已移除部署命令、設定旗標及初始文件，令操作更簡潔。此外亦新增了遷移命令，協助升級資料庫結構描述。

## 新增 {/* #added */}

### `mastra migrate` 命令 {/* #mastra-migrate-command */}

新的 `mastra migrate` 命令可在升級 Mastra 版本時協助執行資料庫遷移。從可能存在資料不相容問題的舊版本升級時，這項功能尤其有用。

```bash
npx mastra migrate
```

此命令會打包你的項目，連接已設定的儲存空間，然後執行所有必要遷移。目前支援遷移可能導致無法建立唯一約束的重複 span 項目。

如要了解何時需要此遷移，請參閱[儲存空間遷移指南](/guides/migrations/upgrade-to-v1/storage#duplicate-spans-migration)。

## 已移除 {/* #removed */}

### `mastra deploy` 命令 {/* #mastra-deploy-command */}

CLI 已移除 `mastra deploy` 命令。這項變更移除了 Provider 特定的部署邏輯，令 CLI 更簡潔。

如要遷移，請選擇其中一個你合用的[部署平台](/docs/deployment/overview)。

### 從 `mastra build` 移除 `--env` 旗標 {/* #--env-flag-from-mastra-build */}

`mastra build` 命令已移除 `--env` 旗標。這項變更令建置命令更簡潔。

如要遷移，請使用 `mastra start --env <env>`，以自訂環境啟動建置輸出。

```diff
- mastra build --env production
+ mastra build
+ mastra start --env production
```

### 從 `mastra dev` 移除 `--port` 旗標 {/* #--port-flag-from-mastra-dev */}

`mastra dev` 命令已移除 `--port` 旗標。連接埠設定現在由 Mastra 實例設定處理，讓連接埠設定集中管理。

如要遷移，請在 Mastra 實例上使用 `server.port`，而非 CLI 旗標。

```ts
const mastra = new Mastra({
  server: {
    port: 3001,
  },
})
```

### 從 CLI 移除遙測選項 {/* #telemetry-options-from-cli */}

CLI 命令已移除 `telemetry` 選項，包括 `--no-telemetry`／`-nt` 旗標。CLI 不再提供遙測設定，反映遙測功能已移至可觀測性套件。

如要遷移，請從 CLI 命令移除遙測旗標。Trace 功能請使用 `@mastra/observability`。
