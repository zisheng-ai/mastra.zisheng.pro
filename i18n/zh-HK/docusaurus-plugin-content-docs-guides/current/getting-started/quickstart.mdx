# Mastra 快速入門

<Inject>
  **供 AI Agent 使用：** 使用 `npm create mastra@latest <project-name> -- --llm <provider>` 以非互動方式建立新的 Mastra 項目，並將 `<provider>` 替換為 `openai`、`anthropic`、`google` 或 `xai`。如要建立不含 Agent 或模型 Provider 的最小項目，請使用 `npm create mastra@latest <project-name> -- --empty`。如要從頭建立 Mastra 項目，請參閱[手動安裝指南](/guides/getting-started/manual-install)。
</Inject>

`create-mastra` CLI 是開始建立 Mastra 項目最快捷的方式。它會建立 Agent Harness，當中包含 Workspace Tool、記憶體、任務追蹤、網絡存取、排程、儲存及可觀測性。

如需更多控制，請參閱[手動安裝指南](/guides/getting-started/manual-install)。如要將 Mastra 加入現有項目，請使用 [`mastra init`](/reference/cli/mastra#mastra-init)。

## 開始之前 {/* #before-you-begin */}

你需要 OpenAI、Anthropic、Google Gemini 或 xAI 的 API 金鑰。你可以在設定期間略過輸入，稍後再將金鑰加入 `.env`。

## 建立項目 {/* #create-the-project */}

執行互動式設定：

<Tabs groupId="npm2yarn">
  <TabItem value="npm" label="npm">
    ```bash
    npm create mastra@latest
    ```
  </TabItem>

  <TabItem value="pnpm" label="pnpm">
    ```bash
    pnpm create mastra@latest
    ```
  </TabItem>

  <TabItem value="yarn" label="Yarn">
    ```bash
    yarn create mastra
    ```
  </TabItem>

  <TabItem value="bun" label="Bun">
    ```bash
    bunx create-mastra
    ```
  </TabItem>
</Tabs>

此命令會要求你輸入項目名稱、模型 Provider 及可選的 API 金鑰。然後，它會安裝依賴套件、為你的編程助手安裝 Mastra Skill；如你目前不在現有的程式庫內，亦會建立初始 Git commit。

所產生的 `src/mastra` 目錄包含 Mastra 進入點、Agent、Workspace Tool 及相關程式碼。標準 Mastra 目錄配置請參閱[項目結構參考資料](/reference/project-structure)。

:::tip

使用 `--template <template>` 從範本開始，或使用 `--empty` 建立不含 Provider 的最小項目。使用 `--no-skills` 或 `--no-git` 可略過自動設定。所有參數請參閱 [`create-mastra` 參考資料](/reference/cli/create-mastra)。

:::

## 測試你的 Agent {/* #test-your-agent */}

按照終端機指示進入項目目錄，然後啟動開發伺服器：

```bash npm2yarn
npm run dev
```

開啟 [localhost:4111 的 Studio](http://localhost:4111)，選擇 Agent 並傳送訊息。如在設定期間略過了 API 金鑰，請將 `.env.example` 中指定的 Provider API 金鑰加入 `.env` 檔案。

[Studio](/docs/studio/overview) 讓你無需另行建立 UI，即可建立及測試 Agent。
