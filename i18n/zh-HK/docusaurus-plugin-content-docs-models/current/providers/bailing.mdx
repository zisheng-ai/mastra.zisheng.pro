透過 Mastra 的模型路由器存取 2 個 Bailing 模型。系統會自動使用 `BAILING_API_TOKEN` 環境變數進行驗證。

詳情請參閱[Bailing 文件](https://alipaytbox.yuque.com/sxs0ba/ling/intro)。

```bash title=".env"
BAILING_API_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'bailing/Ling-1T',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[Bailing 文件](https://alipaytbox.yuque.com/sxs0ba/ling/intro)。

:::
