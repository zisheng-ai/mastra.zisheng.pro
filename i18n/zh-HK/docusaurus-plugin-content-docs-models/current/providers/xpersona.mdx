透過 Mastra 的模型路由器存取 13 個 Xpersona 模型。系統會自動使用 `XPERSONA_API_KEY` 環境變數進行驗證。

詳情請參閱[Xpersona 文件](https://www.xpersona.co/docs)。

```bash title=".env"
XPERSONA_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'xpersona/claude-fable-5',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[Xpersona 文件](https://www.xpersona.co/docs)。

:::

  id: 'custom-agent',
  name: 'custom-agent',
  model: {
    url: 'https://www.xpersona.co/v1',
    id: 'xpersona/claude-fable-5',

})

### 動態選擇模型 {/* #dynamic-model-selection */}

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: 'dynamic-agent',
  name: 'Dynamic Agent',
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === 'complex'
    return useAdvanced ? 'xpersona/xpersona-gpt-5.5' : 'xpersona/claude-fable-5'
  },
})
```
