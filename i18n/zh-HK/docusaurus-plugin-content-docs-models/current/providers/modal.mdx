# <img src="https://models.dev/logos/modal.svg" alt="Modal 標誌" className="inline w-8 h-8 mr-2 align-middle dark:invert dark:brightness-0 dark:contrast-200" />Modal

透過 Mastra 的模型路由器存取 2 個 Modal 模型。系統會自動使用 `MODAL_PROXY_TOKEN` 環境變數進行驗證。

詳情請參閱[Modal 文件](https://modal.com/docs/guide/endpoints)。

```bash title=".env"
MODAL_PROXY_TOKEN=your-api-token
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "modal/moonshotai/Kimi-K3"
});

// Generate a response
const response = await agent.generate("Hello!");

// Stream a response
const stream = await agent.stream("Tell me a story");
for await (const chunk of stream) {
  console.log(chunk);
}
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[Modal 文件](https://modal.com/docs/guide/endpoints)。

:::

## 進階設定

### 自訂標頭

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    url: "https://inference.us-west.modal.direct/v1",
    id: "modal/moonshotai/Kimi-K3",
    apiKey: process.env.MODAL_PROXY_TOKEN,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

### 動態選擇模型

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "dynamic-agent",
  name: "Dynamic Agent",
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === "complex";
    return useAdvanced
      ? "modal/thinkingmachines/Inkling-NVFP4"
      : "modal/moonshotai/Kimi-K3";
  }
});
```
