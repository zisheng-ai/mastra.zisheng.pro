透過 Mastra 的模型路由器存取 6 個 DInference 模型。系統會自動使用 `DINFERENCE_API_KEY` 環境變數進行驗證。

詳情請參閱[DInference 文件](https://dinference.com)。

```bash title=".env"
DINFERENCE_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'dinference/glm-4.7',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[DInference 文件](https://dinference.com)。

:::

### 動態選擇模型 {/* #dynamic-model-selection */}

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: 'dynamic-agent',
  name: 'Dynamic Agent',
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === 'complex'
    return useAdvanced ? 'dinference/minimax-m2.5' : 'dinference/glm-4.7'
  },
})
```
