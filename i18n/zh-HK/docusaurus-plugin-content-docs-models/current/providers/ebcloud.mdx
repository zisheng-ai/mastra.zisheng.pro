透過 Mastra 的模型路由器存取 4 個 EBCloud 模型。系統會自動使用 `EBCLOUD_API_KEY` 環境變數進行驗證。

詳情請參閱[EBCloud 文件](https://docs.ebtech.com/ai/model-api.html)。

```bash title=".env"
EBCLOUD_API_KEY=your-api-key
```

```typescript title="src/mastra/agents/my-agent.ts" {7}
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'ebcloud/DeepSeek-V4-Flash',
})

// Generate a response
const response = await agent.generate('Hello!')

// Stream a response
const stream = await agent.stream('Tell me a story')
for await (const chunk of stream) {
  console.log(chunk)
}
```

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[EBCloud 文件](https://docs.ebtech.com/ai/model-api.html)。

## 進階設定

### 自訂標頭

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: 'custom-agent',
  name: 'custom-agent',
  model: {
    url: 'https://maas-api.ebcloud.com/v1',
    id: 'ebcloud/DeepSeek-V4-Flash',
    apiKey: process.env.EBCLOUD_API_KEY,
    headers: {
      'X-Custom-Header': 'value',
    },
  },
})
```

### 動態選擇模型

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: 'dynamic-agent',
  name: 'Dynamic Agent',
  model: ({ requestContext }) => {
    const useAdvanced = requestContext.task === 'complex'
    return useAdvanced ? 'ebcloud/Kimi-K2.6' : 'ebcloud/DeepSeek-V4-Flash'
  },
})
```
