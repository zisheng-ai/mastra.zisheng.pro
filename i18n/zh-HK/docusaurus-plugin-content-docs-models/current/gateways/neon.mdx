Neon 匯集多個 Provider 的模型，並提供速率限制及容錯轉移等增強功能。你可以透過 Mastra 的模型路由器存取 42 個模型。

詳情請參閱[Neon 文件](https://neon.com/docs)。

## 用法 {/* #usage */}

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from '@mastra/core/agent'

const agent = new Agent({
  id: 'my-agent',
  name: 'My Agent',
  instructions: 'You are a helpful assistant',
  model: 'neon/claude-fable-5',
})
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[Neon 文件](https://neon.com/docs)。

:::
