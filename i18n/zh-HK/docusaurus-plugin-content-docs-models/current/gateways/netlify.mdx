# <NetlifyLogo className="inline w-8 h-8 mr-2 align-middle" />Netlify

Netlify AI Gateway 提供對多個 Provider 的統一存取，並內置快取及可觀測性功能。你可以透過 Mastra 的模型路由器存取 66 個模型。

詳情請參閱[Netlify 文件](https://docs.netlify.com/build/ai-gateway/overview/)。

## 用法

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "netlify/anthropic/claude-fable-5"
});
```

:::info

Mastra 使用與 OpenAI 相容的 `/chat/completions` 端點。部分 Provider 專屬功能可能無法使用，詳情請參閱[Netlify 文件](https://docs.netlify.com/build/ai-gateway/overview/)。

:::

## 設定

```bash
# Use gateway API key
NETLIFY_TOKEN=your-netlify-token
NETLIFY_SITE_ID=your-netlify-site-id

# Or use provider API keys directly
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=ant-...
```
