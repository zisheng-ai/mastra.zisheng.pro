# 整合概覽 {/* #integrations-overview */}

Mastra 可觀測性整合可控制可觀測性數據的傳送目的地，以及數據在匯出過程中的轉換方式。你可以使用整合將數據儲存到 Mastra 儲存空間、傳送到 Mastra 平台、連接外部可觀測性 Provider，或遮蔽匯出的 span 數據。

## 何時使用整合 {/* #when-to-use-integrations */}

- 使用 `MastraStorageExporter`，讓 Studio 可繼續存取可觀測性數據。
- 使用 `MastraPlatformExporter`，將託管的可觀測性數據傳送到 Mastra 平台。
- 將 Trace 轉送至 Datadog、Langfuse 或 OpenTelemetry 後端等外部 Provider。
- 在敏感值離開執行環境前將其遮蔽。

## 選擇整合方式 {/* #choose-an-integration-path */}

- Studio Workflow：由 [Mastra Storage](/docs/observability/integrations/exporters/mastra-storage) 開始。
- 託管 Mastra Workflow：加入 [Mastra 平台](/docs/observability/integrations/exporters/mastra-platform)。
- 外部可觀測性技術棧：在側邊欄的 `Exporters` 部分選擇一個或多個匯出器頁面。
- 現有分散式 Trace 上下文：先使用橋接器，再按需要加入匯出器。

## 匯出器 {/* #exporters */}

匯出器會將可觀測性數據傳送到目的地：

- [Mastra Storage](/docs/observability/integrations/exporters/mastra-storage)：保存可觀測性數據，供 Studio 使用。
- [Mastra 平台](/docs/observability/integrations/exporters/mastra-platform)：將託管的可觀測性數據傳送到 Mastra 平台。
- 外部 Provider：使用 Datadog、Langfuse、OpenTelemetry 及其他受支援平台的匯出器頁面。

## 橋接器 {/* #bridges */}

橋接器可將 Mastra 連接至現有的分散式追蹤上下文：

- [OpenTelemetry 橋接器](/docs/observability/integrations/bridges/otel)：將 Mastra 與現有的 OpenTelemetry Trace 整合。
- [Datadog 橋接器](/docs/observability/integrations/bridges/datadog)：將 Mastra Trace 傳送到 Datadog 及其 LLM Observability 產品。

## 處理器 {/* #processors */}

處理器會在匯出前轉換或遮蔽 span：

- [敏感數據篩選器](/docs/observability/integrations/processors/sensitive-data-filter)：在 span 離開執行環境前遮蔽敏感欄位。
