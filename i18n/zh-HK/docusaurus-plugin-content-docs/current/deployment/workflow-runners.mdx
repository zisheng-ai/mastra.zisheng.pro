# Workflow runner

Mastra [Workflow](/docs/workflows/overview) 可使用內置 Workflow runner 執行，亦可部署至專用的 Workflow 執行平台，由平台處理編排、監察及可靠性。

## Inngest

Inngest 是一個開發者平台，讓你無需管理基礎設施即可執行背景 Workflow。Mastra Workflow 可部署至 Inngest，並使用步驟記憶化、自動重試、實時監察及暫停／恢復功能。

如需設定指引，請參閱 [Inngest 部署指南](/guides/deployment/inngest)；如需完整實作，請參閱 [Inngest Workflow 範例](https://github.com/mastra-ai/mastra/tree/main/examples/inngest)。

## Temporal

Temporal 是一個耐久執行平台，用於編排長時間運行的 Workflow。Mastra Workflow 可在 Temporal worker 上運行，每個 `createStep` 都會對應至一項 Temporal activity，以提供自動重試及耐久狀態。

`@mastra/temporal` 依賴套件屬實驗性質，尚未適合在生產環境使用。如需設定指引，請參閱 [Temporal 部署指南](/guides/deployment/temporal)。
