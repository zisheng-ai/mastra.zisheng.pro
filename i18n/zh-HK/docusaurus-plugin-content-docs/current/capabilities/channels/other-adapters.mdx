# 更多

Mastra Channels 使用 Chat SDK Adapter，因此本節頁面並非受支援平台的完整清單。你可以使用任何匯出與 `channels.adapters` 兼容的 Adapter factory 的 Chat SDK 平台 Adapter。

## Adapter 目錄

[Chat SDK Adapter 目錄](https://chat-sdk.dev/adapters)是可用 Adapter 的權威資料來源。以下清單只是在此刻的概覽，未必時刻保持最新。

撰寫本文時，Chat SDK 列出的 Adapter 包括：

- AgentPhone
- Baileys WhatsApp
- Discord
- Google Chat
- GitHub
- iMessage
- Kapso
- Lark / Feishu
- Linear
- Liveblocks
- Matrix
- Messenger
- Mattermost
- Novu
- Resend
- Sendblue
- Telegram
- Twilio
- Velt
- Web
- Webex
- WeChat
- WhatsApp Business Cloud
- X
- Zalo
- Zernio

請查閱 Adapter 的文檔，了解其依賴套件名稱、憑證變數、webhook 要求及平台特定行為。

## 使用相同的 Mastra 接駁方式

每個 Chat SDK Adapter 在 Mastra 端的設定方式都相同。安裝 Adapter 依賴套件，並將其 factory 加入 `channels.adapters`。然後設定平台憑證，並將其 webhook 指向所產生的 Mastra route。

你可以參考本節其中一個平台頁面，了解 Mastra 的接駁方式：

- [Slack](/docs/capabilities/channels/slack)
- [Microsoft Teams](/docs/capabilities/channels/teams)
- [Discord](/docs/capabilities/channels/discord)
- [Telegram](/docs/capabilities/channels/telegram)
- [WhatsApp](/docs/capabilities/channels/whatsapp)

## Adapter 文檔中的檢查項目

將新的 Adapter 接入 Mastra 前，請在 Adapter 文檔中檢查以下項目：

- 憑證環境變數。
- 所需的平台權限或 scope。
- Webhook 驗證行為。
- 平台是否需要為設定、事件或互動使用獨立 route。
- 一般訊息是否需要長時間運行的 listener 或 polling。
- 對附件、card 及 rich message 的支援。
