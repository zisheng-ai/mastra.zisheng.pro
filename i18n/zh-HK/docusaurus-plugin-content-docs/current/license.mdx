# 授權條款 {/* #license */}

Mastra 採用 Apache License 2.0 授權。這是一款寬鬆的開源授權條款，廣泛允許用戶使用、修改及分發軟件。

## 甚麼是 Apache License 2.0？ {/* #whats-apache-license-20 */}

Apache License 2.0 是一款寬鬆的開源授權條款，廣泛允許用戶使用、修改及分發軟件。它允許：

- 免費作任何用途，包括商業用途
- 查看、修改及重新分發源代碼
- 建立及分發衍生作品
- 不受限制地用於商業用途
- 獲得貢獻者提供的專利保障

Apache License 2.0 是目前最寬鬆且最適合商業應用的開源授權條款之一。

## 為何我們選擇 Apache License 2.0 {/* #why-we-chose-apache-license-20 */}

我們選擇 Apache License 2.0 有幾個重要原因：

1. **真正開源**：這款廣受認可的開源授權條款符合開源原則及社群期望。

1. **適合商業應用**：它允許不受限制地作商業用途及分發，適合各種規模的企業。

1. **專利保障**：它明確為用戶提供專利保障，帶來額外的法律保障。

1. **重視社群**：它鼓勵社群不受限制地貢獻及協作。

1. **獲廣泛採用**：它是業界最常用且最廣為理解的開源授權條款之一。

## 使用 Mastra 發展業務 {/* #building-your-business-with-mastra */}

Apache License 2.0 為使用 Mastra 發展業務提供最大的靈活性：

### 允許的商業模式 {/* #allowed-business-models */}

- **建立應用程式**：建立及銷售以 Mastra 構建的應用程式
- **提供顧問服務**：提供專業知識、實施及客製化服務
- **開發客製化解決方案**：使用 Mastra 為客戶構建度身訂造的 AI 解決方案
- **建立附加元件及擴充功能**：開發及銷售可擴充 Mastra 功能的輔助工具
- **培訓及教育**：提供有關如何有效使用 Mastra 的課程及教材
- **託管服務**：以託管或代管服務形式提供 Mastra
- **SaaS 平台**：構建由 Mastra 驅動的 SaaS 平台

### 合規使用範例 {/* #examples-of-compliant-usage */}

- 公司使用 Mastra 構建由 AI 驅動的客戶服務應用程式，並將其銷售予客戶
- 顧問公司為 Mastra 提供實施及客製化服務
- 開發者使用 Mastra 建立專門的 Agent 及 Tool，並授權其他企業使用
- 初創公司構建由 Mastra 驅動、針對特定垂直領域的解決方案（例如醫療保健 AI 助手）
- 公司向客戶提供 Mastra 託管服務
- SaaS 平台整合 Mastra 作為其 AI 後端

### 合規要求 {/* #compliance-requirements */}

Apache License 2.0 的要求很少：

- **註明出處**：保留版權聲明及授權資訊（包括 NOTICE 檔案）
- **說明變更**：如修改軟件，須註明已作出變更
- **附上授權條款**：分發時附上 Apache License 2.0 的副本
