# Agent 和 Tool

Workflow 步驟可以呼叫 Agent 以使用 LLM reasoning，或呼叫 Tool 以執行 type-safe 邏輯。你可以在步驟的 `execute()` function 內呼叫它們，亦可以使用 `createStep()` 直接將它們組合為步驟。

## 在 Workflow 中使用 Agent

當你需要 reasoning、語言生成或其他以 LLM 為基礎的任務時，請在 Workflow 步驟中使用 Agent。從步驟的 `execute()` function 呼叫，以更精細地控制 Agent 呼叫（例如追蹤訊息記錄或傳回 structured output）。如毋須修改 Agent 的呼叫方式，則將 Agent 組合為步驟。

### 呼叫 Agent

在步驟的 `execute()` function 中使用 `.generate()` 或 `.stream()` 呼叫 Agent。這樣你可以先修改 Agent 呼叫及處理回應，再傳給下一個步驟。

```typescript {6-14} title="src/mastra/workflows/test-workflow.ts"
const step1 = createStep({
  execute: async ({ inputData, mastra }) => {
    const { message } = inputData

    const testAgent = mastra.getAgent('testAgent')
    const response = await testAgent.generate(
      `Convert this message into bullet points: ${message}`,
      {
        memory: {
          thread: 'user-123',
          resource: 'test-123',
        },
      },
    )

    return {
      list: response.text,
    }
  },
})
```

### 將 Agent 用作步驟

如毋須修改 Agent 呼叫，請使用 `createStep()` 將 Agent 組合為步驟。使用 `.map()` 將上一個步驟的 output 轉換為 Agent 可用的 `prompt`。

![將 Agent 用作步驟](/img/workflows/workflows-agent-tools-agent-step.jpg)

```typescript {1,2,5-10} title="src/mastra/workflows/test-workflow.ts"
import { testAgent } from '../agents/test-agent'
const step1 = createStep(testAgent)

export const testWorkflow = createWorkflow({})
  .map(async ({ inputData }) => {
    const { message } = inputData
    return {
      prompt: `Convert this message into bullet points: ${message}`,
    }
  })
  .then(step1)
  .then(step2)
  .commit()
```

詳情請參閱 [Input Data Mapping](/docs/workflows/control-flow#input-data-mapping)。

未提供 `structuredOutput` 選項時，Mastra Agent 會使用預設 schema，預期以 `prompt` string 作為 input，並以 `text` string 作為 output：

```typescript prettier:false
{
  inputSchema: {
    prompt: string
  },
  outputSchema: {
    text: string
  }
}
```

### 使用 structured output 的 Agent

當你需要 Agent 傳回 structured data 而非純文字時，請將 `structuredOutput` 選項傳給 `createStep()`。步驟的 output schema 會與你提供的 schema 相符，讓後續步驟可以 type-safe 方式串連。

```typescript {8} title="src/mastra/workflows/test-workflow.ts"
const articleSchema = z.object({
  title: z.string(),
  summary: z.string(),
  tags: z.array(z.string()),
})

const agentStep = createStep(testAgent, {
  structuredOutput: { schema: articleSchema },
})

// Next step receives typed structured data
const processStep = createStep({
  id: 'process',
  inputSchema: articleSchema, // Matches agent's outputSchema
  outputSchema: z.object({ tagCount: z.number() }),
  execute: async ({ inputData }) => ({
    tagCount: inputData.tags.length, // Fully typed
  }),
})

export const testWorkflow = createWorkflow({})
  .map(async ({ inputData }) => ({
    prompt: `Generate an article about: ${inputData.topic}`,
  }))
  .then(agentStep)
  .then(processStep)
  .commit()
```

`structuredOutput.schema` 選項接受任何 Standard JSON Schema。Agent 會產生符合此 schema 的 output，而步驟的 `outputSchema` 會自動設定為相符的 schema。錯誤處理策略、以 structured output 串流等更多選項，請參閱 [Structured Output](/docs/agents/structured-output)。

### `.agent()` 簡寫

使用 `.agent()` 直接加入 Agent，毋須以 `createStep()` 封裝。它接受與 `createStep(agent, options)` 相同的選項，也可以用 Agent ID string 代替 instance：

```typescript {8} title="src/mastra/workflows/test-workflow.ts"
import { testAgent } from '../agents/test-agent'

export const testWorkflow = createWorkflow({})
  .map(async ({ inputData }) => ({
    prompt: `Generate an article about: ${inputData.topic}`,
  }))
  .agent(testAgent, { structuredOutput: { schema: articleSchema } })
  .commit()
```

`.agent()` 會在 Workflow graph 中記錄 declarative entry，而非 opaque 步驟，因此以此方式建立的 Workflow 可以保留為[動態 Workflow](/docs/workflows/dynamic-workflows)。所有參數請參閱 [Workflow.agent()](/reference/workflows/workflow-methods/agent)。

## 在 Workflow 中使用 Tool

在 Workflow 步驟中使用 Tool，以重用現有 Tool 邏輯。當你需要準備 context 或處理回應時，請從步驟的 `.execute()` function 呼叫。如毋須修改 Tool 的使用方式，則將 Tool 組合為步驟。

### 呼叫 Tool

在步驟的 `.execute()` function 中呼叫 Tool。這樣你可以更精細地控制 Tool 的 input context，或先處理其回應再傳給下一個步驟。

```typescript title="src/mastra/workflows/test-workflow.ts"
import { testTool } from '../tools/test-tool'

const step2 = createStep({
  execute: async ({ inputData, requestContext }) => {
    const { text } = inputData

    const response = await testTool.execute({ text }, { requestContext })

    return {
      emphasized: response.emphasized,
    }
  },
})
```

### 將 Tool 用作步驟

當上一個步驟的 output 與 Tool 的 input context 相符時，使用 `createStep()` 將 Tool 組合為步驟。如果兩者不符，可以使用 `.map()` 轉換上一個步驟的 output。

![將 Tool 用作步驟](/img/workflows/workflows-agent-tools-tool-step.jpg)

```typescript {1,3,7-12} title="src/mastra/workflows/test-workflow.ts"
import { testTool } from '../tools/test-tool'

const step2 = createStep(testTool)

export const testWorkflow = createWorkflow({})
  .then(step1)
  .map(async ({ inputData }) => {
    const { formatted } = inputData
    return {
      text: formatted,
    }
  })
  .then(step2)
  .commit()
```

詳情請參閱 [Input Data Mapping](/docs/workflows/control-flow#input-data-mapping)。

### `.tool()` 簡寫

使用 `.tool()` 直接加入 Tool，毋須以 `createStep()` 封裝。它接受 Tool instance 或已註冊的 Tool ID string，以及步驟層級的 `retries` 和 `metadata`：

```typescript {5} title="src/mastra/workflows/test-workflow.ts"
import { testTool } from '../tools/test-tool'

export const testWorkflow = createWorkflow({}).then(step1).tool(testTool).commit()
```

與 `.agent()` 相同，`.tool()` 會記錄 declarative entry，因此 Workflow 可以保留為[動態 Workflow](/docs/workflows/dynamic-workflows)。所有參數請參閱 [Workflow.tool()](/reference/workflows/workflow-methods/tool)。
