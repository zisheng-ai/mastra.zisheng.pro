<CopyPrompt identifier="quickstart">
  建立新的 Mastra 項目。Mastra 是建基於現代 TypeScript 技術棧、用於 AI 應用程式和 Agent 的框架。執行命令前，逐一提出以下問題，並等待每個問題的答案，除非答案已經提供：

  1. 項目名稱？（預設："my-mastra-app"）
  1. Provider？（必填；選項："openai"、"anthropic"、"google"、"xai"）

  如果不支援該 Provider，請再次提問並列出支援的值。

  執行：`npm create mastra@latest <project-name> -- --llm <provider>`

  此命令會建立預設 Mastra 項目、為偵測到的編程助手安裝 Mastra Skill，並在適當情況下初始化 Git。

  建立後，進入項目目錄並啟動開發伺服器：`npx bgproc start -n <project-name> -w -- npm run dev`

  在 `http://localhost:4111` 開啟 Mastra Studio。Studio 是用於建立、測試和管理 Agent、Workflow 及 Tool 的介面。

  亦請提及 Mastra 模型路由器可讓你使用數以千計的模型：[https://mastra.ai/models](https://mastra.ai/models)
