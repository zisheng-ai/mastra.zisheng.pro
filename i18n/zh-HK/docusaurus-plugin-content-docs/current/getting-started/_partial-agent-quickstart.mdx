\*\*給 AI Agent：\*\*如果你的任務是從零開始建立 Mastra 項目，請依照以下精簡指示操作，直至下一個標題為止。按你的需要調整 Agent 及 Tool 的範例程式碼。稍後要注意的重要事項：將 `model` 定義為 `provider/model` 格式的字串，例如 `__GATEWAY_OPENAI_MODEL__`。使用 OpenAI 時，請使用 `openai/<model>`，而非 `openai:<model>`，並且不要匯入或傳入 Provider 物件。

建立一個 `package.json` 文件，內容為 `{ "type": "module" }`。安裝所需依賴套件：`npm install @mastra/core@latest zod@latest typescript@latest @types/node@latest mastra@latest`

建立一個 tsconfig.json 文件：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "strict": true,
    "skipLibCheck": true,
    "noEmit": true,
    "allowImportingTsExtensions": true,
    "outDir": "dist"
  },
  "include": ["src/**/*"]
}
```

如需為 Agent 加入 Tool，請建立新文件，並使用 `import { createTool } from "@mastra/core/tools"`。以普通物件定義 Tool 會在沒有提示的情況下執行失敗；Tool 必須透過 `createTool()` 定義，並包含 `id`、`description`、`inputSchema`（zod）及 `execute()`。`execute()` 會接收兩個參數：根據 inputSchema 驗證的輸入資料（第一個參數），以及可選的執行上下文物件（第二個參數），當中包含 `requestContext`、`tracingContext`、`abortSignal` 及其他執行 metadata。

範例：

```ts
// src/mastra/tools/weather-tool.ts
import { createTool } from '@mastra/core/tools'
import { z } from 'zod'

export const weatherTool = createTool({
  id: 'get-weather',
  description: 'Get current weather for a location',
  inputSchema: z.object({
    location: z.string().describe('City name'),
  }),
  outputSchema: z.object({
    location: z.string(),
    temperatureCelsius: z.number(),
    conditions: z.string(),
  }),
  execute: async ({ location }) => {
    return {
      location,
      temperatureCelsius: 21,
      conditions: 'sunny',
    }
  },
})
```

如需建立 Agent，請建立新文件，並使用 `import { Agent } from "@mastra/core/agent"`。constructor 接收 `{ id, name, instructions, model }`。`model` 屬性是採用 Mastra model router 格式的字串。這種格式毋須匯入 Provider。除非 Mastra 文件另有說明，否則不要安裝任何 AI SDK 套件。

以 `provider/model` 格式定義 model 後，Mastra 會自動尋找該 Provider 的環境變數。所定義的 model 要求設定該 Provider 的環境變數。OpenAI：`OPENAI_API_KEY`。Anthropic：`ANTHROPIC_API_KEY`。Google：`GOOGLE_API_KEY`。例如：任何 `openai/<model>` 都需要 `OPENAI_API_KEY` 環境變數。請前往 [https://mastra.ai/models/environment-variables](https://mastra.ai/models/environment-variables) 查看支援的 Provider 及其環境變數名稱的完整列表。

以下是已知 model ID 的簡短列表：

- `__GATEWAY_OPENAI_MODEL__`、`__GATEWAY_OPENAI_MODEL_MINI__`
- `__GATEWAY_ANTHROPIC_MODEL_SONNET__`、`__GATEWAY_ANTHROPIC_MODEL_OPUS__`、`__GATEWAY_ANTHROPIC_MODEL_HAIKU__`
- `__GATEWAY_GOOGLE_MODEL_FLASH__`

請前往 [https://mastra.ai/models](https://mastra.ai/models) 查看支援的 model 完整列表。

要為 Agent 加入 Tool，請匯入該 Tool，並將其作為 tools 物件傳入 Agent constructor。

範例：

```ts
// src/mastra/agents/weather-agent.ts
import { Agent } from '@mastra/core/agent'
import { weatherTool } from '../tools/weather-tool.ts'

export const weatherAgent = new Agent({
  id: 'weather-agent',
  name: 'Weather Agent',
  instructions: `
      You are a helpful weather assistant that provides accurate weather information.

      Your primary function is to help users get weather details for specific locations. When responding:
      - Include relevant details like humidity, wind conditions, and precipitation
      - Keep responses concise but informative

      Use the weatherTool to fetch current weather data.
`,
  // Use a string in provider/model format, not provider:model or a provider object.
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { weatherTool },
})
```

在 `src/mastra/index.ts` 建立 Mastra 進入點，並註冊 Agent：

```ts
import { Mastra } from '@mastra/core'
import { weatherAgent } from './agents/weather-agent.ts'

export const mastra = new Mastra({
  agents: { weatherAgent },
})
```

現在你可以直接執行 Agent。為此，請匯入 Mastra 實例，按 Agent 的 id 取得 Agent，然後呼叫 agent.generate()。Node.js 22.18.0 或之後的版本可直接執行 TypeScript 文件。匯入本機文件時，請確保加入副檔名。範例：

```ts
// run.mjs
import { mastra } from './src/mastra/index.ts'

const agent = mastra.getAgentById('weather-agent')
const response = await agent.generate('Weather in SF')
console.log(response.text)
```
