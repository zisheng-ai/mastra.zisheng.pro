# 區域

區域控制平台環境的執行位置、[託管式資料庫](/docs/mastra-platform/database)的放置位置，以及可觀測性資料的儲存位置。區域在建立環境時固定，之後無法變更。

Mastra platform 目前提供 `us` 和 `eu` 兩個資料駐留區域，背後由 Railway 的特定運算區域支援。資料庫及可觀測性會自動跟隨環境區域。

## 選擇區域

建立環境或首次部署至環境時傳入 `--region`：

```bash
mastra deploy --env production --region eu
mastra env create staging --region us
```

`mastra deploy --region` 和 `mastra env create --region` 都接受 `us`／`eu` 簡寫，或下表所列的正式 Railway 區域代碼。建議使用簡寫形式。

未傳入區域時，預設為 `us`，解析為 `pdx`（美國俄勒岡州波特蘭）。

## 可用區域

資料駐留選擇器在兩個區域內提供四個 Railway 區域。`us` 和 `eu` 簡寫會解析為各區域中標示為預設的項目。

| 區域 | Railway 代碼 | 位置 |
| - | - | - |
| `us` | `pdx`（預設） | 美國俄勒岡州波特蘭 |
| `us` | `iad` | 美國維珍尼亞州阿什本 |
| `us` | `sfo` | 美國加利福尼亞州三藩市 |
| `eu` | `ams`（預設） | 荷蘭阿姆斯特丹 |

如要將環境固定於特定數據中心，請直接傳入 Railway 代碼。傳入 `us` 會選擇 `pdx`，傳入 `eu` 則選擇 `ams`。

:::note
部署管線亦支援其他 Railway 區域（例如新加坡 `sin`），但資料駐留選擇器尚未提供，因為託管式資料庫及可觀測性目前在美國和歐盟以外沒有本地放置位置。傳入無法識別的區域會退回美國預設值，而不會固定於該區域。
:::

## 託管式資料庫放置位置

附加[環境範圍資料庫](/docs/mastra-platform/database)時，平台會選擇最接近環境的 Provider 區域。此設定由伺服器作準，因此在 `mastra env db create <env>` 明確指定的 `--region` 會被忽略。環境區域是唯一依據。

| 環境區域 | Turso 區域 | Postgres (Neon) 區域 |
| - | - | - |
| `pdx` | `sjc`（聖荷西） | `aws-us-west-2`（俄勒岡） |
| `iad` | `iad`（阿什本） | `aws-us-east-1`（北維珍尼亞） |
| `sfo` | `sjc`（聖荷西） | `aws-us-west-2`（俄勒岡） |
| `ams` | `ams`（阿姆斯特丹） | `aws-eu-central-1`（法蘭克福） |

項目範圍資料庫（由不同環境共用）不綁定於單一環境，因此接受明確的 `--region`。旗標須使用 Provider 區域 ID，而非 `us`／`eu` 簡寫：

```bash
mastra env db create --kind turso --region fra
mastra env db create --kind neon --region aws-us-east-1
```

Turso 提供超過 20 個區域，而 Postgres (Neon) 則可用於美國、歐盟及亞太區的 AWS 和 Azure 區域。完整清單請參閱 [Turso 區域清單](https://docs.turso.tech/features/data-edge#locations)及 [Neon 區域清單](https://neon.com/docs/introduction/regions)。如果傳入 Provider 不提供的代碼，附加時會因 Provider 錯誤而失敗。

## 可觀測性共置

可觀測性擷取目前在兩個區域運行：**美國**（愛荷華州，`us-central1`）及**歐盟**（阿姆斯特丹）。每個環境的 Trace、日誌及指標都會路由至符合其資料駐留區域的擷取區域：

| 環境區域 | 可觀測性區域 |
| - | - |
| `pdx`、`iad`、`sfo`、`us` 簡寫 | 美國（愛荷華州） |
| `ams`、`eu` 簡寫 | 歐盟（阿姆斯特丹） |

運算及資料庫可以放置於比可觀測性所支援更多的 Railway 及 Provider 區域，因此並非每個組合都能完全共置。`us` 區域的環境一律將遙測資料傳送至美國擷取端，而 `eu` 區域的環境則一律傳送至歐盟擷取端，即使底層 Railway 區域是擷取端點未有直接服務的特定城市亦然。資料駐留會在區域層級維持；來自 `eu` 環境的遙測資料絕不會跨境至美國。
