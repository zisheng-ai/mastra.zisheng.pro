# Mastra platform 上的 Observability

Mastra platform 上的 Observability 是獨立的託管式產品，為不同 Mastra 項目及部署提供可搜尋的 Trace、日誌和指標。如果你需要可觀測性功能，但不想先部署 Studio 或設定本機儲存空間，便可使用此產品。

將 Mastra 加入現有應用程式時，可使用 `mastra init` 設定平台可觀測性；在新建立的 Mastra 項目中，亦可手動設定。

## 快速開始

選擇符合你項目的設定途徑。

### 新項目

建立受管理的 Mastra 項目。系統提示時，選擇啟用 Mastra Platform Observability 以自動完成設定：

```bash npm2yarn
npm create mastra@latest
```

選擇可觀測性後，建立指令會向 Mastra Platform 驗證身份、佈建平台項目，並將憑證寫入項目。如果你略過平台設定或使用免提示建立流程，請改為按照[手動設定](#manual-setup)步驟操作。

### 現有的非 Mastra 項目

如果你已有應用程式（例如 Next.js 應用程式），但尚未加入 Mastra，請執行 `mastra init`，並在系統提示時啟用 Mastra Observability：

```bash npm2yarn
npx mastra init
```

CLI 可以選擇現有平台項目或建立新項目。

### 手動設定

在 [Mastra Platform](https://projects.mastra.ai) 建立項目，將 `MASTRA_PLATFORM_ACCESS_TOKEN` 和 `MASTRA_PROJECT_ID` 加入 `.env`，然後在 Mastra 設定中註冊 `MastraPlatformExporter`。如果你亦希望將可觀測性事件持久保存至已設定的 Mastra Storage，請加入 `MastraStorageExporter`：

```ts title="src/mastra/index.ts"
import { Mastra } from '@mastra/core/mastra'
import { Observability, MastraPlatformExporter } from '@mastra/observability'

export const mastra = new Mastra({
  observability: new Observability({
    configs: {
      default: {
        serviceName: 'mastra',
        exporters: [new MastraPlatformExporter()],
      },
    },
  }),
})
```

平台可觀測性所使用的環境變數，請參閱 [Mastra platform 設定](/docs/mastra-platform/configuration#observability)。

## 查詢可觀測性資料

當項目開始向 Mastra Platform Observability 發佈 Trace、日誌或分數後，你可以在終端機透過 Mastra CLI 或 `curl` 查詢這些資料。

```bash npm2yarn
npx mastra api trace list
```

對於可觀測性指令，CLI 會以託管式可觀測性 API 為目標，並可從項目環境推斷憑證。可用的可觀測性指令、篩選、分頁、憑證解析及直接使用 `curl` 的例子，請參閱 [`mastra api` CLI 參考](/reference/cli/mastra#mastra-api)。
