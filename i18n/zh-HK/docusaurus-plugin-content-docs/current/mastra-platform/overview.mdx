# Mastra platform

[Mastra platform](https://projects.mastra.ai) 提供三項產品，用於部署、監察及管理以 Mastra framework 建構的 AI 應用程式：

- [**Observability**](/docs/mastra-platform/observability)：每個平台項目的基礎產品，提供可搜尋的 Trace、日誌及指標，涵蓋不同 Mastra 項目和部署
- [**Studio**](/docs/mastra-platform/studio)：託管式視覺環境，用於測試 Agent、執行 Workflow，以及檢查 Trace。由 Studio 開始亦會同時獲得 Observability。
- [**Server**](/docs/mastra-platform/server)：生產環境部署目標，以 API 伺服器形式執行你的 Mastra 應用程式。由 Server 開始亦會同時獲得 Observability。

你可以使用單一指令 [`mastra deploy`](/docs/mastra-platform/deploy) 部署，或連接 GitHub repository 以推送觸發部署。關於連結 repository 的流程，請參閱 [GitHub 整合](/docs/mastra-platform/github)。

每個項目都可以執行多個 [**環境**](/docs/mastra-platform/environments)（例如 `production` 和 `staging`）、透過 CLI 或項目設定佈建 [**託管式資料庫**](/docs/mastra-platform/database)以持久保存應用程式資料，並為每個環境取得受管理的 [**Workspace**](/docs/mastra-platform/workspaces)，無須手動設定即可為 Agent 提供檔案系統及 Sandbox。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 可在 Agent 的 Trace 中找出反覆出現的目標、結果、行為及情緒。Trace Intelligence 目前以私人 beta 形式向指定項目開放。

## 開始使用

按你的目標選擇合適的途徑：

- **加入託管式可觀測性**：使用 [Observability](/docs/mastra-platform/observability) 收集跨項目及部署且可搜尋的 Trace、日誌和指標。如你希望先進行監察，而不部署 Studio 或 Server，請由此開始。
- **部署 Studio**：使用 [Studio](/docs/mastra-platform/studio) 為團隊託管視覺開發環境。如你需要共用 UI 來測試 Agent、執行 Workflow 及檢查 Trace，請由此開始。
- **部署 Server**：使用 [Server](/docs/mastra-platform/server) 將 Mastra 應用程式作為生產環境 API 伺服器執行。準備好從雲端提供 Agent、Tool 及 Workflow 時，請由此開始。

## 主要概念

**項目**是所有產品共用的上層實體。單一項目可以包含 Observability、Studio 及 Server 全部產品。項目隸屬於一個**組織**，亦即容納你團隊的多租戶容器。

你的 Mastra 應用程式由三種建構單元組成：

- [Agent](/docs/agents/overview)：可以使用 Tool、遵循指示及維持上下文的 AI Agent
- [Tool](/docs/agents/using-tools)：可供 Agent 呼叫的函式及整合
- [Workflow](/docs/workflows/overview)：協調 Agent 與 Tool 的多步驟編排管線

## 投入生產環境

使用 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本機開發項目，並開啟 [Studio](/docs/studio/overview)，在視覺環境中測試 Agent、Workflow 及 Tool。

準備好將應用程式部署至生產環境後，執行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy) 將應用程式推送至雲端。

請按照[部署](/docs/mastra-platform/deploy)文件中的逐步指示操作。

如你在自己的基礎設施託管 Mastra 應用程式，仍可透過 [MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform) 將可觀測性資料傳送至 Mastra platform。
