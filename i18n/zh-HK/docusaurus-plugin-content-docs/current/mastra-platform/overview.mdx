# Mastra platform {/* #mastra-platform */}

[Mastra platform](https://projects.mastra.ai) 提供三項產品，用於部署、監察和管理以 Mastra 框架建立的 AI 應用程式：

- [**Observability**](/docs/mastra-platform/observability)：每個平台項目的基礎產品，可搜尋不同 Mastra 項目及部署的 Trace、日誌和指標
- [**Studio**](/docs/mastra-platform/studio)：用於測試 Agent 和執行 Workflow 的託管視覺化環境，並提供檢查 Trace 的工具。以 Studio 開始亦會同時獲得 Observability。
- [**Server**](/docs/mastra-platform/server)：production 部署目標，以 API 伺服器形式執行你的 Mastra 應用程式。以 Server 開始亦會同時獲得 Observability。

只需一個指令 [`mastra deploy`](/docs/mastra-platform/deploy) 即可部署，亦可連接 GitHub 程式碼儲存庫，設定推送後自動部署。程式碼儲存庫連結流程請參閱 [GitHub 整合](/docs/mastra-platform/github)。

每個項目都可執行多個[**環境**](/docs/mastra-platform/environments)（例如 `production` 和 `staging`）、透過 CLI 或項目設定佈建[**託管資料庫**](/docs/mastra-platform/database)以持久保存應用程式資料，並為每個環境取得一個受管理的 [**Workspace**](/docs/mastra-platform/workspaces)，讓 Agent 無需手動配置即可使用檔案系統和 Sandbox。

[**Trace Intelligence**](/docs/mastra-platform/trace-intelligence) 可從 Agent Trace 中找出重複出現的目標、結果、行為和情緒。Trace Intelligence 現正以私人測試形式向部分項目開放。

## 開始使用 {/* #get-started */}

按你的目標選擇合適的方式：

- **加入託管 Observability**：使用 [Observability](/docs/mastra-platform/observability) 收集可搜尋的 Trace、日誌和指標，涵蓋不同項目及部署。如果你想先使用監察功能，而不部署 Studio 或 Server，請由此開始。
- **部署 Studio**：使用 [Studio](/docs/mastra-platform/studio) 為團隊託管視覺化開發環境。如果你想使用共用 UI 測試 Agent、執行 Workflow 及檢查 Trace，請由此開始。
- **部署 Server**：使用 [Server](/docs/mastra-platform/server) 將 Mastra 應用程式作為 production API 伺服器執行。準備好從雲端提供 Agent、Tool 和 Workflow 時，請由此開始。

## 主要概念 {/* #key-concepts */}

**項目**是所有產品共用的上層實體。單一項目可包含所有產品：Observability、Studio 和 Server。項目隸屬於一個**組織**，即容納你團隊的多租戶容器。

你的 Mastra 應用程式由三項基本元素組成：

- [Agent](/docs/agents/overview)：可使用 Tool、遵循指示並保留上下文的 AI Agent
- [Tool](/docs/agents/using-tools)：Agent 可呼叫的函數及可用整合
- [Workflow](/docs/workflows/overview)：協調 Agent 和 Tool 的多步驟編排管線

## 投入 production {/* #going-to-production */}

使用 [`mastra dev`](/reference/cli/mastra#mastra-dev) 在本機開發項目，並開啟 [Studio](/docs/studio/overview)，在視覺化環境中測試 Agent、Workflow 和 Tool。

準備好將應用程式部署至 production 後，執行 [`mastra deploy`](/reference/cli/mastra#mastra-deploy)，將應用程式推送至雲端。

請按照[部署](/docs/mastra-platform/deploy)文件中的逐步指示操作。

如果你在自己的基礎設施上託管 Mastra 應用程式，仍可使用 [MastraPlatformExporter](/docs/observability/integrations/exporters/mastra-platform) 將 Observability 資料傳送至 Mastra platform。
