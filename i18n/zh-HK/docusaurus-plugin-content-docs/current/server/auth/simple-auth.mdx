# Simple Auth

`SimpleAuth` 類別透過基本的 token 對應用戶方式，提供以 token 為基礎的身份驗證。它包含在 `@mastra/core/server` 中，適合用於開發、測試及基本 API 金鑰身份驗證情境。

## 使用情境

- 本機開發及測試
- 簡單的 API 金鑰身份驗證
- 整合完整身份 Provider 前製作原型
- 使用靜態 token 的內部服務

## 安裝

`SimpleAuth` 已包含在 `@mastra/core` 中，毋須安裝其他依賴套件。

```typescript
import { SimpleAuth } from '@mastra/core/server'
```

## 使用範例

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { SimpleAuth } from '@mastra/core/server'

// Define your user type
type User = {
  id: string
  name: string
  role: 'admin' | 'user'
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth<User>({
      tokens: {
        'sk-admin-token-123': {
          id: 'user-1',
          name: 'Admin User',
          role: 'admin',
        },
        'sk-user-token-456': {
          id: 'user-2',
          name: 'Regular User',
          role: 'user',
        },
      },
    }),
  },
})
```

## 配置選項

| 選項 | 類型 | 必填 | 說明 |
| - | - | - | - |
| `tokens` | `Record<string, TUser>` | 是 | token 與用戶物件的對應 |
| `headers` | `string \| string[]` | 否 | 用於檢查 token 的其他 header |
| `name` | `string` | 否 | 用於記錄日誌的 Provider 名稱 |
| `authorizeUser` | `(user, request) => boolean` | 否 | 自訂授權函式 |
| `protected` | `(RegExp \| string)[]` | 否 | 需要身份驗證的路徑 |
| `public` | `(RegExp \| string)[]` | 否 | 略過身份驗證的路徑 |

### 預設 header

SimpleAuth 預設會檢查以下 header：

- `Authorization`（有或沒有 `Bearer` 前綴皆可）
- `X-Playground-Access`

使用 `headers` 選項加入自訂 header：

```typescript
new SimpleAuth({
  tokens: {/* ... */},
  headers: ['X-API-Key', 'X-Custom-Auth'],
})
```

## 發出已驗證身份的請求

在 `Authorization` header 中加入你的 token：

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

或者不使用 `Bearer` 前綴：

```bash
curl -X POST http://localhost:4111/api/agents/myAgent/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: sk-admin-token-123" \
  -d '{"messages": "Hello"}'
```

## 自訂授權

加入按角色或自訂的授權邏輯：

```typescript
new SimpleAuth<User>({
  tokens: {
    'sk-admin-token': { id: '1', name: 'Admin', role: 'admin' },
    'sk-user-token': { id: '2', name: 'User', role: 'user' },
  },
  authorizeUser: (user, request) => {
    // Only admins can access /admin routes
    if (request.url.includes('/admin')) {
      return user.role === 'admin'
    }
    return true
  },
})
```

## 環境變數

在類似生產環境的設定中，從環境變數載入 token：

```typescript
const tokens: Record<string, User> = {}

// Load from environment
const adminToken = process.env.ADMIN_API_KEY
if (adminToken) {
  tokens[adminToken] = { id: 'admin', name: 'Admin', role: 'admin' }
}

const userToken = process.env.USER_API_KEY
if (userToken) {
  tokens[userToken] = { id: 'user', name: 'User', role: 'user' }
}

export const mastra = new Mastra({
  server: {
    auth: new SimpleAuth({ tokens }),
  },
})
```

## 配合 `MastraClient` 使用

使用你的 token 配置 client：

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
  headers: {
    Authorization: 'Bearer sk-admin-token-123',
  },
})

const agent = client.getAgent('myAgent')
const response = await agent.generate('Hello')
```

## 限制

SimpleAuth 以簡單易用為設計目標，而非生產環境的安全性：

- token 儲存在記憶體中
- 不設 token 到期或更新機制
- 不進行加密驗證
- 所有 token 都必須在啟動時已知

如用於生產應用程式，請考慮使用 [JWT](/docs/server/auth/jwt)、[Clerk](/docs/server/auth/clerk)、[Auth0](/docs/server/auth/auth0) 或其他身份 Provider。
