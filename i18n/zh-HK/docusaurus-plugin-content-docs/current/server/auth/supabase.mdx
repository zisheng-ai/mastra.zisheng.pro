# Supabase

`@mastra/auth-supabase` 依賴套件使用 Supabase Auth 為 Mastra 提供驗證。它會透過 Supabase 的驗證系統核實傳入請求，並使用 `auth` 選項與 Mastra 伺服器整合。

## 前置條件

此範例使用 Supabase Auth。請務必將 Supabase 憑證加入 `.env` 檔案，並確保 Supabase 項目已正確設定。

```env title=".env"
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

:::note

請檢查 Supabase Row Level Security（RLS）設定，確保資料存取控制正確。

:::

## 安裝

使用 `MastraAuthSupabase` 類別前，必須先安裝 `@mastra/auth-supabase` 依賴套件。

```bash npm2yarn
npm install @mastra/auth-supabase@latest
```

## 使用範例

```typescript {2,6-9} title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { MastraAuthSupabase } from '@mastra/auth-supabase'

export const mastra = new Mastra({
  server: {
    auth: new MastraAuthSupabase({
      url: process.env.SUPABASE_URL,
      anonKey: process.env.SUPABASE_ANON_KEY,
    }),
  },
})
```

:::info

預設的 `authorizeUser` 方法會檢查 `isAdmin` 欄；此欄位於 `users` 資料表，而資料表則位於 `public` schema。如要自訂使用者授權，請在建立 Provider 時提供自訂的 `authorizeUser` 函數。

如要查看所有可用設定選項，請參閱 [MastraAuthSupabase](/reference/auth/supabase)。

:::

## 用戶端設定

使用 Supabase Auth 時，你需要在用戶端從 Supabase 取得存取權杖，並將其傳入 Mastra 請求。

### 取得存取權杖

使用 Supabase 用戶端驗證使用者並取得其存取權杖：

```typescript title="lib/auth.ts"
import { createClient } from '@supabase/supabase-js'

const supabase = createClient('<supabase-url>', '<supabase-key>')

const authTokenResponse = await supabase.auth.signInWithPassword({
  email: "<user's email>",
  password: "<user's password>",
})

const accessToken = authTokenResponse.data?.session?.access_token
```

:::note

如要了解 OAuth、魔法連結等其他驗證方法，請參閱 [Supabase 文件](https://supabase.com/docs/guides/auth)。

:::

## 設定 `MastraClient`

啟用 `auth` 後，所有透過 `MastraClient` 發出的請求都必須在 `Authorization` 標頭中包含有效的 Supabase 存取權杖：

```typescript {6} title="lib/mastra/mastra-client.ts"
import { MastraClient } from '@mastra/client-js'

export const mastraClient = new MastraClient({
  baseUrl: 'https://<mastra-api-url>',
  headers: {
    Authorization: `Bearer ${accessToken}`,
  },
})
```

:::info

在 Authorization 標頭中，存取權杖前必須加上 `Bearer`。

如要查看更多設定選項，請參閱 [Mastra Client SDK](/docs/server/mastra-client)。

:::

### 發出已驗證請求

使用 Supabase 存取權杖設定 `MastraClient` 後，即可傳送已驗證請求：
